# S3 同步存储

让 Tau 使用 S3 兼容存储同步数据库、对话、资源和用量记录。支持私有桶，读写请求均使用凭据签名。

## 安装与配置

1. 使用支持同步插件的 Tau 0.59.0 客户端，在插件页安装 ZIP 并按提示重启、启用。
2. 打开“设置→同步”，选择“同步插件→S3 同步存储”。
3. 填写 Endpoint、Bucket、Region、Access Key ID、Secret Access Key，按服务商要求选择地址模式；路径前缀可选。
4. 保存后使用客户端原有的检查、上传和下载功能。自动同步仍由客户端设置控制。

配置与启用状态在重启后保留。停用插件不会删除配置；同步任务进行时不能停用或卸载插件。CLI可使用桌面配置好的同一目标。

## 常见问题

- **提示权限不足**：检查凭据、桶策略、Endpoint和区域。私有桶不需要开启公开访问。
- **服务拒绝条件写入**：版本提交使用条件创建，失败时客户端不会推进版本；插件不会通过覆盖现有记录绕过冲突保护。请保留错误信息以便排查服务兼容性。
- **已有S3同步配置**：新版客户端首次启动会迁入插件配置，无需重新填写。开发版0.1.0/0.1.1用户可通过ZIP升级到0.1.2。
