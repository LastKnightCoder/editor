# 火柴人

在 Tau 白板中放置人物与场景，表达动作、情绪、工作和团队关系。支持经典、豆豆、象形三种形体，单色或点缀配色，以及水平翻转。

安装插件并启用后，完整退出并重启 Tau。打开白板，在「扩展工具」中选择「人物」，选择一个姿态，再单击画布放置。

选中人物后，可在属性栏切换姿态、形体、配色和翻转。拖动四角可等比缩放，也可以连接箭头。人物跟随页面画风，或通过「笔触」单独设置普通、手绘及笔触强度。

新建人物沿用当前工作区上次选择的形体和配色。不同工作区各自保存偏好。偏好读取或保存失败时会提示错误。

人物可以复制、撤销和重做，支持图层名称、列表缩略图与白板图片导出。停用后已有内容显示为缺少插件的占位，重新安装并启用可恢复。

当前版本需要支持白板插件的 Tau 开发客户端，尚未公开发布。
