# GitHub 同步存储

使用 GitHub 仓库存放 Tau 数据和资源。

1. 在插件管理中安装并启用「GitHub 同步存储」。
2. 在「设置 → 同步」选择插件，填写仓库所有者、仓库名、已有分支、访问令牌和可选路径前缀，保存配置。
3. 使用客户端的检查、上传和下载；自动同步开关也由客户端管理。

需要包含渲染进程同步插件支持的 Tau 0.59.0 客户端。令牌需要具有目标仓库的内容读写权限。仓库与分支应先存在，插件不会代建。建议使用专用私有仓库，并确认不同知识库没有误用同一目录。

文件通过 GitHub Contents API 读写，受该服务的文件大小、频率及仓库权限约束；不提供额外的大文件上传方式。停用插件不会删除配置和远端数据。
