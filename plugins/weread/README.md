# 微信读书

将微信读书书架、划线与想法同步到 Tau，在书籍页面查看笔记，并将摘录用于搜索、引用、转卡片与转问题。

## 配置与使用

1. 在Tau插件管理中安装并启用“微信读书”。
2. 打开插件设置“账号与连接”，通过页面中的获取入口取得微信读书API Key，填写并验证连接。
3. 从侧边栏打开微信读书书架，执行同步后选择书籍查看划线与想法。
4. 在单书页复制Markdown、打开微信读书原文，或使用材料动作转为卡片/问题。

## 数据说明

需要Tau 0.59.0或更高版本。API Key与书架缓存按工作区保存，首次使用或从旧内置功能迁移后需要重新填写Key。
划线与想法保存为Tau摘录，停用插件后仍可引用。已保存摘录支持离线查看；整书书评及无原文想法需要连接后读取。远端确认移除的书籍会将对应摘录软删除，重新出现后复位。

同步失败时先在插件设置检查连接，再重试；不要在反馈中粘贴API Key。
