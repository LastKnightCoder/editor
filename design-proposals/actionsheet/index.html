移动端 ActionSheet 重设计 · 三套方案

现有面板是 iOS 原生居中样式，与应用的 Bento 卡片语言（左对齐、粉彩语义色、圆角卡片）脱节。以下三套方案均覆盖全部使用场景，并支持四主题切换预览。

每个方案内含 10 个可切换场景：文章菜单 / 项目菜单 / 节点菜单 / 任务操作 / 新建入口 / 卡片类型 / 任务类型 / 提醒时间 / 仓库空态 / 仓库加载。可切换杏子、玄夜、薄荷、海盐四主题验证融合度。
D

融合版（第二轮 · 根据反馈调整）

全宽贴底零空隙 + 操作回归 list-group 列表语言（卡内虚线行）+ 裸线性语义色图标，无底色块、无按钮感。

 › A

Bento 彩底图标（第一轮）

悬浮卡片组不贴边 + 语义粉彩底图标 + 危险项独立玫瑰卡 + 选中主色胶囊。最贴近现有主题语言。

 › B

夜航玻璃

全宽磨砂玻璃面板 + 顶部高光发丝线 + 同材质子卡。通透悬浮感，玄夜主题下最出彩。

 › C

纸感排版

去底色块、靠字号字重与细线分层 + 左缘主色指示条。安静克制，信息密度最低。

 ›

对应代码位置：通用面板 apps/mobile/src/components/ActionSheet.tsx（对象菜单 / 新建入口 / 任务操作 / 类型与提醒选择），设置选择面板 apps/mobile/src/features/settings/components/ActionSheet.tsx（Provider / 模型 / 仓库 / 分支，含加载与空态）。方案选定后两者将统一重构为同一套视觉语言。
