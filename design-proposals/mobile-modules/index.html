文章

写作与发布 · 阅读体验优先

定位是「打开即编辑」：置顶特写卡 + 杂志式卡片流的列表页；点开文章直接进入编辑器（无阅读/预览切换），标题与正文就地编辑、自动保存 + 实时字数；吸底工具条覆盖底部安全区，撤销/重做、加粗斜体删除线、标题、列表、引用、分割线真实生效；目录在左上角，底部弹出。封面以渐变 + 噪点呈现（实现时换真实图片）。

① 列表 ② 编辑器（默认编辑态）

迁移取舍：一期保留 置顶 / 标签 / 编辑 / 导出 MD 与长图 / AI 制卡；演示模式、EPUB 与 PDF 导出、播客生成仍留在桌面端（菜单中已如实标注）。

项目

工作容器 · 什么都能装

项目与知识库的关键区别：项目是容器，可容纳文档、PDF、网页、音视频、表格等八种节点。列表页分「活跃 / 已归档」；详情页用面包屑逐层下钻替代桌面端的常驻侧栏树（完整树收进抽屉）；每种节点有专属彩色图标；文档节点打开即编辑（吸底工具条）；PDF 附件节点展示阅读进度环与标注摘录。

① 项目列表 ② 详情 · 节点下钻 ③ 文档节点（编辑态） ④ PDF 附件

迁移取舍：一期 文档树型项目完整可用（新建 / 编辑 / 树浏览 / 关联引用）；表格项目只读预览；白板、音视频、网页、PDF 编辑为二期（添加菜单中已用「二期」角标如实标注）；思维导图二期只读。

知识库

知识沉淀 · 纯文档树 + 跨库关联

知识库是纯文档树，核心差异是关联：节点可关联卡片、文章与其他库的节点（徽标一目了然），底部关联面板就地增删。检索交给全局搜索入口（右上角，与现有全局搜索一致）。节点同样打开即编辑，配吸底工具条。

① 库列表 ② 库详情 · 关联徽标 ③ 节点编辑 · 关联面板

迁移取舍：一期 浏览 / 编辑 / 关联 / 导出全量保留；向量检索并入全局搜索（设置内提供「AI 与索引」管理入口）；网页剪藏等仍属项目域。

信息架构说明：三个功能均从「我的 → 功能」Hub 进入，作为二级页从右侧滑入（与现有「任务中心」一致），不动四 Tab Dock。视觉与交互词汇（页头、筛选 chips、Bento 卡片、虚线分隔、底部抽屉、Toast、四主题）全部复用线上「杏子 Bento」设计系统。
