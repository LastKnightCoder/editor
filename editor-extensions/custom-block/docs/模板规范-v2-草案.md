## 1. 模板契约

模板是一段 TSX，**不允许 `import`**（无模块系统），必须声明名为 `Component` 的无参组件：

```tsx
const { useState } = React;

const Component = () => {
  const [count, setCount] = useState(0);
  return (
    <div className="flex items-center gap-3">
      <ui.Button variant="secondary" size="sm" onClick={() => setCount(c => c + 1)}>
        点击 +1
      </ui.Button>
      <span className="text-tau-body text-ink-2">已点击 {count} 次</span>
    </div>
  );
};
```

运行时注入的全部绑定（v2 收敛为 4 个）：

| 绑定          | 内容                                                                                                                                                          |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `React`       | React 本体；hooks 一律 `const { useState, useEffect } = React` 解构                                                                                           |
| `ui`          | `@tau/ui` 精选子集，见 §3                                                                                                                                     |
| `useTokens()` | 主题钩子：`{ isDark, color(word) }`，`color("accent")` 返回当前主题下 `--tau-accent` 的计算值，主题切换时组件自动重渲染。专供 Canvas / SVG 属性 / JS 计算颜色 |
| `toast`       | `@tau/ui` 的命令式提示（替代 antd `message`）：`toast.success("已复制")`                                                                                      |

兼容：`hooks.useTheme()` 与 `components` 在 v2 运行时保留一个版本，读到时在控制台给出迁移提示；全部存量重写后删除（D-091 口径，不长期留兼容层）。

## 2. 样式规则

**2.1 载体**：Tailwind 类优先；Tailwind 表达不了的（CSS 新特性演示、复杂选择器、keyframes）写在模板内 `<style>`，且必须用 `@scope` 包起来（见 2.5）。少量动态值用 `style={{}}`。

**2.2 颜色只用语义类**（与应用同一套词表，随主题自动切换，**不需要也不允许** `dark:` 或 `isDark` 分支）：

| 用途          | 类名                                                                                                   |
| ------------- | ------------------------------------------------------------------------------------------------------ |
| 舞台/区域底色 | `bg-surface`（卡片面）`bg-sunken`（下沉区、画布底） `bg-page`                                          |
| 文字          | `text-ink-1` 正文 / `text-ink-2` 次要 / `text-ink-3` 注释、刻度                                        |
| 描边          | `border-line-1` 常规 / `border-line-2` 弱分隔                                                          |
| 强调          | `bg-accent text-ink-inverse` 实心；`bg-accent-soft text-accent-text` 轻量；`text-accent-text` 强调文字 |
| 状态          | `ok` / `warn` / `danger` / `info`，各有 `-soft` 底色                                                   |
| 交互态        | `hover:bg-hover` `active:bg-press` 选中 `bg-selected`                                                  |
| 分类/数据系列 | `tag-1` … `tag-5`（及 `-soft`），用于多个并列对象（多个盒子、多条曲线）                                |

`<style>` 与 `style={{}}` 中同样只写 `var(--tau-*)`。禁止 Tailwind 调色板（`bg-blue-500`、`text-zinc-800`）、hex、rgb。

**例外——演示色**：当颜色本身就是演示内容（渐变色标、`mix-blend-mode`、`color-mix()` 示例），可以写字面颜色，但要求：在浅色和深色下都清晰可辨；并且只用在被演示的那个元素上，外围的舞台、标签、说明仍走 token。

**2.3 尺度**：字号 `text-tau-body`（默认）/ `text-tau-meta` / `text-tau-sm`，代码与数值 `font-tau-mono`；圆角 `rounded-tau-sm` / `rounded-tau-md`；阴影只用 `shadow-card`；缓动 `ease-tau-out`。不用 Tailwind 默认刻度 `text-sm` / `rounded-lg` / `shadow-md`。间距、宽高用 Tailwind 默认刻度即可。

**2.4 与文档合为一体**：

- 块外框（标题栏、源码切换）由编辑器提供，模板**不要**再包一层带阴影的大卡片。
- 宽度跟随正文栏，不写死宽度；高度由内容撑开，Canvas 等需要固定高度时给 `h-[240px]` 这类明确值。
- 推荐的演示骨架：`舞台（bg-sunken rounded-tau-md p-6，居中放被演示对象） + 控件行（gap-3，ui 组件） + 读数（text-tau-meta text-ink-3 font-tau-mono）`。

**2.5 样式隔离**：模板 `<style>` 一律写成

```tsx
<style>{`
  @scope {
    .target { transition: scale .3s var(--tau-ease-out); }
  }
`}</style>
```

无前缀的 `@scope` 只作用于 `<style>` 的父元素子树，不会泄漏。`@keyframes` 不受 `@scope` 约束，名字加块内前缀（如 `cb-snap-bounce`）。

## 3. `ui` 子集

只暴露与演示相关、能对应原 antd 用法的组件：

| `ui.*`                                                         | 替代 antd           |
| -------------------------------------------------------------- | ------------------- |
| `Button`（variant: primary/secondary/soft/ghost，size: sm/md） | `Button`            |
| `IconButton`                                                   | —                   |
| `Input` / `Textarea` / `NumberInput`                           | `Input`             |
| `Switch` / `Checkbox`                                          | —                   |
| `RadioGroup` / `Radio`                                         | `Radio`             |
| `Select`                                                       | —                   |
| `Tag`                                                          | —                   |
| `Spinner`                                                      | `Skeleton` / 加载态 |
| `toast`（顶层绑定）                                            | `message`           |

`Flex` / `Card` 改用 Tailwind（`flex gap-3`、2.4 的舞台）；`Progress` 用两层 div；`ColorPicker` 用原生 `<input type="color">`。
不暴露 Dialog / Drawer / Menu 等浮层组件：块是文档内容，不应弹出应用级浮层。

## 4. 行为规则

- 所有 `addEventListener`、`setInterval`、`requestAnimationFrame`、`ResizeObserver` 必须在 effect 清理函数中释放（块会因编辑、主题切换、滚出视口反复挂载卸载）。
- 只操作自己子树的 DOM（用 ref），禁止 `document.querySelector` 读写块外元素、改 `document.body` 样式。
- `position: fixed` 只在演示锚点定位等确需时使用，并确保卸载后不残留。
- 禁止网络请求、`localStorage` 持久化、读写 `window` 上的全局变量。
- Canvas：按 `devicePixelRatio` 设置画布尺寸，用 `ResizeObserver` 跟随宽度重绘；颜色取自 `useTokens().color(...)`，并把它放进 effect 依赖，主题切换即重绘。

## 5. 文案

- 简体中文，短句，全角标点；不用 emoji。
- 控件文案是动词短语（「重置」「播放动画」），读数格式 `标签：值`（`距离：128px`）。
- 说明文字放在文档正文里，块内只保留操作所需的最少文字。
