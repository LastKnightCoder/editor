## 1–5. 模板规则（已迁至 skill）

契约、样式、`ui` 子集、行为与文案规则的正文统一维护在应用内置 skill
`apps/desktop/src/constants/internal-skills/custom-block.md`（AI 生成与人工编写共用，单一事实源）。
skill 中的示例由 `internal-skills/__tests__/custom-block.test.ts` 守护：静态检查旧写法，并在 v2 运行时中实际渲染。
修改运行时注入的绑定或 `ui` 子集时，必须同步更新该 skill。

与草案初稿相比的调整：注入绑定增加 `icons`（lucide 全量，动态加载）；`ui` 子集增加 `IconButton` / `Tooltip` / `Popover`。

## 6. 运行时改造清单

1. ✅ 运行时 Tailwind 输入改为 `theme + utilities` 两层 + `@tau/themes/tailwind.css`（去掉 preflight，接入语义类）——R1、R2。主进程 `tailwind-runtime.ts` 以 `?raw` 内联映射并随任务传给 worker；发布生成器、浏览器扩展走同一模块，自动生效。
2. ✅ 注入 `ui` / `toast` / `useTokens`，移除 ahooks、`extraInfo`（0 处使用）与重复的 `useTheme`——R4、R5。宿主主题改为传 `useEditorTheme()` 整个对象，主题族/token 变化也会触发重渲染。
3. ✅ 错误态改用 `text-danger`，外层容器去掉 `--font-size`——R7。
4. ✅ 删除 antd Proxy 垫片与 `components` / `hooks` 兼容绑定（库内 72 篇 197 块已全部按 v2 重写）——R8。
5. ✅ 新建块的默认模板改为符合本规范的骨架。

## 7. 已确认的取舍

- 交互控件注入 `@tau/ui` 子集；`ui.*` 的 props 因此成为模板契约的一部分，改动需同步 skill。
- 演示色例外成立，只限被演示元素。
- R3 本轮不处理，记为已知限制：mobile / blog 应用内编辑器中模板 Tailwind 类不生效；桌面端、浏览器扩展、发布站点正常。
- 浮层只提供非模态的 `Tooltip`（悬停说明）与 `Popover`（点开详情）；`Dialog` / `Drawer` / `Menu` 不进契约——文档内容不弹模态遮罩，且编辑块源码时块会重新挂载，打开的模态浮层会直接消失。
- `icons` 提供整个 lucide 图标库（用户选择全量而非精选集），只在渲染自定义块时随运行时一起动态加载，不影响应用首屏。
