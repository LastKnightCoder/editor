# 链接扩展

`@tau/editor-link` 持有链接模型、渲染、链接浮层、工具条/快捷键、粘贴成链和 wrapLink/unwrapLink 操作。链接打开消费 @tau/shared/host-services 的 IOpenerService。

```ts
import { createEditorKit } from "@tau/editor";
import linkExtension from "@tau/editor-link";

export const kit = createEditorKit({ extensions: [linkExtension] });
```

- 根入口安装元素类型增强并导出扩展，宿主显式选择是否装配。
- /types 仅提供模型类型，不加载 React 或编辑器运行时。
- /markdown 导出 linkCodec，显式加入 createMarkdownProcessor 的 codecs；可独立进行无 DOM 类型检查。
- 样式扫描须包含本包 src；复用核心和设计系统的样式契约，颜色只取 `--ed-*`。

生产实现仅消费核心公开 API；命令 id 和持久化 type 不随迁包更名。只读查看不写入文档。

## 交互约定

每个编辑器只挂一个链接浮层（扩展 `layers`），查看、编辑、新建、撤销提示在同一容器里原地切换，尺寸与位置平滑过渡；状态与计时在 `panel/controller.ts`，文档写入只在 `operations.ts`。

| 场景     | 行为                                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------ |
| 行内样式 | accent 字色 + 淡下划线，悬停或浮层打开时下划线变实色；按住 ⌘/Ctrl 显示手型                                               |
| 悬停     | 停留 350ms 出现，离开有 220ms 宽限；已打开时移到另一链接立即切换；跨行链接贴指针所在行                                   |
| 光标进入 | 光标停在链接里 450ms 后出现，离开即收起；开始打字收起，且在离开该链接前不再自动弹出                                      |
| 打开     | ⌘/Ctrl 点击或浮层「打开」；编辑态单击只放光标，只读时单击打开                                                            |
| 新建     | ⌘L / 工具条：选区在链接里时编辑，否则新建。新建期间文档不变，选区经 CSS Highlight 保持高亮；回车成链，Esc 取消并还原选区 |
| 编辑     | 可同时改文字（仅纯文本链接）与地址，确认时一次写入（一次撤销还原）；↵ 与点外面都算完成，Esc 还原；地址清空即取消链接     |
| 取消链接 | 浮层原地变为「已取消链接 · 撤销」，保留 3.5s                                                                             |
| 粘贴     | 剪贴板是单个网址时：选区上直接成链，光标处插入为链接；已在链接里、行内代码中或跨块选区按纯文本粘贴                       |
| 地址校验 | 像域名的补 `https://`；只拦含空白、漏冒号、协议拼错等明显错误，相对路径与 `#锚点` 放行                                   |

宿主自建工具条（如移动端）调用 `openLinkPanel(editor)` 走同一个浮层，不要自行插入空链接。浮层关闭经 OverlayBackDismiss 接宿主返回/Esc 仲裁。
