# 主题系统重设计 + 资源管理模块重构(对齐 Eagle)

设计语言:**中性表面 + 单一 Accent + 亮度分层**(参考 Raycast/Linear/Arc)。工程原则:**不留兼容别名**,全应用一次性切换到一套 token,旧变量定义全部删除。

## 阶段 1:新主题体系落地

### 1.1 重写 `styles/theme-colors.css` —— ~24 个核心 token 成为唯一真相源

- **表面(亮度分层,不再染色)**:`--th-bg-page / --th-bg-surface / --th-bg-elevated / --th-bg-hover`,中性配方带轻微冷调(oklch hue 250、chroma ~0.006),明暗两套
- **文字**:`--th-text-1 / 2 / 3` + `--th-text-on-accent`
- **边框**:`--th-border-subtle / default / strong`
- **Accent**:由单输入(色相)派生 `--th-accent / hover / active / soft(淡背景)/ text`
- **状态色**:`--th-success / warning / danger / info`
- **其它**:`--th-overlay / --th-shadow / --th-focus-ring`
- **柔光装饰**:页面底层 radial 光晕从 accent 派生,仅作背景装饰层,不参与任何组件 token

### 1.2 Accent 预设收敛 + 旧值迁移

- `data-accent` 从 gradient1~9 + solid(10 值)收敛为 6 个精选色:indigo / violet / rose / emerald / amber / graphite,每个保证明暗两版对比度达 WCAG AA
- 旧 `backgroundType` 一次性迁移:gradient1→violet、gradient2/7→indigo、gradient3→amber、gradient4→emerald、gradient5→rose、gradient6→graphite、gradient8→amber、gradient9→rose,同时默认开启柔光;在 `useSettingStore.applyAppearanceFromSetting` 读取时映射并写回(localStorage 与 setting.json 同步)

### 1.3 重写 `hooks/useThemeColors.ts`

- class key 从 39 个收敛到 ~20 个:保留高频 key 且**名称不变**(cardBgClass / textClass / secondaryTextClass / borderClass / hoverClass / primaryButtonClass / activeTextClass / tagBgClass / inputBgClass / modalPanelBg 等),204 个消费文件零改动
- 删除冷门 key(pinned* / icon-deep* / badge-active / tagCountBg 等单点消费项),受影响的 ~30 个文件改为等价高频组合
- 删除 GRADIENTS 9 套配置,graphNode / timeline / twoTone 等 raw 色改为从 accent 单公式派生

### 1.4 重写 `hooks/useAntdThemeToken.ts`

- 删除 themeTokenMap / overlayTokenMap 7 套硬编码(~80 个色值)
- colorPrimary / overlay 全部从 accent 与 elevation token 派生,消灭"选了主题但 antd 回退灰色"的不一致

### 1.5 设置页与背景收敛

- `AppearanceSetting`:10 张渐变卡 → 明/暗切换 + 6 个 accent 色卡 + 柔光开关(保留背景动画开关)
- `ContentLayout` 的 BACKGROUND_GRADIENTS 9 套硬编码删除,改为 accent 派生的单一柔光实现(与设置页共用一份来源)

## 阶段 2:全应用替换旧变量,然后删除(无别名)

执行顺序:**先落新 token(旧变量保持原值并存)→ 全量替换引用 → 删除旧定义**,任何时刻都不存在"指向别家"的别名。

- 替换 `tailwind.css` 工具类层的 `--color-*` / legacy 引用
- 替换 8 个直接消费 `--color-*` 的组件、几十个消费 legacy 变量的文件(`--common-hover-bg` 28 文件、`--line-color` 22、`--active-text-color` 16、`--text-normal` 11 等)→ 新 token
- 替换 17 个直接引用 `--th-*` 的文件到新 token 名
- 清空 `themes/dark.less / light.less` 中的 `--color-*`(26 个)与 legacy(34 个)定义,合并两处重复的 antd 毛玻璃段为一份
- 范围界定:其它模块里散落的硬编码 `dark:bg-zinc-*` 原子类(zinc 本身接近新中性色)本次不动,避免范围失控;资源管理模块内的硬编码在阶段 3 一并 token 化
- `packages/themes`(blog 发布站点用)是独立副本,本次不动

## 阶段 3:资源管理模块重构(基于新 token,对齐 Eagle)

1. **顶部工具栏** `ResourceToolbar.tsx`:分类名+数量、搜索(侧边栏搜索框移除)、排序下拉(更新时间/名称/类型/引用次数)、视图切换(网格/列表)、上传、刷新
2. **网格卡片重设计** `ResourceCard.tsx`:`aspect-[4/3]` 统一比例;选中态(accent 边框+角标);图片 hover 缩放;视频 hover 播放蒙层+时长角标;非图片资源类型化彩色 icon tile(消灭灰块);信息区名称+类型徽章+引用数;`typeConfigs` 两处重复定义抽为共享常量;右键菜单(预览/重命名/移动分组/在文件夹中显示/复制路径/删除)
3. **列表视图** `ResourceListView.tsx`:@tanstack/react-virtual 虚拟化表格(缩略图/名称/类型/分组/引用数/更新时间),多选、右键、双击预览
4. **多选与批量**:Cmd/Ctrl 点选、Shift 范围选、点击空白清除;批量操作条(移动分组/删除/取消)
5. **删除资源**:后端 `ResourceTable.deleteResources(db, ids)`(仅删记录)+ `getListenEvents` 注册 `resource:delete`;前端命令封装+store action;确认弹窗提示"不删源文件,仍被引用的资源重新扫描后会再出现"
6. **排序**:前端排序 × 升/降序,store 持久化
7. **大图预览**:复用 `ImageGallery`(当前视图图片数组+defaultIndex),双击/空格触发,←/→ 翻页
8. **快捷键**:空格预览、Del 删除、Cmd/Ctrl+A 全选、Esc 清除
9. **详情栏美化**:紧凑定义列表、补展示创建/更新时间、PDF/EPUB 视觉与网格统一、全 token 化
10. **空状态**加上传/刷新引导按钮
