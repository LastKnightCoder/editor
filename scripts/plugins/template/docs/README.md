# Tau 插件开发文档

默认模板使用 SDK 0.36.0、UI 0.4.0，生成格式 3 的同一插件包。中心 v2 支持上传待审，格式 3 必须人工批准上架；平台测试由作者负责，不要求审核者测试或填写验证记录。Android/iOS 正式安装要求客户端至少 0.2.1，并通过中心兼容选版。先读 [API 支持矩阵](api-support.md)、[跨端契约](portability.md)与[快速开始](getting-started.md)。下文桌面领域接口不表示移动端可用。

Tau 插件用 TypeScript 和 React 编写，打包成一个 ZIP，安装后在 Tau 桌面端运行。插件可以给 Tau 加页面和侧边栏入口，在文档里放自定义块，给 AI 提供工具，接入第三方存储、语音、视频等服务，或者读写用户的卡片和待办。

这份文档按"从零写出一个插件"的顺序组织。第一次接触时按下面的路线读，之后按需查阅。

## 阅读路线

1. [快速开始](getting-started.md)：装好环境，跑通模板自带的计数器，再把它改成自己的插件。
2. [插件的组成](plugin-basics.md)：manifest、入口、生命周期和 `context`，所有能力都建立在这些概念上。
3. 按你要做的功能，读下表中对应的文档。
4. [发布与更新](release.md)：发布到插件中心，以及之后怎么发新版本。

## 约定

- 插件接口从 `@tau/plugins` 导入，界面组件从 `@tau/ui` 导入。它们的实现由 Tau 在运行时提供，模板的构建配置已经处理好，不需要你打包。
- 文中的 `context` 指 `activate(context)` 收到的插件上下文；代码片段如果没有写出外层结构，默认放在 `activate` 里。
- 所有接口都有完整的 TypeScript 类型。文档讲用法和规则，参数的精确类型以编辑器里的类型提示为准。
- 可用版本与能力由目标声明和实际宿主共同决定。

## 给 AI 编程助手

模板根目录的 `AGENTS.md` 是给 AI 编程助手看的项目指引。用 AI 写插件时，让它先读 `AGENTS.md` 和本目录下与任务相关的文档。
