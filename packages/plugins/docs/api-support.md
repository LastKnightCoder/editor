# 插件 API 支持矩阵

本表描述当前 SDK 与仓库宿主实现，不代表线上已发布客户端。统一 API 契约随 SDK、模板、中心和作者插件一起更新，不保留旧能力别名。桌面与移动均接入格式 3 的安装和内容装配，实际发行版本与设备验收独立记录。网页插件中心只浏览与分发，不执行插件；具体发行和设备验证见任务记录。

作者使用同一套 API，宿主负责具体实现和作用域。作者清单只声明支持平台、最低版本与用户数据权限，不填写能力列表；未接入移动端业务接口的插件暂不声明移动目标。调用失败、只读与用户授权继续遵循各 API 的明确语义。

## 上下文 API

“已接”表示存在真实适配或公共实现；“部分”后的边界是支持范围；“未接”不能靠作者改布局解决。Android 与 iOS 目前具有相同 API 子集，但交互验收分别进行。

## ASR 与 WebSocket

SDK 0.43.0 的 `context.asr`、`context.websocket` 与 `settings target: "asr"` 已接桌面 0.59.5、Android/iOS 0.2.7 宿主源码。移动插件使用同一注册、配置和事件接口，音频由宿主采集，插件不访问麦克风。当前仅保留能力层，语音输入与整理的按钮、设置页和导航尚未挂载；ASR 表单可注册，open 返回入口不可用。设备与真实云端账号验收单独记录；Windows 已完成平台评估，本轮保留 NSIS 且不开放原生识别；Whisper 文件转录已实测，Seed 完成宿主契约验证但未验证真实云端账号。

ASR 支持能力探测、可取消的流式会话与可选文件任务；提供方必须真实声明能力，Seed 当前仅流式。WebSocket 的工厂仅扩展鉴权头和 signal，连接保留标准事件、状态、同步 send/close；详见 [WebSocket 契约](websocket.md)。桌面整理服务复用现有模型配置，保留原文和失败回退；输入目标及界面位置由后续接入方决定。

## 声明边界

宿主功能不再维护重复的字符串词表。context.fetch/sync/upload、源码编辑、媒体与样式编译直接使用现有 API；editorExtensions/editorCodecs/whiteboardExtensions 是实际注册内容。清单不再有 requires、required、optional、editor、whiteboard 或节点等级，新构建和上传严格拒绝这些字段。

白板 getService 和 tryGetService 直接访问宿主按扩展绑定的服务注册表，不再重复填写依赖表。必需服务缺失抛错，可缺省服务通过 tryGetService 返回 undefined；插件存储隔离与资源回收继续由宿主控制。

权限、节点数据校验、资源字段、样式源码字段以及 AI 功能定义继续保留，它们分别约束授权、数据或实际行为。移动目标的非空 permissions 仍在构建、上传和求值前拒绝。

## 作者选择与发行边界

1. 先列出插件用到的 API；全部落在移动已接范围，才声明对应移动 target。
2. 若仅交互不同，共用数据/codec，按容器宽度与输入提供操作；未完整适配的平台暂不声明。
3. 若依赖宿主未接的业务能力，保留桌面版本，不用改清单假装兼容。计数器和 ABC 的结论不能外推到所有插件。
4. 官方插件新发行统一使用格式 3；仅桌面插件也声明 desktop target。历史已发行记录不改写，历史客户端选版边界保留。增加平台需同一插件 ID 的更高版本，不覆盖已发布 ZIP、重命名节点或自动清数据。
5. SDK、模板、中心与宿主共用平台和版本契约；不保留重复能力声明或名称映射。普通提交人工批准，具审核权限的作者本人通过已绑定仓库 CI 发布可自动批准。平台适配与功能测试由作者负责，不要求审核者测试或填写验证记录。是否可安装由平台、客户端版本与中心开关共同决定，不能由 npm 版本推断。移动中心首次安装默认保存启用意图，下次打开生效；桌面新装默认停用，用户启用后重启内容插件；更新保留显式启停选择。任意开发 URL 安装仅限调试构建。

已完成的自动测试与模拟器行为验证不替代真机、最低系统、完整 IPA、桌面原生安装包发行、未知旧作者迁移或应用商店验收。

## 正文字数

SDK 0.44.0 的静态 editorMetrics 在桌面与移动内容注册表装配；桌面主进程只接收校验过的字段声明，不执行插件函数。动态工作台使用 metrics 字段。作者用法见[正文字数与空文档](content-metrics.md)。

## 白板协作作者接口

| 能力                                          | 桌面源码实现                                    | 移动端 / 浏览器扩展 / 博客 | 边界                                                     |
| --------------------------------------------- | ----------------------------------------------- | -------------------------- | -------------------------------------------------------- |
| dataVersion、textFields、resources 与历史版本 | 托管白板已接                                    | 未提供白板作者宿主         | 精确契约分发，安装不自动转换                             |
| 身份命令、普通 data 补丁、文本句柄            | 已接                                            | 未接                       | 不开放路径操作、Y.Doc、任意 Map 或嵌套富文本槽           |
| 宿主统一撤销与异步生命周期守卫                | 已接                                            | 未接                       | captureSubmission 不是修订 CAS；普通提交不代表服务端确认 |
| 无插件载荷、跨页、复制与可编辑导出            | 已接                                            | 未接                       | 外部实体不隐式授权，资源跨文档需重新登记                 |
| 远端分享、换代及旧数据转换                    | 主进程/命令层已有接缝与测试，普通 UI 尚无调用方 | 未接                       | 不宣称已可面向用户启用；版本与入口验收属于发布门禁       |

白板 API 与编辑器字段契约共用公共实现，扩展装配 apiVersion 当前仍为 1。SDK 0.45.0 提供本节的身份命令、dataVersion 与文本绑定，0.44.0 及更早版本的旧白板接口须适配。运行时需要首个通过组合验收的桌面发行版，源码桌面 0.59.5 仅为候选。插件中心 compatible 只证明平台、包格式与最低版本等安装条件通过，不证明旧插件具备新白板数据契约；作者必须逐插件适配，不能只提高包版本。用法见[白板扩展](whiteboard.md)与[协作约束](whiteboard-collaboration.md)。
