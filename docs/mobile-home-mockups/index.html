移动端「今天」首页 · 布局 mockup

配色取自 apps/mobile/src/styles.css 的浅色 token，数据取自真机当前截图。三个方向的共同点：区分「今天要做的事」和「资料库规模」两种信息，统一数字位置，消除栅格空洞，去掉重复的今日任务。

现状问题
1. 4 张通栏卡（任务 / 番茄 / 日程 / 闪卡）竖着堆，数字一会儿在左、一会儿在右、番茄没有数字，视觉节奏乱。
2. 半宽卡只剩 3 张（日记 / 卡片 / 文章），去掉知识库后右下留出空洞；「项目」又回到通栏，数字在左。
3. 「今日任务」出现两次（顶部统计 + 下方列表）；而且顶部 215/257 是全部任务的累计数，不是今天的，标题有误导。
4. 行动类（复习、专注、写日记）和统计类（卡片总数、文章数）权重相同，首屏看不出「现在该做什么」。
5. 「最近」一次列 10 条，页面过长。

A · 今日焦点 + 2×2 行动 + 资料库条

任务统计和任务列表合成一张「今日焦点」卡；番茄 / 日程 / 闪卡 / 日记做成等大方块（图标在左上、数字在右上，位置统一）；卡片 / 文章 / 项目压成一条三栏统计。模块关掉时剩奇数个方块，最后一块自动占两栏。改动量最小，推荐。
