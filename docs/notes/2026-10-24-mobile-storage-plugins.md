## 实现范围

- 桌面、Android 与 iOS 共用同步、上传、fetch 和领域设置 API；作者只表达注册与保存意图。两端宿主决定持久化、选用、任务及原生传输。
- 七个官方提供方保留桌面表单，迁入移动账号卡与位置表单；公共 ConfigurationPanel 负责草稿取消与保存快照。WebDAV 同包提供同步和上传，两份配置独立。
- 移动旧集成账号一次性复制到各插件完整配置，不统一账号共享。保留当前选择与所有配置；已有插件配置优先，旧值保存在源内容摘要命名的私有备份。
- 旧路径按原生实际规则修剪首尾空白、斜杠，旧资源账本按原始配置定位；恢复同一有效目标，不从新 UI 字符串猜目录。
- 原生服务商提供方与账号验证分支退役，改为通用 JS 调用。配置、选择、同步元数据经原子更新，旧设置快照不能覆盖新值；切库撤销旧会话，迟到结果不交付。
- 修复 S3/OSS 列举错误转空、目录前缀失真，以及桌面 OSS 表单误读校验结果。跨端 API 包装保留动态 getter，不冻结环境快照。

## 边界

- 本轮只生成 SDK 0.38.0、UI 0.5.0 与插件候选，未执行推送、中心部署或客户端发布；tarball/ZIP 仅保存在本地。公开锁文件记录待发行候选摘要，普通 npm 安装需等待对应版本发布，开发验证使用候选注入流程。
