# 同步覆盖后的连接恢复验证

日期：2026-11-25。环境：本机 macOS；资料库及 Electron 系统路径使用临时目录，未操作用户资料库或远端同步服务。

## 改动与回归范围

日程、闪卡与测验订阅资料库连接身份；同名覆盖后重建命令及查询缓存。主进程将新身份广播给存活窗口；旧命令继续被拒绝，旧读取或写入的迟到响应不能覆盖新缓存。同步完成刷新跳过失效查询；先到的新广播不会被旧连接响应覆盖。

新增回归在修复前复现三个已挂载页面仍显示旧内容，修复后通过。最终相关回归 59 项通过；两项压力用例按环境门控单独执行并通过。

## 压力结果

| 层次                                       | 规模                                      | 结果                                                                         |
| ------------------------------------------ | ----------------------------------------- | ---------------------------------------------------------------------------- |
| React 页面、查询缓存、命令封装             | 16 个保留视图，200 轮连接替换             | 29,821 次有效调用；200 次主动旧连接调用全部拒绝                              |
| 主进程 handler、真实 SQLite 文件替换与事务 | 100 次替换，16 组并发读取，两窗口接收广播 | 6,400 次读取、100 次写入；200 次旧请求全部拒绝；另一资料库身份与数据保持一致 |

页面层仅替换 IPC 传输；主进程层仅替换 Electron 窗口与系统路径。迟到读取、迟到写入、重复通知和连接响应乱序由确定性回归覆盖。

## 适用边界

本次没有执行 Windows 安装包或真实 WebDAV 服务端到端测试，也没有进行视觉验收。测试结果覆盖本机上述规模与场景，不表示所有操作系统和时序组合都已穷尽。

通用连接发布、订阅和查询身份隔离已建立；页面接入及回归范围为日程、闪卡、测验。静态复查还发现数据库图库封面、行详情及部分白板宿主服务按库名缓存命令：同名覆盖后若组件继续保留，存在同类风险，尚未逐项复现。编辑入口的后续接入须保留旧草稿与在途写入隔离，不能让全部旧命令自动改用新连接。
