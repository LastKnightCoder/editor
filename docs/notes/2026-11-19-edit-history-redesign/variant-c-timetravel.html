方案 C · 沉浸式时间旅行

出现位置
不再有独立面板：整个正文区接管为只读历史视图，正文本身就是预览
入口
正文右上「时钟」图标 / 菜单「回到过去」，进入后顶部出现时间胶囊，Esc 退出
交互
时间胶囊：节点滑轨（颜色=作者）+ 前后步进 + 键盘 ←/→ 穿梭版本
diff 呈现
inline 落在正文原位：绿=恢复后会回来的内容，红删除线=恢复后会失去的内容（相对当前）
优势
零翻译成本——看到的就是文档当时的样子；对照最直觉
代价
进入即只读，与写作互斥；长列表筛选/检索能力弱于 B
