# 白板删除与内部笔迹分段排查、修复和压力验证

目标：删除手写、导图或包含它们的容器后，不出现内部存储节点的“缺少扩展”占位，删除、撤销、重做和协作合并保持数据一致。

## 原因与修复

手写由主体和 `host.whiteboard.stroke-segment` 存储子节点组成，画布投影不包含分段。原宿主删除从画布树展开观察集合，只删除主体，分段失去父级后进入恢复区并被当成未知元素显示。反馈日志中修订 67–144 的 78 次增量均有耐久保存回执，没有节点类型和删除集合，因此日志不能直接确定截图中每个占位的身份；此根因通过真实模型、绑定及删除入口复现确认。

宿主与插件删除现在共用 `collaboration/removals.ts` 的观察集合计算：从完整模型子树展开，再按本批及手势待提交的创建、移动和删除调整归属。计算只观察发起端已知节点，接收端不追加级联删除。

相近入口排查还复现并修复了三类情况：

- 插件批次先移出／移入孩子再删除容器时，原实现仍按旧树展开，误删移出的内容、漏删移入的内容；先删孩子再删父级也可能重复删除。观察集合按批次顺序计算后，保留已移出的内容，避免重复删除。
- 插件同批新建孩子再删除容器时，原新建命令尚无 ID，不能纳入观察集合。适配层现在预分配新元素身份，创建和删除仍在同一事务及撤销步内。
- 整笔删除与离线追加并发时，未被删除端观察到的新分段应保留。精确匹配内置契约的分段只作为存储数据，恢复区分段不独立进入画布；撤销主体删除后，追加内容重新组成笔迹。同名第三方契约继续保留未知元素及扩展提示。

`cancelStroke` 已使用完整模型子树；剪贴板与文件导出、跨页移动使用模型身份和模型内容。主进程 Agent 的单节点删除拒绝有孩子、引用或连线的目标，没有同样的投影漏删入口。

## 行为回归

直接相关的七个测试文件合计 195 个用例通过，7 个既有环境门控用例未启用。本次新增的三个压力场景均显式启用并完成。

覆盖 Delete、Backspace、右键删除、剪切、同批移入／移出／创建／删除、手势提交与取消、非法末操作的零写入、单步撤销重做、重开、未知契约保留，以及删除和离线追加的竞态。

## 数据与行为压力结果

| 场景                         | 规模                                                    | 结果                                        |
| ---------------------------- | ------------------------------------------------------- | ------------------------------------------- |
| 手写、画框及四类导图混合删除 | 100 笔，564 模型节点，删除 352 节点                     | 通过                                        |
| 手写、画框及四类导图混合删除 | 400 笔，2,064 模型节点，删除 1,327 节点                 | 通过                                        |
| 手写、画框及四类导图混合删除 | 950 笔，4,814 模型节点，删除 3,117 节点                 | 通过                                        |
| 四种导图布局的批量分支删除   | 每种布局 961 节点，删除 120 条分支及其后代，共 480 节点 | 四种均通过                                  |
| 删除与离线追加竞态           | 三个客户端，40 轮，不同接收顺序及重复交付               | 三端收敛，40 个并发分段保留，撤销后恢复笔迹 |

每档混合删除和每种导图布局都完成三轮撤销／重做及远端一致性检查。混合场景还完成重开、整页剪切和粘贴到新白板，核对模型节点数量、每笔点数及非空轮廓。普通删除的恢复区为空；并发新增的分段保留在恢复区，画布没有独立存储分段。

手写每笔四个分段，最高一档接近 5,000 个模型记录的现有预算。剪切目标使用新白板；源文档保留的可撤销记录继续占用容量，测试不放宽预算。上述测试验证数据及交互行为，不代表实际桌面帧率或视觉验收。

压力场景均位于 `packages/whiteboard/src/collaboration/__tests__/removals.benchmark.test.ts`，默认关闭，完整复跑入口：

```sh
pnpm --filter @tau/whiteboard bench:removals
```
