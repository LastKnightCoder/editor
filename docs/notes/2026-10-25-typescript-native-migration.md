# TypeScript 原生编译器迁移验证

## 范围与实现

基线提交：`0a7db5aab`。工作区直接使用的 TypeScript 从 5.8.3 升至 7.0.2，命令仍为 `tsc`；独立插件与作者工程保持自身锁定版本。

需要编译器 API 的边界脚本、SDK/博客声明打包、门户/统计/协作配置检查以及 SDK AST 测试，显式使用官方 `@typescript/typescript6` 兼容包。包版本固定 6.0.2，锁文件解析的实际 API 为 TypeScript 6.0.3。没有用原生编译器的非稳定 API 代替旧 API。

兼容修正：

- Blob、Request、Web Crypto 边界明确使用普通 ArrayBuffer 支持的视图；复制时保留 byteOffset/byteLength 对应的有效字节。
- 截图编码、base64 解码、有界请求读取的返回类型明确为 `Uint8Array<ArrayBuffer>`，与原实现分配新缓冲区的行为一致。
- WebSocket 状态收窄到标准四种状态；异步等待后通过方法重新读取关闭状态，保留取消和关闭检查。事件处理函数使用 WebSocketEventMap 约束，同时消除两处原有 Function 类型 lint 错误。
- 浏览器扩展显式加载 chrome 与 vite/client 类型；SDK 与博客的 CSS 副作用导入使用共享环境声明。未关闭严格检查或副作用导入检查。

日常命令和编译器 API 使用方法见 [代码检查与格式化](/docs/guides/development-quality.md)。

## 类型检查速度

Apple M3 Pro、macOS arm64、Node.js v24.21.0。使用桌面 tsconfig，直接运行编译器 `--noEmit`；不计 pnpm 启动和安装时间，不使用增量缓存。每套编译器先预热一次，再连续三次取中位数。

| 编译器           |    第一次 |    第二次 |    第三次 |    中位数 |
| ---------------- | --------: | --------: | --------: | --------: |
| TypeScript 5.8.3 | 27.811 秒 | 25.965 秒 | 25.407 秒 | 25.965 秒 |
| TypeScript 7.0.2 |  2.242 秒 |  2.171 秒 |  2.189 秒 |  2.189 秒 |

本机中位数提速约 **11.9 倍**，所有计时轮次退出码均为 0。旧数据在兼容修正前测量，新数据在兼容修正后测量；包含新版本标准库与必要类型修正，不是逐字相同输入的编译器微基准。

## 基线问题与验证边界

迁移前已存在的独立包类型错误保持可见：

- `packages/blog`：测试清单中两处过期 required 字段，以及 load.ts 对清单联合类型的 editor 属性访问，共 3 个诊断。
- `packages/whiteboard`：audio-tts 测试夹具缺少 imageInfo/videoInfo，共 1 个诊断。

模板子模块的作者文档原本与宿主源码不同步，会使 SDK 打包前置检查失败。验证时通过仓库的同步脚本临时生成一致文档，完整打包后恢复模板文件；子模块没有留下修改，也没有发布生成包。这不代表模板文档的存量同步问题已修复。

本阶段没有升级 Vite 或执行应用安装包发布；Vite 8 单独验证。
