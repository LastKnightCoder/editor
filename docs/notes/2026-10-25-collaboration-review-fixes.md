# 编辑器与白板联合审查修复记录

本记录仅覆盖联合审查确认的四项 P1、三项 P2，不代表全部发行条件已满足。没有增加作者 API、网络协议或恢复产品；未执行真实库转换、发布、部署或视觉验收。

## 修改与回归

| 问题                           | 当前处理                                                                     | 补充验证                                                                                      |
| ------------------------------ | ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| 普通增量离线过期后无法继续同步 | 查询到 EXPIRED 终态且仍为同基线时，保存新操作身份后续传；不复活原操作        | 六分钟断网与重启、完整后继链；条件替换不续传、未知回执不换身份、换代保留旧字节                |
| 跨窗口草稿反序导致恢复失败     | 同基线 outbox 整体合并验证；合并批次以增量摘要确定幂等身份，确认后删除原记录 | 两次会话恢复产生依赖，窗口 ID 反序；保存中继续输入、回执丢失、补发只记一批                    |
| 旧白板首次升级缺入口           | 原“转换格式”命令接入已有隔离基线准备，沿用原迁移记录与安装事务               | 无来源身份及已有部分身份两种旧库；安装失败回滚、重试成功、重复转换不重复安装                  |
| 白板业务字段被宿主占用         | data 内允许普通业务键；结构保护保留在外层，文本仍只经句柄修改                | data.id/type/children/geometry、text 文本合并、资源声明、跨副本接收、版本转换及不安全属性拒绝 |
| 成功回执内嵌完整旧基线         | 只保存幂等元数据；加载旧日志时移除已确认回执中的冗余全文                     | 50 次编辑、旧操作重试、旧日志收敛、被拒材料原样保留                                           |
| 同一会话材料重复完整备份       | 同时核对正文投影、草稿、视图及附件字节，重复操作复用已验证副本               | 有来源会话重复保全不新增副本；同路径附件字节变化必须另存；旧文件不被覆盖                      |
| 无关恢复清单损坏影响全库回收   | 桌面本机恢复登记保存 workspace_id，回收限定所属库；旧登记从可信材料补齐      | A 库损坏不阻止 B 库回收；A 库仍保守保留；旧缓存登记升级不改变原包和回执                       |

此前禁止 data.id 的测试反映了错误边界，已改为验证不安全 JSON 属性被拒绝；新增测试同时断言业务字段不能改变外层身份和几何。没有通过删除失败场景或跳过断言取得通过。

## 保留边界

- 历史恢复包、未确认输入、被拒分支、旧私有材料和真正整库替换保障不删除。成功回执仍保留紧凑幂等元数据，不宣称历史元数据零增长。
- 低频的必要文件校验与落盘仍存在；本轮解决重复完整副本，不宣称大附件处理已经无阻塞。
- 旧登记若清单损坏，且原迁移/持有记录也无法证明归属，继续保守阻止回收；不能通过猜测来源释放数据。新登记已有独立归属，不再因无关清单损坏扩大保护范围。
- 桌面协作缓存版本为 3，旧登记就地补所属库；这不改变正文/白板共享协议或主库 schema。移动端本机缓存未改。
- 七项修复未替代服务与客户端发行组合核对、目标设备输入/交互验收。过渡代码仍按最后升级版本与下一拒旧基线的条件退役。
