# 图库、行详情与白板宿主的覆盖复现与压测

日期：2026-11-25。环境：本机 macOS。未修改用户资料库，也未连接真实同步服务。

## 复现与修复

| 入口                       | 修复前实测                                           | 处理                                                                       |
| -------------------------- | ---------------------------------------------------- | -------------------------------------------------------------------------- |
| 数据库画廊封面             | 同名覆盖后仍用旧连接，刷新失败并保留旧正文           | 订阅连接身份，查询缓存按身份隔离，迟到结果只归旧缓存                       |
| 行详情新正文               | 覆盖后新输入保存失败；覆盖前的创建响应可回填同编号行 | 草稿归属连接；丢弃被替换库的草稿；旧响应不回填；新输入等待旧请求后继续保存 |
| 数据库行补丁与外部保存回调 | 同名覆盖后使用旧命令；旧实例回调未区分连接           | 内部实例按连接重建；命令与回调捕获原身份，旧回调不接管新库                 |
| 嵌入式白板正文服务         | 保留的宿主在替换后继续访问旧连接                     | 旧画布只读并提示重新打开；旧正文与保存操作停用，新实例取得新身份           |
| 白板视频笔记面板           | 旧画布只读后，打开事件仍向旧连接发请求               | 面板固定所属连接，过期事件及迟到结果停止访问或回填                         |
| 主白板文档画布             | 未复现；现有 viewId 交接会重建绑定、释放旧模型       | 保留现有交接实现，新增连续重建验证                                         |

普通切换活动库不等于替换库：旧白板仍可对有效的原连接清理引用，原连接被替换后才停止清理，防止误写新库。

## 验证结果

- 原有针对性基线：18 项通过。
- 最终相关回归：13 个文件、77 项通过；5 项环境门控压力用例在普通回归中跳过，本轮另行运行其中 4 项新压力用例。
- 本轮压力运行：4 个文件、26 项通过，包含所有 4 项新压力用例。
- 图库/行详情/行补丁：200 次同名覆盖，400 次当前库写入，200 次旧回调阻断；每轮旧草稿均不写入新库。
- 嵌入白板：200 次替换与重新打开，200 次当前连接正文创建成功，200 次旧服务调用被阻断。
- 旧视频笔记面板：1,000 次重复打开事件，失效连接请求为 0。
- 主白板：100 次租约替换，100 个旧模型均释放，新画布绑定正常建立。
- TypeScript、目标文件 lint、生产构建通过；存量测试中的非空断言与空函数仍有 lint 警告。
- 官网 69 项测试通过。
- 数据库/白板架构边界、文档检查及主窗口/内容转换/插件窗口三项生产启动验证通过。
