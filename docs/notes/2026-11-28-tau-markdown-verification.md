# Tau Markdown 协议验证记录

日期：2026-11-28。验证环境为本机 Windows、当前工作区与已安装依赖；未做视觉验收，未部署远端服务。

## 交付范围

- 原生文本协议、严格编解码、未知数据保留、双向位置映射、版本及容量限制。
- 桌面正文 Agent 的读取、同快照查找、稳定块定位、局部编辑编译、审阅、提交、全文回写。
- 同身份节点的属性、文本和同父级排序更新；本机及共享范围逆操作继续经过原有冲突与权限检查。
- Markdown 文件会话识别并保持原生方言及元信息，富文本编辑和撤销后仍可还原。
- Node / Cloudflare 服务同步声明原生身份复用能力；旧服务拒绝不支持的操作。

普通 GFM 导出仍是显式的有损导出目标。移动端只做共享包的类型与构建兼容验证，未新增移动 Agent 正文写入入口。

## 协议压力

1,000 组固定种子随机载荷覆盖控制字符、换行、孤立代理字符、零宽字符、Markdown 符号、长围栏与未知嵌套属性；500 次连续文本改色往返与独立预期一致；64 层节点往返通过。容量、深度、重复字段、原型键、非法版本及不完整载体的拒绝另由协议契约用例覆盖。

每个规模预热 1 轮，测量 30 轮，逐轮严格比较完整数据；与构建、类型检查和其他压力项串行。对象输入为带行颜色、稳定 ID 和普通文本的双列表格，未把计时阈值放进单测。

| 行数   | 文本字节  | 编码 P50 / P95（ms） | 解码 P50 / P95（ms） |
| ------ | --------- | -------------------- | -------------------- |
| 100    | 25,372    | 0.769 / 1.225        | 1.219 / 1.594        |
| 1,000  | 258,022   | 7.149 / 8.339        | 12.124 / 15.436      |
| 10,000 | 2,629,522 | 75.064 / 153.794     | 134.070 / 307.148    |

万行阶段结束时的进程 RSS 采样约 695 MiB，包括 Vitest、输入、结果、位置映射及多轮分配；它不是隔离分配量或连续采集的内存峰值，也不构成长期内存稳定性结论。计时为本机样本，不是生产 SLA。

初次压力发现逐单元格的 remark 往返证明成本偏高；增加严格受限的无语法字面量路径后，编码格式和语义保持不变，并用普通处理器 parity、全量真实库及压力重新验证。优化前后报告均保留；最终性能以 measuredRounds=30 的 pressure-时间戳.json 为准。

## 实际提交与持久化

- 通过真实 MCP 工具、Yjs 正文运行时与 SQLite 日志/投影，验证改色、清色、文字修改、完整回写、稳定节点排序、完整数据与 ID 保留、重开及撤销。
- 100 个固定随机种子，各 10 轮，覆盖整表删除、同文表格区分、范围内/外并发输入、冲突后重读、重复提交、投影、重开、撤销及重复撤销；100 / 100 通过。
- 真实本机 Node 协作服务与 WebSocket 验证原生改色，同步后投影及撤销均与独立预期完全一致。旧服务能力缺失时提交被拒绝，服务端序列及正文保持不变。
- Cloudflare 的正式构建与生产配置 dry-run 均通过；现有正式 Worker 范围编辑用例通过，覆盖 16 次并发、重放与冲突提交。该 Worker 用例验证共享范围提交基线，原生表格改色的端到端证据来自 Node 共享服务。

首次共享持久化用例误用了关闭实时连接的夹具，服务端改色后本地仍旧。修正夹具为真实 WebSocket 并等待文档同步后，落盘和撤销的严格断言通过；未因此修改生产投影逻辑或降低断言。

## 真实模型

使用用户本机 chat 槽配置的 glm-5.3。输入为只读副本的一段有限真实正文与合成表格，写入独立临时资料库；通过实际桌面工具注册和提交路径执行，每个场景重开并核对全部节点、属性、契约与身份。

| 场景             | 第二轮结果 | 模型请求数 | 模型纠正次数            |
| ---------------- | ---------- | ---------- | ----------------------- |
| 改色             | 通过       | 4          | 1                       |
| 清色             | 通过       | 3          | 1                       |
| 改字保色         | 通过       | 3          | 0                       |
| 行移动保真       | 通过       | 2          | 0                       |
| 非法语法后的恢复 | 通过       | 2          | 0（前置失败为主动注入） |
| 全文回写         | 通过       | 2          | 0                       |

首轮为 4 / 6：行移动耗尽单场轮次，全文回写被整轮请求预算拦截。修复工具使用问题，提供稳定 block-id 定位及同一 snapshotId 内查找后，第二轮 6 / 6、16 次请求通过；保留首轮与第二轮全部报告，不把失败运行删除后当作一次通过。

两轮共 46 次模型请求，输入 44,339 tokens、输出 14,747 tokens。第二轮的改色与清色各有一次被拒绝后纠正；结果不表示模型每次首试成功或其他模型必然成功。非法原生语法和错误范围被写入边界拒绝，AI 按错误信息纠正。
