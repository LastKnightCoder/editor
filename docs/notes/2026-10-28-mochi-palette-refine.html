配色精修：三个方向

「像色块」不是哪一个颜色选错了，而是三件事叠在一起。下面三行用同一份页面结构、只换配色规则，左边是首页一角，中间是卡片列表，右边是卡片详情，可以直接对比。

大面积都是满色天空整块蓝、草地整块绿、便签整张黄、背景整片软木色。马卡龙色本来只适合点缀，铺满就成了儿童贴纸。
每样东西一样「重」页面、卡片、按钮、标签全是同样粗的黑描边加硬投影，没有主次，眼睛不知道先看哪里。
卡片页换了材质其他页面都是奶油色的纸，只有卡片页是棕色软木板 + 图钉，像进了另一个网站。

现状 对照

全部满色、全部 2.5px 黑描边、卡片页是软木板。

A · 水彩手帐 推荐

整站统一成「一本手帐」：底色、天空、草地都退成淡淡的水彩晕染；大面积的纸面改用细而浅的线和柔和的落影，粗黑描边只留给按钮、标签、团子这些「贴纸」，主次一下就出来了。卡片页不再是软木板，而是手帐里的点阵页，便签用浅色纸 + 同色和纸胶带固定，和文章页的手帐纸是一套。团子与插画保留墨线，可爱的记忆点不丢。

B · 糖霜软陶

彻底去掉黑线：每个元素用比自己深一点的同色系描边和投影，像捏出来的软陶、蛋糕上的糖霜。更柔、更「现代」，但贴纸感和绘本感会弱很多，团子和房子的墨线放在这种画面里会显得突兀，需要一起改成彩色线。

A 方向具体改什么

项现在改成
大面积底色奶油底 + 满色天空 / 草地 / 软木板奶油底不变；天空改为由浅蓝晕到奶油的渐变，草地退到很浅的绿，软木板取消
描边分两级所有东西 2.5px 墨线 + 硬投影「纸」（页面容器、卡片、信纸、便签）：1.5px 浅墨线 + 柔和落影；「贴纸」（按钮、标签糖果、开关、团子、插画）：保留墨线
填充色分两档同一套马卡龙色既铺大面积又做点缀新增一组「淡色」用于大面积（便签纸、高亮区）；原来的马卡龙色只用于小面积点缀与胶带
卡片列表软木板 + 图钉 + 满色便签手帐点阵页 + 浅色便签 + 同色和纸胶带；标签罐子保留
卡片详情满黄色大便签和文章页同一种手帐纸，顶部一条和纸胶带；红毛线保留
夜晚同样的规则同样分两级：纸面用深紫灰细线，贴纸保留浅紫灰描边；淡色组按夜晚重新取值，对比度测试照常守护
