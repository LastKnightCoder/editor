## 最低能力组合与放行条件

新版 SDK + 首个完整支持的桌面发行版 + 已适配插件版本（或无插件时的保真占位）+ 经验证的协议 3 服务构建；跨发行物组合需以固定产物（SDK tarball、桌面构建、插件 ZIP、服务构建）联验旧端拒绝、缺插件、因果 / epoch、回执与迁移重试。目标设备高负载与长会话体验由用户手工验收。
