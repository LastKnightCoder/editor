# 第二轮编辑器与白板审查修复记录

本轮仅处理独立审查确认的四项 P1、三项 P2。全部源码、测试与文档编辑使用 apply_patch；没有改动其他任务文档，没有执行真实资料库转换、部署或视觉验收。

## 已确认的两项边界

- 白板删除只删除本机白板入口；仍被引用的页保留；共享先使用现有结束/退出流程；无引用、无活跃编辑的文档沿用已有延迟回收规则退役，不新增恢复产品。
- 本机旧白板转换的提交决定在主库安装成功后确认。取消和重启先核对主库安装结果，已安装的候选只续做，未安装的允许取消后重新准备；远端提交和远端首次发布的决定不可回退。

## 实现与对应回归

| 问题                         | 修复及保留边界                                                                                                                                                       | 验证                                                                                    |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| 正文正常退出可能丢未确认输入 | 正文加入原耐久保存屏障；失败取消退出并保留窗口，移除尽力保存的 prepareQuit。保存回执关联本次请求，旧回执不确认下一次退出                                             | 超时、投影失败、重试、迟到回执、窗口保留及白板原屏障回归                                |
| 完整导出漏文档级恢复区       | 未确认页面归属时明确拒绝完整导出，不生成缺元素的包                                                                                                                   | 并发删页/移入后拒绝导出；确认归属后元素与契约正常导出                                   |
| 新格式白板无法删除           | 原列表和插件入口按需进入白板服务，先冲刷再在原事务内解除拥有者；引用页仍可编辑，隐藏页所有权引用一并释放。原连接事件执行到期回收，检查日志、活动编辑、转换和网络分支 | 原入口删除、共享拒绝、嵌入引用、隐藏页、插件操作记录与恢复、主库/日志故障回滚和幂等回收 |
| 首次转换失败后无法续做或取消 | 按已确认边界调整本机首次安装顺序；主库未装而全库基线改变时，原确认入口取消旧候选并重新准备；已装则续做                                                               | 安装失败后无关主库写入；此前仅有本机决定的记录；关闭并重新打开三个存储后取消仍续装      |
| 时钟偏差拒绝操作或持续重投   | HTTP 传输从标准 Date 取服务端时间；缺有效时间不提交；同一增量每次 flush 最多续投一次，释放队列后再重试                                                               | 客户端快一秒/慢六分钟、实际响应头读取、再次过期的有限重试和可取消性                     |
| 持续输入推迟同步             | 保留更早排期，输入可提前同步但不能无限推迟；断网输入不绕过原退避                                                                                                     | 每 500ms 输入、持续 30 秒仍持续同步；断网退避和恢复轮询                                 |
| 旧元素换号断开引用           | 先建立唯一旧 ID 映射，再转换元素；已知连线与演示应用相同映射，歧义仍保全并报告                                                                                       | 非新格式字符的旧 ID、前向/跨页连线、演示及重复 ID 歧义                                  |

删除不直接撤销旧快照守卫。原插件删除回执与业务删除仍在同一主库事务；回收失败留下主库检查点。没有清理被拒或未确认网络分支，也没有新增后台回收定时器、通用分发层或作者 API。
