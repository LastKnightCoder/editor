# 纯本机白板历史回收压测

在 macOS 26.5.1 arm64、Node 24.21.0 上，从提交 `98f22c8a1` 建立独立 worktree。本次验证桌面纯本机白板的冷检查点回收。共享白板参加保存与网络回归。

## 连续回收

同一份文件型 SQLite 白板包含两页、一个画框及 1000 个带独立文字的子元素。通过真实模型命令将整框移走、移回，使检查点接近 8 MiB。每轮关闭前保留全部元素的预期数据，换代后经正常会话打开白板，逐项核对模型、文字和坐标。随后从新代次再次积累历史。

| 轮次 | 回收前字节 | 回收后字节 | 正常释放视图耗时 | 释放返回至观察到新检查点 | 期间主进程事件循环最大采样间隔 |
| ---- | ---------: | ---------: | ---------------: | -----------------------: | -----------------------------: |
| 1    |  7,880,811 |    948,527 |            33 ms |                   553 ms |                          13 ms |
| 2    |  7,853,073 |    948,527 |            28 ms |                   502 ms |                          19 ms |
| 3    |  7,853,073 |    948,527 |            32 ms |                   502 ms |                          16 ms |
| 4    |  7,853,073 |    948,527 |            30 ms |                   458 ms |                          12 ms |

回收的是 Yjs V1 文档检查点。SQLite 可复用释放的页，数据库文件大小由 SQLite 管理。释放视图的耗时包含已有的保存屏障。后台墙钟时间包含测试观察新状态的轮询间隔。事件循环采样间隔设置为 2 ms，记录地点是运行桌面会话与 SQLite 安装事务的 Node 进程。画布每帧耗时与输入延迟需另行测量。

## 数据和故障对账

- 重建同时核对完整投影与共享根。专项验证覆盖失去页面归属的元素、隐藏页和删除池、未知插件字段、附件和实体引用、富文本格式与换行、画框归属、演示序列。新代次的移动可以撤销和重做。
- 两个窗口持有同一白板时释放其中一个，另一个仍能使用。回收启动后立刻重开并写入，新文字持续保留。旧租约晚到的写入被拒绝。以资料库别名写入的未投影日志也能阻止切换。
- 模拟窗口崩溃后从草稿队列恢复未送达的编辑。向 SQLite 切换事务注入写盘故障，原检查点的字节数、代次、修订和摘要保持一致。重新打开后可重试，按原请求重放的助手操作仍返回原回执。
- 子进程分别在回收意图落盘后、主库事务内、主库提交后、日志交接事务内遭到 SIGKILL。四次均从磁盘重开并核对千元素完整模型。两库的 SQLite 完整性检查通过，随后再写、再关、再开均读到新内容。
- 桌面 Vite 生产构建输出的工作线程在 Electron 中只读打开 SQLite，重建一份 5,284,548 字节的插件字段反复编辑样本，得到 51,864 字节。独立模型读回与来源一致。真实 Electron IndexedDB 分别以两种资料库名称核对待保存草稿，其他白板与其他资料库的草稿不参与。

## 保存与协作回归

三视图保存压测用 12 个种子运行 960 轮，共导入 1898 个元素。240 次预期的断线、确认丢失、草稿或投影写入失败经重试恢复，另有 60 次缺依赖补齐、60 次渲染端重开、24 次冷重启。每轮把三份模型、SQLite 投影和草稿队列与独立预期账本核对，全部通过。这组压力覆盖常规保存链路，近满容量换代由上面的四轮专项覆盖。

真实双端 SQLite 与 WebSocket 共 9 个场景通过，包括千元素整框拖动、单步撤销和重做、远端中断、断线重连及接近上限时保留已广播位置。首轮与其他压力组并行时，近上限用例在等待双方握手的 4 秒内未就绪。该用例独立复跑通过，最终整组串行复跑也通过，沿用原有等待条件。

## 复测入口

在 `apps/desktop` 目录运行以下命令。涉及等待双端握手的用例与大压力组串行运行。

```sh
TAU_WHITEBOARD_RECLAIM_STRESS=1 pnpm exec vitest run src-electron/main/modules/whiteboard-documents/__tests__/{compact,compact.stress,journal}.test.ts --no-file-parallelism
TAU_WHITEBOARD_SAVE_STRESS=1 pnpm exec vitest run src/services/whiteboard-documents/__tests__/client-save.stress.test.ts
TAU_FRAME_DRAG_STRESS=1 TAU_FRAME_QUOTA_STRESS=1 pnpm exec vitest run src/services/whiteboard-documents/__tests__/drag-realtime.test.tsx
```

持续打开至接近容量上限的白板仍会走原有容量保护。当前页面、仍可恢复的内容、附件引用和隐藏记录会继续占用空间。回收要求最后一个视图正常释放、草稿已落盘且新检查点至少节省两成。机器断电、存储介质损坏和真实设备上的画布帧率不在本次故障注入的测量范围内。
