# 画框功能修复验证

目标：修复新建收纳、大批拖动/解散、分栏入框。未进行性能优化。

## 结果

- 新建画框以空容器加结构移动收纳已有内容，不重建元素与正文身份。
- 普通绑定提交按数量和字节使用隔离分批，整体验证后一次合入。非法末项不会部分写入或增加撤销历史，原有预算未放宽。
- 解散删除使用操作执行时的当前后代集合，已移出内容不会被旧快照误删。
- 分栏新建、拖入、扩大画框统一准入；内部托管与排序识别嵌套父容器，运动子树不作为目标，解散分栏将内容留在所属画框。
- 旧分栏按精确摘要读取，用户收纳时原子升级，保留标题根、内容、记录与引用。远端只接受受限分栏契约过渡，任意身份或文字绑定替换仍拒绝；并发改标题不会被移动的撤销覆盖。
- 退出分栏只恢复元素已有的尺寸字段，文档卡不会再收到未声明的富文本尺寸属性。
- 选择状态将 Esc 转发给拖动，已经提交中间位置的拖动也可完整取消，迟到松手不会重放。

## 验证证据

原始结果见 [功能采样](./2026-11-26-whiteboard-frame-fix-results.json)。全部真实浏览器操作使用生产构建与独立临时文档，不操作用户资料库、不做视觉验收。

- 12 条定向指针样本：256 / 1000 个子元素整框拖动、1000 个根元素中圈住内容新建画框、拖入分栏、新建圈住分栏、解散 1000 个子元素的画框，各两轮，failure 与 errors 均为空。
- 909 个元素、20 轮、121 次手势压力：旧分栏入框升级、框内文档卡拖入和末尾排序、跨栏、60 次撤销/重做、整体移动、20 次 Esc 取消。逐轮核对稳定记录、标题根、连线绑定、元素数量、父子归属及恢复区，errors 为空。
- 1000 个子元素、48 步完整长拖动：最终移动正确，单次撤销恢复全部原始内容，单次重做恢复完整提交，未报错。
- 定向白板回归 101 条通过，3 条环境门控跳过；模型与预算 39 条通过；官网内容与发布验证 69 + 5 条通过。两包类型检查及白板边界、文档检查通过。
- 新增定向回归覆盖身份与真实正文根、非法末项原子回滚、旧契约反复进出与并发标题、远端接纳、冷重开、嵌套解散及已发布位置的 Esc 回滚。
- 真实 SQLite 耐久保存、WebSocket 双画布与离线重连的既有回归 7 条通过；既有模型与预算回归 39 条通过。
- 原有白板产品测试有 3 项环境门控（混合笔迹及预览性能）跳过，未将它们计作通过。

## 边界

压力中的文档卡使用轻量测试卡面，不覆盖真实 PDF 解码、正文宿主排版或全部平台设备。1000 个子元素的长拖动仍有长帧，本轮只验证操作正确性，不承诺流畅度。分栏契约过渡要求服务端及共同编辑端使用支持该过渡的构建，旧端会拒绝升级增量；本次未部署或发布。
