# 查询数据库真实副本压力与一致性验证

验证日期：2026-11-25 至 2026-11-26。环境：macOS 26.5.1 / arm64，Node 24.21.0，Electron 43.1.1。结果是本机观测，不是跨设备性能保证。

最终真实链路矩阵 **73 / 73 通过**；主渲染进程崩溃 0，未处理异常 0。替换前后 SQLite `quick_check` 均为 `ok`，外键异常均为 0。冷查询和拒绝写入前后，逐表记录摘要相同。

## 数据与隔离

源主库与索引库仅以只读 SQLite online backup 取得副本；每轮测试再从基准副本克隆独立工作目录。所有夹具、批量新增、修改、删除、故障和文件替换都发生在临时副本。未上传业务数据，报告不保留标题、正文、标签或凭据。

初始备份约 89 MiB 主库和 80 MiB 索引库，物理记录包括：682 张卡片、79 篇文章、23 个项目、349 个项目条目、275 个独立待办、2,130 条持久日程、867 条日记、31 张数据表、9 张白板、7 条剪藏、261 个对话与 4,282 份正文。业务读取另按软删除、引用条目与可见场景过滤。Notebook 原为空，在副本内补充非空夹具。

使用正式 preload、真实主进程数据库命令和 SQLite、真实业务只读投影、原生 Worker、React 刷新宿主与事件传播。待办和日程传输接到真实 task-assistant 查询函数，不启动后台提醒或远程同步。窗口隐藏，不进行视觉验收。

## 验证中修复的问题

- 普通表未暴露虚拟行 `id` 字段，DSL 无法按行编号查询：补齐投影，并用真实 SQLite 多页普通表对账锁定。
- 数据源返回不可克隆对象时，消息转发产生未处理 Promise，最终只能等超时：转发与分页验证改为及时受控失败。
- 字节预算按 JavaScript 字符长度计算，低估中文和表情：统一按 UTF-8 序列化字节计量。
- 日记通知排除了发起窗口，通用正文与分块投影又不经过日记命令：日记命令通知所有窗口，正文提交后按归属补发专用通知；不扩展插件公开事件。
- 同窗多个查询可同时创建大量执行环境：增加有界队列，等待也受期限约束。
- 反复创建隔离文档后 Chromium 保留较多进程：同窗复用沙箱文档，Worker 与消息端口仍逐次独立；显式终止确认后清理，失效环境退役并重建。

沙箱复用前的同等 71 场景小批量矩阵，渲染进程峰值 36、结束后 25；复用后分别为 5 和 3。最终 73 场景、2,000 条完整矩阵同样为 5 和 3，主进程及子进程工作集加总观测峰值约 1.23 GiB。该峰值包含真实主库、索引、正文处理与 50,001 行和 17 MB 失败夹具，且进程工作集可能重复计入共享页，不能解读为单个查询的内存开销。查询专属 iframe 最终为 0。

受限堆实验在独立 Electron 进程将 V8 old-space 限为 128 MB，两次持续分配数组均触发 V8 OOM；主渲染进程存活，每次后续查询都成功，执行环境释放。Worker 构建产物 19,090 字节，无新增脚本引擎依赖。

## 边界

这些证据支持所测场景的稳定性和只读边界，不能保证任意用户脚本、所有设备与操作系统整体内存耗尽下永不异常。类型校验也不能证明用户脚本的业务逻辑正确。

已验证本机源修改传播及下载后的真实同名库替换链路；没有连接真实云端存储完成网络上传下载，也没有验证跨设备、移动端 UI 或视觉表现。多来源查询按读取先后取得数据，保证变化后收敛，不承诺跨来源事务快照。

相关检查通过：共享核心与执行队列 14 项、桌面 SQLite 与日记事件 33 项、官网文档 69 项与发布响应 5 项；包含验证夹具的桌面类型检查、Vite 生产构建、生产主窗口与内容转换及插件入口启动、数据库与启动及插件进程边界检查均通过。构建仍有已有的大 chunk 与 CJS `import.meta` 提示。
