# 思维导图联系线修复与验证

验证日期：2026-11-26。本轮修复联系线组件重复遍历画布，以及并发删除端点后留下联系线两项问题。原始两项失败复现均通过，新增行为回归和压力验证通过。产品代码未创建提交或发布。

## 修复结果

本机 `Board.apply` 在发布新快照前复用 `ArrowProjection`，一批计算全部绑定端点，并同步更新元素事件与选区中的引用。派生端点随撤销重做重新计算，历史只记录原始操作。箭头组件的几何变更监听和逐线写回已移除，唯一消费者随之清零的 `mindRelationNode` 同步删除。移动和折叠在未挂载箭头视图时也能正确更新端点。

并发联系线使用端点有效性定义可见性：`inactiveMindRelationIds` 只识别宿主箭头和两个宿主导图身份，包含已删除但仍在保留池里的节点身份。任一端不在同页活树时，联系线退出画布和可编辑导出；恢复两端后复用原身份显示。底层记录、正文和预算占用保留，读取、合并和重开不追加共享删除。该规则也用于公共导出入口，避免经过完整导出、重导或重建共享基线后出现残线。普通箭头和同名第三方元素继续保留。

数据格式和现有身份保持不变。`readElementIdentity` 默认仍只返回存活身份；显式 `includeRemoved` 只读保留池身份，不改变编辑权限。

## 组件性能

原始夹具挂载真实箭头组件，对真实单节点文字颜色编辑统计身份读取。1000 节点、500 条线从约一百万次读取降至 2998 次；100 与 500 节点也体现线性增长。访问次数包含操作的其他工作，不以插桩时间估算产品耗时。

| 普通节点数 | 联系线数 | 修复前身份读取次数 | 修复后身份读取次数 |
| ---------- | -------: | -----------------: | -----------------: |
| 100        |       50 |             10,000 |                298 |
| 500        |      250 |            250,000 |               1498 |
| 1000       |      500 |          1,000,000 |               2998 |

最终组件采样使用订阅画布快照的真实箭头视图，覆盖实际 `Board.apply`、属性更新和 React `act` 收尾。组件挂载、预热和断言均在计时窗口外；没有身份 getter 或 Proxy 插桩。每个规模三次采样，中位数单位 ms。

| 普通节点数 | 联系线数 | 单节点编辑 | 整批端点移动 |
| ---------- | -------: | ---------: | -----------: |
| 100        |       50 |       0.65 |         8.00 |
| 500        |      250 |       1.16 |        18.79 |
| 1000       |      500 |       1.85 |        30.70 |

这些读数属于全部箭头挂载的 jsdom 场景，包含真实箭头 React 更新，但没有导图节点正文、浏览器绘制和系统输入开销，不代表真实桌面帧率。大批量移动仍有整批组件更新成本；本轮确认消除的是逐线全树扫描和逐线重入写回。1000 节点加 500 条线仅是本机组件工作量，不能用来突破协作文档的独立富文本根预算。旧夹具直接发出的 `element:change` 已不负责几何写入，其耗时不再用作编辑性能读数。
