# Obsidian 大库批量导入压测

2026-11-23 在 Apple M3 Pro、36 GiB 内存的 macOS 上，用桌面端生产构建分别导入文件夹和 ZIP。每次启动新的 Electron 实例，使用独立的临时用户目录和资料库。从命令面板打开批量导入，选择全部笔记，导入为文章。

每份来源含 22,000 篇约 8 KiB 的 Markdown 笔记、221 处 Obsidian 双链和两篇笔记共用的一个 64 MiB 附件。两次导入均通过。

| 来源   | 选择来源到扫描完成 | 预览到完成并核验 | 实际写入文章 | 回填链接 | 预览挂载行 |
| ------ | -----------------: | ---------------: | -----------: | -------: | ---------: |
| 文件夹 |            52.3 秒 |         114.3 秒 |       22,000 |      221 |         23 |
| ZIP    |            45.6 秒 |         105.2 秒 |       22,000 |      221 |         23 |

逐次查询目标 SQLite 核对文章数，抽查首尾两篇笔记之间的双向引用。检查资源目录只生成一个附件，字节数与 SHA-256 均与来源一致。

## 进程内存

单位为 MiB。基线取选择来源前的 Electron 工作集。每 500 毫秒采样主进程及主窗口渲染进程，并在预览和结束时补采。下表按进程分别取最大采样值，采样间可能存在更短的峰值。GPU、索引子进程等其他进程未计入。

| 来源与进程      | 基线 | 扫描峰值 | 预览 | 写入峰值 |
| --------------- | ---: | -------: | ---: | -------: |
| 文件夹 · 主进程 |  426 |      626 |  595 |      576 |
| 文件夹 · 主窗口 |  340 |      460 |  461 |      702 |
| ZIP · 主进程    |  427 |      590 |  438 |      558 |
| ZIP · 主窗口    |  342 |      496 |  503 |      774 |

结果覆盖本地资源存储、文章目标和此份合成库。正文和 ZIP 附件按需读取，路径、文档树和勾选状态的内存仍随条目数增长。

## 复跑

在仓库根目录运行。用例自行生成测试数据并清理临时资料库。

```sh
pnpm --filter desktop exec vite build --configLoader runner
TAU_IMPORT_SCALE=1 pnpm --filter desktop exec playwright test e2e/batch-import-scale.spec.ts
```

每组结束时输出 `IMPORT_SCALE_RESULT`，包括秒数、进程工作集和可见行数。用例见[桌面端批量导入压测](/apps/desktop/e2e/batch-import-scale.spec.ts)。
