# 提供方设置归位验证记录

范围：同步与资源上传沿用现有方案，TTS、ASR、图片生成、视频与博客发布的连接配置归插件页。应用设置选择服务；TTS 保留账号、模型、音色与试听；视频按 URL 匹配多个来源。Bilibili 扫码登录与 GitHub 发布的目录授权保留专用组件。保存配置不自动改变当前选用。

桌面由 ProviderAccountSettings 管理账号，ProviderConfigForm 统一渲染声明式字段；移动在插件设置列出 TTS 账号并进入原账号、模型与复刻子页，ASR 配置在插件页，语音设置单独选用。多账号 ID、已存凭据、自定义模型及当前选择沿用现有数据；写入继续使用原有持久化命令。旧 TTS 桌面配置组件、手机专用凭据表单及 S3 发布表单样式已删除。
