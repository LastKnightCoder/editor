# 白板拖动快速验证与桌面混合验收

11 月 21 日的复核以[上一轮专项](2026-11-21-whiteboard-performance.md)结束时的源码作起点。在 Apple M3 Pro 上，快速验证连同生产构建耗时 3.5 秒，桌面混合验收连同生产渲染构建耗时 21.6 秒。两个入口均可独立运行。[复跑命令与门限](/packages/whiteboard/src/utils/benchmarks/README.md)

## 快速验证

1,000 个富文本元素，1000 × 700 CSS 像素，Chromium 153，4 倍 CPU 降速。右键拖动 48 步，位移 240 像素。本次修复前 P95 帧间隔为 33.4 ms，主线程任务累计 1,333 ms。交付版本分别为 16.7 ms 和 704 ms，记录到 48 次实际画布位置变化、首次位移 48 ms、最长帧 16.8 ms，落点误差小于 0.1 像素。动画帧中的屏幕变换矩阵用于确认画布跟随，≥50 ms 帧单独计数。

## 桌面混合验收

Electron 43.1.1 的隔离资料库打开同一张 972 元素白板，包含 480 个图形、240 条绑定连线、240 个富文本框和 12 张引用同一份本地 PDF 的卡。确认 12 张卡面全部解码后开始计时。实际显示设备在本次采样的空闲 P95 为 9.2 ms。以下为额外记录松手反馈的同一生产构建复核，第 0 轮预热。

| 正式轮次 | 48 步中可观察的位置变化 | 首次位置反馈 | 相邻位置 P95 | 最长帧 | ≥50 ms 帧 | 实际水平位移 |
| -------- | ----------------------: | -----------: | -----------: | -----: | --------: | -----------: |
| 1        |                      47 |        17 ms |       8.4 ms |   9 ms |         0 |      -120 px |
| 2        |                      46 |        26 ms |       9.1 ms | 9.2 ms |         0 |       120 px |
| 3        |                      47 |        25 ms |       9.2 ms | 9.3 ms |         0 |      -120 px |

跨区滚动往返后回到原位置，缩放前后的指针保持在同一画布坐标。移动 PDF 卡后，通过独立租约重新读取了已保存的二进制模型，卡片位置与屏幕反算位置的偏差小于 1 个画布单位。

拖动 PDF 卡的 16 步输入用时 243 ms，移动阶段 P95 帧间隔 9.3 ms。**松开 PDF 卡到下一个动画帧为 173 ms**，释放阶段仍有明显停顿。完整落库与位置核对覆盖在功能验收里，快速平移门限不覆盖文档提交延迟。

## 修复位置

- 格内平移直接移动 HTML 合成层。画布订阅跨格、缩放及内容变化，浮动属性条单独订阅精确视口。拖动中指针由画布接管，按键不匹配的自定义手势跳过空间命中查询。
- 富文本存在滚动溢出时才使用边缘渐隐蒙版。
- 本机白板的连续元素拖动合并中间提交，长拖仍向其他窗口报告位置。共享白板使用原有实时节奏。纯几何移动保留模型候选校验，文档绑定按事务复用只读快照。保存状态摘要独立读取页数和标题。
