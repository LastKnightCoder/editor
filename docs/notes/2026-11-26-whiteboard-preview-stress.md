# 白板创建预览压测回归

日期：2026-11-26。范围：本次预览会话、内置字段与插件只读作用域改动。使用真实 React DOM（jsdom）和 Yjs 白板模型，不做截图或视觉验收。

## 发现并修复

- React 同批次取消、同 ID 重开时，组件未经历中间卸载，内置文字保留旧绑定。预览渲染子树改为按会话身份隔离，Frame、Column 与图片说明的正常回归已覆盖此场景。
- 通用创建工具可在提交前省略元素 ID；首次预览的身份比较错误访问空状态。初始化现在先判断是否已有预览；原有通用创建测试中的 8 个失败已恢复。
