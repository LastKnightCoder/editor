# 编辑器插件协作：本地实现与验证记录

本记录是 2026-10-25 的验证快照。当前实现说明见[协作架构](/docs/architecture/collaboration.md)，操作见[正文转换与保全](/docs/architecture/collaboration.md)，作者 API 与完整 v1→v2 示例见[作者文档](/plugins/tau-plugin-template/docs/editor-collaboration.md)。

纠正此前验收结论：上一轮测试没有覆盖单篇副本携带无关主库数据、未知旧插件附件漏报、折叠区实体引用重复记账这三个场景，因此当时“全部完成”和“单篇保全已收窄”的表述不成立。本轮仅针对这三处修复，历史测试数量不能作为这三项已通过的证据。

## 交付范围

- 插件用 `collaboration.textFields` 声明源码合并，附件复用 `resources`，版本复用 `dataVersion / previousVersions / migrations`。没有平行资源 API、通用实体分发或契约业务包装层。
- 正文与契约同事务保存，契约随复制、导入导出和协作传递。业务元数据不解释契约；索引从正文入口取得文本，数据库原始正文交转换进程解析。
- 正常运行中删除 private blocks 分类、占位替换及私有真身写入；移动和浏览器扩展仍可只读显示不可访问的实体。历史私有数据仅在保全和显式旧格式转换中读取。
- 已批准的稳定节点、文本片段与代码步骤模型保留；移动不复制内容身份，拆合段保留远端文字，当前步骤和折叠归本机状态。
- 旧格式首次转换由桌面执行；移动端保全、导出和接收新基线。没有恢复包导入、独立资料库恢复、来源选择界面或移动端旧实体转换引擎。
- 单文档保全只收目标会话及相关正文、草稿、视图、引用资源；真正整库替换才保全对应主库。未知来源拒绝覆盖，不扩到活动库或全资源目录。
- 桌面单篇副本用 `source-projection.json` 保存来源正文和契约，不再携带 `main.db / main-before.db`；转换用的临时隔离库不进入副本，操作结束即删除。没有来源的会话不读取当前主库。
- 旧插件节点转换前按旧文档携带的 `resources` 收集附件，下载成功保存文件，失败在缺失清单记录原引用。折叠区 `allContent.slice(1)` 与正文还原使用相同范围统计旧实体引用。

## 本轮三项修复的回归

迁移、会话和持有检查的相关集 39 项通过，其中新增 7 项：单篇转换排除无关正文/草稿/视图/附件，单篇会话采用同样范围，无来源会话不读取当前库且视图变化重新保全，来源变化拒绝保全，未知插件附件下载成功与失败两种情况，以及折叠引用转换/重试计数不变并在删除后归零。既有整库替换保全、取消、过期和中断续做用例仍通过。

最终相关回归共 8 个测试文件、79 项通过（包含上述 39 项，不重复累加）：`content-migration`、`content-retention`、`manager-node-document`、`content-recovery`、`content-local-state`、`asset-service`、`legacy-upgrade`、`content-document`。桌面 `tsc --noEmit` 通过；文档检查通过（228 个 Markdown 文件，0 警告），`git diff --check` 通过。测试中的附件下载使用模拟下载结果，资源服务本身另有相关回归；不将其表述为真实公网附件下载验收。

本轮桌面 Vite 生产构建通过，包含渲染端、主进程与 preload；渲染产物写入临时目录。构建报告第三方依赖的 `use client` 指令警告，没有因此修改依赖或扩展优化范围。没有运行签名发行、部署或真实用户库转换。全部源码与文档编辑均使用 `apply_patch`，没有修改白板任务实现或文档。

## 边界与未执行项

- 测试使用临时数据库、内存文档、本机测试服务；未转换真实用户库，未部署服务，未发布或安装候选 SDK。
- 生产构建验证不包含签名、公证、安装包发行或商店提交。分包与依赖指令警告未扩展为优化任务。
- Android/iOS 系统目录与文件管理器可见性、真机输入法/弱网体验和视觉由设备验收完成；本记录不宣称已做真机或视觉验收。
- 白板协作、ASR 和移动源码页的独立任务不作为本任务完成门槛，也不在本轮修改范围。经用户单独批准的跨任务改动仅为将 `textControlInput.ts` 的 DOM setter 读取移入函数内。
- 经用户授权仅维护两处白板文档的反向链接；任务文档及旧候选脚本已退役，方案沉淀到常设架构、指南及作者文档。没有修改白板实现或任务内容。
