# 画框绘制平面隔离验证与接入判定

结论：原型显著减少收纳、解散的 DOM 归属移动，但未通过密集长拖动与完整交互的 60 FPS 验收，尚不能证明所有档位都不退化。已撤回默认入口试接入，生产继续使用逐元素稳定容器。新批次实现只在夹具中由 `--flat-renderer` 或 `--renderer-compare` 注入。

## 本轮机制

旧方案保留每个元素的 React/DOM 实例，但收纳或解散仍移动约 1000 个宿主。连续绘制组仅把次数减到一次，换 DOM 父级仍触发整片文字的样式与布局重算。原型把已注册显示根的画框子元素保留在根绘制平面，以 `registerPaintGroup` 同步位移；插入画框时以最大已连接批次为锚，移动轻量画框宿主，避免搬动整片正文。分栏内部树与无显示根插件继续使用插槽。

模型、记录身份、正文与存储格式均未改变。原型的完整收纳和解散宿主/批次移动次数均为零，1000 份编辑器在提交、撤销及重做后仍保留。试接入后恢复生产默认；类体移回夹具前后做了文本等价校验。显示服务的附加组接口不由默认元素层注册。

## 数据、保存、撤销和协作

- 候选状态 44 条定向行为测试与类型检查通过，真实 SQLite/WebSocket 回归 10 条通过。
- 4× 混合场景 909 个元素、20 轮、121 次原生手势通过，覆盖旧分栏、嵌套文档、连线绑定、取消及撤销重做。
- 4× 千元素 5 轮完整收纳/解散，共 10000 次前向归属移动；追加 2512 次跨两个画框与根层的交错移动、重排、归并。每步及撤销重做后对账独立模型、真实绘制顺序、未提交输入、焦点和 iframe 文档身份。
- 原生拖动中接纳远端几何更新、远端解散各一次；迟到松手不覆盖远端，实际 SVG 屏幕位置一致。1000 个 SVG 保留，iframe 只加载一次。
- 恢复默认入口后复核资源/层级行为与类型；类体搬回夹具后再次进行保活压力。静态检查按相关路径执行。

## 创建操作的剩余热点

4× 的诊断剖析记录约 2.5 万次包围盒调用；原生命中测试、SVG 绘制和图层处理仍占明显成本。创建手势本来已经捕获指针，重复捕获不是新优化。带 profiler/trace 的诊断有额外开销，不能把其时间与普通采样混算百分比，嵌套事件总时长也不能相加。

透明输入面诊断把一组命中测试累计时间约 844ms 降到约 66ms，光标继承隔离把最大样式重算约 79ms 降到约 7ms。但正式端到端样本不足，原型也尚未覆盖只读中断、宿主浮层和编辑交互，未接入。注入实现已退役，仅保留证据；后续实现必须限于已接管的画框创建手势，并独立验证标签内的光标边界。

三档扩展复测受并行应用与任务负载影响而停止，只关闭本任务浏览器。恢复 CLI 原始记录得到 12 条中间记录，包含主动停止的关闭异常；它们不算完整验收。整理中发现异常行缺少 renderer 导致元数据写入失败，已改为可处理异常行，数值从原始记录恢复。

另一项明确约束是整框同步仍要写入全部子元素的几何，松手后仍要更新相应 SVG 坐标。增量快照并不消除这些批量写入。进一步改动仍须先做隔离原型，验证数据、耐久保存、单步撤销和远端竞争，并重新比较三档完整交互；全面 60 FPS 目标没有完成。
