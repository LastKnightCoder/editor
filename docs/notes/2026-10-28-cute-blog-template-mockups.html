在家做一杯好喝的手冲咖啡

秋天的早上，最适合慢慢磨一把豆子。这篇是我练了三个月后的一些小心得，不追求专业，只求每天那一杯能让自己开心。

先选一包新鲜的豆子

烘焙日期在两周以内最好。浅烘的果酸更明亮，中深烘更像巧克力和坚果。第一次买可以选中烘的单品，容错率高。

小提示：豆子开封后用带单向阀的罐子装，放在阴凉处，不要进冰箱。

水温和粉水比

我常用 1:15 的粉水比，15 克粉配 225 克水，水温 92 度左右。先用 30 克水闷蒸 30 秒，看着粉层鼓起来，像一个小小的面包。

brew.ts
// 按豆子重量算出注水量
const water = (beans: number, ratio = 15) => beans * ratio;
console.log(water(15)); // 225

注水的节奏

分三段注水，每段之间等水位降到一半。手要稳，水流细，绕着中心画小圈。听起来很玄，其实练几天手就记住了。

最后一段注完，整个萃取时间控制在两分半到三分钟。如果太苦，就把研磨调粗一点；太酸，就调细一点。

写在最后

好喝的咖啡没有标准答案。记录下每一次的参数和感受，慢慢就会找到属于自己的那一杯。

④ 视觉系统

颜色

奶油底 + 一根墨色描边 + 六个马卡龙色。马卡龙色只做色块填充，文字一律用墨色，所以对比度只需校验墨色与各色块（全部 ≥ 7:1）。

字体、描边、动效

  • 标题：站酷快乐体（ZCOOL KuaiLe），圆润、可商用；拉丁字符用 Baloo 2。
  • 正文：霞鹜文楷屏幕阅读版，温柔但长文不累；代码保持等宽。
  • 描边：统一 2.5px 墨色；投影只用硬投影 0 4px 0，不用模糊阴影，这是「贴纸感」的来源。
  • 圆角：胶囊 999px、卡片 18–26px；便签保留一个直角，像撕下来的纸。
  • 动效：响应类统一弹簧曲线 300–550ms；常驻类慢于 3 秒。遵守 prefers-reduced-motion，开启后全部改为瞬时，角色变静态插画。
  • 正文区收敛：Content 渲染区只换字体、行高、标题小图标、引用块和代码块外框，不加旋转和纹理，保证编辑器内容（表格、公式、图册）原样可读。

⑤ 落地建议

做成新模板还是换皮

  • 推荐：新建独立模板仓库（如 tau-blog-template-mochi），从 tau-blog-template 复制数据层与路由（services/、utils/navigation、utils/search、main.tsx），只重写 templates/、components/Layout 与样式。官方模板保持克制风，两者在插件中心并列，用户自己选。
  • 不建议在官方模板里加「可爱主题」开关：两套布局差异太大（首页是场景、列表是信件和便签板），共用组件会让两边都变复杂。
  • 依赖可以全部沿用：motion 做弹簧与布局动画（便签飞走用 AnimatePresence），lucide-react 只保留少量功能图标，角色全部是内联 SVG 组件。

站点字段（siteFields）

字段用途
description首页介绍，沿用现有字段
mascotName团子的名字，出现在问候和 404
mascotColor团子颜色：粉 / 薄荷 / 天蓝 / 奶黄
mascotLines戳一戳时的口头禅，每行一句
ambient布尔，关掉云、烟、蜗牛等常驻动画

建议的实现顺序

  1. 视觉系统与团子组件：token、字体、<Mochi mood track /> SVG 组件、贴纸按钮。这一步决定成败，建议先出团子的 6 个表情给你确认。
  2. 文章页与卡片页：用户停留最久的页面，优先保证 Content 渲染区的可读性，再加目录书签团子、红线、表情喷泉。
  3. 两个列表页：信件与便签板，含标签筛选动画。
  4. 首页小镇与日夜：场景最重，放后面，等组件稳定。
  5. 搜索、404、加载与彩蛋。

需要你拍板的：风格方向（A/B/C 或混合）、团子的形象（这里是占位造型，正式版建议请插画师或再迭代几版）、是否做表情反馈按钮（静态站没有全站计数，只能记录访客自己点过）。
