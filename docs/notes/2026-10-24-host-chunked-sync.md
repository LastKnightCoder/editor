# 宿主分块同步验证记录

验证范围：当前 worktree 的宿主分块同步及四个仓内同步插件；未发布 SDK、插件或应用。

## 交付行为

- 桌面与移动共用协议 6、8 MiB 内容块及哈希清单；数据库、资源及会话文件由宿主拆分、校验与重组，公开插件 API 保持一致。
- 同步插件只处理普通对象。四个仓内同步提供方已调整大对象读取或响应释放；公网直链上传保持完整文件输入与 HTTP(S) URL。
- 仅维护当前格式，不读取或转换原远端单体布局。完整本地数据库、资源及插件凭据保留，首次重新发布；原远端对象不自动删除。

## 验证结果

| 范围             | 结果                                                                         |
| ---------------- | ---------------------------------------------------------------------------- |
| 插件 SDK         | 278 项测试通过                                                               |
| 桌面相关回归     | 89 项通过，1 项跨语言测试在普通运行中按环境条件跳过                          |
| 移动前端全量回归 | 788 项测试通过                                                               |
| Rust             | 119 项测试通过，格式与 Clippy 检查通过                                       |
| 类型与构建       | 桌面、移动类型检查及 Vite 构建通过，SDK 类型检查通过                         |
| 仓内作者工程     | 四个同步插件、三个上传插件及模板工程的候选包构建通过；定义了测试的工程均通过 |
| 静态检查         | ESLint 无错误，29 处警告；文档及插件进程边界检查通过                         |

TypeScript 与 Rust 使用共同的中文文件名、二进制内容夹具，并显式运行了两端实际对象文件的双向互读；普通运行中跳过的跨语言测试已在该环境单独通过。两端分别完成 129 MiB 文件往返，断言后端每次接收的文件内容不超过 8 MiB。

失败回归覆盖损坏块、上传失败不发布清单、取消、资源并发预算、旧计数隔离，以及数据库和会话目录安装在五个阶段遭遇真实进程终止后的恢复。连续 24 次控制响应及分块请求验证原生网络槽位释放。移动插件生命周期测试隔离了与该生命周期无关的重编辑器模块，保留原有超时与行为断言。

原始日志和候选包位于当前 worktree 的 `output/chunked-*`；汇总作者结果位于 `output/chunked-authors-final/report.json`。这些是本地验证产物，不进入版本库。

## 验证边界

提供方测试使用受控服务或模拟请求，没有对真实账号执行上传；未测量手机真机峰值内存，也未进行真机或视觉验收。构建仍有现有体积提示。测试证明分块传输预算和跨端协议一致，不代表所有提供方套餐或网络条件均已实测。
