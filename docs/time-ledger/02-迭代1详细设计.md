## 3. 纯函数层：`ledger.ts`

新文件，无 React 依赖，供两个视图共用，单测覆盖。

### 3.1 阶段判定

```ts
export type LedgerPhase =
  | { kind: "record" } // 已结束
  | { kind: "plan" } // 未开始
  | { kind: "live"; split: number }; // 进行中，split ∈ (0,1) 为已过去比例

export function eventPhase(event: CalendarEvent, nowMs: number): LedgerPhase;
```

- 绝对时刻：`startMs = startDate + startTime·60000`；`endMs = (endDate ?? startDate) + (endTime ?? startTime + 60)·60000`。跨天定时事件自然成立。
- 全天事件不参与（调用方只对定时块调用）。
- `endMs <= nowMs` → record；`startMs >= nowMs` → plan；否则 live。

### 3.2 标记判定

```ts
export type CalendarRole = "pomodoro" | "deadline" | "planned" | "recurring";
export function buildCalendarRoles(calendars, groups): Map<number, CalendarRole>;
export function isMarker(event: CalendarEvent, roles: Map<number, CalendarRole>): boolean;
```

- 实现位置：`buildCalendarRoles` 与 `CalendarRole` 放在 `eventTone.ts`（来源识别的原归属），`isMarker` 在 `ledger.ts`；`queries.ts` 新增 `useCalendarRoles`。
- 由现有 `eventTone.ts` 的 `buildCalendarKinds` 细化：待办清单分组下按日历名区分「截止任务 / 计划任务 / 周期任务」（与主进程 `todo-calendar-sync.ts` 的 `TODO_CALENDARS` 约定一致）。`buildCalendarKinds` 改为由 roles 派生（deadline / planned / recurring → `"todo"`），对外签名不变，`EventTitle` 等消费方不动。
- 标记 = 全天事件 **或** 角色为 deadline / recurring 的事件。不依赖 `useTodoEventSources` 的异步结果，首帧即定，不闪。
- planned 本迭代仍是时间块。

### 3.3 当日时间线条目

把 `DayColumn.tsx` 里内联的 `items` 构建抽成纯函数：

```ts
export type TimelineItem =
  | { kind: "event"; event: CalendarEvent; start: number; end: number; phase: LedgerPhase }
  | { kind: "record-gap"; start: number; end: number } // 过去空隙：补记
  | { kind: "plan-gap"; start: number; end: number } // 未来空档：点击安排（现有行为）
  | { kind: "now"; at: number };

export function buildDayTimeline(input: {
  day: number; // 选中日 0 点
  events: CalendarEvent[]; // 已排除标记
  nowMs: number;
}): TimelineItem[];
```

规则：

- 定时块按 start 排序，`cursor = max(已遍历块的 end)` 处理重叠（与现状一致）。
- **record-gap**（TL-007）：
  - 参与的块：start 早于现在的块（今天）；过去的日子全部块；未来的日子没有。
  - 范围：参与块的最早 start 到 `min(参与块的最大 end, 现在)`。睡眠与当天最后一条之后都不算空白。
  - 块与块之间的空隙 ≥15 分钟才产出。
- **plan-gap**：保持现状（08:00–22:00、从现在向上取整到 15 分起、≥60 分钟），只对今天的未来部分与未来的日子。
- **now**：保持现状插入位置。
- 常量 `RECORD_GAP_MIN = 15` 与现有 `MIN_GAP`（改名 `PLAN_GAP_MIN = 60`）、`DAY_FROM/DAY_TO` 一并移入本文件。

## 4. 视图改动

### 4.1 填充样式（`eventTone.ts`）

现有 `TONE_SOFT_BG` 把软底色直接写在 `bg-[color-mix(...)]` 里，明暗两套混法不同。为了能做切分渐变，抽一个变量：

- `TONE` 同时派生 `--cal-soft`：`[--cal-soft:color-mix(in_srgb,var(--cal)_14%,var(--tau-bg-surface))] dark:[--cal-soft:color-mix(in_oklab,var(--cal)_16%,var(--tau-bg-surface-hover))]`（混法与原 `TONE_SOFT_BG` 一致）。
- `TONE_SOFT_BG` 改为 `bg-[var(--cal-soft)]`；现有消费方（AllDayBar、TimedBlock、QuickAdd 日历标签）都已同用 `TONE`，行为不变。
- 新增 `ledgerFill(phase)`，返回 `{ className, style }`，只管底色：
  - record：`bg-[var(--cal-soft)]`
  - plan：`bg-surface`
  - live：`style.background = linear-gradient(to bottom, var(--cal-soft) S%, var(--tau-bg-surface) S%)`，S = split×100
- 计划描边色 `PLAN_OUTLINE = color-mix(in srgb, var(--cal) 45%, transparent)`，由视图决定载体：当日时间线卡片用现有 `border`（记录时透明），周视图块用 `outline`（不与悬停阴影互相覆盖）。
- 颜色只用 `--cal*` 与 `--tau-*` 变量，符合 D-001；具体透明度、描边粗细由用户视觉验收后再调。

### 4.2 当日时间线（`DayColumn.tsx`）

- `items` 改用 `buildDayTimeline`；`past` 属性与 `opacity-55` 全部删除，卡片样式改用 `ledgerSurface(item.phase)`。
- 圆点：record 实心 `bg-[var(--cal)]`；plan / live 空心环 `shadow-[inset_0_0_0_1.5px_var(--cal)]`。
- 顶部全天区：现在只放 `allDay`，改为放 `isMarker` 的全部事件，顺序为「全天在前，定时标记按时刻在后」。`AllDayBar` 新增可选 `time` 文本（定时截止显示「18:00」），已完成（`decor.source?.isCompleted`）整体 `opacity-55`。
- 计数行「N 项 · 已排 X 小时」：已排时长只算时间块，标记不计（现在定时截止 +60 分钟会被误计入）。
- **record-gap 行**：
  - 默认：虚线框「+ 补记 HH:mm–HH:mm」，样式沿用现有空档按钮。
  - 点击：原位变输入框，占位「HH:mm–HH:mm 做了什么？」；本地 `useState` 记录正在编辑的空隙（行内输入，不是浮层，不需要返回 / Esc 仲裁接入）。
  - 回车（`!isComposing`）：用 `quickAdd.ts` 新抽出的 `extractCalendarTag`（`parseQuickAdd` 同样改用它）**只摘 `#日历`，其余文本原样作标题**（不解析日期时间词，「3点 对需求」原样保留），时间以空隙为准；无 `#日历` 落默认日历（沿用 `defaultCalendar`：首个非系统、未归档日历）。调 `useScheduleMutations().createEvent`，`allDay: false`。成功无 toast（新块出现即反馈），失败 `toast.error`。
  - Esc：取消编辑并 `stopPropagation`（与底部 QuickAdd 同模式，不触发上层浮层退场）。失焦：内容为空则取消，非空保留编辑态不丢字。
  - 没有可用日历：`toast.warning("请先创建一个日历")`（沿用现有文案）。
- plan-gap 行：行为不变（打开新建弹窗）。

### 4.3 周视图（`WeekView/index.tsx`、`EventChips.tsx`）

- `TimedBlock`：`past` 属性替换为 `phase: LedgerPhase`，删除 `opacity-60`；底色改用 `ledgerSurface`。左缘 3px 色条：record / live 保留，plan 改 50% 透明度。
- 按天分列定时事件时排除 `isMarker`；全天车道的数据源从 `event.allDay` 改为 `isMarker`，定时截止在车道里带时刻文字。`assignWeekViewLevels` 只依赖起止日期，直接复用。
- 周视图的 `nowMs` 取 `Date.now()`，随 `useNowMinutes` 的分钟 tick 重算（现状已有该 tick）。

### 4.4 不受影响的消费方

- 月视图、议程视图不调用 `ledger.ts`，表现不变。
- `EventTitle` 的勾选圈逻辑不变（本迭代截止 / 周期标记仍可勾选完成）。
- 速览浮层、事件抽屉、拖拽新建不变。
