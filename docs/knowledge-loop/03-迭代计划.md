## 迭代 1：底座 + 反向链接 + 脉络面板 v1 🟡

- [ ] 脉络面板 v1 的挂载位置与形态（给用户看草图后定）
- [ ] 测试清单与验证命令

**第二步：实现**（详细设计定稿后拆分）

- [ ] 待拆分

**验收**

- 在 A 文章里内联引用卡片 B，B 的脉络显示「被 A 引用」，并能定位到 A 中引用所在的段落
- 卡片与项目文档共用正文时，两者的脉络互相显示
- 卡片是问题材料时，脉络显示该问题
- 移动端写入、切库、同步下载后，重启或重连时引用索引对账正确
- `pnpm db:schema:build`、`pnpm db:schema:check` 通过；桌面 `npx tsc --noEmit` 与相关测试通过
