# C12-A 最小权限执行边界

日期：2026-10-15。用户已要求发布平台暂缓，先推进生产本地闭环，从最小权限边界开始，不扩展更多 API。本单元交付可运行的候选载体与攻击性回归，不是生产插件管理或完整 C12 验收。

后续 C12-B 已增加真实 Electron 与独立安装包验证，见 [25](25-C12-Electron监督与WASM打包.md)；本文件保留 C12-A 的验收范围。解释器主体迁入 worker-core.mjs 供两个入口共用，权限通道未扩大。

## 范围与结构

原同环境 CJS 加载器不具备权限隔离；历史 Electron 浏览器实验存在 TURN TCP 旁路。本次不继续叠加浏览器网络拦截，改用 QuickJS/WASM 解释器候选，精确锁定 quickjs-emscripten 0.32.0，作为根工程开发依赖，不进入桌面生产包或作者 SDK。

独立 Node 子进程只运行宿主可信 worker；插件源码作为字符串进入 QuickJS，绝不进入 Node 的 eval、Function 或动态 import。客体没有默认文件、网络、DOM、Node 或 Electron 对象，不安装模块加载器。QuickJS 的 Function 构造器仍在客体内执行，并非通过删除关键字实现限制。

宿主监督器 → 每实例独立子进程 → 独立 QuickJS 堆 → 有界字符串桥 → 宿主只读测试通道。子进程不继承父进程环境变量，不开放 stdout/stderr 输出通道；宿主和其他实例不会在客体同步死循环中等待同一事件循环。

源码位置：

- [supervisor.mjs](../../scripts/plugins/restricted/supervisor.mjs)：授权前置检查、不可变身份绑定、请求验证、撤销、外部期限及进程回收。
- [worker.mjs](../../scripts/plugins/restricted/worker.mjs)：解释器、字符串桥、Promise 调度与客体预算。
- [limits.mjs](../../scripts/plugins/restricted/limits.mjs)：固定实验预算与信封校验。
- [boundary.test.mjs](../../scripts/plugins/restricted/boundary.test.mjs)：正反例、并发实例与真实本地网络探针。

## 权限语义

授权绑定安装身份、工作区、实例代次和源码 SHA-256。声明包含未获准权限、摘要不匹配、未知权限或身份变化时，在创建子进程前拒绝。这里的授权记录由测试宿主注入，尚未实现 manifest v2、用户授权界面或授权持久化。

唯一操作 `probe.read` 返回测试夹具字符串，不读取用户数据，也不导出到 `@tau/plugins`。它只验证权限代理是否真正拦截调用，不是新增产品内容 API。宿主按绑定身份选数据；客体不得提交 owner/workspace/generation 或任意内部 channel。声明和授权两者都包含该项才允许调用。

撤销立即封闭通道并取消服务 signal，终止该子进程；异步服务完成时再次核验实例有效性，旧结果不会发送给新代。宿主服务如不响应取消，已有 Promise 仍可能留在宿主，必须由生产适配器提供可取消、有期限的实现。本单元只有只读测试，不证明数据库写事务的提交撤销或数据回滚。

返回结果在子进程 close 后才交付，重复撤销幂等。子进程结束时整堆释放，不把这个单次任务原型当作长驻插件上下文的句柄回收证明。

## 固定实验预算

| 项目                 | 限制                                       |
| -------------------- | ------------------------------------------ |
| 插件源码             | 64 KiB UTF-8                               |
| 单次 IPC 文本        | 16 KiB UTF-8；宿主测试读取字符串最多 8 KiB |
| 客体 QuickJS 内存/栈 | 8 MiB / 256 KiB                            |
| 桥调用               | 总计 64 次，同时未完成最多 8 次            |
| 客体执行             | 1 秒墙钟中断检查，包含异步等待时间         |
| 子进程全生命周期     | 5 秒外部监督，包含启动；超时强制终止       |
| 子进程 V8 old-space  | 64 MiB，不能等同于操作系统硬 RSS 配额      |

预算是可复现实验参数，不是生产性能承诺。客体字符串转入 Node 前由解释器堆限制体积，进入 IPC 前再校验字节数；对象不直接跨边界。原始客体异常与宿主服务堆栈不返回插件。

## 验证与证据边界

本机 macOS arm64 / Node v24.21.0 / quickjs-emscripten 0.32.0：15 项边界测试通过；既有 SDK 的 36 项测试通过，新脚本 ESLint 通过。没有执行 Electron 集成、完整桌面构建或视觉验收，不能将这些结果换算成生产闭环通过。

运行：

```sh
node --test --test-timeout=20000 scripts/plugins/restricted/boundary.test.mjs
```

验证覆盖：默认环境及构造器旁路、拒绝授权与摘要变化、合法读取、未声明能力拒绝、伪造身份、两实例隔离、在途撤销/新代恢复、启动时撤销、错误脱敏、直接 HTTP/WebSocket/WebRTC 与模块导入拒绝、同步死循环、悬挂 Promise、内存/栈/并发/消息/累计预算、微任务与序列化死循环。

网络使用真实回环 HTTP/TCP 监听，先由宿主发起正对照确认监听有效，再运行客体并检查计数未增加；不访问公网或生产数据。没有浏览器 API 的客体无法走旧 TURN 路径，但这不是覆盖未来所有注入 API 的形式证明。后续开放网络代理必须另测目标、重定向、DNS 和权限范围。

首轮内存夹具用重复字符串，未可靠触发上限；已改为明确申请 16 MiB ArrayBuffer，与 8 MiB 客体限制对照。测试不能靠“应该分配很多内存”的直觉给出安全结论。

## 不在本次完成范围

- 尚未验证 Electron utilityProcess、生产打包中的 WASM 定位、应用退出和所有目标平台；本次是本机 Node 独立进程证据。
- 独立进程用于终止和故障隔离，不是操作系统权限沙箱。可信 worker 仍有 Node 权限；引擎/桥本身的漏洞、供应链风险与进程硬资源限制仍需评估，不能宣称任意恶意代码绝对安全。
- 没有生产加载入口、安装升级、兼容协议、授权 UI、持久权限或受限 UI。G1 同环境开发路径未改。
- 没有复用现有作者 create/activate/deactivate 契约的生产适配；原型一次运行后结束，不承诺现有 React/CJS 产物直接兼容。
- 未构建插件中心、发布者账户、审核、签名目录或 R2，未新增内容/编辑器/数据库/白板 API。
