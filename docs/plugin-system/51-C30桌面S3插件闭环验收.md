# C30 桌面 S3 插件闭环验收

这是桌面接线阶段的验收记录；后续CLI、配置迁移与旧实现退役已完成，当前状态和验收方式见[52](52-C30CLI与S3旧实现退役.md)。下文的未完成项属于该阶段历史，不是当前待办。

## 当前结果

桌面已接通实际插件安装包、启用意图、同步设置表单、应用级配置、后台提供方及数据库/会话、资源、用量同步。作者只实现五个已有存储方法和配置组件；客户端继续负责版本提交、冲突、恢复与同步计划，没有新增服务商能力声明或安装前网络探测。

工作分支为 `codex/sync-storage`，客户端目录为 `~/.codex/worktrees/sync-storage/editor`，独立作者项目为相邻 `tau-plugin-s3`。完整安装包在 `tau-plugin-s3/dist/tau.sync-s3-0.1.0.zip`。

## 已完成验证

- 桌面12个测试文件、54项测试通过，覆盖实际ZIP中的配置组件、保存失败后保留草稿、启用状态、后台任务归属、加载及在途操作占用、资源列表/上传/下载、配置持久化及原同步与用量流程。
- SDK70项测试、S3作者4项测试、类型检查和桌面Vite生产构建通过。
- `apps/desktop/scripts/sync-storage/run-client.mjs` 使用真实Electron、preload、IPC、安装事务、插件后台和应用设置模块，启动两个独立进程。首进程安装ZIP、启用、保存配置、上传下载、发布/读取版本1并验证占用保护；第二进程验证配置和启用恢复、停用拒绝新任务、重新启用。
- Electron验收使用独立临时应用目录和本地HTTP测试服务，没有修改真实 `~/.editor/setting.json` 或向真实插件目录安装。它验证客户端接线，不替代真实S3服务的兼容性判断。

复现隔离验收（在客户端仓库根目录）：

```sh
node apps/desktop/scripts/sync-storage/run-client.mjs ../tau-plugin-s3/dist/tau.sync-s3-0.1.0.zip
```

脚本输出各进程JSON结果，验收目录放在忽略的 `output/sync-client/`。配置组件集成测试需显式设置 `TAU_SYNC_PLUGIN_ZIP` 为该ZIP绝对路径，否则该外部产物测试跳过。

## 本地交互验收

1. 在上述客户端工作区运行 `pnpm dev`，使用开发分支客户端，不使用已发布旧客户端。
2. 从插件页安装上述ZIP，按既有安装流程重启并启用“S3 同步存储”。也可在作者项目运行 `pnpm install:local` 安装到约定目录，再重启客户端；不要同时使用两条安装路径。
3. 打开“设置→同步”，选择“同步插件”及“S3 同步存储”。填写服务地址、桶、区域、路径和凭据，保存同步配置；没有额外连接认证步骤。
4. 使用隔离测试库和远端前缀，按原流程检查远程版本、上传、下载，并检查资源与用量同步。保存配置将切换当前同步目标，测试前记住原目标，结束后切回。
5. 重启并切换工作区，确认启用状态与同步配置保留。停用插件后配置仍在，重新启用后可以继续；同步过程中停用、卸载或恢复版本应被拒绝，任务结束后允许。

UI视觉由用户验收，本轮未进行截图或视觉走查。

## 边界与剩余工作

- 当前阿里云S3兼容入口的条件写入失败，在旧桌面、旧CLI和新插件中均已复现，证据见50。本轮未改写条件提交或失败恢复规则，不将其作为插件准入门槛。
- CLI尚未接入插件；旧四种同步入口仍存在，旧S3配置尚未自动迁入、对应Provider/资源Adapter尚未退役。桌面闭环完成不等于整个M0—M2完成。
- SDK同步入口尚未发布。作者项目暂依赖相邻仓库 `output/c30-wiring-sdk` 中的SDK/UI本地tarball；当前无法仅克隆作者仓库便独立安装依赖。发布匹配SDK后应换为正式npm依赖并更新锁文件，再创建公开仓库。
- 尚未上传插件中心、发布SDK、合并master或安装到用户真实目录。后续先完成CLI及旧S3配置/实现退役，再统一安排发布，不混入条件写入兼容性修复。
