## 模板约定

2026-10-16 作者模板修订：公开模板改用 pnpm 11.9.0，提供锁文件及 esbuild 构建配置。内部类型边界测试移入 `scripts/plugins/fixtures/author-contract-check.ts`，只在独立验证工程中注入；公开模板不再包含内部包的失败导入示例。README 只介绍开发、安装与排错，API 补全参数、返回值、约束及示例，删除内部阶段编号和发布过程说明。8 个文档代码示例类型检查、独立 pnpm 安装构建及 15 个 Electron 进程回归通过。

- TypeScript/TSX 承载插件代码；mjs 只负责构建和安装。
- README、API、AGENTS 提供作者与 AI 开发说明，类型声明为具体签名依据。
- 构建保留完整版本目录与原子构建指针，新增 `<id>-<version>.zip`，ZIP 根包含插件 ID 目录。
- `install:local` 读取 ZIP，核对身份及完整性后安装；目标已存在时拒绝覆盖。更新仍采用停用、备份旧目录、安装、刷新，不声称提供自动升级或回滚。
- 包内包括 manifest、main.js 和可选 main.css；用户可以不使用脚本，自行解压到固定目录。
