## 使用与维护

实际验收入口：[Actions运行](https://github.com/LastKnightCoder/tau-plugin-github/actions/runs/39118740476)、[v0.1.0 Release](https://github.com/LastKnightCoder/tau-plugin-github/releases/tag/v0.1.0)。Release为正式发布，附件tau.sync-github-0.1.0.zip，5294字节，SHA-256为53a16df11032fc64f31c4a0db2135fab6570781888a9798e2e2d1ac70199caf8。

从Release重新下载后校验ZIP结构、manifest及integrity全部通过；包内文件与主项目固定0.1.0逐字节一致。该下载包通过run-client.mjs的install/restart/migrate/migrate-restart四阶段，未访问真实用户配置或同步仓库。火柴人、微信读书、自定义块的原普通CI本次云端运行也均成功。其余插件未打新tag，不声称已逐一进行云端Release发布。

1. 修改插件时同步提升package.json与manifest.json版本，提交代码。
2. 推送对应版本tag（如v1.2.3或1.2.3），Actions自动校验版本、冻结安装pnpm依赖、运行已有test脚本、构建ZIP。
3. 工作流使用仓库GITHUB_TOKEN及contents:write创建Release并上传dist/<id>-<version>.zip，无需另配发布Token。预发布版本自动标为Pre-release，重跑会更新已有Release的同名附件。
4. 代码修复发布新版本，不移动已发布tag；临时网络故障可在Actions重跑任务。
5. 2026-10-19起（PS-040）release.yml在Release后以OIDC令牌把同一ZIP提交插件中心：已登记插件自动进入待审，审核者本人推送的tag自动批准并发布；预发布版本不提交，未登记插件仅告警。主项目不再维护plugins/distribution.json。Release说明取自CHANGELOG.md中与tag同版本的小节（缺失时才用GitHub自动生成），与插件中心「更新日志」同源；更新日志写给用户，规范见模板DEVELOPMENT.md「写更新日志」。2026-10-19已按此改写17个官方插件的全部更新记录与历史Release说明并重新发布。

本机origin统一为git@github.com:LastKnightCoder/<仓库>.git。当前网络SSH 22端口超时，各任务副本局部配置core.sshCommand使用ssh.github.com:443，并以HostKeyAlias=github.com复用已知主机密钥校验；没有关闭校验或更改全局SSH配置。该配置不进入仓库，新克隆按使用者自己的SSH配置连接。
