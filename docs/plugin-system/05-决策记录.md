使用 PS 编号保存背景、选择、理由、影响和验证。状态为已确认约束、待验证提案、已采用、已替代。用户确认目标不等于确认所有技术细节；提案进入实现前需补调查依据与验收，不为普通实现选择反复请求授权。

- 目标：设计架构合理、可扩展、安全的插件体系。

- 验证：阶段计划包含多场景退出条件，公开能力有实际消费者和边界反例。

## PS-003 安全边界先于第三方开放

- 日期：2026-10-13。
- 状态：分档原则保留；隔离实现已由 PS-012 推迟，第三方高信任档策略由 PS-010 确认。
- 候选：全部同进程、全部隔离、多运行档位。
- 选择：受限运行环境承担可代理能力，受信任档承担必要的同步深度界面扩展；两者共享能力语义，不伪装成相同安全保证。
- 理由：同环境任意 JS 可绕过门面；同步渲染、编辑行为和手势也不适合一律逐次 RPC。
- 影响：受限第三方开放前必须有隔离样本和绕过测试；PS-012 将当前 P2 改为可信 API 验证，不提前宣称安全隔离。
- 历史选型：WebContentsView 专用容器的出站探针未通过，当前未采用为运行器，见 PS-006；后续隔离阶段重新验证。

## PS-004 渐进契约与现有领域内核

- 日期：2026-10-13。
- 状态：C01 已采用为设计，领域装配待 P5 实施验证。
- 选择：统一应用插件生命周期，复用现有编辑器、数据库、白板扩展协议，再按领域适配；服务通过上下文注入。
- 理由：已有领域机制承担文档和交互语义，另建三套内核会扩大风险。
- 影响：公开接口不直接等于内部接口全集，不一次创建无消费者 SDK。
- 验证：多个实例可独立运行；深层导入被禁止；不同领域退出后的数据均可保真。

## PS-005 数据身份与一致性

- 日期：2026-10-13。
- 状态：C01 已采用访问与身份边界；具体数据库布局、跨域原子提交待 P3 裁决。
- 选择：业务迁移先改访问边界，保留原 ID 和事实源；通用私有存储单独设计；公共实体走领域服务。
- 理由：微信读书现有缓存与摘录共用事务，直接拆库会改变一致性。
- 影响：同库受控批量提交与独立库 outbox 在 P3 根据整体存储目标比较，不因单个样本强行选型。
- 验证：幂等、失败回滚、来源删除、引用保留、切库迟到写入和数据恢复。

## PS-006 受限运行载体

当前实施状态：PS-012 已将此路线推迟。网络探针发现未授权 TURN TCP 连接，尚未形成可用的受限运行器，不继续作为 C02 实施选型。

- 日期：2026-10-13。
- 状态：原 C01 实施选择，已暂停；一次网络探针未通过出站门槛，不构成第三方开放许可。
- 选择：独立 WebContentsView、专用 preload、非持久化独立 session、受限本地资源协议；C02 用隐藏 BaseWindow 承载，禁止复用业务窗口工厂。
- 理由：现有主窗口具有通用 IPC 和同环境执行能力；Node utilityProcess 具有本机能力；Chromium 容器提供可落实的 OS 沙箱及 session 策略，但须验证旁路。
- 否决条件：不能封锁 WebRTC/预连接等未授权流量，或不能可靠终止插件而不误伤其他内容时，停止该载体实施并重新评估，不能降级到主界面运行。
- 验证：09 的 A01 至 A12；不能用 VM/mock 测试代替实际 Electron。

## PS-007 身份和可撤销能力

- 日期：2026-10-13。
- 状态：后续隔离与宿主接线的设计方向。当前 C02 仅实现可信代码的插件/工作区作用域和 AbortSignal，未实现下述通信身份链。
- 选择：安装身份由宿主确定；运行实例绑定 WebContents、精确 frame、session、generation、工作区会话与授权版本。固定 IPC 信封只接受允许操作，不接受自报 owner 扩权。
- 理由：库名、窗口 ID、消息中的 pluginId 均不能独立代表当前授权；异步完成时身份可能已经失效。
- 影响：接受请求和提交写入时复核，正常停用、强制撤权、已提交结果分别处理；多窗口共享工作区后台实例。
- 验证：伪造身份、旧 frame、迟到结果、同名库重开、撤权和重复请求测试。存量工作区的持久 ID 映射留在 P3，不能把会话句柄直接持久化。

## PS-008 首个入口和协议

- 日期：2026-10-13。
- 状态：后续外部产物的设计候选，随 PS-012 推迟。当前 C02 使用正常工作区模块及 definePlugin/create，不包含此受限入口加载器。
- 选择：受限入口为本地浏览器 ESM，activate(context) 与可选 deactivate；上下文注入，普通依赖打包，无 Node/Electron、远程 import 或任意 eval。preload 是另一个由宿主构建的单文件。
- 理由：不依赖宿主 CommonJS require 或发布纯类型 npm 包即可验证运行协议；适配未来浏览器载体。
- 影响：隔离页面可打包自己的 React，可信同界面扩展才共享宿主 React。首版仅有限 JSON，明确 schema、载荷和并发上限；暂不引入 MessagePort 和复杂依赖求解。
- 验证：资源清单、入口协议、未知版本拒绝、非法消息和生命周期测试。

## PS-009 数据不能成为执行权限旁路

- 日期：2026-10-13。
- 状态：C01 已采用为开放能力的硬约束；现有业务代码本轮不修改。
- 依据：custom-block 在当前界面通过 AsyncFunction 执行文档源码，现有通用 preload 提供业务 IPC。
- 选择：受限插件文档写入不隐式包含执行代码权限；开放前递归检查节点，覆盖导入转换和嵌套路径，未知可执行内容默认拒绝。
- 影响：不能仅凭沙箱容器与 network 权限宣称完成安全隔离；正文、HTML、资源 URL 和宿主动作都须检查间接提权。
- 验证：受限插件经文档写、Markdown 导入及宿主动作均不能生成会在可信环境自动执行的内容；阻塞对应 P3/P4 能力，不阻塞无正文权限的 C02。

## PS-010 第三方默认受限并允许显式高信任授权

- 日期：2026-10-13。
- 状态：用户已明确确认，替代 C01 的“首期可信档仅内置”建议。
- 选择：第三方默认在受限档运行；用户明确授权后，可以进入高信任档。安装、声明能力或受限加载失败均不得自动提升信任等级。
- 授权语义：由宿主可信界面说明同环境代码不能被细粒度权限可靠约束；默认取消，不预选、不从插件提供的布尔值或 manifest 自行授予。拒绝后保持受限档；不支持受限档的功能明确不可用。
- 技术约束：授权绑定安装身份与具体代码版本/完整性摘要；换发布者或更新代码不能静默沿用旧版本高信任授权。授权记录与插件私有存储隔离，撤销后禁止再次启动；已执行的同环境代码可能需要重启宿主才能可靠清除，不声称撤销会回滚既有副作用。
- 范围：经 PS-012 调整，C02 只实现宿主显式登记的可信开发样本；高信任启用界面及第三方接线按后续领域/安装阶段实施，不存在从受限失败自动提权的入口。

## PS-014 面向作者的单一 SDK 入口

状态更新：由 PS-015 替代 UI 必须从 SDK 根入口导出的部分；页面、编辑器等产品 API 仍保持统一。

- 日期：2026-10-13。
- 状态：用户明确要求。采用一个公共入口获取所有可用的 Tau 插件 API；当前沿用 @tau/plugins，最终发布命名在 P6 确定，不要求作者理解内部包拆分。
- 选择：插件定义、页面相关 API、UI 组件和领域扩展辅助/类型随实现统一从根入口提供；需要插件身份的服务通过 context 调用。内部继续复用 @tau/ui、@tau/editor 等独立包。
- 边界：“所有可用 API”是所有受支持的作者 API，不是内部实现全集。PluginHost、文件存储适配器及私有业务不进入根入口。当前 host/node 子入口是内部开发用途，不作为外部 SDK 承诺。
- 实施顺序：C03 接页面与 UI 导出，C04 接编辑器导出，后续领域同样处理；P6 收口实际发布、类型和模块解析。当前根入口已符合基础契约的用法，本轮不提前导出尚无宿主接线的 UI/领域能力。
- 验证：作者样本只依赖一个 Tau SDK 入口；公共名字避免领域冲突；新增 UI 后纯逻辑样本仍在无 DOM 环境可用；外部类型和构建不需要作者安装未发布内部包。

## PS-015 产品 API 与公共 UI 双入口

- 日期：2026-10-13。
- 状态：用户明确确认，取代 PS-014 的全根入口方案。
- 选择：页面、编辑器及其他插件 API 从 @tau/plugins 获取；Button、Input、Dialog 等组件从 @tau/ui 获取。内部实现分包仍不成为作者依赖，不要求直接导入 @tau/editor/api。
- 原则：@tau/plugins 保持可无 DOM 加载；UI 是明确的可选公共设计系统入口。两者均需要受支持的公开契约，不把内部实现全集作为 API。
- 影响：C03 使用双入口的真实页面样本，C04 沿用 SDK 的领域 API；P6 统一类型、依赖共享和外部发布。host/node 子入口继续只供内部宿主开发。
- C03 范围：采用固定 Page 承载动态插件页面，复用已有导航和 UI 上下文；使用工作区分域的本机偏好适配器，不为小样本引入新主进程模块。具体桌面边界见 D-140。
