# C09-B 自动监听完整构建

基线 `9149ecd43`，2026-10-15。建立作者构建发布到自动重载的闭环，复用 C09-A 的实例替换与失败恢复；本轮不开放生产第三方插件，微信读书继续暂停。C10 已通过限定平台 G1 行为验收，见 [22](22-C10-G1集成验收.md)。

## 作者流程

使用更新后的 scripts/plugins/template/build.mjs。首次构建后仍在 Tau 中选择完整版本目录并启用；在该插件的管理行点击「监听构建」，再修改源码并执行 `npm run build`。后续成功发布会自动重载，无需重新选择目录。

监听的是当前登记版本的上级输出目录，开启时只记录已有指针，不加载离线期间已经发布的其他版本。需要立即切到已有构建时使用「重载构建」；该操作先关监听，避免后来仍被旧输出目录触发。切库或重启后需重新开启监听；旧模板没有发布指针，需要更新构建脚本才能自动触发。

## 完整发布合同

构建先写 `.building-*` 暂存目录，生成 JS/CSS/manifest 和摘要，再 rename 为新的不可变版本目录。最后写临时指针并原子替换输出目录中的 `tau-build-<pluginId>.json`：

```json
{
  "formatVersion": 1,
  "id": "example.external-counter",
  "buildId": "a53ce04d-04c1-4df8-9241-23e35d7086a6",
  "directory": "1.0.0-a53ce04d-04c1-4df8-9241-23e35d7086a6"
}
```

实际模板使用 UUID 作为 buildId。目录字段只允许单个相对目录名，不能指向 `.building-*`、绝对路径或上级目录；宿主额外校验 realpath，拒绝逃出监听根的符号链接。每个插件各有指针，多个插件共用输出目录不会串用。

编译失败不更新指针；版本目录完成但指针发布失败时，也不会触发自动加载。宿主不按目录名、mtime 或单个 JS 文件判断完成，不执行安装脚本。读取新指针后继续校验清单/API/平台/ID 和完整摘要；读取期间指针再次变化时放弃该候选，读取新发布。

## 事件与生命周期

主进程使用非递归 fs.watch 监听输出目录，对目标指针事件做 100ms 合并，按指针内容去重。渲染通知携带当前窗口会话 token、插件 ID 和 watchId，旧监听的通知不能认领新会话；IPC 包装层解包 preload 的 Electron 事件首参。

同插件的管理操作串行。自动发布等待已有操作结束，只保留最新待处理版本；主进程只保留最新已校验候选，过期版本请求返回空，不回放积压队列。实际替换仍走 C09-A 的 starting 标记、停止旧代、激活/提交和失败恢复。

- 不完整指针/产物只显示错误，当前实例继续运行，等待下一次新发布。
- 普通新版本激活失败并成功回退后，继续监听下一次发布，不循环重试失败的同一条指针。
- 清理失控、旧版恢复失败或共享的每窗口每插件 20 次替换上限触发时，停止自动处理；达到次数上限时当前实例仍可使用。
- 停用、移除、手动重载会先停止监听；切库/关闭取消渲染订阅，主进程会话关闭或窗口销毁回收原生 watcher 与候选。启动监听期间取消也不会遗留 watcher。
- 监听开关不持久化。输出根目录迁移/删除后需停止并重新开启监听，不承诺自动跟踪整个作者项目的搬迁。

这是可信代码的开发工具，不是安全隔离。代码回退不撤销插件已写入的数据或任意全局副作用；同步失控仍需重启，详见 18/20 的边界。监听不运行编译器，作者仍负责构建；将来是否增加作者侧 watch 命令另行按需求处理。

## 验证与回退

`node scripts/plugins/verify-external.mjs` 验证实际模板编译失败后指针保持不变，再运行真实 Electron：暂存目录/半写文件不重载、完整指针自动加载、故障版本回退、后续好版本恢复、停止监听拒绝新发布，以及带活跃监听关闭后下一进程不自动恢复监听。测试发布只写临时复制的构建目录，不改调用方作者产物。

单测使用实际文件系统和 fs.watch 验证不回放、去重、半构建、失败后继续、符号链接拒绝和关闭清理；管理器测试验证 token/代次过滤、等待合并、停用后的旧事件、失败恢复与共享上限，事件桥单测覆盖 preload 解包和 off 的函数身份。视觉由用户验收，当前仅 macOS arm64 / Electron 43.1.1 实证，Windows/Linux 文件事件行为尚未实证。

回退此提交恢复 C09-A 的手动重载；版本目录和登记 JSON 格式未变，额外指针被旧宿主忽略。没有业务 schema 或偏好格式转换。下一步 C10 从干净作者目录完成 G1 集成验收，不以本轮局部通过代替全部框架验收。
