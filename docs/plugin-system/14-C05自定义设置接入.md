# C05 自定义设置接入

本工作单元补充 P4 的设置分区能力，复用 C02 的生命周期/存储与桌面现有设置浮层。C04 基线为 `200a86d22`；全部工作在 `codex/plugin-system` worktree 中进行。完成本样本不等于完整 P4 或第三方开放已完成。

## 作者 API

```ts
import { definePlugin, type PluginSettingsProps } from "@tau/plugins";
import { Button, Panel, Switch } from "@tau/ui";
```

`context.settings.register({ id, title, description?, component })` 返回 `PluginSettingsHandle`，包含只读 id、`open(): Promise<void>` 和 `dispose()`。组件接受 `PluginSettingsProps`，从 props.context 获取所属插件的存储与 signal；不会获得宿主设置 store 或数据库连接。实际示例见 `apps/desktop/src/features/plugins/example/settingsPlugin.ts` 与 `ReadingSettings.tsx`。

局部 id 与页面/命令一样受格式校验；宿主按插件命名空间登记，两个插件可以使用相同局部 id，同一插件重复登记会报错。`open()` 表示设置窗口已经收到切换请求，不代表组件的数据读取或保存已经结束。无设置适配器宿主明确拒绝注册，根 SDK 仍可在无 DOM 环境加载。

句柄自动归属本次 activate，无需再手动 context.register。单项 dispose 只移除分区，插件的其他能力与存储保持有效；停用取消整个插件 signal，旧注册/打开/存储调用失效。重新启用创建新组件与上下文，已保存值不会被删除。unregister 也不自动清理私有数据。

组件自己的订阅使用 React effect 清理；context.register 管理的是整个插件激活期，不等于分区关闭生命周期。存储按插件而非分区隔离，同一插件的多个分区应自行约定不同 key 或明确共享同一偏好。

设置分区与插件页面分开，是因为它们的承载语义不同：设置位于已有全窗口浮层，沿用 Ctrl/⌘+,、返回与 Esc 仲裁，不进入 Page 栈；页面仍使用 context.pages。没有新增 settings.get/set，避免两套持久化口径。

## 桌面承载

- DesktopPluginProvider 按窗口/工作区持有宿主，并将打开设置窗口的操作注入运行时。开发构建动态加载独立 settingsPlugin，默认停用，不影响原页面/编辑器样本。
- SettingsScreen 合并内置导航与运行时的活动插件分区；内置定义仍在 sections.tsx。选择 key 为 `plugin:<pluginId>:<sectionId>`，存入既有 SettingsUiStore；该 key 是导航选择，不包含设置值。
- 只有 activate 成功后的贡献可以打开。停用的 abort 通知立即更新导航和内容，不等待业务 deactivate；注销或插件缺失时保留原选择并显示不可用，用户仍可选择其他内置分区。
- 插件设置仅在窗口打开时挂载。切换分区、关闭窗口、停用、注销与切库都会卸载组件和 UiProvider 的 Portal。重新启用以新 mountId 重建错误边界，单个组件渲染失败不破坏设置窗口。
- 当前分区获得独立的 React Query 缓存，生命周期随本次挂载，关闭再打开重新读取。即使旧读取/保存稍后完成，也不会写入重新启用分区的缓存。作者仍可使用 React 与 React Query 等生态依赖，Tau 能力只从两个公共入口取得。

## 保存与失败语义

样本提供“启用阅读提示”开关，使用 `context.storage` 的 `reading-hints` key。值缺失时为 false；存在但不是布尔值则显示错误并禁止覆盖，修复数据后可重新读取。数据按当前工作区、插件与 key 保存在本机浏览器存储。

保存期间禁用开关并显示状态；写入成功后才更新控件和“已保存”提示。保存失败显示错误，保留旧值，下一次操作可重试。停用和重新启用不会清空偏好；重建宿主仍可读取，切换工作区互不串值。

沿用存储合同：停止前已提交的写入不会回滚；尚未提交的写入必须由适配器在提交前校验 signal。仅关闭设置分区不会停用整个插件，因此不取消已经提交给插件存储的保存任务。这里没有跨窗口实时通知、读改写事务或通用草稿保存守卫，不把即时保存样本外推为批量表单合同。

这些是本机 JSON 偏好，不是凭证服务或业务数据同步协议；没有改宿主全局设置对象、数据库 schema 或主进程模块。第三方安装、显式授权与隔离继续留给后续阶段。

## 验证与入口

开发构建中从命令面板打开「插件开发台」，启用「自定义设置示例」，点击「打开插件设置示例」；也可正常打开设置，在「插件」分组选择「阅读偏好（示例）」。修改开关后关闭/重开，或返回开发台停用再启用，检查保存值与分区恢复。

自动化覆盖：SDK 无界面拒绝与非法输入、失败回收和旧句柄；真实 SettingsScreen/存储下的注册、保存、停用/重新启用、宿主重建与工作区隔离、读写失败重试、迟到读写、渲染失败恢复、单项注销、相同局部 ID、关闭/切换清理 Portal、异步 deactivate 期间立即撤销。原有设置、Page、页面插件与编辑器插件路径一起回归，结果记录在 06 执行日志。

视觉验收由用户完成，不做截图或浏览器走查。下一步按真实消费者接入 P3 网络/凭证/任务/公共数据服务；侧栏贡献、生产编辑场景及其他领域各自验收，不因设置样本完成而冻结全部 SDK。
