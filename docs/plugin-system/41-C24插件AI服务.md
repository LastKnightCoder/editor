## 边界

插件仅声明功能和提交文本消息，不能通过 AI API 获取密钥、供应商连接配置或其他插件分配。用户在插件设置分配模型、开启授权并设置本机每日额度。宿主生成插件归属，统一记录用量，不保存提示词和回复正文。停用和撤销取消请求；取消不能撤销供应商已经产生的消费。当前完整权限插件不是安全沙箱。

## 实现与维护

- `packages/plugins/src/ai.ts`：作者协议，定义中的 `ai.features` 静态声明；延迟加载包先解析定义再绑定服务。
- `src-electron/main/services/plugin-ai.ts`：跨窗口共享的授权、生命周期、取消和额度；可注入依赖进行无收费回归。
- `src-electron/main/modules/plugin-ai.ts`：BACKGROUND 模块，依赖 pi-ai 与 model-usage；接入真实模型运行时、审计和 IPC。
- 配置与本机每日额度使用现有 usage.db 的 usage_meta，按插件 ID 分域，不写插件私有 storage，不随用量分段同步到其他设备。插件 AI 默认未授权。
- 请求开始前持久化预占与运行中审计，结束时更新同一事件，避免重复计数。进程退出遗留的运行中事件在下次启动标记中断且用量未知。审计不可写时不发送模型请求。
- Token 预占采用模型上下文容量加输出上限，完成后按供应商已知用量释放；未知或中断无法确认用量时保留预占。额度按本机自然日，跨午夜仍结算到开始日。请求、Token、并发上限在主进程统一执行；无隐式队列。
- usage.db 版本 2 增加插件 ID、名称、功能名和用量是否已知字段，保留既有数据；跨设备审计分段保留这些字段。不是业务主库 schema，无需修改 main.sql。
- 运行中审计仅在本机显示，不导出用量分段；完成或中断后才随原有分段同步，远端设备不展示无法由本机取消的运行请求。
- 插件详情只提供配置和「查看用量」。统一用量页增加插件筛选，概览、趋势、排行与明细使用同一过滤条件；仅新增插件请求的运行控制，不改变内置代理会话控制。
- 作者文档为 `scripts/plugins/template/AI.md`，随 npm SDK 0.7.0 与 GitHub 模板发布；0.6.0 不包含该接口。客户端运行实现随桌面应用分发，npm 仅提供作者契约。
