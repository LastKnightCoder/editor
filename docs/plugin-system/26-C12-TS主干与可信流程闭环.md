## 流程验证

新增集成测试直接使用正式宿主与真实临时文件存储：

1. 同一实例连续命令保留局部状态；重复启用不重复创建，停用后命令退出，重新启用创建新实例；deactivate 后资源逆序清理。
2. 私有 JSON 保存后，调用方修改原对象不改变已存值；注销/重建宿主后仍可读取，删除后再次重建也保持删除结果。
3. 两个工作区、多个插件的同名命令/键分别工作，不互相覆盖。
4. 激活失败撤销已注册命令并清理资源，允许修复后重试；已成功写入的数据不会假装回滚。
5. 已停用实例的迟到命令不能继续写入，新实例仍能正常保存和读取。

这些是现有生命周期和数据一致性的使用验证，不是在当前阶段新增权限安全策略。原有包校验、错误处理、数据校验和清理机制保留，不为暂停安全选型而破坏已工作的流程。

独立进程样本扩展为四步：写入 → 新进程读取 → 删除 → 新进程确认删除。每个进程都验证命令计数的实例保持/重置。`.mjs` 只启动四个进程；命令、生命周期、存储均由 TS 核心实现。多进程按顺序运行，不承诺同时写同一目录。
