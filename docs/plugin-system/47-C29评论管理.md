管理员可按插件ID、匿名身份ID、可见/已删除状态分页浏览评论，删除评论，停用/恢复评论所属匿名身份，并查看操作记录。沿用审核员名单，不创建另一套账号权限。

入口是门户 `/moderation`，登录后在“我的提交”点击“评论管理”。操作记录分页展示管理员GitHub数字ID、评论ID、匿名身份ID、动作、理由和时间。被删评论仍能通过“已删除/全部”筛选找到身份并恢复其权限，正文不能恢复。

删除立即清空正文、不可恢复；理由为必填，审计记录操作者、目标、时间与原因，不保留被删除正文或凭证。停用阻止该身份继续评论和喜欢，不自动删除历史评论或取消历史喜欢；恢复重新允许写入。并发修改按版本检查，网络重试沿用请求ID，不重复执行。匿名身份可被用户清除并重新申请，不能宣称封禁物理设备。本期不新增用户举报、自动审核或批量处置。
