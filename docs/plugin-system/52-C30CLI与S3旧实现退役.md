# C30 CLI接入、S3配置迁移与旧实现退役

## 实现边界

S3后台源码只在独立仓库 [tau-plugin-s3](https://github.com/LastKnightCoder/tau-plugin-s3) 维护。客户端固定 `plugins/releases/tau.sync-s3/0.1.1`，来源提交和所有文件摘要由distribution.json记录；构建不访问作者源码。它随桌面安装，仍服从插件启用、卸载与更新规则。没有另建SDK接口，存储协议仍是五个既有方法。

经用户确认，读取统一为SDK签名GetObject/HeadObject，404返回不存在、403继续失败，不回退匿名请求。上传、条件创建、对象命名及客户端版本发布/恢复算法未改；服务端条件写入兼容性问题继续独立记录在50。

桌面数据库、资源与用量同步，以及CLI的push/pull/status/TUI，都加载同一个已安装sync入口。CLI运行时不需要Electron窗口；应用版本从桌面package.json在CLI构建时注入，不以CLI自身工具版本冒充宿主版本。插件缺失、停用、摘要损坏均沿用已有失败处理，不能静默改用旧S3实现。

## 一次性迁移

桌面主进程读取setting.json时执行sync-settings-migration，成功落盘后才返回设置快照：

1. 将旧sync.s3的桶、区域、前缀和integration.s3凭据合入sync.plugin.configurations["tau.sync-s3"]；已有插件配置优先，不覆盖用户新配置。
2. 只有旧active为s3时才切换到plugin，保留自动同步、数据库版本与其他目标。启用意图初始化只补缺省值，保留已有明确停用。
3. 原S3资源同步账本转换为插件账本，保留文件状态与最后同步时间；配置摘要按键排序，不因表单字段顺序变化失效，账本不存凭据。
4. 保存失败保留原setting.json；重试不会重复覆盖已有插件配置。迁移完成删除sync.s3，后续运行只消费插件配置。

integration.s3、上传及博客发布的S3接口仍有业务消费者，保留这些并不是保留第二套同步实现。当前升级版本保留一次性迁移函数；全部用户完成升级后的清洁版本再退役迁移函数，不能现在删除迁移而丢失旧配置。

首次升级先启动新版桌面客户端完成随包安装与配置迁移，之后CLI可独立运行。CLI不写入插件启用事实源；遇到旧active=s3明确提示完成升级，不恢复旧Provider作为兜底。真实用户目录未在本轮验收中修改。

## 生命周期与维护

进程内继续使用PluginSyncSessions；桌面与CLI通过宿主内部sync-leases共同记录任务占用。配置不进入占用文件；短时文件锁协调任务开始和插件修改，多个同步任务可以共同占用同一插件。CLI正常结束释放，进程崩溃后下一次检查清理失效进程记录。

占用期间拒绝停用、卸载和恢复版本；桌面启动时遇到CLI占用则保留待更新包，不中途替换文件。任务结束后下次启动应用更新。CLI数据库锁、cli-sync:begin/version/finish以及快照成对安装继续复用原实现；没有在插件中复制同步引擎。

已删除：桌面S3SyncProvider、资源S3Adapter、CLI s3.ts、旧同步类型/表单/工厂分支，以及依赖旧源码的历史audit构建脚本。其它三种同步实现按原计划后续独立迁出。

## 验收与复现

本轮结果：桌面15个文件76项测试、CLI21项、SDK73项、S3作者4项通过；桌面、CLI与SDK类型检查通过，桌面Vite及CLI生产构建通过。旧S3同步Provider/Adapter与ESync.S3生产消费者已复核清零。真实Electron四个独立进程验收通过。

```sh
# 固定产物校验及随包目录生成
node scripts/plugins/build-distribution.mjs
# SDK及CLI：包含私有桶插件加载、版本提交与跨进程占用测试
pnpm --filter @tau/plugins test
pnpm --filter @tau/cli test
pnpm --filter @tau/cli exec tsc --noEmit
pnpm --filter @tau/cli build
# 真实Electron隔离验收，需要独立作者项目构建的ZIP
node apps/desktop/scripts/sync-storage/run-client.mjs ../tau-plugin-s3/dist/tau.sync-s3-0.1.1.zip
```

Electron脚本使用四个进程覆盖ZIP安装、重启、旧配置迁移与迁移后重启；测试服务拒绝未签名请求。配置迁移测试另覆盖账本保留、失败重试、已有新配置优先、不改变其他目标；更新测试覆盖CLI占用期间保留待更新包。测试使用临时目录，不操作生产桶或真实插件目录，视觉验收仍由用户完成。

本地交互验收从 `~/.codex/worktrees/sync-storage/editor` 运行pnpm dev；已有S3同步用户打开设置应只看到插件路径，原目标与开关保留。开发阶段曾手装0.1.0插件的环境应通过ZIP升级到0.1.1，随包安装按既有规则不覆盖用户已安装版本。

源码仓库已推送；SDK同步入口仍是开发快照，作者仓库尚依赖本地SDK打包文件，独立公开npm构建需要后续发布匹配SDK。没有上传插件中心或发布客户端，也未合并master。
