- 独立博客：工作树同级 `../tau-blog-template`，从原 apps/blog 复制后独立改造，未放回主仓库的产品 plugins 目录。

宿主只输出数据、搜索与插件产物，复制冻结模板目录；没有阅读器、mountContent、默认预览 UI、路由或站点 React 运行时。官方模板自己使用 React、EditorKit、HashRouter、悬停预览和全页 HTML 子文档，其他模板无需使用这些实现。

## 完成范围

1. SDK 定义六类 PublishedData、ContentRef、清单、资源、搜索文档/命中/匹配范围，以及同步创建、惰性读取的数据辅助客户端。空查询零请求，失败可重试，并发单调用取消不影响其他调用。
2. 模板专用 root/entries 与完整资产摘要进入客户端及门户校验，纯模板不进入代码生命周期。安装、更新、恢复沿用原事务，管理页显示已安装模板，发布设置选择模板。
3. 生成器输出摘要 JSON、原始 documents 搜索索引、data/styles/<摘要>.css、内容插件 CJS/CSS。关系使用 ContentRef，集合业务类型提供 collectionType；不输出宿主业务 URL、导航、激活态、分页态或 currentPath。
4. 模板入口仅替换真实 HTML 属性中的协议占位符，禁止通过脚本字符串替换；JS/CSS 与其他资产原样复制。图标使用 _tau/site/，与作者根文件共存。
5. 发布按物理目标记录成功资源，跨窗口/数据库发布同一目标时串行保护；路径预览只回传元信息。增量上传依赖后才更新入口，只保留当前及前一轮有产物变化的成功发布依赖，无变化不轮转。撤下时优先清理旧正文、聚合数据、索引；删除失败留待重试。
6. Git 只处理本次发布路径，包含被 ignore 的资源，保留 CNAME 与其他文件；特殊文件名按字面暂存，不强推覆盖远端，新分支不带入默认分支源码。拒绝目录逃逸、Git 元数据及输出目录中的链接，日志脱敏。
7. 官方博客保留页面、样式、主题、目录、标签、正文、搜索、求索录研究信息与内容预览。预览和引用型答案按数据 key 读取，分别装配节点与组件状态；共享取数缓存不共享可变编辑器树。全页 HTML 的脚本与伴生 CSS 留在模板自己的子文档中。
8. 门户 ZIP 上限从 8MiB 调整为 16MiB，解压 32MiB / 512 项不变；限制常量由 SDK、门户和客户端共用。

Tailwind 发布编译仍作为过渡生产者；本轮没有新增浏览器宿主编译服务。后续完整退出范围按 64 §10.2，待 HTML 与其他动态样式生产者转为插件自有产物后删除。

## 验证方式与证据

在宿主根目录：

```sh
node scripts/plugins/verify-blog-template.mjs ../tau-blog-template
TAU_VERIFY_BLOG_BROWSER=1 node scripts/plugins/verify-blog-template.mjs ../tau-blog-template
```

可通过 TAU_ELECTRON_BIN 指定本机已安装的 Electron。脚本使用本分支的正式生成器、真实形状的数据夹具、真实 Tailwind 编译 worker、完整官方模板 ZIP 和真实 C23 计数插件；不读取或发布用户私有数据库。

生成的 `output/blog-template-integration/<本轮目录>/report.json` 与 `browser-report.json` 记录数据协议、完整资产、换模板的数据复用、搜索、插件交互、同内容多实例、全页 HTML、Router 前进后退、刷新和预览清理。隐藏窗口只检查行为，不截图或做视觉走查。

已验证的检查包括宿主与管理器回归、SDK 全量测试、原博客迁移测试、门户 API/网页测试、各工程类型检查、桌面 Vite 构建、独立模板构建及 SDK 类型包打包。最终报告路径与本轮统计见文末。

## 使用边界

独立模板构建暂需指定宿主 checkout 的公共 packages/editor-extensions 源码，打包后不依赖宿主 UI 或本机路径；当前 npm SDK 的占位入口不是渲染运行时。具体命令见独立工程 README。

本轮未部署门户、创建远端仓库、上架模板或向真实发布账户上传文件；未做桌面安装包及用户数据库发布验收。正式上架前需随新宿主版本确定 minAppVersion 并发布门户协议更新。视觉与真实账户部署由用户后续验收。

## 旧实现与耦合再审（2026-10-19）

- 新插件删除 `_INIT_DATA_` 声明及测试用法、开发 mock 的全局数据写入和无消费者的旧开发入口；测试夹具集中在 test-fixtures，只保留现有页面回归所需内容。
- 正文插件贡献通过各实例组件上下文传递，删除全局注册表和隐式安装入口。EditorKit 设置缓存改为 WeakMap；加载失败立即回收已取得的样式资源。
- 插件资源加载必须显式提供 dataUrl；预览读取只使用数据 key，不再额外计算公开 URL。路由拼接删除旧 `/docs` 重写及资源路径特判；首页直接使用此模板自己的 `/projects` 路由，搜索直接使用清单给出的资源 URL。
- 删除宿主先生成再剥离的分页字段，以及模板里依赖这些字段的无效分页分支，继续保持当前整集合展示与模板内标签筛选。删除旧搜索 payload 空壳和伪造的时间字段，搜索结果使用协议 key 作为身份。
- 删除无人调用的按文件重试命令、IPC 和主进程方法，防止绕过目标互斥、依赖先行和发布记录；失败后仍由完整发布计划处理增量重试。
- 独立插件自行安装并锁定构建、Router 与测试依赖，不再链接 apps/blog 或 apps/desktop 的依赖目录。保留显式公共库源码 link，原博客说明标为历史存档；删除不再使用的 plugin-runtime.json 标记文件。

原 apps/blog 未修改；宿主职责与第三方模板接入契约保持不变。再审验证结果见下文补记。

首次接替旧发布链路时，旧历史表没有目标身份，沿用已有删除计划的迁移口径；之后以目标记录为准。公开源站删除不收回已经缓存或下载的内容。
