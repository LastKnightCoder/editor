## 完成范围

1. SDK 定义六类 PublishedData、ContentRef、清单、资源、搜索文档/命中/匹配范围，以及同步创建、惰性读取的数据辅助客户端。空查询零请求，失败可重试，并发单调用取消不影响其他调用。
2. 模板专用 root/entries 与完整资产摘要进入客户端及门户校验，纯模板不进入代码生命周期。安装、更新、恢复沿用原事务，管理页显示已安装模板，发布设置选择模板。
3. 生成器输出摘要 JSON、原始 documents 搜索索引、data/styles/<摘要>.css、内容插件 CJS/CSS。关系使用 ContentRef，集合业务类型提供 collectionType；不输出宿主业务 URL、导航、激活态、分页态或 currentPath。
4. 模板入口仅替换真实 HTML 属性中的协议占位符，禁止通过脚本字符串替换；JS/CSS 与其他资产原样复制。图标使用 _tau/site/，与作者根文件共存。
5. 发布按物理目标记录成功资源，跨窗口/数据库发布同一目标时串行保护；路径预览只回传元信息。增量上传依赖后才更新入口，只保留当前及前一轮有产物变化的成功发布依赖，无变化不轮转。撤下时优先清理旧正文、聚合数据、索引；删除失败留待重试。
6. Git 只处理本次发布路径，包含被 ignore 的资源，保留 CNAME 与其他文件；特殊文件名按字面暂存，不强推覆盖远端，新分支不带入默认分支源码。拒绝目录逃逸、Git 元数据及输出目录中的链接，日志脱敏。
7. 官方博客保留页面、样式、主题、目录、标签、正文、搜索、求索录研究信息与内容预览。预览和引用型答案按数据 key 读取，分别装配节点与组件状态；共享取数缓存不共享可变编辑器树。全页 HTML 的脚本与伴生 CSS 留在模板自己的子文档中。
8. 门户 ZIP 上限从 8MiB 调整为 16MiB，解压 32MiB / 512 项不变；限制常量由 SDK、门户和客户端共用。

Tailwind 发布编译仍作为过渡生产者；本轮没有新增浏览器宿主编译服务。后续完整退出范围按 64 §10.2，待 HTML 与其他动态样式生产者转为插件自有产物后删除。
