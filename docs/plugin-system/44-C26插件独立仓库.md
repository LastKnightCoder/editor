# C26 插件独立 GitHub 仓库

用户确认统一拆分微信读书、custom-block、火柴人，并创建 GitHub 仓库。主项目保留 SDK、运行时、宿主集成测试及版本化发布产物；不使用 submodule，不保留两份插件源码。

## 执行任务

- COMPLETE：Investigate/Triage/Understand the problem。已核对源码、构建、测试、分发与登录状态；微信读书/custom-block 仍引用内部主题 CSS，custom-block 测试包含宿主集成消费者。
- COMPLETE：三个独立仓库移除 workspace/宿主路径依赖。微信读书和 custom-block 通过 git subtree split 保留各自源码历史，火柴人沿用独立开发历史。
- COMPLETE：用户确认公开仓库与 SDK 发布；三个仓库源码已推送，SDK 0.8.0 已发布 npm。
- COMPLETE：主项目消费固定产物，宿主集成测试改为加载真实插件包，原源码目录及源码构建分支已退役。
- COMPLETE：干净克隆、Release 摘要、分发、回归与维护文档验证通过。

公开仓库：LastKnightCoder/tau-plugin-weread（1.0.4）、LastKnightCoder/tau-plugin-custom-block（1.0.2）、LastKnightCoder/tau-plugin-stickman（0.1.1）。主项目只保留发布产物、源码出处、通用运行时和包级集成测试。

SDK 新增公共 @tau/plugins/tailwind.css，打包从主题包的同一份语义映射生成，作者无需依赖未发布主题包。SDK 仍只提供作者契约与构建资产，JS 执行实现由客户端提供。

custom-block 的编译/清理/Skill 示例单测在独立仓库，宿主 UI 使用明确的测试替身；真实编辑器拖拽、HTML 转义、Markdown 往返、源码编辑及博客发布留在主项目，改为加载发布包，不再导入作者源码。微信读书独立仓库保留 29 项业务测试，宿主另验证页面、命令与摘录接线。
