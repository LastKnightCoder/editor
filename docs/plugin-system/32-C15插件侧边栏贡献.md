# C15 插件侧边栏贡献

2026-10-16。插件可以创建分组，也可以向公开的已有分组追加页面入口；启停、切库和重启沿用已有生命周期，不增加领域 API 或发布平台。

## 作者接口

- `context.sidebar.registerGroup({ id, title })` 返回带命名空间的 `{ id, dispose }`。
- `context.sidebar.registerItem({ id, title, group?, page, params? })` 返回 `Disposable`。
- `SIDEBAR_GROUPS` 暴露 daily、knowledge、learning、ai、sharing、plugins 稳定 ID。
- page 必须是本插件本次启用注册的有效句柄。条目参数为注册时的标量快照；跳转和高亮沿用页面的 single/params 实例身份。
- 插件不能向他人分组写入或覆盖重复 ID。没有匹配的分组时回落“插件”；空自建组/默认组隐藏。分组注销后其存续条目回落默认组；页面注销后关联入口隐藏。

## 实现

PluginHost 校验页面句柄归属并托管资源；DesktopPluginRuntime 保存贡献和页面代次，过滤非活动或已失效的贡献；navigation.ts 为已有分组补稳定 ID，并集中合并贡献。Sidebar 复用原按钮、图标列、分组折叠与 Page 导航，高亮精确比较 pluginId/pageId/instanceId。

内置分组折叠偏好保留原 label 键，自建分组使用命名空间 ID，重名分组互不影响。本阶段交付时统一使用插件图标；后续自定义图标见 33，拖拽排序和徽标接口仍未扩展。
