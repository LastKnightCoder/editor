身份是当前浏览器或客户端安装的随机凭证，不是硬件设备ID。删除Cookie或客户端凭证后无法恢复原评论的管理权；不要求GitHub登录。喜欢按插件与身份唯一，PUT设置目标状态以保证重试幂等。评论为纯文本，1至2000字符，每个身份每天最多20条，删除不返还额度；客户端请求ID防止网络重试重复发表。评论删除后正文清空，仅保留去重与限额所需记录。

用户入口：网站插件中心卡片“评论与喜欢”，按需展开列表、喜欢状态和评论输入框。删除复用公共ConfirmDialog；正文使用纯文本渲染。网络失败不清空草稿，同正文在当前页面重试沿用请求ID；离开页面不会持久化草稿。

公开接口不返回匿名身份ID或凭证，仅返回当前身份的liked和评论canDelete。写请求需要X-Tau-Visitor标识和有效身份，浏览器来源沿用已有白名单。禁用身份不能继续写入。匿名身份不能阻止用户换身份，因此这不是强防刷系统。
