# C16 侧边栏自定义图标

2026-10-16，SDK `@xiongtao.xt/tau-plugins@0.3.0` 已发布。

- registerItem 增加可选 `icon: PluginSidebarIcon`，传 React SVG 组件引用。
- 公开 `PluginSidebarIconProps`（SVGProps + size）和 `PluginSidebarIcon`；无需新增运行时共享模块或资源下载协议。
- runtime 保留图标引用，navigation 缺省回落 Plug。Sidebar 为图标统一传入 size、strokeWidth、className、aria-hidden；SVG 使用 currentColor 继承主题和选中态。
- 内置静态导航继续保留 LucideIcon 类型，动态导航允许作者组件，不改变命令面板的静态图标协议。
