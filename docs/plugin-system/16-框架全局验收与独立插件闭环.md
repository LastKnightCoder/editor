## 作者与宿主之间的合同

以下包含当前 C07 合同与后续 G1 目标，不是稳定发布协议。C07 已按 PS-021 采用 CJS 模块工厂；作者工作流第 1–4 步及第 5 步的普通启停已接线，应用重启与第 6 步仍待 C08/C09。

### 作者工作流

1. 在 Tau 仓库外创建 TypeScript 项目，只安装可分发的 `@tau/plugins`、需要时的 `@tau/ui`，以及公开声明的生态依赖。
2. 作者经 definePlugin 导出定义；命令、页面、设置通过 activate(context) 注册，资源归 context 管理。顶层只定义函数/组件，副作用放到激活期。
3. 构建生成完整版本目录；开发时用本地 SDK 压缩包即可，不要求先发布公共 npm，不依赖宿主源码路径别名或 workspace 链接。
4. 在开发构建选择本人信任的插件目录，宿主只读 manifest 展示详情；校验完成后由作者显式启用，再加载代码。
5. 从应用命令打开页面，用 @tau/ui 编辑并保存私有设置；停用、重启用、重启应用都能按合同恢复。
6. 修改并构建成功后手动重载；随后才增加监听构建完成的自动重载。移除开发包后贡献消失、管理记录删除、默认保留数据。

首个样本使用本地计数/偏好、一个命令、一个页面和设置分区，可加入一张静态图片与样式用于验证产物。第二个小插件验证 ID 冲突、依赖和资源互不干扰。网络使用本地服务夹具；不需要微信读书凭证、远端账号或公共实体 API。

移除开发目录只解除登记并清理宿主管理的副本/缓存，不删除作者源目录或构建目录。后续生产卸载也只删除宿主托管的安装文件，不能把 manifest 路径当作任意删除目标。

### 发现、加载与运行分层

- 包管理器管理静态目录、manifest、版本、来源、启用意图与文件；读取列表和打开详情不执行插件模块。
- 加载器负责校验后执行模块、绑定宿主模块、CSS/资源及释放模块代次；不在 PluginHost 混入文件监听和安装逻辑。
- PluginHost 继续管理定义实例、作用域、服务与贡献；桌面 adapter 继续负责 Page、设置和编辑器的接线。
- 开发登记的来源/清单与启用意图区分，C08-B 按本机工作区槽位 UUID 保存，暂不建立生产全局安装目录；同一工作区只允许一个窗口管理，不是后台任务单例。身份和持久化边界已按 PS-023 裁决，见 19。
- 包目录中的 id 不赋予权限。开发目录入口只用于作者明确选择的可信代码；生产保持关闭。受限档尚未实现时不增加“自动回退高信任”路径。

## 生命周期合同与失败处理

作者初期仍只需要 create、activate、可选 deactivate 和 Disposable，不新增 install/update/uninstall/attach 等空回调。安装与文件升级属于宿主事务；数据迁移另有真实需求时设计。停用后仍可查看管理详情，但不能运行插件设置组件。

| 操作            | 目标合同                                                                                  | 已有与待补                                                 |
| --------------- | ----------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| 发现/登记       | 只读元数据，默认停用；无效入口、冲突 ID、越界路径和版本不兼容有明确原因                   | C07 已实现                                                 |
| 启用            | 校验兼容与运行条件 → 加载 → 核对定义 → 新实例/代次 → activate → 对外可用                  | C07 已接模块加载；C08-B 启动前持久标记，成功才确认         |
| 激活失败        | 收回半注册贡献、取消在途调用、卸载样式，管理页保留失败与重试；不保存“运行成功”假状态      | C08-A 已接超时隔离；普通激活失败且清理成功仍可重试         |
| 停用            | 拒绝新调用、signal 失效；清理资源并保留私有数据与详情                                     | C08-A 已接有界清理；未保存内容仍仅支持即时保存场景         |
| 重新启用        | 新实例、新 signal，旧句柄/回调不能影响新贡献，已提交设置恢复                              | C07 外部包实证通过；重执行登记快照，不读取新构建           |
| 应用重启/切库   | 按有效工作区启用意图恢复；旧作用域失效，失败可跳过插件启动                                | C08-B 已接持久意图与跳过启动；同名槽位同步替换保留身份     |
| 移除开发包/卸载 | 先停用和释放加载资源，再移除包记录/代码；默认保留私有数据和公共内容，数据清除作为独立动作 | C08-B 已移除开发登记，保留数据与作者目录；生产卸载未实现   |
| 重载            | 验证新产物完整兼容 → 停用旧代 → 加载新代；禁止旧新实例同时提供贡献                        | C09-A 已接手动整实例替换；自动监听待 C09-B，不是 React HMR |
| 更新失败        | 加载前失败不打扰旧实例；替换后失败先清理新代，再恢复上个好版本或明确停用                  | C09-A 已接普通失败恢复与不可恢复时停用；不承诺数据回退     |

未保存内容在取消 signal 之前由宿主既有守卫预检；取消操作应保持旧实例可用。首个样本沿用即时保存，无草稿；开放草稿类能力前再接对应守卫，不能宣称已支持任意保存钩子。

C08-A 已覆盖 activate/deactivate/dispose 的未决 Promise、启用与停用排队、清理抛错和迟到完成。激活等待最多 10 秒，取消后最多再等 5 秒且不延长原期限；deactivate 与逆序资源清理共用 5 秒预算。超时不等于终止任意 JS：同步死循环、绕过 context 的订阅与全局副作用在同环境无法可靠清除。激活超时或清理失败标记需要重启，窗口内注销/重登记/切库不能绕过；不以 Promise.race 宣称安全隔离。

模块缓存回收是 C07 选型、C09 实证的共同门槛。仅反复给 import 加时间戳会累积模块，不作为无限热重载方案。若当前同界面载体不能真正释放，必须限制并明确提供宿主重启恢复，再决定是否满足 G1 约定；不能将其宣传为无缝热更新。连续重载的资源计数、内存基线和允许范围在实现时先记录，再判定通过。

## G1 验收清单

C07 已验证第 1–3 项、第 4 项的普通启停与双插件隔离，以及第 9 项的当前版本/平台边界；C08-A 补充第 5 项的 SDK/桌面异常回归及切库隔离。C08-B 通过四个独立 Electron 进程补第 6/7 项的正常恢复、停用、移除及跳过启动，文件与存储失败另有单测。C09-A 补第 8 项手动重载、失败恢复及连续资源计数；双工作区完整外部流程、自动监听与 G1 全链路集成仍待 C09-B/C10；局部通过不能替代整条链路证据。

1. 作者只拿文档、公开包产物和桌面开发构建，在仓库外完成类型检查及构建；无源码别名、workspace 链接、私有入口或隐藏安装脚本。
2. 插件不修改宿主源码就能登记；展示包详情不执行顶层代码；错误 manifest、缺文件、不兼容版本、路径越界和重复 ID 都在执行前拒绝。
3. 真实 Electron 加载实际 JS/CSS/资源产物；页面、@tau/ui、React hooks、设置与命令可用；不靠 mock loader 或 Vite 源码导入替代。
4. 停用后贡献及样式退出，管理仍可用，重新启用读取已保存值；两个插件同局部 ID 不串用，两个工作区不串数据。
5. 激活抛错、清理抛错、异步挂起、连续启停与迟到结果均有确定结束/恢复状态；不可抢占故障明确要求重启，不虚报卸载成功。
6. 应用重启恢复有效启用意图；插件缺失、版本不兼容或启动失败时宿主仍可进入管理并停用问题插件；验证只跳过插件的恢复启动路径。
7. 移除开发包后不再发现或自动运行；默认保留数据，重新登记同身份包可恢复；清除数据须单独明确操作。
8. 手动重载及后续自动重载只消费完整产物；构建失败保留旧版本，激活失败清理新版本且可恢复；资源计数与缓存行为符合已记录的重载边界。
9. 记录 SDK/UI/React/宿主 API、支持平台与运行档位矩阵；生产不开放未经授权的开发包入口；用户视觉验收与 Agent 行为验收分开记录。

G2 在此基础上补真实安装/更新/卸载事务、来源和路径校验、权限升级和撤销、默认受限执行及高信任明确授权、安全启动、诊断脱敏、数据迁移失败恢复，以及每个宣称支持的桌面平台实测。完整安全模型沿用 [07](07-安全模型.md)，本轮不扩大隔离实现。
