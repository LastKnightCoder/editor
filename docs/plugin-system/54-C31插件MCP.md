## 实现边界

`ctx.mcp.register({ id, name, description?, tools })` 注册插件函数，传 `transport` 则连接外部服务器；两者互斥。允许多次注册，不引入工具组接口。注册返回自动回收的 Disposable；激活成功才发布，激活失败不留下半注册项。

桌面适配在 `src/tools/pluginMCP.ts`，复用 ToolRegistry 和 customMCP。来源使用稳定的 `plugin:<pluginId>:<mcpId>`，工具名称由来源和原名摘要生成；激活与重连代次进入执行身份。工具默认 execute，继续经主进程 pi 审批；不改变 ctx.ai 的文本生成接口。

MCP 页面及聊天快捷面板通过同一 useMcpServers 显示插件项，沿用自定义区、卡片和抽屉，仅注明插件来源。整项和逐工具偏好沿用 providerStates / disabledTools，连接参数覆盖保存在本机 pluginTransports；执行器和包内默认连接配置不落入 customServers。插件提供的名称与说明只读；外部服务器可修改 transport、查看日志及重连，插件函数仅显示工具。

停用、单项注销和切库立即拒绝旧执行快照并取消等待；关闭某个 MCP 不停用所属插件。工具调用固定数据库身份、合并调用方与插件 signal，60 秒超时。取消不能回滚已提交的外部副作用。同环境插件不构成安全沙箱。

插件外部连接使用独立运行 ID，生命周期绑定发起窗口；窗口销毁、崩溃、导航及插件回收断开连接。连接握手与重连退避也检查撤销，防止停用后复活；不改变手动添加服务器的生命周期。
