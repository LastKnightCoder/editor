# C21 插件中心与已安装管理

2026-10-17。替换设置弹窗里的草稿版插件管理，在客户端内提供插件中心（发现、详情、安装）和已安装管理（启停、设置、恢复、卸载）。决策见 PS-036 与桌面 D-164，视觉参考 `apps/desktop/mockups/plugins/index.html`（方案 B）。本文是设计稿，尚未实现。

## 已确认

- 独立插件页：侧栏底部「插件」入口（设置上方）→ `plugins` 页，标签为发现 / 已安装 / 更新；详情 push 为 `plugin-detail` 页（`match: "params"`，参数为 pluginId），Alt+← 返回。
- 插件自己的设置并入详情页「设置」标签；设置弹窗「系统 → 插件」只保留概要（已安装数、可更新数、失败数）和「打开插件页」，点击关闭弹窗并 push。
- 从插件中心安装后自动启用；本地 ZIP 与手动放入目录仍默认停用。
- 发现页不做“刚刚上架”大卡，只展示全部插件网格。

## 交互约定

- 安装、更新、恢复都沿用 C17 事务：下载 → 校验 → 暂存 → 下次完整启动切换。页面顶部显示重启条（“N 项变更将在重启后生效 · 立即重启”），按钮显示“重启后生效 · 取消”，不做热安装。
- 来源标签：插件中心 / 本地 ZIP / 内置 / 开发中。只有插件中心来源检查在线更新；同一 pluginId 只有一个来源，换源需要卸载后重装。
- 信任提示照实说明：插件在完整应用环境运行，能读写笔记数据，审核不保证没有缺陷。详情页右栏和首次安装确认都显示。
- 卸载默认保留私有数据，勾选后才删除；已写入笔记的内容不受影响。内置插件不能卸载。
- 启用失败只隔离该插件，行内给出“恢复上一版 / 重试 / 复制错误 / 卸载”。
- 从 ZIP 安装、打开目录、重新扫描、作者文档、发布门户收在页头 ⋯ 菜单；开发登记目录的监听和重载只在开发构建的“开发中”分组显示。
- 不使用 Segmented；排序与筛选用按钮 + Menu。中心离线时已安装标签照常可用，发现标签显示重试和 ZIP 安装。
