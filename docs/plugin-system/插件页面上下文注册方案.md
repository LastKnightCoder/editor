## 范围

复用已有的 `get_current_context` 工具，只增加插件页面上下文提供器的注册机制。返回值的内容和形状完全由作者决定，宿主仅校验有限 JSON 并复制快照，将其原样放进当前上下文返回给 AI。

操作由作者使用现有 `context.mcp.register()` 自行提供。AI 可将上下文中的信息传给插件 MCP。此次不增加页面操作协议、工具分发器、页面引用令牌或新 MCP 工具。

## 作者接口

在页面组件的 `PluginPageProps` 增加实例级 `pageContext`，提供一个注册方法：

```ts
interface PluginPageContext {
  register(provider: () => JsonValue): Disposable;
}

interface PluginPageProps {
  readonly context: PluginContext;
  readonly params: Readonly<PluginPageParams>;
  readonly pageContext: PluginPageContext;
}
```

`JsonValue` 与 `Disposable` 复用现有 SDK 类型。类型与运行时已在本仓库接通，尚未发布新版 SDK。

注册示例放在页面组件内，`currentValue` 为作者自行选择的任意 JSON 值：

```tsx
useEffect(() => {
  const registration = pageContext.register(() => currentValue);
  return () => {
    registration.dispose();
  };
}, [pageContext, currentValue]);
```

提供器在 AI 读取时同步调用，返回有限 JSON 快照；不规定对象、字段或内容格式，也不强制提供 Markdown。尚未就绪时可返回 null。首期不引入异步加载协议。

## 接入现有上下文工具

`get_current_context` 继续返回现有的 page、editor、details，只在插件页面的 page 下增加 pluginContext。以下仅为一种作者自定义值的例子，不构成业务字段约定：

```json
{
  "page": {
    "key": "plugin-page",
    "label": "阅读清单",
    "params": {},
    "pluginContext": {
      "customField": ["任意值", 42, true]
    }
  }
}
```

示例省略原有 editor 和 details。pluginContext 直接是作者的返回值，也可以是字符串、数字、布尔值或数组，无须套对象或提供指定字段。未登记、返回 null 或提供器异常时 pluginContext 为 null；异常在宿主隔离，不影响原有上下文读取。

## 必要的运行时约束

- 注册归属真实页面实例；同一插件页面打开多个参数实例时，只读取当前栈顶实例，隐藏保活页不参与聚合。
- 每个实例同时只允许一个提供器。返回的 Disposable 只注销自己的登记，不误删后续登记；组件 effect 清理及重新执行时可正常注销、重登。
- 页面卸载、插件停用或重载、切库时由宿主兜底回收；业务回调应读取最新状态，避免首次渲染闭包导致状态过期。
- 返回值经宿主有限 JSON 校验与复制，不传出可变业务对象。作者提供摘要与定位信息，避免全量列表、凭据和无关数据。
- 页面状态只是读取当时的快照。后续 MCP 根据业务 ID 执行时，自行校验对象、数据版本与权限，沿用现有 MCP 生命周期和审批机制。
