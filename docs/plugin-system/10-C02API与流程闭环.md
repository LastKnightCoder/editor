# C02 API 与流程闭环

用户已调整当前优先级：先验证 API 设计和完整流程，不继续扩建隔离运行环境。本文替代 09 的当前实施合同；09 保留为将来的隔离验收备忘，不再阻塞 C02。

## 范围

以显式信任的本地示例验证插件定义、独立实例、启用、命令、插件私有存储、停用清理、注销与重新启用。不提供第三方安装、授权 UI、网络代理、沙箱、页面或领域内核扩展；这些接口等真实消费者需要时再增加。

高信任第三方仍须用户明确授权，默认受限；本阶段的 registerTrusted 是宿主开发入口，不能当成生产授权流程。没有受限运行器时，不加载未经信任的外部代码。首期只做桌面，核心契约不绑定 Electron。

## 当前 API

- 插件：definePlugin({ id, name, version, create })，每次启用由 create 返回 activate(context) 与可选 deactivate 的实例。
- 上下文：pluginId、workspaceId、signal、commands.register、storage.get/set/delete、register(resource)。
- 宿主：registerTrusted、enable、disable、unregister、getState、listCommands、executeCommand、dispose。
- 数据：有限 JSON，读写复制；命令局部 ID 由宿主加插件前缀；存储适配器由宿主选择，插件不选择命名空间和路径。

生命周期状态为 disabled、activating、active、deactivating、failed。激活/停用串行；停用先取消作用域，失败清理继续处理其余资源。注销保留数据，不把禁用、卸载代码和删除用户数据混为一谈。

不提供假事务。get 后 set 不是原子读改写；需要并发更新时依据实际需求增加协议。异步命令停用后不能继续使用旧上下文，但停用不会回滚已提交副作用。受信任代码必须配合 signal 和正常清理，不承诺隔离失控循环。

## 代码位置和验证

核心位于 [packages/plugins](../../packages/plugins/README.md)，示例位于 [examples/plugin-workbench](../../examples/plugin-workbench/README.md)。示例插件不导入宿主、应用 store、Electron 或数据库连接。工作区包尚未发布，对外稳定承诺留在后续阶段。

```sh
pnpm --filter @tau/plugins check
pnpm --filter @tau/plugins test
pnpm --filter @tau/plugins build
pnpm --filter @example/plugin-workbench check
pnpm --filter @example/plugin-workbench demo
```

本阶段没有修改桌面生产代码、schema、Page 或壳层协议，验证范围为新增包、样本和仓库结构门禁，不为此启动整套桌面打包或视觉走查。后续真正接入桌面时再执行对应类型、行为和构建门禁。
