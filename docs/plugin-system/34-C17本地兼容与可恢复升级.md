# C17 本地兼容与可恢复升级

2026-10-16。客户端本地构建版本为 0.58.0，SDK 保持 0.3.0，没有发布新的客户端发行版或恢复插件市场工作。

## 已交付

- `minAppVersion` 为 manifest 可选字段，严格版本比较覆盖预发布和构建元数据。扫描、开发包读取、ZIP 暂存与启动应用共用检查；不兼容时不执行插件代码。未声明的旧包继续兼容。
- 管理页增加“安装或更新 ZIP”“取消待更新”“恢复上一版”。操作只暂存，下一次完整启动时切换；启用意图与数据沿用现有机制。
- 主进程 TS PluginUpdates 串行操作，使用 pending、transactions、backups、errors 等目录。prepared 之前不移动旧包，未提交中断恢复旧包，committed 后中断完成备份。未能恢复的事务阻止对应包加载，不影响其他正常插件。
- 上一版可以安排恢复。激活失败不会自动回退数据或盲目在同一进程加载旧代码；用户通过管理入口安排旧包，下次启动恢复。被撤回的未提交目标保留在 failed 目录供排查。
- 更新要求版本高于当前包；恢复入口可以降级。直接手工解压的替换不进入备份/恢复协议，首次安装脚本仍拒绝覆盖现有目录。
