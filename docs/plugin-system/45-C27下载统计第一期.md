口径：平台成功读取并返回完整 ZIP 计为一次有效分发，不代表安装人数或网络接收完成。同一匿名身份、同一版本、同一 UTC 日只计一次；最近七日含今天及前六个 UTC 日。升级到不同版本计数。无有效身份仍能下载但不进榜单，统计故障不能阻断下载。历史从本次上线开始，不伪造以前的下载量。

身份由服务端生成 ID 和随机凭证；浏览器使用 HttpOnly Cookie，桌面主进程使用安装级凭证（不随工作区改变，不通过 IPC 返回）。本期不做喜欢和评论，不使用硬件指纹。

目录在数据库按插件聚合计数、排序并分页，再只读取当前页插件的版本资料，沿用现有 SemVer 判断兼容版本。搜索先在已发布版本资料中筛选候选，再按最高版本资料过滤，可能返回不足一页但继续给 nextCursor。更新与详情现有桌面消费者仍由主进程按页读全目录，防止遗漏更新；网站逐页加载。榜单变化期间游标不承诺冻结快照，消费者按 pluginId 去重，刷新重新取榜。
