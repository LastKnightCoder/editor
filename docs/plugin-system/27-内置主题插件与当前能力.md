## 最小内置插件

[themePlugin.ts](../../apps/desktop/src/app/plugins/builtin/themePlugin.ts) 使用既有 definePlugin/create/activate/commands.register；插件 ID 为 `core.theme`，显示名为「主题切换」。它直接消费 `@tau/themes` 的主题清单及 `@tau/themes/react` 的主题 store，不依赖 feature 私有 store，不新增插件 SDK API。

插件贡献两个命令：

- **切换到下一个主题**：按照已注册主题清单轮换主题族。
- **切换明暗模式：浅色、深色、跟随系统**：沿用现有 nextAppearance 循环。

主题选择仍由现有主题运行时应用 DOM、持久化到 localStorage，并由原有窗口同步机制处理。插件不直接写 data-theme/data-mode，不另存主题偏好。停用不撤销用户已经选择的主题，只移除命令；重新启用不重复注册。

DesktopPluginProvider 在开发与正式构建均只默认注册该插件，首次无记录时默认停用。启用状态已按本机应用保存，重启/切库自动恢复；主动停用后保持停用，见 [28](28-内置插件启用状态持久化.md)。其他验证样本已移入测试夹具，不再自动装配；外部开发目录管理仍只在开发构建加载，正式构建不会调用开发插件 IPC。这属于工具链边界，不是可信/受限权限分档。

## 手动验收

1. 打开设置 → 插件，找到「主题切换」，点击启用。
2. 打开命令面板（Ctrl/⌘+K），搜索「切换到下一个主题」并执行。
3. 执行「切换明暗模式：浅色、深色、跟随系统」，确认偏好和界面同步。
4. 在插件管理中停用，确认插件命令消失、已选主题保持；再次启用，命令恢复。

既有外观设置和原生主题快捷入口保持可用，本次不把整个主题系统迁成插件。
