## 实现边界

- Typst 仅 HTML，既有编译入口与新 SDK 共用 TS worker，删除旧 JS worker与复制步骤。数学公式 HTML 适配共用同一前导规则。
- Tailwind 使用已有编译 worker，每次 SDK 调用独占进程和临时目录；取消不影响其他编译。
- TikZ 独立 iframe 复用已有编译器，服务包装 document 环境；SVG 包含字体样式，120 秒超时或取消销毁上下文。不是任意 LaTeX 宏包安装服务。
- FFmpeg 复用既有二进制缓存；取消准备等待不会中断其他调用共享的下载。ffprobe 用平台可选依赖，打包配置解包、补齐平台包并在签名前修复执行位；打包后的 native-runtime 验证增加真实 ffprobe 执行检查。
- 文件整体经内存传输，目前不承诺超大媒体流式处理。进度返回媒体时间，不猜百分比；日志保留末尾 64 KiB。
- Markdown 使用客户端 codec，支持每次调用独立扩展，不读取编辑器实例；warnings 覆盖未识别节点与已知 HTML 降级，不宣称任意输入无损。HTML 输出保留客户端既有原始 HTML/外部资源规则，不是净化器。
