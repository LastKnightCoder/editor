## 微信读书当前链路

| 范围       | 当前实现与证据                                                                                                                                                                     | 插件化要求                               |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| 网络       | [服务](../../apps/desktop/src/services/weread/index.ts) 读取设置中的 API Key，经 `nodeFetch` 请求 Agent Gateway                                                                    | 注入网络与凭证能力，业务协议仍归插件     |
| 查询与同步 | [queries](../../apps/desktop/src/features/weread/queries.ts) 使用 react-query、模块级同步状态、增量元数据与划线同步                                                                | 工作区和实例作用域、取消、任务去重       |
| 缓存命令   | [commands](../../apps/desktop/src/commands/weread.ts) 经 `withModule` 调用 `weread:*`                                                                                              | 保留初始化竞态保障，收口公开服务         |
| 主进程     | [WeReadModule](../../apps/desktop/src-electron/main/modules/weread.ts) 在 handler 中取当前数据库，保存后发布摘录变化                                                               | 在宿主边界校验请求所属数据库与会话代次   |
| 事务       | [WeReadNotebookTable](../../apps/desktop/src-electron/main/modules/tables/weread-notebook.ts) 同事务保存笔记本与同步摘录                                                           | API 拆分不能破坏原子性、幂等和变更通知   |
| 页面       | [书架](../../apps/desktop/src/features/weread/pages/weread.page.tsx) 为 single，[单书](../../apps/desktop/src/features/weread/pages/weread-book.page.tsx) 按 bookId 去重           | 保持定位参数、实例身份和导航语义         |
| 跨域动作   | [详情页](../../apps/desktop/src/features/weread/views/WeReadBookView.tsx) 查公共摘录、转卡片、发起问题                                                                             | 公开素材动作，避免插件导入内部服务       |
| 连接设置   | [IntegrationSection](../../apps/desktop/src/features/settings/sections/IntegrationSection.tsx)、[ConnectPanel](../../apps/desktop/src/features/weread/components/ConnectPanel.tsx) | 设置贡献与凭证处理，保持入口完整         |
| 启动校验   | [启动 Hook](../../apps/desktop/src/hooks/useWeReadSessionBootstrap.ts) 等设置及模块就绪后校验                                                                                      | 迁入工作区或插件生命周期前保持唯一调用链 |
| 本机偏好   | [prefs](../../apps/desktop/src/features/weread/prefs.ts) 保存书架布局、排序、目录开合                                                                                              | 区分本机偏好、工作区数据和凭证           |

当前同步代码在部分异步边界比较活动库名；主进程命令不携带完整工作区会话身份。是否存在可复现的跨库提交窗口及其覆盖范围，需要 C01 用延迟夹具核实，不能仅凭静态阅读宣称已复现。

[旧微信读书数据流文档](../weread-data-flow.md) 保留了不同时间的实现说明：页首更新已经指出旧页面、补偿队列和 Slate 转换过时。当前调研以本表链接的源码为准，不能把旧文档里的全量覆盖、表格视图等描述直接当作现状。

## 来源身份和公共数据

[摘录类型](../../apps/desktop/src/entity/excerpt/types.ts) 将来源限制为 `weread | web`，锚点是来源专属联合类型；[素材模型](../../apps/desktop/src/entity/material.ts) 包含具体微信读书定位。[展开函数](../../apps/desktop/src/entity/excerpt/weread.ts) 将划线与想法映射成稳定外部 ID。

迁移必须保留摘录 ID、外部 ID、书籍 ID、已生成素材引用和源端删除的软删除语义。来源提供器可以先适配既有身份，不必在引入注册表时重写历史数据。是否扩大 SQL 约束、索引及跨端模型，须检查实际 schema 后单独裁决。

## 外部实现依据

以下来源在首轮调研中已阅读；在线源码会变化，后续实施依赖其具体行为时应重新核实或固定版本。

- [Obsidian 包定义](https://github.com/obsidianmd/obsidian-api/blob/master/package.json)：类型入口指向声明文件，运行实现由宿主提供。
- [Obsidian 示例构建](https://github.com/obsidianmd/obsidian-sample-plugin/blob/master/esbuild.config.mjs)：`obsidian` external，输出 CJS 的 `main.js`。
- [Obsidian 插件协议](https://github.com/obsidianmd/obsidian-api#plugin-structure)：入口、依赖打包及资源注册清理。
- [Hot Reload 源码](https://github.com/pjeby/hot-reload/blob/master/hot-reload.ts)：文件监听、防抖、串行 disable/enable；当前源码跳过未启用插件，不能照搬 README 的旧描述。
- [Obsidian 插件安全](https://obsidian.md/help/plugin-security)：社区插件不能可靠限制到细粒度权限。
- [Electron 安全指南](https://www.electronjs.org/docs/latest/tutorial/security)：隔离、沙箱、IPC sender 校验和能力桥边界。
- [Node VM](https://nodejs.org/api/vm.html)：VM 不能作为安全机制。
- [Electron utilityProcess](https://www.electronjs.org/docs/latest/api/utility-process)：可作为进程运行载体，独立进程本身不代表权限沙箱。

Obsidian 的包与构建说明足以解释“开发期类型、运行期宿主实现”；本调研没有审计其闭源加载器，不把推测的加载器内部写法当作事实。
