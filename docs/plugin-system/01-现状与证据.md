# 插件系统现状与证据

核实日期为 2026-10-15，C10 从 `3b032979a` 继续；初始代码基线为 `51fd53b66082217a5f616999ab7d1184fd29e67d`。本文件描述现有行为；目标接口见 [目标架构](02-目标架构与能力.md)。源码变化时就地更新现状，历史过程保留在执行日志。

## 框架全局结论

当前按 PS-030 流程优先，C12-C 将基础作者类型集中到 TS contract.ts，正式 PluginHost、生命周期和文件存储继续由桌面与测试共用；40 项测试和四个顺序独立进程验证可信生命周期与持久化流程，见 [26](26-C12-TS主干与可信流程闭环.md)。QuickJS/WASM 实验及依赖已从当前树移除；C12-A/B 的限定结果保留在 24/25 与历史 Git 提交中，不代表当前生产模块。安全选型和发布平台暂停。

现有内置样本仍由源码显式装配；C07 另提供外部可信开发包的静态清单登记与延迟加载，不再要求修改宿主源码。工作区包仍 private、导出源码，但可生成独立安装的声明契约包，作者项目不依赖 workspace；宿主共享 React/UI，真实 Electron 已验证命令、页面与设置。C08-B 已按本机工作区持久登记与恢复启用意图，可移除登记并保留数据；C09-A 已提供手动重载与失败恢复，C09-B 已接原子发布指针与显式自动监听，没有生产安装包升级/卸载，C10 已通过 macOS arm64 可信开发档 G1 行为验收，G2/G3 未完成。

PluginHost 已有普通启停、失效 signal 和逆序回收；C08-A 为异步生命周期增加期限，激活超时或清理失败标为 restart-required，同窗口重新登记/切库不能绕过。普通激活失败且清理成功仍可重试，迟到结果不会复活贡献；同步失控和任意全局副作用不能强制回收。unregister 只注销定义，不等于安装包卸载。源码证据、缺口归属和验收门槛统一见 [16](16-框架全局验收与独立插件闭环.md)，当前收尾合同见 [18](18-C08生命周期与管理收口.md)。微信读书后续推进暂停，现有 C06 网络和样本代码保留。

## C02 已落地的开发能力

[packages/plugins](../../packages/plugins/README.md) 提供契约、受信任宿主、内存和 Node 文件适配器；[独立进程样本](../../examples/plugin-workbench/README.md) 验证注册、命令、启停和两个进程间的数据恢复。桌面开发构建已通过 C03–C06 消费新包，生产领域业务尚未整体迁入。

新包不包含安装器、授权 UI 或沙箱；C06 已增加宿主注入的 fetch。作用域检查防止正常代码的串用，不限制恶意同进程插件；不承诺同时多进程写同一存储目录。

## C03 桌面开发接线

页面 API 已进入 SDK 根入口，UI 直接从 @tau/ui 使用；桌面开发构建提供「插件开发台」与一个随构建提供的可信样本。壳层按工作区持有宿主，动态页面经固定 Page 承载，插件命令接入现有命令面板，偏好用注入的浏览器存储保存。Page 栈机与双注册表没有改动。

样本默认停用，启停不持久化；生产不加载样本。C04 已增加编辑器应用级注册和独立实验文档，数据库和白板尚未接入。具体代码索引与限制见 [12 C03 接入](12-C03桌面页面与UI接入.md) 和 [13 C04 接入](13-C04编辑器扩展接入.md)，不再把原 C02 的无界面状态当作当前全貌。

## C04 编辑器开发接线

SDK 根入口复用 `@tau/editor/contracts` 中的扩展定义，提供 context.editor.register、defineEditorExtension、defineEditorElement 和节点类型增强；组件使用 @tau/ui。桌面运行时校验并撤销贡献，开发台独立 PluginEditorSession 按贡献集合变化重建 Slate，并恢复原始正文、选区与 history。EditorKit、未知节点保护、命令和 Markdown 内核保持原实现。

样本是提醒块和纯 Markdown codec；只支持 workbench 场景。关闭页面/切库会丢弃实验文档，生产 ContentEditor、Y.Doc 与 external history 尚未接入。纯 codec 可以在 Node 独立装配；未改变主进程生产 codec 列表。实际重建不保留组件局部状态/焦点/在途操作，不属于无缝热更新。

## C05 设置分区接线

SDK 根入口提供 context.settings.register 及组件/句柄类型，实际 React 设置组件只从 @tau/plugins 和 @tau/ui 获取 Tau 能力。SettingsScreen 只有一个插件管理入口，宿主根据登记定义提供列表和每插件详情；设置贡献成为详情内分组，旧 open 仍可定位。停用后管理信息与启用按钮保留，自定义组件退出，重新启用恢复。开发台将启停交给同一管理入口。

组件仅在设置打开时挂载，离开/关闭/停用会回收 UI Portal，查询缓存和错误边界按挂载隔离。样本复用插件私有浏览器存储，按工作区保存布尔偏好，成功后生效、失败可重试；没有新增全局配置写权限、数据库表或设置草稿协议。详见 [14 C05](14-C05自定义设置接入.md)。

## C07 独立开发包接线

[声明交付工具](../../scripts/plugins/package-sdk.mjs) 输出 @tau/plugins/@tau/ui 开发包；[作者模板](../../scripts/plugins/template/package.json) 在仓库外独立安装、检查及构建。声明中的私有包引用收拢到包内，普通依赖打包，入口为 CJS，源码仍使用标准 import/export。

[主进程读取](../../apps/desktop/src-electron/main/services/plugin-package.ts) 校验 manifest、版本/平台、路径/符号链接和 JS/CSS 摘要，返回快照，不执行代码。[加载器](../../apps/desktop/src/app/plugins/development-loader.ts) 在启用时执行并核对定义，复用宿主和管理页，CSS 随 signal/dispose 释放。目录选择仅在桌面开发模式可用，安装版及非开发启动由主进程拒绝。未增加删除作者文件、生产安装或隔离能力；完整合同见 [17](17-C07独立插件开发与加载.md)。

## C08-B 开发插件持久管理

C08-B 的身份、登记、启动中断跳过和移除合同见 [19](19-C08开发插件持久管理.md)。主进程只读作者目录，恢复核对原摘要；损坏记录不自动覆盖，同工作区只允许一个窗口管理。四个独立 Electron 进程验证重启、停用与移除后重新登记恢复数据。

## C06 标准 fetch 接线

SDK 提供 context.fetch，直接沿用原生签名及 Request/Response。桌面新 BACKGROUND fetch 模块执行原生 fetch，IPC 按需传输请求/响应流；旧 nodeFetch 函数、选项、DTO 和 IPC 已删除，微信读书、B 站、图片、资源、剪藏及 MCP 调用直接迁移。

微信读书开发插件通过业务依赖取得自己的既有账号配置，标准 fetch 验证手动读取、分页、刷新及取消；未写书架/摘录。Node 本地 HTTP 和真实 Electron 隐藏窗口验证 multipart、二进制、流、Cookie/Set-Cookie、clone 和取消；未读取真实账号凭证或请求远端微信读书。详见 [15 C06](15-C06真实服务API与微信读书书单.md)。下表的原业务同步与存储保持原语义，网络调用已改为 desktopFetch。

## C01 补充核实

- 通用窗口工厂加载主应用页面和公共 preload，不能直接作为受限运行容器。
- 已有 RPC 契约和服务注册表解决类型与装配，不提供插件身份与细粒度授权。
- 数据库既有窗口到库名映射，也有当前库访问及连接替换；新插件需绑定工作区会话。
- 已有 utilityProcess 用于可信本地推理，可参考监督和取消模式，不能视为第三方沙箱。
- 默认 session 的 ltoh 协议、本机 24678 服务和全窗口广播不应暴露给受限插件。
- custom-block 在当前界面执行 JavaScript，受限文档写入可能形成间接执行路径，必须在开放前限制。
- 编辑器行为、数据库排序与渲染、白板命中与手势均包含同步契约；受限档只接可代理子集。

具体源码、复用边界和六类样本的同步/异步分析见 [C01 裁决](08-C01需求与运行架构裁决.md)。这些是静态调查结论，不代表完成全仓漏洞审计或复现所有潜在攻击；隔离和网络旁路测试属于 C02。
