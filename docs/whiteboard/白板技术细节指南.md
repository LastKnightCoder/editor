## 一、架构与文件结构

- **入口组件**：`index.tsx` —— 创建 `Board`，注册插件，绑定全局事件，渲染 Toolbar/Attribute/Sidebar/StatusBar/ContextMenuLayer 与资源选择器。
- **核心引擎**：`Board.tsx` —— 事件分发、操作应用、历史、参考线、渲染入口、演示管理、能力查询。
- **插件**：`plugins/*` —— 每种元素或行为一个插件；可处理事件、渲染、命中、移动、菜单、能力声明。
- **渲染层**：`components/BoardContent`（SVG）、各元素组件（Arrow/Image/Video/Audio/MindNode/Webview/Frame/WhiteBoard/Column 等）。
- **工具与服务**：`utils/BoardOperations`（纯函数操作）、`SnapManager`、`PresentationManager`、`ResourceUsageTracker`、`CapabilityService`、`ViewportUtil`、`MindUtil/FrameUtil/PathUtil/BoardUtil`。
- **上下文**：`context.ts` —— Board/Selection/ViewPort/BoardState Context；ArrowMove Context 在 `hooks/useArrowMove.ts`。
- **变换**：`transforms/SelectTransforms`、`ViewPortTransforms`。

---

## 二、数据与操作模型

### 2.1 核心类型

- `BoardElement`：`id/type/name/groupId/children` + 通用属性 `resizable/autoHeight` + 插件自定义字段（位置、尺寸、样式等）。
- `ViewPort`：`minX/minY/width/height/zoom`。
- `Selection`：`selectArea`（框选锚点+焦点）、`selectedElements`。
- `Operation`（`types/operation.ts`）：插入/删除/移动/设置属性/视口/选区等，支持路径 Path（数组下标寻址）。

### 2.2 快照与历史

- `snapshot`：`{ children, viewPort, selection, presentationSequences }`，供 `useSyncExternalStore` 读取。
- `undos/redos`：数组形式，每 entry 可包含多条 Operation；默认最大 100。
- 归并策略：`apply` 中 1 秒窗口合并到同一 undo entry；redo 在新操作后清空。

## 三、核心引擎 Board.apply 详解

1. **预处理**：`BoardOperations.applyOperations`（纯函数）深拷贝数据 → 过滤无效操作 → 插入操作按深度排序 → 逐条执行 → 返回 `data` + `metadata`（changed/removed/inserted/hasChanges）+ `executedOps`。
2. **资源追踪**：`ResourceUsageTracker.track(metadata, resourceSource)` 统计新增/删除资源（图片/音视频/白板引用）。
3. **状态更新**（immer Draft）：若 children/viewPort/selection 有变化，更新 draft。
4. **参考线**：apply 不再维护参考线数据，吸附候选由 `board.snap` 在交互开始时按需快照。
5. **历史记录**：若 `updateHistory=true`，使用 `executedOps`（或 preprocess 结果）入栈，1 秒内合并；超过 100 弹出最旧。
6. **事件广播**：完成 draft 后 `finishDraft` 并 emit `onValueChange/onViewPortChange/onSelectionChange/element:change/element:remove/change`。

## 四、事件分发与时序

- 入口事件（鼠标/指针/键盘/滚轮/粘贴/拖拽）在 `Board` 中通过 `bindHandler(eventName)` 收集插件对应 handler，`executeSequence` 按注册顺序调用。
- 只读模式：大部分事件直接 return。
- 演示模式：Select/Move 等会在插件层判断并阻断（如正在演示或创建序列）。
- 指针事件节流：`index.tsx` 用 `useThrottleFn`(25ms) 包装 `onPointerMove`，降低高频事件开销。
- 全局事件绑定：`index.tsx useEffect` 在 document/container 上注册，组件卸载时清理并销毁 board。

| ------------------ | ------------------------------ | ------------------------------------------------- | -------------------------------------- |
| ViewPortPlugin     | wheel/keyboard                 | 改变 viewPort，提供 fit/zoom 控制                 | 滚轮缩放阻止默认滚动                   |
| SelectPlugin       | keydown                        | delete/mod+a                                      | 点选/框选手势在交互内核 SelectingState |
| HistoryPlugin      | keydown                        | 调用 `board.undo/redo`                            | 组合键监听                             |
| CopyPastePlugin    | copy/cut/paste                 | 克隆选中元素，剪切后删除                          | 偏移粘贴位置                           |
| CardPlugin         | pointer/render                 | 继承 CommonPlugin，提供命中/resize/连接点         | 文本卡片                               |
| GeometryPlugin     | pointer/render                 | 绘制矩形/圆角/菱形/三角等，支持 resize            | 使用 CommonPlugin 能力                 |
| RichTextPlugin     | pointer/render                 | 富文本块，编辑时写入 `board.isEditingElements`    | 编辑态禁止删除/移动                    |
| ArrowPlugin        | render/hit/getArrowBindPoint   | 连线，中心/左右连接，Marker 统一在 `ArrowMarkers` | 依赖元素的连接点                       |
| ImagePlugin        | context menu/paste/drop/render | 触发 ImageSelector，过滤空资源                    | beforeSave 清洗                        |
| VideoPlugin        | 同上                           | 支持多来源（local/resource/url 等）               | 右键菜单打开选择器                     |
| AudioPlugin        | 同上                           | 支持 url/TTS 等                                   | 右键菜单                               |
| MindPlugin         | move/render/isHit              | MindNode 折叠左右子树，RootOnly 吸附              | isElementSelected 自定义               |
| PresentationPlugin | context menu/key               | 创建/编辑帧，驱动演示模式                         | 与 PresentationManager 协作            |
| WebviewPlugin      | context menu/render            | 嵌入网页，选择器选择 URL                          | 右键插入/替换                          |
| FramePlugin        | render/move                    | 容器，移动时可带子元素；参考线参与受能力控制      | `shouldMoveWithChildren`               |
| WhiteBoardPlugin   | context menu/render            | 引用/创建其他白板                                 | 资源追踪                               |
| ColumnPlugin       | render                         | 列布局元素                                        | 子列容器                               |
| FileDragDropPlugin | drag/drop                      | 识别文件类型并委派到图片/视频/音频/白板插入       |                                        |

> CommonPlugin：提供通用命中、resize、箭头连接点、拖拽处理（对 x/y/width/height 元素适用）。
> 拖拽/吸附/参考线手势不在插件中，由交互内核 `interactions/states/DraggingState` 承接（原 MovePlugin 已删除），支持 Frame/Mind 特殊规则，Alt 关闭吸附。

**连接点归属仲裁**（`utils/ConnectPointOwner.ts`，store 经 `BoardStateContext.connectPointOwnerStore` 下发）：同一时刻只有一个元素显示悬停连接点、只有一个元素成为拖动箭头的落点目标（选中元素的连接点常显，不受仲裁）。

- 各元素经 `useDropArrow` 把包围盒注册为候选（悬停与落点共用）；规则：指针在元素内部优先于只落在外扩感应区；同为内部取面积最小（嵌套落到最内层），同为外部取距离最近。
- 悬停：指针变化时统一选出 owner，感应半径 `ARROW_CONNECT_PROXIMITY_RADIUS`；指针停在连接点上或从连接点拖出箭头时锁定 owner；owner 变为空时延迟 `ARROW_CONNECT_PROXIMITY_HIDE_DELAY` 清空，切换到其他元素则立即生效。
- 落点：`arrow:update` 时各元素调用 `resolveAt(currentPoint, ARROW_DROP_PROXIMITY_RADIUS)`（同一点结果缓存共享），只有归属元素显示落点并上报 closing。
- `useDropArrow(element, { container: true })`（Frame）：内部空白不参与，只在距边框 ≤ 感应半径时命中，且不提供 `center` 连接点（悬停与落点都不提供；已有的中心连接箭头不受影响）。

## 六、吸附/参考线与能力系统

- **能力声明**：插件通过 `getCapabilities` 返回 `IElementCapabilities`，`CapabilityService` 查询：
  - `shouldParticipateInRefLines`：是否参与参考线显示/吸附。
  - `shouldElementSnap` & `getSnapCapability(type)`：吸附行为，支持 `SnapBehavior.RootOnly`（如 mind-node root）。
  - `shouldMoveWithChildren`：容器移动时是否携带子元素（Frame）。
- **吸附流程**：纯几何在 `utils/snap/SnapGeometry.ts`，会话在 `utils/snap/SnapManager.ts`（`board.snap`）。
  - 移动：DraggingState / Mind 根拖拽把运动包围盒（多选取并集）交给 `board.snap.move`，得到一次 `dx/dy` 后整体回放到全部运动元素。
  - 缩放：`board.snap.resize` 只吸附正在拖动的边；等比缩放只吸附主轴、另一维按比例回算；`axes` 可限定轴（固定高度元素只吸 x）。
  - 吸附点：x 取左/中/右，y 取上/中/下；每轴只取最近的偏移，阈值 `SNAP_THRESHOLD_PX / zoom`（8 屏幕像素）。
  - 等距（仅移动）：`SnapGaps` 先在候选中求相邻间距（每个候选只与该轴正方向、垂直方向有重叠的最近邻配对，按候选快照缓存）；运动包围盒可居中于间距内、或接在一对元素前/后复制间距。与对齐偏移一起比较取最近，相同时对齐优先。测距线只画吸附后真正等长的间距，并沿等长且首尾相连的间距扩展整条序列。
  - 参考线：只画吸附后真正重合的坐标，同坐标合并为一条线，跨度覆盖所有对齐点；`ReferenceLines` 直接订阅 `board.snap`。
  - 候选：首次调用时拍快照——视口内、参与参考线、排除运动元素及其子孙；视口变化时重拍。
  - 网格：网格可见时（`board.snap.setGridSize`）改为对网格取整，不画参考线，与对象吸附二选一。
  - 生命周期：交互结束调用 `board.snap.end()`；另有窗口级 pointerup/pointercancel/blur 兜底清空，参考线不会残留。
- **按键控制**：Alt 关闭吸附。

## 七、渲染管线与可见性过滤

- **BoardContent**：
  - viewBox = `minX/minY/width/height`（同步视口）。
  - 网格 `Grid`、箭头 Marker、元素分层（中心连接箭头/非中心箭头）、选区、参考线。
  - `board.renderVisibleElements` 递归渲染可见树（见 `filterElementsInViewport`，默认扩展 100px）。
  - MindNode 在渲染时过滤折叠方向子节点。
  - **简化渲染**：`simplifiedRenderZoomThreshold=0.3` 写入 `BoardStateContext`，子组件可降级（如隐藏复杂细节）。
- **分层**：箭头按是否“中心连接”拆分，避免遮挡；ReferenceLines 在最上层。

## 八、演示模式细节

- `PresentationManager` 管理 `sequences`，提供事件：`presentationModeChange/currentSequenceChange/currentFrameIndexChange`。
- 进入演示模式：`presentationManager.startPresentationMode(sequenceId)`，Board 进入只渲染当前帧元素的过滤模式。
- 过滤逻辑：`index.tsx` 中 `filteredChildren` 递归保留当前帧包含的元素（包含父链）。
- 控制 UI：`PresentationCreator`（创建/编辑帧）、`PresentationMode`（播放）、`StatusBar`（切换帧/删除）。

## 九、复制/粘贴/拖拽与外部资源

- **CopyPastePlugin**：克隆选中元素，剪切时先复制后删除；粘贴偏移位置避免重叠。
- **FileDragDropPlugin**：识别拖入文件类型并委派到对应插件（图片/视频/音频/白板），触发插入操作。
- **资源来源**：`whiteboardContentId` 通过 `board.setResourceSource` 注入，用于 ResourceUsageTracker 统计；删除元素时自动回收。

## 十、性能优化要点

- 视口过滤：仅渲染可视区域及少量扩展；尽量保持元素尺寸稳定减少 diff。
- 事件节流：指针移动 25ms 节流；避免在高频事件中做重 CPU 操作。
- 命中索引：`BoardUtil.getHitElements/getElementsInSelectArea` 使用空间索引（R-Tree）先粗筛，再由插件 `isHit/isElementSelected` 精判；元素变更通过 `board.getElementVersion()` 触发惰性失效与按需重建。
- 参考线：候选只取视口内元素并在会话内缓存，每帧只做一次运动包围盒与候选的比对。
- 历史/操作：大量操作时可临时关闭 `updateHistory` 或合并操作，以免 undo 栈膨胀。
- 渲染降级：放大缩小时可根据 `simplifiedRenderZoomThreshold` 在元素组件内降级显示。
- 大型 Mind/Frame：可选择关闭子元素参考线参与，或优化 `MindUtil/FrameUtil` 遍历。
- 命中基准：可运行 `pnpm --filter desktop bench:whiteboard-hit` 输出 DFS 与索引多轮耗时对比；支持 `HIT_BENCH_ELEMENTS/HIT_BENCH_QUERIES/HIT_BENCH_ROUNDS/HIT_BENCH_WARMUP_ROUNDS` 覆盖默认规模。

## 十一、扩展实践

### 11.1 新元素插件

1. 创建 `plugins/MyPlugin.tsx`，实现 IBoardPlugin；如为矩形类元素，可继承 CommonPlugin。
2. 实现 `render/isHit/getBounds/moveElement`，必要时 `getArrowBindPoint`。
3. 声明 `getCapabilities`（吸附/参考线/子元素移动等）。
4. 如需右键插入/替换，提供 `getContextMenu`，onSelect 中调用 `board.apply` 或触发弹窗事件。
5. 将插件实例注册到 `plugins/index.ts` 并在入口的插件列表中使用。

### 11.2 新菜单项/弹窗

1. 在插件 `getContextMenu` 返回菜单项（priority 决定顺序）。
2. 需要弹窗时，通过 `board.emit("context-menu:open-modal", payload)`，入口组件会根据 payload 打开相应选择器。
3. 弹窗回调中执行 `board.apply` 插入或更新元素。

### 11.3 扩展演示/视口

1. 在 `PresentationManager` 增加自动播放/动画时序，广播事件并触发 `change`。
2. 新视口操作可放入 `ViewPortTransforms`，再由 `ViewPortPlugin` 和 `useViewPortControls` 暴露。

## 十二、常见问题排查

- **吸附/参考线无效**：检查能力声明（`shouldElementSnap` / `shouldParticipateInRefLines`）、Alt 是否按下、是否开着网格（网格模式不画参考线）。
- **选区/删除无效**：演示模式、创建序列、或 `board.isEditingElements` 非空会阻断；确保插件 onKeyDown 未被阻止。
- **Undo/Redo 不正确**：确认操作是否通过 `Board.apply` 且 `metadata.hasChanges` 为 true；1 秒归并可能导致多步合并，可调节或临时禁用归并。
- **演示模式元素缺失**：帧数据未包含目标元素 id，或过滤逻辑未带上父链；查看 `index.tsx filteredChildren`。
- **资源未清理**：确保删除操作产生的 `metadata.removedElements` 包含资源信息，ResourceUsageTracker 才能回收。
- **性能瓶颈**：关注 `renderVisibleElements` 与 `filterElementsInViewport`，必要时减少 children 层级或增加 simplified 渲染分支。
