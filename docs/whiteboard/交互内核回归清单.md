# 白板交互内核（阶段 A）回归清单

## 架构变更概述

原"行为插件靠注册顺序 + `return false` 竞争指针事件"的分发方式已收编为内核级交互状态机（`src/components/WhiteBoard/interactions/`）：

```
Board（数据内核：Operation / undo / 事件总线；阶段 A 未改动，后续阶段参考线与可见性过滤已接入 capabilityService 能力查询）
└─ interactions/InteractionManager（手势唯一裁决与路由层）
   ├─ SelectingState    点选/框选（组合内嵌拖拽阶段）   ← 原 SelectPlugin 指针部分
   │   └─ DraggingState 拖拽移动、吸附、容器拖入/拖出    ← 原 MovePlugin 指针部分
   ├─ PanningState      右键拖拽平移 + 右键菜单触发      ← 原 ViewPortPlugin 指针部分
   ├─ KeyboardMoveState / ViewportMoveState（继承 ContinuousArrowMoveState）
   │                     方向键移动选中元素 / 平移视口    ← 原 MovePlugin + ViewPortPlugin 键盘部分
   └─ claimPointerGesture 声明的自定义手势
       └─ MindDragInteraction（思维导图拖拽）           ← 原 MindPlugin 的 return false 抢占
```

关键机制：

- **双轨过渡**：内核未接管的事件仍走原插件广播；广播被插件 `return false` 中断时内核同样不开新手势。
- **仲裁时序显式化**：pointerdown 广播前先询问命中元素插件的 `claimPointerGesture`（自定义手势）；广播后按 SelectingState → DraggingState → PanningState 顺序仲裁（原注册顺序的显式化，不再依赖插件数组顺序）。
- **消费语义**：手势状态的处理器返回 `true` 表示事件已被处理，Board 跳过插件广播（原 `return false` 的内核化替代）。
- **插件瘦身**：MovePlugin 已删除；SelectPlugin 仅保留键盘命令（mod+a / delete）；ViewPortPlugin 仅保留滚轮与缩放快捷键；MindPlugin 保留拖拽状态机并通过 `claimPointerGesture` 声明接管。

## 手动回归清单

阶段 A 为纯代码搬移（行为等价改造），以下场景需逐项人工验证：

### 拖拽与移动（DraggingState / SelectingState）

- [ ] 单选元素拖拽移动；多选拖拽移动；框选后拖拽
- [ ] 拖拽期间按住 Alt 关闭吸附；松开恢复吸附对齐参考线
- [ ] 拖拽元素进出 Frame：进入高亮（isChildMoveIn）、松手后成为子元素并触发 autoResize
- [ ] 拖拽元素进出 Column：插入指示（dropIndex）、拖拽预览位置、松手插入/移出并 relayout
- [ ] Column 内上下拖动重排序
- [ ] Frame 整体拖拽（子元素跟随）；多选中同时含 Frame 及其子元素时子元素不重复移动
- [ ] 拖拽结束后撤销（mod+z）可还原位置；重做（mod+shift+z）可恢复
- [ ] 点击已选中元素后拖拽，结束后选区恢复为拖拽的元素集合

### 点选与框选（SelectingState）

- [ ] 空白处点击清空选区；空白处按下拖动出现框选，框内元素被选中
- [ ] 点选元素选中；ctrl/cmd 点选增删多选；分组元素点选整组选中
- [ ] 点击选中分组的边界框拖拽可移动整组
- [ ] mod+a 全选；delete/backspace 删除选中

### 平移与缩放（PanningState / ViewPortPlugin）

- [ ] 右键按住拖动平移视口（超过 3px 阈值）
- [ ] 右键按下未移动松开：画布内弹出右键菜单、画布外不弹出
- [ ] 滚轮缩放（ctrl+滚轮以光标为中心）、触摸板双指平移
- [ ] mod+= / mod+- 缩放；mod+o 全览（有选中时全览选中元素）

### 键盘方向键（ContinuousArrowMoveState 派生）

- [ ] 有选中元素时方向键微移（按住持续移动，5px/步）
- [ ] 无选中元素时方向键平移视口
- [ ] 按住 alt 精确模式（1px/步）；松开 alt 恢复
- [ ] 元素编辑态（双击进入文本编辑）时方向键移动光标而不移动元素

### 思维导图（MindDragInteraction，claim 声明）

- [ ] 拖拽根节点整树平移；拖到另一棵导图旁出现吸附高亮，松手合并为子树（含左侧方向统一）
- [ ] 拖拽子节点出现预览与候选父节点连线高亮；同树换父、跨树换父、拖到空白成为独立导图
- [ ] 拖拽中按 Esc 取消并还原；拖出画布外松手取消
- [ ] 思维导图拖拽期间 `element:move(-end)` 事件正常（元素移动中状态如视频笔记等联动正常）
- [ ] 点击节点选中（含 ctrl 多选切换）；选中后方向键节点间导航、Tab 加子、
      Enter 加兄弟、mod+方向排序/换向、空格编辑；单选节点时 mod+z 撤销正常
