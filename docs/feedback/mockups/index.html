用户反馈 · 独立反馈窗口与管理后台

反馈表单放在一个独立的小窗口里，和快捷卡片窗口一样：单例、默认置顶、不阻塞主窗口。用户可以一边继续操作主窗口、复现问题、随时截图，一边写反馈。管理员在插件门户的工作台里查看和处理。传输与存储方案见 docs/feedback/README.md。

行为做法
打开单例：再次点击入口时聚焦已打开的窗口，草稿不丢。首次打开贴在主窗口右侧，之后记住位置和大小
置顶默认置顶，标题栏图钉可以切换。置顶时切回主窗口操作，反馈窗口也不会被盖住
截图「截取窗口」默认截主窗口，下拉可以选其他 Tau 窗口；截的是那个窗口自身的画面，不会截到反馈窗口，所以不用先隐藏。也可以用系统截图（⇧⌘4 / Win+Shift+S）后直接 ⌘V 粘贴
标注点缩略图上的「标注」，窗口原地加宽进入画布（框选 / 打码 / 撤销），完成后恢复原尺寸
关闭有内容时先确认是否丢弃；发送成功后在窗口里显示结果，可以关闭，也可以再写一条
配色：整个窗口用 surface 底，输入框、环境信息和窗口同色，只靠 line-1 细描边区分，不再使用比窗口更深的 page 底。
外观

1 · 入口

三个入口都打开（或聚焦）同一个反馈窗口：侧边栏底部「反馈」（和插件、设置放在一起，在 NAV_FOOTER 里加一项）、命令面板「发送反馈」、菜单栏「帮助 → 发送反馈…」。不做右下角常驻悬浮按钮。

3 · 截图来源与标注

「截取窗口」的下拉列出当前打开的 Tau 窗口，截的是所选窗口自身的画面（webContents.capturePage()），不受遮挡影响，也不需要屏幕录制权限。要截别的应用或整个屏幕，就用系统截图后粘贴。标注时窗口原地加宽到 880px，标完恢复原尺寸。

5 · 管理后台：插件门户工作台 › 用户反馈

沿用门户方案 A 的结构：统一顶栏 + 工作台侧栏，在「管理员」分组下加一项用户反馈。页面是列表 + 详情双栏：左边按状态筛选（新反馈 / 处理中 / 已解决 / 已忽略），右边是正文、截图（点开看大图）、环境信息、内部备注和处理操作。截图由 Worker 校验管理员会话后从私有 R2 读出，不暴露直链。
