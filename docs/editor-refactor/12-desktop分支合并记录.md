合并原则：保留 editor 的公开边界和功能包归属，将来源分支的新功能、界面及删除决策接到新位置；不恢复核心领域实现，不整侧覆盖解决冲突。完成后执行受影响类型、行为、构建与依赖门禁并创建合并提交。

## 实际合并决策

- 图片灯箱、裁剪几何/导出、图片/图集属性条及工具随 media 包归属；保留来源分支的新交互与样式，同时保留本分支的只读、陈旧异步目标、返回仲裁、Activity 隐藏释放和滚动锁保护。旧概览及网络地址 store/组件删除。
- 核心接入通用 notifier.prompt/PromptHost，移动端使用原分支 BottomSheet 宿主。媒体消费该服务，直接调用与迟到确认均检查只读/挂载状态；未恢复退役节点运行时处理。
- ElementMenu 只接目标元素、位置与关闭回调，由核心聚合已有菜单声明并经命令执行；扩展不能传低层条目或获取内部 Kit。真实图片“更多”菜单测试验证命令调用。
- 引用块新样式/嵌套规则、Tabs 新样式与跨实例拖拽隔离同时保留。引用样式 token 归 blockquote 包，未回流核心；新引用测试迁到所属包并显式安装扩展。
- 桌面旧大纲、旧闪卡和音频笔记视图按来源分支删除；保留新行详情、PortalScope、主题和页面协议。测试删除已退役的 Page.status 字段。
- Chat UI 保持当前包归属，吸收来源分支 Tailwind/普通 CSS 改造；删除失效 Less 依赖，保留数学渲染和单一工具登记。antd 改为绝对禁止并覆盖 editor-extensions/examples。
- ER-020 编号冲突中的宿主输入框决策记为 ER-049，已有 P9 类型/API 决策仍为 ER-020。
- 移动图片设置测试按来源分支新标签“直角/圆角 8/12/16、卡片/轻抬/浮起”更新，仍验证持久值和旧布尔归一。数据库退役测试中的 Markdown 黑名单断言按 ER-047 删除，数据库迁移测试保留；通用 Markdown 的外部类型认领由 directive-ownership 测试覆盖。
- 桌面全量初跑 4600 例通过，性能阈值在并发构建下 3.177 秒超出 3 秒；停止并发负载后原用例 0.447 秒通过，未放宽阈值或修改算法。

依赖锁文件由 pnpm 合并并按最终 manifest 同步。Schema build/parity 通过（63 表、103 索引）；没有操作个人数据库。视觉/实机仍由用户验收，已有 React act/行内图 DOM 与大分块告警保留。
