# 异步写入入口与提交守卫

基线：607637823。范围为编辑器媒体上传、裁剪、剪切和输入确认；不引入命令事务、自动重试、资源回滚或插件生命周期框架。

## 写入入口矩阵

所有操作均绑定发起时的编辑会话；只读、Activity 隐藏、卸载、文档换源和整体内容重设使旧会话永久失效。恢复后只允许新操作提交。目标允许随结构编辑移动，删除再插入同类型或同 UUID 不视为原目标。

| 入口                  | 目标与冲突条件                                                           | 成功写入                                           | 失败与取消                                                                 |
| --------------------- | ------------------------------------------------------------------------ | -------------------------------------------------- | -------------------------------------------------------------------------- |
| 本地媒体选择器        | 打开选择器时固定目标或段落落点；上传时捕获资源服务、原地址与图片裁剪状态 | 仅更新目标的资源字段，保留期间修改的标题/说明/布局 | 既有空媒体失败保留；新建占位失败补段落；失效不写文档                       |
| 图片/音视频拖放、粘贴 | 批次开始时创建全部占位并捕获全部目标；不在前一文件返回后重新认领后续目标 | 回填对应占位，选区移动不改变目标                   | 图片保留失败占位；音视频粘贴失败补段落、拖放失败保留；取消不再启动后续上传 |
| 替换图片              | 原地址、预览地址和裁剪参数不变；允许说明、对齐、宽度变化                 | 更新地址并清除原图尺寸/裁剪参数                    | 同目标在途上传/裁剪互斥；失效静默丢弃，真实失败提示                        |
| 裁剪图片              | 打开裁剪器时捕获原图与会话；确认时获取该目标的上传占用                   | 更新裁剪参数、预览地址和尺寸                       | 关闭/隐藏裁剪器使旧导出及上传无效；真实上传失败可在原会话重试              |
| 剪切块                | 路径跟踪原块，完整节点快照必须与实际复制内容一致                         | 剪贴板成功后删除原块                               | 复制失败或内容变化不删除；移动仍可剪切                                     |
| 图片替代文本输入      | 原图地址与开始时的 alt 不变；允许布局和说明变化                          | 仅更新 alt                                         | 取消、目标变化或字段冲突不写入                                             |
| 网络媒体地址输入      | 固定打开输入框时的段落及折叠选区，用引用跟踪偏移                         | 在原落点插入                                       | 无有效落点不打开；落点删除/转换、请求取消不追随新光标                      |
| 行内图片上传/链接输入 | 上传或打开输入会话时捕获原行内节点，拒绝通过 UUID 全树搜索认领新节点     | 写入原节点地址                                     | 关闭、只读、隐藏或节点失效丢弃结果                                         |
| 图集设置内上传        | 只更新组件草稿，不直接写 Slate                                           | 用户确认时走既有同步目标校验                       | 本轮不把草稿编辑伪装成异步文档提交                                         |

## 公共边界

- 核心提供会话失效、PathRef/RangeRef 跟踪、同步提交与释放；业务提供 accept 判断，不向核心加入媒体字段名单。
- commit 回调必须同步返回 undefined，真正的异常向外传播，不提供回滚保证。正常失效返回 discarded 与原因。
- 会话、取消信号与声明服务的更换立即废弃操作；目标和业务字段在 check/commit 时求值，不订阅全树变更。check 可能触发取消和释放，不能放入要求纯判断的表单 validate。
- `<Editor>` 自动管理会话；纯 Slate/headless 宿主没有 React 生命周期，由调用方传入 signal 表达生命周期。
- 媒体运行时管理同目标在途操作和忙态，不再把本次上传的纯 UI 状态写入文档。上传服务发生替换时拒绝提交，无关主题派生不取消上传。
- 资源上传接口目前不保证支持网络中止；取消承诺停止后续启动和文档提交，不自动删除已上传资源。

主要代码入口：核心 `packages/editor/src/api/submission.ts` 与 `kit/submissionScope.ts`；媒体 `utils/mediaSubmission.ts`、`utils/uploadMedia.ts`、`utils/ingestMedia.ts`；剪切 `packages/editor/src/menu/defaultMenu.tsx`；输入 `services/editorNotifier.ts` 与媒体 `utils/mediaInsert.ts`。宿主自定义 MediaInsertSource/MediaAction 的内部异步业务不在本轮迁移范围，仍由宿主负责；没有据此宣称全仓异步写入已收口。

## 验证矩阵

覆盖移动/替换、无关字段与目标字段变化、只读后恢复、隐藏后恢复、同谱系换源、服务替换、多个实例、重复提交、异常传播、引用释放和网络输入落点漂移。既有批量上传失败顺序、剪切内容保真与独立扩展示例继续保留。
