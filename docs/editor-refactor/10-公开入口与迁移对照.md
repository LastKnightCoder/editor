# 公开入口与迁移对照

当前公开入口由 packages/editor/package.json 的 exports 限定；原 src 别名与通配出口已删除，宿主和功能扩展不再通过私有路径访问实现。

| 入口                      | 使用方与职责                                                             |
| ------------------------- | ------------------------------------------------------------------------ |
| @tau/editor               | 宿主：Editor、Kit/文档源、服务装配、defaultMenuExtension 与共用工具/类型 |
| @tau/editor/api           | 扩展：元素/命令/菜单/标记/复制等声明、模型增强、服务读取与通用编辑能力   |
| @tau/editor/api/services  | 纯服务契约入口                                                           |
| @tau/editor/api/paragraph | 段落工厂与识别入口                                                       |
| @tau/editor/markdown      | paragraphCodec 与 editorMarkdownCodecs；领域 codec 从各扩展包引入        |
| @tau/editor/toolbar       | 工具条分组与浮层位置算法、对应类型；Node 运行时可加载                    |

渲染用的 ToolbarSubmenu/useToolbarState/EditorTooltip 仍从 api 引入；toolbar 子入口只收口共用布局计算，不暴露内部 store、Provider 或菜单回调。

## 旧入口迁移

| 旧用法                                                                         | 当前用法                                                                     |
| ------------------------------------------------------------------------------ | ---------------------------------------------------------------------------- |
| @tau/editor/src                                                                | @tau/editor                                                                  |
| src/types/custom-element 的 ExternalElementMap / ExternalInlineElementMap 增强 | @tau/editor/api 的 ExtensionElementMap / ExtensionInlineElementMap           |
| IExtensionBaseProps                                                            | ElementRenderProps                                                           |
| 私有 useIsLastElement                                                          | api 的同名导出                                                               |
| 私有 floatingPosition / compactLayout                                          | @tau/editor/toolbar                                                          |
| 私有 FloatingSubmenu                                                           | api 的 ToolbarSubmenu                                                        |
| 私有段落 codec                                                                 | @tau/editor/markdown 的 paragraphCodec                                       |
| 核心 EditorContextMenu / ContextMenuItem / BuildMenuParams                     | 节点菜单通过 EditorExtension.menu/menuFor 引用命令；普通 UI 菜单使用 @tau/ui |

模型登记只影响 TypeScript；运行时仍须通过 defineElement/defineExtension 创建声明并由宿主显式安装到 Kit。所有跨端功能在 editor-extensions，宿主专属扩展使用相同公开增强入口。核心保留 paragraph/text，不允许扩展替换基础段落。

程序化调用为 editor.commands.execute(id, payload, element, path)，命令 run 接收组合后的 context。只读、陈旧节点与异步目标仍须按既有协议验证，不靠调用者记住私有路径或内部 store。

纯入口与渲染入口分开：主进程/脚本使用 markdown 或各扩展的纯子入口，不从 UI 根入口取得 codec。未知数据与旧端的具体限制见 ER-030/033；完整参考示例见 [editor-reminder](../../examples/editor-reminder/README.md)。

仓库内必要的低层测试夹具仍可用显式相对路径访问核心实现；它们不构成公开 API，也不为此恢复包通配出口。护栏排除测试文件/test-setup，生产代码的私有模块增强、旧包路径及相对 src 引用均被拒绝。

核心 check 包含源码、公共入口和测试，未通过排除测试、降低检查选项或开放字符串索引来清零诊断。当前仍沿用原 strict:false；新扩展及示例按各自配置验证，不能把“检查通过”写成全仓严格模式已完成。
