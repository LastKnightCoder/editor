## 踩坑

### desktop 对 `@tau/themes` 的两处别名指向不一致（P1 前已存在）

- 现象：`apps/desktop/tsconfig.json` 把 `@tau/themes` 指向 `packages/themes/src`，`vite.config.mts` 却指向 `packages/themes`。
- 原因：历史上只用 `@tau/themes/light.less` 这类深路径，两边刚好都能解析。
- 解法：P1 删除手写别名，改为 workspace 依赖 + package `exports`。未验证：保留别名时 `@tau/themes/react` 这类子路径在 tsc 和 vite 下能否一致解析；直接删掉别名，就不用去验证了。
