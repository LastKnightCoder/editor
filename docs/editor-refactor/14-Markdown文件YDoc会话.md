# Markdown 文件 Y.Doc 会话

范围：桌面 Markdown 文件视图。每个路径实例使用一个本地内存 Y.Doc；文件仍以 Markdown 保存，不创建数据库正文记录、协作房间或后台同步连接。

## 单一更新通道

| 输入                   | 文档操作                                                  | 历史                       |
| ---------------------- | --------------------------------------------------------- | -------------------------- |
| 首次读取、外部版本载入 | 解析 Markdown，增量对账到 Y.XmlText，更新原文与规范化缓存 | external，不进入用户撤销   |
| 富文本编辑             | Slate/Yjs 绑定写正文                                      | 本地用户历史               |
| 源码输入               | 原文及解析正文在同一 Yjs 事务更新                         | 用户历史，原文缓存同时撤销 |
| 保存                   | 当前正文与规范化缓存相同则返回原文，否则序列化正文        | 不修改文档                 |

`MarkdownFileView` 不再拥有另一份可写的 content，也不调用 setEditorValue。React 的内容只是 Y.Doc 投影，用于字数、大纲和显示。CodeMirror 原生 undo/redo 委托文档，两个视图常驻，切换模式前后隔开撤销分组。

源码模式通过 `binding.wrap` 内的 Activity 停驻 Slate/Editable 视图效果，Editor 自身的文档连接持续运行。恢复富文本时沿用实例并显示最新投影，不在隐藏期间运行预览编译效果。

## 增量与身份

`editor-collab/local` 共用现有 Slate/Yjs 绑定底层，不依赖房间或产品迁移。序列对账以完整语义相同的节点为锚点；差异段内同型节点更新属性与子树，删除已不存在的属性，文本按字符差分更新。类型变化、真正新增/删除的节点使用结构操作，重排不承诺保留被移动项的 Yjs 身份。

Markdown 宿主用 codec 输出作为语义键，未在 Markdown 中表达的宽度、编译缓存等不导致未改块重建。修改图片或代码块时保留既有 UUID，避免重新导入生成随机 UUID 而重建控制器。未知节点与文本字段走原有 codec，不引入退役黑名单。

## 文件与生命周期

- `useTextFileSession` 保留“有未保存内容时提示冲突”的规则；Yjs 不能把任意外部文件快照当作携带 CRDT 身份的远端更新自动合并。
- 文件路径由页面 key 隔离。组件退出先 flush，再销毁 Y.Doc 与 UndoManager；StrictMode 的重复挂载不会提前销毁会话。
- 同一文件的外部更新不换绑定，异步提交按实际节点变化判断；文件切换和只读切换仍结束旧编辑会话。
- 外部读取按请求版本和保存版本核验；逆序返回、关闭后返回或读取期间已开始保存的旧结果全部丢弃。
- Yjs 无法表达的属性不能悄悄删除。转换失败时原文仍存在 Y.Doc，富文本隐藏，源码可继续修改、保存或另存为。

## 验证要求

验证未编辑不写文件、外部更新无回声保存、文件冲突两种选择、关闭后迟到事件、源码与富文本共用撤销、模式切换保留编辑器与未改块身份，以及未知字段和转换失败的原文保留。类型/行为/构建验证由 Agent 完成，视觉与实机由用户验收。
