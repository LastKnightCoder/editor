# 编辑器架构文档 · 总览

> 本文档是编辑器架构系列文档的索引入口。编辑器核心包位于 `packages/editor`（`@tau/editor`），基于 Slate.js 构建，采用"内核 + 扩展 + 服务注入"的分层架构：44 个通用内置扩展随内核分发，宿主通过 `EditorProvider` 统一注入服务、配置和外部扩展。

快速导航：

- 想快速了解全貌：先读 [编辑器架构](./编辑器架构.md)（浓缩总览）
- 想深入某个主题：按下表进入对应章节
- 想查完整实现细节：读 [编辑器技术文档](./编辑器技术文档.md)（3800+ 行完整版）
