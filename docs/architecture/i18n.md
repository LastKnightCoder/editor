# 国际化

## 职责与依赖

`@tau/i18n` 提供 `defineI18n`、本地 i18next 运行时、可序列化消息引用及 React Provider / Hook。应用与插件分别维护词典；运行时不依赖应用设置，不提供机器翻译或线上资源服务。包接口见 [@tau/i18n](/packages/i18n/README.md)。

`@tau/shared/language` 是 Tau 支持语言与偏好解析的单一来源。设置的 `language` 为 `system`、`zh-CN`、`zh-TW` 或 `en-US`；缺失和无效值归一化为中文。语言是设备应用偏好，与资料库身份及正文语言独立。中文变体按文字体系匹配：`zh-TW`、`zh-HK`、`zh-MO` 与 `zh-Hant` 匹配繁体中文词典 `zh-TW`，简体中文匹配 `zh-CN`。

桌面 `app/i18n/connect.ts` 从设置 store 与系统语言更新 `desktopLocaleSource`，同时更新文档 lang 和 dayjs 的显示语言；设置持久化、窗口广播与辅助窗口首次快照沿既有设置协议。移动 `services/i18n.ts` 从 `mobileSettingsBridge` 更新同类语言源。应用的 React 绑定显式指定宿主实例，避免嵌套插件的 Provider 改变宿主组件文案。

React Hook 返回的 t/resolve 引用随语言变化更新，使依赖翻译函数的 useMemo 失效；既有回调中的函数仍在调用时读取当前语言。

导航与设置清单在读取标签时解析词典，不在模块求值时固化译文。订阅语言的视图刷新，命令面板的命令列表和最近访问投影随语言失效。Page 协议只保存字符串或消息引用，导航核心不读取词典，标题栏在展示边界解析。

## 公共控件与功能词典

`@tau/ui` 的 Dialog、ConfirmDialog、Select、Input、Tag 与 YearHeatmap 从所在运行时读取语言，使用 UI 包 `src/locales/` 下的简体、繁体与英文 JSON 词典。`useI18nRuntime()` 允许适配层读取可选的上下文；独立使用 UI 而没有 Provider 时，使用本包只读中文默认运行时。显式传入的文案保持优先，语言切换不重建控件或清除确认输入。

外观设置的词典就近位于 `features/settings/locales/appearance.*.json`，`useAppearanceI18n` 显式绑定桌面运行时。选项标签、字体默认值提示与无障碍名称在渲染时翻译，字体名称、主题身份和持久化设置值保持原样。中文字体的预览继续展示汉字，繁体界面展示繁体字形。

桌面卡片库与手机卡片入口分别使用 `features/cards/locales/` 的词典；桌面共享标签组件维护 `components/AddTag/locales/`，标签管理接收稳定的 `card` / `article` 身份，完整句子与数量形式由组件词典负责。卡片时间分组的数据层只返回分组键与卡片，展示层翻译组名，虚拟列表身份不受语言影响。表格筛选操作符及已保存的视图名称保持原值；导出文件的原有兜底标题与新建业务记录的名称不随界面语言改写。

文章模块在两端各自维护 `features/articles/locales/`；文章速切器、菜单和月份标签订阅当前语言，不以语言作为查询键、虚拟列表键或编辑器重挂载键。桌面共享排布菜单维护 `features/shared/list/locales/`，日期与紧凑数字格式化位于同目录的 `format.ts`，由卡片与文章展示层共同消费；手机卡片与文章的时间格式化共用 `utils/contentTime.ts`，相对时间模板由业务词典注入。剪贴板操作的固定反馈归 `utils/locales/copy.*.json`，只翻译反馈，不改变 Markdown 或 HTML 输出。

两端日记各自维护 `features/diary/locales/`，日期、星期、月份与数量在展示时生成。桌面日期快捷范围只保留稳定 key 与日期区间，标签颜色只保留语义色值。手机日记进入正文详情的 `diaryDate` 参数为 `{ mode, baseDate }`；首页、快捷创建、搜索、日记流与插件导航均传原始类型/日期，详情在当前语言下派生标题与副标题，月份分组只返回月份键与条目。日记正文、标签、周/月日期键及查询和片段身份独立于语言，发布、串行标签写入与延迟删除撤销不因语言变化重建。

项目模块在两端分别维护 `features/projects/locales/`。文档树添加菜单与节点菜单的纯构建器显式接收翻译函数，缓存依赖当前翻译函数；菜单键、节点类型、关联目标、展开状态、拖拽与持久化默认名称独立于展示语言。手机节点元信息只存类型键、图标与颜色，展示时解析类型名；引用来源查询保存原始标题，缺标题提示在渲染时翻译。

桌面 `features/shared/cockpit/locales/` 维护公共列表与表单文案，`CockpitCopy` 的 `entityCount` / `metricCount` 接收真实数量与展示插值，由所属模块生成完整数量消息，`itemTitle` 提供空标题占位。项目已提供三语资源；数据库与 Notebook 的模块文案按各自批次处理，公共控件可跟随语言。公共改标题弹层维护 `components/EditTitleModal/locales/`，显式传入文案优先，语言不参与草稿初始化或编辑会话键。

两端搜索分别维护 `features/search/locales/`。桌面缓存命令与内容类型使用动态标签，固定宿主命令把三语标题作为检索别名，导航标签与页面引用仍由应用词典负责；身份、执行动作与访问记录只用稳定 key。`scope-prefixes.json` / `capture-prefixes.json` 定义跨语言的输入语法，独立于当前界面语言，保留已有简体写法并接受繁体和英文，正文查询不自动翻译。

搜索查询缓存保留每路失败的来源代码与原始原因，文档待办保留 completed 布尔值；界面格式化状态和提示，语言不进入查询键，不重复请求。警告按原始问题身份通知，语言变化不重放警告。面板按结果键维护选择和滚动，标签变化不改变结果身份；手机搜索的工作区修订失效与分页序号仲裁保留原规则，语言本身不清空结果。插件提供的名称/类型文案与原始内容保持提供方所有权。

快速添加的展示归 `features/shared/quick-add/`：三语 JSON 提供完整提示，纯格式化函数接收解析结果、now 与翻译接口，日期分桶与周期排序沿原业务口径；格式化不修改解析结果。待办解析器只返回数据，命令面板、待办输入条和日程快速添加共用预览；自然语言解析词表独立于界面语言，未识别文本保留为标题。卡片新建与快捷窗口启动反馈归卡片词典，失败状态只保留原始原因，界面语言不触发数据库连接或新建。

手机新建菜单词典归 `components/quick-create/`，动作键独立于标签；速记页及控制器反馈归卡片词典，长按收集词典归 `features/speechInput/locales/capture.*.json`。语言不进入草稿读取、会话修订、自动保存或录音生命周期依赖；异步动作反馈在发生时解析。识别文字及语音输入配置保持原值，原始服务错误和设置引导判定沿现有协议，捕获入口的未配置提示由自身词典提供。

手机编辑控件维护 `features/cards/editorToolbar/locales/`，工具栏、样式/插入/媒体面板及内容引用的展示绑定手机运行时。缓存的内置菜单通过动态标签读取文案，插入项用稳定 kind/group 标识并保留三语搜索别名；语言不参与编辑器、选区或引用请求的会话身份。颜色、渐变、代码语言值、命令、引用目标和持久化兜底标题保持原值，类型与日期只在展示层格式化。

手机编辑器提示服务维护 `services/locales/editor-notifier.*.json` 的上传反馈；请求仓库保留选项属性描述符，使动态标题不会在排队时变为字符串快照。提示宿主订阅手机语言，草稿与请求按原对象身份管理，语言变化不结算请求或重置输入；显式字符串仍按调用方原文显示。

`@tau/editor` 的链接弹层、文字样式工具栏、调色/下划线面板、批注与行内公式维护包内 `src/locales/`，从现有 `I18nRuntimeProvider` 继承运行时，无 Provider 时使用包内只读中文默认值；不读取桌面或手机设置，不改变公共扩展接口。紧凑分组只保存消息 key，在分组组件内订阅语言，配置数组与组件类型不随语言重建。颜色、渐变与线型展示按原始身份查词，正文标记和最近使用存储值不变；纯色板与导出仍不依赖 React 或翻译运行时。批注日期的纯格式化接收语言与相对时间模板，线程身份与草稿独立于译文；行内公式沿用原编辑会话和实时写入协议。语言变化保留链接输入、打开的面板及编辑器实例，链接确认操作才写入正文；内置块插入、通用块操作和转换菜单通过编辑器实例关联的继承运行时解析，不以 locale 重建 kit 或编辑器。块条目与菜单标题保持动态读取，菜单条件、目标与参数仍在打开时固定；第三方标题函数仍只在打开时求值一次。分组使用显式 id/group 配置，规则见 [编辑器包](/packages/editor/README.md#块插入分组)，不推断中文标题。代码/图表、图片、音视频及网页书签的专用界面使用包内 `code.*.json`、`image.*.json`、`av.*.json`，通用媒体与提示资源归 `common.*.json`。字符串 title getter 保留读取语义，普通标题函数的打开时求值约定不变。

默认编辑器提示请求保留选项属性描述符，内部附带发起者运行时；同页队首宿主订阅该运行时，避免使用其他编辑器的语言。语言变化只重算展示与纯校验，不替换请求或草稿。输入框退出动画使用最后一次展示文本，避免源运行时关闭后继续求值。网页插入与书签编辑的独立 React root 显式继承所属编辑器运行时。

`@tau/editor-source-view` 维护自身 JSON 词典，源码页与预览控件继承 Provider；预览动作对象通过 getter 读取类型标题，不因语言重建或提交。源码、绑定、光标、预览 DOM 与撤销会话保持原身份。共享 `MediaPlayer` 在 `@tau/shared` 内维护词典，继承可选运行时并提供独立中文默认值；播放反馈保存消息 key/参数和反馈身份，渲染时翻译，语言不重放反馈计时、切换资源或更改播放位置/速率。

桌面实体选择器维护 `components/EntityPicker/locales/`，元信息保留稳定 kind 与图标，类型标签读取时翻译。选择器仅在展示时格式化日期与数量，语言不进入查询键、筛选、草稿或已选项身份；白板插入记录使用的原始时间描述仍保持写入规则。桌面内容引用维护 `editor-extensions/content-link/locales/`，搜索、预览与动作反馈绑定宿主运行时；用户标题/正文和插件类型外观归提供方，缺标题和元信息只在展示时生成。

桌面通用导入/导出界面分别维护 `features/transfer/locales/import.*.json`、`export.*.json`，单篇图片/PDF/EPUB 维护 `components/ContentExportModal/locales/`。传输反馈与共享勾选树使用 `services/locales/content-transfer.*.json`；单篇导入按稳定 target 生成完整数量句，不传入语言相关量词。已知导出错误附带稳定 code，保留原 Error.message，展示层解释 code；历史 warnings、来源文件名和解析诊断保持原文。

导出范围与类型只保存原枚举，目录、文件名和正文仍用原数据；范围预览按稳定根 id 投影标签，UI 语言不进入资源打包、frontmatter、PNG 内日期或 EPUB 的语言/作者字段。勾选树展开、弹层草稿与格式选择、预览快照和异步任务均独立于译文。独立编辑与 Markdown 窗口的复制/导出入口共用传输词典。

手机外部 Markdown 导入维护 `features/markdownImport/locales/`，IncomingFileHost 的 single-flight 与事件订阅不依赖语言；预览查询、文档和编辑器身份只由原始 Markdown 与插件修订决定。缺标题只翻译展示占位，写入名称保留原有规则。原生接收失败的已知错误由 `services/locales/errors.*.json` 按原错误码映射；未迁移错误仍保持原映射与原始原因，语言不改变校验或错误码。

视频笔记电子书使用 `components/VideoNotePanel/locales/ebook.*.json`。弹窗步骤、风格说明、封面候选、失败格式与续导出提示在展示时翻译，状态保留原始来源/序号/格式与 resolver；重写流、手工草稿和编辑会话不因语言重建。模型的中文提示词与输出、videoTitle 数据兜底、元数据语言/作者/文件名和记忆键独立于界面语言；错误反馈按原问题身份通知，不因换语重放。

待办两端分别维护 `features/todos/locales/` 与 `features/todo/locales/`；系统分组/类型/议程/打卡状态按稳定类型生成标签，用户项目名、任务标题、描述和文档内容保持原文。日期计算/分类仍在纯 `utils/dayWords.ts`，显示在 `utils/date-format.ts` 显式接收 locale；模型不再转出展示函数。日期胶囊按类别判断是否附注，不比较译文，原始 Slate 文本不替换；提醒紧凑模式不裁剪“前”等自然语言。

公共日期控件使用 `@tau/ui` 本包的 datepicker JSON，继承可选运行时、独立使用默认中文。值解析保持 ISO/本地时区与分钟协议；范围草稿比较原始端点，语言不改变周一起始、网格/步长或提交/取消规则。共享提醒由 `packages/shared/locales/reminders.*.json` 维护，纯 formatter 显式接收 locale/t/compact，默认中文与原输出一致；预设只保留 offset，菜单展示时生成标签。纯 i18n 入口使用显式 .ts 相对引用，提醒 JSON 带导入属性，可由 Node 原生类型擦除加载而不依赖 DOM 或应用设置。

日程两端分别维护 `features/schedule/locales/` 和 `features/calendar/locales/`，固定文案与日期/时长显示从数据算法分开。过滤、勾选、草稿、延迟删除/撤销与查询身份不随语言重建；已知即时错误使用稳定 code，原始诊断保留。日历/分组/事件名称是数据，只有原有业务已经识别的来源标记翻译；不能把同名或 `isInSystemGroup` 当创建来源证明并猜译名称。共享 GroupDialog 按实体 id 和原始字段重置基线，不因对象新引用或称呼/占位的语言变化清空草稿，颜色仍提交原始枚举。

番茄专注两端各维护 `features/pomodoro/locales/`，桌面展示 formatter 显式接收 locale/t，计时与查询模块不读翻译。预设候选缓存保存 phase/range 与原始名称，时间/模式/统计在展示时生成；主界面、小窗和沉浸窗继承同一宿主语言。语言不重启计时、不重放声音或完成反馈，不改变会话/历史/预设数据与日历协议名称。原生和定时通知载荷由通知模块单独管理。

编辑器核心的占位、复制/拖放反馈与默认无障碍名称由 `core.*.json` 维护。失败块的叶子订阅运行时，语言更新不重试扩展或再次报告错误。源码字段失败保留 `TextFieldInputFailure` 的稳定 code/原始 cause，在源码页、行内公式和 front matter 展示时按 locale 格式化；输入绑定与保留草稿不以语言为依赖。纯 formatter 可由 Node 加载，旧错误回调第一参数维持默认中文，第二参数承载结构化失败。

闪卡两端分别维护 `features/flashcards/locales/`、`features/flashcard/locales/`，类型/等级/颜色以稳定枚举投影标签，日期、数量与间隔在展示时格式化。解析/校验失败保留原始诊断与语义消息身份，公共判答只翻译宿主已知错误；手机插件制卡入口维护自己的界面词典，不处理插件或 AI 的产物语言。语言不改变复习队列、翻面/评分/提交锁、会话时间点、题干/答案/标签草稿、默认卡组名与 FSRS 数据。

PDF 词典归 `features/pdfs/locales/`，展示 formatter 与模型/阅读引擎分离。目录缺标题在界面投影，原书签默认名、引文序列化与 AI 提示保持原值；切换语言不重读文件、重建索引/引擎或提交批注。共享阅读标题栏、对话选择器、项目插入弹层与字幕空态使用 `components/reading-locales/`，按桌面宿主语言更新；原始会话/章节/笔记标题不翻译，打开状态、筛选、插入位置与查询保持。漫步只在桌面存在生产入口，词典归 `features/walk/locales/`；足迹、已见记录、偏好与抽取行为不随语言变化。

Notebook 词典归 `features/vibe-learning/locales/`；生成应用/文章风格以稳定 kind/id 投影界面标签，工具用的名称/描述、schema、提示词与名称匹配读取独立的原语义字段。内置任务阶段保留 phase key 与 builtin 来源，插件阶段保留原始文本和 plugin 来源；只在展示时翻译内置状态。模板常量、默认落库名、测验/产物内容与文件名不变；语言不重开资料请求、清空生成配置/测验答案或重复执行插件生成回调。

公共消息 UI 由 `packages/chat-ui/src/locales/message.*.json` 维护，继承可选运行时，独立使用默认中文。耗时/状态 formatter 接收显式 locale；思考计时只依赖执行状态，错误边界只更新叶子提示，不因语言重试已失败的渲染器。展开/复制状态、原始推理/代码、引用内容与工具输入输出保留；容器/审批/提问/预览专属界面不混入该消息词典。

图片生成设置分别使用桌面 `sections/locales/image-generation.*.json` 和手机 `settings/images/locales/`。手机共享配置草稿保留原始失败 cause 与必填字段 key，展示时按当前语言和字段标签生成错误；可选 `errorText` 供业务解释自己的已知错误。保存状态、离开确认与成功反馈不存译文，语言不重跑 beforeSave、提交/测试服务或清空草稿；插件自带的 schema 文本和未知诊断由原提供方维护。

桌面缓存管理词典归 `settings/cache/locales/`，未命名预览保留语义身份，异步反馈完成时读当前语言。来源过滤/勾选和视频 DOM/src/播放状态不随语言重建；缓存桶、删除、设置写入与剪藏翻译的目标语言保持原语义。

桌面插件中心词典归 `features/plugins/locales/`，model 只保留数据/合并与版本动作，固定标签、日期与状态从 display 模块投影。版本说明保存稳定结构，manifest 名称/描述、版本日志与诊断原文不翻译；语言不重开安装/更新/卸载或改变搜索、确认与风险偏好。

上传/存储两端词典分别归 `settings/storage/locales/`，手机同样归 `settings/storage/locales/`，纯相对时间显示集中到 storage/format，旧 syncState 显示导出清零退役。上传记录保留原错误 code/message 与已有 kind，展示边界解释语义；历史记录原样读取，不回写译文，近期失败的一次消费与过期窗口不变。插件声明的字段/分组/选项名称保持提供方所有权，表单、远程选项请求与保存不随语言重置。手机设置入口词典归 `settings/locales/shell.*.json`，单选面板与功能宫格按值/key 保留身份；深浅标签用于反馈提交的原始元数据仍保留，界面按稳定值显示。

大语言模型设置分别使用桌面 `sections/locales/llm.*.json` 与手机 `settings/ai/locales/`，设置 UI 的模型/服务商选择与用量展示显式接收语言，数据聚合/范围和查询键保持独立。手机 LLM_FEATURES 只保存功能 key，旧 label/desc 显示消费者清零后删除；工具权限模式原始数据仍由未迁移对话工作台消费，设置按稳定 mode 投影。语言不重新测连接、保存配置、重开用量请求或重置模型/功能分配草稿。

手机插件中心词典归 `features/plugins/locales/`，管理器的自建阻塞原因保存 reasonCode/errorCode，unknown 原因保持原文。安装/更新冻结清单保存原 permission id 与新申请标记，在展示时按稳定 id 投影；原 manifest/版本/发行 ID、URL/校验值与安装阶段不变。语言不重装/取消、重读清单、重启插件或丢弃开发 JSON 草稿。

桌面嵌入设置使用 `sections/locales/embedding.*.json`，模型选择、激活/删除确认与本地下载状态只做显示投影。已有探测/订阅/下载与当前模型提交维持原时序，测试样本文本和插件/服务原始名称不翻译；手机没有对应嵌入设置入口。

数据库同步进度在展示时调用纯 `@tau/shared/sync-progress` 的 `formatDatabaseSyncStatus(status, locale)`，不把语言送入传输流程；跨端数值/阶段协议见[宿主分块同步](/docs/architecture/storage-sync.md#分块传输与重试)。同步两端词典归 `settings/sync/locales/`，自动同步窗口与命令反馈各归其模块；资源/云端失败只对已知 code 作解释，保留原始诊断与数值。手机客户端捕获的资源失败保存 errorCode/errorMessage，不缓存译文；无码的原生和逐文件诊断保持原文。服务切换、覆盖确认、长按时序、建库草稿、清单/过滤和任务身份不随语言改变。

插件权限/数据动作/实体选择/页面与提供方设置控件分别归两端 `features/plugins/locales/controls.*.json`。固定文案按稳定权限/实体/动作 ID 投影，原 manifest 名称、标题、插件显式文案与未知诊断保持提供者所有权。表单分组的 React key 使用全部原始字段 key 序列，既不读标题，也不随条件可见性变化；语言不重建输入、重载远程选项或重复操作。

设置草稿控制器不制造缺省保存按钮文案，saveLabel 省略时由宿主显示；保存可返回普通字符串或带惰性 message 的 SettingsDraftFeedback。反馈 getter 在展示时由原所属域解释当前词典，不跨词典解析无归属的 ref。失败保留原 cause/诊断；展示语言变化不清空 saved/failed，只有重新变脏的状态转换才让位给编辑反馈。动态反馈不重跑保存/测试，纯控制器不依赖应用语言设置。辅助栏订阅宿主语言，元信息 getter、无障碍名、宽度与失败恢复随之更新，保活与错误边界身份不变。

语音输入设置两端分别使用桌面 `sections/locales/voice.*.json`、手机 `settings/speech/locales/`，共享转录字段与本次配置弹层使用 `VideoNotePanel/locales/transcription.*.json`。组件自产的准备/失败状态保留语义键，原服务下载进度、识别语言/设备/引擎/模型参数和用户整理要求保持原值；语言不重建探测/下载/订阅、重放选择或提前启动任务。

关于/更新两端分别维护 `settings/about/locales/`，桌面更新日志单独维护 `features/release-notes/locales/`。默认标题从版本数据展示时生成，不在 store 缓存译文；原始错误保留 code/diagnostic/cause，语言不重启启动检查、下载或安装。事件型通知在创建时按当前语言生成字符串载荷，已发送通知的正文/动作保持该快照，不因语言变化重发；通知中心的固定控件归通知模块维护。

反馈两端词典分别归 `features/feedback/locales/` 与 `settings/feedback/locales/`，截图/压缩/提交失败保留原 cause/response/code，展示时投影；明确的本机失败经 IPC 错误 envelope 返回，不改成功结果或未知服务诊断。公共 ErrorState 的默认/路由/报告控件归其组件词典；原始诊断、errorReportMessage 前缀及上传 metadata 不翻译。报告重试复用第一次输入快照和请求 ID，语言变化保留展开/失败状态且不重发。

TTS 设置/试听/克隆分别维护桌面 `sections/locales/tts.*.json`、手机 `settings/tts/locales/`，手机卡片生成功能维护自身词典。定义/纯绑定与 React 壳分开，纯插入目标在警告发生时读取所属词典并传字符串，不向编辑器传无归属 ref。输入/输出语言、默认朗读样本、voice/账号/资源 ID 与朗读落库标题不改；缓存失败保留脱敏后的原诊断，已知码展示时译，语言不重启播放/生成/上传/克隆或丢草稿。

白板宿主管理词典归 `features/whiteboards/locales/`，列表/信息表单/标签/选择器使用显式 locale/t 的展示 formatter；model 仅留原名称搜索/排序口径，创建默认页名不进入词典。用户画布/标题/描述/标签、路由/scope与任务身份不变，语言不清空表单、过滤、选择或重放删除/确认；公共画布内容与工具拥有各自的展示边界。

## 插件

SDK 从根入口导出 `defineI18n` 和 `useI18n`。作者将词典挂在 `PluginDefinition.i18n`，非 React 逻辑用 `context.i18n.t/resolve`，组件用 `useI18n(messages)`。词典由静态定义提供，静态内容组件无需 activate。定义求值与激活均校验词典；每个激活实例有独立运行时，停用和激活失败回收。

`PluginEnvironment.locale` 是宿主实际界面语言；`usePluginEnvironment` 和 `context.environmentChanges.subscribe` 获取变化。`PluginEnvironmentProvider` 根据环境源提供翻译运行时，不要求插件自建 Provider。浏览器环境适配器可以接收宿主语言源，并在 connect / disconnect 时连接或移除订阅。

命令、页面、导航入口、侧栏、设置分区、首页面板和窗口标题接受消息引用，字符串保留字面语义。宿主将引用绑定到所属插件，向展示适配器交付随语言读取的字符串属性；语言变化发布宿主修订，不重新激活或重新注册贡献，不改变页面实例与输入状态。其他尚为字符串的业务字段由作者在组件或动作中调用 t。

桌面插件窗口通过只读应用状态 `system.locale` 获取启动快照及带修订号的变化，发布接口只接受宿主窗口。旧快照不覆盖新事件；窗口独立求值词典，更新标题与语言环境，不启动另一份插件生命周期。

发布站 `ContentRenderer.locale` 由站点提供，默认中文；服务端和客户端使用同一个显式值。组件不根据桌面设置或正文猜测界面语言。

## 资源与边界

宿主词典在 `apps/desktop/src/app/i18n/locales/`，手机语言入口与主导航词典在 `apps/mobile/src/locales/`，由 `services/i18n.ts` 导入；今天页与问答建议分别就近放在 `features/home/locales/`、`features/aiChat/locales/ask.*.json`；功能词典就近放置在 `locales/`，按语言拆分为 JSON 文件，由明确使用者导入并绑定。模板插件和工作台示例也使用 `src/locales/`，词典随现有应用或插件构建打包，不新增运行时文件加载协议。繁体中文与英文缺词按词典配置回退，未迁移界面保留原文。

正文、用户标题、业务枚举、插件 ID、导出元数据以及 AI / ASR 的语言设置不随界面语言改写。词典与插值按纯文本使用；消息参数不能覆盖底层翻译器的语言、命名空间等选项。
