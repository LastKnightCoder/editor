# AI 入口与能力

同一个模型分配可以服务多种功能。例如，桌面 PDF 对话、学习项目「生成报告」和数据库「一句话生成公式」都使用「对话功能」分配的模型。PDF 对话可点名 Skill、调用工具并等待用户审批；生成报告的后台任务可查资料，但遇到需要确认的工具会收到拒绝；公式生成只把列定义和要求发给模型。下表按用户发起任务的位置说明这些差异。

桌面通用应用工具包括笔记检索、正文改写与审阅、关系与元数据、数据表与只读 SQL、待办日程、网页与图片等。各来源的启用状态决定本轮可用清单，执行时还要核验会话、资料和审批条件。例如，个人记忆查询与更正工具会核验当前库和主对话身份。[工具装配](/apps/desktop/src/agent/toolRegistryAgentTools.ts) · [应用工具](/apps/desktop/src/mcp/providers/index.ts) · [记忆工具](/apps/desktop/src/mcp/providers/assistant-memory-tools.ts)

桌面还有三类通往既有聊天能力的入口，操作结果不同。

- **预填新对话。** 洞见「聊一聊」、问题插件及插件 API `context.app.run("chat.start")` 可预填问题和笔记引用，由用户确认发送。[洞见](/apps/desktop/src/services/insight-chat.ts) · [草稿与发送](/apps/desktop/src/features/chat/chatStart.ts)
- **派活或续改。** 正文选区 @助手／@职责名把选区与要求发到主对话；审阅中的反馈可以交还正在等待的工具，或发回原对话继续处理。[选区派活](/apps/desktop/src/components/ContentEditor/AgentCommentComposer.tsx) · [审阅跟进](/apps/desktop/src/services/content-editing/follow-up.ts)
- **返回已有消息。** 今日页的历史提问、正文对话引用和内容预览可定位回原会话。[正文对话引用](/apps/desktop/src/editor-extensions/chat-ref/components/useChatRefHover.ts)

## 学习项目生成与插件调用

**Notebook 生成**使用桌面 `chat` 模型分配。大纲、重点、文章、思维导图、测验、PPT、报告和插件产物各有模板。用户可附加要求，报告续改带入已有 HTML。各风格的演示新稿与续改使用独立临时目录，限定工具为项目查询、草稿文件和离线播放检查；启用的图片生成可为页面提供随稿资源。清单和各页以文件名标识，分别存为代码块。通过检查的快照携启动时正文修订提交，预览与下载从同一模板版本编译。手绘稿内联固定版本的 Rough.js 和应用模板装饰，全览复制画布位图。首次续改旧稿时，宿主在临时目录中试拆、比对源码往返，检查原稿和重组稿的离线播放，成功后才运行模型。旧壳作为只读文件随正文保存；自带脚本、页面边界不明或验证失败的文稿继续以原格式查看和下载。任务以一次性 Agent 运行，可调用启用的工具、绑定本项目的检索工具和 Skill 工具。它没有聊天输入框的自动 Skill 目录拼接或本轮点名机制；需要等待用户审批的操作会被拒绝，派发子 Agent 仅支持同步等待。[任务入口](/apps/desktop/src/features/vibe-learning/views/VibeLearningView/tasks/runner.ts) · [生成编排](/apps/desktop/src/services/generation-orchestrator.ts) · [工具装配](/apps/desktop/src/services/piAgentRunner.ts)

**插件直接请求模型**时，插件通过 `context.ai.chat/stream` 或 `requestCapability(...).chat/stream` 提交自己构造的消息，可以包含历史文本和图片。接口返回文本或文本流，无 Skill 或模型工具参数。插件自有 AI 功能单独分配模型；借用应用对话或闪卡模型需要对应授权。实际调用还受额度与并发限制。[插件 AI 接口](/packages/plugins/src/ai.ts) · [跨端插件宿主](./plugin-portability.md)

| 插件入口 | 输入和结果                                                                                              | 模型来源                                                                                                                                                                                               |
| -------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 记账     | 从描述建议分类、整理口述记录，按所选范围给提示或复盘                                                    | 授权使用应用对话模型。[记账](/plugins/tau-plugin-expense/src/ai.ts)                                                                                                                                    |
| 体重     | 从文字估算热量、整理记录、生成按日或按周的分析                                                          | 授权使用应用对话模型。[体重](/plugins/tau-plugin-weight/src/ai.ts)                                                                                                                                     |
| 播客     | 独立生成页从来源材料写脚本，再分角色合成音频；Notebook 中的播客由插件给出脚本要求，交项目任务检索与生成 | 独立页取插件自有功能 `script` 的分配，Notebook 取项目生成模型，合成另取 TTS 服务。[生成任务](/plugins/tau-plugin-podcast/src/gen/jobs.ts) · [Notebook 接线](/plugins/tau-plugin-podcast/src/index.tsx) |
