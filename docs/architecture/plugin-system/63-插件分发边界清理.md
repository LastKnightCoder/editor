# 插件分发边界

正式用户从插件中心安装。桌面生产不随包预装业务插件，不读取测试清单，也不从官方旧 S3 目录自动补装。用户本地已安装的包、配置和私有数据保留；开发 ZIP 与目录入口仅供调试和测试，不作为普通用户的新安装来源。

固定插件产物位于 tests/fixtures/plugins，生产构建不读取或编译测试包。中心负责正式发布记录和 HTTPS 下载来源，客户端校验包身份与摘要；这不构成恶意代码隔离或离线数字签名。

移动端已经接入受控开发的格式 3 宿主，使用私有包事务和当前工作区 KV；移动 release 构建仍拒绝安装和启用。生产中心仍只接受原有格式。移动宿主、编辑器及数据边界的权威事实见[跨端插件宿主](/docs/architecture/plugin-portability.md)，公共作者契约见[SDK 跨端契约](/plugins/tau-plugin-template/docs/portability.md)。

浏览器扩展没有插件运行机制，未知节点保留原数据。博客继续按发布上下文收集用户已安装插件的资源与 codec；格式 3 尚未进入正式博客分发，启用格式 3 开发内容包时阻止正式博客发布。
