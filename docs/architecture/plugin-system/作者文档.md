# 插件作者文档

作者文档唯一维护于模板子仓库 `plugins/tau-plugin-template/docs/`。SDK 打包（`scripts/plugins/package-sdk.mjs`）整目录复制进 `@xiongtao.xt/tau-plugins` 的 `docs/`，官网 `/developers/` 构建时读取同一目录（目录登记在 `apps/website/src/docs/developers/manifest.ts`）。不在 `packages/plugins` 或官网另存副本。

## 篇目

开始：概览（README）、快速开始、插件的组成、多端适配、发布与更新。能力篇：界面、存储与网络（含 WebSocket）、用户数据、摘录、闪卡、编辑器扩展（含字数统计）、块的数据版本与协作、白板扩展（含画布修改与数据版本）、AI、MCP 工具、Skill、编译与转换服务、本机后台、站点数据。服务提供方：共同写法 + 同步、上传、语音合成、语音识别、图片、视频、博客发布。

## 写作口径

- 读者只有插件作者，带着具体任务来查：每篇首段直接说这个能力能做什么、何时使用，紧接可运行示例，再给字段表和注意事项。不写「这一篇讲三件事」「按以下顺序介绍」等介绍文档本身、给内容报数的句子。
- 不写宿主内部实现、主进程模块、内部专题编号、仓库内验证脚本、发行开关和审核内部流程。
- 不写 SDK 或客户端「从哪个版本开始支持」，不写已移除能力和旧 SDK 升级步骤；示例里的 `minAppVersion` 只作示例值。
- 平台差异只在「多端适配」的接口表集中维护；其他篇只在首段用一句话标注「仅桌面」或链接过去，不逐段重复。WebSocket 只在「存储与网络」写一次，语音识别只在提供方篇写一次。
- 跨提供方的共同写法（注册、配置表单、取消、错误）只在 `providers/README.md` 写一次，表单字段只在 `providers/sync.md` 写一次。
- 用界面上的叫法描述位置（「设置 › 语音 › 语音输入」「我的 › 插件功能」）。

## 维护

- 修改 SDK 公开契约或宿主行为影响作者用法时，在同一提交中更新模板 `docs/` 对应篇目，并更新模板子模块指针。
- 增删篇目或改一级标题时同步官网 manifest；`apps/website/src/docs/developers/manifest.test.ts` 校验目录、标题与文档间链接。
