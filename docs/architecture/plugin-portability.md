# 跨端插件宿主

## 范围与分发边界

桌面、Android 和 iOS 共用一个 SDK 和一套作者模板。跨端应用插件使用格式 3 的 web-v1 包；独立 Skill 沿用格式 1 的文档目录协议，使用 portable/targets 声明跨端目标，没有 main、format 或 profile。旧可执行格式 1 在读取和上传时拒绝；格式 2 只承载有明确后台声明的桌面包，静态模板及旧 desktop 独立 Skill 保持原桌面声明。公共 API 与作者约定以 [SDK 跨端契约](/plugins/tau-plugin-template/docs/portability.md) 为准；本页描述客户端装配。仓库版本以 [插件 SDK](/packages/plugins/package.json) 和 [UI 包](/packages/ui/package.json) 为准，作者模板依赖以[模板清单](/plugins/tau-plugin-template/package.json)为准；发行状态与仓库实现分别核验。最低宿主版本由插件声明的 targets 与所用 API 共同约束。中心通过人工上架审核与 /v2 分发，具审核权限的作者本人经已绑定仓库 CI 发布可自动批准；作者负责平台适配和测试，审核者不承担平台测试或验证记录。平台开关独立于客户端安装能力，线上配置以[门户运维手册](/apps/plugin-portal/infra/运维手册.md)为准。正式构建只接受固定中心安装，拒绝任意开发来源安装。

`formatVersion` 选择清单和文件布局的解析规则，不代表平台或能力等级；包自己的 `version` 用于更新排序，`apiVersion` 表示宿主契约版本，平台与最低客户端版本由 `platform/targets` 决定。中心从已校验清单派生 packageKind，移动宿主声明可读格式 1/3，但格式 1 只接收明确声明移动目标的独立 Skill，不能借此安装模板或旧可执行插件。

可信插件与宿主共享 JavaScript、React 和 DOM；摘要、模块白名单、API 能力与数据授权不构成恶意代码沙箱。同线程同步死循环只能在后续启动恢复，不能承诺抢占或后台常驻。

## 中心数据边界

逐 API 的支持与作者适配要求以 [SDK 支持矩阵](/plugins/tau-plugin-template/docs/portability.md#各平台可用的接口) 为准。作者、上传和客户端共用 `PortablePluginManifest` 与 `validatePortablePluginManifest` 读取格式 3 清单；发行入口 `validatePortableDistributionManifest` 额外检查移动业务与 AI 权限，运行入口独立检查宿主兼容性。targets 只保留 minAppVersion，不再承载宿主能力、可选需求或节点等级。正文和白板从实际静态定义识别，不再复制进清单。permissions 继续约束用户数据访问，移动权限开放卡片、文章、项目、项目文档、待办与日程的 read/write/delete、闪卡的 read/write，以及 SDK 声明的 `ai:<能力名>`，目标最低版本必须不低于 0.2.13；其他业务权限在构建、中心和运行前拒绝。

`@tau/plugins/center` 提供中心与宿主共用的目标摘要、结构化兼容原因和客户端接口。兼容性检查平台、最低客户端版本、API/格式版本和 profile，调用方继续核验发布状态、来源和权限。宿主请求只携带真实平台、版本与协议集合；中心不执行插件代码，历史发布 ZIP 和审计内容保持原文，平台摘要仅返回最低版本，选版结果只包含状态与原因，不保留旧能力字段、空数组或旧客户端适配分支。读取器只提取协议字段，忽略不使用的附加元信息；不为已删除的字段建立禁止规则。该入口不进入作者 tarball。

门户 `PortalApi.center` 提供 /v2 HTTP 适配与查询 hooks，沿用错误信封与取消信号。/v2 的平台计数、选版、发布状态与格式 3 审核契约见[门户协议](/apps/plugin-portal/docs/协议.md)。旧公共 v1 过滤格式 3；客户端真实失败不会回退旧接口或模拟成功。显式 mock 可注入测试发布记录，不生成可安装 ZIP。

移动 `services/pluginCenter` 与 `features/plugins/data/center-queries` 通过固定操作的 Tauri 命令访问中心，不把请求 URL 或宿主版本的决定权交给页面。原生使用实际平台与应用版本；禁止跳转并限制响应大小，保留结构化错误。默认 origin 固定，调试构建可指定 HTTPS 或本机 HTTP；release 构建忽略调试来源。中心安装只接收 pluginId/releaseId，原生 resolve 后下载、暂存，TS 对账规范化清单与审核记录，原生提交前再次 resolve。来源记录包含 origin/releaseId，普通开发 commit 不能提交中心包。

## 校验边界

清单公共元数据在读取边界统一解析，构建输出只写入协议字段，不携带依赖 imports 等无用途信息。保留身份、版本与 ABI、用户权限、路径与来源、摘要与文件完整性、节点归属和冲突、工作区与生命周期检查；归档、上传、请求体和私有存储保留整体资源预算。简介、关键词、Skill 与表单字段没有额外的文案长度或数量限制。版本按 SemVer 解析，支持预发布和构建标识。

编辑器扩展只提取公开字段后交给内核，附加属性不触发报错，私有钩子不会进入执行链路。构建、中心接收、安装与实际执行是独立的信任或状态边界，各自检查其消费的数据；同一阶段不重复完整解析清单。

## 桌面宿主

`DesktopPluginProvider` 给 PluginHost 注入同一环境源；应用根部的 Provider 覆盖主窗口、辅助窗口与静态内容。平台由宿主明确为 desktop，输入精度由 any-pointer 媒体查询更新；布局由插件容器决定。作者环境只含 platform/input，兼容条件独立传入 PortablePluginHost。兼容校验读取桌面构建版本与移动原生 package_info 版本，不写死测试版本。语义 navigation 入口复用 DesktopPluginRuntime 的页面/侧栏模型，和旧 sidebar 条目使用不同内部身份；页面注销、激活失败、停用都会回收入口。贡献统计包含 navigation。

真实页面经 `features/plugins/pages/plugin-page.page.tsx` 承载。实例上下文管理状态提供器、活动状态、浮层退场与离开守卫；PageProvider 的通用守卫在导航前检查，异步结果过期不执行旧导航，不引入插件业务依赖。页面无效时卸载作者组件，保留宿主的不可用提示。

桌面 0.59.1 从 v2 获取本机兼容版本，下载前后核对精确 releaseId、摘要与清单；PluginUpdates 复用原目录、事务、备份及来源恢复，首次安装即启用，内容插件完整重启后生效。格式 3 的读取保留原始清单，共用平台版本检查与定义求值；正式页面和独立内容进程使用同一产物，主进程不执行作者代码。正式扫描/启用/内容启动拒绝非固定中心来源的跨端包。

桌面启动仅检查已启用的格式 3 候选包，在无 Node、无业务 preload 的内容进程求值定义并识别正文/白板贡献；普通插件不进入静态启动快照，仍可直接启停。首次启用新内容插件时识别静态贡献并提示重启，不调用其 activate；已装配内容贡献在所有窗口固定，更新延续原有重启边界。

未打包 Electron 仍可通过显式 `TAU_PORTABLE_PLUGIN_DIR` 读取隔离开发目录，`.enabled.json` 为开发者选定的 ID 数组；该目录不进入正式安装事务。格式 3 正式内容包保留原始清单参与博客分发，开发来源仍不能发布；静态消费者不激活应用生命周期，渲染协议保持 1。

## 移动宿主与页面

正常 AppShell 在当前数据库作用域挂载 MobilePluginProvider，不依赖桌面 runtime/store。包清单通过 react-query 获取；切库先完成旧运行时清理，再恢复文件事务、校验包、冻结静态内容、激活页面与命令。包验证与装配失败记录到管理界面，并以一次 Toast 提示，不伪造兼容或回退另一个来源。

插件会话不阻塞应用：Provider 立即渲染子树，启动阶段（starting / ready / safe / failed）写入 `app/plugins/content` 的 mobilePluginState，供界面与编辑器 kit 层共用；插件环境 Provider 常驻（会话就绪前给占位快照），会话切换不重挂应用子树。消费方各自等待：插件页/设置页在 starting 时显示加载态；内容编辑器经 `useMobileContentKit`，只读模式随会话换最新 kit，编辑模式在落定前显示编辑区占位、落定后锁定首个 kit，编辑中途不因会话重建而重建编辑器；未注册节点经 IUnknownElementNotice 说明「插件内容加载中」或「插件未运行」，数据始终原样保留。启动只用本地缓存的撤回状态（已确认撤回的包拿不到包体、不会运行），联网核验在会话就绪后执行并按 blockFromCenter 停用新近撤回的版本。

“我的”仍是 settings Tab；插件入口作为 props 插槽进入 SettingsPage 的独立插件功能区。pluginPage、pluginSettings、plugins 均由移动 definePage 自动注册。页面身份与标量参数规范化使用 SDK 规则，返回、转场、保活与 LRU 使用原 router。启停、更新与回退按新会话生效：插件中心「立即生效」重建插件会话（应用待生效包、重启全部插件），不重启应用；中心安装与更新下载完成、安装队列清空后自动重建一次会话（安全模式除外），无需手动点按。「我的」插件中心入口显示可更新数（与已安装页更新条同一选版缓存与口径），有更新时直达已安装标签。已打开的可编辑正文保留原 kit。

页面的活动状态与系统后台状态分别处理。作者应在操作时持久化数据，不依赖 deactivate 一定执行。启动标记位于本机 localStorage，仅用于发现上次插件启动未结束并跳过该次加载（安全模式，插件中心提供重新加载）；包文件与业务 KV 不放 localStorage。

移动管理页消费 `features/plugins/data/usePluginManager`，查询、动作可用性与原生变更由控制器统一编排。动作在调用时复验清单和会话，不只靠按钮禁用；操作互斥，清数据固定工作区，切库/卸载使旧回调失效。启停等操作使用原生 managementEnabled；development 只表示开发来源安装资格，JSON 入口还要求前端 DEV。正式构建只运行来源记录与固定中心 URL 匹配的包；启用和恢复同时检查持久撤回记录。取消或失活后的迟到暂存结果不提交。

中心安装由 `app/plugins/center-install` 按应用 QueryClient 保存任务表（按 pluginId 一项），所有页面通过同一个订阅式 hook 消费；Activity 隐藏、路由深入、关闭安装面板和页面卸载不会取消中心任务。同一插件同时只有一个任务，不同插件并行：最多 3 个同时下载（原生 `Download` 上限 4、与开发安装共用），其余以 queued 排队。取消按插件进行：已开始的任务终止原生等待响应/读取数据的过程；排队中的任务只出队，不调用原生取消（原生取消会清掉已有待生效包）。失败重试仍使用该插件原 releaseId 并重新核验。此机制不承诺进程被系统终止后继续下载；原生事务仍负责保留旧包与恢复文件状态。

已安装清单分别提供 currentVersion、pendingVersion、centerSource、撤回原因和状态刷新失败标记。首次仅有 next 时 currentVersion 为 null，不冒充已安装；固定中心新装包默认保存启用意图，下载完成即重建会话生效，更新保留已保存意图，损坏的 enabled.json 不会默认启用。权限说明不等于授权。Android/iOS 原生宿主提供 browsingEnabled/installationEnabled，正式安装仍由中心复验平台分发与发布状态；非移动宿主不能安装。

中心包在启动及应用回到前台时核验发布状态。已有中心包的会话监听文档可见性、窗口 focus 和 Tauri 原生 focus；考虑 WKWebView 可能缺失前台事件，同时每 30 秒进行可见状态核验，后台不主动刷新，切库/卸载释放监听与定时器。原生按 origin/releaseId 保存撤回/禁用记录，确认撤回不会被后续 available/not_found 覆盖；断网保留既有记录，状态文件损坏时不装配中心包。前台获知不可用后回收页面并把节点写入策略设为 none；保留当前静态内容至下一会话，原文不删除。该机制不抢占主线程死循环，也不回滚已提交数据。

## 移动对象动作

移动运行时接入 `context.actions`，卡片、文章和项目文档详情页的「更多」菜单按注册顺序展示匹配动作，位于内置操作之后、删除之前，并标明插件来源。项目文档引用卡片或文章时，使用来源对象的类型、ID 与创建时间；普通文档使用项目节点身份。material、chat-message、text 暂无移动入口。

菜单展示不授予权限。用户点击时，固定工作区的原生引用事务检查对象是否存在及创建身份是否匹配，再登记与 pick 相同的标题访问授权；正文读取仍按业务权限。授权前后检查插件与动作注册是否有效，停用、激活失败、注销及切库会回收入口，迟到授权结果不会调用旧实例。作者只收到冻结的 kind/id，不收到宿主创建身份或正文。执行错误通过移动 Toast 提示。

## 移动宿主动作

`app.run` 支持 `card.create`、`project.insertDocument` 与 `content.share`，其他动作明确拒绝。用户手势发起后，由会话级 `MobileAppActions` 保存唯一请求，PluginProvider 挂载宿主面板；与内容选择器互斥。切库、停用或会话释放使请求失效，返回与取消关闭未提交请求。新建返回对象引用，取消返回 null；协作只返回 void，不向插件交付宿主读取的正文。

新建卡片使用独立 NodeTree 草稿与移动正文工具栏，预填正文和标签可修改，不读取或覆盖快速记录草稿，确认后才写库。项目文档选择项目与父级位置，项目分页读取；普通输入按正文契约复制，shareOf 只允许本插件活跃实体，预览只读，提交由原生事务再次检查归属并共用正文。保存互斥，失败留在面板重试；写入绑定工作区 token，取消不回滚已经提交的事务。

协作引用按正文创建身份解析；未共享内容先展示来源与正文摘要，用户确认才打开发布流程，已有绑定打开成员管理。发布流程在异步步骤之间检查请求有效性及正文创建身份，失效后不继续绑定、投影或生成邀请码；已经发出的远端操作不承诺撤回。编辑器契约、copyOf 准备与分享内容复用现有数据和协作协议，不新增数据库表或业务授权。

## 移动闪卡基础接口

`context.flashcards` 支持 listDecks、createDeck、createCard 和手动 openCreate；generate、generateAndSave 与 mode: ai 明确拒绝。SDK 在查询牌组时要求 flashcards:read，直接创建牌组和闪卡要求 flashcards:write，移动适配器在异步准备参考资料后复验写权限。构建、中心与原生授权存储共用新增权限范围。

原生 plugin_flashcards 固定工作区 token，核对活动库后复用现有闪卡事务；不新增表，不修改复习调度。正文参考先检查插件读取资格，写入事务再核验创建身份并增持引用；自定义参考资料按正文契约创建独立 contents 行，任何参考失败则整张卡片回滚。返回 SDK 公开字段，不交付复习统计等宿主内部字段。

手动建卡是独立 pluginFlashcardCreate 页面，复用 CardCreatePage、CardEditPage 和牌组表单，可选择或新建牌组、选择五种题型并修改预填题干。请求固定发起插件与工作区，单会话互斥；保存由用户确认，不要求插件整类闪卡写权限，引用其他正文仍需读取权限。未指定 references 时把输入 content 作为自定义来源；显式空数组不添加来源。保存后返回 completed 与真实卡片，退出返回 cancelled 与已保存卡片；停用或切库撤销请求，旧页面不能继续保存，已经提交的数据不回滚。

## 同步与资源上传提供方

两端共用 @tau/plugins/provider-host 的同步和上传注册表；该入口只用于宿主装配，不进入作者 tarball。作者注册 context.sync/context.upload，并以 target 为 sync/upload 的设置分区声明配置字段（form），不提供组件。提供方直接使用统一 API，不再重复填写 fetch/sync/upload 能力需求。

移动 AppShell 的插件会话连接受工作区约束的原生传输。Rust 同步流程固定数据库、配置与任务会话，存储操作经主窗口事件交给同一 JS 提供方执行；原生不包含服务商提供方分支。对象存储插件保留目录前缀末尾分隔符，列举错误不转为空列表，防止资源同步误报完成。连接令牌、请求 ID 拒绝旧回复；切库原生立即撤销连接，React 清理取消上下文。

两端复用内部 `@tau/plugins/fetch-bridge` 的 open/upload/response/read/cancel 协议，此入口不进入作者 tarball。响应头先于响应体完成，响应体按消费进度拉取，取消覆盖等待响应头及响应体阶段。移动 reqwest 上传使用容量为一块的背压通道；每次 IPC 最多传 256 KiB 的当前块，Android 使用逐块 Base64 避免二进制 IPC 缺陷，不编码整文件。没有 128 MiB 请求或响应总量上限；网络保留连接和读取空闲超时，文件提供方任务不设整单 180 秒截止时间，不承诺后台常驻。移动 `response.arrayBuffer()` 先流式写入私有临时文件，再逐块填入一份最终 JS 字节；显式流消费和 clone 保持标准 Response 行为。

数据库、资源和会话文件采用两端共用的[宿主分块协议](/docs/architecture/storage-sync.md)。逻辑文件在宿主拆分、校验和重组，JS 提供方只收到内容块或清单。原生授予的文件句柄绑定会话和方向，校验偏移及完成长度；任务结束、断开或失败释放句柄与临时文件，进程中断的暂存目录在下一会话首次使用时清理。JS 文件任务与原生文件/图片处理的内存许可分别串行，宿主新建的独占上传字节不再复制。

公开同步和上传接口继续使用 `Uint8Array`。同步提供方消费的是宿主生成的有界对象，不能把对象名或某次调用等同于完整数据库。公网直链上传继续接收完整资源字节，其内存仍随文件大小增长；本次同步分块不改变直链行为。原生图片压缩仅处理编码体积不超过 32 MiB、像素不超过 8 Mi 的图片，最长边缩至 2048；超预算保留原文件上传，不限制传输大小。

配置界面由宿主按插件声明渲染，连接配置住在插件详情 › 设置：桌面为一张设置卡片（卡头选用状态、分组为小节、卡脚保存栏），移动为服务页（`syncProvider` / `uploadProvider`）的分组行，选择类字段推入全屏选择层。两端都是显式保存：必填校验 → 插件 beforeSave → 与已存配置合并写回，未声明的键保留；同步目标保存后读取一次云端版本作为连接测试，失败时说明配置已保存。保存只写配置、不改变选用；选用是独立动作：设置 › 同步 / 资源存储（移动为同步服务、上传位置列表页）列出各服务的摘要与状态，切换同步服务前探测目标云端，已有数据时确认。移动保存经原生固定库、固定插件的串行原子更新，选用核验配置未变化。旧版以组件注册的存储设置仍可激活与同步，宿主不渲染其表单，只提示更新插件。普通设置快照不能覆盖提供方配置、选择及原生数据库同步元数据。

其余提供方（tts / asr / images / video / publish / embeddings）的 form 同样由宿主渲染，配置入口统一在插件详情 › 设置（应用设置页只选用服务、点「配置」跳回插件详情）：桌面 `ProviderFormView` 接收调用方给出的绑定（已存值、写回、可选的保存后测试与头部卡片），sync / upload 走 `useStorageBinding`，tts / images 的多账号与 asr / video / publish / embeddings 的单份配置由 `ProviderAccountSettings` 绑定到各自的保存命令；embeddings 目前只有桌面宿主，移动端不注入 `context.embeddings`；发布页抽屉另以 `inline` 布局嵌入同一份 publish 配置并自动保存（`autoSave`），不显示保存栏。移动插件设置页（`pluginSettings`）承载 tts 账号列表与 asr 账号表单，TTS 账号页复用 `MobileProviderForm` + `useProviderDraft`，保存在导航栏。字段类型为 text / secret / url / choice / remote-choice / switch / service-choice（宿主服务选择，目前仅桌面 `git.cacheDirectory`，移动只读展示）；字段可用 `visibleWhen` 条件显示，隐藏时不校验；分组可带外部链接；≤3 项且带说明的 choice 在移动平铺为整行单选、在桌面短选项为分段器；beforeSave 抛 `ProviderFieldError` 时宿主把文案标在对应字段。

账号与目标配置分别存 sync.plugin/imageBed.plugin 的 configurations，按插件 ID 隔离，不使用共享账号引用或主库 KV。提交校验当前服务选择，不转换旧 integration 凭据或搬迁资源账本；移动端读取时先备份原文件，剔除不支持的服务配置，服务选择回落到插件（同步）或本地（上传）。WebDAV 一个包可同时注册同步和上传，二者配置独立。

## 原生文件事务与数据

移动原生中心选版与 TypeScript 运行时使用同一平台和实际应用版本，不维护额外能力词表。原生请求覆盖页面传入的宿主信息；安装和实际加载继续分别复核平台、版本、权限与完整性。

Rust 在应用私有目录 `.editor/portable-plugins/<id>/` 保存 current、staging、next、backup 和设备本地 enabled.json。开发来源描述包含 id/version/url/size/sha256；仅接受 HTTPS 或本机 HTTP，不跟随重定向；同 ID 不跨来源 origin 接管。下载限额、ZIP 总量/文件数、越界、重复路径、符号链接、入口与完整性清单均在原生侧校验。支持模板的单层插件根目录 ZIP。

下载完成先留 staging，前端重复校验目标平台、最低客户端版本，再提交为 next/pending。下一次完整插件会话切换文件：先记录 switch 日志，再保留旧 current 为 backup、将 next 改为 current；中断后恢复。取消清暂存/待生效包；恢复备份只恢复代码，并在下一会话生效，不回退私有数据。安装与启用意图属于设备，不从同步自动授予。

私有存储复用主库 plugin_kv，不新增 schema。TS 适配器固定发起库并检查实例 signal；Rust 核对活动库后打开该固定库连接，后续切库也不会把写入转移到新库。单值限 1 MiB，JSON null 与缺失分开。已发出的同步原生写入可能完成于原库，取消不撤销已提交数据。卸载包默认保留私有数据；独立清除操作要求插件已停用并确认，同一事务删除当前工作区的该插件 KV 与已选择引用的标题访问授权，不删除其他工作区或正文。

## 正文与公共交互

普通正文及其预览使用 mobileContentPlugins 的同一快照，Markdown 转换使用同一 codec。Kit 缓存按快照对象失效；闪卡等其他场景不自动加入插件扩展。键盘位置的 InsertPanel 将插件 blockPanel 显示在插件分组，按 title/keywords 搜索；图标沿用组件契约。执行前恢复打开面板时的选区，插入后保存新选区并关闭面板回到键盘，原实例失效或只读时不执行。指定 allowedKinds 的轻量插入面板不自动加入插件项，插件项不混入内置最近使用记录。

节点仅在 editorExtensions 中注册一次，声明的平台承诺插件完整适配，不再另填节点支持等级。宿主从实际贡献生成节点目录与插入入口；IElementEditingPolicy 按当前只读、会话与撤回状态约束标准 UI、useElement/useSourceBlock 和 captureElementSubmission。已失效的提交不会因后来恢复可编辑而复活，未知节点原样保留。

公共 SourceBlockEditor 按每个 EditorKit 的宿主服务选呈现方式，不在运行时切换全局实现。源码输入统一使用 CodeMirror 的 textarea 通道，在按键命令前同步待输入值，避免移动 contenteditable 延迟回读与快速回车竞争。触摸浮层经 UiProvider 自有的 Portal 容器挂到正文 DOM 之外，隔离按键、输入法、输入及剪贴板事件，避免 React Portal 冒泡触发外层 Slate 热键；页面隐藏时回收 Portal 并取消未保存草稿。草稿只在保存时提交，取消/返回不写入；外部源码变化时禁止覆盖，隐藏/卸载/只读通过提交守卫终结旧操作。普通块外框提供触摸菜单入口，菜单复用标准上下移/删除等命令。真机键盘手感不由此声明为已验收。

UiHostProvider 只接受平台中立的 dismiss 登记函数。真实 Dialog/Drawer 在打开时登记，关闭/隐藏时注销，锁定或关键模态消费返回而不关闭。UiProvider 继承当前 Portal 容器；插件页面使用局部 PortalScope，避免浮层遗留在其他页面。公共 UI 不引用应用路由；模态层级边界保证同批打开时，宿主返回也先交给子模态。

博客 ContentRenderer 独立注入 web/只读环境并订阅输入变化，不依赖 activate；加载器读取原始格式 3 清单并只求值静态贡献。

## 派生数据消费者

移动端的前端导入、导出与正文预览使用插件 codec；Rust 的列表摘要、搜索摘录和部分关联摘要仍只递归抽取 text/children，不解释插件源码字段。因此插件源码不进入这些移动检索结果，管理界面明确提示；原始 JSON、同步与协作投影保留节点字段，不在 Rust 执行插件 JS。未知节点的 Markdown 保真仍由编辑器通用封装承担。

## 验证入口

`plugin-validation` 模式保留正常 AppShell，只注入行为验证器；独立应用标识复用专用测试应用，输出 dist-plugin-validation。验证器调用正式原生安装服务，随后从真实“我的”页打开计数器、在正常卡片正文编辑 ABC；报告写入隔离测试库的 validation.host/report。普通构建不包含自动验证器或固定包来源。

正式宿主复现见 [接入校验指南](/docs/guides/plugin-portability-hosts.md)。验证沿用正式 AppShell、原生安装、运行时和正文编辑入口。

## 移动 AI 插件宿主

`MobilePluginRuntime` 把 `context.ai`、`context.mcp` 与 `context.chat.registerToolRenderer` 接入已有 `MobileAiService`，实际模型运行与原生凭据注入沿用 [移动 AI 服务](/packages/ai/README.md#移动宿主)。AI 服务按需加载；普通插件启动不创建模型请求或聊天文件。SDK 的 AI 请求只做无工具单发，持久聊天仍经宿主 `sessions/runs` 接口管理。

默认连接使用惰性单例；`connectMobilePluginTransport(runtime, { ai, openSettings })` 也允许宿主注入同一 AI 服务与设置打开回调。需要审批/提问时由宿主配置该服务的交互端口，插件不能修改权限模式。插件运行时只回收自己的请求、工具和来源，不销毁注入的共享 AI 服务。

`context.ai.requestCapability` 复用 PluginHost 的清单声明、逐能力授权与撤权订阅，模型取 `llmUsageSettings` 对应项，不隐式回退。`ai.features` 自定义功能默认关闭，由宿主通过 `runtime.ai.info/configure` 维护功能模型分配和每日请求、Token、并发额度；`running/cancel/revoke` 管理在途请求，`usage` 分页读取当日额度与审计记录。额度与桌面一致，按同一设备的 pluginId 计数、跨工作区共享，调用授权仍绑定工作区。插件只收到文本增量、最终文本与可确认的 Token 用量；未知用量为 null。模型、网络与鉴权的原始错误不交付插件。

原生 `plugin_ai_*` 命令使用当前插件 transport token 与数据库身份，模型分配由宿主读取。prepare 到 begin 之间比较配置指纹，begin 持久预占额度并返回提供方指纹；创建模型上下文时以同一设置快照复验指纹，再冻结凭据，冲突不发网。结束时按可确认的实际用量结算；未知用量保留预占，不把 SDK 默认零值当作免费调用；明确尚未接受生成或发网前配置冲突的请求按零用量结算。finish 再检查调用身份与配置，撤回后不能交付迟到成功。配额与请求账本放应用私有 `plugin-ai.json`，不进入主库插件 KV，不保存提示词、回复或凭据；已结束审计保留最近 30 天且最多 1000 条，未结束请求不丢弃，当日额度独立保留。插件停用、提前退出流、调用者取消及切库会停止模型调用并回收绑定。移动端没有独立 AI 配置页面，未注入宿主打开回调时 `openSettings` 返回 `AI_SETTINGS_UNAVAILABLE`。

插件 MCP 支持内联工具及 Streamable HTTP；工具按当前库注册，默认 execute 风险，执行前后仍经过 AI 服务的库租约与工具权限检查。宿主暴露注册状态和等待就绪接口，连接失败不伪装为已可用。stdio 不受支持。工具名与稳定历史 ID 由 `@tau/ai/tool-identity` 同时供桌面与移动使用，展示数据沿用既有 render 版本与载荷。聊天工具渲染器保存为宿主注册表，按工具名或历史 ID 取用；此注册表不创建聊天界面，缺少渲染器时历史仍可使用公共工具投影。

Skills 来源包括已激活的 portable 应用插件和已安装启用的独立 Skill 包。应用插件的 `skills` 元数据进入 PluginHost；独立包不求值 JS、不进入 PluginHost，沿用同一安装、待生效更新、恢复、卸载和来源校验事务。原生清单读取和资源读取核验工作区、当前安装代次、声明路径、完整性与文本预算，拒绝符号链接和越界资源。JS 再对照当前已加载包的 skillRevision 与包类型，旧实例不能读取更新后的包；安全模式不自动恢复独立来源。技能目录按需注册到 AI 服务，停用、重载、撤回、卸载及切库撤销来源；ID 采用桌面的 `包ID:目录ID`。移动端可安装和保留带脚本的独立包，但只暴露受限 Markdown 正文与参考资料，不执行脚本；桌面脚本继续沿用既有审核与执行确认。

以上是宿主与数据能力；闪卡 AI 生成等领域流程、聊天/模型设置界面和 MCP 管理入口不随注册自动产生。API 行为测试和原生临时文件测试不能替代 iOS/Android 设备验收。

## ASR 与 WebSocket 宿主

`ASRProviderRegistry` 统一提供方注册、配置快照、会话取消和最终结果校验；提供方注销、插件停用与工作区失效会使会话终止。`settings target: "asr"` 在两端插件页承载声明式配置表单与识别模型，程序化 open 打开插件设置；应用语音输入设置（桌面 设置 › 语音 › 语音输入，移动 我的 › 语音 › 语音输入）只选用已配置的提供方，未配置时跳到插件页填写。账号保存为 `{ modelId, config }`，保存不改变选用，选用核验配置未变化；选用的插件停用后保留选择并提示，不自动回退系统识别。聊天、搜索等使用入口不在设置范围。麦克风及输入目标由应用负责，协议解析属于独立插件仓库。

网络桥的作者接口和限额唯一维护于 [WebSocket 契约](/plugins/tau-plugin-template/docs/storage-and-network.md#websocket)。公共 JS 适配器提供 EventTarget 及状态机，桌面通过 Electron IPC 和 ws，移动通过工作区 token 校验的 Tauri 命令和 tokio-tungstenite；内部桥接 Promise 与收包机制不暴露给插件。原生层保留握手头、子协议、消息边界、关闭码和关闭原因；断线不隐式重连，工作区释放回收连接。

## 白板作者数据边界

白板 SDK 使用 dataVersion、直接历史版本与同步业务载荷转换，共用编辑器版本规则和公共文本句柄。静态契约准备不执行交互工厂；文档中的精确摘要决定渲染与写权限，未知插件数据保真。作者数据入口不提供路径操作或原始模型，服务与命令按真实归属和激活代次检查；第三方创建回调也不获得宿主 API。详细接口以 [SDK 白板说明](/plugins/tau-plugin-template/docs/whiteboard.md) 为准，完整业务元素和迁移安装不由 SDK 自动完成。

## 移动业务授权与内容数据

移动 0.2.13 的 PluginHost 从已验证清单注入权限，忽略入口代码自行附加的权限；通过 PermissionsAdapter、DataAdapter 和 EventsAdapter 接入卡片、文章、项目、项目文档、待办、日程及正文。公开 API 与桌面同名；app 开放下述选择、描述、页面打开及常用宿主动作，插件自有数据通过下述独立适配器接入。

授权状态机在内部 `@tau/plugins/permission-host`，移动壳层在插件启动期间也承载授权提示，系统返回消费为拒绝。仅本次授权与拒绝属于激活实例，停用/重载/切库失效；持久允许与阻止保存到应用私有 plugin-permissions.json，按工作区和插件分区，不随主库同步。连续拒绝三次阻止，详情可撤销、解除与处理后台请求；读取失败不自动授予。卸载清理该插件的本机决定。授权约束 SDK，不构成代码沙箱。

原生调用复用工作区 token，持锁核验后使用与目标库一致的连接；切库撤销 token，同名库下载替换与插件命令互斥并重建会话。已提交写入不因 JS 取消回滚。查询使用有界游标，游标绑定过滤与排序；元信息修改和删除在事务内比较版本。正文引用包含创建时间，未知节点和来源契约保留。

本地正文修改先冲洗活动编辑器，再重读并比较版本，转换结束后检查新输入；成功写回通过正文同步总线更新视图。协作正文读取会话快照，候选经当前基线校验后由服务器条件提交，冲突不改当前 Y.Doc，成功后落缓存并投影。协作附件能力沿用现有移动限制。删除协作绑定内容仍需先结束共享。内容删除与 plugin_operations 快照同事务，正文延迟释放；七天内恢复核对原正文身份，编号已被占用时拒绝而不覆盖现有内容。

事件消费已提交的 operation 日志，有订阅且前台可见时每两秒有界读取；卡片、文章、项目、项目文档和正文操作统一映射为领域事件，插件写入记录运行期来源，其他来源标为 app。事件不带正文，公共宿主在投递时检查当前读权限；切库与停用清理订阅。整库替换终结旧调用并重建插件会话。应用查询缓存随写入和事件失效。

项目插件数据复用业务数据的 token、固定库连接、版本校验及删除恢复通道。`projects` 提供信息 CRUD 和 `tree`；`documents` 提供查询、标题/标签修改、富文本创建、移动及删除。目录从当前项目根加载，节点与展开数量受预算约束，不全量读取项目文档表；同一文档在多处保留多处条目，卡片/文章引用项带 `ref`，不可经 `documents.get` 读取，但可用目录版本移动。

目录移动改动指定的父子边，拒绝错误源位置、跨项目目标、重复挂载及环。父节点本身跨项目共享时，边变更作用于它的全部挂载；保留其他父节点/根引用，重新计算受影响子树的项目归属。创建与结构变更推进相关项目和父文档版本并写提交日志；移动内置项目操作与插件订阅使用同一项目版本/日志维护函数。

项目只允许删除空目录；文档有子节点或属于视频笔记时拒绝删除。删除文档保存全部挂载序号与容器创建身份，正文及白板页按引用延迟释放；恢复只挂回仍存在且身份未被复用的位置，全部位置失效或原编号冲突则整体回滚。快照沿用共用 plugin_operations 的 row/contentCreatedAt/placements 字段，新增容器身份字段不改变桌面读取。白板型条目只开放元信息和引用维护，不开放画板正文或白板扩展。

### 移动待办与日程

`plugin_tasks_read/write` 复用工作区 token 和固定连接，调用前后受插件生命期限制。待办使用 `todo:<id>:<createTime>` 或 `document:<contentId>:<createTime>:<taskId>` 身份，周期实例再带原始日期；公开 ID 仍是不透明字符串。`todos.query` 默认 tasks，occurrences 必须给日期窗口，游标固定查询、时区和宿主代次，并记录候选内实例位置。正文待办逐页从主库节点读取，按真实来源、排除与提升设置过滤，不依赖移动端未维护的索引镜像，不全量传输笔记库。

实例完成/改期/跳过按原始日期选择历史规则段；改期不改变实例身份，dueAt=null 取消改期，删除实例仅跳过，系列删除才移除系列。SDK 不提供周期规则创建和变更接口。停止周期并转为普通待办后，可完成当前普通待办，历史实例状态保持独立。普通父待办完成沿用子树语义，但含周期子项时拒绝整组完成；含子项的待办不能删除。内部 DataAdapter 的实例写入单独接线，公共宿主不把带日期的 ID 交给未接线的旧适配器，防止忽略实例日期后修改整系列。

正文待办只修改目标节点的首段标题、日期词、勾选或实例属性，保留项目词、富文本格式与其他节点；日期使用显式值或已保存锚点，不根据今天猜测无锚点的相对日期。活动编辑器先冲洗，写入复验正文与目标修订；共享正文走服务器条件提交和既有投影。正文删除恢复采用保守冲突检查：删除后正文发生其他变化时拒绝覆盖，材料保留。

日程查询把实际安排与虚拟任务标记合并分页，周期历史（包括已停止系列）按规则读取，不依赖旧物化窗口。系统日历及虚拟标记不可由日程写接口修改；关联安排的标题跟随待办。全天 end 是排他的下一日，定时安排须带时区且精确到分钟，无法无歧义保存的夏令时重复时刻拒绝；待办写入及正文编辑入口的关联清理使用该日期的 IANA 时区偏移。缺少所需节假日资料时明确失败，不以周末规则冒充完整节假日结果。

任务删除复用 task_assistant_operation、task_assistant_content_pin 和 plugin_operations；周期历史、完成/改期状态、备注与关联安排同事务记录。删除独立待办移除未来安排、解除过去安排的关联；恢复检查原分组/日历/父待办及正文身份、后续修改和保留引用。共享删除与恢复先持久化提交指纹，再提交服务器操作；投影在事务中完成本地日志确认。恢复界面核验未决回执，已中止则撤销意图，已提交则续完投影；不能确认或关联冲突时保留待确认状态，不宣称跨服务存储原子提交成功。已确认记录保留七天，未决记录保留至结果可确认；取消记录保留编号防止迟到回调指向另一操作。

待办/日程变化按集合发送 todos.changed/calendar.changed（不携带实体数据，origin 保持 app），投递时仍校验当前读权限；普通移动待办写入、正文写入与关联清理也写统一操作日志。

### 移动引用选择与打开

移动 `app.pick/describe/open` 支持 card、article、project、普通正文 document、diary、todo、实体 event 及 plugin-entity。选择和打开必须来自当前用户手势；仅支持 page，window/dock 明确拒绝；at.block 支持卡片、文章、普通项目文档、日记片段与插件实体；插件实体经注册页面传到正文组件。项目引用项仍归原实体，白板/视频等非普通正文文档不进入选择候选；日程虚拟标记须改用查询结果中的 todoId 打开待办。周期实例经历史规则验证后打开所属系列详情，不把系列完成按钮解释为所选历史实例的完成操作。

diary 引用与桌面一致，ID 为 diary_segments.id，创建身份取片段 create_time。候选按片段分页，标题复用脉络的正文摘要口径，空白内容显示「空白日记」；日期作为宿主选择器的副标题并参与搜索，不随 pick 结果交付插件。describe 只接受逐条选择授权，原生忽略 diary 的整类 readable 标记；授权仅含标题，未开放日记正文读写。片段、所属日记或正文缺失时不列候选，确认时整批复验创建身份，编号复用不会继承旧授权。打开经原生解析到片段 contentId，直接进入公共正文详情并带日记日期头与保存刷新，不调用可能创建片段的日记打开流程。

`plugin_app_query` 与 `plugin_app_refs` 固定 token、数据库和插件身份。选择器请求隔离缓存、分页与取消信号；实体候选使用 ID keyset，正文待办使用有界扫描，游标绑定查询、插件、时区和会话。候选的创建身份仅在宿主内部传递，确认时在单一事务中复验整批身份并记录 plugin_ref_grants，插件只得到引用与当前标题。describe 按输入顺序返回状态，先检查读取权限或已有引用授权，未经许可不探测是否存在；引用授权绑定目标创建身份，不能落到复用编号的新实体。它不授予正文或整类数据读取权限。

选择器在插件激活完成前即可挂载，使用全局确认层和当前页面的返回仲裁。确认前取消不登记授权；提交确认期间锁定取消，避免把已经确认的登记显示为取消。停用或切库仍强制终结旧请求，已在原库完成的授权不回滚，迟到结果不再交付旧插件。describe 返回前再次检查读权限，撤权期间的迟到标题不交付。

打开目标由原生验证后返回宿主私有导航信息；独立待办携带真实分组，正文待办按 contentId/taskId 打开原文。卡片、文章和项目文档页面通过 block/locationRequestId 参数交给公共详情页的 useContentLocation；块序号从零开始，越界回到首块。每次带 at 的打开产生新定位请求，重复打开同一块会重新定位，参数不参与页面身份；普通重渲染与返回页面不重复拉回视口。正文加载与 DOM 就绪后只滚动并提示位置，不改变焦点、选区、折叠属性或完成状态；目标折叠、消失或暂不可定位时给明确提示，页面隐藏时取消定位。公开 EntityRef/ContentEditor/ContentPreview 通过移动共享模块装配，作用域与数据通道见下节。

### 移动插件自有数据

`MobileOwnData` 为 entities、records、links 和 transaction 提供适配，原生 plugin_own_data 统一分派到可组合的事务函数。复用 plugin_entities/plugin_entity_kinds/plugin_records/plugin_links/plugin_operations，不新增 schema。读写固定工作区 token、插件和激活 lease；adopt 注册有效租约并在事务内领取本插件孤立数据，release 留下失效标记，不能用旧 lease 再次激活。异步节假日预取前后均复验租约，失效请求不能提交；已经提交的事务不因 JS 取消回滚。

实体 ID 经持久序列预留，原生按 token/lease/plugin 保存未消费集合。预留消费后事务失败也不复用，批次包含外来身份时整批不消费；工作区终结清理内存租约与预留。事务最多 500 项，正文先在 JS 准备，再复验关联读权限，以同一 SQL 事务执行实体、记录和关联写入及事件。普通单项更新/删除必须带 expectedRevision，事务可按契约省略；实体元数据与正文分别保留版本。查询复用 JSON 类型校验、NULL 语义、混合排序和 ID 兜底键集游标，游标绑定作用域及过滤排序。

实体删除保存行、正文创建身份和出边，在七天恢复窗口内延迟释放正文；恢复验证 ID/key/正文身份和全部出边，冲突整体回滚。删除目标保留入边，记录删除不进最近删除。shareOf 仅用于新建卡片、文章及项目文档：校验本插件活跃实体后在同一事务增持原正文，失败回滚；同正文只允许一张卡片和一篇未删除文章，项目文档允许多处引用。copyOf 沿公共复制契约，不改变源正文，也不额外要求来源读取权限。

entity/record 的提交日志使用 plugin-event 类型与结构化 action，持久保存真实拥有者和类型/集合；删除后不依赖回查存量行。事件适配器按 ownerPluginId 隔离并剥离该私有字段，origin 只表示写入来源。普通正文写入与协作投影由正文当前实体归属生成 entity.updated；显式领取孤立数据发 created，重复领取不重复通知。

类型名和图标随库保存，停用不删除外观。移动端不根据本机安装清单标记或回收其他设备的数据，卸载保留实体/记录；当前工作区的清除操作仅清 KV 与已选择引用授权。实体原生检索、@ 和注册打开方式由统一运行时接入，数据接口与公开正文组件可在插件自有页面使用。反链复用引用索引与来源解析，公共宿主只返回已获读取权限的来源，其余只计数。关联保存 to_created_at，但公开数字引用未携带它；整类读取权限下的 describe 仍按当前 ID 描述，此跨端边界不表示旧边自动改绑。

### 移动实体入口与公共正文组件

统一搜索与 reconcile 索引生产覆盖 plugin-entity 的标题、正文及较新的实体/正文更新时间；删除同步移除索引行。LIKE/FTS 还原统一的 pluginEntity 元数据（拥有者、类型、标签、图标、创建时间），普通搜索保留现存孤立实体。显式包含插件实体的空词搜索按类型返回有界最近结果；@ 的活跃 mentionable 白名单在 SQL 分页前过滤，候选确认时再次核验当前运行时声明及实体/正文身份。

运行时保存每个激活实例的类型定义，失效即注销；全局打开服务固定当前宿主，再由原生解析归属、实体及正文创建身份，使用拥有者上下文读取实体并执行 open.params。原生只返回宿主目标，发起打开的另一插件不获得目标 meta/body。异步读取完成后同时复验拥有者、调用方及当前工作区，定位参数不参与页面实例身份。搜索、引用预览、脉络和公共 EntityRef 共用此路径；原生 presentation 单独检查引用访问资格，只读取 label/icon，不读正文或 meta。

真实 @ 入口在卡片/文章/项目文档公共详情、快速记录、待办描述、日程详情、独立协作页及公共 full 编辑器接入。捕获实际 @ 范围与文档/编辑器身份，避开 IME、代码、链接及只读；取消不删原字符，确认前复验范围与当前活跃目标声明。compact 和闪卡独立套件不启用内容引用识别。查询缓存含宿主代次，旧窗口的迟到确认不能落到新请求。

公共组件由移动 shared-modules 覆写同名 SDK 导出，不修改进程全局正文组件运行时。插件页面、独立设置及详情设置均注入拥有者 scope、活动状态与离开守卫；权限只查询，用户按钮才申请。组件订阅权限代次、实例终结和原生变化，迟到正文与外观不交付失效视图。Editor 复用 useEditContent 的串行保存、CAS 和活动编辑协调，以及真实本地/共享 NodeTree 文档；组件保存直接走固定库的已验证通道，不递归冲洗自己的 writer。共享投影缓存落盘后再次复验权限、绑定及视图守卫，并携带 token/database 来源。

本地缓存、节点视图及共享文档写入都组合动态 canWrite/guard，外层 readonly 不是唯一保护。full 含业务扩展，compact 使用底座加已安装插件扩展并保留不支持节点；预览默认 3 块、最多 100 块。ContentEditor.at 解析 JSON block/taskId，非法或越界回到文首，隐藏时停止定位。EntityRef 按实例批量 describe（每批最多 200），原生复验后展示声明外观；SVG 仅作为 CSS mask 图像使用。移动既有协作附件限制继续生效。
