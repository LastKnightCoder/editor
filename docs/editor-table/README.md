# 编辑器表格重设计

跨会话入口。视觉与交互以 mockup `apps/desktop/mockups/table/index.html` 的「★ 定稿」一节为准；代码在 `editor-extensions/table/`（`@tau/editor-table`）。

## 已定（2026-10-05）

| 项     | 结论                                                                                                                                                                                                                                                       |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 交互   | 方向 A 边缘手柄：悬停格子时该列顶边、该行左边出现手柄；点击 = 选中整行/整列 + 弹出行/列菜单，拖动 = 排序；右侧/底部「+」追加。不做边框插入点与选区浮条（曾考虑与 B 组合，已改为纯 A）                                                                      |
| 视觉   | 细框线：圆角外框、浅内线、表头浅底；去掉斑马纹，内边距 `7px 12px`                                                                                                                                                                                          |
| 列宽   | 不做，按内容自适应（GFM 无列宽，导出会丢）                                                                                                                                                                                                                 |
| 表头   | 始终保留；删除首行时下一行升为表头                                                                                                                                                                                                                         |
| 键盘   | 只留 `Tab`/`⇧Tab`（末格 Tab 新增行）、`Enter`（下一行同列，末行新增）、`⇧Enter`（格内换行，导出 `<br>`）、`↑`/`↓`（上下格）、`⌫`；删除 12 个 `⌘[⇧]+方向` 命令。不做「格内 Esc 选中当前格」：编辑器常嵌在卡片弹窗等浮层里，Esc 归宿主浮层仲裁，表格不应吞掉 |
| 粘贴   | 做：格内粘贴多格数据按格填充并扩行扩列；正文粘贴多格数据生成新表                                                                                                                                                                                           |
| 移动端 | 暂不适配（共用扩展，需保证触屏下基本编辑不退化）                                                                                                                                                                                                           |

## 问题根因（为什么不只是换 UI）

- 没有 normalize 守住「table → row → cell、每行格数一致、至少 1×1」，异常操作后出现缺格。
- 增删行列是整表替换节点，撤销粒度粗、协同易冲突。
- 跨格选区删除被 `deleteGuard` 直接吞掉，没有「格选区」语义。
- Markdown 导入丢弃列对齐（`:---:`）。

## 实施计划

### P1 模型与不变式

- `TableElement` 增加 `align?: Array<"left" | "center" | "right" | null>`；codec 导入读 mdast `table.align`，导出写对齐行；同步 CLI 渲染器、HTML 序列化。旧文档无此字段即左对齐，无需数据升级。
- `table` / `table-row` 的 `normalize`：只允许对应子节点类型；每行补齐/截断到最大列数；0 行或 0 列时整表替换为空段落；`align` 长度跟随列数。存量缺格文档加载即被修复。
- 操作改为**按下标、作用于表格路径**的纯函数（不依赖光标）：`insertRow / insertCol / deleteRows / deleteCols / moveRow / moveCol / setAlign / clearCells`，内部只用 `insertNodes / removeNodes / moveNodes / setNodes`，一次操作一步撤销。

### P2 格选区

- 格选区不另存状态：Slate 选区两端落在同表不同格即按矩形理解；手柄产生的整行 / 整列选区另带类型标记，标记只在选区原样未变时有效。
- 进入方式：跨格拖选、`⇧`点击、点行列手柄。渲染为覆盖层，期间隐藏原生选区。
- 核心悬浮工具条在格选区上仍会出现：加粗等文本格式（addMark / removeMark）改写为只作用于矩形内的格。
- `⌫`：整行/整列 = 删除；任意格 = 清空内容。替换 `deleteGuard` 的吞键分支（全选删除补段落的逻辑保留）。
- `⌘C`：写入 TSV（纯文本）+ HTML 表格 + 子表 Slate 片段。

### P3 交互外观

- 删除表格上方的工具条与 `Actions/ActionItem` 菜单。
- 行列手柄：悬停格子时出现在该列顶边、该行左边；拖动排序改用指针事件实现（行列共用一套），替换首格内的 react-dnd 行手柄。
- 底部、右侧追加条。
- 手柄菜单：列 = 左侧插入 / 右侧插入 / 对齐（左中右）/ 清空内容 / 删除列；行 = 上方插入 / 下方插入 / 清空内容 / 删除行。已有格选区时点手柄，作用于选区覆盖的全部行/列（「删除 2 行」）。菜单接宿主返回仲裁（`OverlayBackDismiss`）。
- 表格级操作（复制、剪切、删除、上下移）直接用块手柄的通用菜单，不另声明。
- 样式只消费 `--ed-*` / `--tau-*` token。

### P4 键盘与粘贴

- 热键收敛到 Tab / ⇧Tab / Enter / ↑ / ↓ 五个命令（⇧Enter 由插件改写 insertSoftBreak）；同步 `packages/editor/src/__tests__/define-extension.test.tsx` 中对 `tau.table.*` 的断言。
- `⇧Enter` 在格内插入软换行，codec 导出为 `<br>`、导入还原。
- 粘贴由插件改写 insertData / insertFragment（见进度 P4）。正文里只认领 HTML 表格，避免把带制表符的代码误转成表。

### P5 收尾

- 更新扩展 README、单测（normalize、各操作、格选区删除、粘贴、codec 对齐往返）。
- 视觉由用户验收。
