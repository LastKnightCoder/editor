沉浸墨韵 · 夜读复习

列表页延续令牌、随主题；复习页切换到固定的玄夜深色屏（琥珀主色 + 氛围光），把复习做成一段专注仪式，夜间护眼。

风格 C

纸感卡堆 · 翻面卡片

「卡」是实体纸卡：3D 翻面看答案、背后错位堆叠显示余量、左滑吃力 / 右滑轻松手势评分。卡组瓷贴双列 Bento 主页。

  • ＋闪卡隐喻最直白，触感与趣味性最强
  • ＋堆叠余量可视化，翻面交互记忆点鲜明
  • －实现最复杂（3D + 手势，约 1.3×）；手势有学习成本

📝 编辑页重设计稿（三方案待选）：A 轻纸面 —— 整页即纸面，题干/选项是仅有的实体，其余输入无框融入纸面，信息密度最高； B 卡片流改良 —— 保留一区一卡的现有骨架，卡内输入去底色无边框，改动最平滑； C 题干主角 —— 题干大字号置顶无框，低频字段折叠默认收起，出题路径最短。三方案共同修复：选项长文自适应多行（textarea 自动长高）、输入框去双层底色嵌套、标签 chip 化（回车/逗号确认、⌫ 删末尾、点 × 移除），全部可真实交互。
