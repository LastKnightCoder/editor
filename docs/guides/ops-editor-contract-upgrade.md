# 正文转换与本机数据保全

协议、存储边界及退役规则见[协作架构](/docs/architecture/collaboration.md)，插件声明和版本示例见[作者文档](/packages/plugins/docs/editor-collaboration.md)。以下操作使用提供该能力的客户端；源码存在不代表服务或 SDK 已发布。

## 桌面转换

1. 安装并启动包含自动升级的桌面客户端。后台扫描已连接资料库和设置中已有的本地资料库文件；正文、独立白板、内嵌页与创作页统一处理，无需逐篇打开或点击转换。
2. 正常内容自动保全、校验并安装；短暂等待时仍可只读查看原内容。不要在升级期间启动旧客户端修改同一资料库。
3. 退出、崩溃或断电后重新启动；后台优先沿原操作回执续做。共享正文由所有者客户端自动转换，其他设备保全本机修改后采用新基线；等待网络或所有者时自动重试。
4. 只有收到“部分内容需要处理”时查看详情：磁盘空间、损坏数据、缺失资源或未知载荷按报告处理，再选择“重试”。未知载荷仍保留原文，不以恢复占位当作完整转换验收。
5. 插件后续数据版本升级仍使用正文的版本升级入口，与本次旧格式自动转换分开验收。

成功判据：旧格式剩余数为零、正文契约及白板投影可读、全部安装回执完成、异常已核对。安装了新客户端或队列扫描结束都不能单独证明数据已升级。

## 移动端接收

1. 旧格式先在桌面完成转换。移动端不执行旧实体转换。
2. 有本机未确认输入时，使用“导出本机副本”保留材料，或选择“保全并采用新版本”。必要保全失败时停止采用。
3. 采用后确认文档已使用新基线，原未确认输入仍在副本中；不得向新基线重发旧增量。

## 查看和导出副本

- 在协作界面打开“本机恢复副本”。检查完整性错误与“资源未取得”清单。
- 桌面使用“导出到下载目录”；移动端使用“导出恢复包”。Android 10 及以上写入系统下载目录；较早版本写应用外部文档目录；iOS 写应用 Documents 下的 Tau Recoveries。
- 整库替换后的桌面提示可选择“使用下载后的正文”；该操作解除已保全旧会话与当前库的关联，不删除恢复材料。
- 当前不提供恢复包导入、从包创建独立资料库或自动合并新旧输入。
- 新生成的单篇副本用 `source-projection.json` 保存来源正文与契约，`input-drafts.json`、`node-views.json` 只含目标文档；不应出现整库文件。历史副本不会自动删改。旧插件附件按旧文档资源声明检查，取得的文件进入副本，未取得的引用列入缺失清单。

## 验证

使用临时数据库及测试房间验证：后台分页扫描、无主库来源的未决共享操作、PREPARING、空白板目录、异常版本及缓存损坏、扫描结束前新增旧数据、未打开内容与隐藏页、中断后主库已安装的续做、保全校验失败不覆盖、切库暂停期间的定时重试不打开数据库、本机旧缓存与主库分叉先保全两份、中断后新内容及白板改名不被覆盖、修改时间保持、异常集中提示，以及准备/提交/安装中断重试、取消与过期、原引用保全、同代次换基线拒绝、迟到草稿回执、覆盖前失败回滚。正常切库不得生成整库备份。原生设备上另检查系统目录可见性、导出文件可读取，以及中文输入与页面隐藏恢复；自动化行为测试不代替设备验证。
