## 本阶段裁决

- Seed 为独立私有仓库 `LastKnightCoder/tau-plugin-asr-seed`；厂商地址、鉴权字段、二进制协议、压缩、结果修订均留在该仓库。宿主不内置 Seed。
- WebSocket 工厂为 `context.websocket.connect(url, protocols?, { headers, signal }?)`，同步返回连接，标准事件、状态与 send/close 语义保持不变；仅扩展鉴权头和插件／任务生命周期，背压由宿主处理。不再暴露异步 send 或 receive 接口。
- 默认 Mac SpeechDetector 为 medium；消费 VAD 结果流，识别结束等待 finalize 及结果流。Seed 使用服务端 VAD 句界与二遍结果，宿主不额外裁剪音频。
- P3 本轮优先 Mac、Seed、聊天与搜索。Whisper 文件能力已在 P2 接入；“录完后转录”的听写入口尚未实现，保留在后续任务清单，不将文件能力伪装成实时输入。AI 整理仍属 P4。
- Windows 原生继续待验证，不扩张旧版兼容范围。移动不启用 Mac 原生能力，使用插件。
- SDK 0.43.0、桌面 0.59.5、移动 0.2.6 为源码接入版本，不代表正式发行。用户授权创建与修改仓库，未授权 npm/插件发行；不发布标签或上架。移动版本随当前工作区的 0.2.6 对齐，避免覆盖其他任务已推进的版本。

## 实现边界

公共 ASR 保留原有文件与实时引擎契约；新增宿主 AudioWorklet 采集和输入编排。用户点击时创建 AudioContext，按引擎采样率混合为单声道、小端 Int16；200 ms 一帧，最多两秒未消费音频。stop 刷完尾帧再 endInput，result 才是最终成功；cancel、设备结束、页面隐藏、插件停用均终止录音。默认最大录音 120 秒、尾句等待十秒。

桌面 `speech-input` 是 BACKGROUND 模块，通过 ensureModule 就绪；主进程跨窗口租约防止并发录音，心跳与窗口生命周期释放租约。Mac helper 使用当前架构开发构建及 arm64/x86_64 通用生产构建，读取管道的实际到达字节，不等固定缓冲填满。原生输出无最终结果即退出、异常退出均立即令录音失败。

JS WebSocket 适配器以 EventTarget 实现 open/message/error/close、readyState、bufferedAmount、protocol、extensions、binaryType。send 同步排队，复制二进制视图并保持 Blob 顺序；close 校验关闭码和 UTF-8 原因长度，排空后握手；异常通过 error/1006 close 交付。内部 Electron/Tauri 桥可以使用 Promise，作者不接触内部收包与排队机制。宿主只接受 wss 或本机 ws，鉴权头不能覆盖握手保留头；不自动携带浏览器 Cookie、不重定向或重连。

Seed 在 open 后发送 gzip 配置和 PCM 帧，结束发送负序号末包，收到服务端最终包后才成功。临时完整分句快照做修订，已确认分句不可改写。连接断开、鉴权错误、协议错误不会返回半句成功，也不重放音频。

ASR 配置经专用保存接口写入并由用户明确选用；普通全量设置提交保留最新的语音账号，渲染缓存不保存账号。聊天捕获编辑器提交守卫和原内容，搜索捕获当前输入身份和内容。临时结果仅预览，最终结果只在目标仍有效时写入；目标改变时保留可复制结果，不自动发聊天或执行搜索命令。

## 验证证据

### Mac 产品 helper

当前 Mac、zh-CN、medium VAD、16 kHz 单声道 PCM Int16：

| 场景           | 结果                                                                          |
| -------------- | ----------------------------------------------------------------------------- |
| 中文约 21 秒   | 首次更新 1061 ms；82 次临时更新；停止后 182 ms 返回最终文字，保留“春夏秋冬雨” |
| 最后五秒       | 首次更新 1041 ms；停止后 51 ms 返回最终文字，尾句保留                         |
| 两秒纯静音     | 0 次文字更新，3 ms 内完成，空文字                                             |
| 空输入立即停止 | 成功返回空文字与 0 ms 时长                                                    |
| 取消           | 子进程 SIGKILL 后约 4 ms 退出                                                 |
| 非连续音频帧   | 明确失败，不返回成功                                                          |
| 模型准备       | 当前已有资源，准备调用约 86 ms；不是冷下载证明                                |

原始指标：[产品 helper 汇总](./evidence/p3-native-summary.json)。复现脚本：[产品管道验证](./native-probe/validate-product.py)，先用同目录 make-fixtures.py 生成合成音频；本轮使用 P1 已有的中文末尾去静音夹具。未重新录制真人音频，真人麦克风证据仍为 P1。无录音、密钥或真人转录正文进入仓库。

验证暴露并修复两点：关闭 VAD 结果报告的纯静音会触发系统内部错误，启用报告并持续消费后通过；FileHandle 定长读取会累积管道数据，改用按到达字节读取后恢复约一秒首字。错误码不被当作“无语音”吞掉。
