## 侧栏用来做什么

现在三个容器各管一段：

| 容器                 | 生命周期                     | 擅长                                 |
| -------------------- | ---------------------------- | ------------------------------------ |
| 页内浮窗面板（现有） | 随网页，切标签页就收         | 就地：对着这段原文提问、批注         |
| 伴读库标签页（现有） | 独立标签页                   | 批量整理：三栏浏览、改名、按站点筛选 |
| 浏览器侧栏（新）     | 跟随窗口，切标签页内容跟着换 | 边读边写、跨页查找、回看             |

侧栏和浮窗功能重叠的根源是二者都在「看当前页」。区分点在于侧栏不遮正文（浏览器把网页挤窄），而且跨标签页常驻。所以侧栏的定位是**阅读工作台**：

1. **本页**（默认）：本页标注列表 + 本页笔记 + 对话（含浮窗面板已有的会话管理：新建、切换、删除本页的多段对话），内容随当前标签页切换。
2. **记笔记**：笔记默认写给当前页；可「钉住」一篇，读别的页时摘录继续接进这一篇（跨多页写一篇综述的场景，浮窗做不到）。
3. **全部**：所有页面 / 全部标注 / 笔记的紧凑列表和搜索；点标注跳到原页面并定位，已打开就切过去。复杂整理（改名、站点筛选）仍去伴读库标签页，侧栏 ⋯ 里有入口。

## 方案对比：侧栏和浮窗面板怎么共存

|          | A 侧栏取代浮窗面板（推荐）                                                                    | B 两者并存                       | C 侧栏只做「全部」                       |
| -------- | --------------------------------------------------------------------------------------------- | -------------------------------- | ---------------------------------------- |
| 形态     | 工具栏图标 / ⌥J 开关侧栏；页内只保留悬浮球、选区工具条、原位快答气泡、页边批注                | 图标开侧栏，悬浮球开浮窗         | 侧栏只放跨页列表，本页仍用浮窗           |
| 用户心智 | 一个面板，一个位置                                                                            | 两个面板内容相同，要学哪个用在哪 | 两处来回切                               |
| 实现     | 面板三页签从内容脚本搬到扩展页面（同笔记页的做法，Tau 编辑器直接跑在扩展页面，不再走 iframe） | 两份 UI 都要维护                 | 改动最小                                 |
| 风险     | Firefox 侧栏 API 不同（`sidebar_action`），需要单独适配                                       | 维护成本翻倍                     | 没解决「不想跳转」的主诉求之外的边读边写 |

推荐 A：选区工具条和快答气泡仍在页内负责「就地」，侧栏负责「列表和书写」，没有重叠。悬浮球在侧栏关闭时作为入口保留（可在 ⋯ 里关掉），侧栏打开时隐藏。

## 交互要点

- 开关：工具栏图标 `setPanelBehavior({ openPanelOnActionClick: true })` 原生就是切换；⌥J 走 `sidePanel.open()`（需用户手势，快捷键算）与 `sidePanel.close()`（Chrome 141+）。
- 跟随标签页：侧栏是窗口级（全局 panel），监听 `tabs.onActivated` / `tabs.onUpdated` 切换内容，页头标题淡入替换。
- 页面与侧栏联动：点侧栏标注 → 网页滚到高亮并闪烁；点网页上的高亮 → 侧栏选中对应卡片。经后台转发给该标签页的内容脚本。
- 选区工具条的「批注」在侧栏打开时直接在侧栏卡片里编辑；侧栏关闭时仍用页内批注框。
- 侧栏顶部一行（τ Tau 伴读 + ×）由浏览器绘制，扩展改不了。
- 离线：沿用现有口径，标注先写本机，「全部」只列本浏览器看过的页面。
