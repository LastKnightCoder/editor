# 移动端编辑器体验重做

状态：进行中
目标：让移动端编辑器符合触屏使用习惯——工具栏贴键盘、二级面板占用键盘位置、块操作改为「选中后操作」、默认阅读态，并给插件留出承接位置。

视觉稿：`apps/mobile/mockups/editor-mobile/`（静态页，需从仓库根起 HTTP 服务访问，`.claude/launch.json` 的 `mobile-editor-mock`，入口 `http://localhost:8834/apps/mobile/mockups/editor-mobile/`）。各节对应的 mockup 页签标在小节标题后。

## 1. 现状与问题

- 工具栏：`apps/mobile/src/features/cards/editorToolbar/MobileEditorBottomToolbar.tsx` 是悬浮在键盘上方 12px 的横向滚动胶囊，4 组约 16 个 36px 按钮；标题、颜色、下划线是锚在按钮上方的小 popover；插入走 `ActionSheet`。
- 块操作：内核拖拽手柄（`packages/editor/src/core/components/BlockDrag/`）只靠 hover 显示，移动端挂的是 react-dnd `HTML5Backend`（`apps/mobile/src/app/AppShell.tsx`），触屏无法拖拽，也没有块菜单入口。
- 选区浮动工具栏在移动端被 CSS 隐藏；斜杠菜单仍会被 "/" 触发。
- 复杂块（表格、代码块、公式）没有上下文工具。
- 没有阅读态：打开文档点哪里都会弹键盘。
- 插件：编辑器贡献字段白名单（`packages/plugins/src/editor-fields.ts`）中 `blockPanel`（斜杠菜单项）与 `menu`（块菜单项 `EditorMenuEntry`）已存在，`toolbar` 不对插件开放；移动端当前不运行插件。

可复用：`useMobileEditorToolbarController`（聚焦、选区记忆与恢复、动作执行、激活态）、`toolbarActions.ts`（纯 Slate 操作）、`useKeyboardViewport` / `--kb-height`、`useKeyboardAutoReveal`、内核 `EditorMenuEntry` 与 `blockPanel` 数据。

## 2. 交互方案

### 2.1 配件栏（mockup「方案 A」）

- 46px 高，贴住键盘上沿（`bottom: var(--kb-height)`），无间隙、无圆角阴影；键盘收起即消失。
- 左端固定「+」（插入），右端固定「收起键盘」；中段默认：Aa、待办、无序列表、反缩进、缩进、关联卡片、图片、撤销，可横滑，后续支持用户自定义。
- 加粗、斜体等行内格式不在一级，选中文字时配件栏切到格式模式（2.3）。
- 闪卡等轻量场景继续用 `visibleButtons` 白名单。

### 2.2 面板占用键盘位置（mockup「方案 A」A2/A3）

- 点 Aa 或 + ：收起键盘，在原键盘位置升起同高面板，正文可视区不变；按钮切换为「键盘」，点它或点正文回到键盘。
- 面板高度 = 最近一次测得的键盘高度，首次无值时取视口 38%。
- Aa 面板：转换为（横滑排版预览）/ 行内样式（44px 分段按钮）/ 文字颜色与高亮（两行色点）。低频样式进二级页。
- - 面板：搜索、最近使用、分组宫格（基础 / 媒体 / 高级 / 插件），数据来自 `blockPanel` 经移动端能力白名单过滤。
- 有选区时样式作用于选区；面板打开期间光标静态显示。

### 2.3 上下文配件栏（mockup「上下文工具栏」）

优先级：选中文字 > 插件块 > 表格 / 代码块 / 公式 > 通用。左侧出现上下文标签，点它退回通用模式。

- 选中文字：B / I / U / 删除线 / 高亮 / 链接 / 批注 / 行内代码，右端 Aa。不自绘选区气泡，系统菜单保留。
- 表格：下方插行、右侧插列、删行、删列、对齐、⋯。
- 代码块：语言芯片 + 按语言给出的符号键（Tab 缩进，长按反缩进）。公式块同理并实时预览。

### 2.4 阅读态（mockup「阅读态」）

- 打开已有文档默认阅读态：无光标、键盘、配件栏、块把手。单击只做阅读交互（链接、待办勾选、大图、展开折叠）。
- 进入编辑：双击正文（光标落在双击处，滚动使该行保持原屏幕位置）或顶栏「编辑」（光标回上次位置，没有则在末尾）。
- 退出编辑：顶栏「完成」或配件栏「收起键盘」。只滚动不退出；Aa / + 面板打开时仍算编辑态。系统返回直接返回上一页。
- 阅读态选中文字：保留系统菜单，底部浮出标注条（高亮、批注、摘录成卡片、关联卡片），不进入编辑。
- 顶栏「⋯」：查找、目录、选择块、整理结构、「打开文档时」偏好（阅读态 / 直接编辑）。
- 默认状态：已有文档 → 阅读态；新建卡片、快速记录、空文档 → 直接编辑；协作只读、冻结、跨端降级 → 阅读态且隐藏「编辑」；闪卡复习 → 阅读态；编辑中切后台再回来 → 保持编辑态。

### 2.5 块操作（mockup「块操作」）

- 光标所在块左侧常驻把手（20×26，热区 32×40），其他块不显示。点把手 = 选中该块；长按 300ms = 提起拖拽。
- 块选择模式：收起键盘，顶栏「取消 / 已选 N 个块 / 全选」，其他块显示勾选框可多选；底部操作栏：上移、下移、转换、复制、删除、更多。按钮来自 `EditorMenuEntry`（按 `when` 过滤），「更多」用 `ActionSheet` 渲染完整菜单树（插件项单独分组）。系统返回 = 取消。
- 拖拽：Pointer Events 自实现，落点计算复用内核拖拽逻辑；插入线、边缘 64px 自动滚动、触感反馈。
- 整理结构：底部 Sheet 中每块一行，右侧把手重排；标题可折叠，折叠后整节移动；完成后作为一个撤销步提交。

### 2.6 插件位（mockup「插件位」）

插件只贡献数据和命令，摆放由宿主决定：

| 位置                 | 插件提供                    | 状态     |
| -------------------- | --------------------------- | -------- |
| 配件栏可固定项       | `commands`（需新增 `icon`） | 小扩展   |
| 插入面板「插件」分组 | `blockPanel`                | 已有     |
| 块「更多」菜单       | `menu`                      | 已有     |
| 插件块上下文配件栏   | `commands` + `when`         | 只留位置 |

移动端宿主内部把内置动作与插件命令统一成一个工具栏项模型（id、title、icon、slot、when、run、source），UI 不区分来源。本任务不实现移动端插件运行时，只保证 UI 有位置、数据模型能接入。

## 3. 技术验证（第一阶段）

先在真机上验证三个风险点，结论决定 2.2 / 2.4 的实现方式。验证用开发构建内的实验页（仅 `import.meta.env.DEV` 注册），不进生产。

| 编号 | 验证内容                                                                                                         | 通过标准                                                             | 不通过的退路                               |
| ---- | ---------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- | ------------------------------------------ |
| V1   | 键盘高度来源：`__TAU_NATIVE_KB_HEIGHT` 是否有注入方；visualViewport 推算值是否准确，切换输入法、候选栏时是否跟随 | 测得高度与实际键盘一致，误差 ≤ 2px                                   | 补原生注入（Android `WindowInsets.ime()`） |
| V2   | 面板 ↔ 键盘互换：blur 收键盘的同时升起同高面板；点「键盘」聚焦并恢复选区                                         | 正文不跳动；选区恢复到原位置；中文输入法组合中切换不丢字；无明显闪烁 | 面板叠在键盘上方，限高 180px               |
| V3   | 只读 → 编辑：双击时在同一手势内同步切换只读并聚焦，光标落在双击处                                                | Android 与 iOS 都能弹出键盘，光标位置正确                            | 阅读态保持可编辑，改为拦截单击聚焦         |

另外记录：只读状态下待办勾选、链接点击是否可用（影响 2.4 单击行为的实现量）。
