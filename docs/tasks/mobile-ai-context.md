# 移动端 AI 就近提问（第三期）

状态：进行中
目标：在卡片、文章、日记、项目文档里看到就能问——选中文字提问 / 解释、顶栏 ✦ 带整篇提问，以半屏对话承载；对话里可 @ 引用笔记、拍照提问。

## 需求

- **选中提问**：阅读态选中文字后，底部标注条（`ReadingSelectionBar`）新增「问 AI」。点按打开半屏对话，选中文字作为引用出现在输入框上方，可直接输入问题；输入框为空时给出「解释这段 / 总结这段 / 翻译这段」快捷问。
- **整篇提问**：内容页顶栏加 ✦ 按钮，打开半屏对话，当前笔记整篇作为引用。
- **半屏对话**：底部抽屉两档（约 55% / 全屏），下拉关闭；头部「关于这张卡片 / 这篇文章…」+ 「展开为全屏对话」+ 关闭。同一篇内容再次打开时续上最近一次就近对话（同一 `domainRef`）。展开为全屏即推入 `aiChat` 页，会话不变。
- **引用**：用户消息上方显示引用条（被选中的原文，最多两行；或「整篇：标题」）。引用随消息进入模型上下文：选中文字以原文给出，整篇只给标题与 contentId，模型按需调用 `get_content_markdown` 读取。
- **@ 引用笔记**：全屏与半屏输入框都可点 @ 按钮（或输入 `@`）搜索卡片、文章、日记、项目文档，选中后成为输入框上方的引用条，可删除。
- **拍照提问**：输入框 ＋ 打开面板：拍照、相册、引用笔记。选中图片压缩为 data URL 作为图片附件；当前模型不支持图片时置灰并提示换模型。
- 对话记录里就近对话显示来源（「来自 · 间隔重复为什么有效」），点来源回到原内容。
- 视觉以 `apps/mobile/mockups/ai-mobile/` 第 2D、4（长按以外）、6 帧为准。
- 实现取舍：全屏「展开」时若这段就近对话还没发过消息，打开一个普通新对话（没有可延续的会话）；按 contentId 直入的详情页只有日记能确定身份，其他来源（如正文待办跳转）不挂就近提问。

本期不做：长按消息动作面板（存为卡片 / 追加到日记）、分叉；正文改写工具；编辑态的选区菜单（编辑态已有配件栏）。

## 方案

- **引用的数据形状**：沿用 chat-core `TextContent.mentions`（`MentionRef`：entityType / entityId / contentId / title / previewText）表示 @ 与整篇引用；选中文字是一条 `previewText` 为原文、带 `quote: true` 的引用。发送时 `message` 为 `[{type:"text", text, mentions}]`（图片另成 `{type:"image", image: dataUrl}`）。
- **进入模型**：移动 `MobileAiService` 的 `prepareInput` 把 mentions 展开成正文前缀（`<引用 type=card contentId=12 title="…">原文</引用>`），模型文本里因此带上下文；会话的 display 条目保留原始 `message`，历史投影仍显示用户原话与引用条。桌面无 prepareInput 时 mentions 不入模型——与桌面现状一致，不改桌面。
- **会话作用域**：就近对话 `scope = "content-chat"`、`domainRef = "content:<contentId>"`；全屏对话记录同时列出 `main-chat` 与 `content-chat`，后者显示来源。
- **半屏**：`SnapSheet`（states `normal` / `full`），内部复用第二期的 `ChatMessages` / `ChatComposer`；控制器（`chatController`）按 sessionId 共享状态，从半屏展开到全屏不打断运行。
- **入口装配**：`ContentDetailPage` 增加可选 `aiContext`（kind / id / title），由各宿主页（卡片、文章、日记、项目文档）传入；未配置对话模型时 ✦ 与「问 AI」仍显示，点按进入引导。
