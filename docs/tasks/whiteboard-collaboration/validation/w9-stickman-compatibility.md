# W9 火柴人候选组合验收

日期：2026-10-25。范围：火柴人现有功能接入冻结的新白板契约，以隔离候选 SDK、插件实际构建产物、宿主绑定和本地 Node 服务构建验证。没有修改桌面产品 UI、增加插件 API、增加恢复包或执行真实迁移、发布、部署。

## 实现与边界

- 插件 ID `taunote.stickman`、元素 type `taunote.stickman.figure` 以及 pose/body/tint/flip 业务字段保持不变。元素声明改为 `dataVersion: 1`，创建结果不再夹带旧 schemaVersion。pose 是姿态枚举，不是协作文本；文本字段和资源声明均为空，没有制造不存在的能力。
- 属性栏保留原控件与布局，数据动作改用稳定 ID 和普通字段补丁，不再提交整份旧元素。远端期间修改的姿态、位置和未知载荷不会被旧面板快照回写覆盖。
- 换姿态读取当前几何，以一次 submit 同时修改尺寸/位置和 pose，共用宿主一条历史；保留旋转、其他业务字段和未知数据，不建立插件独立撤销栈。
- 原笔触功能通过 style.sketchMode/sketchLevel/sketchSeed 保存，渲染还原 ElementSketch 后继续调用宿主 useSketch。只提交用户改动的笔触项；null 表示移除该项覆盖、跟随页面，不覆盖其他样式或远端新种子。没有增加新的画风或控件。
- 工作区偏好仍使用 IPluginStorage，不进入共享文档或文档历史。读取失败不生成节点，插件失活后的迟到创建由现有宿主作用域守卫丢弃；偏好写失败仍沿用原错误反馈与后续重试。
- 新版 schema 校验保留未知字段，声明准备和安装不执行数据迁移。缺失插件时文档继续按存储契约保真；重新装配须精确匹配契约摘要。

**旧快照限制没有扩大**：schemaVersion 不是新 dataVersion 的历史契约。现有显式旧快照转换将无法识别的旧人物保留为原载荷占位，包括未知字段与笔触；不会因为安装此候选插件就自动变成可编辑人物。本轮补了严格保真断言，没有新增旧人物专用转换器。这里沿用的 `host.whiteboard.recovery` 是已有未知载荷占位类型，不是恢复包。

代码事实分别位于 [作者声明](/plugins/tau-plugin-stickman/src/index.tsx)、[身份命令](/plugins/tau-plugin-stickman/src/commands.ts) 和 [插件兼容说明](/plugins/tau-plugin-stickman/COMPATIBILITY.md)。

## 候选版本与依赖

插件代码候选标识为 `0.1.11-rc.0`，desktop 最低版本暂设为源码候选 `0.59.5`，以阻止旧宿主装载新接口。此下限不是对正式桌面发行物的认证。未修改 SDK 包版本、正式 npm 依赖或 pnpm-lock.yaml 中的 registry 记录。

正式 SDK 0.44.0 仍缺新白板接口；插件仓库记录的 SDK 0.42.0 也无法编译当前新源码。因此不能直接用正式旧依赖发布此候选；独立测试可运行，类型与打包必须使用隔离候选环境。正式 SDK 发行后仍要更新真实依赖、锁文件并重验，不用本地同号包掩盖差异。

## 可复现的组合验证

在主仓库执行：

```sh
node scripts/plugins/verify-stickman-collaboration.mjs
```

[验证脚本](/scripts/plugins/verify-stickman-collaboration.mjs) 在系统临时目录生成 SDK tarball，复制作者源码后只在副本中注入候选依赖；独立安装后运行 `pnpm test`、`pnpm build`（包含 TypeScript 检查）。它核对 SDK 实际解析到隔离作者目录，且仓库 package.json、manifest.json 和锁文件未被脚本改写。SDK 运行时由宿主提供，测试求值的是实际插件 main.js；没有把插件源文件通过 workspace alias 冒充已构建产物。

随后构建 Node 服务，启动实际 `dist/index.js` 子进程，使用随机回环端口和临时数据库。测试真实 HTTP 接纳、操作回执及状态读取；结束后关闭服务并删除临时数据库。插件 ZIP、SDK、组合报告留在脚本输出的临时验收目录，未安装到 Tau 用户目录、未上传。

宿主画布绑定来自工作区源码，运行在无视觉验收的测试环境；本轮不是 Electron 原生安装包验收。Worker 运行既有本地模拟器回归，未宣称把同一插件 ZIP 对接过线上 Worker 或完成真实重新部署演练。

组合断言覆盖：

- 实际候选包清单和内容完整性、旧宿主拒绝、静态契约的空文本/资源声明。
- 异步创建的样式偏好、单次历史、创建撤销重做的身份稳定。
- 旧面板动作保留远端未知字段和移动；换姿态整体撤销不撤销远端修改。
- 三端独立属性/笔触，乱序重复全状态更新收敛，删除后撤销保留载荷。
- 缺插件保真、跨页身份不变、重新装配精确契约；旧快照原载荷保留。
- 权限失效拒写且字节不变；异步失活/读取失败不生成节点；笔触撤销恢复覆盖状态。
- 实际 Node 构建接纳插件生成的文档、操作幂等回执、旧协议拒绝、错误 epoch 的 ABORTED/EPOCH_CONFLICT 回执及服务修订不变。
- 新人物的后继增量先于创建到达时返回 MISSING_DEPENDENCIES，回执仍为 PENDING，状态及序号不变；补齐创建后重试原操作才 COMMITTED。

候选插件类型检查/构建、Node 构建、Worker 两配置本地 dry-run、白板边界和插件进程边界检查通过。作者文档同步及限定路径 diff 检查通过；`pnpm check:docs` 通过（227 个 Markdown，0 警告）。

初次试跑暴露了类型标注、独立测试根的 Slate 解析、jsdom 与 Node Buffer 的实例域差异，以及将业务 ABORTED 错当 HTTP 409 的测试假设；均在本轮修正后完整重跑。保留 epoch 拒绝原因、服务序号和原数据不变等严格断言，没有修改服务行为来迎合测试。
