# W9 联合验收与发布准备

## 发布门禁

| 项目                   | 当前结论                             | 放行判据                                                                                                                                                                              |
| ---------------------- | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 现有语义及容量边界     | 由最终自动化结果确认                 | 全部相关回归通过，失败原因有据；不得删数据或放松断言                                                                                                                                  |
| Presence               | 本轮修复 UTF-8 字节计量              | Node 与 Worker 使用同一检查；多字节边界和 600 次限额有测试                                                                                                                            |
| 普通用户的远端协作入口 | 已接线，有自动化证据；待目标设备验收 | 见下方「入口接线」。publish/resume/cancel、remote-install、remote-open/sync、adopt（含 rebuild）、unshare、migration-source/prepare/finish、legacy-convert 均有界面消费者             |
| 高负载可用容量         | 不放行“5000 元素流畅编辑”承诺        | 根据实测延迟与目标设备交互验收确定可用规模；不把编码状态大小当成堆内存或界面帧率                                                                                                      |
| 发行版本与兼容性       | 阻断，已核对正式产物                 | 正式 SDK 0.44.0 缺少新白板接口；公开桌面更新源为 0.59.0；火柴人 0.1.10 仍为旧声明；活动 Worker 尚缺本轮构建对应证据。最低组合和证据见 [正式版本兼容核对](w9-release-compatibility.md) |
| SDK 与模板文档         | 本地验证                             | 主文档与模板同步，tarball 仓库外编译、首个完整作者示例、冻结类型夹具及模板构建通过；后续 [火柴人候选组合验收](w9-stickman-compatibility.md)补齐实际作者插件适配与本地服务构建联验     |
| 真机与视觉             | 待用户验收                           | 按项目规则由用户检查目标桌面系统的输入、拖动、媒体与关闭/重开                                                                                                                         |
| 实际发行操作           | 未授权，未执行                       | 另行确认真实数据迁移、SDK 发布或部署                                                                                                                                                  |

普通产品入口、版本与设备门禁未满足前，不宣布整体发布验收通过。W9 首轮只记录缺口；入口接线在后续一轮完成（下节），版本与设备门禁仍未满足，任务继续保留。

## 入口接线

三类结论分开记录，不互相替代。

**已完成接线且有测试证据**（`whiteboard-documents/__tests__/collaboration-flow.test.ts` 用真实服务端路由跑两台设备；渲染端为 `services/whiteboard-documents/__tests__/remote.test.ts` 与 `features/whiteboards/__tests__/DocumentBoardCanvas.test.tsx`）：

| 流程                               | 证据                                                                                                                                                                                                 |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 首次共享、重复发起、响应丢失后续做 | 只建一个房间；结果未知期间暂停写入并拒绝另起操作；publish-resume 按原操作完成，已绑定后再发起直接拒绝且不冻结视图                                                                                    |
| 成员打开与双向同步                 | remote-install 幂等落库；本机保存与远端确认分开显示；远端投影只推进一次本机修订、再同步不提交                                                                                                        |
| 断连、关页与多窗口                 | 断网报 OFFLINE 并自动退避；释放租约后重开仍从本机日志补交且只提交一次；同设备两窗口并发同步只提交一次，关闭一窗不影响另一窗                                                                          |
| 缺依赖不误确认                     | MISSING_DEPENDENCIES 保持待确认，远端序号不前进                                                                                                                                                      |
| 权限、版本、换代                   | 权限撤销与版本不兼容只报原因、本机内容不变；远端换代后旧代次编辑不重投，采用新版本后旧日志保留并恢复同步；这些状态不自动重试                                                                         |
| 旧格式转换                         | 安装失败原内容不变，同一操作续做；缺失插件数据保真                                                                                                                                                   |
| 投影不回写、不双记历史             | 主进程远端投影不再提交；渲染端远端事件不进 outbox 沿用 client.test，宿主单次历史沿用 B28                                                                                                             |
| 结束共享与再次共享                 | 断网时结束失败、绑定与内容不变；成功后房间关闭、本机留下取回他人确认编辑的本机白板，远端入口拒绝；成员同步报共享已结束并可转为本机白板；再次共享建新房间、旧房间保持关闭                             |
| 成员退出                           | 退出前补交本机编辑，作者房间保留改动且成员失去权限，成员留下本机白板                                                                                                                                 |
| 资源转存                           | 托管图片转存为本机引用；仍有权限时下载失败不结束共享；失去权限时只用缓存、缺失引用保留并计数；缺失插件载荷保真（unshare.test）                                                                       |
| 被拒分支重建                       | 暂停同步；换代采用不能处理同代次被拒；以协作端版本重建后继续同步，被拒材料仍在网络分支                                                                                                               |
| 插件数据升级                       | 冻结来源后中断：白板暂停打开、状态报告待续、可不经画布读回来源；按原操作完成后房间换代，作者继续同步、成员收到采用新版本；只转换同插件可直接转换的旧版本元素，缺失插件保持原样（collaboration.test） |
| 轮询开销                           | 远端未变化时只请求确认摘要，不下载完整状态                                                                                                                                                           |

**正式发行版本兼容仍待确认**：上表基于仓库内 Node 服务实现；Worker 正式实例、已发行客户端与新入口的版本组合未验证，发行版本号与最低宿主版本仍按「发布门禁」确认。

**目标设备视觉与体验仍待用户验收**：状态行、共享对话框、成员面板（含结束共享/退出协作）、协作页白板条目、各确认框的外观，以及真实网络下的轮询延迟与弱网体验，由用户在目标桌面系统验收。远端有变化时仍下载完整状态，大白板多人同时编辑时的流量与比对开销须实测。

## 测量口径

容量用例分别覆盖 64 页/5000 元素、1024 富文本根和接近 8 MiB 的实际编码状态；各上限不同时耗尽。长会话执行三端 3600 轮、7200 次主要事务，包含逐条乱序/重复投递、双删双撤和 30 次副本重开。副本通过二进制状态重建，投递在内存中模拟；真实网络连接由既有 Node/Worker 回归另行覆盖，不能把本用例当成 30 次实际网络重连或数小时弱网体验。

延迟来自 Node 单进程测试；RSS 包含测试框架、所有副本及垃圾回收影响，不是单文档堆预算。命中与 React Profiler 使用现有基准，Profiler 不构成视觉验收。试跑中的测试比较方式、超时与重新执行情况随结果记录，未完成的试跑不计为通过。

可执行的检查步骤见 [发布前检查](/docs/guides/ops-whiteboard-release.md)。本文件不提供发布、部署或真实迁移命令。
