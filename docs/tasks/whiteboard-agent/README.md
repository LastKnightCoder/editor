# 在当前白板与 Agent 共同编辑

当前白板读写和本轮故障压测已完成，完整性能矩阵及实际设备交互验收待执行。目标是在桌面左侧打开白板后，直接在右侧对话里请 Agent 画图、改字或整理选中的元素。用户能看见它正在处理哪里，在它工作时继续编辑，关闭再打开也能看到已确认的结果。

## 首版体验

例如，用户选中两个框，在右侧说「中间加一个校验步骤，连起来」。Agent 读取选区与相邻连线，按当前写入权限提交一个批次。左侧原位出现新节点和连线，并短暂标出 Agent 正在处理的对象。用户的视口、选区、输入焦点和撤销记录独立。较长的工作按有意义的小批次逐步呈现，每批完成就可见。取消保留已经完成的批次，聊天列出已完成与未完成的部分。

建议首版覆盖桌面白板详情和独立单页画布中的托管白板，包含本机白板和已有共享白板。本机白板无需建房或联网；这里的离线能力指白板写入，所选模型的联网需求单独计算。右侧使用应用内置 MCP 工具，目标限定在发起指令的窗口与白板页。其他设备按现有机制收到共享内容；有名字的 Agent 在场提示首版仅在本机同页展示，与正文一致。外部 MCP 客户端、跨设备 Agent 身份、后台无人打开的白板编辑可另行评估。

第一版使用当前元素契约可以表达的操作。内置文字的纯文本编辑须保留其绑定，富文本仅在支持保留未涉及的节点、格式和身份时开放对应操作。插件未知载荷原样保留；删除包含未预期子树或连线的对象须重读并明确影响范围。白板上的文档卡只描述引用，改卡内原文另走已有正文工具及权限。Agent 在场由工具调用自动驱动。

## 提交与并发

[查看一次写入从右侧到左侧的流程图](./write-flow.html)

```text
在用户发送消息时捕获窗口、资料库、文档来源、基线、epoch、页与视图代次
读取当前页，将选区和可见范围转换为稳定元素 ID，记录本次修改依赖的字段
执行写工具前按现有权限处理；若需用户确认，先展示操作和目标页
在原文档写入队列中：
    核对调用者、目标身份与请求摘要，已有耐久回执则返回原结果
    核对页仍有效、当前可写、运行未取消、相关字段与交互前提仍成立
    在候选模型校验整批语义操作，生成一次增量
    同一日志事务保存增量、请求摘要、生成的 ID 与修订
    复用既有投影、广播与共享发送，按实际提交阶段返回结果
左侧应用该修订，绘制新内容；共享设备按自己的接收与确认进度更新
```

- **目标绑定。** 对话获焦不使左侧画布失活。等待模型、审批或队列时切页、关板、切库或换代，未提交调用返回目标失效；下一轮重新捕获。执行层用宿主提供的身份，页句柄不能跨窗口、会话或资料库使用。
- **人机同时编辑。** 更新位置仅依赖读过的位置，改文字仅依赖读过的文本范围；无关字段允许合并。同一位置被拖动、文字正在组合输入、连接端点被删、删除范围改变时，返回具体冲突。实施时把未提交输入或手势纳入本机画布的冲刷或占用检查。远端离线并发仍按现有 CRDT 语义合并，冲突提示只能基于已观察状态。
- **幂等与恢复。** 以文档代次、调用方和稳定请求 ID 查找语义回执；回执摘要绑定操作及前提。同键同载荷返回原始元素 ID 和修订，异载荷拒绝。重试从持久回执恢复，避免重新生成不同的 CRDT 更新。日志已提交但主库投影失败，返回「已记录、待恢复」，保留原请求；投影追平后才报告本机已保存。已知提交后收到取消时返回实际完成情况。
- **身份与历史。** 本地 Agent 使用独立操作来源；同名并发运行按运行实例区分。忙碌或等待时显示身份与目标，结束、取消、窗口关闭或超时清除。在场失败允许内容照常提交。用户撤销只处理自己的历史。共享端从已有授权设备接收内容，沿用既有断线对账与被拒分支保全；聊天分别显示本机保存和远端确认。

## 实施顺序与退出条件

1. **打通一条真实链路。** 捕获活动画布，接入工具、Agent 身份和单个内置形状创建。隔离库里从真实右侧对话发指令，左侧无需刷新即可见；落盘重开后能按回执 ID 找回同一对象。
2. **完成批量编辑。** 接入分页读取、文字、几何和连线，补齐权限确认、作用域失效、字段冲突、候选原子提交和语义回执。以「选两框 → 插步骤并连线」作为贯通样例；执行失败的批次须保留此前双方的有效编辑。
3. **接通共享与恢复。** 用第二个桌面客户端核对白板内容；演练断网、重连、回执丢失、撤权与崩溃。核对人机撤销隔离、在场生命周期和共享确认状态。
4. **测量并放行。** 在固定构建执行下列矩阵，解决正确性失败、瓶颈或明确缩小首版支持范围后复测。实现同期更新桌面白板与 AI 架构、官网白板与 MCP 使用文档，按项目约定做结构、类型和站点对账。

## 压测与验收

在隔离资料库和本地协作服务执行。普通使用路径用真实对话和目标模型冒烟；高频测试用可复现的工具调用驱动同一注册表、权限、生产 IPC、SQLite、画布订阅及共享服务。模型思考时间与工具执行分开计量。表中时延是验收目标，已运行的实测口径见文末。

| 场景           | 工作负载与故障点                                                                                                                                                             | 通过条件                                                                                                                                                                              |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 真实桌面闭环   | 同窗口左右分栏，未共享、已共享分别走一轮；创建、连线、改字、整理选区、取消。再打开第二窗口同页和另一页                                                                       | 首批在聊天结束前显示，结果无需刷新。读写与 Agent 标记只命中目标页；用户验收输入焦点、中文输入、缩放、名字和选框，重开按 ID 核对                                                       |

**核对方式。** 驱动端独立记录请求、预期元素 ID、字段值和端点，不从生产模型复制期望值。每轮排空后比对左侧画布、同页另一实例、重开后的主库，以及共享端的规范化投影；按请求核对耐久回执、修订和主库关系。仅比较两端相等无法发现两端一起丢数据。错板、已确认操作丢失、重复提交、越权、部分提交和静默覆盖已观察的人类修改，任一例都阻断放行。

**采样与报告。** 用运行 ID 和操作 ID 贯穿工具获准、入队、日志、投影、广播、画布提交及远端确认。双客户端由同一测试驱动使用单调时钟测量发起至收到渲染确认，分进程阶段各用本地耗时。另测人在画布拖动的响应时间，与同机同板关闭 Agent 时比较，建议 P95 劣化不超过 20%。每轮记录提交号、构建、设备、种子、网络、操作分布、样本数及 P50/P95/P99。超时进入失败统计，预期拒绝单独计数。环境门控跑容量和长稳，常规测试只收确定性的行为契约。
