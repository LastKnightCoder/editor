## 内容插件 codec 的执行边界（本轮不处理）

- codec 是编辑器内容与 Markdown 等格式之间的转换器，与同步存储五方法没有直接关系。
- 当前主进程 `services/plugin-codecs.ts` 会求值内容插件，`index-content.worker.ts`、`publish-generator.worker.ts` 也加载插件转换实现。
- 搜索、正文分段、内容查询、全文/向量索引和发布搜索索引还存在同步转换消费者。直接删除主进程注册会丢失插件转换语义，不能这样修。
- 后续单独核查：将插件转换移到渲染进程，主进程只消费结果；保持文档、博客、Markdown往返、搜索及索引结果不变，不新增render.js、转换缓存或后台窗口。
- 用户已明确本轮不改codec。当前同步纠偏不包括上述内容转换链路，也不能因此宣称全部历史插件Node执行路径已清零。
- 详细消费者清单见 `docs/plugin-system/55-插件渲染进程边界纠偏.md`。
