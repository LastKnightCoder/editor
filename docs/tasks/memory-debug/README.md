# 个人记忆实时调试

状态：进行中

目标：在开发工具中查看真实的记忆处理进展、近期状态、长期画像及其依据，无需手动刷新。

## 需求与方案

- 入口属于现有开发工具注册表，不恢复普通设置中的记忆管理，不提供修改或删除操作。
- 使用现有非模态 Drawer，可在其他页面操作时保持实时观察，沿用 @tau/ui、主题和浮层退出约定；视觉验收由用户进行。
- 主进程按来源扫描、提炼、归纳、全面复核、提交、失败和向量处理的真实生命周期报告状态；只在开发环境注册只读诊断接口。
- 快照包含当前库、暂停原因、进度计数、下一次处理/归纳/复核时间、最近模型和经历。详情按需核对证据。数据列表有界，展示数量明确；不加载整个历史大表。
- IPC 订阅绑定窗口、库连接和独立订阅 ID，关闭/切库/销毁解除；推送合并到短时间窗口，版本号防止初始快照覆盖较新的推送。
- 数据经 react-query 缓存，事件更新缓存；不用手动刷新或定时轮询。状态与内容版本分开，只有内容变化才更新已展开的证据详情。
- 诊断只读，不触发提炼、索引重建或过期整理，不输出模型请求、密钥或持久化调试日志。
