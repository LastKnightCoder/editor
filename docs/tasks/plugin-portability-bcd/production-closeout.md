# 桌面与 Android 正式安装闭环

目标：沿用现有 SDK/API，交付桌面和 Android 正式包，并用生产插件中心完成页面与六个编辑器插件的下载、安装、激活和重启恢复验证。

## 范围与决策

- 用户授权修复中心校验、正式打包、发布本轮对应插件及必要的中心改动，完成后提交。
- 不扩展 API、不添加兼容层；SDK 0.37.0 已发布，不重发该版本。
- 所有官方插件已升级 SDK；本轮移动功能范围为普通页面和六个编辑器插件，不扩展其余桌面业务插件的移动宿主能力。
- iOS 正式包继续等签名，D 的最低系统、真机、平板、性能和同步验收保留。独立验证应用不能代替正式包验收。
- 视觉验收由用户完成；本轮执行类型、行为、构建、原生安装及持久化检查。
