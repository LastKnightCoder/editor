# 桌面与 Android 正式安装闭环

目标：沿用现有 SDK/API，交付桌面和 Android 正式包，并用生产插件中心完成页面与六个编辑器插件的下载、安装、激活和重启恢复验证。

## 范围与决策

- 用户授权修复中心校验、正式打包、发布本轮对应插件及必要的中心改动，完成后提交。
- 不扩展 API、不添加兼容层；SDK 0.37.0 已发布，不重发该版本。
- 所有官方插件已升级 SDK；本轮移动功能范围为普通页面和六个编辑器插件，不扩展其余桌面业务插件的移动宿主能力。
- iOS 正式包继续等签名，D 的最低系统、真机、平板、性能和同步验收保留。独立验证应用不能代替正式包验收。
- 视觉验收由用户完成；本轮执行类型、行为、构建、原生安装及持久化检查。
- 用户随后决定接手剩余交互验收。Agent 停止手动测试，只整理交付、保留未验收项并提交，不将移交视为全部通过。

## 用户验证步骤

1. 安装对应客户端；Android 使用本次 APK，macOS 按芯片选择 DMG。
2. 桌面进入侧栏「插件」；Android 进入「我的 → 插件中心」。安装或更新计数器 1.2.0、ABC 0.1.7、HTML 0.1.6、自定义组件块 1.0.9、TikZ 0.1.6、Typst 0.2.2、图册 0.1.2；桌面安装后主动启用，再完全退出并重启。
3. 页面入口：桌面侧栏与 Android「我的」打开计数器，增加保存，重启后检查计数。
4. 在正常卡片或文章插入上述编辑器块，检查源码编辑、预览、保存和取消；React 点组件按钮，图册添加两张图片并排序。
5. 完全退出后重新打开，确认正文、源码、图册顺序及计数保留。记录平台、插件版本、复现步骤和期望结果，后续据此修复。
