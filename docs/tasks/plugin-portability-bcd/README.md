## 技术方案

### B：桌面与公共交互

在 DesktopPluginRuntime 接入环境源和语义入口，复用真实 Page 与 Sidebar。页面、静态正文和独立内容渲染作用域提供明确环境。页面守卫、资源回收和 UI 浮层通过平台中立适配接入现有导航仲裁；公共包不依赖应用。新格式只走显式开发加载，旧格式和生产目录协议不变。

### C：移动页面与持久化

正常 AppShell 工作区生命周期创建独立移动宿主，先恢复包事务与冻结内容快照，再装配编辑器与激活页面。“我的”显示语义入口，通用插件页和设置页使用移动 definePage、返回仲裁与查询协议。Rust 在应用私有目录校验、暂存、提交、取消与恢复包文件，不执行 JS；设备本地保存启用意图。私有数据复用当前工作区 plugin_kv，切库失活及数据库身份检查阻止迟到写入。

### D：正文与整体回归

普通正文和预览使用同一内容快照与 codec，Kit 缓存包含会话身份；内容更新在新会话生效。插入动作恢复选区，标准源码组件适配移动返回与保存，写入端与 UI 同时执行只读等级。审计搜索、导出等派生消费者，保全未知节点原文。以同一计数器和 ABC 包验证真实三端入口、数据往返、隔离和异常恢复；模拟器结论不代替最低系统及真机验收。
