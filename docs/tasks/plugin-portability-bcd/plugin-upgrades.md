## 技术方案

使用已发布 SDK 0.36.0 / UI 0.4.0 进行仓库外构建。ABC 已采用格式 3，桌面最低 0.59.1、Android 最低 0.2.2，共用静态节点、codec 与标准触摸源码编辑器。其余插件本轮先升级公共依赖和兼容代码，保留格式 1：HTML/自定义块的动态样式、图册媒体能力尚有移动缺口；TikZ/Typst 具备浏览器编译器，但还要保留 Skill 与博客能力，不能简单改格式造成退化。业务提供方和白板保留桌面能力。

所有待升级仓库从 GitHub main 独立克隆，最终位于 `/Users/t.xiong/Desktop/projects/tau-plugin-upgrades-20261023/`，分支均为 `codex/sdk-0-36-upgrade`。未放在主仓库内部，避免没有 Vitest 配置的插件向上误用宿主测试配置；不覆盖用户已有本地较旧副本或未提交改动。tau-plugin-example 是本地旧计数器，存在用户未提交源码，不覆盖，当前统一模板已提供升级后的计数器。

## 升级与移动适配的区别

用户追问“这些插件不需要修改就可以跑在移动端吗”后已明确说明：本轮完成依赖兼容升级，不代表已经移动适配。新增平台必须同时完成清单、宿主能力、作者交互和对应设备验证，不能仅提高 SDK 版本。

| 插件                                     | 当前移动结论                                | 下一步必需工作                                                                       |
| ---------------------------------------- | ------------------------------------------- | ------------------------------------------------------------------------------------ |
| ABC                                      | 同一格式 3 包已支持桌面与 Android           | 维持已发布 0.1.6；iOS 等签名与正式发行验证                                           |
| TikZ                                     | 浏览器编译器可复用，仍为桌面包              | iframe/Blob/WebAssembly、取消、内存验证；保留现有 Skill 和博客能力的分发协议接入     |
| Typst                                    | 浏览器 WebAssembly 编译器可复用，仍为桌面包 | 手机首次约 32 MiB 下载、缓存与内存验证；保留 Skill、博客缓存与导出的分发接入         |
| HTML                                     | 源码节点与 codec 可复用，仍为桌面包         | 移动运行时 Tailwind、行内输入/浮层/返回；Skill、博客样式能力的分发接入               |
| 自定义组件块                             | 节点与源码编辑器可复用，仍为桌面包          | 运行时 Tailwind、Worker、组件窄屏/触摸与资源预算；保留 Skill/博客                    |

| 问题管理、微信读书                       | 移动业务 API 尚未齐备                       | 实体/集合/正文/授权或摘录/材料/网络能力及页面交互；单改 navigation 不足以运行        |
| 同步、上传、发布、图片、语音、视频提供方 | 移动领域提供方 API 未接                     | 宿主注册、领域设置、原生网络/媒体能力与资源生命周期；内置移动同步中心不是插件宿主    |

## 本轮验证结果

- 22 个仓库使用公开 npm 依赖，仓库外冻结安装与 TypeScript/构建全部通过；21 个定义测试脚本的仓库合计 162 项通过。火柴人无自动测试脚本，不能写成测试通过。
- Typst 默认测试跳过的 2 个网络引擎用例，另以 TYPST_E2E=1 执行通过；真实下载编译器/字体并产出含中文、公式与表格的 SVG。合计执行 164 项插件测试，不能外推为手机 WebView 验收。
- 22 个最终 ZIP 通过生产中心 inspectPackage 的清单、路径、文件数、大小及完整性校验；22 个包通过桌面实际 shared modules 求值。编辑器包静态贡献存在，custom-block/TikZ/Typst 和块级 HTML 样例通过真实 Markdown 处理器。
- HTML 继续遵循原生 Markdown 的 HTML 语义：行内标签与块级标签会按 Markdown 规则重新解析，不承诺任意 HTML 的节点形态完全不变；未为本轮依赖升级擅改既有格式。
- 移动类型检查、全量 722 项测试、Rust 96 项测试、Vite 构建通过；合并范围 ESLint 0 错误，保留 73 条存量警告。未重新生成 APK/IPA，上一轮 APK 不包含本次同步中心提交。
- 验证日志、临时产物检查脚本及逐仓 SHA-256 位于本 worktree 的 output/plugin-upgrades。初始将 clone 放在主仓库下导致 Vitest 向上读错配置，移出后独立复验通过，没有为此更改插件依赖。
- 仅合并已提交的 master；主工作区正在进行的资源 UI/上传等未提交改动不在本轮合并范围。D 的真机、最低系统、视觉、输入法、性能、实际同步冲突及 iOS 签名项继续保留。
