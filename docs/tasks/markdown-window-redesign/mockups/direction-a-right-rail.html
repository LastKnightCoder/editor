从碎片到体系：我的知识管理工作流

过去两年我试过不少笔记工具，最后留下来的不是某个 App，而是一条简单的工作流：收集、整理、输出。这篇文章把它完整记录下来，方便以后的自己回来对照。

收集：先记下来

收集阶段只有一个原则——快。念头出现时，三秒内要能被记下，不打断手里的事。

  • 通勤路上：语音备忘录，回家转文字
  • 阅读时：划线即收藏，不写感想
  • 聊天中：直接转发给「收集箱」

整理：每周半小时

整理不是归档，而是「再读一遍」。每周日晚饭后留半小时，把收集箱清空：值得展开的移进项目，暂时用不上的打标签归档。

标签而非文件夹

文件夹是独占的，标签是网状的。一条笔记可以同属「写作」和「产品」，这正是日后产生连接的地方。

输出：写给自己看

输出的读者首先是自己。把学到的东西讲清楚一遍，含糊的地方会自己浮出来。

「写作不是记录思想，写作本身就是思想。」
