# 独立文件编辑窗口改版设计

状态：进行中（方向已定，实施中）
目标：重新设计 `/markdown-window` 独立文件编辑窗口——大纲从左侧页签移到右侧，文件树放宽密度，侧栏支持拖拽调宽。

## 现状（事实）

代码：`/apps/desktop/src/features/markdown-window/`（辅助窗口，默认 1200×800，最小 640×420）。

- 左栏 `FileSidebar`：固定 248px、不可拖宽；自上而下 = 文件夹头(h-8) → 「文件/大纲」互斥页签(11.5px/22px) → 筛选框(11.5px/26px) → 文件树或大纲。
- 文件树 `fileTree/FileTree.tsx`：字号 12.5px(tau-meta)、行高 27px、行内 gap 5px、缩进 `6 + 14×depth`、图标 14px、chevron 12px。
- 大纲：与文件树互斥占左栏；数据链路是 `FileViewStatus.outline`（`MarkdownFileView` 上报 headers + scrollEl + resolveAnchor），渲染组件是共享的 `ContentOutline`（默认宽 208px，左 border 指示激活项）。

## 问题

1. 大纲与文件树互斥：看文档结构时看不到文件列表，写作中反复切换页签。
2. 文件树偏挤：27px 行高压 12.5px 字，图标/gap 都贴着下限；页签和筛选框只有 11.5px，是全场最小字级。
3. 页签条本身还吃掉约 34px 纵向空间，进一步压缩树。

## 已有可复用资产

- 「大纲在右」在仓库里有两个现成实现，数据协议与 markdown-window 完全同源（同一 `ContentOutline`、同一 `resolveEditorHeaderAnchor`）：
  - 文章详情页 `features/articles/views/ArticleDetailView.tsx:582-590`：版心 `grid 1fr \| minmax(0,720px) \| 1fr`，大纲 `col-start-3 + sticky`，贴正文右缘、不参与版心计算。
  - 编辑小窗 `features/editor-window/EditorWindow.tsx`：宽窗常驻右列、窄窗降级为标题栏 ListTree 按钮 + Popover（`OUTLINE_COLUMN_MIN_WIDTH = 900`），开合状态按文档类型持久化。
- 即：挪大纲只动 `MarkdownWindowPage`/`FileSidebar` 布局与 prefs，数据链路零改动。

## 方向 A：三栏式 · 大纲独立右栏（推荐）

布局：`标题栏 | 左栏(纯文件树) | 编辑 sheet | 右栏(大纲 216px)`

- 左栏删掉「文件/大纲」页签，纵向空间全部还给文件树；保留文件夹头与筛选框。
- 右栏与左栏同语言（落在 page 底上、不进 sheet 卡片）：顶部「大纲」小标题 + `ContentOutline`；仅 markdown 文件且 headers 非空时显示条目，否则空态提示。
- 标题栏右侧加 PanelRight 开关（快捷键如 ⌥⌘\），右栏可整体折叠，开合状态进 `markdownWindowPrefs`。
- 降级：窗口宽 < 1080px 时默认收起右栏（仍可手动开）。
- 优点：默认 1200px 窗口下大纲与文件树可同时常驻（264 + 216 + 编辑区 ~700px，版心仍够）；大纲宽度稳定，长标题比贴缘方案更从容。
- 代价：编辑区横向被再压缩约 216px；三栏视觉重量略大。

## 方向 B：大纲贴正文右缘（文章详情页模式）

布局：`标题栏 | 左栏 | sheet 内 grid 1fr | minmax(0,720px) | 1fr`，大纲 sticky 在右列、贴正文右缘。

- 完全复刻文章详情页的观感，最轻、最不占 Chrome。
- 降级照搬 EditorWindow：sheet 内宽 < 1080px 时不渲染贴缘大纲，标题栏出 ListTree 按钮弹 Popover(240px)。
- 关键事实：默认窗口 1200px **且开侧栏**时，sheet 只有 ~930px —— 低于阈值，大纲会降级成 Popover；常驻需要窗口 ≥ ~1360px（开侧栏）或 ≥ ~1100px（关侧栏）。
- 优点：阅读/写作视线最短，与主窗口文章详情页体验一致。
- 代价：默认尺寸 + 开侧栏的常用组合下大纲不能常驻，恰好削弱了「大纲随手可见」的初衷。

## 文件树宽松化规范（两方向共用）

| 项                  | 现状                                            | 提案            | 依据                                 |
| ------------------- | ----------------------------------------------- | --------------- | ------------------------------------ |
| 树字号              | 12.5px (tau-meta)                               | 13px (tau-body) | 与界面正文同级，扫描省力             |
| 行高                | 27px                                            | 32px            | 行间留出呼吸                         |
| 行内 gap            | 5px                                             | 6px             | chevron/图标/名称不再相贴            |
| 缩进                | 6 + 14×depth                                    | 8 + 16×depth    | 层级更可读                           |
| 文件/文件夹图标     | 14px                                            | 15px            | 与 13px 字匹配                       |
| 文件夹头            | h-8 / 12.5px                                    | h-10 / 13px     | 与树同字级                           |
| 筛选框              | 26px / 11.5px                                   | 32px / 12.5px   | 去掉页签后它是唯一输入控件           |
| 「文件/大纲」页签   | 有（11.5px/22px）                               | 删除            | 大纲移出，页签失去存在意义           |
| 侧栏宽              | 248px                                           | 264px           | 缓解名称截断；拖拽调宽列为可选后续项 |
| 选中/hover/未保存点 | bg-selected + accent-text / bg-hover / 6px 圆点 | 不变            | 已是设计系统口径                     |

## 决策

- 方向选定 **B**（大纲贴正文右缘，文章详情页模式；窄窗降级 ListTree + Popover）。
- 侧栏拖拽调宽**纳入本次范围**（持久化宽度，设最小/最大约束）。
- mockup 评审结论：方向 B 宽窗常驻阈值修正为 sheet 内宽 ≥ 1080px（开侧栏 ≈ 窗口 1360px）。
