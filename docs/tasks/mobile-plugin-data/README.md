## 需求与用户决策

用户已同意先落任务文档，再实施第一批。共用插件 API 与数据语义，不另建移动专属作者接口，不新增清单能力字段。第一批覆盖 cards/articles 的查询、创建、修改、删除与恢复，content.read/edit、permissions 和对应业务事件。第二批项目与项目文档已由用户追加授权并接入；第三批待办与日程也已追加授权并实施；插件自有 entities/records/links/transaction、AI、白板扩展和 app.run 不纳入本任务。视觉验收由用户完成，Agent 负责结构、行为、类型和构建验证。本任务不发布客户端、SDK 或门户。

## 技术方案

### 授权

manifest 是申请上限，安装不等于授权。授权按设备本地的工作区 × 插件 × 权限保存，不进入同步主库或插件 KV。仅这次与本次拒绝绑定激活实例；始终允许与阻止持久化；连续拒绝三次阻止，详情页可撤销、解除阻止、处理后台待申请项。弹窗串行，返回等同拒绝，停用或切库的取消不计入拒绝。更新新增权限不自动授予，卸载清除授权。损坏记录不能继续授权。权限是 SDK 闸门，不构成恶意代码沙箱。

### 工作区与调用链

插件 API → 公共校验/授权 → 移动适配器 → 固定工作区会话的原生命令 → 业务服务。会话固定数据库、插件身份及代次；切库、停用、撤回、同名数据库被同步替换后旧请求失效。异步授权和正文转换后重新检查生命期。连接固定原库，不在执行时重新选择活动库；已提交写入不随取消回滚，非幂等创建超时不自动重试。

### 查询与写入

使用 SDK DTO、不透明引用和稳定游标，支持时间范围、标签、排序和有界分页。修改/删除的版本比较与写入在同一事务完成，元数据和正文版本分别校验。正文访问由真实所有者确定，共享正文不简化归属。

正文操作统一协调三条路径：已打开的本地文档会话、未打开的本地权威文档、协作会话及投影；不得直接 SQL 覆盖协作正文或编辑草稿。复用 Markdown、节点契约、字数、资源和派生索引。支持 append/prepend/replaceAll/replaceText、markdown/nodes/copyOf，保留未知节点。shareOf 依赖插件自有实体，未实现时明确拒绝，不宣称完整支持。

### 事件与恢复

提交成功后发业务事件，用户编辑、插件写入、协作投影与恢复均接入；事件不携带正文，按当前读权限投递，带工作区与来源，触发应用缓存及编辑器刷新。同步替换发 workspace.reset 并终结旧调用。删除与 plugin_operations 快照同事务，恢复检查身份冲突、保留共享正文；恢复成功发事件。恢复完成前不开放 delete 权限。

### 准入与改动边界

公共 plugins 包复用契约和纯逻辑；移动 app/plugins 装配授权/数据/事件；Rust 负责本地授权文件、固定库命令、事务及恢复；移动详情页承载权限管理。必要的正文服务从既有文档/协作机制提炼。发行与运行校验只开放已完成领域，最低版本以实际交付版本为准，其余权限继续拒绝；已完成领域在本地准入校验中开放，未完成领域继续拒绝，线上分发须另行部署。尽量复用现有表，不预先新增 schema。若调整 schema，同步数量断言、数据库内置说明并执行 schema 检查。

## 实施补充

- 插件权限来自验证过的 manifest，不接受 JS 入口增加权限；静态内容在 activate 前装配，允许激活阶段使用已声明节点。
- 授权损坏时保留原文件，详情页可显式备份并重置设备授权；调用次数按设备本地七天统计，短期缓冲。
- 已打开的本地编辑视图注册写入协调器，先冲洗，再比较修订与新输入。协作请求先在隔离 Y.Doc 构造候选，服务器条件提交成功后才合并本机并投影；失败不改当前副本。现有协作附件限制保留。
- 复用 applyNodeTreeContent 时发现宿主快照的插入身份被普通编辑路径重建，导致合法快照差分失败；新增仅宿主使用的身份保留选项，普通粘贴仍重新分配，编辑器包与桌面协作回归通过。
- 事件消费现有已提交 operation 日志，无订阅时仅推进游标，有订阅时有界拉取并合并；不新增业务表。恢复与写入均触发应用缓存刷新。整库替换重建会话，旧代次请求拒绝。
- app.pick/open/describe、插件自有实体及 shareOf 均未在首批开放。删除协作绑定内容仍需先结束共享；恢复原编号已占用时明确失败，不覆盖新数据。

后续工作限定在独立 worktree 的 `codex/mobile-plugin-data` 分支，基线为 `31091178bb7c94e5c547a4296b9cbb8efd13a519`。迁移包含主仓库 44 个已跟踪文件的改动、28 个新增文件及模板子模块的 3 份文档，移除原工作区对应改动前已逐文件校验内容一致。模板使用独立子模块 worktree，其他任务的改动留在 master，原暂存区不变。用户已授权本地提交保存当前修改；模板文档先独立提交，再由主仓库记录对应子模块版本，不推送或发布，设备验收继续保留。
