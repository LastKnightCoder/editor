# 平板适配

状态：进行中
目标：移动 App 在 iPad 与安卓平板上不再是拉长的手机，按窗口宽度换导航、浮层和内容排版。

## 需求

- 只看当前窗口宽度分三档：紧凑 < 600（现状不变）、中等 600–839、宽 ≥ 840。转屏、分屏、台前调度时实时切档，页面栈、滚动位置、草稿不丢。
- 中等与宽档：底部 Dock 换成左侧导航条（80 宽）：新建置顶，今天 / 卡片 / 日记 / 我的，底部搜索；所有页面常驻。Tab 根左右滑切换关闭，左边缘返回从导航条右缘起算。
- 浮层：选择类底部面板在中等与宽档变成居中卡片（520 宽）；可拖高的抽屉（脉络、引用预览等）也变成居中卡片（680 宽），遮罩盖住整屏。
- 今天页：一张纸、单列，顺序同手机；插件面板按宽度流式排（每格最小约 340）。
- 导航条分隔线下放自选入口：就是「我的」宫格的顺序，按剩余高度露出，放不下的进「更多」；在「我的」长按宫格拖动排序调整。
- 我的：整页宫格 + 设置分组，宽屏宫格一行 8 个、设置单列；点插件或设置项整页进入详情。
- 卡片库：中等与宽档列表两列。
- 主从两栏（卡片 / 日记 / 文章 / 项目在宽档列表 + 详情）是第二批，本批不做。
- 外接键盘与键鼠（第三批）、插件宽档排版（第四批）本批不做。
- 设计稿：`apps/mobile/mockups/tablet-mobile/index.html`。

## 决策

- 宽档导航用左导航条，不保留底部 Dock。
- 中等档（竖屏 iPad）不做两栏。
- 右栏里点链接在右栏前进（第二批实现）。
- 插件按宽度排版写成文档建议，不做上架要求。
- 首版先做第一批（不变形），第二批主从两栏紧随。
- 「我的」不做主从两栏；今天页不拆两栏。

## 方案

- 档位：`src/hooks/useWindowClass.ts` 用 `matchMedia(600 / 840)` 订阅，只给壳层与浮层组件用；样式侧用 Tailwind 断点 `medium:` / `wide:`（同一组宽度），页面内列数用容器查询。
- 屏幕区域偏移：`router/screenInset.ts` 是唯一写入方，同时写 CSS 变量 `--screen-inset-left` 与 JS 值。PageHost 页面层从该偏移起铺，并用 `contain: layout` 让页内 `fixed` 元素以页面层为准；边缘返回起点与跟手宽度扣掉偏移。
- 导航：`AppDock` 的创建动作（新建卡片 / 文章 / 日程 / 日记、说一段、长按速记）抽成 `useQuickCreate`，Dock 与 `AppRail` 共用；壳层按档位二选一。中等与宽档 `--dock-visual-height` 只剩安全区，`dock-pad` 自动收缩。
- 浮层：`BottomSheet` / `ActionSheet` 在非紧凑档改居中卡片（淡入缩放，无下拉关闭）；`SnapSheet` 在非紧凑档不走 `PanContainer`，改为挂到 body 的居中卡片（680 宽）。
