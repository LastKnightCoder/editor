# 进行中任务

一个任务一个目录（大任务）或单文件（小任务）。任务文档**自含**：目标、技术方案、过程中的用户决策、进度、验证都写在这里，不外链决策档案。

收尾（完成或放弃）必做三步，缺一不可提交：

1. **沉淀**：评估任务产出——方案中「现在是什么」的部分沉淀进 `docs/architecture/`；用户表达的通用裁决（跨任务有效的规则）进 `docs/decisions.md` 或 `docs/preferences.md`；可复用的操作流程进 `docs/guides/`。其余随任务退役。
2. **退役**：删除本任务目录/文件（git 历史可查）。
3. **索引**：更新 [docs/README.md](/docs/README.md)。

期限 90 天，超期由 `pnpm check:docs` 提示。

## 任务模板

```markdown
# <任务名>

状态：进行中 | 待验收 | 已放弃
目标：<一句话说清原始目标>
需求：<范围、约束、验收标准>
方案：<技术方案与结构，自含完整>
决策：<任务过程中用户做的选择与理由>
进度：

- [ ] …
      验证：<命令与结果>
```
