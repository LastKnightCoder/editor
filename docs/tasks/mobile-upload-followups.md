# 移动端图片上传遗留事项

状态：进行中
目标：做完「图片与附件」重设计里约定后续再做的两项编辑器侧增强，之后本文件退役（现状沉淀进 `/docs/architecture/mobile.md`「图片与附件（设置）」）。

## 已有基础

- 上传失败时编辑器 toast 会给出原因与「去设置」（`services/uploadOutcome.ts` + `editorNotifier`）。
- 设置页目的地卡展示最近一次上传结果与修复入口。

## 待做

- **失败图片留在原位可重试**：现在上传失败会移除占位块。改为保留一个「没传上去 · 点击重试」的块，持有本机暂存的文件，重试不需要重新选图；关闭文档前仍未成功时提示「有 N 张图片未上传」。需要编辑器侧（`packages/editor` 媒体扩展 `uploadMedia.ts` / `Image` 组件）支持失败态节点与暂存文件，桌面端是否同步采用需一并确认。
- **插入面板显示目的地**：插入面板（`features/cards/editorToolbar/InsertPanel.tsx`）底部一行小字「保存到 GitHub 仓库 ›」，点击进入「图片与附件」，避免误把私密截图传到公开仓库。可选增强。

## 决策

- 两项都排在主体改造之后，做之前再确认是否仍需要。
