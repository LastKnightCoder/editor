## 🔑 关键概念速查

### 插入元素

```typescript
insertHeader(editor, 1); // 插入标题
insertCodeBlock(editor, "javascript"); // 插入代码块
insertTable(editor, 3, 3); // 插入3x3表格
insertImage(editor, { url: "..." }); // 插入图片
```

### 快捷键

- `Cmd+B` - 粗体
- `Cmd+I` - 斜体
- `Cmd+\`` - 插入代码块
- `Cmd+Alt+1~6` - 插入标题
- `/` - 打开块面板

```

/table → 表格
/image → 图片
```

## 🛠️ 开发工作流

### 添加新功能的典型流程

1. **定义类型** - 在 `types/element/` 中定义元素类型
2. **创建扩展** - 实现 `IExtension` 接口
3. **实现组件** - 编写 React 渲染组件
4. **添加插件** - 实现 Slate 插件 (可选)
5. **配置交互** - 添加块面板项、快捷键、悬浮工具栏 (可选)
6. **添加 Markdown 支持** - 注册序列化器 (可选)
7. **注册扩展** - 添加到 `startExtensions` 列表
8. **测试** - 编写单元测试和集成测试

详细步骤请查看 **[开发新扩展文档](./04-开发新扩展.md)**。
