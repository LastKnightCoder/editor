PDF 页边笔记 · 四个方向

现状：笔记只能依附划线，以 22px 图钉的形式显示在页面右边缘内侧，悬停才能看到内容。读纸书时的「页边批注」有三个特征——常驻可见（扫一眼就能看到自己写过什么）、位置即上下文（写在哪一段旁边就是在说哪一段）、可以不依附划线（随手冒出的想法）。下面四个方案都围绕这三点展开，按推荐程度排序。

定稿 · A + B 已定稿

平时是 A：页边和 PDF 同一张纸、同一底色，只用一条虚线隔开；笔记直接排在对应段落的高度，超过 4 行折叠。写和改的时候是 B：点页边的笔记或空白处，就地弹出卡片编辑，长笔记、富文本都放得下。悬停页边笔记时，原文里对应的划线会描一圈。

A · 纸张外延 推荐

在页面外侧「接」出一条同质纸边（暖白，不是 PDF 的纯白，暗示这是你的而不是书的），笔记直接以小号正文排在对应段落的高度，左侧一道划线同色的细竖线。没有卡片、没有边框——像铅笔写在书边上。悬停才显出接缝；点空白处直接落笔，写下的就是不依附划线的「自由批注」（虚线竖标）。

推荐 A 的细节：怎么做到「不丑」

核心原则：页边是纸的一部分，不是一块 UI 面板。所有视觉增量都要能用「铅笔写在书边」来解释。

① 本页无笔记

页边依然在（宽度全书统一，避免翻页时页面左右跳），但完全空白，接缝不可见；悬停才浮出「点击写批注」。

② 常规

笔记顶端对齐锚点所在行；重叠时向下顺排（复用现有 layoutPins 的避让逻辑）。划线批注=实色竖线，自由批注=虚线。

③ 写满

单条超过 4 行折叠，悬停展开；挤出页底的笔记合并为「+2 条」，点击在页边内滚动，不越过页面。

+2 条

④ 窄窗口 / 收起

放不下页边时退化为页外 6px 细轨，只画色标（等于把现在页内的图钉挪到页外，不再遮正文）；点击色标展开为浮层。

视觉

  • 纸边用暖白 #fbf9f4（亮）/ 页面同色降一档（暗），与 PDF 纯白形成「书页 vs 我的纸」的微差
  • 与页面共用一个阴影，看起来是同一张纸；接缝 1px 只在悬停出现
  • 笔记用界面字体、比正文小一号、ink-2 色；不用手写体（廉价感 + 中文手写字体体积大）
  • 页边宽度 ≈ 页宽 × 0.42，随缩放等比，字号也随缩放，保持「写在纸上」的比例

交互

  • 点页边空白 = 在该高度新建自由批注，直接进入编辑（复用 NoteCard 的 Slate 编辑器，去掉卡片外壳）
  • 划线后「写笔记」= 在页边对应高度落笔，不再弹浮卡
  • 悬停批注 ↔ 原文划线互相高亮；拖动批注可微调高度
  • 页边开关放进 HUD（按文档记忆），有批注的文档默认开

数据

  • pdf_annotations.type 新增 "margin"：存 pageIndex + y（PDF 坐标），不写进 PDF 文件
  • 划线批注沿用现有 notes，只是换个显示位置，零迁移
  • 自由批注同样进入摘录 / 知识闭环 / 对话引用（「第 12 页 · 页边」）
  • D（活页）可作为后续：页边批注「展开为活页」
