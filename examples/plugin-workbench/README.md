# 插件 API 开发样本

这是桌面插件体系的开发验证入口，使用 Node 运行可移植的宿主核心，不启动应用、不读取用户数据库，也不是第三方插件安装器。

```sh
pnpm --filter @example/plugin-workbench check
pnpm --filter @example/plugin-workbench demo
```

`src/plugin.ts` 只从 `@tau/plugins` 导入公开契约，注册保存、读取、删除和实例计数四个命令。`src/main.ts` 负责显式信任注册、启用、调用、停用、重新启用和断言结果；直接消费与桌面相同的 TS PluginHost 和文件存储，不实现另一份生命周期或协议。

`build.mjs` 仅编译 TS，`demo.mjs` 仅创建临时目录和启动四个顺序执行的独立进程：写入、重启读取、删除、重启确认删除。每个进程验证重复启用不重复创建、同实例命令计数递增、重新启用计数重置，以及磁盘数据符合阶段预期。结束后清理临时目录，不写入用户应用数据。

四个进程顺序运行，不代表支持多进程并发写入；同进程多个宿主应共享一个存储适配器。测试只验证可信流程，不证明沙箱或权限隔离。
