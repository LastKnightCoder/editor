## Default Permission

允许移动端待办与日程的本地提醒通知。

#### This default permission set includes the following:

- `allow-permission-state`
- `allow-request-permission`
- `allow-open-settings`
- `allow-schedule`
- `allow-snooze`
- `allow-cancel-owner`
- `allow-take-actions`
- `allow-set-foreground-banner`
- `allow-register-listener`
- `allow-remove-listener`
