## 新功能

### 协作

- **手机端支持协作**：在手机上把内容分享给同伴一起编辑，也能加入别人发起的协作；成员管理直接在手机上完成。

### 日记、待办与番茄钟

- **日记**：随时写下今天的碎碎念，翻看往日记录，与桌面端同步。
- **任务待办**：查看待办清单，勾选完成、新增修改，重复任务也支持。
- **番茄钟**：在手机上开始专注计时，每一段专注都有记录。

## 改进

- **Markdown 粘贴即所得**：粘贴 Markdown 文本会自动转成排版好的内容，不再是一整段源码。
- 代码块的语法高亮更准确、更好看。
- 安装包更小，下载更快。
- 视频与音频内容的显示样式更协调。

## 修复

- 修复了深色模式下部分颜色显示不对的问题。
- 修复了设置弹窗底部被截断、看不全的问题。
- 修复了同步数据下载完成后，列表内容没有及时更新的问题。
