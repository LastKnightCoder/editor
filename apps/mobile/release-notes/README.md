# Android 更新说明

每个发布版本一个文件：`<版本号>.md`（如 `0.2.5.md`），写给用户看的更新说明。

## 硬约束

- `pnpm publish:mobile` 发布前校验当前版本的说明文件存在且非空，缺失即拒绝发布。
- 截至发布版本（含）的全部说明写进 R2 上的 `mobile/android/latest.json`，客户端按自身版本截取跨越的区间展示。
- 已发布版本的说明不要再改：线上清单只在下次发布时重写。

## 用户在哪里看到

- 我的 → 版本（关于页）：发现新版本时展示从当前版本到新版本之间每个版本的说明，从新到旧排列。
- 已是最新版本时展示本版说明。

## 写法

用 Markdown，不写版本号标题（界面会自动加），分组与措辞同桌面端 [升级公告](/apps/desktop/release-notes/README.md)：

```markdown
## 新功能

- **应用内更新**：在「关于」页发现新版本后可直接下载安装。

## 修复

- 修复了卡片列表在横屏时错位的问题。
```
