## 新功能

- **Skill 与 MCP 管理**：「我的 › AI」新增 Skill 和 MCP 服务器管理页。Skill 按内置、插件提供、Skill 包分组，可设为自动、仅手动或停用；MCP 支持整组或逐个工具开关，连接失败会给出原因；手机上可直接添加远程 MCP 服务器（Streamable HTTP）。
- **对话接入 Skill 与 MCP 工具**：对话输入框可直接选择本次使用的 Skill，聊天中 AI 能调用 MCP 工具办事；切回前台时自动重连。
- **图片生成**：设置新增「图片生成」，配置好服务商后，对话里可以直接让 AI 生成图片。
- **编辑器文字转语音**：插入面板「文字转语音」、选中文字「转语音」、AI 音频「重新生成」与「用文字生成」共用底部生成面板——先试听再插入，可调音色与语速，插入可撤销。
- **网页书签块**：在空段落粘贴网址可选择「粘贴为网页书签」，书签块提供横向卡、封面卡、紧凑行三种外观，标题、描述与封面都可编辑。
- **插件融入首页**：「今天」页新增两列插件卡片；「我的」功能宫格并入插件入口；插件可使用语音输入，与应用的听写共用识别服务。
- **插件设置保存条**：修改插件设置后底部出现保存条，返回或切换页面前会先确认未保存的修改。

## 改进

- **注解重设计**：注解标记改为按文档顺序编号的上标序号；点按序号打开底部抽屉查看与编辑，删除后可撤销；插入注解后直接进入编辑，留空关闭即自动移除，键盘弹出时自动避让。
- **按住说话按下即录音**：对话「按住 说话」与语音面板按下立即开始录音；语音面板轻点可转为点按模式继续录，对话里短按则取消不发送。
- 插件版本历史改为两行列表，当前安装版本以强调色圆点标出；最低版本要求只在手机不满足时提示，不再常驻。
- 优化与桌面端之间 AI 对话记录的同步：改为增量传输，请求并发与失败重试更稳健，同步更快、更不易失败。

## 修复

- 完善协作共享：修复协作中图片跨端保存与缓存恢复的问题，共享结束后即使错过通知也能可靠收尾。
- 修复点击附件、书签等内容块末尾时，光标落点异常、输入位置不对的问题。
- 修复添加服务商弹层横向滚动异常的问题。
- 修复「新文章」快捷按钮背景透明的问题。
