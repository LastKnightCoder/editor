## 新功能

- **提醒与系统通知**：待办与日程最多可设 3 个提醒；截止任务、周期待办、日程与正文里的待办到点后发送系统通知，通知上可直接「完成 / 知道了 / 稍后」；应用在前台时改为应用内横幅，番茄钟结束也会发通知。新增「设置 › 提醒与通知」：管理通知授权、准点提醒、默认提醒、稍后间隔与前台横幅。
- **局域网设备同步**：同步页新增连接电脑同步库的入口——三步引导配对，剪贴板里的配对码可自动探测；配对后显示同步状态，可随时「立即补齐」拉取增量；下载覆盖与重新配对收在底部面板。
- **AI 制作闪卡**：新建闪卡可选「AI 制作」——给出参考资料，AI 自动生成题目、答案与解析；可在「我的 › AI › AI 模型」为闪卡单独指定模型。
- **文档录音**：编辑器插入面板新增「录音」，在文档中录音并插入为音频块，音频块可一键转写成文字。

## 改进

- **对话工具时间线**：AI 调用工具的过程改为逐条时间线，点按任一步可查看详情（搜索结果、读取的笔记、数据表格、待办与日程）；写入类操作给出结果卡与确认卡，图片生成直接显示图片、点开可全屏查看。
- **内置功能常驻**：任务、日记、番茄专注、日历不再受模块开关控制，始终可用；「番茄」更名为「番茄专注」；「我的」宫格移除白板入口。
- 高亮新增马克笔笔触（平头荧光笔、下半划线、干笔颗粒），随外观设置在两端一致渲染。
- 同步上传与下载显示实时进度与完成百分比，大数据量同步不再是黑盒。
- 制作闪卡与简答题答案评判共用同一个「闪卡」模型，AI 模型设置里相应合并为一项，原有配置自动迁移。
- 若干界面细节修复：闪卡卡组改用与桌面一致的线性图标、批量操作条隐藏时完整移出屏幕、正文字体列表未选项样式修正、今天页建议问题留出页边距并加横向渐隐、番茄入口改用统一图标。

- 修复正式版中输入 / 呼出的菜单图标初始化异常的问题。
- 统一「我的」页插件中心入口与插件页面安全区、首页卡片入口的样式细节。
