设计说明
  • 录音时把「文档 id + 落点前一块的 uuid + 开始时间」写进本地小文件，录音文件边录边落盘。
  • 重新打开这篇文档时检查到未完成录音就显示横幅；落点块已不存在则插到文末。
  • 7 天没处理自动删除，和收集箱同一期限。

其他边界

  • 录音太短：不足 1 秒不插入，提示「录音太短」。
  • 存储不足：剩余空间低于 200 MB 时开始前提示；录音中低于 50 MB 自动完成并插入，提示原因。
  • 时长上限：默认 3 小时自动完成并插入（约 90 MB），到点前 5 分钟胶囊提示。
  • 耳机 / 蓝牙：录音中切换输入设备不中断；蓝牙断开转为暂停（同 E3）。
  • 只读、他人文档：插入面板本就不出现，无需处理。
  • 协作中的文档：落点只存在本机；完成时插入作为一次普通编辑同步。落点所在块被他人删除时插到文末并提示。
  • 同步：录音文件按现有资源同步走，大文件（几十 MB）不需要新逻辑，但首次同步时间会变长。

自动选择，不让用户选：

  • 资源走远程存储（OSS、S3 等上传插件）：转码后的 Ogg 用同一个存储上传，拿到地址交给标准版。录音本来就在这个存储里，多放一份转写用的副本不改变数据存放位置。
  • 标准版失败（地址下载不到、账号未开通标准版）：改用极速版。
  • 资源存在本地：直接用极速版，不为转文字上传任何文件。

接入要点

  • 格式：按提供方 probe 声明的 fileMimeTypes 决定。不声明或声明里含原文件格式时原样交出；否则宿主在 Rust 侧转成 16 kHz 单声道 Ogg Opus（约 16 kbps，1 小时约 7 MB），声明里没有 Ogg 时提示换服务。Seed 两个版本都不收 m4a，所以手机录音会被转码。转码副本用完即删；上传的副本由上传插件决定能否删除。
  • 协议：ASRAudioFile 增加可选 url（公网可下载的同一份音频）。宿主有远程地址就填，插件自行决定用 URL 还是 open() 读字节。这是插件 SDK 的公开接口变更，模板文档同步。
  • 插件：tau-plugin-asr-seed 新增 transcribeFile。有 url 时调标准版（volc.seedasr.auc，submit / query，format / codec 按交来的格式填，show_utterances），失败回落极速版（volc.bigasr.auc_turbo）；utterances 映射为 segments。probe 声明 audio/ogg、audio/mpeg、audio/wav，不报 maxDurationMs；极速版超过 100 MB 在插件里拒绝。
  • 轮询：标准版轮询在内存里进行；转写期间 App 被杀，回来后需要重新点「转文字」。
  • 开通：标准版与极速版是两个计费资源，与实时识别也不同。两个都未开通时映射成「账号未开通录音文件识别」，归入 T4 面板，按钮去控制台。

需要实测的点

  • 用真实 API Key 验证两个版本：新版控制台 Key 能否直接调用、开通流程、错误码；标准版接受 format / codec 按交来的格式填 的 Ogg 文件。
  • 常见存储（阿里云 OSS、S3、GitHub 公开仓库）的公开地址火山侧能否下载；私有桶确认回落极速版。
  • volc.bigasr.auc_turbo 对应的模型版本（文档未写明是 1.0 还是 2.0），识别效果与实时识别是否一致。
  • 约 20 MB 请求体经移动端插件 fetch 桥（plugin_fetch.rs）的耗时与内存峰值；必要时让桥接支持从文件读请求体。
  • 转码依赖：AAC 解码与 Opus 编码在 iOS / Android 交叉编译下的体积与可用性。
