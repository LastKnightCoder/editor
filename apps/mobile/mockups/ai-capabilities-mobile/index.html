MCP 页回答三个问题：AI 现在能用哪些工具、哪个服务器坏了、怎么修。手机端的工具有两类来源：Tau 自带（笔记检索、只读 SQL、待办日程、图片生成，等同桌面的“内置”）和插件提供（插件内联工具或远程 Streamable HTTP 服务）。列表行尾是服务器级开关，详情里可以逐个关工具。写入类工具每次执行前都要用户确认，这一点保持不变，管理页只说明、不提供“总是允许”。
