逐项清单（调研结论）

媒体依赖桌面的交互
图片悬停属性条、8px 缩放手柄、双击预览、右键菜单（替换 / 外观 / 替代文本 / 复制）、拖入或粘贴替换、快捷键
行内图片四角缩放（不锁比例）、双击预览、Del 删除；没有工具条
视频属性条与缩放手柄同图片；播放器 hover 控件、音量悬停、双击全屏、滚轮调音量
音频标题是常驻 <input>，阅读时点到就弹键盘；没有菜单入口；AddParagraph 只读下也显示
网页视图高度拖拽 ResizeHandle 只监听 mouse 事件，手机完全拖不动；只读下仍能拖并写回节点；内嵌页面滚动和正文滚动冲突；「选择本地 HTML」在移动端被禁用
大图预览无捏合、无滑动切图、无下滑关闭
裁剪能力完整（pointer 事件 + touch-none），但弹窗按桌面尺寸布局

已经可以复用的部分：上下文配件栏（表格 / 代码块 / 公式已在用）、顶替键盘的面板、ActionSheet / SnapSheet、系统返回关闭浮层（IOverlayBackDismiss），以及插入面板里的相册、相机和网络地址三个入口。

推荐媒体块就是另一种「上下文」。编辑态点一下图片就选中它，同时收起键盘，配件栏切换成「图片」上下文：尺寸、对齐、裁剪、说明、替换、⋯。这和表格、代码块已经在用的上下文配件栏是同一套机制。尺寸和外观的面板顶替键盘位置，正文里的图片会实时变化。低频操作都收进「⋯」。图片上不放任何浮动按钮。
