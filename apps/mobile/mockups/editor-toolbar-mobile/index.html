移动端编辑工具条 · 重设计颜色取自 @tau/themes · 手机帧 360×740 · 键盘为系统绘制示意

现状

  • 左端三种按钮形态并排：浅橙方块（麦克风）、实心橙方块（插入）、裸字（Aa）。
  • 右端「完成」又是浅橙胶囊，一条栏里出现两种 accent 用法，视线被左右两头的橙色拉扯。
  • 平条 + 顶部细线贴着键盘，和键盘没有层次，像「贴上去的板子」。
  • 分隔竖线 + 右侧渐隐同时存在，中段显得局促。

A 浮岛推荐

  • 工具条离开屏幕边缘，变成一块浮在键盘上方的圆角纸片，投影分层，不用描边线切割。
  • 全条只留一处实色：「插入」是 accent 圆钮；麦克风、样式、列表都是同一套裸图标。
  • 「完成」改为墨色圆钮 + 对勾，收在纸片右端，和左端插入对称。
  • 格式模式（选中文字）沿用同一块纸片，左端标签换成「格式」，外形不跳。

B 一体平条

  • 保留贴边平条，去掉顶线，改用向上的柔和投影接住键盘。
  • 所有按钮同一个 40px 裸图标；插入只把图标染成 accent，不铺底。
  • 「完成」是 accent 色文字，不加胶囊底。最安静，接近 Bear / 备忘录。

C 三段分离

  • 插入、工具胶囊、完成拆成三块独立浮件：左圆钮、中胶囊、右圆钮。
  • 中段胶囊可横滑，两端圆钮位置固定，拇指记忆更稳。
  • 麦克风进中段胶囊首位（accent 色图标）。浮件多一块，画面略碎。
