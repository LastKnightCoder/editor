## P1 — 高（功能缺陷，必须修）

### 1. 归档预设成为"死巷"，归档分区是死代码

`PomodoroPage.tsx` 只渲染 `activePresets`；"取消归档"入口在行内 ActionSheet（`moreItems` 的 `preset.archived ? "取消归档" : …`），但列表里永远只有未归档预设，该分支不可达；`PresetEditPage` 的归档开关也只能从主页列表进入。用户归档预设后再也无法找到它；`queries.ts` 的 `splitPresets` 的 `archived` 分支随之成为死代码（其注释声称"P3 管理用"）。
**修复**：主页预设列表下增加"已归档 (N)"折叠分区，展开后列出归档预设：点击进编辑页（那里有归档开关），行内 ⋯ 菜单提供"取消归档"。

### 2. 今日英雄卡 ≥1h 时显示格式错乱

`PomodoroPage.tsx:235` `formatFocusDuration(todaySummary.focusMs).replace("m", "")`：`formatFocusDuration(65min)` 返回 `"1h05m"`，`replace("m","")` 得 `"1h05"`，副单位判定显示"小时"——最终渲染 **"1h05 小时"** 这种中英混搭的错乱格式；且 `replace` 只去第一个 `m` 的写法本身就脆弱。
**修复**：大数字直接展示 `formatFocusDuration` 全格式（自带 `h/m` 后缀），去掉单位 `<em>` 与 `replace`。

### 3. 沉浸页在活动会话"加载中"即误判无会话并自动退场

`FocusImmersivePage.tsx:92` 的自动退场条件是 `!controller.session && !controller.justCompleted && !controller.busy`。`usePomodoroController` 中 `session = activeQuery.data ?? null`——**首次挂载、缓存未预热时 `data` 为 undefined，查询还在路上就会被判成"无会话"立即 `onRequestClose()`**。当前入口（start 成功后 push、进行中横条）都有缓存预热所以未爆，但任何冷启动直达/深链/未来新入口都会闪退；正确语义应区分"还没加载完"与"加载完了确实没有"。
**修复**：controller 暴露 `isActiveLoading`（react-query v5 的 `isPending`），退场 effect 增加 `!isActiveLoading` 条件。

## P2 — 中（健壮性 / 竞态 / DRY，应修）

### 4. 完成庆祝态依赖 `preset` 非空，否则白屏卡死

`FocusImmersivePage.tsx:125` 庆祝分支要求 `preset` 非空才渲染；而 stop 成功后 `invalidatePomodoroQueries()` 会使 presets 重拉，期间 `presets=[]` → `preset=null` → 渲染 `null`；又因 `justCompleted=true` 阻止了退场 effect → **页面白屏**。若 presets 查询失败（预设已被删除也走此路径）则永久白屏。
**修复**：controller 在 autoStop 落库成功后保存 `lastCompleted`（stop 返回的已落库会话，含 `focusMs`），庆祝分支不再依赖 `preset`；"再来一个"按钮仅在 `preset` 存在时渲染。

### 5. Rust 活动会话存在 TOCTOU 竞态

`pomodoro_start_session`：`peek_active()` 检查与 `put_active()` 放入是两次独立加锁——并发两个 start 都可能通过检查后互相覆盖；`pause/resume/stop` 的 `take_active()`→处理→`put_active()` 窗口期内会话不在锁内，另一线程 `peek` 得 `None` 可插入新会话，随后被 `put` 回来的旧会话覆盖（原会话无声丢失）。单客户端低频下概率小，但这是后端状态机的正确性缺口。
**修复**：收敛为单锁临界区原语 `with_active(app, f)`（锁内完成"db_name 校验 + 读/写"），start/pause/resume 走它；stop 在锁内取出并定稿字段、锁外落库，**落库失败把会话放回**（当前实现落库失败会话直接丢失）。

### 6. `pomodoro_delete_sessions` 无事务且返回值失真

逐条 `conn.execute(DELETE)` 不在事务中：中途失败留下半删状态；`total` 按入参计数而非受影响行数，含不存在的 id 也计数。
**修复**：事务包裹 + 累计 `execute` 返回的受影响行数。

### 7. History 页与 queries.ts 双轨查询，缓存碎片化

`PomodoroHistoryPage.tsx:74-87` 自写两个 `useQuery`：`["pomodoro","summary","week",weekOffset]`、`["pomodoro","sessions","week",weekOffset]`；而 `queries.ts` 已有 `usePomodoroWeeklySummary`（key `["pomodoro","summary","week"]` 无 offset）与 `usePomodoroSessions`（无 start/end 参数）。同域两套写法：当前周数据在两个近似 key 里各存一份，违背本仓"域查询统一收口 queries.ts"的既定模式（todo/diary 均如此）。
**修复**：`usePomodoroWeeklySummary(weekOffset)`、`usePomodoroSessions({ start, end, … })` 参数化收进 `queries.ts`，History 页改用域 hooks；`weekOffset=0` 与主页共享同一缓存。

### 8. 日期算法三处重复实现

`timer.ts` 已有 `startOfDay/weekDayStarts/weekdayIndex`；`PomodoroHistoryPage.tsx` 又实现 `startOfWeek(offsetWeeks)`、`DAY_MS`、`today = new Date(new Date().setHours(0,0,0,0)).getTime()`——"本地零点""周一锚点"两概念各自三份实现，DST/口径调整时极易改漏。
**修复**：`timer.ts` 补 `startOfWeek(offsetWeeks, now)`（History 版语义），History 页与 queries.ts 统一复用；纯展示格式化（`formatDayLabel` 等）留在页面。

### 9. `startPreset` 失败仍然推入沉浸页

`PomodoroPage.tsx:96` `controller.start(preset).then(() => onOpenFocus())`——`start` 内部 catch 吞错后正常 resolve，`onOpenFocus()` 无条件执行；失败时沉浸页随即因"无会话"自动退场，表现为一次闪屏跳转。
**修复**：`controller.start` 返回 `Promise<boolean>`，失败返回 `false`；`then(ok => { if (ok) onOpenFocus(); })`。

## P3 — 低（风格 / 一致性，顺手修）

### 10. 隐藏图标 hack

`PomodoroHistoryPage.tsx:124` "删除记录"传 `icon: <MoreHorizontal size={16} className="hidden" />`——`ActionSheetItem.icon` 本就是可选字段，直接省略即可。

### 11. payload 定义位置不一致

`pomodoro.rs:384-394` `DeletePomodoroPresetPayload`/`DeletePomodoroSessionPayload` 落在文件中部（预设命令与会话命令之间），其余 payload 全部集中在顶部"── payload ──"区块。上移合并。

### 12. `PomodoroStatus` 缺 `"aborted"`

`types.ts` 声称"与桌面端同构"，但桌面端 `PomodoroStatus` 含 `"aborted"`（types.ts 移动端版缺失）。两端共享同一数据库文件，桌面端写入的 aborted 会话同步到移动端后，类型收窄失真、`status === "stopped"` 判定落空（无"提前结束"标签）。补全类型，History 页 `stopped | aborted` 都按提前结束展示。

### 13. 正计时保存强制把 `durationMin` 写成 25

`PresetEditPage.tsx:66` 编辑时 `durationMin: mode === "countdown" ? durationMin : 25`——后端对 `None` 本就保留原值，此处应传 `undefined`，否则"倒计时45→切正计时保存→切回倒计时"时长被静默重置为 25。

### 14. 沉浸页光晕样式内联硬编码

`FocusImmersivePage.tsx:169-172` 内联 `rgba(217,119,87,…)` 渐变 + 内联 animation 名，而 `@keyframes pomodoro-breath` 在 styles.css——同一视觉资产分散两处且颜色绕开主题变量。收进 styles.css 一个类。

### 15. 编辑不存在的预设是死胡同

`PresetEditPage` 在 `presetId` 无效（预设已删/链接过期）时表单永远空、`hydrated=false`、无提示。presets 加载完成且查无此预设时展示"预设不存在或已删除"空态。

## 第二轮复审结论

**PASS（无遗留阻塞问题）**。复审覆盖全部 15 项修复的落地代码与最终 `git diff`，结论如下：

1. **15 项修复全部落地且语义正确**：逐项核对了修复代码（controller 状态机、归档分区渲染、Rust `with_active` 临界区、事务化删除、域 hooks 收口等），未发现修复不完整或引入回归。
