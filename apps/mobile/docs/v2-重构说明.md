# v2 全面重构说明（对齐 design-proposals/v2-apricot.html 模板）

> 本轮重构按用户确认的 v2 原型严格执行：UI、交互、布局全部重做，而非仅换样式。

## 信息架构

- 底部导航改为 **4 Tab + 中央 FAB**：今天 / 卡片 / 日记 / 我的（`components/AppDock.tsx`，AppShell 全局挂载）。
- Tab 切换语义：栈内已有则 `popTo`，否则 `push`（`router/switchTab.ts`）。
- Dock 仅在 Tab 根与任务中心显示；编辑器/详情/搜索等二级页自动隐藏。
- FAB 点击弹出三类快捷创建：新卡片（quickCapture）/ 写日记（当天首个片段）/ 新任务（todo 页自动弹创建面板，`openCreate` 参数）。
- 桌面版功能持续迁入的承接位：「我的」页功能宫格（已上线直达 + 「即将」预告）。

## 主题系统

- `theme/themeStore.ts`：杏子（默认）/ 玄夜（深色）/ 薄荷 / 海盐 + 跟随系统；旧值 `dark|light|nocturne` 自动迁移。
- 生效方式 `html[data-theme]`，玄夜同步挂 `.dark`（编辑器包兼容）；深色判定统一走 `.dark` 类（editorRegistry/useMobileTheme）。
- `styles.css` 四套完整令牌（背景/文字/线/品牌/六组粉彩语义色/阴影/Dock/Toast/纹理）；**卡片白描边已移除**（`--hairline: transparent`）。

## 页面

- **今天（首页）**：纯仪表盘——搜索条、Bento 统计（任务大数字+进度条，无圆环）、今日任务摘要（可就地勾选，`todo/toggleComplete.ts` 共用循环任务语义）、最近动态（卡片/日记/任务混排）。
- **卡片库**：v2 页头（大标题+搜索），chips 筛选；列表项 **无 more 按钮**，修改类型/删除收进预览面板头部。
- **日记**：改为**信息流**（按月分组 + 片段数/字数/心情），顶部快捷输入对准今天；日历降级为右上角 BottomSheet 查找入口。
- **任务中心**：大数字 + 细进度条统计头（数字再大不溢出）；标题改「任务中心」。
- **我的**：v2 页头（日记统计）+ 功能宫格 + 原设置分组；子模块返回键回到根视图而非退出页面。

## Bug 修复：日记 NOT_FOUND

后端 `hydrate_entry` 已把日记改为**多片段模型**（`entry.contentId` 恒为 null，内容挂在 `diary_segments`）。
移动端 `openAt` 旧逻辑返回 `current.contentId` 永远为空 → `DIARY_CONTENT_NOT_FOUND`。
修复：`useDiaryStore.openAt` 改为返回**首个片段的 contentId**（`firstSegmentContentId`）。

- 新增：`components/AppDock.tsx`、`router/switchTab.ts`、`features/diary/feedUtils.ts`、`features/todo/toggleComplete.ts`、`features/todo/TodoCheck.tsx`
- 删除：`components/FloatingToolbar.tsx`（被 AppDock 取代）
- 契约测试同步：icons 清单、topbar 安全区契约（Tab 根页改 pagehead 模式）、ThemeSection 四主题断言
