PageHeader 顶栏按钮 · 去背景沉浸方案

现行 方案 D：返回 / more 按钮为 40×40 卡片实底（bg-surface #fffdf9）+ 双层阴影（shadow-card）， 在奶油纸底与封面图上都偏「浮起」，沉浸感弱。以下 A / B / C 为去背景的三个候选， 每个方案均在「奶油纸底（常规页）」与「封面图底（transparent 沉浸页）」两种场景下演示。 按钮热区仍为 40×40，active 缩放反馈与现行一致。

方案 A · Ghost 裸图标 最沉浸

完全去掉底色与阴影，只留图标；按压时浮现一团淡墨色圆形反馈。图形语言最轻，顶栏与页面融为一体。
