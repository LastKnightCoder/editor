方案 C · 极简分组

参考 Apple 设置 / Working Copy 的导航纪律

核心思路

  • 主页只做选择：单选组 + checkmark，一屏放得下全部入口，零学习成本
  • 所有细节进子页：状态详情、服务配置、资源同步都是 push 页（原型可点，带转场动画）
  • 危险操作归组：整库上传/下载放进独立「危险区」分组，红色文字 + sheet 确认
  • ⓘ 与选择分离：点行 = 切换选择，点 ⓘ = 进配置（Wi-Fi 设置模式）

演示 · 主题

可点击：状态行 → 同步详情；服务行 ⓘ → 配置页；资源同步行 → 进度页。
