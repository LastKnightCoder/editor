方案 B · 连接卡片

参考 Stripe / Linear 的 Integrations 页

核心思路

  • 消灭「集成」分段：凭证 + 业务参数合并到同一张「连接卡」，一站式配置，不再跨页跳转
  • 连接有生命周期：未连接 → 已连接 → 使用中，三态徽章一眼看清
  • 显式启用：用「设为同步服务」主按钮表达单选，不用伪装成开关的 Switch
  • 状态条常驻顶部：数据库同步状态压缩成一行，点击展开完整操作
  • 分段从 4 个减到 2 个：同步 / 资源

演示 · 主题

点卡片上的「配置」展开凭证+参数；点「设为同步服务」切换当前服务。
