主题同步：主题名跟桌面，深浅各管各

插件改为直接使用 @tau/themes 的六个主题（暖纸 / 海盐 / 薄荷 / 紫藤 / 樱花 / 水墨），不再维护自己那套灰蓝配色（style.css 里的 --color-* + tau-tokens.css 桥接）。
  • 同步的：主题族名称。桌面切到「樱花」，插件随之变成樱花（连接时读取一次，之后实时推送）。
  • 不同步的：深浅。插件自己选「跟随系统 / 浅色 / 深色」，默认跟随系统——浏览器和桌面常在不同环境下用。
  • 桌面未连接时，沿用最后一次同步到的主题名（存在扩展本地），不会闪回默认主题。
用顶栏的「桌面端主题」按钮模拟桌面切换主题，所有 mockup 页都会跟着变。

实现要点

① 侧栏 <html data-theme data-mode> 与桌面同一套 tokens.css，删除扩展私有配色与桥接；
② 桌面 aiServer 新增 appearance.getTheme 请求与 appearance.themeChanged 通知（只带主题 key，不带深浅）；
③ 扩展 chrome.storage.local 记最后一次主题 key，首帧脚本先读它，避免闪烁；
④ 页面内的划线工具条（content script）也换同一套 token，跟侧栏同主题。

两个设置方案

S1 可脱离：默认「跟随桌面」，关掉后可在插件里单独选主题。
S2 只跟随：插件不提供主题选择，只显示「暖纸 · 在桌面端更改」，设置更少。
推荐 S2：你说「主题名称同步」，S2 最直接；有人想分开再加开关。
