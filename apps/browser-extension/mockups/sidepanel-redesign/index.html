浏览器插件侧栏重设计 · 三个方向

现状的问题：底部四个纯图标页签要猜意思；外观是一套单独的灰蓝配色，和桌面不像；设置、刷新、全部笔记散在头尾两处；看不出侧栏在说哪一页。 三个方向都用桌面的主题、对话消息与输入框（上一轮已共享），区别在信息怎么组织。
标 新增? 的是现在没有的功能，选方向时一并告诉我做不做。

A · 顶部页签

结构不变：概览 / 对话 / 笔记 / 高亮四个页签，从底部图标挪到顶部文字页签；顶栏显示当前网页。改动最小。

B · 阅读伴侣

不分页签，一页一张纸：总结 → 高亮 → 笔记从上往下排，底部常驻「问这一页」。对话和笔记编辑是进入的二级页。

C · 对话为主

和桌面停靠栏同构：主体是对话，总结是开头一张卡；高亮、笔记从顶栏计数按钮拉出底部面板。
A 顶部页签B 阅读伴侣C 对话为主
主要动作四块平级，切页签读、划线、记笔记（边读边看）提问
划线后切到「高亮」才看得到流里立刻多一条顶栏计数 +1，点开面板看
记笔记笔记页签，直接编辑点卡片进入整页编辑顶栏笔记面板 / ＋ 面板
与桌面一致性中中（对话页与桌面一致）高（就是停靠栏）
改动量小：换皮 + 导航收口大：重排主界面与导航中：对话页扩成主界面，其余做成面板
适合想先换掉外观、保留习惯插件主要用来读书摘录插件主要用来问 AI
我的倾向：B。插件独有的价值是「这一页上的痕迹」（划线、想法、笔记），对话桌面已经有了；B 让这些痕迹一屏可见，追问也随手可得。 如果你主要用插件问 AI，选 C。主题同步与三个方向无关，单独看 主题同步。
