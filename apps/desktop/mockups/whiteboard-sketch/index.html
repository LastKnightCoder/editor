白板手绘风格重构 · 三个方向

现状的「草图风格」是 rough.js 的一层薄封装：只有形状和连线能开，每个元素单独开关，属性面板直接暴露 rough.js 的 7 种填充 + 粗糙度 / 填充角度 / 填充间距 / 填充粗细四根滑杆。读完代码后，问题不只是参数没调好，而是三层都缺：笔迹本身（等宽线、机械排线、圆角抖成麻花）、心智模型（手绘是元素特效而不是白板的画风，文字、画框、导图都不跟随）、实现（命令式 DOM、箭头每次重绘随机 seed）。

三个方向共用同一套「地基」改动（白板级画风、三档笔触、五种填充、seed 固定、手写字体），区别只在笔迹怎么画。mockup 用的是项目里同版本的 rough.js 4.6 与 perfect-freehand 1.2，算法可直接搬进 src/。

二 · 设计原则

  • 手绘是白板的画风，不是元素的特效。一个开关整块白板切换（画框、形状、连线、文本、导图一起变），元素可以单独覆盖。正式场合一键切回「普通」导出。
  • 参数说人话。笔触只有「工整 / 自然 / 潦草」三档；填充收敛为「无 / 淡涂 / 斜线 / 交叉 / 涂鸦」五种；排线角度、间距、粗细按形状尺寸与线宽自动算，不再给滑杆。多一个「换一笔」，不满意就重摇。
  • 笔迹稳定。seed 落进元素数据（连线也是），拖动、缩放、撤销、重开都是同一笔；抖动是「沿弧长的连续函数」，端点移动时线形平滑变化，不跳。
  • 文字跟着变。手绘时形状内文字、文本、连线标签、画框标题换手写字体，这是「像手绘」最大的单项来源。
  • 克制。卡片 / 图片 / 视频 / 网页 / 白板引用是「内容」，不手绘；选中框、控制点、参考线等 chrome 永远普通（D-049）。用户选的颜色原样渲染，只有未指定颜色时默认墨色跟主题 ink。

三 · 三个方向差别只在「笔迹怎么画」

方案 A

纸笔 · rough.js 调优

保留 rough.js，把参数调对：单笔描边（潦草档才双描）、-41° 排线、间距 / 粗细随线宽与尺寸、圆角与心形先采样成折线再抖、箭头改开口两笔且尺寸封顶 22px。观感接近 Excalidraw。

＋ 改动最小，用户熟悉的白板手绘语言－ 等宽线条，「电脑模拟手绘」的感觉还在成本：S（参数 + 轮廓采样 + seed）
方案 B 推荐

墨水 · 变宽墨迹 + 马克笔淡涂

形状轮廓一笔绕一圈、收尾轻微搭接；用 perfect-freehand 描成起笔重、收笔轻的变宽墨迹。填充是马克笔淡涂：轮廓外扩抖动 + 套色错位 3px，multiply 叠在纸上，文字始终清楚。与现有「手写」工具同一个墨水引擎，批注和图形终于是同一支笔。

＋ 最像真人用笔，好看的关键在「线有粗细」＋ 可移除 rough.js 依赖；纯 path、无滤镜，导出图片零改动－ 轮廓采样 / 抖动 / 描边需自写（约 300 行纯函数，可单测）成本：M
方案 C

铅笔 · 多遍细线 + 出头

直边按边拆笔、两端出头交叉，两遍细线叠出铅笔的深浅；曲线绕两圈；填充是彩铅排线。最有「建筑速写」的结构感。

＋ 结构感强，适合草图构思－ 细线在缩小、深色主题下发虚；元素一多显得「脏」－ 不适合信息密集的知识白板成本：M

四 · 交互改版整板演示里可以直接点

白板级「画风」—— 右下状态栏

状态栏最前面一个按钮「✎ 手绘 · 自然」，点开菜单：画风「手绘 / 普通」（带一句说明）+ 默认笔触三档。切换即时作用于整块白板里没有单独设置过的元素。数据挂在白板（页）上，随白板保存。

新建元素跟随页面画风，不再用 localStorage 记忆 sketchEnabled / sketchOptions。

元素级「笔触」—— 浮动属性条的一项

替换现在的「草图风格」开关 + 四根滑杆。弹层三段：画风「跟随页面（显示当前值）/ 手绘 / 普通」→ 笔触三档 → 填充五种（缩略图用真实渲染画）；底部「🎲 换一笔」。条目上直接显示当前档位（如「自然」），不用点开就知道状态。

多选时同一弹层批量改；普通模式下只留一句说明，不摆禁用控件。

六 · 实现草案以方案 B 为例

// 白板（页）级：画风默认值
interface BoardSketch { style: "hand" | "precise"; level: "neat" | "natural" | "loose" }

// 元素级：可选覆盖 + 固定笔迹种子（形状 / 连线 / 画框 / 文本 / 导图节点共用）
interface ElementSketch { style?: "hand" | "precise"; level?: SketchLevel; seed: number }
// 形状的填充样式与画风无关，普通模式下 hatch / cross / scribble 退化为实色淡填
type FillStyle = "none" | "wash" | "hatch" | "cross" | "scribble"

// 渲染：纯函数，输入几何 + 样式 + seed，输出 path 列表；组件里 useMemo 缓存、声明式 <path>
sketchShape(input): SketchPath[]   // { d, fill?, stroke?, opacity?, blend? }
sketchArrow(input): SketchPath[]
  • 删掉 sketch/ 下的 Manager 单例 + 抽象基类 + 三个子类，和命令式的 SketchRenderer.tsx / SketchArrow.tsx（576 行）；换成 utils/sketch/ 一组纯函数（轮廓采样 / 抖动 / 墨迹 / 填充），单测覆盖「同 seed 同输出」「端点微移输出连续」。
  • 导出图片：输出全是普通 path，没有 SVG filter，ExportImagePlugin 不用改；缩略图（D-047 复用导出管线）同样受益。
  • 性能：每个元素一次轮廓计算（perfect-freehand 单笔 ~0.1ms），按几何 + 样式 + seed 做 memo；拖动时只重算被拖元素与相连连线。
  • 数据升级（D-091）：旧 sketchEnabled: true → 元素级 style: "hand"；roughness → 档位（<0.8 工整 / <1.6 自然 / 其余潦草）；fillStyle hachure→hatch、solid→wash、cross-hatch→cross、zigzag / zigzag-line→scribble、dots / dashed→hatch；角度 / 间距 / 粗细字段丢弃。白板默认「普通」，存量白板打开后观感不变。

七 · 待拍板

1. 方向：A / B / C？

推荐 B：好看的关键是线有粗细与收笔，等宽线怎么调都像程序画的；它和手写工具同一支笔，还能顺手去掉 rough.js。A 可以作为「最小改动」的保底。

2. 画风放在白板级 + 元素覆盖，还是只保留元素级？

推荐白板级 + 覆盖：手绘是一种整体氛围，逐个开关既累又容易混搭；同时保留元素覆盖，满足「这块白板手绘，但这张图要普通」。

3. 手写字体：系统回退还是打包？

mockup 用系统字体回退（macOS 手札体 / 翰字铅笔 / 楷体，Windows 楷体），零包体，但各平台观感不一、部分 macOS 字体需要按需下载。打包一款开源手写字体（如 小赖字体、Excalifont 拉丁部分）能保证一致，代价是数 MB 包体，且导出 / 缩略图要内嵌字体。

4. 思维导图跟不跟随画风？

导图有自己的主题（配色 × 风格），手绘可以作为它的第三个维度，也可以干脆不跟随。mockup 里画成了跟随。

5. 新建白板默认画风？

推荐默认「普通」，手绘由用户在状态栏一键打开；存量白板升级后观感不变。

6. 填充从 7 种砍到 5 种可以吗？

去掉「点状」「虚线填充」（小尺寸下和斜线难分），「锯齿」「锯齿线」合并为「涂鸦」。
