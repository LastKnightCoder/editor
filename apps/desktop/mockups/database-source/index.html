待定的问题

1. 第一批接哪些建议先做待办、日程、日记三个：字段结构稳定、最常被拿来做汇总和看板。卡片、文章这类正文为主的源，表格能给的增量小，可以放后面。
2. 删除行删不删源头稿子里是「删除行 = 删除源头条目」并在菜单里写明。另一种做法是关联表不能删行，只能在源头删，更安全但不顺手。
3. 文档待办能不能在表里勾文档待办以正文为准。勾选写回正文在技术上可行（改对应勾选项），但正文正被打开编辑时会有冲突，需要确认要不要做。
4. 复制一份要不要保留它和现有的 CSV 导入是同一类能力。如果只做「保持关联」，弹窗会更简单，想要独立副本可以事后「转为普通表」。
