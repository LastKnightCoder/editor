方案 A · 列表 + 详情双栏（参考 Cherry Studio「MCP 设置」、VS Code MCP 视图、macOS 系统设置）

一张纸左右两栏：左侧 300px 是服务器列表（内置 / 自定义两组，每行带状态点和开关），右侧是选中服务器的详情——头部是身份 + 状态 + 启停，下面三个标签页：工具（逐个开关 + 执行前确认策略）、配置（结构化表单，可切 JSON）、日志（stderr 与连接事件）。内置服务器只有「工具」页。
  • 添加入口在列表顶部「＋」，打开共用的添加弹窗（常用服务器 / 手动填写 / 粘贴 JSON）。
  • 连接失败的服务器：侧栏条目上挂红色徽标，列表行变红字，详情顶部横幅直接给出原因和「去配置 / 看日志 / 重试」。
  • ＋ 服务器 10 个以上也不乱；查错、改配置、看工具都在一处，不用来回开关弹窗。和 Skill 管理页（左树右详情）是同一种结构。
  • － 服务器很少（1~3 个）时右侧显得空；信息密度偏工具型，不如卡片好看。
