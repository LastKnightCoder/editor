表格 · 合并单元格

在定稿的「边缘手柄 + 细框线」上增加合并 / 拆分。下面的表格可以真的操作，右侧实时显示按推荐数据结构存下来的模型与导出结果。

00现状：数据模型不支持合并

  • 没有跨度字段。TableCellElement 只有 type 和 children。
  • 不变式按满格矩形写死。normalize.ts 把每行补齐到最大列数；如果像 HTML 那样省略被覆盖的格，下一轮 normalize 会把它们补回来。
  • 所有能力都按「路径下标 = 逻辑坐标」寻址。行列增删移动、格选区矩形、复制子表、粘贴填充、手柄几何（measureTable 取首行 cells 当列）、移动端 editingContext 都依赖这一点。
  • Markdown 是 GFM 表格，语法里没有合并，导出必然有损。

所以需要扩模型。推荐方案保留满格矩形和「下标 = 坐标」，改动面最小，见 03。

02行为规则

  

    
场景规则理由

    
入口格选区 ≥ 2 格时，选区右下角浮出「合并 n 格」角标；选区恰好是一个合并格时变成「拆分单元格」。行 / 列手柄菜单在所选行列含合并格时多一项「拆分合并单元格」。只在有选区时出现，不给普通编辑加噪音；和手柄菜单是同一套浮层。

    
合并内容所有非空格的内容按阅读顺序拼进左上格，格之间用软换行；其余格清空。合并后选中新格，可以直接再拆。不丢内容。只有一格有内容时不产生多余换行。

    
拆分内容留在左上格，其余格为空。⌘Z 一步回到合并前。和 Google 文档、飞书一致。

    
选区矩形碰到合并格的一部分时，扩到包住整块，反复扩到稳定。整行 / 整列选区不扩。保证合并区域永远不会被切开。

    
插入行 / 列插在合并区域内部：区域跨度 +1，新格成为被覆盖格。插在边界上：不影响。和电子表格一致。

    
删除行 / 列删掉区域的一部分：跨度收缩；左上格所在行 / 列被删时，内容和跨度移到剩下的第一行 / 列。区域全被删时随之消失。不留下悬空的跨度。

    
拖动排序被拖的行 / 列在某个多行 / 多列合并区域里，或放置位置落在区域内部：放置线变红，松手不移动并提示原因。移动会切开区域。先拆分再移动，规则简单可预期。

    
导航Tab 跳到下一个非覆盖格；Enter 跳到合并格底边下一行的同列格；↑↓ 同理按区域边界跳。光标不会落进被覆盖格。被覆盖格不可见。

    
对齐合并格用左上格所在列的对齐；垂直方向保持顶对齐。对齐仍按列存储，不新增格级字段。

    
表头首行仍是表头。允许表头内横向合并；跨表头和正文的合并按表头样式渲染。不额外设限，见 04 待定。

    
复制选区已扩成完整区域，子表片段带跨度；HTML 写 rowspan / colspan；TSV 被覆盖格为空。粘回编辑器和粘到飞书 / Word 都保留合并。

    
粘贴粘贴区域覆盖到的合并格先拆分再填充。从网页 / Word 粘贴带 colspan / rowspan 的 HTML 表格时还原合并。现在 parseHtmlTable 已处理 colspan（补空格），改为保留跨度。

  






  
03数据结构 推荐方案 A

  
实现后的规则见 packages/editor/src/extensions/table/README.md。这里只比较三种存法。

  

    

      
A · 满格矩形 + 左上格带跨度 推荐

      
每行仍然有全部列的格。左上格存 colSpan / rowSpan（等于 1 时省略），被覆盖的格保留为空的占位格，渲染成 hidden。被覆盖状态由跨度推出，不单独存。

      
    
        
  • 路径下标仍等于逻辑坐标，现有变换、选区、粘贴、移动端都只需「加规则」不需「改寻址」
    • 
        
  • 字段落在格上，复制出的子表、HTML 序列化自带跨度
    • 
        
  • 旧数据零迁移：没有跨度字段就是普通表格
    • 
        
  • 占位格要靠 normalize 保持为空、光标要绕开
    • 
      

    

    

      
B · 省略被覆盖格（HTML / ProseMirror 式）

      
格带跨度，被覆盖的格不存在，各行长度不同。需要一张 TableMap 把逻辑坐标换算成路径。

      
    
        
  • 和 HTML 一一对应，没有占位格
    • 
        
  • 路径不再等于坐标：transforms / selection / paste / geometry 和移动端全部要改成经 TableMap 寻址
    • 
        
  • 「每行补齐」不变式要重写成「按跨度算宽度后补齐」
    • 
      

    

    

      
C · 表级 merges 数组

      
格不变，表上加 merges: [{ row, col, rowSpan, colSpan }]，类似现在的 align。

      
    
        
  • 格节点完全不动
    • 
        
  • 每个行列变换都要二维重算坐标并整体 setNodes，协同时任意两个合并操作都冲突在同一个属性上
    • 
        
  • 格自身不知道自己的跨度，渲染、复制都要回查表
    • 
      

    

  






  
04需要你拍板

  

    
① Markdown 导出
GFM 表示不了合并。降级：左上格保留内容，被覆盖格写空，Markdown 往返会丢掉合并（编辑器自身存 JSON，不受影响）。或者：有合并的表整张导出成 HTML <table>，往返无损但 Markdown 里可读性差，导入侧也要新增 HTML 表格解析。
建议：降级为 GFM。

    
② 跨表头合并
是否允许把表头行和正文行合在一起？允许时那一格按表头样式渲染；禁止时选区跨首行就不出现「合并」。
建议：允许，不额外设限。

    
③ 入口
除了选区角标和手柄菜单，要不要加快捷键（如 ⌘⇧M 合并 / 拆分切换）？移动端是否这一期就做（工具栏表格面板加「合并 / 拆分」）？
建议：桌面端角标 + 菜单先做，移动端下一期。
