阅读时标记 mockup 形态 A 段落右侧细点 B 节末一行 C 只在浮层里 页面 文章 卡片 状态 阅读 正在输入

要回答的问题：读的时候提醒「这一节和别处在说同一件事」，又不打扰

  • A 段落右侧细点：节首右侧页边一个很淡的点，悬停提示「和《X》相近」，点开在这一节下面就地展开。位置精确到节，余光可见又几乎不占地方。页边窄时没地方放；点很小，容易被当成装饰忽略。
  • B 节末一行：这一节读完时出现一行小字「这一节和《X》相近」。出现在读完一节的停顿处，时机最自然；窄窗口也能放。占正文纵向空间，三处就是三行。
  • C 只在浮层里：正文不加任何东西；打开「N 处关联」浮层，「相关」行带上「← 第 N 节」，悬停时正文那一节淡淡高亮。零打扰，只是给 7a 的「相关」补上落点。不打开浮层就看不到，谈不上「阅读时」。
  • 三种共用的约束（待确认，见 docs/knowledge-loop/15）：每篇最多 3 处；正在输入时隐藏，停下 2 秒后再出现；「忽略」只对这一条生效。卡片页只作对照：推荐卡片不出标记（整张一节，与浮层「相关」重复）；长文与卡片之间不能添加连接，展开卡里的「添加连接」只在卡片页出现。
