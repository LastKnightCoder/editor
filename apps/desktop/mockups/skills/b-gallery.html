方案 B · 卡片库 + 预览抽屉 + 整页编辑器（参考 Claude.ai「设置 → Capabilities → Skills」、与 MCP 页 D-058 同构）

整页卡片网格（我的 / 内置 / 关联目录 / 示例），卡片上直接开关、看调用方式与使用次数。点卡片从右侧滑出预览抽屉（概览 / 设置 / 使用记录）；点「编辑」推入整页编辑器：左文件树、中间 SKILL.md（表单 + 正文）、右侧「试一试」对话用未保存版本实时验证。
  • 「示例」区放几份写得好的 Skill，一键「复制为我的」再改——比空白模板更容易上手。
  • ＋ 与 MCP 页交互完全一致（卡片 + 抽屉），AI 组两页一套心智；浏览 / 管理轻、编辑重，分开后各自都舒展；「试一试」让写 Skill 有即时反馈。
  • － 层级多一层（卡片 → 抽屉 → 编辑页）；Skill 很多时卡片网格的信息密度不如列表。
