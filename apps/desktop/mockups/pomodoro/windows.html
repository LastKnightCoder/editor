小窗与沉浸窗 · 形态候选

两者都是 Electron 独立窗口（Web 端不渲染入口），与主页面共享同一个主进程会话。每种形态都接了实时计时：用右上角按钮切换专注 / 暂停 / 快进，鼠标悬停小窗可看到隐藏的控件。三个页面方案都可以搭配任意一款，页面 mockup 里点「小窗」「沉浸」弹出的是默认款（M1 / I1）的示意。

小窗 · always-on-top

legacy 是 240×130 的无边框置顶窗：左边进度环（悬停出暂停 / 结束），右边时间和预设名，右上角是关闭按钮。小窗的目的是在别的应用上面扫一眼剩余时间，所以信息只留时间和预设名，控制收进悬停态，窗口越小越好。拖动整个窗体就能移动，不单独画标题栏。

M1 胶囊300 × 64 · 推荐默认
环本身就是暂停 / 继续按钮，悬停时环心出现图标。信息和 legacy 一样，高度只有它的一半。
M2 方块184 × 184
最接近 legacy 的形态，适合副屏一角。控件悬停时才出现，平时只有圆环和数字。
M3 细条380 × 38
最省地方，可以贴在屏幕顶边或菜单栏下面。进度用底边一条 2px 细线表示，和方案 C 的控制条同一种语言。

沉浸 · 全屏

legacy 用的是翻页钟（FlipClock），视觉上偏装饰。三款都取纸底加一个锚点：Esc 退出，空格暂停 / 继续，鼠标静止 2 秒后控件自动隐去。

I1 大字钟推荐默认 · 页面 mockup 里点「沉浸」即此款
Esc 退出
数字占据视觉中心，只保留一条细进度线。暂停时数字退成 ink-3，不闪、不变红。
I2 呼吸环
Esc 退出
accent-soft 光晕按 8 秒一个周期缓慢缩放，可以当作呼吸节拍来用；和方案 A 的圆环同构。遵循 reduced-motion 时静止。
I3 今日时间带
Esc 退出
底部放今天的时间带，当前这一段会跟着增长，让人看到这一段落在一天中的位置。和方案 C 的账本同构。

对照

款式尺寸常显信息控制与页面方案的亲和
