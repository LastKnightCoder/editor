个姿态 × 3 种形体 × 普通 / 手绘。人物以「关节骨架 + 道具图元」数据存储，渲染时才决定笔触：手绘复用页级手绘模式的墨水引擎与固定 seed，墨色走 currentColor、填充只用主题变量，所以深浅主题、手绘开关都不需要第二套素材。点击任意卡片可复制当前样式的 SVG。

形体取舍

  • A · 经典：线条火柴人，最轻、最不抢戏，适合流程图里当「角色标记」；缺点是缩小到 40px 以下时四肢会糊成一团。
  • B · 豆豆：胶囊身体 + 实心头，可着色区分角色（多人场景自动轮换主色 / 标签色），适合用户旅程、角色关系图；视觉更重，需要和形状填充色协调。
  • C · 象形：粗线 + 实心头，类似公共标识，小尺寸可读性最好，适合当图标嵌进卡片或连线标签；手绘时笔触宽度变化最不明显。
  • 建议：首批只做 A + B 两种形体、手绘跟随页级模式（不单独给人物一个开关），C 作为后续「图标化」需求再评估。
