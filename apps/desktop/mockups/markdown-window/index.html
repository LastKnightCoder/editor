本章回顾与本文密切相关的三类研究：间隔重复算法、知识追踪模型，以及基于大语言模型的学习辅助系统。

2.1 间隔重复算法

自 Ebbinghaus 提出遗忘曲线以来，间隔重复（Spaced Repetition）成为记忆研究的经典范式。SM-2 算法以固定的难度系数调整复习间隔，而 FSRS 则引入了可检索性与稳定性两个隐变量。

记忆的稳定性决定了遗忘速度；每一次成功回忆都会让稳定性增长。

2.1.1 SM-2 与其变体

SM-2 的核心更新公式如下：

EF' = EF + (0.1 - (5 - q) × (0.08 + (5 - q) × 0.02))

③文件树操作

现在只能在根目录新建文件、文件夹没有任何操作、删除是永久删除。改为：

  • 右键菜单（文件与文件夹都有）：新建文件 / 新建文件夹（建在该目录下）、重命名（F2）、复制路径 / 相对路径、在访达（资源管理器）中显示、移到废纸篓（shell.trashItem，可恢复）。
  • 行内编辑：新建与重命名都在树里原地输入（VS Code 式），Enter 确认、Esc 取消；重命名默认只选中文件名不含扩展名；同名 / 非法字符原地红框提示，不再弹 Modal。
  • 拖拽移动：拖到文件夹上高亮落点，松手移动；移动当前打开的文件时编辑区跟随新路径（图片等相对引用不改写，给出提示）。
  • 筛选：顶部按文件名即时筛选（命中高亮，自动展开命中所在目录）。全文搜索页签下一轮。
  • 显示规则：隐藏以 . 开头的文件和目录、node_modules；不支持的文件类型默认隐藏（⋯ 菜单「显示所有文件」切换）；展开状态按文件夹记忆。
  • 侧栏标题行：文件夹名 + 新建文件 / 新建文件夹 / ⋯（刷新、打开其它文件夹、最近打开、显示所有文件、在访达中显示）。

④外部文件同步

文件在别的编辑器（VS Code、git pull、同步盘）里被改动时：

  • 本地无未保存改动：静默重载，底部轻提示「已同步外部修改」1.5s 消失，光标尽量保持在原位置（按行映射）。
  • 本地有未保存改动（冲突）：纸面顶部横幅「文件已在外部修改」——[载入外部版本] [保留我的版本]（保留即用本地覆盖写回）。替换现在的 Modal，不打断输入。
  • 文件被删除 / 移走（现在没处理）：横幅「文件已不在磁盘上」——[重新保存到原位置] [另存为…] [关闭]；编辑内容保留在内存里不丢。
  • 目录变化：文件树只刷新变化的那一层（现在是任何变化都整树重读）。
