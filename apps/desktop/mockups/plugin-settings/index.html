插件详情 › 设置：层次感方案

以 OpenAI 图片（多账号 · 声明式表单）为样本，单账号插件（同步 / 发布 / 语音识别）走同一套容器。

为什么看着没层次

  • 白卡叠白纸：详情页本身是 bg-surface + shadow-card 的整张纸，字段组却用默认 Panel raised（同色 + 阴影），只剩一圈若有若无的影子。Panel 自己的注释写着「纸上再叠阴影卡会糊成一片，用 outline」。
  • 同一页四种容器：账号 / 账号名称是裸行，「连接」是阴影卡，「模型」又是裸行，TTS 的音色复刻是描边框——用户分不清谁跟谁是一组。
  • 层级被拍平：真实结构是「账号 › 连接 / 模型」，现在账号行、连接组、模型行、保存栏是平级的，保存栏到底保存谁也不直观。
  • 标题重复：只有一个设置分组时，「OpenAI 图片」小标题与页头同名，白占一层。

三个方向

方案做法改动适合
A 统一描边分组所有组一律 outline；账号行收进「账号」组，模型进「模型」组；单分组隐藏重复标题小：ProviderFormFields 改 outline、ProviderAccountSettings 套组先止血
B 账号即卡片（推荐）顶部账号胶囊切换；当前账号是一张卡：卡头（名称 / 使用中 / ⋯）、卡身（连接、模型小节）、卡脚（保存栏）中：新增 AccountCard，表单分组在卡内渲染为小节多账号与单账号同一结构
C 列表 + 详情左列账号列表（带摘要），右侧同 B 的卡片中偏大：窄屏要回退账号常 ≥4 个时
