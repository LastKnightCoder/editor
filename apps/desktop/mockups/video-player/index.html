视频播放器 · UI 与交互升级

编辑器视频块、视频笔记、Vibe Learning 预览、白板视频共用 @tau/shared 的 VideoPlayer，这里的方案会一次作用到所有场景。三套方向的控件组成相同，差别在控件放在哪里、画面被遮住多少。每套方案的第一个播放器都能点、能拖、能用键盘操作，页面里的标本也能直接交互。

00现状

按当前代码复刻（VideoPlayer + 编辑器视频块的选中态）。

  • 画面和纸面没有融合：直角黑框、直角选中描边，和纸面的圆角 + 投影语言对不上。
  • 皮肤不跟主题：控件写死 bg-black / text-white / bg-white/90，换主题、换深浅色都不变。
  • 悬停会撑开布局：音量滑条宽度从 0 撑到 80px，把倍速、全屏按钮挤开。
  • 控件隐藏后看不到进度：只能再悬停一次才知道播放到哪里。
  • 没有快捷键：空格、方向键都不响应；拖动进度条时只有时间提示，看不到画面。
  • 编辑态能力藏得深：选中后只有四个角的缩放点，对齐要去块菜单里找，宽度只能手动拖。
  • 异常态粗糙：缺少 metaInfo 时显示裸红字（#ff4d4f）。

A纸框底栏

视频放进一张 surface 卡片，控件是画面下方的一条纸色底栏，进度条贴在画面和底栏的接缝处。画面永远不被控件遮挡；底栏常驻、不随悬停显隐，右侧还能放来源和标题这类信息。

  • 优点：最像文档里的内容卡，和纸面语言一致；控件用主题色板（按钮用 accent 实底，进度条用 accent）；没有悬停显隐，布局零抖动；符合「悬浮控件不要半透明叠在内容上」。
  • 代价：比画面多占 48px 高度；全屏时底栏改成深色贴底，交互不变。

B浮岛胶囊

控件收进画面底部的一块不透明深色胶囊，悬停时出现，静置 2 秒完全收起，只在画面底边留一条 3px 的进度细线。画面占满整张卡片。

  • 优点：画面最大、最沉浸；控件都集中在一处，全屏和内嵌是同一形态；胶囊实底不透明，不会和画面混在一起。
  • 代价：悬停时会盖住画面底部约 54px（字幕区）；文档里并排多个视频时，每一个都是一块暗色画面，没有「卡片」的感觉。

C边缘极简

进度条就是卡片的下边沿（6px accent 细条，常驻），悬停时画面左下、右下各浮出一枚小药丸：左边是播放和时间，右边是音量、倍速、画中画、全屏。整块控件区最小。

  • 优点：静态时几乎没有 chrome，文档里最安静；进度常驻在边沿、不遮画面；两枚药丸只压住画面的两个角，遮挡最少。
  • 代价：边沿进度条只有 6px 高，靠一块向上扩展的 20px 透明热区来保证好拖；控件分在两处，找「倍速」要多扫一眼。

+交互升级（三案通用）

下面这些能力与选哪一案无关，控件是同一套，只是换色板（A 用纸面色板，B / C 用深色浮层色板）。标本统一用 A 展示。

⌨快捷键

只在播放器获得焦点（点过画面或 Tab 进入）时生效。编辑器里正文光标在别处时不拦截按键；Esc 退出全屏交给浏览器原生处理，不接入浮层的 Esc 仲裁。每次按键在画面中央弹出一个短暂的反馈条（OSD）。
