代码块 · 渲染与交互重设计

现状的右上角悬浮条混了「复制 / 开启 Diff 动画 / 新增步骤 / 删除步骤 / 翻页」五种职责，图标语义不清，分步内容在非悬停时完全不可见。下面先拆问题，再给外框三个方向和分步演示两种形态。所有块都可交互（悬停、点行号、切步骤）。

未开启时，悬浮条第一个按钮是 </> 图标，提示文字是「开启 Diff 动画」。

  1. 一条悬浮条五种职责：编辑步骤（+ / 删除）、播放（‹ › 2/3）、复制挤在一起；读者要的只有翻页和复制，作者要的是管理步骤。
  2. 入口不知所云：「开启 Diff 动画」用的是 </> 图标——整块都是代码，这个图标等于什么都没说；而且它不是 diff，是「分步演进 + 过渡动画」。
  3. 步骤不可见：不悬停时，一个有 3 步的代码块和普通代码块长得一样，读者不知道可以翻页，也不知道这是第几步、这一步改了什么。
  4. 顶部 3em 空白：只为左上角的语言选择器留位，正文第一行被推得很低，像少了个标题栏。
  5. 隐藏操作太多：折叠箭头、拖拽高度、行高亮（只能右键）都要靠猜。
  6. 浮条压在块边缘外：FloatingToolbar 带浮层阴影，和上一段正文重叠，视觉上像一个全局菜单，而不是属于这块代码的东西。

01外框：三个方向

同一段普通代码。原则：常用的露出来，不常用的收进 ⋯；工具不再浮在块外，而是属于块本身。行号可点击切换高亮（替代右键），三个方向通用。

A · 标题栏 推荐
36px 头部：语言 + 文件名（可选）｜ 悬停露出 复制 · ⋯

请求用户信息：

api/user.ts
  • 有固定位置放语言、文件名和动作，分步条也有天然的落脚处（见 02）
  • 复制按钮带文字，「⋯」收纳低频项，不会再有猜图标
  • 顶部空白变成有信息量的标题栏，代码首行不再被推低
  • 两三行的短片段也要多一行头部，显得略重
B · 角标
无头部；右上角淡色语言名，悬停展开成 语言 · 复制 · ⋯

请求用户信息：

  • 最轻，阅读态几乎只有代码，短片段很友好
  • 角标贴在块内，不再压到上一段正文
  • 没有文件名位置；分步条只能放到底部
  • 长首行会被角标盖住，需要给首行右侧留白
C · 编辑器页签
块顶伸出一个文件页签（文件名 / 语言），动作靠右

请求用户信息：

user.ts
  • 「这是一个文件」的心智最强，适合教程 / 项目笔记
  • 分步可以做成多个页签（但和「多文件」概念会混淆）
  • 没有文件名时页签只能显示语言，意义变弱
  • 异形轮廓，和编辑器其他块（引用、callout、图片）的圆角矩形不统一

02分步演示（替代「Diff 动画」）· 第二版

分步是小场景，所以不给它常驻的版面：普通代码块上看不到任何分步相关的东西，入口只在 ⋯ 菜单；开启了的块也不加底栏，只在标题栏里放一个紧凑的步进器。另外不再有「1/1」这种中间状态：开启时直接复制出第 2 步。
保留上一版的两点：每步可以写一句说明（数据里已有的 steps[].title）；切换后本步改动的行短暂标出约 1.5 秒，然后淡出，不常驻。
两个块都能操作：点 ‹ › 或按 ← →（先点一下块让它获得焦点），切到「编辑」看作者视图。mockup 用的是行级过渡，真实效果是 magic-move 的 token 级过渡。

H1 · 标题栏步进器 推荐
TypeScript ｜ ‹ 2/3 › 说明文字 …… 复制 ⋯ —— 不增加高度

给 getUser 加缓存的过程：

  • 和普通代码块同高同形，只是标题栏里多了一个小步进器；不知道这个功能的人也不会被打扰
  • 读者一眼能看出「这块代码可以翻页，现在是第几步」，这正是现状缺的
  • 编辑态步进器末尾多一个 ＋，说明文字可以直接点击编辑；删除、关闭等收进 ⋯
  • 说明只有标题栏剩下的宽度，长说明会被截断（悬停时显示全文）
H2 · 悬停浮出
平时只在标题栏淡淡写「3 步」；悬停时代码底部浮出 ‹ ● ● ○ › + 说明

给 getUser 加缓存的过程：

  • 静态时最安静，和普通块几乎没区别
  • 圆点能看出总步数和当前位置，像图片轮播，读者有现成的心智
  • 浮层盖在最后一两行代码上，翻页时要挪开鼠标才能看全
  • 不悬停就看不到是第几步，和现状「步骤不可见」的问题只解决了一半

05落地映射

  • 数据不变：继续用 magicMove.steps[]，title 字段已存在，直接作为「步骤说明」露出；切换后短暂标出的改动行，在渲染时对相邻两步做行级 LCS 得出，不落库。
  • 组件拆分：ToolbarButtons 改成 CodeBlockHeader（语言 / 步进器 / 说明 / 复制 / ⋯），步进器只在 steps.length ≥ 2 时渲染；SelectLanguage 移进头部，去掉 --ed-code-pad-top: 3em。
  • 命令：tau.code-block.magic-move.* 命令 id 不变，只改 title：「开启 Diff 动画」→「分步演示」；enable 命令改为「建初始步 + 立即插入下一步」；⋯ 菜单直接复用 codeBlockCommands。
  • 行号：叠层编辑器（透明 textarea + shiki 层 + 测量层）三层需同步加左侧 gutter 宽度，改 --ed-code-pad-left 即可，gutter 单独绝对定位渲染。
  • 只读 / 预览：头部只剩语言 + 复制；步进器照常显示（读者最需要它）；← → 仅在只读态或块获得焦点、且 textarea 未聚焦时生效。
