00统一行内色板

字色、高亮、下划线共用一套 7 色相（灰 / 红 / 橙 / 黄 / 绿 / 蓝 / 紫），每个色相明暗各一档：字色直接用它，高亮取同色相淡底 + 底线，下划线取同色相的线。三个面板的色块列一一对齐，同一个「红」在三处是同一个红。 现状三套各自为政：字色是一套调过明暗的 7 色，高亮和下划线另是一套不分明暗的 5 色（蓝是浅天蓝、紫是深灰紫，和字色的蓝紫不是一家；深色下浅天蓝底线几乎看不见）。

  • 数据兼容：高亮与下划线在文档里存的是色名（yellow / red…），只换色名对应的取值，旧文档自动变成新色，无需迁移；新增 gray / orange 两个色名。字色存的是具体色值，保持不变。
  • 明暗：高亮与下划线改为跟随明暗取值（现状固定一档），深色下不再发灰发脏。
  • 单一来源：色板收成编辑器 constants 里一张表，三个面板与正文渲染都从它派生。

01工具条：一个家族、一种提示

所有按钮统一 30px 槽、中性墨色图标，激活 = accent 淡底；提示一律走 @tau/ui Tooltip（关联内容不再是 antd 的另一种样子），并在子菜单展开时自动收起，避免「提示压在面板上」。 颜色与高亮合并为一个入口：左半点一下直接套用上次的组合，右侧箭头展开面板；按钮上的 A 与色条实时显示当前字色 / 高亮色。工具条少一格，也不用在两个相邻菜单间来回找。悬停下列按钮试试。

有一个 lsof 的命令，它的作用是查看进程打开的文件，网络套接字也被认为是文件的一种，因此可以根据此命令找到端口对应的信息。

  • 分隔：工具条内按「字形 / 颜色 / 引用关系 / AI」分成四组，组间一根 16px 短竖线（工具条内唯一的线，仅作分组节拍）。
  • 展开时机：悬停 120ms 意图延迟后展开（避免划过就弹），紧凑模式改为点击；展开态按钮保持 hover 底色，提示隐藏。
  • 关联内容：只换提示与反馈（antd message → 编辑器 notifier），选择弹窗本身已是 @tau/ui，不动。

02颜色面板（字色 + 渐变 + 高亮）

每个色块直接画成品样子：字色格是彩色的「A」、高亮格是带底色与底线的「A」、渐变格是渐变字——看一眼就知道套上去什么效果，不用猜圆点代表什么。当前选区的取值带 accent 描边；分组靠留白与小标题，不画横线。底部「清除颜色」一次性去掉字色、渐变与高亮。

04批注：锚点、空态直写、线程
