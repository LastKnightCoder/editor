发布 · 从设置弹窗抽成独立页面

发布的高频动作是「勾内容 → 看变更 → 发布」，站点与目标配置基本只配一次。设置弹窗里这几件事平铺成一长列，高频的内容选择被夹在中间、只有一小块树可操作。独立页面按使用频率重新分区：

  • 页头 = 站点身份：favicon + 标题 + 访问地址 + 目标徽标，一眼确认「发到哪」；配置收进右侧抽屉（低频）。主按钮全页只有一个，放在右栏流程末端。
  • 主区 = 内容选择：左侧五类内容竖排（粉彩色标 + 已选/总数），右侧搜索 + 「全部/已选/未选」筛选 + 三态勾选树，吃满桌面宽度。
  • 右栏 = 变更与动作：接入已有但未暴露的 previewPublishPlan（上传/删除/未变），发布中显示五阶段进度 + 当前文件 + 取消，结束后失败文件可一键 retryPublishFiles。
  • 配色：纸底 + 白面板两档拉开，不使用 bg-group（容器靠留白/描边，小件用 bg-hover 淡墨）；accent 只用于主按钮、勾选与进度；五类内容用 tag-1~5 粉彩区分；变更语义用 accent / danger / ink-3，不另造色。
  • 入口：侧栏「工具」组新增「发布」；设置弹窗删除该节，凭据仍留在「集成」。
