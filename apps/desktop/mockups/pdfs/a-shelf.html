方案 A · 文档墙 + 列表排布（推荐）

一整张纸：页头「PDF」+ 搜索 + 「添加 PDF」主按钮；工具条左侧来源 chips（全部 / 本地 / 远程），右侧排序与「封面 / 列表」切换；下面是「最近打开」续读行（读到第几页），再往下是全部文档。点文档进详情页（下一步迁移）。
  • 封面用 PDF 第 1 页缩略图；右上角「封面样式」可对照文字封面（不渲染，按文件名派生色块）。
  • 列表排布是行式无横线：名称 / 页数 / 标注 / 来源 / AI 检索状态 / 最近打开，列头排序，不做保存视图。
  • 顶栏按钮切各形态：空态、加载、无结果、添加对话框、整页拖入、条目菜单、删除确认、导入中。
