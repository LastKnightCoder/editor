编辑器 · 标签页块重设计

四个方向，全部只消费主题 token（实现时落到 --ed-*），切主题/明暗检验契合度。每个方向的主演示可交互：点击切换、双击或 Enter 重命名、拖动排序、中键关闭、× 删除、＋ 新建；标签多时可滚轮横向滚动。

切到「暖纸 / 薄荷」或深色看：它不随主题变，永远是一块冷灰 + 白胶囊。

颜色绕开主题：zinc-* / white / 裸 rgba 阴影，暖色主题下发冷发脏；深色是 zinc-700 灰块。
Segmented 观感：灰色轨道里浮一颗白胶囊，像设置页的分段开关，而不是文档里的内容分组。
× 常驻每一项：三个标签三个叉，噪音比标题还多；删除这种低频危险操作不该常显。
视觉体系不一：卡片自带投影，而代码块 / callout 都是「平面 + 1px line-1 描边」。
双重分隔：灰底头部 + border-t 两层分界，头部显得厚重。
溢出无提示：标签超宽时硬裁剪、滚动条隐藏，用户不知道后面还有标签。
A书签下划线推荐
最轻的一种：头部无底色，只有一条 line-1 基线；激活项文字转 ink-1、下方一道 accent 短线压在基线上。与桌面端设置页 SettingsTabs、代码块同属「平面描边」家族，放在文档流里不抢正文。

∑对比与建议
方案气质主题契合标签多 / 长标题嵌套代码块时移动端改动量
A 书签下划线克制、文档感，像目录标签最好：只用 line + accent横滚 + 渐隐层级清爽原样可用小：3 个组件换类串
B 文件夹页签实体、边界清晰好：page / surface 双层横滚 + 渐隐page 底色重复原样可用小
C 淡墨签亲和、可点性强中：accent 面积大横滚 + 渐隐清爽原样可用小
D 侧栏目录结构化、像小目录好最佳清爽需退化为 A中：新增布局属性 + 竖向拖拽
建议 A 作为默认；如果你喜欢 D 的结构，可以做成块菜单里的「布局：顶部 / 侧栏」二选一（数据上给 TabsElement 加一个可选 layout 字段，缺省即顶部，旧文档零迁移）。 所有方案共用的交互细节：× 悬停/激活才显形但占位固定（不跳变）、触屏只在激活项显示；溢出一侧渐隐 + 纵向滚轮转横向 + 激活项自动滚入视野；重命名用 focus ring；插入线用 accent。
