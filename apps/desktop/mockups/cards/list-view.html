卡片库 · 列表视图（第 4 个视图）

卡片墙适合浏览，但卡片一多就很难按字数、链接数、更新时间来找和整理。列表视图是同一份数据的行式排布，与项目列表的列表排布口径一致。
  • 入口：面包屑视图速切器里加一项「列表」，放在卡片墙之后：卡片墙 / 列表 / 图谱 / 表格。偏好按库记忆（CardsViewMode 加 list）。侧栏的标签筛选三个视图通用，现在四个视图也一样。
  • 行：卡片没有标题，就把正文首行当标题（加粗），第二行放摘要（灰色）；之后依次是标签、链接数、字数、更新、创建、悬停操作（置顶 + ⋯，复用 CardActionMenu）。点行打开预览弹窗，和卡片墙一样。
  • 与「表格」的分工：表格是可编辑的 Database（加属性、行内改标签），列表只读、轻量、跟随卡片墙的筛选和操作。列表不做行内编辑，避免和表格重复。
  • 可选项（控制条切换）：① 分组：按时间分段（同卡片墙：置顶 / 今天 / 本周 / 本月 / 更早，段内按创建时间）还是平铺 + 列头排序（置顶始终在前）；② 密度：两行（标题 + 摘要）还是紧凑单行。
  • 性能：卡片全集本来就在内存里（useCardsFeed），排序是纯前端操作；行高固定，复用 CardWallList 的行级虚拟滚动。
