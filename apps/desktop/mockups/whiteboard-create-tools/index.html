创建工具与扩展工具 · P1

Esc 退出创建、回到选择
扩展工具
设计说明

工具栏

  • 新增「选择」工具放在最前面，替代原来"没有选中任何工具就是选择"的隐含状态；任何模式下按 Esc 都回到选择。
  • 第三方工具统一收在末尾的「扩展工具」入口里，工具栏宽度不受插件数量影响。入口图标会记住最近用过的扩展工具；没有第三方工具时不显示这个入口。
  • 弹层显示扩展的名称（"来自 Acme 便签"），不显示扩展 ID。
  • 工具不设单字母快捷键；Esc 是唯一的键盘入口（退出创建、回到选择）。

创建

  • 拖拽预览 = 元素本体 + 1px 强调描边 + 尺寸徽标；Shift 等比，Alt 从中心拉出（箭头按 Shift 吸附 45°）。
  • 预览不写入文档，不触发保存；松手后才一次性提交，整个创建算一步撤销。
  • 拖框架时，会被收进框架的元素显示一圈淡强调色，代替现在拖动中就实时把元素搬进去的做法。
  • 只点一下不拖：默认什么都不创建，工具保持选中；扩展可以声明默认尺寸，点一下就按默认尺寸创建（见"投票卡"）。
  • 创建完成后选中新元素并回到选择工具；画笔会一直保持；文本和便签创建后直接进入编辑。

动效

  • 激活指示块在按钮之间滑动 180ms（ease-tau-out）；系统开启"减少动态效果"时直接跳过去。
  • tooltip 悬停 400ms 后出现，淡入 120ms。
  • 弹层：淡入 + 缩放 0.98→1，140ms。
  • 提示胶囊：激活工具 250ms 后淡入并上移 4px（160ms），快速切换工具时不会闪；在画布上按下鼠标就淡出（120ms）。
  • 预览跟手移动，不加动画；按 Esc 取消时预览淡出 120ms；提交时不做动画，直接显示选中框。
