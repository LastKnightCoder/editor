卡片提取练习比重读更有效

① 说出意图

入口：新建文章菜单里的「创作模式」、文章详情标题栏的布局切换、命令面板。已有文章也能进入，此时意图会预填为标题 + 首段。

为什么先问一句

  • 文章还是空的，没有正文可以拿来做检索；一句意图就是最好的查询。
  • 意图会留在正文顶部（可折叠），后面「再找一些」拿它当上下文。
  • 来源类型可勾选，默认全选；PDF 标注默认关（量大、噪声高）。
  • 可以跳过：白板空着，自己往里放资料。

② 召集资料

两段式粗筛（AI 必须参与）

  • 已有文章先摆「已关联」：建板时把文章已有的连接（显式连接 + 正文里的引用）摆成第一组「已关联」，召集只找还没关联的。新文章没有这一组。
  • 本地宽候选：意图做向量检索（节级，D-099）＋ content_ai_meta 概念 / 主张匹配，取 50～80 份。
  • 一次模型调用：从候选里挑 8～12 份，分成 3～4 组，每份写一句「为什么相关」。分组变成白板上的框，理由印在卡片底部。
  • 卡片按组逐个摆上来（有动效、不刷屏）；不要的直接 × 移走，记为负反馈，再找时排除。

摆什么

  • 卡片 / 文章 / 项目文档 / 日记 → 现有文档卡（D-122），长文定位到命中的节。
  • 网页剪藏 → webview 元素；视频笔记 → 视频元素并跳到命中时间点。
  • 白板是一块真实白板，绑定这篇文章；退出后还在，下次进入原样恢复。

③ 边看边写

白板 → 正文：拖进来

  • 拖文档卡到正文：行内连接 / 引述原文 / 嵌入卡片，三选一。落下的都是 content-link，自动进脉络与谱系。
  • 思维导图可一键「生成正文大纲」：节点变成标题，只生成结构，不写正文。
  • 点开文档卡在白板区域内铺满阅读（不再停靠右侧，右侧是正文）。

正文 → 白板：被动联动

  • 停笔约 2 秒后，用当前段落做一次本地检索，只在白板上让相关卡片轻轻亮起，正文里什么都不出现。
  • 亮起的卡片下方只有一个按钮「连到此段」。卡片在视野外时，白板边缘出现一个小箭头。
  • 这里只用向量、不调模型（实时、免费），判断交给 ④。

④ 标出可引用处

  • 做的事：AI 通读写好的正文，标出哪些话可以引用白板上的资料，并列出还没用到的。普通文章里同一个功能叫「AI 洞见」。
  • 用户点「标出可引用处」才运行，沿用 7b 洞见视图：扫光 → 报告卡 → 正文里逐处画线，编号与白板卡片角标对应。
  • 候选范围以白板上的资料为主，也包括库里其他内容（白板外的会提示「放到白板」）。
  • 每处一个气泡、最多两个按钮：连接 / 不相关。连接后原文片段包成 content-link，白板卡片标上「已引用」。
  • 报告卡额外给出「白板上还没用到的」，提醒漏掉的论据，而不是替你写。

不做

  • AI 代写段落、自动插入连接、正文常驻提示。
