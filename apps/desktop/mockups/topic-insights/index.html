7b 的路子用到地图、今日页和项目上：点一下 → 读（看得见）→ 一处处画出来 → 一处一个气泡、最多两个按钮 → Esc 恢复（设计见 docs/knowledge-loop/17）

  • 知识地图：标题栏右边「✦ AI 洞见」。读：一道光从左往右扫过地图；点亮：标题下展开一张报告卡（版图两三句 + 数量签 + 生长条），地图上画出呼应（两个主题之间的蓝色弧线）和问了但没写（虚线圈「?」）。有发现的主题名后有个小点，点主题名镜头飞进去，报告换成这个主题的（关注点变化、生长），主题里画出重复（灰点线）、矛盾（红波浪）、缺一环（链 + 虚线空位）、同一思路（紫色圈）、还缺（标签下淡注）。Esc 先退回全局，再退出。
  • 今日：「继续」段首一张「洞见」卡，一次只说一件事（‹ › 换一条），两个按钮：去看看（地图就地点亮那一处、弹出气泡 / 打开项目回顾）、不相关。
  • 项目：项目树上方「✦ 回顾」。生长中 = 生长回顾：最近长了什么、新连上哪里、哪里还薄（树里淡注），可能属于这里的笔记以虚线行一行行长进树里（引用到这里 / 不相关）。刚归档 = 结项回顾：留下了哪些观点、连上了哪里、没解决的问题（记为问题）、可以归进哪个体系项目。
  • 平时什么都不出现：地图、项目树都和现在一样，只有按钮旁一个小点表示「有还没看的」。
