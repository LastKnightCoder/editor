白板画布内部换皮 · 三方案

现状：D-047 / D-048 只迁了页面外壳，画布组件 components/WhiteBoard 内部还是旧皮。它有六件「chrome」：顶部居中工具条（14 个按钮：形状 / 箭头 / 手写 / 富文本 / 思维导图 / 图片 / 视频 / 音频 / 网页视图 / 卡片 / 白板 / Frame / Column / 演示序列，其中 6 个带子菜单）、右侧属性竖条（按选中元素类型切换，每一项点开一个 antd Popover，多选时是对齐与均分）、右下状态栏（网格设置 / 全览 / 缩放 / 演示序列列表）、左侧 300px 元素树侧栏（占一整列，带 border-r）、右键菜单、以及十来个插入 / 选择弹窗和演示序列创建面板 / 放映控件。视觉上是一套独立的「蓝调毛玻璃」：rgba(248,250,255,.9) + backdrop-filter + 大投影，激活态靛蓝，选中框蓝色。规模：51 个文件 import antd、27 个 .module.less、13 个文件用旧 --th-*、16 个文件写了 backdrop-filter。

三套方案共用同一张 mock 画布（「Transformer 结构拆解 / 注意力机制」：画框、富文本、手写、图形、连线、卡片、图片、思维导图），元素按真实类型画出，都能操作：点选 / Shift 多选 / 框选 / 拖动（属性随元素类型切换，改颜色、线型、虚线、圆角等会真的改到元素上）、工具子菜单（形状图块、图片 / 视频 / 音频 / 白板菜单；点工具再点画布放置，手写可以直接画）、右键菜单（元素 / 空白处，带「图层」「创建为」子菜单）、元素树浮层（查找、折叠、双击改名、右键）、缩放 / 网格（⌘+滚轮缩放、滚轮平移、空格拖动）、插入弹窗（图片 URL、AI 生成、网页、选择卡片、引用白板、导出图片）、演示序列（右下「演示」→ 放映 / 编辑 / 新建，创建面板里选元素「添加帧」，放映时 ← → 翻页、激光笔）。标题栏「演示」区：主题化元素（预览元素默认色一起换的样子，见待拍板 1）、多选、单页（页签栏隐藏、底边悬停浮出）。右上角月亮切换 cream / cocoa。

方案 A

顶部工具条 + 跟随浮动属性条 · 属性长在选中的元素上

工具条留在顶部居中（现状位置，肌肉记忆不变），按「绘制 / 媒体 / 引用 / 容器」四组靠留白分开。属性不再固定在右边，而是选中元素上方 14px 浮出一条横向小条（贴不下时翻到下方），拖动元素时隐去、松手回来；每一项点开是向上弹的小面板。纯开关项（草图、流动、压感）点一下直接切换，不弹面板。

✓ 属性离操作对象最近，鼠标移动最少；没选中时画布四周只剩工具条与状态栏 ✓ 不和右侧的卡片笔记 / 视频笔记抽屉抢位置 ✗ 位置随元素变化，找控件要先看元素在哪；会盖住元素上方的内容；项多时（箭头 8 项）横条偏长

三个方案都做的事

  • 浮动件统一主题语言：实底 surface + shadow-lift + 1px 细描边，去掉毛玻璃与靛蓝；激活 = accent-soft 底 + accent 墨，悬停 = bg-hover；组内分隔靠 8px 留白，不画竖线；
  • 画布自身的 chrome 改 accent：选中框、控制点、框选矩形、演示帧高亮从蓝色改为 accent（这些是界面，不是用户内容）；网格点用 --canvas-dot；
  • 元素树不再占一列：左上（B 为竖条顶端）一个按钮，点开是盖在画布上的 264px 浮层：查找（命中高亮）、画框 / 导图按层级缩进可折叠、点一行选中并把元素移进视野、双击改名、行尾「更多」占固定槽位（悬停只改透明度，不改尺寸）；
  • 演示序列入口合一：工具条上的「演示序列」按钮去掉，并进右下「演示」——一个弹层里列出序列（点即放映，悬停出编辑 / 删除），底部「新建演示序列」；创建面板用 surface 浮层：名称直接写在标题位、帧列表带「这一帧在整页的位置」小地图；放映时纸面铺满窗口、chrome 全部让位，底部一个小控件（翻页 / 激光笔 / 退出），提示 2.6 秒后淡出；
  • 子菜单与右键菜单换成 Menu / ContextMenu 公共件：形状用四格图块；图片 / 视频 / 音频 / 白板菜单项带一行说明；右键「图层」「创建为」「添加节点」为子菜单，快捷键右对齐；
  • 插入弹窗换成 Dialog（取消 = secondary、确认 = primary，每屏一枚主按钮）：图片 URL 带实时预览、AI 生成带生成中状态、网页（URL 或本地 HTML）、选择卡片（查找 + 多选，按钮写「插入 N 张」）、引用白板（先选白板再选页，缩略图复用列表页）、导出图片（背景 / 倍数 / 边距 + 预览）；
  • 属性里的颜色是数据色：色板完整保留现状（8 组浅底 + 描边、8 实心、仅描边、自定义色；箭头 11 色主题色；卡片 7 色浅底），只把外壳换成主题语言——圆形色块、选中为 accent 外环；
  • 不复述看得见的状态：开关型属性的开关放在分区标题右侧（不再在下面写一遍同名开关）；A / B 里纯开关项点一下直接切，按钮本身显示开 / 关；
  • 中文化：「Frame」→ 画框、「Column」→ 分栏、「富文本」→ 文本；网格设置去掉 antd Switch / InputNumber，改开关 + 档位 chip；
  • 不动：页签栏（D-048）保持左下，状态栏保持右下；元素本身的画法与默认色不在本轮（见待拍板 1）。

可以混搭的部件

  • 工具条形态与属性形态是独立的两个轴：mockup 里三套只是三种组合，实现时可以任意配（例如「A 的顶部工具条 + C 的检查器」、「C 的底部 dock + A 的浮动条」）；
  • A 的浮动条 + C 的检查器做「更多」：浮动条只放 4–5 个常用项（颜色 / 粗细 / 线型 …），末尾「更多」展开完整检查器——常用快、全量也有；
  • B 的元素树并入工具条顶端可以用在 A / C（省掉左上一个孤立按钮）；
  • C 的平铺控件（色板 / 滑杆 / 图示选项）本身就是 A / B 弹层里的内容，三方案共用同一套属性控件，改的只是容器。

待你拍板

1. 元素默认样式要不要这次一起换？

现状新建元素的默认色是 legacy 的：图形无填充 + 黑描边、箭头 Tailwind 蓝 #3b82f6、卡片白底 #fff、思维导图蓝色主题。这些属于用户内容，改默认值只影响之后新建的元素；已有元素保存了自己的色值，基本不变（例外：图形描边存的是 currentColor，会跟着墨色走）。点标题栏「主题化元素」可以看到换成墨色 + surface + accent 的效果。建议：本轮不动，单独一轮再议。

2. 属性栏形态选哪种？

A 跟随浮动小条 / B 右侧常驻竖条 / C 平铺检查器，或者「浮动条 + 更多展开检查器」的混搭。

3. 工具条放哪里？

顶部居中（现状）/ 左侧竖条 / 底部 dock。另：演示序列按钮从工具条移到右下「演示」合并，可以吗？

4. 卡片笔记 / 视频笔记抽屉

画布右侧还有两个从右边滑出的抽屉（打开卡片笔记、视频笔记），现在是 antd 白底 + 边框线。它和右侧的属性（B / C）有位置冲突，要不要这轮一起换皮、并定一下与属性的互斥规则？
