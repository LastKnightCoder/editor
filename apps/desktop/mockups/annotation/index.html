颜色全部取自 @tau/themes 的 --tau-*，右上角可切主题族和明暗。注解在 Markdown 里导出为脚注 [^n]，所以新设计把它当作「脚注」来做：正文里是序号，内容在浮层里。

问题
  • 占位错位：外层占 1.5em 宽，圆圈却绝对定位向左上偏移，压到前一个字，后面留一块空白。
  • 不跟主题：灰色和 80% 黑底浮层是硬编码色值，暖纸/薄荷等主题下很突兀，深色下对比也弱。
  • 多个注解分不清：每个都写「注」，和导出的脚注序号对不上。
  • 浮层没有操作：只能改文字，不能删除、复制；看和改是同一个状态，只读时也打开光标。
  • 插入后要先删「注解内容」：默认文本是真内容，不是占位提示。
  • 移动端：命中区只有约 12px，浮层从顶部弹出常被键盘和刘海挤掉。

02桌面端交互（可操作）

悬停看、点击改。悬停 300ms 出只读预览；点击打开编辑卡片，带删除和复制。只读文档点击只打开查看卡片。下面的正文可以直接试。

为什么间隔重复有效

艾宾浩斯在 1885 年发现，记忆在学习后的头一天流失最快。之后再复习，遗忘曲线会变得更平缓。

间隔重复的核心是在快要忘记时复习，这样每次提取都更费力，也记得更牢。主流算法如 SM-2 和 FSRS 都按这个思路安排下次复习时间。

03插入

入口不变：斜杠菜单「注解」和 ⌘⇧N。变化是插入后直接打开空的编辑卡片并聚焦，内容为空字符串，「写下注解…」只作占位提示；空着点外面关闭时自动删掉这个注解，不留空标记。

04移动端

没有悬停，统一点按打开底部抽屉。标记视觉和桌面一致，命中区扩到约 32×32。抽屉附带注解所在的原文片段，方便确认点的是哪一个。编辑时抽屉贴在键盘上沿。

05实现要点与待定项

项做法
序号编辑器根 counter-reset，注解元素 counter-increment + ::before；数据结构不变，dataVersion 不升。
颜色只用 --ed-accent / --ed-accent-soft / --ed-accent-text / --ed-bg-surface / --ed-border / --ed-shadow-float，删掉 useEditorTheme().isDark 分支。
浮层桌面沿用 @tau/ui Popover，去掉透明壳，卡片本身就是浮层；移动端由宿主用底部抽屉承载，Esc / 返回键继续走 OverlayBackDismiss。
插入insertAnnotation(editor, "") 后打开该注解的编辑卡片；关闭时内容为空则 removeNodes。命令和斜杠菜单都改用空字符串。
删除 / 复制卡片头部两个图标按钮；删除可 ⌘Z 撤销，移动端给撤销 toast。
