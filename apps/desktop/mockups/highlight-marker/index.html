马克笔高亮 · 三种笔触

现在的背景高亮是一段 span：同色相 16% 淡底 + 2px 底线（text-formatting/src/components/Highlight），干净但像「标签」不像「划过的笔」。下面三种笔触都在同一段正文、同一套 7 色色板上对比，每种都给浅色 / 深色两张纸。

A / B / C 都是纯 CSS 背景图（SVG 切片），跟随换行、不动排版，与平涂一起在「设置 › 外观 › 高亮」里选择，发布博客时跟随设置。平头荧光笔的切片与 Highlight/marker.ts 一致。

一 · 三种笔触同一段正文、同一套色板，左浅右深

现状

平涂：淡底 + 底线

对照组。整块矩形，上下沿笔直，看不出「划过」的动作。

A 推荐

平头荧光笔

斜切的笔头，上下沿轻微起伏，沿笔画方向有积墨和两道淡纹，起笔略深、收笔略淡。笔迹比字身略宽，两端各伸出约半个字。浅色纸用正片叠底，墨色和字不打架。

＋ 一眼就是荧光笔；纯 CSS 背景图，跟随换行（box-decoration-break: clone），每行各自有笔头 － 是平铺的切片，看久了能看出每 64px 一个周期；整笔没有倾斜 成本：小。只改 Highlight 组件 + 样式，7 色 × 明暗的切片启动时生成一次
B

下半划线（swipe）

只覆盖字身下半，圆头。像用马克笔在字底下快速扫一道，字形完全露在外面。

＋ 字最清楚，长段高亮也不压抑；中文方块字上半留白，读起来更轻 － 更像彩铅 / 记号笔划线，「荧光笔」感弱；和现有下划线功能观感接近 成本：同 A
C

干笔颗粒

毛边 + 横向噪声镂空，像墨快干的马克笔压在纸纹上。

＋ 纸感最强，和白板手绘风格一个味道 － 小字号下颗粒像脏点；深色纸上颗粒几乎看不见 成本：同 A，但切片带 SVG 滤镜，每个色值光栅化一次，长文需实测

《认知天性》读书笔记

文章 · 2026-10-28 编辑

这本书反复在讲一件事：让学习变难的方法，往往记得更牢。重读和划线给人「我懂了」的错觉，真正起作用的是提取练习——合上书，试着把刚才的内容讲出来。

三个可以马上用的做法

  • 间隔复习：第一天、第三天、第七天各回顾一次，比一口气看三遍有效。
  • 穿插练习：不同类型的题目混在一起做，逼自己先判断「这是哪类题」。
  • 先试着解答再看讲解，哪怕答错，后面看到正确答案时也记得更深，这一点和直觉正好相反。
「犯错并纠正，是学习的一部分，而不是学习失败的证据。」

四 · 实现上要处理的几件事

问题做法
跨行用 box-decoration-break: clone，每行片段各自画两端笔头。
同一段被拆成多个叶子高亮里有加粗、字色、链接时，Slate 会拆成几个相邻 span，每个都画笔头就会在中间叠出一道深色（下图左）。相邻叶子都是高亮时，衔接侧不画笔头（下图右）。
不动排版笔头画在左右 padding 里，再用等量负 margin 抵消，开关笔触时文字位置不变。
深色纸正片叠底在深色上看不见，深色改普通混合、压低透明度；对比度沿用色板的 AA 单测口径兜住。
导出公众号不支持 CSS 变量和背景图，继续用 exportHighlightColors 的平涂色值；博客渲染同组件同样式。
性能切片是每笔触 7 色 × 明暗 × 3 张的 data URI，首次用到时生成，所有高亮共用；C 带滤镜需长文实测。
不处理：加粗处两个笔头叠在一起
