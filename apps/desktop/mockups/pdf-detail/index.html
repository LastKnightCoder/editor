PDF 阅读页 · 方案与决策

现状：旧详情页是顶部一整条工具栏（翻页 / 缩放 / 适宽 / 单双页 / 旋转 / 截图 / 全屏 / 选择 / 抓手 / 高亮 / 下划线 / 波浪线 / 删除线 / 书签 / 问 AI，窄窗时折成两行），左侧五个页签的侧栏，右侧 AI 对话栏；标注是先点工具、再划线；弹窗、提示、菜单、空态都是 antd。本轮不参考旧界面，只保留能力清单，重新设计版面与交互，全部用 @tau/ui 和主题 token。

① 三套版面

三套共用同一套交互（选区工具条、框选、笔记卡、查找条、底部 HUD、引用跳页），区别在「标注放哪、对话放哪」。在方案 A 页用顶栏按钮可以切换所有状态。

A 沉浸阅读 推荐

一整张纸：左面板（目录 / 页面 / 标注 / 书签）· 阅读区 · 对话栏，两侧都能收起；翻页缩放进底部 HUD。

没有顶部工具栏；左标注右对话可以同时看。

B 边注

有笔记的标注在页边内放图钉，悬停浮出笔记卡、不占阅读宽度；左面板保留「标注」页签用于查找跳转；对话在纸内右栏，⌘J 开关。

✔ 已选定：页面不变窄，扫页边就知道哪里有笔记。

C 学习台

左页面缩略图 · 中阅读 · 右栏「笔记 | 对话」分段切换，同 Notebook 学习台。

整理与问答同处；三栏常驻、笔记和对话不能同屏。

② 交互重做（三套通用）

动作 旧 新
高亮 / 下划线 先在工具栏选工具，再划线；不切回选择工具就一直处于标注模式 直接划线 → 原地弹工具条 → 点颜色即高亮（默认沿用上次颜色），同一条上可切成下划线。不存在「工具模式」
改 / 删标注 点标注出一个 antd 小菜单 点标注弹同一条工具条：当前色打勾、可换色换样式、笔记、问 AI、删除（删除后给 toast 撤销，不弹确认框）
写笔记 侧栏里另开编辑面板 工具条「写笔记」→ 标注下方弹笔记卡，直接输入，⌘↵ 保存 / Esc 取消；有笔记的标注尾部带一个小图标
框选区域 先点截图工具 按住 Alt 拖动，松开出工具条：存为区域标注 / 问 AI / 复制图片
问 AI 套一段固定提示词直接发送 选区作为引用带进输入框，不自动发送，给「解释 / 翻译 / 举个例子 / 找相关段落」快捷问法；回答里的页码点了跳回原文并闪一下
书签 工具栏按钮 悬停页面右上角出书签图标，点一下加 / 取消；快捷键 B
查找 侧栏「搜索」页签 ⌘F 在阅读区右上角弹查找条，分「关键词」（逐个跳转高亮）和「按意思找」（AI 索引，列出段落）
翻页 / 缩放 顶部工具栏 底部悬浮 HUD（页码可点改、缩放档位、查找、⋯），常驻显示（不随滚动变淡）；←→ 翻页、⌘+⌘- 缩放
双页 / 旋转 / 全屏 顶部工具栏 HUD 的「⋯」里，另加「夜间页面（反色）」、在文件夹中显示、重建 AI 索引
抓手 工具按钮 去掉；按住空格拖动或触控板平移

版面

3
标注样式
高亮 + 下划线工具条只给两种；旧的波浪线 / 删除线照常显示和编辑，只是不再能新建

4
颜色
5 色黄 / 红 / 绿 / 蓝 / 紫；旧的粉色标注照常显示
保留 6 色含粉色
5
笔记编辑
轻量富文本沿用现有笔记数据格式（Slate），编辑器只开基础格式与行内公式
纯文本最轻，但旧笔记里的格式会丢
6
删除标注
直接删 + toast 撤销高频操作不打断
确认框同旧行为
7
进入本页
收起全局侧栏同 Notebook / 项目详情，离开时还原
不动保持用户当前侧栏状态
