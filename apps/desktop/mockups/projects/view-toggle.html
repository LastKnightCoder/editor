项目列表 · 网格 / 列表切换 + 最近打开

参照 PDF 与微信读书书架：同一份数据两种排布，并在网格顶部放「最近打开」续读行。点续读卡直接回到上次看的那篇文档（project-detail {id, itemId}）。
  • 视图切换：用「按钮 + Menu」，不用 Segmented。A 放在工具栏右侧，B 放在标题栏面包屑，同卡片库「卡片墙 ▾」的做法（D-024 追记）。菜单项是命令项，当前项高亮，不用 Radio。偏好按本机保存。
  • 最近打开：网格模式取最近打开的 3 个项目，每张卡显示「上次看到的文档」。列表模式不单独放这一段，由「上次打开」列和默认排序承担。从没打开过的项目不进续读行。
  • 网格卡片：项目没有封面，网格就是卡片，不做封面。卡片上有标题、两行简介、「上次看到」的文档条和 meta 行。卡片纵向撑满，同一行的卡片等高，文档条统一压在底部。只有打开过、记录到文档的项目才显示文档条。
  • 置顶：原来的 hero 段并进「全部」，任何排序下置顶项都排在最前，带星标。续读行接替首屏入口的位置，避免首屏同时出现两段大卡。
  • 排序：最近打开（默认） / 最近更新 / 名称 / 创建时间；列表模式下也可以点列头排序。这会推翻 D-031「无排序 UI」，需要在 DECISIONS 里补一条。
  • 数据：project 表新增 last_open_time 和 last_open_item_id，在进入详情或切换文档时写入（PDF 表已有 last_open_time，可以照着做）。
