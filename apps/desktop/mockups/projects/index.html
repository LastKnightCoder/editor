项目列表页设计探索 · 三方案

背景：项目列表现状是「antd 卡片网格 + 右下悬浮球」——卡片只有标题与富文本描述（每张卡内嵌一个只读 Editor 实例），无类型标识、无子项计数、无时间信息；新建藏在右下角悬浮球（hover 触发展开三型菜单，触发不稳，且文章页已裁决新建入口移工具栏右上、废除悬浮球）；归档是一个折叠区块但没有筛选；无类型筛选、无排序。三个方案共用同一套 mock 数据（13 个项目：3 置顶、7 活跃、3 归档，覆盖文档树 / 数据表格 / Vibe Learning 三型），浏览器打开即可交互——类型筛选、新建菜单、归档收纳、hover 操作均为真实现。

领域判断 · 项目页与文章 / 卡片页的差异

项目不是内容流，是长期进行的学习容器，这决定了它与文章月刊、卡片墙的分野——三方案的不同取舍都围绕这四条：

  • 数量级小：项目通常个位数到几十个，且「正在进行的少数项目」承载几乎全部价值——密度不是第一诉求，「继续」与「找回」才是；
  • 三型即身份：文档树 / 数据表格 / Vibe Learning 是用户创建时就明确的心智分类，是列表的第一筛选维度（对应文章页的标签 pills、卡片库的分类 chips）；
  • 状态双空间：置顶（活跃空间内的强调）与归档（退出活跃）是两个独立状态，legacy 已有，三方案全部保留但承载方式不同；
  • desc 是富文本：列表侧只取纯文本摘要（与命令面板摘要同口径），不再在每张卡内嵌只读 Editor 渲染——这是实现层的重要简化，三方案一致。

三方案共用的基线（来自已裁决页面，不再讨论）

  • 工具栏右上「新建 ▾」split 下拉展开三型（icon + 名称 + 一句描述），废除右下悬浮球——对齐文章页 2026-09-19 评审基线；
  • 无页内搜索（D-024 口径）：页内只做类型筛选，语义检索走全局 Ctrl+K，空态文案引导同一入口；
  • 类型派生色为设计数据色（与文章封面派生色、热力图色阶同性质）：文档树 = 青蓝、数据表格 = 紫罗兰、Vibe Learning = 主题 accent 暖橙——按类型取固定色，不进主题词表；
  • hover = 淡墨底 / 阴影加深，卡片操作 hover 浮现（置顶 + ⋯ 菜单：编辑信息 / 归档 / 整体导出 / 删除），删除走 ConfirmDialog danger——对齐 Dialog / Button 使用边界；
  • A2 视觉铁律：零横线（分组靠留白与底色）、tabular-nums、shadow-card、edge-fade 滚动、4px 细滚动条。

三个方案

方案 A

书架网格 · 置顶段 + 更新序网格

与文章月刊 / 卡片墙完全同构：类型 pills → 置顶段（sticky 段头）→ 按最后更新排的卡片网格 → 底部归档折叠段。卡片以类型色图标块为身份，标题 + 摘要两行 + 子项计数 + 相对时间。

✓ 基因最强，三个内容页视觉一体；描述展示面完整 ✗ 项目少时网格稀疏；密度最低
方案 B

档案行 · 活跃度分组列表

项目域自己的叙事：不按时间分段，按活跃度分组——置顶 / 进行中（30 天内有更新）/ 沉睡（更久），沉睡组可折叠。行 = 类型色点 + 标题 + 摘要一行 + 右对齐元数据，hover 行内操作，单屏 15+ 行。归档走视图切换而非页面段。

✓ 密度最高、扫视最快；「沉睡」是项目独有且诚实的分组 ✗ 摘要被压成一行；展示面为零，与 A/C 视觉断层
方案 C

学习驾驶舱 · 进行中 hero + 紧凑网格

工作台叙事：首屏「继续学习」横幅区——最近更新的两个项目升格大卡（大标题 + 摘要 + 子项计数 + 「进入项目」主行动）；下方全部项目紧凑网格 + 归档收纳。把「少数进行中项目」的核心价值放在第一屏。

✓ 打开即回到学习现场，续学动线最短；仪式感最强 ✗ hero 与今日页「继续编辑」叙事重叠；首屏只见 2 个项目

待裁决问题（不阻塞方案选择，实现前需定）

① Vibe Learning 的进度暗示：方案 C 的 hero 若呈现学习进度（如「已完成 24 / 60 节」）需要主进程聚合命令；若数据源不存在，hero 退化为纯信息卡（mock 中以子项计数示意，落地前核实）。

② 排序：三方案均以「最后更新」为默认序。是否需要「创建时间 / 标题」排序切换？文章页已裁决无排序（按月归段即时间序），项目页建议同样不做排序 UI，保持克制——如有强诉求再加。

③ 新建动线：三方案沿用「新建 ▾ 选型 → 弹窗填标题 / 描述 → 创建并进入详情」。弹窗形态沿用 legacy EditProjectInfoModal 的字段（标题 + 富文本描述 + 类型预选），换 tau Dialog 皮——字段不变，仅承载升级。

④ 类型色板：三型固定色（青蓝 / 紫罗兰 / accent 暖橙）为本次设计定稿数据色，深色主题（cocoa）下的对应色值在实现时与封面派生色板一并校准。
