插件文字装饰 · 外观与交互

给 context.textDecorations 的 appearance 重新设计，主要服务 FakeLink（正文里出现的标题可点开）。原则：装饰是「插件看到的东西」，不是用户写下的格式，所以必须比真链接、用户高亮更安静，并且能和它们叠加不打架。

00现状的问题

现在只有 link（accent 字色 + CSS 点状下划线）和 highlight（accent-soft 底）两种。

link现状
读完 间隔重复 再回头看 Anki 官方手册，会发现 遗忘曲线 其实不是一条曲线。

和真链接同色同位置，读者分不清哪个是用户插的链接、哪个是插件识别；一段文字识别多了就满屏 accent 色。text-decoration 还会和用户的下划线、删除线互相覆盖（同一属性只能有一个值）。

highlight现状
读完 间隔重复 再回头看 用户自己的高亮，会发现 遗忘曲线 其实不是一条曲线。

整块底色和用户高亮标记长得一样，语义冲突；没有悬停、聚焦、加载中这些状态，点了之后要等几百毫秒才有反应也没有反馈。

01外观一览

六种外观，按「打扰程度」从低到高排。悬停每个卡片里的词看状态变化；按住 ⌘ 预览「Mod 键显形」。推荐 FakeLink 默认用 reference，ghost 给「只想偶尔用」的人。每张卡片都放了真链接 / 用户高亮 / 行内代码做共存对照。

  • 点线、半高底色都用 background-image 画，不占用 text-decoration，所以用户给同一段字加的下划线、删除线、波浪线都还在。wavy 是唯一用 text-decoration 的，它本来就是「提醒」，和用户下划线同时出现的概率低。
  • 跨格式叶子要连续：一个装饰会被加粗、斜体切成多片 leaf。背景方案天然连续；dot 只在最后一片画圆点（宿主传 tail 标记）。
  • 换行时用 box-decoration-break: clone，每行的底色两端都是圆角。

02色调

外观管「形」，tone 管「色」，只给主题里已有的语义色，插件不能传任意颜色（否则换主题、深色模式都要插件自己适配）。FakeLink 用 accent；术语表、AI 建议这类插件可以用 info / warn；muted 给「次要匹配」，例如 FakeLink 匹配到小标题而不是文章标题时。

03交互原型

可编辑的正文。FakeLink 识别出的标题用当前外观渲染；匹配到多个同名内容时，点开弹出候选列表（替代现在跳转到一个独立页面）。

外观

试一下

  1. 悬停识别出的词：0.4 秒后出现提示，告诉你会打开什么、来自哪个插件。
  2. 单击「遗忘曲线」：只有一个匹配，直接打开（演示里闪一下表示打开）。异步期间字变淡，防止重复点击。
  3. 单击「间隔重复」：有两个同名，就地弹候选菜单，↑↓ 选、↵ 开、Esc 关。
  4. 拖选跨过识别词：不会触发打开（现在的实现已经这样判断）。
  5. Tab 聚焦后 ↵ 打开，焦点环用主题 ring。
  6. 按住 ⌘：所有识别词同时显形，便于扫一眼有哪些可点。
  • 悬停提示由宿主画，插件只提供文案（label）。这样所有插件的提示长相一致，也能统一写上「由 FakeLink 识别」，让用户知道这不是自己插的链接。
  • 候选菜单也建议由宿主画：插件在 onActivate 返回候选数组即可，宿主用和 @ 提及同一套 Menu。插件不需要再为选择开一个页面。

04FakeLink 设置页

把现在的 <select> 换成带预览的外观卡片，点选立即生效。只给 FakeLink 实际有意义的四种：reference / ghost / marker / tint。

显示方式

识别出的标题在正文里怎么显示。所有方式都不会改动原文。

05接口建议

向后兼容：旧值 link 映射到 reference，highlight 映射到 marker，一个版本后移除旧值。

export type PluginTextDecorationAppearance =
  | "reference" // 默认：墨色字 + 点线，悬停变实线 + accent 字
  | "ghost"     // 静止几乎不可见，悬停或按住 Mod 才显形
  | "marker"    // 下沿半高荧光笔
  | "tint"      // 只改字色
  | "wavy"      // 波浪下划线，用于提醒/待确认
  | "dot";      // 末尾小圆点，最省空间

export interface PluginTextDecoration {
  start: number;
  end: number;
  appearance: PluginTextDecorationAppearance;
  tone?: "accent" | "info" | "warn" | "muted";   // 默认 accent
  key?: string;
  label?: string;                                 // 悬停提示文案，例如「打开文章《遗忘曲线》」
}

export interface PluginTextDecorationProvider {
  ...
  // 返回候选时宿主就地弹菜单；选中后以 candidate.key 再次调用
  onActivate?(action: { key: string; source: PluginDecorationSource })
    : void | readonly { key: string; title: string; meta?: string; kind?: string }[]
    | Promise<...>;
}
