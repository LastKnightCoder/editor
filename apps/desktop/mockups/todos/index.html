待办页设计探索 · 三方案

现状：legacy pages/TodoWindow 是「左侧项目栏 + 主区任务树 + 居中详情大弹窗」，antd Dropdown / modal 与旧 --th-* 混用，外加大量硬编码灰。三个方案共用同一套 mock 数据（5 个进行中项目 + 1 个归档项目，26 个任务，四种类型全覆盖：普通 / 截止 / 计划 / 周期，含子任务、关联笔记、打卡历史），用 cream / cocoa 两个主题的真实 token 值。浏览器打开即可交互：勾选、添加、筛选、详情编辑、右键菜单、拖拽都是真的能用，右上角可切换明暗。

领域判断 · 待办和文章 / 项目页有什么不同

待办页不是拿来「浏览内容」的，是拿来「处理事情」的。三个方案的分歧都来自下面四点：

  • 时间是第一维度：截止、计划、周期三种类型都带时间，用户打开页面先想知道「今天要做什么、有什么已经过期」，然后才是「这个项目还剩什么」；
  • 高频的小操作：勾选、快速添加、改日期一天要做几十次，所以密度、键盘操作和撤销比装饰重要；
  • 周期任务其实是打卡习惯：它不会被「做完」，只是今天打没打卡，有连续天数和缺卡记录，和一次性任务混在同一个列表里会互相干扰；
  • 项目是轻量容器：只有名称和颜色两个属性，数量在个位数，不需要项目页那种卡片展示。

三个方案都修掉的 legacy 问题

  • 「系统分组」其实是类型筛选：全部 / 普通 / 截止 / 计划 / 周期这五个固定分组，本质是按 type 过滤。三个方案都把它降级成筛选项，空出来的位置放按时间划分的视图（今天、即将到来等，全部由已有的 dueAt / startAt / 周期规则算出，不加新字段）；
  • 周期规则可以改了：legacy 创建之后只读，详情里把类型改成「周期」也不会生成规则。现在详情里有重复规则下拉，接的是已有的 updateRecurrence；「跳过今天」接 skipRecurrence；
  • 关联笔记接上界面：legacy 的 TodoNotesDnd / NoteCard 已经写好、store 和命令也都在，只是没挂载。三个方案的详情里都有「关联笔记」区；
  • 归档项目有入口了：legacy 只能归档、找不回来。A 放在视图列底部的折叠区，B 和 C 放在工具栏菜单里，都能恢复；
  • 子任务可以折叠（A）：store 里的 expandedIds 终于接上；
  • 键盘作用域收窄：Delete / ⌘N 只在列表有焦点时生效，编辑文字时按 Delete 不会再把整条任务删掉；删除和完成都支持 Toast 撤销；
  • 拖拽不会再把任务拖进系统分组：系统分组已经不存在了；C 方案的「移动到其他项目」直接拖卡片完成。

三个方案的共用基线

  • 圆形复选框：一次性任务勾选后变 accent 实底；周期任务用虚线圈表示「今日打卡」，打卡后变 ok 绿；逾期任务的圈描 danger 色；
  • 类型用语义色表达：截止 = warn 旗子、计划 = info 时钟、周期 = ok 循环，逾期统一 danger，今天到期用 accent-text。全部取自现有 status token，不新增；
  • 项目色是设计数据色，不进主题词表（和文章封面派生色、项目类型色是同一口径）：legacy 的 17 个色名映射到 8 色板，cream / cocoa 两套取值都已给出；
  • 详情内容三方案完全一致，只是承载方式不同：属性（项目 / 类型分段 / 时间 / 重复 / 提醒 / 日程同步）→ 打卡（连续天数、完成率、12 周热力格、今日打卡 / 跳过）→ 子任务 → 关联笔记 → 描述（富文本）；
  • 视觉铁律照旧：分组不画横线、数字用 tabular-nums、滚动区边缘渐隐、4px 细滚动条；页内不做搜索，统一走全局 ⌘K。

三个方案

方案 A

三栏清单 · 视图列 + 列表 + 常驻详情

清单工具的思路（Things / TickTick）。左侧视图列：今天 / 即将到来 / 全部 / 已完成，下面是项目和已归档；中间是任务列表，顶部有按当前视图预填的快速添加行；右侧是常驻详情面板，选中就能看、就能改。支持全键盘：↑↓ 切换、Space 完成、Tab 缩进、⌫ 删除（可撤销）。

✓ 最接近 legacy 的心智，迁移成本最低；详情不遮挡；键盘效率最高 ✗ 三栏加壳层侧栏共四列，窄窗口会挤；视觉上最「工具」，个性最弱

方案 B

议程流 · 时间分段 + 打卡栏 + 抽屉详情

以时间为主轴：已逾期 / 今天 / 明天 / 本周稍后 / 以后 / 无日期，每段是一张卡片，行左侧有「时间槽」，今天段里有一条「现在」刻度线。顶部是自然语言快速添加：输入「明天 17:00 交周报 #编辑器」会实时识别类型、时间和项目。右栏放今日打卡、本周负荷和最近完成；详情从右侧抽屉滑出。

✓ 最直接回答「今天做什么」；自然语言输入把 legacy 三步新建变成一步；与文章 / 项目页骨架同构 ✗ 手动排序和子任务树展示最弱；按项目整理要切到「按项目」模式；解析器需要维护中文日期词表

二轮（2026-09-24）：原版碎卡漏底被否，页内右上角可切换三个收敛变体——B1 一张纸（工具栏以下整块纸面）/ B2 落纸（零容器）/ B3 两块板（议程一块 + 右栏一块）。

方案 C

项目看板 · 今日焦点列 + 项目列 + 双栏弹窗

每个项目是一列，列头有进度条；第一列是跨项目的「今日焦点」（逾期 + 今天 + 今日打卡）。任务是卡片，拖到其他列就是换项目，拖进今日焦点就是设为今天截止。列尾可以直接添加任务，已完成默认折叠；最后一列是「新建项目」。详情用居中的双栏 Dialog。

✓ 一屏看全多个项目；拖拽换项目最直观；视觉个性最强 ✗ 项目超过 4 个要横向滚动；弹窗详情会打断连续操作；子任务只显示进度

可以混搭的部件

  • B 的自然语言输入可以直接替换 A / C 的快速添加（解析结果都以 chips 展示，可以点开修改）；
  • B 的时间槽 + 现在刻度线可以用在 A 的「今天」视图；
  • B 的今日打卡卡片和 C 的项目进度条都可以作为 A 视图列里的附属信息；
  • 三种详情承载方式（常驻面板 / 抽屉 / Dialog）可以互换，详情内容是同一份。

裁决记录（2026-09-24 一轮评审）

① 不并入日程：待办保持独立页（todos）。首页「待办」卡片的跳转已从 schedule 改为 todos。

② 删除不做二次确认：立即删除 + Toast 撤销。

③ 不保留独立 /todo 小窗口：createTodoWindow 与 /todo 路由随迁移登记进 04 删除清单。

④ 日程同步（已核实）：正常 UI 下只有周期任务会出现在日历里（读取日历时按规则即时生成）；截止 / 计划任务的同步命令只有 AI 工具在调，界面新建或修改都不会写入日历；键盘 Delete 走的非级联删除也不清理日历映射。落地时在主进程 create / update / delete 里补上同步（UI 与 AI 两条路径一并覆盖）。

⑤ 方向：选 B 议程流；原版「每段一张小卡、中间漏底」被否，页内三个收敛变体对照后定稿 B3 两块板，且待办页不注册状态栏（D-039，已落地 features/todos）。
