文档属性（front-matter）

从 Markdown 导入、或手写 --- 开头的 YAML 元数据，在编辑器里显示为「文档属性」块。下面的块都能点：点值编辑、点属性名出菜单、悬停块头切换 YAML 源码。

00现状

米色底卡片里逐行列出键值；只有 description 可编辑，其余字段（包括 title、tags）都改不了；对象直接 JSON.stringify；没法加、删、改名字段；不能折叠；YAML 写坏了静默显示为空块；也没有任何插入入口，只能靠导入。

A属性表（推荐）

块融进纸面，不再加底色：一行一个属性，属性名 | 值两列，悬停只铺一层 hover 底。值按内容自动识别显示形态： 文本、多行文本、列表（胶囊）、日期、勾选、链接、数字；嵌套对象显示为只读 YAML 片段，提示到源码里改。 点值即编辑，失焦或 Enter 提交，Esc 撤回；Tab 跳下一个值。 选中块（点进去）后块头出现「属性 / YAML」切换与「添加属性」。 写入时只改动对应的那一个键，注释、顺序、其他键的写法原样保留。

编辑态
点 tags 值加标签、Backspace 删最后一个；点「created」属性名看菜单；改坏 YAML 看报错

间隔重复的遗忘曲线

艾宾浩斯在 1885 年用无意义音节做了第一组记忆实验……

  • 所有标量与字符串列表都能改；增、删、改名、调整顺序都在属性名菜单里
  • YAML 源码随时可切，写坏时保留最后一次能读的属性并标红原因，不再变空
  • 删除整个块：属性名菜单底部「删除全部属性」，或选中块后按 Backspace

C插入入口

现在只能从导入得到属性块。补两个入口，都只在文档开头生效（front-matter 只能在第一个块）： ① 在第一行空段落输入 --- 回车，转成属性块，光标落在「添加属性」； ② 块菜单（/）里的「文档属性」，文档已有属性块时改为跳到它。 已在别处的位置插入时直接放到文档顶部。
