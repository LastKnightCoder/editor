入口 C · 分屏 pane（页面协议原生能力）

不做「AI 专用侧栏」：AI 对话就是一个普通页面，快捷入口 = navigator.openInSplit("chat")（蓝图 §3 已预留，上限 2 pane）。Ctrl J 在右侧 pane 打开 / 聚焦对话；任何页面都能右键「在右侧打开」，同一机制顺带解决文章对照、卡片对照。
  • 两个 pane 同为 surface 纸面，中间拖动分隔（默认 55 / 45）；标题栏面包屑跟随聚焦的 pane，后退 / 前进作用于聚焦 pane 的栈。
  • 一期：需要先把 PageHost 扩成双 pane 栈（栈机、保活、槽位注入都要按 pane 区分），然后对话页整体放进去——工作量明显大于 A / B。
  • ＋ 概念统一（没有第三种容器）；对话在 pane 里是完整对话页，宽度够、功能不打折。
  • － 需要先改导航框架；1280 下两栏各约 500px，读写都偏挤；「顺手问一句」的开合比 A / B 重。
