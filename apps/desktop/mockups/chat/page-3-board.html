页面 3 · 板内会话列（接近 legacy 布局，隔离做法取问题页 A1）

会话列放进同一张纸的左侧，用一层淡墨底和对话区区分，不落在纸色上，读起来是「板内的列表」，不是第二条侧栏。列表顶部的搜索与分组 chips 取代分组树（子分组在 chip 下拉里选）；列表按「置顶 / 今天 / 本周 / 更早」分段，拖拽排序与右键菜单保留。Ctrl \ 折叠会话列。
  • 一期：最接近 legacy ChatManagementSidebar + ChatArea，几乎可以原样搬进新壳：外面包一张纸，里面左右两块。
  • ＋ 会话一眼可见，切换零额外点击；迁移成本最低、与旧习惯一致。
  • － 你之前两次否决过「页内第二条列」（协作 A、问题 A 初版），这里靠同纸 + 淡墨底隔离，仍有风险；对话列会被压窄约 280px。
