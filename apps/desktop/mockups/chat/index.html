AI 对话 · 布局方案

两个问题分开裁决：① 快捷入口怎么放（在其他页面里随手问），② 对话页本身怎么排（会话多了怎么管）。两者可以自由组合。所有方案一期都只换容器，里面原样挂 legacy ChatContainer（消息流 / 输入框 / 工具调用 / 分支都不动），样式替换留到二期以后。

① 快捷入口

先回答「右边空间够不够」：左栏 218 + 对话 400 之后，1440 窗口的正文还有 788px，1680 有 1028px，都够用。1280 只剩约 630px，这时自动收起左栏（→ 58px 图标栏）就能回到 788px。所以右侧停靠栏在空间上是成立的，前提是做好这条自适应规则。

A · 右侧停靠栏 推荐

壳层新增辅助栏槽位，Ctrl J 开合，并排不遮挡；空间不够时依次「收左栏 → 覆盖浮层」。

B · 锚定浮窗 + 命令面板直问

不改壳层布局，非模态浮窗可钉住成 A；Ctrl K 输入问题可直接得到速答。

C · 分屏 pane

对话页用 openInSplit 在右侧开成第二个 pane；概念统一，但要先改导航框架。

② 对话页布局

legacy 的会话管理能力都要保留：分组 / 子分组、置顶、拖拽排序、归档、移动、分支。差异在于会话导航放在哪里。

1 · 侧栏嵌套 推荐

置顶和最近会话作为侧栏子项，全量管理放进「全部会话」弹窗；对话页就是一整张纸。

2 · 顶部切换器

面包屑 ▾ 展开会话面板，和停靠栏的会话下拉是同一个组件；另有一行可选的最近标签。

3 · 板内会话列

接近 legacy：同一张纸左侧放淡墨底会话列，可折叠。迁移最省事，但有「两条侧栏」的风险。

一期接入路径（以 A + 1 为例）

  1. 新建 features/chat/：pages/chat.page.tsx（params: chatId）+ views/ChatView.tsx，纸面内直接 lazy 挂 legacy ChatContainer；替换 page/legacy.tsx 里的 chat 占位。
  2. 侧栏子项：navSlots.tsx 注册 chat-sessions，数据读 useChatMessageStore（置顶 + 最近 3 条）；「全部会话」弹窗里先原样放 ChatManagementSidebar。
  3. 停靠栏：AppShell 网格加第三列 assist 槽位 + shellStore 持久化开合与宽度；壳里挂同一个 ChatContainer（沿用 scrollPositionScope="right-chat-sidebar" 与 useRightChatSidebarStore.currentChatId）。
  4. Ctrl J / 命令面板「打开 AI 对话」「新对话」；BlockCard 点击改为纸内块预览抽屉（替代 BlockPreviewSidebar 的分栏）。
  5. 二期：当前页面上下文 chip、选中文字「问 AI」、消息与输入框按 tau 主题重写、antd 组件替换。
