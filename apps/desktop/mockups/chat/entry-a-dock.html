入口 A · 右侧停靠栏（推荐）

AppShell 增加第三列「辅助栏」槽位，AI 对话是它的第一个住户。标题栏右侧按钮 / Ctrl J 开合，任何页面都能与对话并排；宽度 360–560 可拖（默认 400），开合状态与宽度持久化。
  • 空间自适应（用上方「窗口宽」切换验证）：打开后正文 < 640px → 自动把左侧栏收成 58px 图标栏（关闭对话时还原）；仍 < 560px → 退化为覆盖式浮层，不再挤压正文。
  • 一期：面板壳 = 新写（标题行 + 会话下拉 + 开页 / 关闭）；主体原样挂 legacy ChatContainer（scrollPositionScope="right-chat-sidebar"），会话与对话页同源 useChatMessageStore。
  • 二期：输入框里「当前页面」上下文 chip（legacy 没有自动注入，现靠 MCP tab-tools 让 AI 自己读）；选中文字「问 AI」送入面板。
  • ＋ 高频入口零跳转、可边读边问；与 legacy 心智一致，迁移成本最低。
  • － 1280 宽窗口下正文被压到约 660px，只能靠收起左栏换空间；需要给 AppShell 加一个新槽位。
