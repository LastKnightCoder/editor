数据库视图 · 右侧筛选与搜索重设计（初稿）

范围：ViewTabs 右侧控件（搜索框 + 筛选 / 排序 / 分组三钮）与三个 Popover 的内部结构。 对应实现 src/components/Database/ViewTabs.tsx · FilterPanel · SortPanel · GroupPanel。 现状四个问题：① 三图标钮间距 6px 挤在一起；② 搜索框 150px 常驻、视觉重；③ 低透明度图标群常显，页面不安静；④ 三个 Popover 均为「盒子套盒子」，编辑成本高。 已裁决（2026-09-21）：采用方案 B——搜索位于筛选左侧、清空 + 失焦收回且跨视图不保留；面板保留「取消 / 确定」；日期分组加二级粒度；空态加常用引导。详见页底裁决记录。

裁决记录（2026-09-21）

  1. 工具栏：采用方案 B（胶囊钮）；搜索位于筛选左侧，不落最右。
  2. 搜索收回：清空 + 失焦即收回；切换视图时清空收起、不保留关键词。
  3. 面板交互：保留现「取消 / 确定」暂存逻辑（本地编辑、确定生效），底部补「清空」快捷；实现中若发现现逻辑缺陷，先修复再调整。
  4. 分组粒度：日期字段增加二级粒度（按日 / 按周 / 按月）——groupBy 数据模型需扩 granularity 字段。
  5. 空态引导：排序 / 筛选空态提供常用项一键添加（见上方引导卡片）。
  6. 实现范围（待排期）：ViewTabs 右侧 + 三面板均在通用 Database 组件（src/components/Database/，legacy 侧），改动影响卡片库数据库视图与其余 DataTable 使用方；实现排期与迁移方式另行裁决。
