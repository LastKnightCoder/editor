网页书签块（bookmark）· 设计方案块级链接卡：网站图标 + 名称 + 标题 + 描述 + 封面 · 颜色取自 @tau/themes · 封面和网站图标是示意图

三种外观都做，存在节点的 appearance 上，从操作条「⋯ → 外观」随时切换，切换不重新抓取。A 横向卡是默认，高度约 104px，夹在段落之间不抢戏；B 封面卡像社交分享卡，适合单独推荐一个站点；C 紧凑行适合一组参考资料连续排列。页面没有封面时 B 自动按 A 显示。

元数据在插入时抓取一次并存进文档，之后渲染只读文档里的快照，不会每次打开都联网。所以「加载中」只出现在插入后的一两秒；抓取失败或页面没有 Open Graph 信息时，卡片退化成「网站图标 + 域名 + 完整网址」，依旧可点。

「粘贴为」菜单只在空段落里粘贴单个网址时出现，默认项仍是链接，↵ 即确认；行内粘贴（段落里已有文字）不出现菜单，和今天一样直接成链接。另一个入口是斜杠菜单 / 块菜单里的「网页书签」。

书签是 void 块，桌面单击整卡直接打开网页（编辑态也一样，卡片里没有可放光标的文字），交给 IOpenerService 用系统浏览器打开。选中、拖拽靠左侧手柄，其余操作放右上角悬停条。标题不理想可以在编辑面板里改，改过的字段刷新时不会被覆盖。

手机帧 360×760。正文宽度只有 320px 左右，横向卡改为右侧 76px 方形缩略图，标题允许两行、描述一行。阅读态点一下直接打开（交给系统浏览器）；编辑态点一下只选中，底部弹出操作面板，避免误触跳出应用。返回手势先关面板。
