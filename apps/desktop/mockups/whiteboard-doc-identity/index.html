文档卡的「文档感」

要解决的问题

文档卡现在是「白底 + 圆角 + 底部渐隐」，和带边框 / 底色的富文本、矩形差别很小，手绘模式下尤其分不出来。文档的本质是「一份放在别处的独立文件」，所以区分靠身份符号，而不只是阴影。

现状

  • 普通模式靠阴影勉强区分；手绘模式只剩手绘框，与带框富文本几乎一样。

D · 圆角 + 阴影

  • 圆角放大到 16px，阴影三层：贴边细描线、近处接触影、远处柔和投影，像一张纸浮在画布上。
  • 不加任何装饰，最干净；靠「浮起来」与贴在画布上的富文本拉开层次。
  • 手绘模式也保留阴影，纸面手绘框画成圆角。

E · 圆角 + 阴影 + 卡头

  • 在 D 的基础上加卡头（类型 + 标题），身份更明确，低缩放时也认得出是哪类文档。

B · 卡头 + 纸叠

  • 保留作对照：后面错开露出纸张的边。

手绘模式

  • D / E 保留阴影；纸叠改用手绘线条，卡头文字用手写体。

50% 缩放

  • 正文缩成骨架线；阴影与卡头仍保留。
