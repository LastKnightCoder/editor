设置 · 方案 A 第三版

第二版的粉彩和渐变已撤回。这一版只用我们的主题语言，骨架还是方案 A：1080 宽弹窗加左侧导航。

对照 02 规范与已定稿的「发布」页

  • 表面中性：只有纸色（弹窗底）和 surface（面板）两层。面板沿用发布页的 surface + shadow-card，不描边；弹窗是唯一用 shadow-float 的浮起物。
  • 色彩表意：accent 只用在选中项、主按钮、焦点和分段选中段；ok / warn / danger 只作状态点和失败数字。图标一律中性墨色，没有品牌色，也不按分区上色。
  • 层级：页标题 20 / 600，分组标题 13.5 / 600，行标题 13.5 / 500，说明文字 12.5 / ink-2（符合规范的说明性正文下限），字重只用 400 / 500 / 600。
  • 不拥挤：行高 56，分组间距 28。同一面板内的行之间用 line-2 弱分隔（规范「列表行间」的专用 token），分组靠面板和留白区分。
  • 控件：全部是 @tau/ui 定稿的样式——连体描边分段、描边输入框和下拉框、accent 开关，没有新造控件。
  • 资源同步：放在「同步」页的第二个 Tab 里，包括文件列表、需重传项和黑名单。
