文章 · 网格 / 列表切换

现在的月刊网格封面占了大半张卡，一屏只能看到 6～9 篇。列表排布一屏能放 12 篇以上，适合整理和翻找。做法和项目列表（D-092）一致：同一份数据两种排布，偏好按本机保存。
  • 切换入口：工具栏放「按钮 + Menu」（网格 / 列表），位置在搜索框和「导入」之间，与项目工具栏 A 方案一致。文章页标题栏没有面包屑速切器，所以不放在那里。
  • 行：小封面缩略（有 banner 用 banner，没有就用 id 派生的渐变色，和卡片同色）+ 标题 + 一行摘要；之后是标签、字数、更新、创建、悬停操作（置顶 + ⋯，菜单与卡片一致：演示 / 导出 / 换封面 / 窗口打开 / 删除）。播客用耳机小图标标出。
  • 分组可选（控制条切换）：
    A 按月分段：月头吸顶，和网格同一套分段与无限滚动，主进程不用改，只是换了排布。
    B 平铺 + 列头排序（创建 / 更新 / 字数 / 标题，置顶始终在前）：需要给 getArticlePage 加 orderBy 参数，分页仍按 offset。按更新时间排序是网格做不到的，适合找「最近改过的那篇」。
  • 搜索：标题搜索框两种排布都能用，列表里把命中的词高亮出来。
  • 不做：「最近打开」续读行。文章表没有打开记录，要加得像项目那样补 last_open_time，这个之后再说。
