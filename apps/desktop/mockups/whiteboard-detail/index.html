白板详情页设计探索 · 三方案

现状：legacy pages/WhiteboardDetailView 有两种形态。一种是多页白板：画布下方是一条通栏的子白板页签（毛玻璃底 + 上边框横线），页签悬停出现编辑 / 删除图标，拖动排序，「＋」弹窗输入名字新建，删除走 modal.confirm，每 3 秒整页保存一次。另一种是单页（独立或嵌套白板）：顶部一条 antd 面包屑（带上边框线）+ 画布。画布本身自带四件东西：左侧 300px 的元素树侧栏、顶部居中的工具条、右侧属性栏、右下角状态栏（网格 / 缩放 / 演示），都是蓝调毛玻璃风格。

新壳层里已经有 whiteboard-content 画布页（列表页和嵌套白板都跳它），但只能看一页。三个方案都在这一页上补多页能力，共用同一份 mock（「Transformer 结构拆解」4 页）。都能操作：切页、新建页、双击改名、右键 / 更多菜单（重命名 / 复制 / 删除）、拖动排序、元素树浮层、⌃PageUp / ⌃PageDown 切页。点标题栏里的白板名会打开编辑信息。画布里的浮动件只是示意位置，按主题语言重画过。

方案 A2

底部页签栏 · 纸面底部一整条，左页签、右状态

画布纸面分上下两段：上面是画布，下面一条 40px 的页签栏（surface 底，两段靠底色区分，不画横线）。左侧「＋ 新建页」和「所有页」列表，接着是各页签，当前页与上方画布同色、底部一道 accent 短线；页多时横向滚动。右键页签：重命名 / 复制 / 删除，双击改名，拖动排序。网格、缩放、演示从画布右下的浮层并进页签栏右侧。

✓ 与 XMind 一致；页名常驻；画布上少一块浮层✗ 纸面底部固定占 40px（包括只有一页的白板）

一轮 · 三个方案

方案 A

底部页签 · 画布左下一条浮起的页签

最接近 legacy 和表格软件的「工作表」。页签不再是贯穿底部的通栏，而是画布左下角一块浮起的小条，与右下状态栏在同一水平线上；当前页用 accent 淡底。页很多时页签条横向滚动（演示开关「页很多」）。画布占满整个内容区。

✓ 熟悉、直接；页名一眼全在，切页一次点击；不占任何额外空间 ✗ 页签只有名字，看不到每页的内容；页多了要横向滚

方案 B

侧栏嵌套页 · 页挂在全局侧栏「白板」下面

和协作页 A3、日记标签同一套做法：打开一块白板时，全局侧栏「白板」入口下展开这块白板的名字和各页（页码 + 页名，悬停显示元素数和「更多」），末尾「＋ 新页」，上下拖动排序。页面里只剩一整张画布。

✓ 最沉浸，画布上没有页的控件；和已定稿页的侧栏嵌套一致；页名竖排不怕长 ✗ 侧栏收起成图标列时看不到页（要靠快捷键或展开侧栏）；看不到每页的内容

方案 C

翻页器 + 页总览 · 平时只露当前页，要时展开缩略图网格

像 Keynote 的看片台。画布左下只有一个紧凑翻页器「‹ 2/4 注意力机制 ›」；点页名或网格按钮，同一张纸上展开「所有页」：每页一张画布缩略图（列表页那套缓存），拖动排序、双击改名、悬停「更多」、末尾「＋ 新页」，点一页跳过去并收起，Esc 关闭。

✓ 平时画布最干净；总览里每页长什么样一目了然，排序最直观 ✗ 切到不相邻的页要多一步（打开总览）；页名不常驻

三个方案都做的事

  • 元素树不再占一列：画布自带的 300px 元素树侧栏和全局侧栏并排就是「两条侧栏」（PREFERENCES 反例）。改为画布左上一个按钮，点开是盖在画布上的浮层，不挤压画布；
  • 一整张纸：画布是内容区里的一张 surface 大纸，四周不再有通栏横线（legacy 页签条和面包屑都带边框线）；
  • 标题栏面包屑：「白板 / 白板名 / 当前页」，点白板名打开编辑信息（与列表页同一个弹窗）；嵌套白板（画布里的白板元素）继续新开一页，逐层返回靠后退；
  • 切页不进历史：同一块白板内切页只原位换参数，后退直接回到列表或上一个地方，不是一页一页倒回去；
  • 新建页不弹窗：直接建「第 N 页」并切过去，名字之后双击改；删除页仍然确认（这一页的元素会一起删掉，不可撤销）；
  • 保存：沿用现在的实时保存（改动停 400ms 落库），替代 legacy 每 3 秒轮询保存；缩略图照列表页的机制后台生成。

可以混搭的部件

  • C 的页总览可以加到 A 或 B 上，作为「看所有页长什么样 / 大量排序」的补充入口；
  • A 的页签可以只在侧栏收起时出现，给 B 兜底。

待你拍板的几件事

  • 画布自带的浮动件要不要这次一起换皮：工具条、属性栏、状态栏、右键菜单、各种插入弹窗现在都是蓝调毛玻璃 + antd。只迁页面壳层的话，打开画布会是新旧两种风格混在一起；一起换皮的话，这次的改动范围会大很多（画布组件内部十几个文件）。建议先迁壳层，换皮单独做一轮 mockup；
  • 独立白板（画布里「新建白板」嵌进去的那种，不属于任何白板，只有一页）：打开时不显示任何页控件，面包屑只有「白板 / 页名」。可以吗？
