B · 预览上正文，对话退到停靠栏（推荐）

只有一条规则：预览永远占正文，对话永远在右边。块预览是页面栈里的一页（已有 block-preview 页）：从对话页点开时，对话用现成的形变过渡收进右侧停靠栏，预览占满正文纸；从任意页面的停靠栏点开时，同样推入预览页、停靠栏不动。后退 / Esc 关闭预览，回到原页面（从对话页来的会把对话还原成整页）。
  • 实时：预览页不再拿冻结的快照，而是按「会话 + 消息 + 第几个块」从对话仓库实时取内容，停靠栏里继续追问生成的新版本直接出现在版本切换里。
  • ＋ 对话页和停靠栏一套形态、一个组件；演示页 / 导图拿到最大画面（1440 下约 900px）。
  • ＋ 复用已有机制：页面栈（后退 / 历史）、停靠栏、对话页 ⇄ 停靠栏形变；预览页能单独被 MCP / 命令面板打开。
  • － 从对话页点开会发生一次「对话收进侧栏」的形态变化，需要形变过渡做得顺；对话只剩 400px 宽。
  • － 窄窗口（1280）下停靠栏 + 预览要先自动收起左栏（沿用停靠栏已有的空间裁决）。
