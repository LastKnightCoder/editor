统一预览框

不管 A / B / C 选哪种容器，里面都是同一个预览框：头部一行固定骨架（图标 · 标题 / 类型·大小 · 版本 · 预览⇄源码 · 类型专属工具 · 复制 · 全屏 · 更多 · 关闭），画布类的缩放控件浮在右下角，不占头部。渲染器只声明「有哪些专属工具 / 更多菜单项」，chrome 由框统一画——替掉现在每个渲染器各写一套 antd 工具栏。
