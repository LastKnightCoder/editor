标签 · 选已有标签 + 批量修改（卡片库，文章同一套）

反馈两个问题：① 加标签只能手打，记不住已有的叫法，容易打出「前端/css」「前端/CSS」两个；② 想给一批卡片统一加 / 去标签，或把一个标签改名，找不到入口。
  • 标签选择器（一件，三处用）：点「添加标签」弹出选择器，空输入列出最近用过与全部标签（按使用次数），输入即模糊匹配（含路径，打「css」命中「前端/CSS」）；没有完全同名时最后一行是「新建「xxx」」。↑↓ 选、↵ 加上、可连加，Esc 收起。详情页、新建卡片、批量都用它，替换现在的 contentEditable 手打框。
  • 批量：列表视图多选：列表行首留一格勾选框，悬停才出现；点勾选或 ⌘/Ctrl 点行进入选择，Shift 点选连续一段，表头勾选框全选当前筛选结果。选中后纸底出现不透明选择栏：已选 N 张 · 标签 · 置顶 · 导出 · 删除 · ✕。卡片墙不加勾选（卡面靠浏览，整理去列表）。
  • 批量改标签 = 同一个选择器的三态版：每个标签显示「全部有 ✓ / 部分有 – / 都没有 ☐」和「3/5 张」；点一下在「全部加上 ↔ 全部去掉」间切换，部分态可回到原样。改动先在行上预览（新增橙底、去掉删除线），点「应用」一次写入，可撤销。
  • 改名 / 合并 / 删除：放在标签本身上：侧栏标签树每项悬停出 ⋯（替换计数位置）：重命名、删除标签。重命名到一个已存在的名字即合并，弹确认说明影响几张；改父级「前端」时子标签「前端/CSS」一起改。删除只从卡片上摘掉，不删卡片。
