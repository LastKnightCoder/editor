Vibe Learning 页 · 排版方案

现状：VibeLearningView 是三块并排的板子（资料 / 对话 / 应用侧栏）直接贴在页面底色上，里面 ResourcePanel、生成弹窗等仍用 antd。这一轮只看排版：三套方案都是「一整张纸」，每套都可以在顶栏切换 默认 / 空项目 / 预览资料 / 编辑笔记 四种状态。生成配置弹窗、添加资料弹窗、测验答题这几块等排版定下来再单独出。

三套排版

区别在于资料、对话、工作室三者谁是主角。

A 纸内三栏

保留现在的三栏心智，合进一张纸，纸内透明栏。打开资料 / 笔记时中间变大画面，对话退到右栏。迁移成本最低。

B 对话为主

和 AI 对话页同构：资料变成输入框上方的 chips，工作室收进右侧非模态抽屉。最沉浸，窄窗口最宽裕。

C 学习台

左栏资料 + 产物合成一棵目录，中间常驻阅读区，右边对话。围着「当前这份资料」看、问、生成。

三套共用的改动

  • 三块板子合成一张 surface 纸，栏与栏之间不画横线，只用一道极淡的竖线和留白分开。
  • 应用卡片去掉副标题，改成细描边的小格（图标 + 名称）；「创作内容」和「测验集」两个空态盒子合成一个产物列表，「新建笔记」收进产物区的 ＋。
  • 资料行把处理状态标在行内（转录中进度条 / 失败 + 重试），不另起徽章。
  • 对话头部保留会话切换（「新对话 ▾」），输入框控件保留现有四项：＋、手动确认、模型、思考强度。回答里的引用做成可点的角标和来源 chips。
  • antd 全部换掉：按钮 / 菜单 / 弹窗 / 进度条走 @tau/ui，图标统一 lucide。
