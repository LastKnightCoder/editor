闪卡复习设计探索 · 三方案

现状：legacy pages/FlashcardCenter 是「可拖宽的卡组侧栏 + 主区瀑布 / 表格 + 居中复习大弹窗 + 编辑大弹窗」，样式靠 useThemeColors 拼 class 串，混着 antd modal.confirm、旧 --th-* 和 slate / white 硬编码。三个方案共用同一套 mock 数据（6 个卡组，其中 1 个空卡组、1 个今天已复习完；32 张卡片，五种题型都有，含填空备选答案、选项解析、参考资料），也共用同一个复习引擎和编辑器，用的是 cream / cocoa 两套主题的真实 token 值。浏览器打开就能操作：作答、翻面、评分、撤销、暂停、编辑、新建、筛选、右键菜单都能用，右上角可以切换明暗。

领域判断：闪卡和待办、卡片库有什么不同

导航里这一项叫「闪卡复习」，说明页面的主要任务是复习，其次才是整理卡片。三个方案的分歧来自下面四点：

  • 一天里的两种状态：复习是每天一次、一次 5～20 分钟的连续作业，需要专注、需要键盘、不能被别的东西打断；整理（新建、改错、挪卡组）是零碎的，常常在复习过程中顺手发生；
  • 队列由排期决定：什么时候复习哪张卡由主进程 calculateSchedule 算出来，用户的决定只有「现在复习不复习」「这张记得怎样」。所以首屏最重要的信息是「现在有几张、分别在哪些卡组、大概多久」；
  • 五种题型的作答方式不一样：单选 / 判断选完就能判对错，多选和填空要提交，问答只能自评（配置模型后可以让 AI 评判）。评分和判对错是两件事：答对了也可以评「模糊」；
  • 卡组是轻量容器：只有名称、图标、颜色、描述，数量一般是个位数到十几个。

三个方案都修掉的 legacy 问题

  • 复习全程可以只用键盘：legacy 复习弹窗没有快捷键。现在是 A–D 选选项、↵ 提交、Space 显示答案、1–4 评分、E 编辑本卡、S 暂停本卡、⌘Z 撤销上一张、Esc 结束；
  • 评分按钮显示下次间隔：「忘记 · 15 小时后」「记得 · 5 天后」，算法和主进程 calculateSchedule 完全一致（纯函数，前端可以直接算，不用新 IPC）；答题后会按对错描边推荐一个评分（答错推荐「忘记」，答对推荐「记得」），按 Space 直接采用；
  • 评分文案统一：legacy 复习弹窗是「困难 / 较难 / 一般 / 轻松」，统计页定稿是「忘记 / 模糊 / 记得 / 轻松」，这次统一用后者，按键顺序从忘记到轻松；
  • 可以跨卡组复习：legacy 只能复习当前选中的卡组。现在有「全部卡组」队列（同主进程 get-review-queue 的排序），提交评分时 deckId 用卡片自己的 card.deckId，不用当前页面选中的卡组；
  • 「暂停」接上界面：后端有 suspended 状态，但 legacy 没有设置和查看的入口。现在复习中按 S、右键菜单、编辑器里都能暂停和恢复，卡组视图里有「已暂停」分组；
  • 删除不再二次确认：卡片删除立即生效，Toast 里可以撤销，和待办的做法一致（D-040）。卡组删除会连带卡片，所以保留确认，确认文案写明会删几张；
  • 连续录入：新建闪卡时可以「保存并新建」（⌘⇧↵），卡组和题型沿用上一张；填空题在题干里选中文字、按「设为填空」或 ⌘⇧C 挖空，每个空可以填备选答案；
  • 清理：ReviewDock.tsx 已经没有引用，迁移时和 FlashcardGrid、DeckSidebar 一起登记进 04 删除清单。

三个方案的共用基线

  • 复习卡内容三方案完全一致，只是承载方式不同：卡组 · 题型 · 状态 → 题干 → 作答区 → 翻面（判定 → 答案 → AI 评判 → 解析 → 参考资料）→ 评分条。翻面用一段 accent 短刻度分开，不画横线；
  • 编辑器内容三方案一致：题型分段 → 题干 → 按题型变化的答案区（选项点字母标正确答案 / 填空列表 + 备选答案 / 参考答案 / 正确错误）→ 提示 → 解析 → 卡组 · 难度 → 标签 → 参考资料（关联笔记沿用 ContentSelector）→ 复习信息（编辑时显示）；
  • 卡组身份 = legacy 图标键 + 卡组色：图标沿用 flashcardDeckIcons 的 10 个线性图标（旧 emoji 由 DeckIcon 兼容），legacy 10 个 coverColor 收敛到 tag-1…5 和 accent，只用来区分卡组，不新增 token；
  • 状态和评分用语义色：新卡 = info、学习中 = warn、巩固 = ok、暂停 = ink-3；忘记 = danger、模糊 = warn、记得 = ok、轻松 = info。现在到期用 accent-text，逾期用 danger；
  • 视觉规则照旧：分组不画横线、数字用 tabular-nums、滚动区边缘渐隐、4px 细滚动条、页内不做搜索（统一走全局 ⌘K）、新建放在工具栏右上。

三个方案

方案 A

复习台 · 两块板 + 沉浸复习

骨架和待办 B3 的「两块板」一样：工具栏 → 卡组 pills → 左板 + 右板。左板顶部是「今天 21 张待复习 · 约 9 分钟」和「开始复习」，下面每个卡组一行（待复习数、构成条、7 日到期柱）；点 pill 或卡组行，左板换成这个卡组的卡片列表，按「待复习 / 今天稍后 / 未来 7 天 / 更晚 / 已暂停」分段。右板放连续天数、近 7 天评分分布、未来 7 天到期。开始复习后导航侧栏平滑收起，页面只剩一张题卡和评分条，Esc 退出后恢复原布局。

✓ 最直接回答「今天复习什么」；和待办 / 文章 / 项目页骨架一样；复习时最专注 ✗ 批量整理卡片不方便（每张都要打开 Dialog）；右板的统计和统计页有一部分重复

方案 B

卡组工作台 · 三栏 + 常驻检查器

Anki 卡片浏览器的思路。左列是融在纸面上的卡组导航（今日待复习 / 全部卡片 / 已暂停 + 各卡组）；中板是卡片列表；右板是常驻检查器，选中就能看卡面，Space 翻面，E 或双击直接在检查器里编辑，⌘↵ 保存，编辑和新建都不开弹窗。复习用居中的 Dialog，结束后回到原来选中的位置。全键盘：↑↓ 选卡、⌫ 删除（可撤销）、N 新建、R 复习。

✓ 整理和批量录入最快；编辑不遮挡列表；键盘效率最高 ✗ 三栏加导航侧栏共四列，1200px 宽时列表偏窄；首屏像管理工具，「今天复习」只是一个按钮和一个计数

方案 C

卡组书架 · 封面网格 + 翻面卡片墙 + 页内卡堆

把卡组当成一叠实体卡片。总览顶部是一块「今日条」：待复习数、按卡组分流的小按钮（只复习这一组）、开始复习；下面是卡组封面网格，封面用卡组色派生渐变，上面叠着几张卡片的轮廓，hover 时轮廓散开。进入卡组是卡片墙，放在一整块大面板里，点击卡片原地 3D 翻面看答案，双击编辑。复习在页内进行，题卡身后叠着剩余卡片的轮廓，顶部一排圆点随评分着色。

✓ 个性最强，最有「闪卡」的感觉；卡片墙浏览和自测很直观；和项目页 C 的封面语言一致 ✗ 封面网格是多张卡片并排，有「碎卡漏底」的风险；看卡组状态要逐张看；卡片墙的信息密度最低

可以混搭的部件

  • 三种复习承载（沉浸模式 / Dialog / 页内卡堆）可以互换，复习卡内容是同一份；C 的评分圆点可以替换 A 的进度条；
  • B 的检查器可以作为 A 卡组视图的右板（选中卡片时右板从卡组概况切换成卡片预览 / 编辑），这样 A 也能不开弹窗整理卡片；
  • C 的今日条分流按钮（只复习某一组）可以放进 A 的今日块；C 的卡片墙原地翻面可以作为 A 卡组视图的另一种显示方式（列表 / 卡片墙切换）；
  • A 右板的记忆节律（连续天数、近 7 天评分、未来 7 天到期）和统计页有部分重复，如果选 A，可以只保留「未来 7 天到期」，其余点进统计页看。

裁决记录（2026-09-24 一轮评审）

① 方向：选 A 复习台。

② 复习承载 = 沉浸模式，题卡在剩余空间里水平 + 垂直居中：初版题卡贴顶，已改为居中；卡片内容超过一屏时退化为从顶部开始、整体可滚动，不裁切。

③ 主按钮给「开始复习」：总览与卡组视图各一枚，新建闪卡 / 新建卡组为次级按钮。

④ 推荐评分保留：客观题按对错推荐（错 → 忘记，对 → 记得）；问答题只在已配置模型、且用户写了答案时调用 AI 评判，按分数推荐（≥9 轻松 / ≥6 记得 / ≥4 模糊 / 其余忘记）；未配置模型时问答题不评判、不推荐，由用户自评。

⑤ 不做表格视图：legacy 的表格视图不迁移，卡组视图只保留按到期分段的列表。

⑥ 已落地：features/flashcards（page key review，D-041）。
