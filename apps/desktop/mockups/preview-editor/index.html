编辑器 · 源码预览块重设计

对象是 components/PreviewWithEditor：Mermaid、PlantUML、公式、Typst、TikZ、ABC 乐谱、HTML、自定义块共用的「源码 ⇄ 渲染」容器。四个方向全部只消费主题 token（实现时落到 --ed-*），可切主题 / 明暗检验。每个方向的主演示可交互：悬停出操作条，点 编辑 或空块进入编辑，点 完成 或块外退出，点 全屏 打开工作台。源码可以直接改（mockup 不会真的重新渲染）。

00现状（复刻当前实现，用作对照）
左边是静止 / 悬停，右边是编辑中：源码在上、一根 2px 灰条、预览在下。Mermaid 图用的是改主题之前的官方配色，方便对照「块壳子」本身的问题。

操作条不随主题：rgba(38,38,38,.6) 深色玻璃 + 白图标，暖纸、樱这类浅暖主题上像贴了块黑胶布；和代码块的同款条是一个问题。
编辑态没有边界：只是整块铺上 code-bg，源码区和上下正文段落之间没有轮廓，看不出「这是一个正在编辑的对象」。
分隔太重：源码与预览之间是一根 2px 实心灰条，左右还各缩 20px，像一条没对齐的横线。
不知道是什么块：编辑时没有类型标识，也没有「完成」入口，只能靠点块外退出，新用户不知道怎么结束。
出错即白屏：语法写到一半，预览整块变成红字，改的过程中图一直在闪。
CodeMirror 主题外挂：one-light / blackboard 两套第三方配色，与主题族无关，深色下是一块藏青底。
空态寒酸：一行 #99A1AF 灰字「点击编辑图表」，既不像占位也不像按钮。
全屏只是放大：毛玻璃里把源码叠在预览上方，长源码会把图挤没；没有缩放，看不清大图。
A卡片展开（Typora 精修）推荐
保留你原来「平时只看到渲染结果」的思路，只把细节做对：静止时无边框，悬停浮出淡底 + 浅色操作条；编辑时整块收成一张 line-1 描边卡片，顶部一条细标题行（类型 + 全屏 + 完成），源码坐在 page 底上，1px 分隔后是实时预览。和代码块、标签页块 A 同属「平面描边」家族。
