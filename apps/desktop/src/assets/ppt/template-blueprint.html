KEY CONSTRAINTS

设计约束与技术边界

  • [PERF] API 响应时间 P95 不超过 200ms，P99 不超过 500ms
  • [SEC] 所有通信必须通过 TLS 1.3 加密，静态数据 AES-256 加密

  • [COMP] 符合 GDPR、SOC 2 Type II、ISO 27001 合规要求

COMPARISON

容器 vs 虚拟机

容器 (Container)

  • 共享宿主机 OS 内核
  • 启动时间 < 1 秒
  • 镜像体积 MB 级
  • 密度：单机百容器
  • 适合：微服务、无状态应用
VS

虚拟机 (VM)

  • 完整 Guest OS 隔离
  • 启动时间分钟级
  • 镜像体积 GB 级
  • 密度：单机数十 VM
  • 适合：强隔离、有状态服务
