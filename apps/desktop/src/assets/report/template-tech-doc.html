架构概览

系统架构

基于领域驱动设计（DDD）拆分的微服务架构，通过服务网格实现流量治理，事件总线解耦服务依赖。

gateway
API Gateway
基于 Envoy 的统一入口，支持限流、熔断、灰度路由。QPS 峰值承载 50K+。
mesh
Service Mesh
Istio 服务网格控制面，实现零信任安全、流量镜像、故障注入测试。
event
Event Bus
Kafka 事件总线 + Schema Registry，支持 exactly-once 语义，日消息量 12 亿条。
observe
Observability
OpenTelemetry 全链路追踪 + Prometheus 指标 + Loki 日志聚合。

接口规范

接口规范

ℹ API 设计原则
遵循 Google API Design Guide，采用 gRPC + HTTP/JSON 双协议。内部服务间通信使用 gRPC，对外网关暴露 RESTful HTTP 接口。
proto user_service.proto 
syntax = "proto3";

package api.user.v1;

service UserService {
  // 获取用户信息
  rpc GetUser(GetUserRequest) returns (User) {
    option (google.api.http) = {
      get: "/v1/users/{user_id}"
    };
  }

  // 批量查询用户
  rpc BatchGetUsers(BatchGetUsersRequest) returns (BatchGetUsersResponse) {
    option (google.api.http) = {
      post: "/v1/users:batchGet"
      body: "*"
    };
  }
}

message GetUserRequest {
  string user_id = 1;
  FieldMask read_mask = 2;
}
