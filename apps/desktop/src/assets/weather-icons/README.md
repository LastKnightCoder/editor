# 和风天气图标

本目录包含从 `qweather-icons` npm 包复制的图标文件。

- **图标数量**: 60 个
- **来源**: [qweather-icons](https://github.com/qwd/Icons)
- **版本**: 1.8.0
- **许可证**: CC BY 4.0

## 更新图标

运行以下命令重新同步图标：

```bash
node scripts/copy-weather-icons.mjs
```
