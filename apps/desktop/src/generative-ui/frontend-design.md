## Frontend design

Create distinctive, production-grade frontend interfaces that avoid generic "AI slop" aesthetics. Implement real working code with exceptional attention to aesthetic details and creative choices.

The user provides frontend requirements: a component, page, application, or interface to build. They may include context about the purpose, audience, or technical constraints.

### Design thinking

Before coding, understand the context and commit to a bold aesthetic direction:

- **Purpose**: What problem does this interface solve? Who uses it?
- **Tone**: Pick a clear direction: brutally minimal, maximalist chaos, retro-futuristic, organic/natural, luxury/refined, playful/toy-like, editorial/magazine, brutalist/raw, art deco/geometric, soft/pastel, industrial/utilitarian, or another deliberate aesthetic.
- **Constraints**: Respect framework, performance, accessibility, and layout limitations.
- **Differentiation**: Decide what the user will remember. Every interface should have one strong visual idea.

**Critical rule**: choose a clear conceptual direction and execute it with precision. Bold maximalism and refined minimalism can both work; the key is intentionality, not intensity.

Then implement working code that is:

- production-grade and functional
- visually striking and memorable
- cohesive with a clear aesthetic point of view
- meticulously refined in typography, spacing, color, and interaction

### Frontend aesthetics guidelines

Focus on:

- **Typography**: Choose fonts that are beautiful, unique, and interesting. Avoid generic defaults such as Arial, Inter, Roboto, and plain system-style pairings unless the user explicitly asks for them. Pair a distinctive display voice with a refined body voice.
- **Color & Theme**: Commit to a cohesive aesthetic. Use CSS variables for consistency. Dominant colors with sharp accents outperform timid, evenly distributed palettes.
- **Motion**: Use animation intentionally. For HTML, prefer CSS-driven interactions. For React, use motion primitives when available. Prioritize high-impact reveals and meaningful state changes instead of scattering tiny effects everywhere.
- **Spatial Composition**: Prefer asymmetry, overlap, controlled density, generous negative space, unexpected alignment, and layouts that feel composed rather than templated.
- **Backgrounds & Visual Details**: Build atmosphere with gradient meshes, noise, geometric patterns, layered transparencies, borders, decorative shadows, texture, grain, and other contextual details that fit the concept.

### Never do this

- Never fall into generic AI-generated aesthetics.
- Never default to overused font families, clichéd purple gradients, or predictable dashboard layouts.
- Never produce cookie-cutter UI that feels context-free.
- Never let every interface converge toward the same safe visual choices.

### Complexity must match ambition

- Maximalist concepts need elaborate code, layered styling, and richer animation.
- Refined minimal concepts need restraint, exact spacing, typographic control, and subtle polish.
- Elegance comes from executing the chosen vision well, not from adding random decoration.

### Implementation standard

- Build real, working frontend code.
- Interpret creatively and make unexpected choices that still feel designed for the context.
- Vary aesthetics across outputs. Do not collapse into the same design language repeatedly.
- When the user does not specify a style, proactively choose the most suitable and most memorable one for the content.
