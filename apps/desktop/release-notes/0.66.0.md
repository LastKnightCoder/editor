## 新功能

- **右栏浏览网页**：在对话栏里点网页链接，网页会占用右栏，和正文并排看；按住 <kbd>Ctrl</kbd> 点击链接，可以直接用系统浏览器打开。点栏头左上角的「AI 对话」回到刚才的会话，草稿和正在生成的回答都会保留；在 PDF 或视频笔记里，这个按钮带你回到当前文档的对话。
- **插件页面进驻右栏**：支持右栏的插件可以和正文并排使用。按 <kbd>⌘K</kbd>（Windows / Linux 用 <kbd>Ctrl+K</kbd>）输入插件提供的命令并执行即可打开，右栏右上角可以放大或收回。从插件打开网页后，点网页左上角的插件页面名称，就能回到刚才的位置。
- **数据库从已有内容新建**：新建数据库时可以直接选数据源——卡片、文章、项目文档或日记。左边设置范围（比如只要某些标签、某个项目、本月日记），右边实时预览前几行。建好的表格和原内容保持关联：可以在表格里直接改标签、置顶等字段，表格里新建的内容会带上所选标签；带锁的字段（如创建时间）仍回原来的页面修改。
- **白板指针模式合一**：工具栏最左边的按钮显示当前指针模式，点它右侧的小箭头，可以在「指针」「抓手」「文本」之间切换；用完其他工具，点主按钮就能回到它显示的模式。抓手从文字、图片或空白处按住左键拖动都可以平移画布；文本模式点空白处直接打字，再点另一处空白就能接着写下一段。
- **快速提问新话题**：按 <kbd>⌘⇧J</kbd>（Windows 上为 <kbd>Ctrl+Shift+J</kbd>）在窗口底部呼出输入框，写完按 <kbd>⌘↵</kbd> 发送，右侧对话栏会打开并显示新会话；在 AI 对话页里则直接切到新会话。在 PDF 或视频笔记里这样提问，新会话属于正在看的文档。发送前按 <kbd>Esc</kbd> 或点输入框外面可以收起。

## 改进

- 白板的元素树与素材架合并到画布左侧的同一个侧栏，可互相切换，宽度分别记住。
- 降低白板画布平移和 PDF 文档卡松手的延迟，拖动更跟手。
- 界面字体默认改为使用系统字体。
- 复制到微信公众号时，正文左右留白收窄。

## 修复

- 修复番茄钟里预设与时间账本相互遮挡、开始按钮点击无效的问题。
- 修复白板标题栏的元素树无法展开和收起的问题。
