## 新功能

- **Markdown 文档全文查找**：在 Markdown 文档窗口按 Ctrl/⌘+F 即可查找全文，渲染模式与源码模式都支持，逐个定位并高亮命中位置。

## 改进

- 超长 Markdown 文档打开即可编辑：长文只渲染窗口内的内容，滚动时按需加载，从打开到可以输入大幅加快；保存、复制与导出仍覆盖全文。
- 知识地图洞见分析时，地图上会实时点亮 AI 此刻正在阅读的主题，各主题读完后全部点亮；正文里的洞见读取期间改为在报告卡位置显示骨架占位，不再整篇扫光。
- 正文行内续写建议会参考前后段落的内容，长文中的续写更连贯。
- 点击提醒通知的「查看」可以直接跳到对应的待办、日程或正文中的任务。

## 修复

- 播客待审稿通知可以直接打开这一期的审稿页。正在处理这期播客时，页面会原地更新，不重复弹通知。
- 修复后台通知无法唤起更新详情、正文待办提醒无法定位原文的问题。
- 修复导出图片时预览与实际内容可能不一致的问题：预览现在使用当前正在编辑的正文，未保存的改动也会同步体现在预览和导出结果中。
- 修复取消加粗、下划线等行内格式后，改动可能未被保存或同步给协作者的问题。
