## 升级须知

- 本版改进了正文的保存方式，在 0.62.0 中编辑过的内容，旧版本无法正常读取：旧版电脑端会提示「正文数据格式不兼容」，旧版手机端会显示为空白。如果你在多台设备之间同步，请把其他电脑一并升级到 0.62.0、手机端升级到 0.3.7；升级完成前，不要在旧版手机端编辑这些内容，以免覆盖电脑上的修改。

## 新功能

- **个人助手记忆**：AI 助手会从你在对话中的自述、日记、待办与日程，以及近期编辑过哪些资料中，逐步了解你的近期状态与长期偏好，并记住最近几次对话的要点与遗留事项，新开对话也能接上话题。记忆在后台自动整理、定期复核，无需手动维护；想更正或让它忘掉某件事，直接在对话里说即可。在「设置 › 大语言模型 › 功能分配」为「个人助手记忆」指定模型后启用；记忆只保存在本机，不参与同步。
- **AI 行内建议**：在卡片、文章等正文或代码块中输入时稍作停顿，光标后会出现 AI 续写的灰色建议，按 Tab 采纳（可撤销）、Esc 忽略；代码块里没有建议时 Tab 照常缩进。在「设置 › 大语言模型 › 功能分配」为「行内建议」指定模型后启用，只发送光标附近的文字；协作文档需另外打开「协作正文的行内建议」。
- **表格合并单元格**：在表格中选中多个格子后可以一键合并，选中合并格后可以再拆分；增删行列、复制粘贴时合并自动保持，从网页复制的合并表格也能原样保留。导出为 Markdown 时不保留合并（Markdown 表格语法本身不支持）。
- **内置手写字体**：「设置 › 外观 › 字体」新增内置的中文手写字体「小赖 SC」和英文手写字体「Shantell Sans」，无需在系统中安装即可选用，界面与正文统一生效。

## 改进

- **功能分配更灵活**：为支持推理的模型分配功能时，可以单独设置思考强度（如「不思考」「细致推演」），让剪藏、标题总结等后台任务更快完成，或让需要推敲的功能想得更深；对话的思考强度在输入框未单独调整时也跟随这里的设置。每项功能都可以选择「取消分配（不使用 AI）」，随时停用。
- **长文档保存更轻快**：日常编辑只保存改动到的段落，不再每次重写整篇正文。
- 对话记录同步更快：每次同步只读取一份完整索引，未变化的对话不再逐个向云端核对，请求次数大幅减少。

## 修复

- 修复仅打开或浏览卡片、文章、项目文档也会刷新修改时间、被算作一次编辑的问题；现在只有真正改动正文才会更新时间。
- 修复打开其他窗口时，已连接的自定义 MCP 服务器会被断开重连的问题；现在多个窗口共用同一个连接。
- 修复为笔记建立检索索引时可能把代码块从中间切开，导致 AI 检索到的代码不完整的问题。
- 修复番茄专注的预设列表中，鼠标移到开始按钮上时按钮消失、难以点击的问题。
- 修复插件中心等处的标签栏出现多余纵向滚动条的问题。
