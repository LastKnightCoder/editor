这次更新的主题是「跨端」：Tau 手机 App 正式到来——Android 版可以在官网下载、在应用内直接升级，iOS 版开启测试，手机端的编辑器和同步全面重做。插件生态打通两端：同一个插件在桌面和手机上通用，插件中心还支持并行安装与一键更新。桌面这边，长文档打开更快，独立 Markdown 窗口更好用，协作服务完成升级，已有身份与房间关联延续。

## 新功能

### 手机 App

- Android 版上线：在官网 taunote.app 下载安装，之后可以在应用内检查新版本并直接升级。
- iOS 版开启测试，正式版准备中。
- 手机端编辑器全面重做：打开内容默认是清爽的阅读视图，双击或点「编辑」开始修改；工具栏贴合键盘弹出，表格、代码块、公式、流程图都有专属操作；可以多选内容块批量移动、转换、复制或删除，也能拖拽调整段落顺序。
- 手机端新增「同步中心」：同步状态一眼看清，支持整库覆盖同步；图片、附件的上传管理也统一并入了这里。
- 手机端的正文字体新增霞鹜文楷、思源宋体可选（按需下载），字号提供 9 档。
- 在微信等应用里打开的 Markdown 文件，可以直接转存进 Tau，保存为卡片或文章。

### 插件：一个插件，两端通用

- 插件全面跨端：同一个插件在桌面和手机上都能安装使用。
- 语音合成插件升级后支持手机端朗读（Android 与 iOS）。
- 插件中心支持并行安装与一键更新：可以同时安装多个插件，中途关掉面板也不中断；「全部更新」一次升级所有插件，更新前会列出版本变化和新增权限。

### 桌面编辑器

- 长文档打开明显变快：内容先以只读形式立即呈现、随时可读，进入编辑时阅读位置不丢失；表格的编辑与保存也更流畅。
- 公式编辑更顺手：源码与预览之间的切换和原位编辑交互改进。
- 字数统计口径统一：卡片、文章、白板与协作中显示的字数保持一致，插件内容块里的文字也计入统计。
- 语音合成设置新增「试听」，挑选声音前可以先听一句效果。
- Windows 上的本地语音转录（Whisper 模型）完成适配，可正常使用。

### 独立 Markdown 窗口

- 大纲移到正文右缘，边写边跳转更方便；大纲过长时自己滚动，不再带动正文。
- 文件树密度放宽、行距更舒适，侧栏宽度可以拖动调整。
- 大纲中的长标题自动省略、悬停可看全文，选中与悬停样式等一系列细节全面修正。

### 协作

- 协作服务完成整体升级并统一到产品域名，已有身份与房间关联自动衔接。旧正文和白板需要按提示显式转换格式，转换前保留原始材料，不在打开内容时自动改写。

## 改进

- 附件等大文件的同步改为分块传输，更稳定、资源占用更低。
- Windows 上的文件操作菜单显示正确的文案（如「在资源管理器中显示」「移到回收站」），不再出现 macOS 专用的说法。
- 选中图片时的属性工具条更精简，说明文字不再遮挡内容。

## 修复

- 修复首页偶尔在内容加载完成后仍提示超时的问题。
- 修复手机端 Android 安装包启动闪退、键盘遮挡编辑工具栏、快速连按回车偶发丢字等问题。
