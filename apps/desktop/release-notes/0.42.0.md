## 新功能

- **记忆**：日记和聊天中的内容会被 AI 记住，之后的对话更懂你。
- **Markdown 粘贴即所得**：粘贴 Markdown 文本会自动转成编辑器格式，不再是一整段源码。
- 浏览器扩展支持把网页保存为卡片、文章等内容，并自动同步到应用。

## 改进

- 编辑器打开的 Markdown 文件被外部修改后，会自动同步最新内容。
- 沉浸模式与普通模式切换时，光标位置保持一致。
- 文章详情页界面优化：去掉滚动条，底部状态栏更清爽。
- Vibe Learning 项目效果优化并新增配套工具，还支持生成长篇文章。
- 博客模板界面与发布体验优化。
- 代码块的语言列表过长时可以滚动选择。
- 适配 Kimi 模型，思考内容可正常传递。

## 修复

- 修复文章添加按钮的交互问题。
- 修复退出沉浸模式时报错的问题。
- 修复在列表末尾按回车会跳到上一个内容块的问题。
- 修复复制部分内容时带入多余内容的问题。
