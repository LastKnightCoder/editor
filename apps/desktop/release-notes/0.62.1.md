## 新功能

- **对话子 Agent**：AI 可以把独立任务交给子 Agent 并行处理，比如分头调研多个主题再汇总。对话顶部新增子 Agent 汇总入口，按「等你处理 / 工作中 / 已结束」分组，点开可查看每个子 Agent 的进度和详情；子 Agent 需要你拍板时，标题栏会出现待处理提示，点开即可就地作答；同类任务可以复用已有的子 Agent 继续办，也可随时取消。子 Agent 与主对话使用同一套权限和工具。

## 改进

- 插件账号设置中选择模型时可以直接输入自定义模型 ID（如图片生成插件的「图片模型」），不再只限于列表中的预置项；未保存修改的保存条改为悬浮在底部中央，不再被内容推着走。

## 修复

- 修复代码块切换自动换行后高度不更新、内容显示不全的问题。
- 修复项目、数据库等列表页底部「已归档」折叠区左侧内容被裁切的问题。
