这是 Tau 有史以来最大的一次更新：桌面端界面整体重构，每个页面都重新设计；AI 对话底层重写；一批低频功能移除，安装包缩小约 20%。升级到本版会自动完成数据迁移（迁移前先备份），使用同步的设备需要一起升级，详见文末「数据与升级须知」。

## 新功能

### 全新界面

- **全新设计系统**：六套全新主题（各含浅色 / 深色）统一全部页面的视觉语言；旧主题随重构全部退役，升级后可在设置中重新挑选。
- **侧栏重排**：入口按「日常 / 知识 / 学习 / AI / 分享」重新分组；支持页面后退 / 前进（Alt+←/→）。
- **通知卡片**：应用更新、协作加入申请、发布结果等以右上角通知卡展示，可直接在卡上操作。

### 今日与时间

- **今日页**：统计并入今日页，一页三段——今天（复习 / 待办 / 日程）、继续（最近编辑 / 探究中的问题）、回顾（全年热力图 / 写作趋势等），每条点击直达具体内容。
- **日程 · 时间账本**：时间块按当前时刻自动区分「计划 / 记录」，过去的空隙可一键补记；截止与周期任务改为不占时间轴的标记；日程详情改为右侧抽屉，周视图里可直接拖动日程调整时间；删除改为 5 秒内可撤销。
- **待办 · 议程流**：新增自然语言快速添加（支持 #项目、日期、时段、周期等写法）；详情改为抽屉，重复规则随时可改；打卡、连续记录与本周负荷一目了然。
- **待办与日历打通**：「计划任务」类型取消，把待办从「待安排」栏拖进日历即为安排，一条待办可多次安排；已有计划任务升级时自动转为日历安排。
- **番茄 · 时间账本**：按「日 × 时段」的账本查看专注记录，可翻看任意历史区间，「全部」视图给出累计数据与年度热力图；番茄可选绑定某个日程或待办，专注条会画在日历上；小窗与全屏翻牌沉浸窗重做。
- **日记 · 一整张纸**：时间流 + 底部聊天式输入（# 可联想标签）；新增「那年今日」；标签变成侧栏频道，热力月历快速筛选某段时间。

### 卡片与知识

- **卡片分类取消**：不再区分闪念 / 文献 / 永久 / 主题，用标签组织卡片；「闪念卡超过一个月自动清理」的规则同步取消。
- **卡片 AI 标题**：在设置开启「笔记元信息」后自动为卡片生成标题，列表与详情更易辨认。
- **列表排布**：卡片库新增「列表」视图（平铺 + 列头排序）；文章页全新排版并支持网格 / 列表切换。
- **知识地图**：新的全局页面（入口在标题栏），把卡片、文章、项目文档放进同一张地图，带生长动画，替代原卡片库的图谱视图。
- **脉络**：卡片 / 文章 / 项目文档详情显示「N 处关联」——来源、被引用、也出现在、衍生、被使用、相关问题，一处看全这份内容的一生。
- **摘录**：微信读书划线、PDF 标注、网页剪藏、浏览器插件划线统一入库，全文与语义搜索都能搜到、AI 回答可以引用；命令面板新增「摘录」范围，点击打开到原文位置，并可一键转为卡片。
- **长文按节检索**：检索命中到章节并定位到具体位置，从引用可跳回原文出处。
- **问题枢纽**：划线、PDF 标注、对话里的疑问都可「转为问题」；问题可关联材料、发起探究对话；材料攒够了可「以此立项」直接升级为 Notebook。
- **闪卡复习**：沉浸式复习台，支持跨卡组复习队列与 1–4 评分快捷键，侧栏显示到期数量。

### AI 对话

- **对话底层重写**：设置内置服务商与模型目录（勾选即用）；会话分支在同一棵树上，消息可切换版本；重启后能恢复进行中的回答。
- **工作目录**：每个对话可指定工作目录，输入框上方显示当前目录与 git 分支、可直接切换，让 AI 在你的项目里干活。
- **工具审批**：写文件、执行脚本等敏感工具按「手动确认 / 自动允许编辑 / 跳过确认」三档授权，确认条直接出现在对话里。
- **块预览**：代码、网页、图表等生成物点开进入统一预览框，预览 ⇄ 源码一键切换，同名产物带版本可回翻。
- **AI 洞见**：正文可就地分析——哪里值得连、哪里重复或矛盾，确认后才建立连接；知识地图给出「问了没写」「缺一环」等整体洞见；今日页有洞见卡，项目有生长 / 结项回顾。
- **MCP 服务器页**：MCP 管理从弹窗独立成页，支持逐工具开关与服务器日志。
- **Skill 管理页**：每个 Skill 可设「自动 / 仅手动 / 停用」，对话里用 `$` 点名调用；可关联 `~/.claude/skills` 等外部目录；Skill 脚本支持执行。
- **模型用量**：设置页显示各模型用量统计，可自定义单价，用量数据跨设备同步。

### 白板

- **画廊列表**：白板列表以缩略图画廊展示，悬停即可翻页预览，多页白板一屏看清。
- **多页白板**：详情页底部新增 XMind 式页签栏，双击改名、拖动排序、复制页，只有一页时自动隐藏。
- **画布重做**：顶部工具条 + 跟随选区的浮动属性条；元素树改为纸面内停靠栏；背景改为点阵；右下状态栏提供缩放、全览与视图菜单（Z 键全览）。
- **手绘模式**：整页可切「手绘」画风——变宽墨水笔迹、三档笔触、内置手写字体，文字、图形、导图全部跟随，导出图片同样生效。
- 思维导图主题、卡片与富文本外观重做；移动元素时支持等距吸附并显示测距线。

### PDF 与阅读

- **PDF 文档墙**：列表以封面缩略图展示，记录最近打开与读到的页码，一键续读。
- **PDF 阅读页重做**：划线后原地弹出工具条（五色高亮 / 下划线 / 写笔记 / 问 AI / 复制）；有笔记的标注在页边显示图钉；AI 对话在纸内右栏，选区和截图可作为引用提问；底部悬浮控制条提供夜间页面、双页、查找等。
- **微信读书**：书架 + 列表双排布，整页笔记还原微信读书的划线样式，按章节阅读；同步改为增量，不再每次全量拉取。

### 数据库与 Notebook

- **模块拆分**：数据库与 Notebook（原 Vibe Learning）从项目类型拆为独立模块，项目专注文档树，侧栏各有入口。
- **行详情重做**：左右双栏（正文 + 属性）实时保存，按视图行序上一条 / 下一条切换。
- **日期单元格**：时间条样式直观展示日期范围（剩 N 天、N 天后开始等），窄列自动简化。
- **视图工具栏**：视图切换与筛选、排序、分组面板重做，更好用。
- **驾驶舱**：项目 / 数据库 / Notebook 列表支持网格 / 列表切换、最近打开续读与列头排序。
- **Notebook 学习台**：目录、阅读、对话三栏；生成任务（文章 / PPT / 报告 / 导图 / 测验 / 播客）在后台执行，可实时看到模型的工作过程，完成即保存；文档类资料支持页内阅读。

### 编辑器与写作

- **表格重做**：单元格选区、行列拖拽手柄、导航快捷键；可直接从电子表格粘贴多行多列（支持子表）；支持列对齐。
- **图片重做**：单击选中、双击进暗房灯箱（缩略条、复制、下载）；上方属性条调整对齐与宽度；全屏裁剪编辑器支持旋转、翻转与比例约束，按原格式导出。
- **播放器重做**：视频以纸面控制条为常态、全屏切胶囊控件；音频改为波形卡；两者都有快捷键、续播、音量与倍速，视频进度条悬停可预览画面。
- **块细节**：代码块新增标题栏、行号、自动换行与文件名；链接改为单浮层就地查看 / 编辑 / 新建；行内样式与批注菜单统一色板；引用块、源码预览块外观重做，Mermaid 配色跟随主题。
- **演示模式重做**：全屏舞台按章节推进，超长章节自动分屏；兼容翻页笔；O 全览、D 切深浅。
- **沉浸写作重做**：全屏聚光 + 打字机滚动 + 段落聚焦，放大独立于编辑器正文字号。
- **编辑窗口合一**：卡片、文章、项目文档共用一个编辑窗口（可多开，同一文档自动聚焦）；快捷卡片窗口（⌘⇧N）打开即记，空内容关窗自动丢弃。
- **Markdown 窗口**：对标 Typora——文件树 + 大纲侧栏、低调的源码模式、外部修改提示；支持直接打开 .md 文件或整个文件夹。

### 协作、发布与设置

- **协作页**：共享内容挂在侧栏「协作」下，协作码分段展示一键复制，加入申请就地批复；本机视频等无法上传的资源不再阻止发起共享。
- **发布**：从设置弹窗独立成页面，发布在后台执行不打断使用，结果以通知卡回报。
- **设置**：改为全窗口页面并重排信息架构；嵌入模型页显示索引状态，内容更新后自动补索引。

### 浏览器扩展与移动端

- **扩展侧栏重做**：改为「阅读伴侣」单页流——当前网页的 AI 总结、最近高亮、本页笔记与快速提问；主题跟随桌面端。
- **划线入库**：浏览器插件划线同步进摘录，可搜索、可转卡片。
- **移动端架构重写**：返回手势先关浮层再退页面，页面切换保活更跟手，列表与详情数据全面缓存化；支持多人协作。

## 改进

- 安装包缩小约 60 MB（约 20%）。
- 安全加固：本地服务只对本机与浏览器扩展开放，任意网页与局域网设备不再能访问本地数据与密钥；自托管服务默认强制配置访问令牌。
- 新增升级公告：升级前在「查看更新内容」里看到，升级后首次启动也会提示本版更新，关于页可随时回看。
- 白板列表缩略图后台自动生成；画布保存从定时轮询改为实时保存。
- 播客播放器改为波形卡，支持脚本跟读、边下边播。
- 日记等长列表按天按需渲染，长内容滚动更流畅。

## 移除的功能

- **卡片分类（闪念 / 文献 / 永久 / 主题）**：用标签组织卡片。
- **知识库**：每个知识库自动转为一个文档树项目，内容与结构不变。
- **待办「计划任务」**：把待办拖进日历即为安排；已有计划任务自动转换。
- **独立小窗口**（待办、问题、番茄主窗口）：并入侧栏页面，功能不变。
- **EPUB 阅读器**：导出 EPUB、导入 .epub 转 Markdown 保留。
- **集成终端**、**白板演示录屏**、**音频笔记**、**RSS 订阅与稍后读**（含博客 RSS 输出）：整体移除；演示模式、编辑器音频块、文字转语音、播客等相邻能力保留。
- **检索增强**（查询扩展 / 重排本地模型，约 1.7 GB）：全文 + 向量混合检索保留。
- **资源管理页**：资源文件同步保留在「设置 → 同步」。
- **功能模块开关**：所有功能恒开启，不再需要手动启用模块。
- **统计页**：并入今日页「回顾」段。
- **编辑器块**：图表块、多列布局、行内 AI、代码块全屏模式移除——已有文档中的图表与多列内容会在升级时被移除，需要的话请先导出备份；白板 / TikZ / Typst 内置 AI 生成技能移除，已有 TikZ / Typst 代码块仍可查看。
- **卡片库「图谱」视图**：由知识地图替代。
- **旧版主题**：全部旧主题随新设计系统退役，由六套全新主题替代。
- 其他：日历事件数值字段、视频笔记旧「总结」页签。

## 数据与升级须知

- 升级到本版会一次性完成数据迁移：知识库转项目、卡片分类列删除、旧对话转存会话文件、计划任务转日历安排、已移除功能的数据库表清理。迁移在自动备份后执行，失败不会放行，过程中请勿强制退出。
- 同步协议升级，旧版本客户端无法读取新同步数据：使用同步的桌面端、移动端与 CLI 请全部升级到本版后再开启同步。
- 建议升级前另行备份重要内容，尤其是包含图表块、多列布局的文档。

## 修复

- 修复安装新版后首次启动可能报「数据库连接失败」的问题。
- 修复番茄未到点手动结束仍被记为「已完成」、修改专注时长后日历标题显示错误的问题。
- 修复待办跨项目移动时子任务遗留在原项目的问题。
- 修复白板编辑信息时可能误清所有页面、描述无法清空的问题。
- 修复协作码重新打开对话框后无法读取的问题；修复 Bilibili 连接弹窗关闭后仍在轮询的问题。
- 修复包含特殊字符的文件名导致资源预览失败的问题。
