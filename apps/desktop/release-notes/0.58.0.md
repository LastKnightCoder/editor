这次更新的主题是「重逢」：新增「漫步」页，从你的旧内容里随机抽一条出来重温，还能顺着岔路走向相邻内容；今日页也多了每天翻几张就收的「重温」牌堆。通知升级为卡片样式，切到别的应用也能看到、能直接操作。白板新增人物元素和一批几何形状，项目文档树的层级一眼可辨。另外集中优化了首页热力图、启动速度与知识地图的性能。

## 新功能

### 漫步：与旧内容不期而遇

- 新增「漫步」页：从你的卡片、文章、项目文档、日记碎碎念和 PDF 批注里随机抽一条旧内容出来重温。
- 每条内容旁有「岔路」：顺着双向链接、语义相关与同标签，走向相邻的内容，一路留下足迹。
- 可以选择哪些类型的内容进入抽样池。
- 今日页新增「重温」牌堆：每天固定翻几张旧内容，翻完即止；不喜欢可以重抽，也可以「从这里继续走」进漫步页。

### 通知升级：切出去也能看到、能操作

- 待办提醒、番茄钟结束等通知改为统一的卡片：在应用内时进卡栈；切到其他应用时会在屏幕角落（Windows 右下角、macOS 右上角）弹出置顶小窗，不抢焦点。
- 通知卡上的按钮可以直接操作，结果即时同步回应用。
- 卡栈始终展示最新 3 张，往上层叠纸边，关闭后自动补位，也保留一键清除。

### 输入 [[ 直接引用内容

- 在编辑器里输入 [[ 或 【【 即唤起内容引用面板，搜到选中就能插入引用，不必再从菜单进入。

### 白板

- 人物元素
  - 新增人物（火柴人）元素，53 种姿态、三种形体，单人墨色、多人点缀轮换配色，深浅主题自动适配。
  - 手绘模式下人物同样呈现手绘笔触。
- 几何形状
  - 新增菱形、胶囊、平行四边形、梯形、六边形、圆柱、文档、对话气泡、云朵、箭头、五角星共 11 种形状。
  - 心形轮廓重绘得更饱满，三角形改为尖头朝上；框元素支持虚线边框。
- 属性条改为样式卡
  - 颜色、粗细、圆角、不透明度等外观属性合并为一张「样式」卡，档位与步进器取代滑块，常用值一点即达。
  - 连线的起止端点也合并为「端点」卡。

### 项目文档树：层级一目了然

- 文档树新增折叠箭头与层级引导线，当前文档所在的分支会高亮。
- 顶层与第二层文件夹用主题色两档区分，更深层保持中性色；操作按钮改为悬停时才显示，树更清爽。

## 改进

- 首页写作热力图大幅提速：记录很多的情况下统计从最长十几秒降到瞬间完成，打开首页不再卡顿。
- 应用启动更快，减少了启动过程中的阻塞等待。
- 本地 AI 推理移入独立进程：重建向量索引时不再拖慢应用；知识地图的卡顿与后台索引阻塞也一并治理。
- 数据表行拖拽收口到左侧手柄，不容易误拖整行；无法拖拽时会说明原因。
- 番茄钟页面切走再回来时，「现在」指示线立刻对齐当前时间，不再停留在离开的时刻。
- 卡片详情里过长的元信息改为截断显示，悬停可看全文。

## 修复

- 修复白板箭头上的文字编辑时缩成一列、点击别处后被截断的问题。
- 修复白板手绘模式下透明图片会叠加墨迹外框的问题。
- 修复弹窗里的操作反馈提示被弹窗遮罩挡住的问题。
- 修复延迟删除的撤销提示消失时列表抖动、按钮悬停无响应的问题。
- 修复数据表链接列与微信读书笔记按钮悬停时透出底下文字的问题。
