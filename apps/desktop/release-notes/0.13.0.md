## 新功能

### 快速捕捉与回顾

- 按下 Cmd/Ctrl + N 即可呼出快捷卡片窗口，随手记录闪念。
- 新增小组件：可查看闪念笔记、每日回顾、最近编辑和未回答的问题。
- 卡片支持置顶，重要内容常驻顶部。
- 文档支持批注，阅读时随手划重点。
- 文档支持插入问题。
- 新增窗口缩放功能。

### 网页能力

- 新增网页功能：文档中可以嵌入网页、白板可以添加网页元素、项目支持网页文档，还支持剪藏网页内容保存为笔记。

### 白板与编辑器

- 白板支持编辑名称等信息。
- 白板多个元素支持布局，整理更省力。
- 图片支持裁剪，不必再借助外部工具。
- 独立窗口支持显示目录，长文档导航更方便。
- 导入 Markdown 时支持解析 front-matter 元信息。

## 改进

- 搜索大升级：全文搜索与向量搜索合并，一次搜索全覆盖。
- 新内容默认建立全文索引，不再需要手动操作。
- 选择文档的界面全面统一，各个入口体验一致。
- 图片预览全新升级，看图更清爽。
- 本地文件路径改用 ~ 表示，数据跨平台迁移更方便。
- 右侧栏标签样式优化。

## 修复

- 修复了时间记录中周和月选择的问题。
- 修复了编辑器工具栏悬浮条的样式问题。
- 修复了若干样式和体验问题。
