## 新功能

- **数据库查询语言**：新建数据库时可选「实时查询」，正文里输入 `/` 也有「查询数据库」块。用类 SQL 的查询语言或 JavaScript 把已有内容组织成一张自动更新的表——比如带「读书」标签的卡片、本月日记、各项目的文档数量；结果只读，新建或修改内容会自动进出结果。查询参考同时开放给 AI，可以让 AI 帮你写查询。
- **全局搜索覆盖更多内容**：待办、日程、项目、白板、Notebook、PDF、会话、数据库、闪卡和文档待办都能搜到，搜索筛选与快速添加分开；部分来源查询失败时，其余结果照常返回。
- **思维导图大扩展**：新增逻辑图、组织结构图、树状图布局；节点支持折叠、展开到指定层级。右键节点选「关联笔记」，可以新建或关联已有的卡片和文章，节点旁的笔记图标悬停可预览、点击打开。导图与笔记之间可以互相复制粘贴：导图复制出去是保留层级的缩进列表，多级列表右键「粘贴为思维导图」可整棵转成节点。
- **三套新主题**：新增「黑白」「抹茶」「青瓷」，主题列表按色环排序。
- **AI 导出电子书支持 Word**：视频笔记的电子书导出新增 Word 格式。
- **编辑器**：块菜单可以直接调整标题级别；待办详情等轻量输入界面不再显示块的拖拽把手。

## 改进

- 降低白板画框拖拽与结构更新的开销，大画布操作更流畅。
- 「待安排」栏打开时，工具条按宽度收起次要文字，按钮文字不再重叠。

## 修复

- 修复云同步覆盖资料库后，保留页面异常、白板操作与页面连接失效的问题。
- 编辑历史改为按编辑会话合并版本，并修复预览与断线重连时的边界问题。
- 修复正式版中思维导图快捷键失效的问题。
- 白板一批修复：重新进入后文字节点尺寸漂移、画框内容在大型操作中丢失、分栏里添加文字无响应、双击输入前连接点闪烁、分栏拖放占位残留。
