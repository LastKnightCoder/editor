这次更新请先看「升级须知」：旧格式正文与白板的自动转换功能已移除，数据库同步方式也有调整，两处都需要你在升级时配合操作。功能方面，白板加入了协作中心，可以像正文一样共享与多人编辑；浏览器扩展 Tau 伴读新增「伴读库」，把散落在各个网页的标注与笔记集中到一处；同步、语音、图像、在线视频、发布等服务的账号配置统一搬进了对应插件的详情页。

## 升级须知

- **旧格式的正文与白板不再自动转换。** 0.60.0 启用了新的正文与白板格式，0.60.1 起会在后台自动转换旧内容；从本版起转换功能移除，旧格式内容将无法打开。如果你当前版本低于 0.60.1，请先升级到 0.60.1 并启动应用，让旧内容在后台完成转换（如有转换失败会收到通知），再升级到本版。
- 随之移除的入口：协作中心的「本机恢复副本」列表、编辑器里的格式转换面板，以及白板协作栏上的「采用新版本」「使用协作端版本」「升级插件数据」。转换期间生成的本机备份文件不会被删除，仍保留在原来的位置。
- **数据库同步方式调整，云端数据与旧版不兼容。** 同步改为直接上传、下载整个数据库文件，不再因附件缺失或格式检查而中断。升级后请先在数据最全的设备上点「同步到云端」上传一次，其他设备再「下载更新」；下载前应用会先把本机数据库备份到 backup 文件夹。

## 新功能

### 白板加入协作

- 协作中心现在支持白板：侧栏里白板与正文并列，可以查看协作码、处理加入申请、管理成员，点「打开白板」直接进入。
- 「共享本地内容」新增白板类型，按标题搜索尚未共享的白板即可发布。
- 白板里的共享入口移到右下角状态栏末尾。

### Tau 伴读：伴读库

- 浏览器扩展新增「伴读库」页面：集中查看所有标注过的网页、跨页面的全部标注，以及每个页面的笔记汇总，可按站点筛选。从伴读面板的「⋯」菜单或快捷键 ⌥⇧J 打开。
- 网页可以改名：没有标题的页面默认显示「域名 + 路径」，改个好记的名字方便回找。
- 只写了笔记、没有标注的页面也会出现在伴读库里。
- 离线时伴读库仍可查看本机缓存的标注。
- 页面详情去掉了统计格子、正文限宽，更易阅读。

## 改进

### 服务账号配置搬进插件详情

- 同步、资源存储、语音合成、语音识别、图像生成、在线视频、博客发布等服务的账号与连接信息，统一改到对应插件的「详情 › 设置」里填写，支持「保存并测试」。
- 设置页里的同步、资源存储、语音等分区只负责选用哪个服务、查看状态；点「配置」会跳到插件详情，配置完可一键回到来源分区。
- 切换同步服务前会先探测目标云端是否可用；保存配置不再改变当前选用的服务。
- 以下插件已发布适配新配置方式的版本，请在「插件」页更新：GitHub / OSS / S3 / WebDAV 同步，GitHub / OSS / S3 上传，Qwen 语音、MiniMax 语音、豆包语音识别，OpenAI 图片，YouTube、Bilibili，S3 发布、GitHub Pages 发布。未更新的旧版插件会提示你更新。

### 同步

- 本机与云端版本冲突时交由你确认：可以「强制上传」以本机内容覆盖云端；自动上传遇到云端有更新时会跳过，等你手动处理。
- 同步设置页在插件尚未就绪时显示「准备中」，就绪后自动检查云端状态；插件启用失败时明确显示「插件不可用」。

### 其他

- AI 对话和 MCP 页面里，插件提供的工具改为显示易读的名称，不再夹带一长串内部编码。
- 白板保存失败时的提示更明确：区分「稍后重试即可」与「需要关闭白板后重开」，并附上具体原因。
- 意见反馈表单去掉了联系方式输入，填写更省事（反馈仍为匿名提交）。
- 应用程序体积精简。

## 修复

- 修复编辑器中图片、视频、音频可能无法显示，以及应用启动后停在白屏的问题。
- 修复卡片库里卡片悬停时多出阴影、边框消失的问题。
- 修复白板切换为只读后，板内引用的正文仍可编辑的问题；引用的正文尚未就绪时会显示提示，不再允许编辑占位内容。
- 修复 Tau 伴读悬浮球悬停时抖动的问题。
