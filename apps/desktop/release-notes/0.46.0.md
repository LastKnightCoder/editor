这个版本带来了 AI 报告生成和新的命令行工具，白板演示、博客发布和一批界面细节也都有更新。

## 新功能

- **AI 报告**：让 AI 把笔记整理成一篇报告，内置 18 种风格模板（咨询报告、杂志、数据看板、水墨、手写、极简等），生成后还可以继续编辑修改。
- **tau 命令行工具**：在终端里输入 tau，不用打开应用就能查询卡片、待办和问题，浏览项目与知识库、全文搜索，还能管理数据同步。
- Markdown 文件编辑器新增内嵌终端，写文档时可以直接运行命令；侧边栏能显示更多类型的文件。
- 文章列表新增右键菜单，常用操作更快。
- 博客发布支持设置网站图标（favicon）。
- PPT 模板更新，新增粗野主义风格模板。

## 改进

- 标签页、对话分组、番茄钟页面等一批界面焕新，交互更顺手。
- AI 调用工具时的结果展示更清晰易读。
- 接入 Claude 模型时启用缓存，对话响应更快、开销更低。
- 沉浸式写作窗口体验优化。
- 上传图片、音频、视频的界面更清爽；新建项目和知识库的弹窗同步优化。
- 学习检索结果更准确。

## 修复

- 修复 Windows 上命令行工具无法执行的问题。
- 修复播客生成卡在无限循环的问题。
- 修复未指定语言的代码块渲染出错的问题。
- 修复图册设置弹窗超出窗口范围的问题；图册现在支持直接粘贴图片。
- 修复微信读书登录窗口关闭时报错、视频生成电子书时输出报错的问题。
- 修复博客深色模式显示异常、问题管理的描述未被清除、外部工具连接失败的问题。
- 修复隐藏终端时终端被意外关闭，以及正式环境下中文显示异常的问题。
