这次更新的主题是「一起写」：Tau 支持远程协作了，可以把项目和知识库分享给同伴共同编辑；AI 对话也全面增强。同时，Notion 同步和徽章中心在这个版本告别。

## 新功能

### 远程协作

- 项目和知识库可以发起远程协作：邀请同伴加入，多人实时编辑同一份内容。
- 支持自建协作服务器，团队可以把数据放在自己的服务器上。

### AI 对话增强

- 对话支持全局搜索，历史会话一搜即达。
- 切换页面或最小化窗口时，AI 的回答不会中断，回来接着看。
- 每次对话会显示占用的上下文长度，用多少心里有数。
- 消息可以排队发送：上一个回答还没完成时，先把下一条写好，完成后自动发出。
- 把文件直接拖进聊天区，就能作为引用交给 AI 读取。

### 其他

- 支持批量导出项目，一次导出多个项目的内容。
- AI 服务商设置支持自定义浏览器标识，特殊网络环境下的接口也能正常访问。

## 改进

- PDF 打开后会自动建立索引并显示进度，向它提问和检索更及时。
- 思维导图拖拽更顺，拖动根节点时出现对齐参考线，摆放更整齐。
- Markdown 文件编辑器支持直接重命名和删除文件，源码视图会自动滚动到编辑位置。
- 资源管理页面更清爽。
- 待办等任务数据更加可靠，重启后不丢失，导出更完整。

## 移除的功能

- **Notion 同步**：不再提供与 Notion 互相同步的能力，相关设置已移除，本地已有内容不受影响。
- **徽章中心**：此前上线的徽章功能已下线，侧边栏入口一并移除。

## 修复

- 修复 B 站扫码登录失败的问题。
- 修复首页跳转订阅列表时一直加载的问题。
- 修复浅色主题下下载的视频背景是黑色的问题。
- 修复删除文章后对应的标签页和窗口没有一起关闭的问题。
- 修复 Mac 上窗口信号灯出现两次的问题。
- 修复思维导图快捷键误吞全局按键、画板缩放快捷键失灵、全选拖动时元素被误吸进容器的问题。
- 修复 Windows 上 Codex 智能体无法运行的问题。
- 修复 Markdown 加粗与斜体写法不能正确识别的问题。
- 修复通过外部工具修改文档后字数统计不更新的问题。
- 修复生成图片时偶发的跨域报错。
