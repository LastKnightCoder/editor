## 新功能

- **演示文稿按页续改**：打开 Notebook 演示文稿，点「AI 编辑」可以只改某一页（如「只改第 2 页的标题」），也可以调整页序。生成过程中能看到已写页数，「手绘风格」的笔触和图表随 HTML 一起下载，离线也能播放。
  - 旧演示文稿第一次点「AI 编辑」时，会先检查能否完整保留原有页面、样式和播放顺序，通过后才保存修改；遇到无法识别的情况会提示原因并保留原稿。
- **压缩长对话**：在输入框单独输入 `/compact` 并发送，AI 会把较早的消息整理成摘要，带着摘要和近期消息继续聊，原有记录仍可向上翻看。
  - 输入框旁的用量环会显示压缩后的用量，点开可查看压缩前后的 token 数。
  - 长对话也会自动压缩：在「设置 › AI 服务 › 大语言模型 › 功能分配」的「对话与写作」里填写「自动压缩阈值」，例如 `80` 表示用量超过模型窗口 80% 时尝试压缩。
- **转录引擎新增 Qwen3-ASR**：在「设置 › AI 服务 › 语音」的「语音转录」里可选默认引擎，Windows x64 和 Apple 芯片的 Mac（macOS 14 及以上）可以在 Whisper 与 Qwen3-ASR 之间切换。
  - Windows 上选中 Qwen 后，「运行设备」会列出检测到的显卡并推荐运行包，驱动支持 Vulkan 1.1 及以上的 AMD、Intel、NVIDIA 显卡都可以尝试 GPU 加速，无需安装 Python 或 CUDA；更新驱动后可点「重新检测显卡」。
  - 模型下载源可选 ModelScope 或 Hugging Face；单个视频可在右上角「⋯ › 本次转录设置」里临时更换引擎、模型、输出和语言。
- **对话附件直接引用本地文件**：点输入框「+」选择电脑上的文件，也可以把文件拖进输入框，或在文件夹里复制后粘贴；AI 按原路径读取，文件移动或重命名后需要重新添加。普通文件最大 50 MB。
- **AI 管理项目文档**：对话里可以让 AI 新建、删除项目文档，或跨项目移动——说清现在和将来的位置即可，例如「把『春季调研』『访谈』下的『结论』移到『产品计划』的根目录」；子文档一起移动，正文保留。
  - 已有卡片、文章和文档也可以关联到项目目录，例如「把这张卡片添加到『春季调研』的『访谈资料』下面」；原处仍能打开，两边编辑的是同一份正文，解除关联时原内容保留。

## 改进

- 「设置 › 云端存储」同步时显示已处理文件数和正在处理的文件；比对完成后列出本轮文件明细（已上传、已下载、跳过、失败），失败的文件可以单独重试。

## 修复

- 修复给选中文字加链接、关联内容、下划线、按键样式或批注时，原有加粗、斜体、颜色等格式丢失，或样式越界应用到选区外文字的问题。
- 修复网页剪藏产生的模型用量没有归入对应功能统计的问题。
