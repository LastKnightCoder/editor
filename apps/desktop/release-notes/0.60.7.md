## 新功能

- **网页书签块**：在空段落粘贴网址可选择「粘贴为网页书签」，也可从块面板输入网址插入；书签块提供横向卡、封面卡、紧凑行三种外观，标题、描述与封面都可编辑。
- **博客本地图片随站点发布**：发布博客时，正文里的本地图片会随站点一起上传发布，读者不再受外链失效影响。
- **插件设置保存条**：修改插件设置后底部出现吸附式保存条，支持 Ctrl+S / ⌘S 保存；带着未保存的修改切换页面或关闭窗口前会先确认。
- **视频字幕优先取自平台**：视频笔记优先使用视频平台自带的字幕（人工字幕优先、自动字幕次之），拿不到平台字幕时才转写，字幕来得更快也更准确。

## 改进

- **注解重设计**：正文中的注解标记改为按文档顺序编号的上标序号，与导出 Markdown 的脚注编号一致；悬停即可只读预览，点击打开编辑卡片，输入即保存，可复制、删除；插入注解后直接进入编辑，留空关闭即自动移除。
- 优化与移动端之间 AI 对话记录的同步：改为增量传输，请求并发与失败重试更稳健，同步更快、更不易失败。

## 修复

- 完善协作共享：修复协作中图片跨端保存与缓存恢复的问题，共享结束后即使错过通知也能可靠收尾。
- 修复点击附件、书签等内容块末尾时，光标落点异常、输入位置不对的问题。
- 修复插件安装提示文案被裁切的问题。
- 修正右对齐输入框的留白异常。
