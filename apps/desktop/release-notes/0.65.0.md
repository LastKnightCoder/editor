## 新功能

- **编辑历史**：卡片、文章、项目文档与共享文档都会记录每次保存的历史，自己的修改与 AI 的修改分开标注。点工具栏的「编辑历史」，在正文旁打开时间轴面板。
  - 时间轴按天分组，可按作者筛选；选中一条，正文中原位标出该次改动的块：绿色新增、橙色修改、蓝色移动。
  - 条目展开可查看改动明细或当时全文；单次改动可撤销，也可以把正文恢复到任意历史版本，操作都有两步确认。

## 修复

- 修复删除内容后新建的内容可能复用旧编号、让已有引用错误指向新内容的问题。
- 修复正式版中白板手绘模式的内置手绘字体被覆盖、退回系统字体的问题。
- 修复闪卡侧栏待复习数量与复习页不一致的问题。
