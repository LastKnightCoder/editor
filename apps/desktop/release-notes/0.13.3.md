## 改进

- AI 模型选择更开放，不再默认偏向 OpenAI。
- 视频支持流式播放，无需等待完整加载。
- 白板多元素支持整体复制，包含子元素的节点也能复制。
- 多元素布局同样适用于 Frame 和思维导图。
- 思维导图支持把节点拖拽到根节点左侧。
- 粘贴元素体验更顺畅。
- 标题的大小、粗细和间距更协调。

## 修复

- 修复了拖拽元素到 Frame 上时会丢失箭头关系的问题。
- 修复了解散 Frame 后撤销行为不正常的问题。
- 修复了把前面的元素移到后面时箭头路径错误的问题。
- 修复了编辑思维导图左侧节点时节点向左扩展的问题。
- 修复了获取软件版本时反复请求的问题。
