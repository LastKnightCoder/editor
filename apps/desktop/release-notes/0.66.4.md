- 修复白板批量操作后改动可能漏保存的问题，草稿保存失败会自动重试。
- 修复部分模型信息缺少能力字段时打开设置页崩溃的问题。
- 修复旧版本遗留的服务配置拦截应用启动的问题。
- 统一后台 AI 请求与对话的模型路由，功能分配设置在两类场景一致生效。
- 修复对话会话菜单里点删除时误触发跳转的问题。
- 修复本地 Markdown 文件里选中文字后选区偶尔丢失、状态栏选中字数不同步的问题。
- 修复正文文字变化后滚动区域渐隐提示未及时刷新的问题。

## 面向插件作者

- **新增待办与日程宿主能力**（随 SDK 0.62 开放）：插件可以经 `context.data.todos` / `calendar` 读写用户的待办与日程。
  - 待办与日程条目可以创建、修改和删除；待办支持提醒、重复规则和正文待办的实例级修改。
  - 待办清单和日历目录支持创建与改名等修改，改名后正文的归属保持不变。
  - `context.data.changes.query` 提供覆盖删除、支持分页与检查点的增量读取，适合做同步类插件。
  - 数据变化会以带稳定 ID 的对象动作事件通知插件，按提交分页分发、按序回调。
  - 使用需声明对应的 `todos` / `calendar` 权限，完整契约见插件模板的「读写用户数据」篇。
