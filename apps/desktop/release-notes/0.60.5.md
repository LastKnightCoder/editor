## 新功能

- **嵌入模型支持插件提供的云端服务**：AI 语义检索的嵌入模型不再限于本机下载的本地模型，插件也可以提供（如「OpenAI 嵌入」插件，支持 OpenAI 兼容服务）。之前在设置里填写过的 API 嵌入配置升级后不再保留，安装对应的嵌入插件即可继续使用云端模型。浏览、下载与填写配置都不会改变当前选用的模型，切换需要确认，确认后在后台重建语义索引。
- **侧栏「插件」入口显示待办数量**：插件有新版本可更新或等待授权时，侧栏「插件」入口直接显示数量角标，不必进插件页才发现。

## 改进

- **插件设置改为卡片式布局**：插件详情 › 设置统一为一张卡片：卡头显示账号与使用状态，表单按分组排在卡内，保存按钮固定在卡脚；语音合成、图片生成等多账号服务的账号在顶部用胶囊切换，可直接改名或删除。
- **启动更快**：插件完整性检查的结果会缓存复用，安装插件较多时启动提速；启动画面也更早出现，减少打开应用时的空白等待。

## 修复

- 修复发布时项目卡片列表的来源条目已删除或无效导致发布失败的问题：现在按空列表处理并在发布结果中提示。
- 修复卡片预览弹窗右上角的操作图标与关闭按钮挤成两排的问题。
- 修复大纲里二级标题与一级标题平齐、看不出层级的问题：二级标题现在同样按层级缩进。
- 修复首次「下载更新」时因同步会话目录尚未创建而失败的问题。
- 修复下载更新的弹窗里文案换行不整齐的问题。
