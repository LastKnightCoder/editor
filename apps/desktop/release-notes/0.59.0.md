这次更新的主题是「开放」：Tau 上线了插件系统，侧边栏新增「插件」页，可以浏览插件中心、一键安装和管理插件；一批原有能力（同步、在线视频、语音、微信读书等）搬成了插件，按需安装、独立更新，应用本体更轻。同时内容进出更自由：可以一键导出 Markdown 压缩包，也能从 Obsidian、Notion、Logseq 整库搬进来。官网 taunote.app 上线，macOS 开始提供 Intel 与 Apple 芯片两种安装包。

## 新功能

### 插件与插件中心

- 侧边栏底部新增「插件」入口：从这里浏览、安装和管理插件，按分类和关键词挑想要的。
- 插件需要读取你的内容或联网时会先征得你的同意，之后随时可调整。
- 插件中心网站 plugins.taunote.app 同步上线：分类目录、下载排行，应用里和网站上都能给插件评论、点「喜欢」。

### 一批功能搬家：改为插件提供

- 以下功能不再内置进应用，升级后请到「插件」页安装对应插件并启用；不用的话不装即可，应用更轻。
  - 同步：阿里云 OSS、S3、WebDAV、GitHub——旧的同步配置已自动迁移，装好插件即可接着用；
  - 在线视频：Bilibili、YouTube——账号与代理设置已自动迁移；
  - 语音（含播客朗读）：MiniMax、Qwen——旧配置已自动迁移；
  - 微信读书——已有的摘录与引用全部保留；
  - 编辑器扩展：TikZ 绘图、Typst、ABC 乐谱、HTML 扩展、自定义组件块；
  - 白板人物（火柴人）、图片生成与编辑；
  - 博客发布到 GitHub 与 S3、资源上传到远端。

### 导入导出：内容进出更自由

- 新增「导入与导出」总入口：设置 › 数据，或命令面板直达；卡片、文章、项目文档的菜单里也有各自的导入导出。
- 导出为 Markdown 压缩包：范围可选项目 / 文章 / 卡片 / 全部，压缩包里的文件夹结构就是你的内容树；笔记互链可以选相对链接、[[双链]] 或纯文字；本地图片等资源一并打包，远程图片也可选下载；还能附上 frontmatter 信息。
- 批量导入向导：把文件夹或压缩包拖进来，先扫描出预览——缺失的资源、没认出来的链接会单独列出，确认无误后一次写入，不满意的整批撤销。
- 自动认出 Obsidian、Notion、Logseq 的写法：双链、callout、高亮、标签等直接转换成对应格式；Notion 导出的数据库（CSV）能导入成数据表。
- 导出 PDF 时，文中的本机图片不再丢失。

### 官网上线

- taunote.app 上线：产品介绍、使用文档、插件中心一站直达。
- macOS 提供 Intel 与 Apple 芯片两种安装包，各自原生运行。

### 意见反馈

- 新增「反馈」入口：侧边栏底部、命令面板与托盘菜单都能直达，支持截图标注、附运行信息，匿名提交。
- 页面出错时可以一键「发送错误报告」，帮助更快定位问题。

## 改进

- 全文搜索跟上编辑的脚步：正文写完很快就能搜到，不用再等下次打开应用。
- 安装包明显更轻：Typst 排版改在插件内本地完成，媒体探测等重型工具也不再随包分发。
- 点击应用里的外部链接改为交给系统浏览器打开，不再另开内置小窗。

## 修复

- 修复项目文档很多时，文档树展开/收起卡顿的问题；展开动画也更利落了。
- 修复进入卡片墙时卡片先大后小、跳一下的问题。
