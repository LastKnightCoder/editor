## 新功能

### 多窗口与侧边栏

- 卡片、文章、项目、知识库都可以在独立窗口打开，窗口之间数据自动同步。
- 新增右侧栏，可以随时查看卡片、文章、项目、知识库，内容保持同步。

### 编辑器

- 支持直接打开本地 Markdown 文件，像 Typora 一样即开即编。
- 代码块支持全屏编辑，编写长代码不再局促。
- 标题支持折叠内容，长文档收放自如。
- 不同类型的 Callout 之间可以互相转换。

### 数据库与 AI

- 新增数据库表格功能（初版）。
- 支持配置自定义嵌入模型，向量知识库更灵活。
- 可以设置大语言模型启用的特性。

### 其他

- 新增视频笔记。
- 知识库支持置顶。

## 改进

- 界面再次改版升级，观感更好。
- 卡片列表、搜索列表和侧边栏加载更快，对话列表更流畅。
- 支持选择草图风格。
- Markdown 导出体验优化。
- 演示模式新增关闭按钮和回到顶部按钮。
- 索引数据库功能优化。

## 修复

- 修复了知识库输入卡顿的问题。
- 修复了选择或创建数据库后配置未更新的问题。
- 修复了编辑器内 Tab 键导航的问题。
- 修复了边距没有随字体大小适配的问题。
- 修复了编辑器内白板内容跟随页面滚动的问题。
- 修复了其他若干问题。
