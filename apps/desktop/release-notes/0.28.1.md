## 新功能

- **拖拽插入**：图片、音频、视频可以直接拖进编辑器。

## 改进

- Markdown 源码与富文本编辑器支持路径互通，同一份文件在两边对应打开。
- 应用图标焕然一新。
- 问题管理搜索框更好用。

## 修复

### 界面显示

- 修复 MCP 删除确认弹窗、白板音频音色选择被其他内容盖住的问题。
- 修复问题管理创建分组时出现两组确定按钮、颜色下拉框被遮挡的问题。
- 修复答案弹窗出现两个滚动条、编辑内容时字数不更新的问题。
- 修复 Windows 上拖拽把手不显示的问题。
- 修复知识库侧边栏无法收起的问题。
- 修复聊天显示在右侧时看不到预览卡片生成状态的问题。
