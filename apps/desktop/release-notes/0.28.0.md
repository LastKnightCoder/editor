## 新功能

- **Skill 技能**：支持 Skill，为 AI 扩展更多专属技能。
- **聊天置顶**：常用对话可以置顶，随时找到。
- **聊天分支**：对话支持分支，可以从任意位置另起一路探讨，互不干扰。
- **侧边聊天**：聊天可以显示在右侧，边看内容边对话。
- **联网工具**：AI 新增内置联网工具，可以直接获取网络信息。
- **浏览器标签页工具**：AI 可以读取浏览器标签页中的内容。

## 改进

- 支持并行转录，多个音频可以同时转。
- MCP 更好用，并修复了一批相关问题。
- 数据库搜索框更好用。

## 修复

- 修复无法创建聊天的问题。
- 修复筛选面板中选择选项时面板意外关闭的问题。
- 修复 Mac 上转录程序无法运行的问题。
- 修复微信读书笔记想法无法更新、无法修改样式的问题。
