扩展一 · 预设行 PRESETS（内容使用方决定，即点即定）

预设显示在日历下方（group 底 chips，一行 ≤5 个），数据驱动： presets=[{ label, value: () => string }]——组件不内置业务词表， 用「今天 / 明天 / 下周一 / 周末」还是「今天 · 下午三点」由使用方决定。 点预设 = 取值 + 提交 + 关闭（一步到位）；当前值命中预设时该 chip 高亮回显。

扩展二 · 带时间 PRECISION="MINUTE"（时刻网格 + 确定提交）

点日期 仅选中（不关闭） 时刻框 直接键入任意分钟（9:5 → 09:05） ▾ 展开 15 分钟网格（快捷通道） Enter 确定 Esc 先关网格再关面板
提交模型跟着 precision 走：day 精度即点即定；minute 精度下点日期只是选中， 底栏换成时刻区（时刻框 + 清空 / 确定，单行排布）。时刻可自由键入（"9" → 09:00、"9:5" → 09:05、 越界或非数字失焦还原），网格是 15 分钟步长的快捷通道（timeStep 可调， 当前时段 accent 标记，键入值不在步长上则网格不高亮）；值格式 "YYYY-MM-DD HH:mm"。

Tau v2 · 重构中方案 A+ · 基座 + presets / precision 扩展

A+（基座已定向）

A 的即点即定 + 钻取保留为基座；两个扩展走 prop：presets 预设行 （日历下方、内容使用方决定、即点即定）与 precision="minute" （底栏时刻区 + 15 分钟时刻网格 + 确定提交）。值形状拆两个导出： DatePicker / DateRangePicker 共享引擎，时间与预设不另立组件。
试试：预设行点一下直接提交回填；minute 面板点日期不关闭、 时刻框直接键入 10:37（任意分钟）、▾ 展开网格快捷选择、Esc 先关网格再关面板；右上角切 cream / cocoa。
