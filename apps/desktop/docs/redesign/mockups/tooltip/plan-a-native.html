让浏览器当定位引擎

承载用 popover="manual"（top layer 免 z-index / 免 Portal / 不受裁剪，不抢焦点）； 定位用 CSS Anchor Positioning（12 placement + 声明式 fallback + 滚动跟随内建）。 JS 只剩驱动层：hover 延迟、focus-visible、aria-describedby、show 后读一次实际边向供箭头换边。 Electron 43（Chromium ~150）下 popover / anchor positioning 均已稳定。
