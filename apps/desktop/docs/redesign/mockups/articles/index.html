文章页设计探索 · 三方案

背景：文章页现状是「单列杂志卡（banner 左右交替）+ antd 分页」——一卡占一整行，1440 宽下一屏仅 ~3 条，宽度大量闲置；getAllArticles 全量拉取（每条含完整正文 JSON）后前端每页 10 条切片；无搜索、无排序、无标签过滤；六项操作（演示 / 导出 ×4 / 删除 / 换封面 / 置顶 / 独立窗口）全部收在 antd Dropdown；默认封面是 CDN 外链占位图。以下三个方向共用同一套 mock 数据（42 篇 / 同一批标题、标签、字数、时间），浏览器打开即可交互（搜索、排序、标签过滤、键盘浏览、渐进加载均为真实现）。

2026-09-19 · cream 主题实测色值 · 壳层与 home-final 同构 · banner 用粉彩渐变示意（真实场景为 bannerBg 本地图，无图以首段文字块兜底）

三个方案

方案 A

杂志书架 · 卡片网格

延续旧版「banner + 正文预览」的杂志基因，改为多列自适应网格：置顶升格为横幅大卡，普通文章竖卡（banner 或首段文字块作卡片头）。视觉最丰富，内容即作品的展示面。

✓ 封面呈现最强、杂志感、与旧版习惯连续✗ 密度最低，扫视定位慢于行式
方案 B

档案行 · 高密度列表

与今日页「继续编辑」同构但升格为整页能力：时间分组（置顶/今天/昨天/本周/本月/更早，sticky 分组头，零横线）+ 标签过滤 pills + 行内 hover 操作 + ↑↓ 键盘移动。单屏 ~18 条。

✓ 密度最高、键盘效率高、基因最强✗ 无封面呈现，长标题靠截断
方案 C

浏览台 · 列表 + 预览双栏

邮件客户端式双栏：左列紧凑列表（时间分组、↑↓ 浏览），右列大预览（封面 / 首段、元信息、标签、摘要、操作区平铺旧 Dropdown 全部能力）。判断「这篇是不是我要的」不必先进编辑页。

✓ 浏览与预览同屏、键盘动线最完整✗ 双栏为新增布局语言，窄窗口需折叠

第二轮 · A 系变体2026-09-19 评审后 · 以 A 为基础演进

第一轮裁决：以方案 A（杂志卡片网格）为基础继续设计；四项新基线落实到每个变体——新建/导入入口移工具栏右上角（废除右下悬浮球）、无限滚动（废除手动"继续加载"）、无 banner 文章用派生色封面兜底（保留）、「窗口打开」仅 Electron 渲染。以下三个变体是同一基线下的不同密度/节奏取舍：

A1

书架 v2 · 结构修正

最接近第一轮 A 的形态：置顶从"独立横卡区"改为融入网格的双列宽 featured 大卡（消除横竖两种规格的割裂），补入标签过滤 pills。摘录、标签、meta 三层信息完整。

✓ 信息最完整、改动最小、连续性好✗ 密度一般（3 列），置顶多时占两格
A2

密集书架 · 高密度小卡

minmax(232px) 五列小卡：封面 4:3 成为绝对主角，摘录移出卡片（无图卡保留首段缩略），标题 2 行 + 单行 meta。靠"封面颜色 + 标题"定位，一屏 15+ 条。

✓ 密度最高、封面色板视觉记忆强✗ 无摘录，不点开无法预判内容
A3

月刊 · 按月分段

按月分段（sticky 月头：月份 + 篇数 + 当月字数），每月首条 featured 双列大卡，段内有主次节奏；无限滚动以"月"为加载粒度，滚动自带时间锚点，与热力图/统计页的时间叙事同构。

✓ 时间线索最强、段内有主次、加载粒度自然✗ "最近编辑"排序会打散月份段（需固定为时间排序）
