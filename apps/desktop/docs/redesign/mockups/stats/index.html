统计页设计探索 · 三方案

背景：统计页现状为「6 张平铺数字卡 + 方格热力图 + 2 个柱状图 + 牌组条」，信息平淡、与首页视觉基因割裂。以下三个方向共用同一套真实感 mock 数据（口径与 home-final.html 完全一致），在浏览器打开各 HTML 即可交互体验（时间范围切换、图表 hover、热力图呼吸）。

2026-09-16 · cream 主题实测色值 · 图表全手写 SVG/CSS 零依赖 · 壳层与 home-final 同构（真实 18 模块侧栏）

三个方案

方案 A

叙事回顾 · 年报体

像 Spotify Wrapped 一样讲故事：编辑排版大标题、章节式叙事流（写作轨迹 → 知识构成 → 专注节律 → 记忆保持 → 活动年鉴）、里程碑时间线。窄容器杂志风。

✓ 情感化、有"知识复利"叙事✗ 分析密度低、工具感弱
 推荐
方案 B

分析仪表盘 · 工作台

与今日页同构的行式高密度布局：指标四卡（环比+sparkline）→ 写作趋势（7 日均线面积图）+ 构成环 → 记忆保持（评分四段+到期预告）+ 专注节律 → 热力图 → 牌组。时间 tabs 全页联动。

✓ 基因一致、密度高、可渐进接线✗ 无惊喜感（稳）
方案 C

Bento 面板 · 一屏拼盘

12 列 bento 网格，tile 大小混排传达优先级：4 个速览小 tile（大数字）+ 趋势大 tile + 构成/记忆/节律/牌组中 tile + 全宽热力图。理想状态一屏全貌无滚动。

✓ 视觉最现代、一眼全貌✗ 小窗口 tile 会折行、与首页行式语言有差异

定稿（2026-09-16）：已选定 方案 C · Bento 面板作为统计页形态。响应式为容器驱动：折行用 CSS @container 容器查询（锚点 .bento-wrap，断点 1180/860 对齐 HomeView 惯例），读数用 ResizeObserver——侧栏拖宽/折叠/搜索面板改变的是容器宽而非窗口宽，媒体查询会失真。plan-c-bento.html 的侧栏拖宽条可实际拖动（130–340px），拖动时窗口宽度不变，可直接验证折行响应的是容器。方案 B 的行式结构保留作对照；方案 A 的叙事结构若将来做「年度回顾」彩蛋页可复用。
