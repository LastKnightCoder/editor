选项即数据（推荐）

一个 options prop 吃下全部：搜索是一行 filter、分组是 group 字段、 异步是换数组、M1 多选是 value: V[]、虚拟化是列表区换 VirtualList——API 面不膨胀 （antd Select 40+ props 的反面）。代价：富内容经 label: ReactNode + searchText 绕半步。
试试：搜索框边输边过滤（含命中数与空态）；FilterBar 三联动改统计数字； 200 项大列表 ↑↓ 翻页滚动；右上角切 cream / cocoa。
