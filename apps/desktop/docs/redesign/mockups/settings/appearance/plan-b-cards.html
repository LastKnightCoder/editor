B · 分节卡片（现代产品语感）

每节一张描边卡；主题模式 = 三段分段控件（跟随系统 / 浅色 / 深色）+ token 色带即时反映当前解析色谱；字号 = 滑杆；字体两列并排。 比省 A 约 80px 纵向；色带只给色谱不给版式预览，主题「长什么样」的表达弱于 A 的预览卡。
试试：分段控件切「深色」全稿变 cocoa、色带与解析名联动；「跟随系统」段演示 解析为浅色；拖字号滑杆（12–24）；卡内小节 hairline 只做分隔。
