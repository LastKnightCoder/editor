C · 分层下钻（iOS 设置 / Things 语感）

最小的 640×600 弹窗：首页是设置项列表——每行带当前值摘要 （同步通了吗 / 几个提供商 / 用什么主题，打开即读，不点开也能体检）；点行进子页， 右滑进入、← 返回，Esc 先退子页再关弹窗。没有常驻左栏，小窗口也从容。
试试：点左下角「设置」打开，看摘要列（嵌入模型标了警示色）；点「外观」「同步」 看滑入动效与返回栏；切主题卡看首页摘要联动更新；Esc 两段退出；右上角切 cocoa。
