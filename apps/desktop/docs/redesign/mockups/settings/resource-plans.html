  2. active 语义：图床 Select 切换即切换生效目标（上传写时直达），与「同步」子页的提供商 相互独立；资源目录同步的远端与凭据跟随同步子页（isSyncConfigured），两节并存必须保留提示行 「远端与凭据跟随 同步 · xx 的存储配置」点破。
  3. 提供商描述行：原拟动态拼已配置家摘要（吸收探讨稿建议 2），落地校准 （2026-09-22）：摘要文字过长导致描述行折为多行——退回静态家名清单 （「本地 / GitHub / 阿里云 OSS / S3 / WebDAV」），与同步子页同口径。
  4. 动作语义：资源同步全手动——「同步」开始双向镜像（本地多→上传、云端多→下载、同名跳过）； 存在失败文件时主按钮切换为「重试失败」（只重试失败项）；「停止」中断可续传；错误文件经 「查看问题 n」处理；同步中实时显示进度条、当前文件与统计 chips。

  6. 压缩开关归属：legacy 独立「压缩设置」Section 并入上传目标节——上传管线的一环， 本地目标同样生效；描述文案随目标微调（上传时 / 落盘前）。
  7. 状态存档：同步状态按提供商 + 配置哈希独立存档（换配置不串台）——换远端后统计与 「最近同步」按当前配置重新开始；黑名单（SQLite 表）跨配置共用。
