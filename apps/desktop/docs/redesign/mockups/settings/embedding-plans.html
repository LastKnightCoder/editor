Segmented 规格（进 packages/ui/primitives 的口径）

连体描边（Input 家族语言）：原生 radio 承载单选语义与键盘行为，容器只做 hairline 描边与分割线，激活段轻染。已落地 packages/ui/primitives/Segmented.tsx—— 本页即 02 §5.2 裁决（antd Tabs → 自研 Segmented，M1）的第一个消费者。

部位取值
容器hairline 控件：surface + line-1 描边 · radius 8 · 段间 hairline 分割（连体描边，无轨道无滑块无投影）
激活段accent-soft 轻染 + accent-text · 字重 600（与侧栏选中项「轻染不是浮起」同语言）
非激活段透明底 · ink-2 · 字重 500 · hover 淡墨 bg-hover（只落未选段）· press bg-press
尺寸段高 26 + 描边 2 = 控件总高 28（sm 档）· md 总高 34 radius 9 · 段内 padding 0 14px · 图标 13px stroke 1.75
键盘 / 语义radiogroup：Tab 一次进组、←/→ 移动即选择（roving，原生 radio 白送）；焦点环 --tau-focus-ring（inset 2px 不被容器圆角裁切）
动效轻染淡入 160ms ease-out（色染 + 字重维度，无滑块位移）；内容切换本身无动画（桌面即时感）
段数上限2–5 段；再多说明切的是「值」不是「形态」——改 Select（分界口径）

裁决与落地映射

  1. 形态（2026-09-23 裁决）：取探讨稿案 1——分段；案 2 线轴（下划线 Tab）踩 02 §5.2 「内容切换不该用 Tab」裁决且新增贯穿横线，案 3 溶解把形态开关埋进下拉（切换因果最弱），均否决。 同日追记：分段形制由首版凹槽（bg-sunken 轨道 + 胶囊滑块）改定连体描边（用户否决深底轨道， 通用组件设计稿 mockups/segmented/，D-029）。分界口径自此成立： 形态切换（字段不同构）用分段，值切换（字段同构）用 Select。
  2. Segmented 落地：已实现为 packages/ui/primitives/Segmented.tsx（连体描边， 原生 input[type=radio] 承载语义、Tab 一次进组、方向键 roving 白送；复合组件 Segmented + Segmented.Item，label → aria-label、sm 28 / md 34、图标段与纯图标段）； 测试 segmented.test.tsx 7 例，样板间 Choice 档案增展区。左栏导航零改动（D-028 十四子页对齐不破）。
  3. 切换语义保留 legacy：本地 ↔ API = embeddingProvider.currentConfigId 切换；三类切换 （本地↔API / Provider 激活 / 模型启用）均经 ConfirmDialog 确认「后台自动重建向量索引」； 即时保存模型不变（设置弹窗无应答区）。
  4. 本地态：运行环境三行（下载源 ModelScope / HuggingFace · 设备策略 自动 / CPU / CUDA · 批处理大小）；模型列表实读本机（getEmbeddingModels），启用 = 确认后写 currentModel + 健康预热 （embeddingModelHealth，结果 Toast）；下载走 downloadEmbeddingModel（onEmbeddingDownloadProgress 推进度 + 取消）；删除二次确认。
  5. API 态：Provider 行（启用 / 编辑 / 删除，编辑走 Dialog 表单：名称 · API Key · Base URL · 批处理大小）；模型列表按当前 Provider（新增 / 编辑 Dialog：名称 · 描述 · 上下文长度 · 多模态 · 距离度量），维度变更 Toast「后台自动重建索引」。
  6. 检索模型共享节：Query Expander / Reranker 两开关 + 各自模型行（Qwen2.5-0.5B-Instruct / BAAI/bge-reranker-v2-m3）+ 本节专属下载源与设备策略；本地缺失自动降级的提示语保留。
  7. 落地：替换 features/settings/sections 的 embedding 占位；命令族全量复用 （getEmbeddingModels / downloadEmbeddingModel / cancelEmbeddingDownload / deleteEmbeddingModel / onEmbeddingDownloadProgress / embeddingModelHealth），无新主进程代码。
