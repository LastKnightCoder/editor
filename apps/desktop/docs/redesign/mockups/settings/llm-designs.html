大语言模型子页 · 设计探讨

AI 服务分组的锚点子页，两件事：服务商与模型管理——N 个自定义服务商实例（名称 / API Key / Base URL），每家挂一组模型条目（6 项能力开关 + 协议·温度等高级参数）；功能模型分配——10 个功能槽位 （对话 / 标题总结 / 网页剪藏 / 播客 / 视频总结 / 电子书重写 / 转录优化 / 闪卡 / 评判 / 图片理解）各指定 「服务商 + 模型」。三案：行流同构 / 模型池一览 / 默认模型 + 覆写。 功能严格对齐 legacy（pages/Settings/LLMProviderSetting），只重做排版与主题语言。

功能盘点 · legacy 对照（三案共用，保证无遗漏）

服务商机舱（多实例 CRUD，非图床式五选一）；模型条目 9 字段 + 6 能力开关； 功能分配 10 槽位 × 两级下拉，4 分类 tab 藏分组。

案 1 · 行流同构 —— 服务商切换条 + 组合选择器

✓ 切换条（案 1 采用）

  • 无「生效」语义误导：chips 只切换编辑对象，与同步 / 图床的 active Select 划清界限
  • 单家时退化为「标签 + 表单」（附页左），空态一个虚线 chip 即引导
  • CRUD 动线：虚线 chip 新建、行内即编辑、凭据区尾部确认删除（被引用时列影响）

⚠ 主从双栏（备选）的取舍

  • 优点：服务商全览、点选即切换；模型多家并行管理时心智最顺
  • 620px 右栏两栏并存，模型行 ~400px，能力 chips 易换行
  • 设置弹窗里的新形态（其他子页均无双栏），一致性打折

附 · 分类切换样式 —— 去掉深色轨道的两式

案 1 定稿方向（2026-09-22），分配节的分类切换弃用 bg-group 轨道。A 下划线式最贴 tab 直觉（选中 = accent 短线压在分组线上，暖纸气质如索引页）；B 软选中式更轻（选中 = accent-soft 胶囊，无底线的漂浮感）。二选一微调。

案 2 · 模型池一览 —— 以模型为中心，服务商降为元数据

反转组织维度：用户真正挑选、比较、删除的是模型，服务商只是模型的归属。 全部模型摊成一张表（模型 / 服务商 / 能力 / 被用于 / 操作），「被 N 项功能使用」成为一等列—— 删除保护与沉没配置一目了然；服务商退为下方紧凑列表；功能分配改为 10 行两列矩阵， 无 tab、一屏全览（legacy 要点 4 个 tab 才能看全）。

案 3 · 默认模型 + 功能覆写 —— 分配心智从「10 次填空」到「1 次设定」

10 个槽位的真相：绝大多数功能用同一个主力模型，只有少数场景（图片理解要视觉模型、 评判总结要便宜快档）需要单独指定。顶部默认模型一处设定；未覆写槽位以 ghost 态「跟随默认」 显示继承值，需要时一行覆写、一行可撤。换主力模型从「改 10 处」变「改 1 处」。 这是分配语义增强：视图层 fallback 即可落地（空槽 = 跟随默认，不必改 llmUsageSettings 存储）， 需在 DECISIONS 记一条裁决。

  1. 建议以案 3 为基底：它直击 legacy 分配的根痛点（10 槽填空、换主力模型要改多处、tab 藏分组）， 且实现是视图层 fallback——空槽位渲染为「跟随默认」，llmUsageSettings 存储不动；已存的显式分配 迁移时原样保留为覆写，十个槽位全同模型时自动收敛为默认。分配语义的变化在 DECISIONS 记一条 （含「默认槽存哪」：建议独立 setting 键，而非复用 chat 槽，语义更直）。
  2. 服务商管理定稿切换条（案 1 已采用，主从双栏为附页备选）：LLM 服务商没有「当前 / 生效」语义（各功能在分配节独立指定模型，不同于同步 / 图床的 active）——切换条只表达 「正在编辑哪家」：点 chip 切换、虚线 chip 新建（小弹层：名称 / Base URL / API Key）、 删除走凭据区尾部按钮 + 确认弹层（模型被分配引用时列出受影响功能）。主从双栏在多家并行 管理时更顺，但 620px 右栏下模型行只剩 ~400px，默认不取。字母徽标保留，给服务商身份感。
  3. 组合选择器三案通用：分组（服务商）+ 搜索 + 能力角标 + 键盘导航，取代 legacy 两级下拉； 图片理解等槽位可在下拉内直接看到「图片」角标，减少选错。浮层引擎走 primitives 既有 Select 扩展 分组渲染，不新造组件族。
  4. 案 2 的「被用于」列必须吸收：无论哪案定稿，模型行都要挂使用计数（删除保护）； 若采纳案 3，管理节模型行显示「6 项功能在用（含默认）」即可，不必整表摊开。
  5. 模型编辑表单走 Dialog 浮层（D-002：浮层不经页面栈协议，资源子页已有 Dialog 先例）： 基础两字段 + 6 能力 chip 开关 + 高级折叠区；能力 chips 一律中性底（bg-group + ink-2）， 废除 legacy 的紫 / 粉 / 彩色标签——「色彩表意」宪法只允许 accent 与语义状态用色。
  6. 落地锚点与同构推广：替换 features/settings/sections 的 llm 占位；消费 useSettingStore llmConfigs / llmUsageSettings（读写路径不变）；「服务商 + 模型 + 分配」三段式可整体套用于 嵌入模型子页（embedding 结构同构），图片生成 / 语音子页按各自 legacy 形态裁剪。
