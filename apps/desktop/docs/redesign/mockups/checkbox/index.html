Checkbox 设计稿 Input 方案 A 语言

经典描边 —— 16×16 视觉格 surface + line-1，选中转 accent 实底；原生 input 承载语义，命中 24×24，focus-visible 才显 ring

状态矩阵 · STATE MATRIX（逐个点按对比，Tab 进焦点看 ring）

默认：surface + line-1
选中：accent 实底 + 反色勾
indeterminate：accent + 横线
禁用：整体降透明 55%
禁用：指针与文字同灰
错误：aria-invalid → danger 描边
勾的出现是 110ms 缩放进场（安静而确定）；hover 加深描边半档 （ink-3 50% color-mix 派生，与 Input 同源），选中态 hover 转 accent-hover。 错误态判定与文案归表单层——控件只认 aria-invalid。

键盘与命中 · KEYBOARD / HIT AREA

Tab 到达（focus-visible 才显 ring，鼠标点击不显） Space 切换（原生） 点 label 文字同样切换 命中 24×24（视觉 16 + padding 撑到宪法下限）
// API 草案：原生 input 透传（受控 checked / onChange），形制挂在自绘 box 上 <Checkbox checked={enabled} onChange={e => setEnabled(e.target.checked)} label="自动同步" // 可选：有则渲染关联 label（点文字切换）；无则裸勾选框 indeterminate={some && !all} // 半选（视觉态，aria 同步；不改变点击行为——点击仍由调用方决定全选/清空） aria-invalid={!!errors.x} // 错误态正源（同 Input 裁决） /> // 原生 disabled 透传；无 status prop、无 size 档（勾选框不需要密度分档，需要时靠外层行高）
