Segmented 设计稿 Input 家族 · 连体描边

凹槽深底否决后的重设计：容器是一枚 hairline 描边控件（surface + line-1，与 Input/Select 触发器同皮）， 段间 hairline 分割，激活段 accent-soft 轻染 + accent-text——零轨道、零滑块、零投影，深底彻底退场； 语义仍是 radiogroup 单选（Tab 一次进组、方向键移动即选择）

状态矩阵（全部可点选；Tab 进组后方向键，看段内 ring）

默认：surface + line-1，文字 ink-2
激活：accent-soft 轻染 + accent-text 600
hover 未选段：淡墨 bg-hover（试试）
禁用段：降透明 55%，选中态保留
全组禁用：一档压全组
md 档：总高 34 / radius 9（对齐 Button md）
图标段：图标随文字同染（13px）
纯图标段：aria-label 必填（title 演示）
状态语法与 Input 家族同纪律：hover 只落在未选段（淡墨，激活段色染不被冲淡）、 press 加深一档（bg-press）、focus-visible 才显 ring（roving 跟随方向键， inset 2px 不被容器圆角裁切）；禁用分两档——单项（保留已选态的锁定）与全组（fieldset disabled 压全组）。 激活语义与侧栏导航项（bg-selected + accent-text）同源：选中是「轻染」不是「浮起」。

形制对比 · 连体描边（推荐） vs 分离胶囊（对照，可裁）

连体：一枚描边控件，控件感最强
分离：更轻，但读作筛选 chips 而非一枚控件
推荐 连体描边：整段共享一条 hairline 外框，「这是一枚控件」的边界由描边一次说清， 与 Input / Select 触发器 / Radio 环同一家族语法；激活轻染在描边内完成，不需要轨道承托。 分离胶囊留此对照——它更接近 publish 子页的 chip.on 语言，适合「筛选标签」场景； 若裁决翻转，组件层只换容器与段的两个类。段数口径不变：2–5 段，再多该用 Select（值切换）。

键盘与组语义

Tab 一次进组（到达选中项；无选中则首个可用项） ↑↓←→ 移动即选择（原生 roving，环形环绕） 点击段任意处即选；纯图标段命中 ≥ 28 宽 选择即生效（即时语义，无 Space 二次确认）
// API 草案：Segmented 管组语义（radiogroup），Item 是分段（原生 input[type=radio] 隐藏实现，与 RadioGroup D-026 同源） <Segmented value={source} onValueChange={setSource} size="sm" // sm 28（默认）/ md 34；radius 8 / 9 > <Segmented.Item value="local" icon={HardDrive} label="本地模型" /> <Segmented.Item value="api" icon={Globe} label="API 模型" disabled /> </Segmented> // 组级 disabled（fieldset）压单项；无 loading / error 态——它不是表单输入，是即时的视图切换 // 纯图标段：label 省略时 aria-label 必填；计数徽标不建（数据库视图胶囊 D-027 的职责） // antd 对照：Tabs → Segmented（02 §5.2）；Tabs.TabPane 无对应物——内容区归调用方渲染，组件只管切换器

真实场景 · 嵌入模型来源（设置子页消费者）· 统计时间窗（md）· 视图密度（纯图标）

嵌入模型子页 · 页题下形态切换（sm · 图标段）
统计页 · 时间窗（md · 四段纯文字）
卡片库 · 视图密度（纯图标 · 含禁用段）
三个场景覆盖三种取形：图标段（设置子页的形态切换，正是凹槽版被否决的消费者）、 md 纯文字四段（时间窗，段数上限内的典型）、纯图标（视图密度，禁用段演示看板未开放）。 切换经底部状态栏回报 onValueChange；真实接线时嵌入模型页的切换仍走 ConfirmDialog 确认（后台重建向量索引），组件本身不弹窗。

Segmented（Input 家族 · 连体描边）

容器 = surface + line-1 的 hairline 控件，段间 hairline 分割；激活段 accent-soft 轻染 + accent-text 600，hover 未选段淡墨、press 加深、focus-visible ring 随 roving 走； 无轨道无滑块无投影——凹槽深底（macOS 语言）已被否决，本页为重设计定稿候选。 radiogroup 单选语义（Tab 一次进组、方向键移动即选），sm 28 / md 34，段数 2–5。
试试：状态矩阵逐组点选（hover 未选段看淡墨）；Tab 进组后 ←→ 移动； 图标段与纯图标段；形制对比里两枚对照；真实场景三组切换看状态栏回报。
