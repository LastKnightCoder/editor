长列表滚动 · 视口边缘 flip

下方放不下 → 翻到触发器上方（动画方向跟随）；超过 8 项出滚动， 键盘导航 scrollIntoView(nearest) 跟随。定位数学 = D-004 引擎（GAP=4，与 Select 同族）。

暗账 · 本方案绕不开的三件事

① 纵向开销：34px 行高 + 2px 行距，10 项菜单比 A 高约 44px—— 长菜单（移动到笔记本）更容易进滚动态，「一屏看全」的项数更少。
② kbd chip 的测试矩阵：chip = surface 底 + 描边，在菜单高亮（bg-hover）、 danger 实心 hover、深色主题三种背景下都要显形——D-009 裁了亮底口径， 但菜单内密度比正文行内高，描边可见性要专门回归。
③ danger × 高亮 = 第三态：A 的 danger hover 只是浅红底，高亮态能直接复用； B 的实心红 hover 与键盘高亮（bg-hover）并存时要显式定义 「danger + 键盘高亮 = 实心红」——状态矩阵从 2×2 涨到 3×2。

菜单是一件产品

行是浮起的药丸（34px + 行内 8px 圆角 + 2px 间隙），勾选是显式控件（方框/圆圈）， 快捷键穿 kbd chip（D-009 亮底小药丸），danger hover 实心红—— 与 Toast 卡片、命令面板同一语言。代价：纵向开销 + 状态矩阵涨一档，见页底暗账。
