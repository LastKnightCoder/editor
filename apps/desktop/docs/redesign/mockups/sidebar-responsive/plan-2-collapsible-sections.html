方案二分组折叠 —— 用户自主收纳（业界最主流）

每个组头可点击折叠；折叠后显示条目数保留「信息气味」；折叠状态记忆到下次启动。全展开溢出时仍可滚动兜底（继承方案一的渐隐滚动）。

机制：组头 button + grid-rows 折叠动画 + localStorage 记忆 业界：VS Code 资源管理器、Obsidian、Discord 频道分类、Slack 优点：用户可控、高频组展开低频组收起、业界验证最充分 缺点：找折叠项多一跳；首次使用（无记忆）时仍溢出

如何感受这个方案

  1. 点击组头（如「知识」「学习」）折叠——21 项可压到 10 行以内，普通窗口高度即可完整容纳。
  2. 折叠后组头右侧出现条目数（如「5」），hover 组头即可预览规模；刷新页面折叠状态被记住。
  3. 侧栏头部右上角有「全部折叠 / 全部展开」快捷键。
  4. 全部展开 + 矮窗口时，退化为方案一的渐隐滚动——两个方案叠加使用，不是二选一。
