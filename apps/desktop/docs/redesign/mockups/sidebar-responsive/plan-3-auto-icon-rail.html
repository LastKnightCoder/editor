方案三响应式图标栏 —— 窄窗自动降级 58px rail

窗口宽度低于阈值时自动切换到 58px 图标栏（与现有手动折叠态同一形态、同一套 CSS）：文字隐藏、组头退化为小点分隔、徽标退化为圆点角标、hover 出 tooltip。图标栏自身纵向溢出时仍可滚动。

机制：宽度断点（如 viewport < 920px）自动切 rail + 过渡动画 业界：VS Code activity bar、Arc、Slack 窄窗、飞书的收纳态 优点：横向空间极限压缩（218→58px）；复用现有折叠态，实现成本低 缺点：纯图标牺牲可读性（依赖 tooltip）；21 个图标纵向仍可能滚动

如何感受这个方案

  1. 拖窄浏览器窗口（左右边缘，低于 ~920px）：侧栏自动收成 58px 图标栏——注意宽度过渡动画、组头变成小点、徽标变成角标圆点。
  2. 图标栏下 hover 图标出 tooltip（fixed 定位不被滚动区裁剪）；「今日」保持激活竖点。
  3. 窗口再拉宽，自动还原 218px 完整态；左上角按钮仍是手动折叠（自动 + 手动叠加）。
  4. 也可以用下方切换器强制锁定某形态观察。
