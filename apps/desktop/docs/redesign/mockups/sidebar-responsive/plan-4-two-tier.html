方案四组级双层导航 —— 一级恒定 7 项，结构性不溢出

一级侧栏只放「今日 + 5 个组 + 设置」，任何窗口高度都放得下；点击组在侧栏内推入二级面板（组内条目），返回/Esc 回一级。把「纵向溢出」从根上消掉，代价是所有非今日功能多一跳。

机制：侧栏双层 stack + translateX 推入（同 Page 栈心智） 业界：Apple 系统设置、iOS 设置、Photoshop 工具组 优点：一级永不溢出、侧栏可以更窄、层级清晰 缺点：直达性受损（高频功能也要两跳）、切换组要先进后出

如何感受这个方案

  1. 一级列表恒定 7 项（今日 + 5 组 + 底部设置）——无论窗口多矮都不出现滚动条，拖窗口验证。
  2. 点击组（如「知识」）→ 侧栏推入二级面板（注意一级后退 24% + 变淡的景深效果）；返回按钮或 Esc 回一级。
  3. 右下角读数确认「一级 7 项 / 永不溢出」。
  4. 注意体会缺点：从「卡片库」切到「待办」需要 进出两级——高频直达性变差。
