方案一优雅滚动 —— sticky 组头 + 边缘渐隐 + hover 细滚动条

不减少任何入口：条目多就滚，但把「滚动」这件事做到无感——组头吸顶保持方位感、能滚时上下边缘渐隐提示、滚动条平时隐身 hover 才出现、底部设置固定不参与滚动。

机制：overflow + sticky + mask 渐隐（复用现有 useEdgeFade 协议） 业界：Notion、Figma、Apple 系统设置 优点：零信息损失、实现成本最低 缺点：矮窗口下找条目仍需滚动

如何感受这个方案

  1. 拖矮浏览器窗口（上下边缘）：侧栏开始内部滚动，注意组头「工作台 / 知识 / 学习…」吸顶不跟走、上下边缘出现 12px 渐隐带、滚动条悬停才显形。
  2. 「设置」钉在底部，永远不参与滚动——高频入口在任意窗口高度下直达。
  3. 右下角读数实时显示窗口尺寸与侧栏溢出状态。

对应实现：现有 Sidebar.tsx 已有 overflow-y-auto，只差 sticky 组头 / 渐隐 / hover 滚动条三件套，useEdgeFade hook 可直接复用。
