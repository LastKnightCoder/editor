首输入框自动聚焦全选；表单走 Enter 提交（dialog 承载 form 语义）； 名称为空时主按钮禁用——校验内联在按钮上，不做弹中弹的错误提示。

阻断通知 · 版本冲突（纯文字头部 · critical 二选一）

阻断通知不带 icon——40px 圆底与 17px 内联两轮试验都因「与文字头部 不一体」被否决，最终纯文字（标题 + 徽标），与其它对话同构；分量由 critical 行为 （无 ×、遮罩抖动）与文案承担。「保留我的」放主按钮位（安全侧），「重载他们的」是次按钮。

长内容滚动 · 头尾固定 · edge fade · 尺寸档 + width 任意值

正文区独立滚动，标题与应答区钉住；滚动时上下缘 edge fade 渐隐 （对齐壳层 useEdgeFade 协议，只在真能滚的方向显形）。高度上限 78vh，超出才滚。 尺寸档是预设不是牢笼：三档之外可传 width 任意值覆盖——预设给常见场景， 业务特殊版式（如双列选择器）不必硬凑档位。

异步提交 · loading 期间一切关闭路径失效

主按钮进入 loading（spinner + 文案切换）后，Esc / 遮罩 / × 全部失效—— 半途关闭的导出是坏文件；完成后自动关闭并交 Toast 报告结果（D-003 家族分工：Dialog 管决策，Toast 管回执）。

暗账 · 本方案绕不开的三件事

① blur 遮罩的 GPU 账单：backdrop-filter 在大窗口 + 低端机上连续开关有可感重绘成本； 录屏 / 截图 / 远程桌面下 blur 的观感另算一笔兼容性账。
② type-to-confirm 是行为税：输入名称挡住手滑，也挡住急性子——档位必须只给 「真不可逆」（删除笔记本/清空废纸篓），轻度危险（归档）继续一步确认，否则全线劝退。
③ 最重的一件 Dialog：16px 大标题 + 34px 按钮 + hairline 分区，纵向开销三案最大； 高频小确认（每次归档都停 320ms 动效）会显「隆重」，密集操作流里偏慢。
