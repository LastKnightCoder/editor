Button · 方案 A 纸面凸版

按钮是纸面上的一枚活字：accent 实心带底缘 letterpress 暗边，hover 微浮、 按压下沉 1px——反馈是物理的，不是光的。次级按钮不描线，用 group 下沉填充（02 规范 §2 点名的组合），纸的层次靠「沉浮」表达。参照：Things 3、macOS 本地控件。 变体集与 B/C 完全相同（primary / secondary / soft / ghost / danger / danger-soft × sm / md × 六状态），差异全在皮——同 API 不同材质，可直接横向对比。

变体全谱 variants

六档覆盖一个动作的全部「音量」：primary 是唯一主角（每屏至多一枚）， secondary 应答，soft 是不打断阅读的强调，ghost 是语境动作，danger 两档对应 D-011 的危险分级。

尺寸与图标 sizes × icons

两档高度：md 34（表单 / Dialog 应答区）、sm 28（工具栏 / 面板头 / 紧排行）。 图标 16px stroke 1.75，仅左位（icon={Plus}）—— 纯图标按钮走既有 IconButton（30px ghost），Button 不做 icon-only。

行为契约 contract

三方案共用，定稿后随 ui/primitives/Button.tsx 落地； 与 02 规范 §5.3 一致（size sm/md、data-state 驱动、forwardRef、focus-ring 全局口径）。

Tab 焦点环（仅键盘导航显示） Enter 触发（form 内 = submit 语义，与 Dialog 默认应答协同） Space 按下即按压反馈

· loading：aria-busy + spinner + 文案切进行时态，指针封锁（ConfirmDialog 现行行为，D-011）
· disabled：原生属性（不出现在 Tab 队列），opacity 0.42，cursor default
· 动效 140ms ease-out；prefers-reduced-motion 下降级为纯色变（位移取消）
· 图标仅左位 16px；icon-only 一律走 IconButton，Button 不设该档
· antd 迁移映射：type=primary → variant=primary；type=default → secondary；type=text → ghost；danger 布尔 → danger 变体

暗账 costs

letterpress 暗边需要派生色：demo 用 color-mix(accent × black 22%) 临时表达， 定稿必须在 tokenContract 增补（如 accent-edge）或收口在组件层 color-mix，禁止散落裸值。
group 次级在 cocoa 是「洞」不是「纸」：深色主题里 group 比页面更暗，次级按钮靠暗边撑轮廓， 存在感比 B 的 surface 描边弱——密集表单里可能不够「可指认」。
位移反馈的成本：translateY 会触发重排（1px、140ms，量级可忽略但存在）， 连续快速点击工具栏时有轻微「跳动」感——纸的代价。
