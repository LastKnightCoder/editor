Button · 方案 B 现代产品

按钮是产品表面的一件控件：primary 是 accent 实心 + 微投影（浮起 1px 的光感）， hover 整体加深一档；secondary 是 surface 亮底 + line-1 描边；soft 是 accent-soft 平底—— 现代 SaaS 的「次级强调」。反馈是「光」的（brightness / 阴影），无位移。 决定性理由：ConfirmDialog 应答区现行 BTN_BASE 就是这张皮，Button 落地即替换（注释里 「落地前在此收口」的欠账）；与 Dialog B（D-011）、Menu B（D-010）、Toast 卡片同语言。 变体集与 A/C 完全相同，差异全在皮。

变体全谱 variants

六档覆盖一个动作的全部「音量」：primary 是唯一主角（每屏至多一枚）， secondary 应答，soft 是不打断阅读的强调，ghost 是语境动作，danger 两档对应 D-011 的危险分级。

尺寸与图标 sizes × icons

两档高度：md 34（表单 / Dialog 应答区）、sm 28（工具栏 / 面板头 / 紧排行）。 图标 16px stroke 1.75，仅左位（icon={Plus}）—— 纯图标按钮走既有 IconButton（30px ghost），Button 不做 icon-only。

图标按钮的命中面积由 IconButton 承诺 ≥ 24×24（工具栏 28×28）； Button 的 sm 28 也守住这条线。soft 是 B 的招牌档：工具栏「开始复习」这类高频次级强调， soft 比 secondary 轻、比 ghost 重，正好落在中间。

行为契约 contract

三方案共用，定稿后随 ui/primitives/Button.tsx 落地； 与 02 规范 §5.3 一致（size sm/md、data-state 驱动、forwardRef、focus-ring 全局口径）。

Tab 焦点环（仅键盘导航显示） Enter 触发（form 内 = submit 语义，与 Dialog 默认应答协同） Space 按下即按压反馈

· loading：aria-busy + spinner + 文案切进行时态，指针封锁（ConfirmDialog 现行行为，D-011）
· disabled：原生属性（不出现在 Tab 队列），opacity 0.45，cursor default
· 动效 140ms ease-out；prefers-reduced-motion 下降级为纯色变
· 图标仅左位 16px；icon-only 一律走 IconButton，Button 不设该档
· antd 迁移映射：type=primary → variant=primary；type=default → secondary；type=text → ghost；danger 布尔 → danger 变体

暗账 costs

radius 10 是任意值：尺度词表只有 8/12/16（rounded-tau-sm/md/lg）——ConfirmDialog 现行 rounded-[10px] 就是任意值。定稿要么在 tokens.css 增补按钮专用档，要么收敛到 8（A/C 的取值）。
cocoa 上的浮起感减弱：亮橙 accent 落在暖黑底上，投影对比不足——投影强度需要分主题调， 或接受 cocoa 下 primary 更「平」。
无位移 = 少一档手感：brightness 反馈的心理确认比 A 的下沉弱；高频工具栏场景里 「按到了吗」的确定感靠 140ms 的色变撑。
