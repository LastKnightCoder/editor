三个方案

方案 A · 素卡 — 主方案方向（v2 已按第二轮反馈修订）

素卡 · 单栏就地

与文章页 A4「静」同族的极简路线：正文列 640 恒居中，卡头一行 meta（编号 + 分类徽章 + pin + 时间 + ⋯ 菜单在时间右侧，legacy 位置），一切就地——标签、连接区（有关联才渲染，空卡不堆区块）。底栏纯状态（字数 · 协作 · 保存）。v2 修订：撤掉底栏「更多 ⌃」、暂不做闪卡关联与图谱、去掉面包屑速切器（换卡 = 点连接 chip / 内联引用 / 后退回列表）、删除入口回 ⋯ 菜单、空卡添加连接走 ⋯ 菜单「连接 → 添加链接」。

✓ 与文章页基因最连续、空卡干净（meta + 正文 + 标签即全部）、窄窗最稳、实现最轻✗ 连接多时正文末区块拉长；换卡依赖跳转与返回（无页内切换器）
方案 B 留档对照

卡片桌 · 双栏档案

正文列 + 常驻档案栏（272px sticky，无重容器、留白分组）：关联（行列表 + 解链 + 迷你图谱缩略）/ 标签 / 闪卡 / 档案（分类四色点选器、置顶开关、编号、时间、字数）。卡头精简为编号 + 时间。回应 PREFERENCES 原始偏好「详情页用双栏」。窄窗折叠（A2 抽屉手法）。

✓ 连接管理最顺手（列表耐读、多链接不挤正文）；元数据集中一处；正文视野最纯✗ 宽度依赖（<1280 需折叠）；档案栏与「卡片是完整作品」的整卡叙事略有张力
方案 C 留档对照

街道 · 图谱主视觉

「编号是思想的坐标系，链接是思想的街道」——左侧实体卡纸（surface 浮起 + 分类色脊 + 投影，bg-page 即桌面），右侧凹陷画布（bg-sunken）承载活的局部图谱：中心 = 本卡，两层 BFS 邻接动态生成，节点分类色、hover 显首行、点击即换卡——沿街道散步式浏览；图下列表兜底。

✓ Zettelkasten 网络叙事最完整、换卡动线最直觉（点节点即走）、「卡片在网中位置」一眼可读✗ 宽度要求最高（图谱 <360px 不可用）；日常专注写作时图谱是右侧常亮干扰；实现最重（布局器 + 交互）
