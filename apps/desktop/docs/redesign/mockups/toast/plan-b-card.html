Tau v2 · 重构中toast 上限 4 条 · 5s 自动关闭 · 加载中不自动关

信息密度最高的形态

结构 = 图标色块 + 标题（含时间戳）+ 两行描述 + 动作按钮（ghost 次要 / solid 主要）+ 底部同色倒计时条。 倒计时纯 CSS 动画，悬停自动暂停（animation-play-state）。加载中类型不倒计时不自动关， 由调用方 resolve 后关闭或换形态。适合「同步完成（3 个设备）」「剪藏失败，可重试」这类要解释的反馈。
试试：点「错误（带重试）」→ 悬停看进度条停走 → 点「重试」关闭；切「底部居中?」——B 不提供底部居中，卡片形态居中会挡内容，仅顶部居中可选。
