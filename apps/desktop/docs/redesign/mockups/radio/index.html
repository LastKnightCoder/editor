错误：aria-invalid → danger 描边
选中优先：点 invalid 项即转 accent
禁用（选中）：降透明 55%
禁用（未选）：指针与文字同灰
状态机与 Checkbox 同源：hover 加深描边半档（ink-3 50% 派生）， focus 显式让位（ring + accent 压过 hover）；错误态正源 aria-invalid（未选 danger）， 选中压过错误（选中优先，同 Checkbox 裁决）；判定与文案归表单层 FormRow（未设计）。

选中态形制对比 · RING+DOT（推荐） vs SOLID+CORE（对照）

环+点：状态变化发生在描边维度
实底：与 Checkbox 翻转同构、更重
推荐 环+点：「经典描边」语言里未选 → 选中的变化落在描边上（line-1 → accent， 与 Input focus、Checkbox hover 同一语法维度）；radio 的形状本身即语义（圆 + 心）， 16px 小格上实底挖洞的环厚仅 ~4.5px、信噪比低。实底变体留此对照——如裁决翻转，组件层只改选中态两个类。

Radio / RadioGroup（Input 方案 A 语言）

16×16 视觉圆 surface + line-1，选中 = accent 环 + 中心 accent 点 110ms 进场； 原生 radio 组语义（Tab 一次进组、方向键移动即选），命中 24×24， focus-visible 才显 ring，hover 半档且 focus 让位。选中态取「环+点」而非 Checkbox 的实底翻转——radio 形状本身即语义，页内留实底对照可裁。
