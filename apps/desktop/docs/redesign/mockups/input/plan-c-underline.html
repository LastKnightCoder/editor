形制对照 · 同一字段的三种框（A 描边 / B 槽 / C 线）

A：surface + line-1（表单控件裁决形）
B：group 底凹陷
C：只有一条线
C 与 Select / DatePicker 触发器（描边形）的形制差最大——它不适合与控件混排的 「新建表单」，主场是设置流与行内编辑。可以作为「表单用 A、清单用 C」的双轨并存， 也可以整体放弃 C。

下划线行内（最轻形）

无框无底只有一条 2px 线，focus 转线不弹 ring——「编辑既有值」的最小侵入。 主场：设置页两栏流、数据库行内改值、属性面板。不适合新建表单 （空表单里一排线找不到输入边界）与控件混排。
试试：设置流里点各字段看线转色；数据库表点任务名就地编辑 （Enter 提交 / Esc 还原）；对照区看三种形制并排；右上角切主题。
