经典描边（基线形）

2026-09-17 裁决的标准演绎：surface 亮底 + line-1 + focus ring， 与 Select / DatePicker 触发器同族同皮——表单里控件与触发器混排时 视觉完全连续。装备位（前缀 icon / 清空 × / 计数器）齐全； 错误只换描边、文案归 Field 体系。
试试：逐个点状态矩阵的框对比六态；带值输入框 hover 出 ×； textarea 打字看计数器（超 200 转红）；数值框输 abc 看校验；右上角切主题。
