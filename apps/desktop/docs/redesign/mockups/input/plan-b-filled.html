混排对照实验 · 输入槽 vs 选择框（同页共存）

这是 B 的裁决点：Select / DatePicker 触发器是描边形（2026-09-17 裁决）， 输入是槽形——同页混排形成「选择=框、输入=槽」的双轨语义（未必是坏事： 语义上「选择」本就是点开的浮层锚点）；介意的话要么全族切 B（触发器也改槽形）， 要么回 A 保持同皮。

柔和填充（凹陷形）

输入框是「槽」：group 底无描边，focus 时浮出为框（accent 描边 + surface 底 + ring）。 大表单里线噪归零，层级全靠亮度——正合宪法第 2 条。代价是与 描边形的 Select/DatePicker 触发器混排时形制不一致（双轨语义需裁决）。
试试：状态矩阵逐个点入焦点看「浮出」；设置页整组排开的低线噪观感； 混排实验里槽与框同屏对比；右上角切主题。
