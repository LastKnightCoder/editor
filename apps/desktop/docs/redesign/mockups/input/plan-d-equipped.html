装备化（能力全集）

形制不变（同 A），把 Input 做成输入容器：lead/trail 槽位、 addon 框外连体、Password/Number/计数器特化。纪律：框内挂静默信息、 动作独立成位——框不是工具栏。
试试：密码框点眼睛显隐；步进器 −+ 调数值（第二个 0.5 步长）； textarea 计数超限转红；FilterBar 点搜索联动统计；右上角切主题。
