Tau 桌面端重构 · 样板间

这一步只做决策，不写代码。先定导航大方向（第 1 节），再体验三套设计方向（第 2 节，每套都带浅色/深色切换、详情抽屉、分屏与 Ctrl K 命令面板），最后过一遍决策清单（第 3 节）把结论告诉我。配套文档在 docs/redesign/（蓝图 / UI 规范 / DECISIONS / PREFERENCES）。

1 · 导航方案对比

浏览器式 Tab 只是选项之一。五个方案的完整分析见《01-重构蓝图.md》§4，这里是直观线框：

方案 0 · 维持 Tab 条（现状）

  • 多任务并行、浏览器心智、用户已习惯
  • 33 种 TabType 已失控；标题栏拥挤；管理成本高
  • 保活可修"丢状态"，但 Tab 条噪音仍在

方案 1 · 侧边栏 + 单主视图

  • 导航零管理；切换零丢失；信息架构一目了然
  • Notion / Linear 验证过的桌面惯例
  • 不能同时看两个页面（靠分屏补）

方案 2 · 侧边栏 + 列表详情同屏

  • 浏览-阅读工作流最高效（邮件客户端式）
  • 只适合"列表+详情"型内容，不适合编辑器/白板
  • 作为全局方案过窄——更适合做页面内布局模式

方案 3 · 自由多面板工作台

  • 天花板最高：任意页面并排（IDE / Obsidian 式）
  • 实现与维护成本最高
  • pane 布局管理会重演 Tab 管理的复杂度

方案 4 · 侧边栏 + 页内详情 + 分屏逃生舱推荐

  • 方案 1 骨架 + 详情走抽屉/浮层（蓝块）+ openInSplit 分屏（右窄栏）
  • 10% 成本拿到方案 3 的 80% 价值；架构上可平滑进化到方案 3
  • 命令面板补齐键盘多任务（三套方向 demo 里都有实装）

2 · 三套设计方向

每套都是完整的「卡片列表页」demo，交互一致（可对比）：主题切换、点卡片开详情抽屉、卡片悬停分屏、Ctrl K 命令面板、Esc 逐层退场、标题栏后退/前进（Alt+←/→）；状态栏可切换 Win / Mac 标题栏预览（Mac 模式红绿灯让位左侧、隐藏 Windows 三键）。上排色板为浅色主题，下排为深色主题。另见：A2 · 暖纸柔和版（A 的重写：去横线切割、宽容器、丰满首页、详情双栏）与 今日页三方案（清单流 / 双栏工作台 / 轻量指标）。

A · 暖纸工作台

Cream Studio — 移动端「杏子 Bento」的桌面化

奶油纸底 + 可可墨 + 陶土橙，六组粉彩语义色，卡片不描边靠阴影分层，圆角 14，极淡噪点。深色为玄夜（琥珀 accent）。

气质：温暖、亲切、纸感
优势：与移动端同一设计语言，双端一体的品牌感
代价：与常见工具软件差异最大，需要接受暖色工作台
打开方向 A · 建议全屏窗口

B · 石墨工作台

Graphite Atelier — 冷灰中性 + 靛蓝的专业工具风

发丝线描边分层（不用阴影），圆角 8，紧凑密度，tabular-nums 数字对齐。Linear / Raycast 谱系，现有 --th-* token 血统的完整体。

气质：冷静、精密、工具感
优势：信息密度最高，最贴合"冷静克制"的工具气质，实现迁移成本最低
代价：「个人特色」相对最弱，与优秀工具软件同质
打开方向 B · 建议全屏窗口

C · 墨韵编辑部

Ink & Vermilion — 纸墨与朱砂的编辑风

素白纸面 + 近黑墨色 + 单一朱砂色。卡片题名与页题用衬线（宋体/Georgia），meta 用等宽（档案感），索引卡片式粗墨线顶边，圆角 4，双细线分隔。

气质：书卷、克制而有人味，个人特色最强
优势：卡片笔记 = 索引卡的隐喻天然成立；写作类产品气质契合
代价：衬线标题的阅读效率略低；暖白纸面需接受
打开方向 C · 建议全屏窗口

5 · 决策检查清单

逐项过一遍，把结论（包括混搭，如「A 的配色 + B 的密度」）告诉我，我会落进 DECISIONS.md 与 PREFERENCES.md：

  1. 导航方案是否采纳推荐的方案 4？侧边栏一级导航的分组与命名（demo 中的「工作台 / 知识 / 学习」三分组）是否符合你的心智？
  2. 设计方向A / B / C 三选一，或指出混搭要素（配色、圆角、字体、密度可各自取材）。
  3. 密度基调默认紧凑（B 的行高）还是舒适（A 的行高）？影响 token 默认值与卡片信息量。
  4. 卡片信息取舍demo 卡片带了：标题、两行摘要、标签、来源、时间、复习状态。哪些该留、哪些该按需展开？
  5. 详情形态点卡片开右侧抽屉（现状 demo）还是整页跳转（保留返回栈）？抽屉宽度 480 是否合适？
  6. 标签色彩A 的六组粉彩 / B 的冷调低饱和 / C 的无色描边——标签要不要有颜色？
  7. 命令面板Ctrl K 面板的分组（页面/动作/卡片）与键盘优先的定位是否认可？
  8. 深色主题三套深色（玄夜琥珀 / 石墨靛蓝 / 墨夜朱砂）哪套与对应浅色的关系最舒服？
