## 3. 三大协议（照抄即用）

**新增页面**（如卡片库）：

```tsx
// features/cards/surfaces/cards.surface.tsx —— 文件即注册，无需改任何登记表
const schema = createSurfaceSchema({ keyword: paramOptional(paramString()) });
type CardsParams = typeof schema.type;

export default defineSurface({
  key: "cards", // 与 navigation.ts 的 key 一致即接管侧边栏入口
  match: "single", // 功能页用 single；详情页用 "params" + getId: p => `card-${p.cardId}`
  label: "卡片库",
  status: "new",
  params: schema.schema,
  component: CardsView, // 视图组件放 ../views/
});
```

导航：`navigator.push("cards", { keyword: "..." })`；视图内读当前 params 用 `useSurface().state`（后续可加 useSurfaceParams 语法糖）。
`match: "single"/"params"` 的去重由栈机承担：重复 push 同 key 同参 = no-op、异参 = 原位更新，调用侧不要再做"是否已激活"判断。

**新增页面数据**（features/<域>/queries.ts，照抄 features/home 的形状）：

```ts
export function useXxxSnapshot() {
  const query = useQuery({
    queryKey: ["<域>", "snapshot"],
    queryFn: fetchXxxSnapshot, // 并行 Promise.allSettled + 单项降级，整体不 reject
    staleTime: 60_000,
    refetchOnWindowFocus: true, // 全局默认是关，"今日"类数据按页面开启
  });
  return {
    data: query.data ?? null,
    loading: query.isPending,
    refresh: () => void query.refetch(),
  };
}
```

禁止手写 useEffect+useState 拉取；列表展示 N 条禁止为此全量拉大表（用渐进窗口凑满即停，或主进程聚合命令——参考最近编辑 14→30→90→365 天的实现）。

**新增主题**：`ui/theme/themes/<name>.theme.ts` 用 defineTheme 声明（tokens 全键强制，漏键编译不过），在 `themes.ts` import 之，**并同步在 `tokens.css` 补 `[data-theme="<key>"]` 数据块**（取值运行时由该块级联，`theme-parity.test.ts` 守护两处一致；codegen 落地后改为生成）。派生逻辑写在 tokens() 里。

**颜色消费**：组件只写语义类（`bg-page / bg-surface / bg-group / text-ink-1 / text-ink-2 / text-ink-3 / hover:bg-hover / bg-accent-soft / text-accent / bg-ok-soft / text-warn …`）或 `var(--tau-*)`。**禁止**：裸色值、antd token、内联十六进制。

## 4. UI 风格铁律（A2 校准结论，评审对照）

> **视觉基准与工作流（重要）**：`src/app/shell.css` 是从 `mockups/direction-a-soft.html` **脚本机械导出**的（变量 `--tau-*` 化 + `@scope (.app)` 作用域隔离，不污染 legacy）。调视觉的正确流程 = 先改模板（浏览器校准）→ 重新导出到 shell.css，**禁止手改 shell.css**。组件 className 必须与模板类名 1:1（sidebar/quick/board/doc-row/todo-row 等），不要自创 Tailwind 视觉类；Tailwind 只用于模板没有的临时布局微调。

1. **融合骨架**：侧栏透明融于 bg-page、整高贯通窗口；标题栏/状态栏只属于右列；不出现横贯全宽的条。
2. **零横线**：分组靠底色容器（bg-surface 圆角面板 + shadow-card）与留白；禁止用 border 分隔区块（border 只允许 ≤2px 控件级细节，如勾选圈）。
3. **宽度利用**：内容区 max-w 1680 宽容器；窄列只允许出现在正文阅读列（~72ch）；详情页用双栏（正文+信息栏）。
4. **反馈语言**：hover = bg-hover 淡墨底；激活（侧栏）= 淡墨底 + 左缘 3px accent 竖标；浮起（卡片）= shadow-card，hover 轻抬升；按钮无描边。
5. **圆角**：面板/卡片 var(--tau-radius-lg)=16，控件 md=12，小元素 sm=8。
6. **数字** tabular-nums；字号体系以模板为准（25/14/13.5/12.5/11.5）。

## 5. 交互规范（已定案）

- 导航：栈 + forward buffer（push 清空 forward）；`Alt+←/→` 后退/前进；`Esc`=后退（浮层接入后改为先关浮层）；根页 Esc 无操作。
- 键盘仲裁收口在框架层（SurfaceProvider/Titlebar 的全局监听），业务代码禁止自行监听这些键；两处都已让位编辑上下文（输入框/文本域/contentEditable，`surface/dom.ts`）与输入法组合（`e.isComposing`）。
- 栈操作为 action 式 reducer（连续导航由 React 串行归约，不丢更新）；注册表（surfaceMeta/组件 registry/defineTheme）重复注册策略统一为 dev 覆盖+warn（HMR 兼容）、prod 抛错（真冲突）。
- 后退/前进按钮：**禁用而非隐藏**（面包屑旁，Titlebar）。
- 侧栏：拖宽（180–340，持久化）+ 折叠（58px 图标列；折叠按钮同位镜像反转 `»↔«`；双击拖宽条也可折叠）；Mac 红绿灯在侧栏头部（`[data-platform="mac"]` CSS 控制，真实窗口由主进程写该属性）。
- 保活：`<Activity>`（React 已升级 19.2.3，无降级路径），LRU 上限 12；
- 图标：**lucide-react**（线性，stroke 1.75，`navigation.ts` 直接引用 LucideIcon 组件）；多色图标用 **react-icons**（桌面已有依赖）；
- legacy 占位层：侧边栏 13 个真实模块可导航到占位页；
- tsc 全绿。挂载：主窗口 `/` 默认重定向 `/shell`（旧主界面在 `/legacy`，与 legacy 并行，M1 时删除重定向）。

## 6. 如何迁移一个 legacy 模块（标准流程）

1. `features/<域>/surfaces/<key>.surface.tsx` 新建（key 与 navigation.ts 一致——真实注册自动覆盖 legacy.tsx 的占位）；
2. 视图组件按 §4/§5 风格重写（参考样板间与 HomeView，**不参考旧页面写法**）；
3. 数据接 `queries.ts`（契约类型先行，未就绪的字段返回 null + 空态）；
4. 从 `surface/legacy.tsx` 的 LEGACY_SURFACES 删除该行；
5. DECISIONS.md 的 Surface 迁移清单勾选该行。

## 7. 今日页数据（已全部接线，features/home/queries.ts）

数据契约见 types.ts；来源与降级策略：

- reviewDueCount ← `listFlashcardDecks()` Σ stats.dueCount；
- todos / todoRemainingCount ← `listTodoItemsByType("all")` 未完成（逾期 > 今日到期排序，取 3）；
- events ← `getEventsForDay(Date.now())`（排序：非全天在前、按 startTime）；
- recentEdits ← `getCardsByDateRange` + `getArticlesByDateRange`（渐进窗口 14→30→90→365 天，凑满 12 条即停；Slate 正文提文本截断）+ 文档/项目全量轻表按窗口过滤 + 最新日记，混排取 12；
- focus ← `summaryPomodoroToday()`；weekly 叠加本周聚合；
- todayStats/weekly/trend ← `getAllStatistic` 全量快照差分（口径见 `utils/statistic.ts` 的 diffSeries，与统计页共用）；
- heatmap ← `getCalendarHeatmap(今年)` → 全年每日操作数（GitHub 式，home.css）。
  并行 `Promise.allSettled`，单项失败降级为空值并 console.warn，不阻塞整页。
  新增区块时：types.ts 加字段 → queries.ts 分项函数 → HomeView 渲染。
  数据入口一律走 react-query（`useQuery`）：`useHomeSnapshot` / `useStatsSnapshot` 带 staleTime 与窗口聚焦刷新（覆盖全局默认的 refetchOnWindowFocus: false），`refresh()` 即 `query.refetch()`——新页面禁止再手写 useEffect 拉取。
