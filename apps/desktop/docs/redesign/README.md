## 评审流程（针对本次样板间）

1. 浏览器打开 `mockups/index.html`，先看导航方案对比线框，确认导航大方向；
2. 依次打开三套方向 demo（每套都带浅色/深色切换），对照卡片列表页体验；
3. 回到 index.html 底部的决策检查清单逐项过；
4. 你的所有取舍（包括"A 的配色 + B 的密度"这类混搭）告诉我，我落进 DECISIONS.md 与 PREFERENCES.md；
5. 定稿后：选中方向的取值回填 02 规范，样板间其余归档进 `mockups/archive/`，进入蓝图 M0 基建。

## 硬规则（已生效）

- 桌面端禁止新增 `antd` / `@ant-design/icons` import（存量白名单只减不增，CI 棘轮约束）；
- 新页面一律走 `features/**/surfaces/*.surface.tsx` 声明式注册（协议见蓝图 §3.2），禁止再扩 `TabType`；
- 样式新代码一律 Tailwind 语义类（token 映射），禁止新增 CSS Modules；
- 每迁完一个页面：更新 DECISIONS.md 的 surface 清单勾选行，新发现的偏好追加进 PREFERENCES.md，待删资产（前端 + Node 侧）按模板追加进 04-删除清单.md。
