# 日程页（日历）迁移方案

> 样板间：`mockups/calendar/index.html`（三方案 × 四视图 × 五状态 × 深浅色）。
> 范围：legacy `src/pages/Calendar` → 新壳层 `schedule` 入口（navigation.ts 已占位「日程」）。
> 路线：**第一版直接落方案 C（月历大面板 + 当日时间线），底层逻辑平稳复用 legacy；第二版做交互升级（拖动改时间、右键菜单、键盘、色板收敛）**。

- 分层红线：`features/` 禁止 import `@/pages/`，所以旧组件必须**先 `git mv` 单独提交**（不改代码），再在新位置换皮。
- `PomodoroWindow` 的 3 个弹窗引用了 `EventDialog/index.css`（滚动条样式）：搬家前先把这 3 处换成全局滚动条规则，再删 css。
- store / commands / utils / hooks 位置不动（`eventLayoutAlgorithm` 与 Database 日历视图共用）。

### 第一版顺手修（换皮必然碰到的代码）

- 新建默认日期用 `toISOString()` 取 UTC，东八区凌晨会差一天；
- 月视图行高写死 `100 / 5`，6 行的月份错位（换皮会改行布局，一起修）；
- 周标题是估算的「第 N 周」；
- 结束早于开始没有校验。

### 第一版：系统来源日程（番茄钟 / 待办）

已有参考：日历归属（系统组「番茄钟」与「待办清单」下的截止 / 计划 / 周期三个日历，`todo-calendar-sync.ts`）、单条映射查询（`getCalendarMappingByEvent` / `getSessionByEventId`）、完成动作（`useTodoStore.toggleCompleteCascade`，周期任务走 `completeRecurrence(recurrenceId, scheduledDate)`，MCP 工具里有现成调用）。

| 能力     | 做法                                                                                                                                                                     | 成本                |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------- |
| 来源图标 | 按日历归属判断，番茄钟显示计时图标（替代标题里的 🍅）、待办显示勾选圈                                                                                                    | 零新接口            |
| 勾选完成 | 新增一个**批量**主进程查询：`eventIds → { todoItemId, syncType, recurrenceDate, isCompleted }`（现在只有逐条查询，月视图逐条调太多）；勾选后调现有完成动作并失效日历查询 | 一个 IPC + 表格联查 |
| 点击行为 | 待办 / 番茄钟日程不开日程编辑弹窗，改开轻量 Popover（来源信息 + 完成 / 删除）；「在待办中打开」等待办页迁移后再接                                                        | 小                  |

注意：主进程已有 `syncFromCalendarEvent` 反向同步但前端没调，第一版不在日历里改待办标题，避免两边不一致。

### 第一版明确不做

拖动改时间 / 拉伸、右键菜单、键盘导航、邻月日期、色板收敛。

### 第一版落地记录（2026-09-24，方案 C）

- 布局：无内层侧栏；页头（中文月名 + mono 年份/周次）→ 日历 chips（点击切显隐，右端「管理日历」Dialog 承载完整日历清单：分组 / 新建 / 编辑 / 归档 / 删除 / 合并）→ 主面板（月 / 周 / 议程）+ 右栏 340px 当日时间线。日视图取消（由右栏承担），legacy 持久化的 day 自动迁到月视图。
- 月视图：整块大面板含邻月日期（store 月取数改按整张网格 `getMonthGridRange`）；单击格子选中日期、双击新建全天、拖过多天新建跨天。周视图点日期头切换右栏日期。
- 右栏：大号日期 + 前后一天；全天条 → 时间线（今天插入「现在」，08:00–22:00 未来空档 ≥1 小时显示「点击安排」）→ 自然语言快速添加（`quickAdd.ts`，单测 `__tests__/quickAdd.test.ts`；回车直接创建，解析结果以标签回显）。
- 点日程先出速览 Popover（时间 / 日历 / 备注摘要 / 删除 / 编辑），「编辑」进 EventDialog；「还有 N 项」弹窗与议程行同一行组件。
- 待办日程勾选圈直接完成（主进程 `todo:get-calendar-event-sources` 批量查状态，单测 `tables/__tests__/todo-calendar-event-sources.test.ts`）；番茄钟日程计时图标。
- 议程补全天与跨天；顺手修复：月视图行高写死 5 行、周标题估算、新建默认日期 UTC、结束早于开始无校验；WeekView 在循环里调 7 个 hook 拆成单日列组件。
