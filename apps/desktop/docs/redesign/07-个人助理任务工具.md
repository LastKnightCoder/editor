## 接口与使用边界

- 3 个读取工具：`query_todos`、`query_calendar_events`、`query_task_operations`；10 个写入工具覆盖待办/日程增删改、完成、周期规则、单次实例及撤销。SQL 保留只读。
- 写入一次 1–50 项；每项携带稳定 `requestId`，修改目标使用查询返回的 `taskRef/revision`。不同参数必须使用新请求身份；周期实例使用独立版本，批量完成不同实例不会因自身写入互相冲突。
- 正文没有待办时，可先用 `query_todos(contentId)` 取得 `document` 创建身份和版本。任务定义与周期实例分开查询；实例查询须给日期窗口，最多 366 天。
- 查询默认 20 条、上限 100 条；扫描或来源不完整时返回 `incomplete/warnings`。周期标记是只读投影，按返回的 `taskRef/occurrence` 操作，不把投影编号当作物理日程编号。
- 13 个工具的名称、说明与参数定义序列化为 17,429 字节（约 17 KiB，不是 token 数）；输入 schema 有 32 KiB 回归门限，本地日期校验标记不发送给模型厂商，模型结果与完整 UI 结果分开投影。
- 日程起止精确到分钟，全天 `end` 为不包含的结束日期；无法无歧义表示的夏令时重复时刻明确拒绝。工具不扩大共享正文的写入权限。
- 撤销材料保留 30 天，依赖项目/日历的创建身份和正文位置仍有效才执行；正文已落盘但联动未完成的操作也可撤销。历史无版本卡片只读，重新查询后才能写入。
- 正文中原位移动保持任务身份；剪贴板片段作为新任务插入，清除复制来的身份和实例历史。没有新增全局撤销中心，也没有新增独立重复会议模型。
- 同步信封为版本 5，移动主库 schema 为版本 7；桌面与移动端应一同升级。既有 schema 4–6 按显式升级路径处理，旧同步快照仍拒绝直接覆盖当前数据。
