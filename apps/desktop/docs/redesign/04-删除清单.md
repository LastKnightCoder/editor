## 使用方式

- **追加新页面**：迁移调查完成后，复制 [§模板](#模板--追加新页面章节的骨架) 追加一节，编号带页面前缀（如 `cards-1`），并在索引表、锚点表各加一行。
- **复用老组件**：新页面 import `@/components/` 的老组件（就地换皮口径，03 指南 §6.1）即在该页「明确保留」表登记消费者——不登记，锚点删除时会误伤。
- **删除前复核**：`rg "<符号或路径>" src src-electron` 确认消费者已清零（本文依赖关系是调查当日快照，之后可能漂移）。
- **删除后验证**：每删一批跑 `npx tsc --noEmit` + 相关测试，通过再提交。
- 发现新依赖：先更新本文再动手。
