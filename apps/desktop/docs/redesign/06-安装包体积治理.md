# 安装包体积治理

## 方法与边界

每批只调整一类装箱原因，使用 macOS arm64 本地安装包实测，再提交有收益且验证通过的改动。不删产品能力，不以源码行数推算压缩收益，不修改个人数据库或发布安装包。其他平台仍需在相应平台验证。

MiB 按 1024² 字节计。DMG/ZIP 是压缩体积，ASAR 是应用归档体积，三者不相加。开发依赖仍可被 Vite 编入产物；生产依赖还会被 electron-builder 按依赖关系整包收集。运行时外置依赖不能仅凭名称改为开发依赖。

### 编辑器扩展

- 原因：`@tau/editor-list` 等扩展的生产依赖闭包再次携带 shared、图标库、表情数据和动画库，虽然实际使用代码已经由 Vite 编入产物。
- 修改仅涉及桌面依赖分类与锁文件，各扩展包自己的依赖不变；未清空 node_modules，未升级依赖。
- 验证：22 项编辑器/Markdown 回归、类型、架构门禁、完整构建及 11 项包内原生模块检查通过；归档内八个扩展、react-icons、@emoji-mart/data、@tau/shared 的整包副本退出。

### UI / 主题

- 完整 lucide-react 包原由 `@tau/ui` 生产依赖带入，含约 15.7 MiB source map。两包由 Vite 处理，源码与主题 CSS 仍在构建链中。
- 验证：UI 224 项、themes 48 项测试通过；类型、架构门禁、schema prepare、CLI/桌面构建、11 项包内原生模块检查通过。归档内 lucide-react 和 UI/主题包的独立副本退出。
- 本批 DMG 减少 2.13 MiB，ASAR 减少 20.59 MiB；source map 压缩率高，不能将解压收益当作下载收益。

### 调试映射验收

- files 与 afterPack 统一仅排除 `.js.map` / `.mjs.map` / `.cjs.map`，保留可执行文件、类型声明、文档与普通 `.map` 数据。
- ASAR 少了 2317 个映射文件，共 33.87 MiB；其余依赖文件逐一 SHA-256 对账，新增 0、变化 0，未删除执行代码或资源。回归覆盖嵌套目录、数据映射/二进制保留及重复执行。
- DMG 减少 7.40 MiB，ZIP 减少 7.24 MiB。重新打包后，包内 pi 的 bash、中文路径 write/read、流式事件、插话顺序和单次运行断言全部通过，11 项原生模块检查通过。
- `pi-smoke.mjs` 支持 `TAU_SMOKE_ASAR` 指定包内依赖，使用各包声明的 ESM 入口，不回退开发目录；已接入 verify:native-runtime。检查只在临时目录创建会话及文件，不请求真实模型网关。

### 其余编译依赖

- @hocuspocus/provider、react-query、三个 @tau 协作/协议包、d3-force/quadtree、fuse、两个 remark-cjk 包、tailwind-merge、y-protocols 和 yjs 改为桌面开发依赖；这些能力仍编入前端/主进程产物。归档中 @tau 包、yjs、fuse 的独立副本退出。
- 类型、架构门禁、冻结锁安装、完整构建、包内 pi 及原生模块检查通过；最终桌面完整测试 4684 项通过、3 项跳过、0 失败。曾出现 CodeMirror 环境销毁后的延迟回调错误，单文件 9 项复验及随后完整重跑均通过，未屏蔽异常或放宽断言。

### pi 独立 CLI

- SDK 与桌面未消费独立 `dist/bundle`、`rpc-entry` 或 chord/node。移除 CLI bundle 和 esbuild 两份二进制，但保留 SDK、模型库、chord、类型声明及文档。
- 初次候选错误地连 chord 一起排除，包内 pi 冒烟因 pi-agent-core 的 chord/context 导入失败而阻断；该方案未提交，恢复 chord 后重新打包并通过。边界检查已扩展到 pi-agent-core/ai/tui/telemetry，不再只查 coding-agent 直接入口。
- 构建入口限定已审核 coding-agent 0.87.1，并检查 SDK/桌面对裁剪入口的引用；相关版本/消费者变化时阻断，要求重新审核。回归覆盖间接 SDK 的新增依赖与 chord/context 合法保留。
- 包内真实工具执行、中文路径读写、流事件、插话、TypeScript 文件扩展加载/调用、JSONL 会话身份与内容恢复全部通过，11 项原生模块检查通过。Windows 验证脚本使用系统 PowerShell，避免额外要求构建机安装 Git Bash；本轮实测平台仍为 macOS arm64。
- DMG 减少 9.97 MiB，ZIP 减少 9.61 MiB；ASAR 中 CLI bundle 与 esbuild 已不存在，chord 保留。

### 分词词典单一来源

- `@node-rs/jieba/dict` 显式 external，保留包内 dict.txt/idf.txt；删除 Vite 复制插件、extraResources 重复拷贝和旧 require.resolve 劫持。主库、PDF、Notebook 的分词实现继续使用相同字节的原词典。
- 构建产物明确引用 `@node-rs/jieba/dict`；ASAR 主进程目录和 Resources 根目录均无重复词典，包内词典仍在。
- 真实词典验证加载 dict/idf，检查“南京市长江大桥”包含“南京市”和“长江大桥”，不能以空词典也能切出字符作为通过标准；包内 Tau CLI --help 也纳入验证，依赖路径与安装启动器一致。
- 本批 DMG 从 261.21 降至 253.35 MiB，ZIP 从 253.98 降至 246.63 MiB，ASAR 从 164.21 降至 153.46 MiB；类型、架构门禁、完整构建、包内 pi/CLI/原生模块验证通过。

## 最终保留边界

最终桌面完整测试 4684 项通过、3 项跳过、0 失败；CLI 同步测试 20 项通过，两个打包边界回归通过。类型与架构门禁、当前源码完整构建、包内 pi/真实词典/CLI/原生模块检查通过。六批 DMG 累计减少 62.71 MiB（约 19.84%），ZIP 减少 59.65 MiB，app.asar 减少 230.20 MiB；本地旧版 0.53.3 DMG 为 253.22 MiB，仅作历史比较。

保留 Electron、全部模型 SDK、pi SDK/chord 上下文/动态扩展/文档、正常原生推理与媒体工具、字体和产品媒体资源。没有通过删除产品能力或默认关闭功能减小体积。原生运行时约占大头，继续激进裁剪需要单独审核相应功能与平台，不能沿用本轮收益推算。

本轮未做视觉验收、未安装或发布应用、未访问个人数据库；实测为 macOS arm64，不宣称已执行 Windows/Linux 原生运行验证。

## 安装后启动时序修复（2026-10-01）

用户安装后遇到“数据库连接失败”启动屏。会话日志显示主进程开库、聊天迁移与索引就绪均成功；壳层却在设置同步完成前报告“未找到已初始化的数据库配置”。AppShell 原先只在挂载时连接一次，缓存已有库名时，后续 inited 变为 true 不会重建壳层或重试。

壳层改为订阅设置初始化状态，就绪后再连接，保留真实连接失败及手动重试。新增真实 AppShell 与 ensureDatabaseReady 接线回归，覆盖缓存库名不变、设置延迟就绪、真实 IPC 失败及重试。此前包内原生/pi/CLI 冒烟不能证明渲染端启动时序正确，不能再以它们代替该回归。

新增三项启动回归通过，包含设置完成后切库重连；类型、架构门禁、桌面完整构建和新安装包的 pi/CLI/原生模块验证通过。仅读取启动日志，未改个人数据库；安装后界面仍由用户验收。

用户随后确认修复版运行正常，启动问题关闭。此确认不扩大为跨平台、全部界面或所有历史数据格式的验收结论。
