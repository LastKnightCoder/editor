闪卡用来记住那些需要记住的东西：一个概念的定义、一个公式、一个英文单词。你只管认真回答每一张，Tau 会根据你记得牢不牢安排下次什么时候再看：记得牢的隔很久才出现，记不住的很快就会回来。

## 复习

侧边栏「闪卡复习」旁的数字，就是今天需要复习的卡片数。进入后可以看到今天的复习量和预计用时，点击「开始复习」，所有卡组的到期卡片会排成一个队列。只想复习某一个卡组时，点击上方的卡组名，再点击「复习 N 张」。

::demo{name="flashcards" caption="第一张是填空题，输入答案后按回车；第二张是问答题，按空格显示答案；看到答案后按 1–4 评分"}

每种题型的作答方式不同：

| 题型 | 怎么答                                                                 |
| ---- | ---------------------------------------------------------------------- |
| 问答 | 先在心里或输入框里作答，再按 <kbd>空格</kbd> 显示答案                  |
| 填空 | 在空格里输入答案，按 <kbd>↵</kbd> 提交；有多个空时，回车会跳到下一个空 |
| 单选 | 按 <kbd>A</kbd>–<kbd>F</kbd> 选择，选中即提交                          |
| 多选 | 按字母键勾选选项，再按 <kbd>↵</kbd> 提交                               |
| 判断 | 按 <kbd>A</kbd> 选「正确」，按 <kbd>B</kbd> 选「错误」                 |

不会的题，点击「不会，看答案」直接翻面。卡片设置了提示时，题目下方会有「显示提示」。翻面后会显示答案、解析和参考资料。

### 评分

看到答案后，诚实地告诉 Tau 你记得怎么样：

| 评分 | 按键 | 适用情况         |
| ---- | ---- | ---------------- |
| 忘记 | 1    | 完全想不起来     |
| 模糊 | 2    | 想起来了但很吃力 |
| 记得 | 3    | 正常想起来       |
| 轻松 | 4    | 立刻就想起来     |

每个按钮下方写着选它之后多久再复习。带彩色边框的是推荐评分，按 <kbd>空格</kbd> 或 <kbd>↵</kbd> 直接采用：客观题答对推荐「记得」，答错推荐「忘记」。

问答题没有标准的对错。如果你在输入框里写了答案，并且配置了 AI 模型，Tau 会让 AI 对照参考答案打分，列出亮点、遗漏和建议，再据此推荐评分。

### 复习时的快捷键

| 操作             | 快捷键                                          |
| ---------------- | ----------------------------------------------- |
| 编辑当前卡片     | <kbd>E</kbd>                                    |
| 暂停这张卡片     | <kbd>S</kbd>                                    |
| 撤销上一张的评分 | <kbd>⌘Z</kbd>（Windows 上为 <kbd>Ctrl+Z</kbd>） |
| 结束复习         | <kbd>Esc</kbd>                                  |

一轮结束后，会显示这一轮复习了几张、记住的比例（「记得」和「轻松」的占比）和用时。中途结束也没关系，没复习的卡片会留在队列里。

## 复习间隔是怎么算的

Tau 用的是 FSRS 记忆算法。不用了解公式，记住一个原则就够了：**它会在你差不多快要忘记的时候，安排你再看一次。**

每张卡片都有一个「稳定性」，可以理解为这段记忆能撑多少天。每次评分后，Tau 会更新稳定性，再算出下次复习的时间，目标是到那一天你还有九成把握记得它。

以一张新卡为例，第一次复习的评分大致决定了下一次的间隔：

| 评分 | 下次复习    |
| ---- | ----------- |
| 忘记 | 约 5 小时后 |
| 模糊 | 约 1 天后   |
| 记得 | 约 2 天后   |
| 轻松 | 约 8 天后   |

如果之后每次都答「记得」，间隔会越拉越长，大约是 2 天、11 天、一个半月……一张卡片记熟以后，几个月才需要看一次。反过来，一旦答「忘记」，它会很快重新出现，从头巩固。

:::tip{title="评分要诚实"}
算法只能根据你的评分判断记忆状态。明明很吃力却点了「轻松」，这张卡会隔很久才出现，到时候多半已经忘了。拿不准时，就选推荐评分。
:::

:::info{title="每天复习一点，比攒着一起复习好"}
到期没复习的卡片会显示「逾期」，它们不会消失，会一直排在队列前面。但拖得越久，忘掉的越多。每天花几分钟清掉当天的队列，是让闪卡起作用的关键。
:::

## 制作闪卡

### 先建一个卡组

闪卡都归属于卡组。点击闪卡复习页右上角的「新建卡组」图标，填写名称（比如「操作系统」「英语词汇」）、选择图标和颜色，描述可选。卡组的颜色只用于区分，不影响复习。

### 新建闪卡

点击「新建闪卡」，或在闪卡复习页按 <kbd>N</kbd>。在弹出的窗口中：

1. 在顶部选择题型：问答、填空、单选、多选、判断。
2. 填写题干，再按题型填写答案（写法见下文）。
3. 在右侧选择卡组，可以设置难度（基础、常规、进阶）和标签。
4. 按 <kbd>⌘↵</kbd>（Windows 上为 <kbd>Ctrl+↵</kbd>）保存；按 <kbd>⌘⇧↵</kbd>（Windows 上为 <kbd>Ctrl+Shift+↵</kbd>）保存并接着新建下一张。

每种题型都可以选填三项附加内容：

- **补充说明**：背景、限定条件等，复习时显示在题干下方。
- **提示**：一句话线索，复习时点击「显示提示」才出现。
- **解析**：为什么是这个答案，翻面后显示。

还可以点击「参考资料」旁的「+ 添加」，引用一篇已有的内容，或直接写一段自定义内容。复习翻面后可以展开查看。

### 各题型怎么写

**问答**：题干写问题或要记住的词条，「参考答案」写标准答案或要点。

```text
题干：什么是注意力残留？
参考答案：从一件事切换到另一件事时，部分注意力仍停留在上一件事上，导致新任务的表现下降。
```

参考答案写成要点，AI 评判时会更准确。

**填空**：先把整句话写进题干，再选中要挖掉的词，点击题干下方的「标记为空格」。被标记的文字会变成一个空，选中的文字自动成为正确答案。一道题可以挖多个空。

::demo{name="cloze-editor" caption="选中题干里的「间隔重复」，点击「标记为空格」；再点空格上的 ⚙️，添加备选答案「spaced repetition」"}

点击空格上的 ⚙️ 可以修改设置：

- **正确答案**：默认是你选中的文字，可以改。
- **备选答案**：同样算答对的其他写法，比如同义词、英文原词。
- **提示文本**：显示在空格旁边的小字，比如「人名」「年份」。

判分时会忽略首尾空格和英文大小写，其余必须和正确答案或某个备选答案一致。所以挖空时尽量挖短而明确的词，别挖一整句话。想取消一个空，选中它再点一次「标记为空格」。

**单选和多选**：填写至少两个选项，点击选项前的字母标记正确答案，最多六个选项。单选只能有一个正确答案，多选可以有多个。

**判断**：题干写一个陈述，答案选「正确」或「错误」。

```text
题干：复习间隔应该固定不变，比如每三天复习一次。
答案：错误
解析：间隔应随记忆巩固逐渐拉长。
```

:::tip{title="一张卡只考一件事"}
「操作系统的进程调度有哪些算法，各自的优缺点是什么？」这样的题，复习时很难评分。把它拆成几张小卡：每张只问一个算法，答案一两句话就能说清。小卡更容易记住，评分也更准确。
:::

### 从笔记制作闪卡

读书笔记和文章里的知识点，可以直接做成闪卡，不用从头敲一遍：

- **手动制卡**：在卡片、文章或项目文档详情页的「⋯」菜单中，选择「生成 › 手动制卡（闪卡）」。选好卡组后打开新建窗口，这篇内容会自动作为参考资料。
- **AI 制卡**：同一个菜单里选择「AI 制卡（闪卡）」，AI 会读这篇内容，生成一批不同题型的闪卡。你可以逐张查看、编辑，勾选想要的，点击「添加 N 张闪卡」。
- **漫步时制卡**：在 [漫步](/docs/walk/) 中遇到值得记住的旧内容，点击「做成闪卡」。

AI 制卡需要先连接 AI 模型，详见 [AI 对话与洞见](/docs/ai/)。

## 管理卡组和闪卡

闪卡复习页的上方是一排卡组。「今日总览」列出所有卡组的待复习数、各状态的卡片数和未来 7 天的到期量；点击一个卡组，查看它的全部卡片。

每张卡片都有一个状态，可以按状态和题型筛选：

| 状态   | 含义                               |
| ------ | ---------------------------------- |
| 新卡   | 刚创建，还没复习过                 |
| 学习中 | 刚学不久，间隔还不到一天           |
| 巩固   | 已经记住，间隔在一天以上           |
| 已暂停 | 不再进入复习，恢复后回到原来的状态 |

常用操作：

- **编辑、暂停、移动、删除闪卡**：右键点击卡片。修改内容不影响复习进度。删除后可以在提示中撤销。
- **编辑或删除卡组**：右键点击上方的卡组名，或在卡组页点击「卡组操作」。删除卡组会一并删除其中所有闪卡和复习记录，无法撤销。
- **查看统计**：点击右上角的「概况」，查看近 7 天的评分分布和未来 7 天的到期量；在卡组页中，还能看到卡片构成、题型分布和累计复习次数。

:::detail{title="什么时候该暂停一张卡？"}
有些卡片已经过时，或者你发现题目本身有问题、暂时不想改，又不想删掉，就可以暂停。暂停的卡片不会出现在复习队列里，复习记录也会保留，以后随时可以「恢复复习」。
:::
