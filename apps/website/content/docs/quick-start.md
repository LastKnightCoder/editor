花五分钟，把读书时的一个想法记成卡片，再写第二张卡片引用它。做完你就会用 Tau 最常用的几件事：记一笔、打标签、把内容连起来。

假设你正在读《深度工作》，读到一句很有感触的话：「专注是可以练习的，像肌肉一样越用越强。」下面就用它做例子。

## 写第一张卡片

卡片适合记一个想法、一段读书感想。它不需要标题，也不用先想好放进哪个文件夹。

1. 在左侧边栏点击「卡片库」，再点击右上角的「新建卡片」。
2. 在弹出的窗口里写下「专注是可以练习的，像肌肉一样越用越强」。
3. 点击「添加标签」，输入「读书」后按 <kbd>↵</kbd>。
4. 点击「保存」，卡片就出现在卡片墙的「今天」分组里。

一张卡片可以有多个标签，点击标签上的 × 可以去掉。标签还能分层：写 `读书/深度工作`，侧边栏「卡片库」下方会出现「读书」，展开后是「深度工作」；点击「读书」时，它下面所有子标签的卡片都会显示出来。刚开始不必纠结怎么起名，先用几个宽泛的，比如「读书」「工作」「随想」，用多了自然知道哪里要细分。

:::tip{title="随时随地记一笔"}
不在 Tau 窗口里也能记：按 <kbd>⌘⇧N</kbd>（Windows 上为 <kbd>Ctrl+Shift+N</kbd>）会弹出一个置顶的速记窗口，写完直接关掉即可，内容自动保存。
:::

## 写第二张卡片，引用第一张

读到下一章，作者说切换任务后，注意力会有一部分留在上一件事上。这和第一张卡片说的是一回事：专注要练，也要护着。把它记下来，并连到第一张：

1. 再点一次「新建卡片」，写下「频繁切换任务，注意力会残留在上一件事上」。
2. 接着输入 `@`，列表里会出现最近写的内容。输入「专注」筛选，用 <kbd>↑</kbd> <kbd>↓</kbd> 选中第一张卡片，按 <kbd>↵</kbd> 插入。输入 `[[`（中文输入法下为 `【【`）也能打开同一个列表。
3. 同样加上「读书」标签，点击「保存」。

::demo{name="first-card" caption="在弹窗里写一句，输入 @ 选一篇引用，再点「添加标签」输入「读书」后按回车，最后点「保存」"}

第二张卡片里多了一个链接，鼠标悬停可以预览，点击可以打开。打开第一张卡片，你会看到第二张提到了它。写得越多，这样的连接越多：它们会画在 [知识地图](/docs/walk/) 上，[漫步](/docs/walk/) 时也会顺着它们带你去看相关的内容。

## 在「今日」看看

点击侧边栏最上方的「今日」。这是每次打开 Tau 首先看到的页面：

- 顶部一行是今天的数字：已专注多久、写了多少字、新建了几条、连续活跃了几天；
- 「最近编辑」里能看到刚写的两张卡片，点一下就能回去接着改；
- 等你有了待办、日程和闪卡，它们也会汇总在这里。

更多用法见 [今日](/docs/today/)。

## 可选：把要记住的做成闪卡

想长期记住「注意力残留」这个概念，可以把它做成闪卡，让 Tau 按遗忘规律提醒你复习。

1. 在卡片库里点击第二张卡片，再点击右上角的「进入详情」。
2. 点击右上角的「⋯」，选择「生成 › 手动制卡（闪卡）」。
3. 第一次制卡时先新建一个卡组，例如「读书」，然后填写题目「什么是注意力残留？」和答案。

到了该复习的日子，侧边栏「闪卡复习」旁会显示数字，「今日」的「复习」面板里也能看到。详见 [闪卡复习](/docs/flashcards/)。

## 可选：让 AI 帮你想下一步

Tau 不内置模型，AI 要先接入你自己的模型服务商。AI 没有总开关，但也不是添加完模型就能用：哪项功能分配了模型，哪项才能用。

1. 按 <kbd>⌘,</kbd>（Windows 上为 <kbd>Ctrl+,</kbd>）打开设置，进入「AI 服务 › 大语言模型」，点击「添加服务商」，选一个服务商并填入它给你的 API Key（相当于你在服务商那里的账号密码），再点「选择模型」勾选一个模型。
2. 切到「功能分配」，给「对话功能」选上这个模型。也可以跳过这一步，在对话输入框下方点「选择模型」直接指定。
3. 按 <kbd>⌘J</kbd>（Windows 上为 <kbd>Ctrl+J</kbd>）打开对话栏，试着说一句「看看我标了『读书』的卡片，围绕专注还可以读点什么？」

想让 AI 帮你出闪卡，在「功能分配」里给「闪卡」也选上模型，卡片详情的「⋯ › 生成」里就能用「AI 制卡（闪卡）」。完整说明见 [AI 对话与洞见](/docs/ai/)。
