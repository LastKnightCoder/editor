「今日」是打开 Tau 后看到的第一页。它把今天要做的、要复习的和最近写过的放在一张纸上，你不用挨个页面去找，看一眼就知道今天从哪里开始。

## 页面里有什么

::demo{name="today" caption="点任意一行，看它会带你去哪里；在「今日漫步」里点「下一张」翻牌；点右上角的图标进入调整，隐藏或恢复面板"}

最上面一行是今天的数字：已专注多久、写下多少字、新建了几条内容、连续活跃了几天。点击「已专注」会打开 [番茄专注](/docs/pomodoro/)。

下方是一组面板，每一行都可以点击，直接打开对应的那一条：

| 面板     | 显示什么                                     | 点击后                                                |
| -------- | -------------------------------------------- | ----------------------------------------------------- |
| 复习     | 每个卡组今天到期的闪卡数                     | 进入 [闪卡复习](/docs/flashcards/)                    |
| 待办     | 最紧急的几条未完成待办，逾期的标红           | 在待办页打开这一条的详情                              |
| 日程     | 今天的日程，按时间排列                       | 在日程页打开这一条                                    |
| 洞见     | AI 发现的呼应、矛盾和问了却没写下来的问题    | 在知识地图上点亮那一处，见 [AI 对话与洞见](/docs/ai/) |
| 最近编辑 | 最近改过的卡片、文章、日记和项目文档         | 打开对应内容，接着写                                  |
| 今日漫步 | 每天 5 张以前写过的内容                      | 打开原文，或进入 [漫步](/docs/walk/)                  |
| 回顾     | 全年活动热力图、写作趋势、记忆保持、专注节律 | 可切换近 30 天、近 90 天、今年和全部                  |

「复习」「待办」「日程」三块的标题右侧各有一个「前往…」，点击可以进入完整的页面。

## 典型的一天

**早上打开 Tau**，先看「待办」和「日程」：红色的是已经逾期的，处理掉或者改个日期；再看看今天有哪些会。要开始做事时，从顶部点「已专注」进入番茄专注，选一条待办开始计时。

**午休或通勤的空档**，看一眼「复习」面板。哪个卡组有到期的卡片，就点它直接开始复习，十几张卡片几分钟就能做完。

**晚上收尾**，翻一翻「今日漫步」。它每天会从你以前的卡片、文章和日记里抽 5 张，并告诉你为什么选它，比如「143 天没见过它了」或「那年今日」。

- 点击「下一张」（或聚焦牌堆后按 <kbd>→</kbd>）翻到下一张；
- 点击牌面打开原文；
- 想顺着这一条看相关内容，点击「从这里继续走」；
- 不想再看到某一条，点击「别再出现」；
- 5 张翻完后，可以「再抽 5 张」，第二天会换一叠新的。

**过一段时间**，往下滚到「回顾」，看看这个月写了多少、哪些闪卡记得牢、一天里什么时段最专注。

## 调整首页

不常用的面板可以隐藏，常用的可以挪到前面。点击右上角的「调整首页」图标进入调整状态：

1. 按住面板任意位置拖动，可以调整顺序。
2. 点击面板右上角的隐藏按钮，或把面板拖到底部的「已隐藏」区域，即可隐藏。
3. 点击「已隐藏」里的面板，它会回到末尾；也可以把它拖到想放的位置。
4. 调整好后点击「完成」。

想回到初始布局，点击「恢复默认」。按 <kbd>Esc</kbd> 退出调整状态。

布局跟着笔记库保存。安装的插件也可以在首页添加面板，默认排在内置面板之后，同样可以拖动和隐藏。

:::tip{title="有些面板要等有内容才出现"}
「洞见」需要先连接 AI 模型，「今日漫步」需要你写过一些内容，在那之前它们不会显示。调整首页时，暂时没有内容的面板显示为「今天没有内容」的占位，照样可以排序和隐藏。
:::
