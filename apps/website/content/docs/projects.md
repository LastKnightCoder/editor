项目用来把一个主题整理成一套文档，例如一门课的笔记、一个研究方向或一份个人手册。每个项目是一棵文档树：文档下面可以再挂子文档，层级和顺序随时可以调整。

比如你在学「如何学习」：建一个「学会学习」项目，下面分「基础」「方法」两组，每种方法写一篇文档；再放一块白板画方法全景图、一张表格记录每周的实践。所有材料都在一棵树里，打开就能接着看。

## 项目列表

在侧边栏点击「项目」。网格视图下，页面顶部的「最近打开」显示最近看过的三个项目，每张卡片标着「上次看到」的文档，点击直接从那里继续；下方「全部」列出所有项目。

- **新建项目**：点击「新建项目」，填写名称（比如「学会学习」）和描述（可选），创建后直接进入项目。
- **排序与视图**：右上角可以按最近打开、最近更新、名称或创建时间排序，置顶的项目始终排在最前；旁边的按钮在「网格」和「列表」之间切换。列表视图会多出文档数、上次打开时间等列。
- **置顶与管理**：鼠标悬停在项目卡片上，点图钉置顶；点「⋯」可以编辑信息、归档、整体导出或删除。
- **归档**：暂时不用的项目可以归档，它会移到页面底部的「已归档」里，需要时点「取消归档」恢复。

:::tip{title="把一整个文件夹变成项目"}
把装着 Markdown 文件的文件夹或 .zip 拖到项目页上，可以导入为一个新项目，原来的目录结构会保留成文档树。
:::

## 文档树

::demo{name="projects" caption="点击文件夹展开或收起，点击文档在右侧打开；点击文档树顶部的视图按钮切换到思维导图"}

打开项目后，左侧是文档树，右侧是正文。

### 添加内容

点击文档树顶部的「+」，在项目根部添加内容；鼠标悬停在某一行上，行尾也会出现「+」，在这一行下面添加子内容，菜单相同。以「学会学习」为例：

| 你想做的                                  | 选哪一项                                                                                  |
| ----------------------------------------- | ----------------------------------------------------------------------------------------- |
| 在「方法」下为费曼技巧写一篇文档          | 在「方法」行上点「+」，选「添加文档」                                                     |
| 画一张学习方法的全景图                    | 「添加白板」新建一块 [白板](/docs/whiteboard/)；已经画好的，用「关联白板」挂过来          |
| 每周记录用了哪些方法、效果如何            | 「添加表格」，用法同 [数据库](/docs/database/)                                            |
| 边看《Learning How to Learn》课程视频边记 | 「添加视频」，选本地视频、远程视频，或已安装的视频插件，见 [视频笔记](/docs/video-notes/) |
| 收一篇讲间隔重复的网页文章，在 Tau 里读   | 「添加网页」                                                                              |
| 读一篇讲提取练习的论文 PDF                | 「添加 PDF」，可以选本地 PDF、远程 PDF，或「关联已有 PDF」                                |
| 卡片库里已经写过几张学习方法的卡片        | 「关联卡片」把它们挂到树上，两边是同一份内容，在哪边改都同步                              |
| 以前在别的软件里写过学习笔记              | 「导入Markdown」，每个文件成为一篇文档                                                    |

### 调整结构

按住一行拖动，就可以调整位置。放下的位置决定了它去哪里：

- 拖到另一行的上边缘或下边缘，会排在那一行的前面或后面；
- 拖到另一行的中间，会变成那一行的子文档。比如把「费曼技巧」拖到「方法」中间，它就归到「方法」下面。

有子文档的行前面有一个小箭头，点击可以展开或收起。

### 每一行的「⋯」菜单

文档行的「⋯」菜单和卡片详情页的相同，各项的用途见 [卡片](/docs/cards/) 篇末的「更多操作」。区别有两处：没有「添加连接」；「生成」里多一项「建立卡片」，把这篇文档同时存进卡片库，之后两边是同一份内容。最后一项是「删除文档」。安装「播客」插件后，菜单里同样会多出「生成播客」。

白板、视频、网页、PDF 的行菜单里可以「编辑标题」或删除。

文档的标题在正文上方直接修改。点击文档树左上角的房子图标回到项目列表，点击项目名可以切换到其他项目。

## 思维导图视图

文档树也可以用思维导图的形式查看。点击文档树顶部右侧的视图按钮（提示为「切换到思维导图」），整棵树会以项目名为中心横向展开。「学会学习」的「基础」「方法」两组和每种方法一眼就能看全，适合检查哪一块还没写。

在思维导图里：

- **打开文档**：点击一个节点，右侧打开对应的文档；
- **改名**：双击节点直接修改标题；
- **添加子内容**：鼠标悬停在节点上，点外侧的「+」，菜单与文档树的「+」相同；
- **调整结构**：拖动节点到另一个节点旁边或上面，可以调整顺序或层级；
- **更多操作**：右键点击节点，打开与「⋯」相同的菜单；
- **收起分支**：点击节点旁的折叠按钮，收起或展开它的子节点；
- **移动画布**：拖动空白处或滚动滚轮平移，按住 <kbd>⌘</kbd>（Windows 上为 <kbd>Ctrl</kbd>）滚动滚轮缩放。

再点一次视图按钮回到树视图。下次打开这个项目时，会停留在上次的视图和位置。

## 写项目文档

项目文档的写法与 [文章](/docs/articles/) 一样：支持 [编辑器](/docs/editor/) 的全部块，也可以引用卡片、使用创作模式、制作闪卡。

在项目文档里输入 `/`，还会多出一个「项目列表」：它把当前文档的子文档列成一组卡片，适合给一个章节写目录页。比如在「方法」这篇文档里插入项目列表，费曼技巧、间隔重复、提取练习就排成一页目录。

:::info{title="项目回顾"}
为「AI 洞见」分配模型后，项目名旁会出现「回顾」按钮。点开后，AI 会读这个项目和项目外的笔记，告诉你最近长了什么、哪些笔记可能属于这里、哪里还写得薄。比如你在卡片库里写过一张讲番茄工作法的卡片，回顾会提示它可能属于「方法」。归档的项目可以做「结项回顾」，总结留下的核心观点。设置模型的方法见 [AI 对话与洞见](/docs/ai/)。
:::

点击标题栏左侧的侧栏按钮可以收起文档树，只留正文。

项目里的白板怎么画，见 [白板](/docs/whiteboard/)；视频怎么边看边记，见 [视频笔记](/docs/video-notes/)。
