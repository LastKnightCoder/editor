Tau 的 AI 读得到你的卡片、文章、日记、待办和读书划线。你可以让它查资料、做总结、改写正在写的内容、安排待办，也可以让它把一篇笔记和你写过的其他内容对照着读，指出哪里能连起来、哪里互相矛盾。

## 连接模型

使用 AI 之前，需要先接入一个模型服务商。Tau 不内置模型，你用自己的 API Key，内容只发给你配置的服务商。

::demo{name="llm-setup" caption="点击「添加服务商」，选 DeepSeek 并填入 API Key，再点「选择模型」勾选模型，最后到「功能分配」里指定给各项功能"}

1. 点击侧边栏底部的「设置」，或按 <kbd>⌘,</kbd>（Windows 上为 <kbd>Ctrl+,</kbd>），进入「AI 服务 › 大语言模型」。
2. 在「服务商与模型」中点击「添加服务商」。列表里有的服务商（如 DeepSeek、OpenAI、Anthropic）直接选中，只需填入 API Key；列表里没有的，选「其他服务商」，填写名称、Base URL 和接口类型（多数服务选「OpenAI 兼容」）。
3. 点击「创建」后，在「模型」一栏点击「选择模型」，勾选要用的模型并保存。列表里找不到的模型，可以点「手动添加」，填写服务商给出的模型 ID。
4. 切到「功能分配」，为「对话功能」以及标题总结、网页剪藏、AI 洞见、闪卡等功能分别选择模型。

:::warning{title="记得做第 4 步"}
AI 没有总开关，但添加模型后不会自动分配给任何功能，哪项功能分配了模型，哪项才能用。「功能分配」标签上的数字是还没分配模型的功能数。比如「AI 洞见」没有模型时，内容页里不会出现洞见按钮。对话功能也可以直接在对话输入框下方点「选择模型」来指定。
:::

各项功能可以用不同的模型：对话和洞见选能力强的，标题总结、网页剪藏这类简单任务选便宜快速的。「用量统计」里可以按模型、功能或服务商查看调用次数、Token（模型按它计算用量和费用，大致和字数成正比）和预估费用。

### 让 AI 按意思找内容

你问「我还在哪些地方写过注意力残留」时，就算原文用的是「切换任务后心还留在上一件事上」，AI 也能找到它，靠的是嵌入模型。它在「设置 › AI 服务 › 嵌入模型」里选：

- **本地模型**：下载后在本机离线运行，不产生费用。写完或改完内容，它会在后台自动跟上。
- **插件提供的云端模型**：先在 [插件](/docs/plugins/) 中安装嵌入插件（如「OpenAI 嵌入」），在插件详情的「设置」里填好账号，再回到这里选一个模型点「设为当前」。云端模型按用量收费，所以不会自动更新，新写或改过的内容需要你在「当前生效」里点「立即索引」。

换嵌入模型时需要确认：不同模型的结果不能混用，确认后 Tau 会清掉原来的索引，在后台重新建一遍。

### 图片、朗读与播客

| 想做的               | 怎么准备                                                                                         |
| -------------------- | ------------------------------------------------------------------------------------------------ |
| 在对话里生成、改图片 | 安装图片生成插件，在插件详情的「设置」里添加账号，再到「设置 › AI 服务 › 图片生成」选用          |
| 朗读正文             | 安装语音插件（如 MiniMax 语音），在插件详情里添加账号，再到「设置 › AI 服务 › 语音」选服务和音色 |
| 生成播客             | 在上一行配好语音的基础上，安装「播客」插件，在插件详情的「AI 配置」里给「播客脚本」选一个模型    |

播客怎么生成、在哪里听，见插件中心里「播客」的介绍页；在 Notebook 里生成播客见 [Notebook](/docs/notebook/)。

### 语音输入

在手机上，搜索、对话和编辑器里都可以按住说话。在「我的 › 语音输入」里选识别方式：

- **系统识别**：用手机自带的识别服务，不需要另外配置。
- **云端识别**：安装语音识别插件（如豆包语音）并填好账号，录音会发送到这个服务。

打开「AI 整理文本」后，说完的话会先交给模型补标点、去掉口头禅，再填进输入框，可以选「轻度整理」或「整理并分段」，还能补一句要求，比如保留英文缩写。它用的是「功能分配」里「语音输入整理」的模型，整理失败时保留原话。电脑上的「设置 › AI 服务 › 语音 › 语音输入」是同一套选项，供需要按住说话的插件使用。

## AI 对话

点击侧边栏的「AI 对话」打开对话页。在任何页面按 <kbd>⌘J</kbd>（Windows 上为 <kbd>Ctrl+J</kbd>），右侧会弹出对话栏，边看内容边聊，再按一次收起。输入完按 <kbd>⌘↵</kbd>（Windows 上为 <kbd>Ctrl+Enter</kbd>）发送。

::demo{name="chat" caption="点一句示例，看 AI 怎样查资料、改写内容、添加待办；改写时点「确认应用」，加待办时点「允许」，右上角的新对话按钮可以换一句"}

### 可以对 AI 说什么

用平常说话的方式描述你要什么就行。AI 会自己判断要查哪些内容、用哪个工具。下面是几类常见的说法：

| 你想做的       | 可以这样说                                                                 |
| -------------- | -------------------------------------------------------------------------- |
| 查找和回顾     | 「我读过的书里，关于专注有哪些观点？」「上个月我写过哪些关于写作的卡片？」 |
| 整理和总结     | 「把我关于间隔重复的卡片整理成一份提纲」「把这几张卡片画成思维导图」       |
| 改写正在写的   | 「把这段改得更精炼，别改标题」「帮我检查这篇文章的错别字」                 |
| 安排待办和日程 | 「明天下午三点提醒我写第三季度复盘」「把这周没完成的待办都改到下周一」     |
| 统计和查询     | 「这个月我新建了多少张卡片？」「读书清单数据库里还有哪些书没读完？」       |

比如你在读《深度工作》，写了几张卡片和一篇读书笔记。打开读书笔记，按 <kbd>⌘J</kbd> 问「我还在哪些地方写过注意力残留？」，AI 会搜索你的资料库，在回答里列出相关的卡片和划线，点击引用就能打开原文。接着说「把第二段改得更口语一些」，它会直接改你正在看的这篇。

:::info{title="AI 不会新建卡片或文章"}
AI 可以修改已有的内容，但不会替你新建卡片和文章。让它「整理成一篇文章」时，它会把结果写在回复里，你可以复制到新文章中，或者先新建一篇空文章，再让它往里写。
:::

### 让 AI 看到你说的内容

AI 能感知你当前打开的页面、正在编辑的内容和选中的文字，所以「这段」「这篇」「光标这里」它都听得懂。想让它参考别的内容时：

- **引用**：在输入框里输入 `@`，搜索并选择一张卡片、一篇文章或一篇项目文档；
- **拖入**：把内容直接拖到对话里；
- **附件**：点击输入框左侧的「+」，添加图片或文件。图片也可以直接粘贴，文件需小于 50MB。

### 修改前先问你

AI 读取内容时直接执行，修改内容前会先征得你的同意。输入框下方的「工具权限」决定问不问：

| 模式         | 修改内容 | 执行脚本、命令或网络请求 |
| ------------ | -------- | ------------------------ |
| 手动确认     | 先问你   | 先问你                   |
| 自动允许编辑 | 直接生效 | 先问你                   |
| 跳过确认     | 直接执行 | 直接执行                 |

在「手动确认」下，你会看到两种确认方式：

- **改写正文**时，对话里出现一张「请确认这次修改」的卡片，可以在「改动高亮」和「完整内容」之间切换查看。点「确认应用」写入，点「提修改意见」告诉 AI 怎么调整，点「拒绝」放弃。应用之后，还可以点 ↺ 撤销这次修改。
- **其他修改**（例如添加待办）时，出现「AI 想要修改内容，需要你确认」，可以选「允许」「本会话始终允许」或「拒绝」。待办改好后，结果卡片上也有「撤销」按钮。

### 调整回答方式

- **选择模型**：点击输入框下方的模型名，可以临时换一个模型，同时会改掉「功能分配」里对话功能的模型。
- **思考强度**：从「立答如流」到「极尽推演」共七档。简单问题用低档回答更快，复杂的分析和多步骤任务用高档。
- **使用 Skill**：输入 `$` 选择一个 Skill，AI 会按它写好的做法处理这条消息，详见 [Skill 与 MCP](/docs/skills-mcp/)。
- **插话**：AI 回答到一半时，输入补充信息并按 <kbd>⌘⇧↵</kbd>（Windows 上为 <kbd>Ctrl+Shift+Enter</kbd>），它会在当前这一步结束后读到，不用等整轮回答结束。

### 管理对话

把鼠标移到一条消息上，可以复制、编辑或删除它，也可以重新生成回答。编辑后的消息会生成一个新版本，用 ‹ › 在版本间切换。点「从这里创建分支」，可以从某条消息开始换个方向继续聊，原来的对话不受影响。

侧边栏「AI 对话」下方列出置顶和最近的会话，点「全部会话」可以给对话重命名、置顶、分组或归档。

## AI 能做到哪些事

AI 每读一次或改一次内容，对话里都会显示一行操作记录，点击可以展开查看它查了什么、得到了什么。

| 你想让它做的         | 例子                                                         | 会不会先问你         |
| -------------------- | ------------------------------------------------------------ | -------------------- |
| 找你写过、读过的内容 | 卡片、文章、项目文档、日记，以及读书划线、PDF 标注、剪藏网页 | 不问                 |
| 理解「这段」「这篇」 | 知道你在看哪个页面、选中了哪段文字、打开了哪条待办           | 不问                 |
| 改写正在写的内容     | 改一段、改整篇、查错别字                                     | 修改时问             |
| 安排待办和日程       | 新建、改期、完成、删除，改完可以撤销                         | 修改时问             |
| 统计和查数据库       | 「这个月新建了多少张卡片」「读书清单里还有哪些没读完」       | 不问，只读不改       |
| 打开网页看内容       | 读一篇你给的链接，或查一个网页上的信息                       | 问                   |
| 看图、生成图片       | 读你给的图片；装了图片生成插件后，还能生成和修改图片         | 不问                 |
| 按 Skill 的做法办事  | 读 Skill 的说明，运行 Skill 附带的脚本                       | 运行脚本时问         |
| 处理你电脑上的文件   | 在工作目录里读写文件、运行命令                               | 写文件和运行命令时问 |

这些能力都随 Tau 提供，在侧边栏「MCP 服务器」的「内置」分组里可以看到全部，不需要的可以关掉。想让 AI 用上 Tau 之外的工具，见 [Skill 与 MCP](/docs/skills-mcp/)。

在 PDF 阅读页、[视频笔记](/docs/video-notes/) 和 [Notebook](/docs/notebook/) 里打开对话时，AI 还能直接读当前这份资料：按页读 PDF、查它的目录和批注，按时间段读视频字幕，在 Notebook 的全部资料里找答案。

:::detail{title="工作目录是什么"}
AI 读写文件、执行命令的位置叫工作目录，默认是 Tau 的应用数据目录。在输入框上方可以为当前对话换一个文件夹，比如你的项目文件夹；如果它是 Git 仓库，还会显示当前分支。新对话的默认目录在「设置 › AI 服务 › 大语言模型 › 工具权限」中修改。
:::

## 洞见

洞见让 AI 把你正在看的一篇内容，和你写过的其他笔记对照着读。在卡片、文章或项目文档的标题下方点击「AI 洞见」，稍等片刻，正文里会画出几种标记：

::demo{name="insights" caption="点击「AI 洞见」，等待标记出现后，点击蓝色或红色的下划线"}

| 标记         | 含义                           | 点开后的主要操作 |
| ------------ | ------------------------------ | ---------------- |
| 蓝色下划线   | 可连接：你在别处写过相关的内容 | 连接             |
| 灰色点线     | 重复：和另一篇内容说的差不多   | 连接             |
| 红色波浪线   | 矛盾：和你在别处写的说法不一致 | 聊一聊           |
| 段落下的淡注 | 可以展开：这里值得多写几句     | 去补写           |

点一处标记，气泡里会并排显示这一篇和另一篇的说法。点「连接」，两篇内容就连了起来；点「聊一聊」，会带着两处说法打开对话，让 AI 帮你想想哪个对；觉得不相关就点「不相关」，这条标记会消失。

正文上方的报告会统计各类标记的数量，并在「可以继续想」里列出几个值得深入的问题，点「聊一聊」可以接着和 AI 讨论。标记比较多时，点「逐条看」，用 <kbd>↑</kbd> <kbd>↓</kbd> 切换，按 <kbd>↵</kbd> 执行主要操作，按 <kbd>⌫</kbd> 标记为不相关，按 <kbd>Esc</kbd> 结束。

:::tip{title="写完一篇就读一次"}
洞见最适合刚写完的内容：趁着思路还热，看看它能连到哪些旧笔记。正文改动较大后，报告会提示你点「重新分析」。
:::

[知识地图](/docs/walk/) 里也有「AI 洞见」，可以一次查看所有内容的分析结果。

## 创作模式

写文章时打开创作模式，说明你想写什么，AI 会从你的内容里找出相关资料，分组摆在左侧的白板上，供你边看边写。详见 [文章](/docs/articles/)。

## 在手机上

手机上也能和 AI 对话：在「今天」页顶部的「问问你的笔记…」进入对话；阅读卡片、文章时点顶栏的 ✦，或选中一段文字点「问 AI」，就带着这篇内容提问。Skill、MCP 和对话里生成图片在手机上同样可用，手机上的服务商和模型要单独添加一次，在「我的 › AI 模型」里设置，同步不会带过去。详见 [手机](/docs/mobile/)。

## 常见问题

:::detail{title="发送消息时提示「请先在设置中配置对话功能的大模型」"}
服务商和模型已经添加，但还没把模型分配给对话功能。到「设置 › AI 服务 › 大语言模型 › 功能分配」中为「对话功能」选择模型，或者直接在输入框下方点「选择模型」。
:::

:::detail{title="找不到「AI 洞见」按钮"}
「AI 洞见」需要单独分配模型。在「功能分配」的「内容处理」分组里为「AI 洞见」选一个模型后，卡片、文章和项目文档里就会出现这个按钮。
:::

:::detail{title="想让 AI 按固定的格式写，或者用更多外部工具"}
把做法写成 Skill，或接入 MCP 服务器，详见 [Skill 与 MCP](/docs/skills-mcp/)。
:::

连好模型后，可以先在 [Skill 与 MCP](/docs/skills-mcp/) 里把常用的做法存成 Skill；读书和学习时怎样配合 AI，见 [收集与阅读](/docs/reading/) 和 [Notebook](/docs/notebook/)。
