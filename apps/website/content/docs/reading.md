读书时的划线、批注和随手记下的想法，都可以收进 Tau，并且带着出处：哪个文件第几页、哪个网页、哪本书哪一章。之后你可以把它们转成卡片，写文章时引用，向 AI 提问时 AI 也能检索到它们。

Tau 支持三个来源，各有一条流程：

| 来源     | 在哪里读                  | 需要准备                       |
| -------- | ------------------------- | ------------------------------ |
| PDF      | Tau 内置的 PDF 阅读器     | 无                             |
| 网页     | 你平时用的 Chrome 或 Edge | 安装「Tau 伴读」浏览器扩展     |
| 微信读书 | 微信读书 App              | 安装「微信读书」插件并连接账号 |

## PDF

### 添加 PDF

在侧边栏「学习」分组中点击「PDF」，然后点击右上角的「添加 PDF」：

- **本地文件**：拖入文件，或点击「选择文件」，可以一次选多个。文件会复制到工作区里。
- **链接**：粘贴 PDF 的地址。名称默认取链接里的文件名，可以改。

也可以直接把 PDF 拖到 PDF 页面上。列表顶部的「最近打开」会记住每份文件读到第几页，点击即可从上次的位置继续。

### 划线与批注

打开一份 PDF，选中一段文字，旁边会弹出工具条：

::demo{name="highlight" caption="点击任意一句话（模拟选中文字），选择颜色进行高亮，或点击「写笔记」添加页边批注"}

- **划线**：工具条上有黄、红、绿、蓝、紫五种颜色，点一下就完成划线。点击颜色右侧的样式按钮，可以在高亮和下划线之间切换。
- **写笔记**：点击「写笔记」，在页边写下你的想法，按 <kbd>⌘↵</kbd>（Windows 上为 <kbd>Ctrl+↵</kbd>）保存。不选文字、直接点击页面右侧的页边，也可以随手写一条批注。
- **框选区域**：按住 <kbd>Alt</kbd> 拖出一个方框，把图表、公式这类选不中文字的内容「存为区域标注」，或「复制图片」。
- **问 AI**：针对选中的这段内容提问，AI 会结合整份 PDF 回答。

点击已有的划线，可以换颜色、补写笔记或删除。

:::tip{title="给颜色定个规矩"}
颜色只是标记，Tau 不规定含义。读之前给自己定个约定会很有用，比如黄色是观点、绿色是例子、红色是存疑。之后在「标注」里按颜色筛选，就能把同一类内容一次看完。
:::

### 管理标注和书签

阅读页底部有一条悬浮工具栏，可以翻页、缩放和查找。点击最左边的「左面板」按钮，打开左侧面板，它有四个标签页：

- **目录**：PDF 自带的目录，点击跳转。
- **页面**：每一页的缩略图。
- **标注**：所有划线和批注，按页排列。可以只看「有笔记」的，或按颜色筛选。点击一条跳回原文。
- **书签**：按 <kbd>B</kbd> 给当前页加书签，再按一次取消。

### 和 PDF 对话

按 <kbd>⌘J</kbd>（Windows 上为 <kbd>Ctrl+J</kbd>）打开右侧的对话，可以问「总结全文」「这份文档的结构是怎样的」这类整体问题。AI 回答时会标出页码，点击即可跳到对应位置核对原文。

从选中文字点「问 AI」时，这段原文会作为引用带进输入框，下方还有「解释」「翻译」「举个例子」「找相关段落」几个快捷问题。

:::info{title="第一次提问会慢一点"}
第一次和某份 PDF 对话时，Tau 会先为它建立 AI 索引，之后才能按页检索和引用。索引在后台进行，建好之前也能提问。你也可以在 PDF 列表里点击文件的「⋯」，提前「建立 AI 索引」。
:::

### 阅读快捷键

| 操作                | 快捷键                                          |
| ------------------- | ----------------------------------------------- |
| 上一页 / 下一页     | <kbd>←</kbd> <kbd>→</kbd>                       |
| 加书签              | <kbd>B</kbd>                                    |
| 双页显示            | <kbd>D</kbd>                                    |
| 显示 / 隐藏页边批注 | <kbd>M</kbd>                                    |
| 向右旋转            | <kbd>R</kbd>                                    |
| 抓手工具            | <kbd>H</kbd>，或按住 <kbd>空格</kbd> 临时拖动   |
| 查找                | <kbd>⌘F</kbd>（Windows 上为 <kbd>Ctrl+F</kbd>） |
| 打开 / 关闭对话     | <kbd>⌘J</kbd>（Windows 上为 <kbd>Ctrl+J</kbd>） |

底部工具栏的「⋯」里还有「夜间页面（反色）」和「全屏阅读」，适合晚上或长时间阅读。

## 网页：Tau 伴读

「Tau 伴读」是一个浏览器扩展，支持 Chrome 和 Edge。装上之后，你在任何网页上都能高亮、批注、记笔记，并用 Tau 里配置的模型对这一页提问。扩展只和你电脑上运行的 Tau 通信，标注和笔记保存在你自己的 Tau 里。

### 安装与连接

1. 在 Chrome 应用商店或 Edge 加载项商店搜索「Tau 伴读」，点击添加。
2. 确认电脑上的 Tau 正在运行。
3. 打开任意网页，按 <kbd>Alt+J</kbd> 或点击浏览器工具栏上的扩展图标，打开伴读面板。面板上会显示一个 4 位校验码。
4. Tau 会弹出「想连接到 Tau」的窗口。核对两边的校验码一致后，点击「允许连接」。

只需授权一次。授权窗口里可以选择是否允许扩展「使用 Tau 里的工具」，打开后，在网页上提问时 AI 也能检索你的笔记、管理待办和日程。之后可以在 Tau 的「设置 › 浏览器扩展」中查看已授权的浏览器，调整权限或撤销授权。

:::detail{title="Tau 没有弹出授权窗口？"}

- 确认 Tau 正在运行，并已更新到最新版。
- 在 Tau 的「设置 › 浏览器扩展」中，确认「接受新的连接请求」处于打开状态。
- 没连上 Tau 时，高亮和批注照常可用，会先保存在浏览器里，连上后自动同步。只有对话需要 Tau。
:::

### 在网页上标注

选中网页上的一段文字，会弹出工具条：

- **高亮**：五种颜色，点一下即可。下次打开同一个网页，高亮会自动还原。
- **批注**：给这段文字写一条想法，按 <kbd>⌘↵</kbd>（Windows 上为 <kbd>Ctrl+↵</kbd>）保存。
- **问 AI**：可以选「解释」「翻译」「概括这段」，或「自由提问…」。回答出现在一个小气泡里，可以「复制」「存为批注」「存为笔记」，或「在面板继续」追问。
- **摘录**：把这段原文放进本页的页面笔记。

网页右侧边缘有一个圆形的悬浮球。鼠标移上去会展开三个快捷入口：「问这页」「本页标注」「页面笔记」。不想在某个网站看到它，可以在面板的「⋯」中选择「在此网站隐藏悬浮球」。

### 伴读面板

伴读面板有三个标签页：

- **对话**：对整页提问，例如「总结本页」「列出要点」。回答会标出原文出处，点击编号跳回对应段落。输入框上方的「我的标注」打开后，AI 会参考你在这页的高亮和批注。
- **标注**：本页的所有标注，可以按颜色筛选。
- **笔记**：这一页的页面笔记，边读边写，自动保存在本机。写好后点击「保存为卡片」，就成了 Tau 里的一张卡片，末尾附带网页的来源链接。

点击面板上的图钉可以固定面板，切换标签页时它会保持打开。

### 伴读库

按 <kbd>Alt+Shift+J</kbd> 打开伴读库，所有标注过的网页都汇总在这里：

- **页面**：每个标注过或写过笔记的网页，点开查看这一页的全部标注。没有标题的网页可以改一个好记的名字。
- **全部标注**：跨网页按时间倒序排列。
- **笔记**：所有页面笔记和已经保存的卡片。

左侧可以按站点筛选。扩展会处理哪些数据，详见 [Tau 伴读隐私政策](/docs/browser-companion-privacy/)。

## 微信读书

如果你习惯在微信读书里读书，可以用「微信读书」插件把书架、划线和想法同步进 Tau。

### 连接账号

1. 在 [插件](/docs/plugins/) 中安装「微信读书」，装好后它会直接启用，侧边栏「学习」分组中会出现「微信读书」。
2. 打开「微信读书」，点击「打开获取页」，在微信读书的「AI 技能」页复制 API Key。
3. 把 API Key 粘贴回 Tau，点击「保存并同步」。校验通过后会自动同步一次书架。

:::warning{title="保管好 API Key"}
API Key 相当于你的账号凭证，不要发给别人，也不要出现在截图里。书架和 API Key 按工作区分开保存，换一个工作区需要重新连接一次。
:::

### 浏览书架和笔记

书架可以按「在读」「读完」「未开始」「有笔记」筛选，按最近阅读、阅读进度、阅读时长或笔记数排序，也可以搜索书名或作者。

点开一本书，左侧是目录，右侧按章节列出你的划线和想法，划线颜色与微信读书一致。可以只看「有想法」的条目，或按颜色筛选。鼠标悬停在一条划线上，可以「转为卡片」或复制。书名下方还有「复制为 Markdown」，把整本书的笔记一次复制出来。

### 保持同步

- 点击书架右上角的「同步」，更新新加入的书，以及最近读过、记过笔记的书。
- 觉得数据不对时，点击「同步」旁的小箭头，选择「全量重新同步」。
- 在微信读书里新划了线，回到 Tau 打开这本书，点击「重新拉取笔记」。

已经同步的划线和想法保存在本地，离线也能查看。

## 从划线到卡片

收集只是第一步。读完一章，把真正打动你的那几条转成卡片，再补上自己的话，它们才会变成你自己的东西。

::demo{name="excerpt-card" caption="鼠标悬停在一条标注上，点击右下角的「转为卡片」，再点击提示中的「打开」查看生成的卡片"}

比如你在读《深度工作》的 PDF，划了一句「深度工作是一种越来越稀缺、也越来越有价值的能力」，还在旁边写了「这就是为什么要每天留出两小时不看消息」：

1. 打开左侧面板的「标注」，鼠标悬停在这条标注上。
2. 点击右下角的「转为卡片」。Tau 会提示「已转为卡片」。
3. 点击提示中的「打开」，就能看到这张新卡片。

卡片的内容是这样组织的：

```text
> 深度工作是一种越来越稀缺、也越来越有价值的能力。

这就是为什么要每天留出两小时不看消息。

—— PDF · 深度工作.pdf · 第 12 页
```

原文是引用块，你的批注是正文，最后一行是出处。卡片是一份复制，之后你可以随意改写、补充，原来的划线不受影响。微信读书的划线也一样，出处会写成「微信读书 · 书名 · 章节」。

:::tip{title="别急着把每条都转成卡片"}
划线很便宜，卡片才值得花时间。只转那些你想再写几句、或者想和其他想法连起来的。没转的划线也不会丢：它们都能被搜索到，向 AI 提问时 AI 也会检索它们。
:::

接下来，你可以给卡片加上标签，用 `@` 引用其他内容（见 [卡片](/docs/cards/)），或者把需要记住的知识点做成 [闪卡](/docs/flashcards/)。
