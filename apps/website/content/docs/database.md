数据库用来管理结构化的数据，例如书单、观影记录、项目进度和学习计划。每条记录是一行，每个属性是一列；同一份数据可以用表格、看板、画廊、日历几种视图来看。

拿书单举例：每本书一行，列有书名、作者、状态（想读 / 在读 / 读完）、评分和页数。用表格逐本录入，用看板按状态拖动，用画廊看封面墙，再加一列公式自动算出阅读进度。

## 新建数据库

在侧边栏点击「数据库」，点击「新建数据库」，填写名称和描述（可选）即可。数据库列表的用法和项目列表相同：顶部是「最近打开」，可以排序、在网格和列表之间切换，悬停后置顶或在「⋯」里编辑信息、归档、删除。

## 视图

::demo{name="database" caption="切换表格、看板、画廊视图；在看板中拖动卡片到其他列；在表格底部点击「汇总」并选择「求和」，再打开「筛选」查看结果变化"}

| 视图 | 适用场景                     | 前提条件       |
| ---- | ---------------------------- | -------------- |
| 表格 | 逐行录入、批量编辑           | 无             |
| 看板 | 按状态分组，拖动卡片更新状态 | 至少一个单选列 |
| 画廊 | 带封面的内容，例如书和电影   | 无             |
| 日历 | 按日期安排的事项             | 至少一个日期列 |

点击视图栏末尾的「+」新建视图，选择类型并起个名字。双击视图名称可以重命名，悬停后点「⋯」可以编辑或删除视图。每个视图都可以单独设置：

- **筛选**：添加条件，只显示符合条件的行。多个条件可以选「满足全部条件」或「满足任一条件」，还能添加条件组做更复杂的组合；
- **排序**：按一列或多列排序，按添加顺序依次生效；
- **分组**：按某一列的值把行分成几组，日期列可以按日、按周或按月分组；
- **搜索**：点放大镜图标，只在当前视图里搜索。

看板视图需要指定用哪个单选列分组，还可以选一个复选框列作为「完成状态列」，以及卡片上显示多少属性。画廊视图可以选择用哪个图片列做封面。

:::tip{title="一张表，多种看法"}
同一份书单可以建好几个视图：「全部书」用表格，「在读」用看板并筛选掉读完的，「书架」用画廊。各视图的筛选、排序互不影响，改的都是同一份数据。
:::

## 编辑数据

- **添加行**：点击表格底部的「添加行」。在看板的某一列、画廊或日历的某一天也可以直接新建。
- **编辑单元格**：点击单元格直接编辑。用方向键在单元格之间移动，按回车或空格开始编辑。
- **调整行顺序**：拖动行左侧的手柄。点击手柄可以打开行操作，例如删除这一行。设置了排序规则或正在搜索时不能手动调整顺序。
- **撤销**：<kbd>⌘Z</kbd>（Windows 上为 <kbd>Ctrl+Z</kbd>）撤销，<kbd>⌘⇧Z</kbd>（Windows 上为 <kbd>Ctrl+Shift+Z</kbd> 或 <kbd>Ctrl+Y</kbd>）重做。
- **查看详情**：鼠标悬停在首列上，点击「打开详情」，侧边会展开整行数据。详情里除了各个属性，还有一块完整的正文，可以像写文章一样记笔记。按 <kbd>K</kbd> / <kbd>J</kbd> 切换到上一条或下一条。

## 字段类型

点击表头最右侧的「+」（提示为「新列」）添加一列，填写列标题、选择列类型。双击表头，或点表头上的「⋯」，可以编辑或删除这一列；拖动表头可以调整列的顺序。

| 类型   | 适合存放           | 说明                                               |
| ------ | ------------------ | -------------------------------------------------- |
| 文本   | 书名、作者、备注   | 第一列通常是文本，作为每一行的标题                 |
| 数字   | 页数、价格、时长   | 可以参与汇总和公式计算                             |
| 单选   | 状态、类别         | 每个选项有颜色；看板按它分组                       |
| 多选   | 标签、主题         | 一格可以选多个选项                                 |
| 复选框 | 是否完成、是否推荐 | 看板可以用它标记完成                               |
| 日期   | 开始日期、截止日期 | 可以开启「包含时间」「结束日期」；日历视图按它排布 |
| 评分   | 打分               | 星级显示                                           |
| 进度   | 完成百分比         | 进度条显示                                         |
| 链接   | 网址               | 点击打开                                           |
| 公式   | 由其他列算出的值   | 见下文                                             |
| 富文本 | 带格式的长文字     |                                                    |
| 图片   | 封面、截图         | 画廊视图可以用它做封面                             |
| 附件   | 文件               |                                                    |

在单选或多选格子里输入一个还不存在的选项名，可以直接创建新选项。

## 汇总

表格底部的每一列都可以设置汇总方式。鼠标移到表格底部，点击某一列下方的「汇总」：

| 汇总方式                           | 适用的列                       |
| ---------------------------------- | ------------------------------ |
| 求和、平均、中位数、最小值、最大值 | 数字列，以及结果为数字的公式列 |
| 计数、非空、空值、去重             | 所有列                         |

汇总只计算当前视图筛选后显示的行。比如书单筛选出「读完」的书，页数列的求和就是读完的总页数。汇总菜单的最后一项「公式…」可以把几列的汇总组合起来计算，例如「价格 · 求和 ÷ 书名 · 计数」得到平均每本书的价格。

## 公式

公式列根据同一行的其他列算出一个值，并随数据自动更新。新建列时选择「公式」类型，下方会出现公式构造器：先回答「想算什么？」，再按步骤点选，不需要记任何语法。

::demo{name="formula" caption="点一种计算类型开始；点击下拉框可以换列或换运算符，改动文字和数字后，下方的预览会立即更新。点「换一种」回到开头"}

公式有三种类型：

| 类型       | 做什么                   | 书单里的例子                                  |
| ---------- | ------------------------ | --------------------------------------------- |
| 计算       | 几列或数字之间加减乘除   | 阅读进度 = 已读页数 ÷ 页数                    |
| 按条件显示 | 满足某个条件就显示某个值 | 页数大于 300 显示「大部头」，否则显示「薄书」 |
| 拼接文字   | 把几列的内容连成一段文字 | 书名 · 状态，得到「深度工作 · 读完」          |

几个更具体的例子：

- **算总价**：选「计算」，填「价格 × 数量」。点「再加一项」可以继续加减乘除，先算乘除、再算加减。
- **标记状态**：选「按条件显示」，「如果 截止日期 早于 2026-12-31」显示「年内」。可以「再加一个条件」并用「并且 / 或者」连接，也可以「再加一种情况」，从上往下判断，满足第一种就停；最后填写「都不满足时显示」的值。
- **嵌套计算**：在任意一个格子的下拉菜单里选「改成计算…」或「改成条件…」，可以把一个值换成一段计算，例如「如果 价格 × 数量 大于 500 显示『高』」。最多嵌套两层，更复杂的公式可以拆成两列。

每一步都会在构造器下方用一句中文复述公式的意思，比如「结果 = 已读页数 ÷ 页数」，并在预览里显示前 5 行的计算结果。

:::info{title="用一句话生成公式"}
为「对话功能」分配 AI 模型后，公式构造器顶部会出现一个输入框。用一句话描述需求，比如「成本乘数量超过 500 就显示『高』」，点击「生成」，AI 会帮你填好构造器，确认无误后保存即可。生成时只发送列的结构，不发送表格里的数据。设置方法见 [AI 对话与洞见](/docs/ai/)。
:::

## 在文档里插入数据库

在卡片、文章或项目文档的空行输入 `/`，选择「数据库视图」，会在正文里插入一张新的数据表，可以直接在文档中添加列和行、切换视图。适合在读书笔记里附一张对比表，或在项目文档里放一份任务清单。
