数据库用来管理结构化的数据：书单、观影记录、项目进度、学习计划……一份数据，可以用多种方式查看。

## 四种视图

| 视图 | 适合                       |
| ---- | -------------------------- |
| 表格 | 逐行录入、批量编辑         |
| 看板 | 按状态分组，拖动卡片推进   |
| 画廊 | 带封面的内容，比如书和电影 |
| 日历 | 按日期安排的事项           |

同一份数据可以建多个视图，每个视图的筛选、排序和分组各自保存，切过去就是想看的样子。

## 字段类型

支持文本、数字、单选、多选、日期、复选框、链接、进度、评分和公式。

## 汇总与公式

在表格底部可以对一列求和、求平均或计数。公式可以用构造器一步步拼出来；如果已经连接了 AI 模型，也可以用一句话描述想算什么，让 AI 帮你写。
