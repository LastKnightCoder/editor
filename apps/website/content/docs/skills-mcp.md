有些事你每次都要向 AI 交代一遍做法，比如周报按什么结构写、读书卡片先写什么。把这套做法存成一个 Skill，之后只说一句「写周报」，AI 就会照着做。想让 AI 用上 Tau 之外的工具，比如读写电脑上的某个文件夹、查 GitHub 上的问题，就接入一个 MCP 服务器。两者都在侧边栏的「AI」分组里。

## 把做法存成 Skill

下面用「周报」做例子：每周五你都要让 AI 把这周的日记、完成的待办和开过的会整理成周报，格式每次都一样。

### 添加 Skill

在侧边栏点击「Skill」，然后点击「添加 Skill」：

- **新建**：填写名称和描述，从空白、流程类、参考资料类或格式规范类模板开始写。周报适合流程类。
- **用 AI 创建**：描述你想让 AI 学会什么。也可以直接贴一段你满意的对话，比如上周那次整理周报的对话，点「起草」生成初稿，改好后点「保存 Skill」。
- **导入**：选择 `.zip` / `.skill` 压缩包或一个文件夹，也可以粘贴 GitHub 上的链接。
- **关联目录**：你在 Claude Code、Codex 等工具里已经写过 Skill，可以直接关联它们的文件夹，两边共用同一份。关联进来的 Skill 只读，想改时点「复制为我的」。

插件中心里也有现成的 Skill 包，安装后会出现在 Skill 列表里。

:::warning{title="只导入信任的来源"}
Skill 里可以附带脚本，AI 会在你的电脑上运行它们。
:::

### Skill 的写法

一个 Skill 是一个文件夹，里面至少有一个 `SKILL.md`。文件开头用 `---` 包起来的部分写名称和描述，下面用平常的话写清楚要做什么：

```markdown
---
name: "周报"
description: "把一周的日记、已完成的待办和日程整理成周报。用户提到「周报」「本周总结」时使用。"
---

# 周报

## 步骤

1. 找出本周写的日记，挑出和工作有关的
2. 查出本周完成的待办，按待办项目归类
3. 查出本周的会议和日程
4. 按下面的格式输出

## 输出格式

- **本周完成**：按待办项目列出，每项一句话
- **进行中**：还没完成的事和卡在哪里
- **下周计划**：最多三条

## 注意

- 只写有依据的内容，查不到的部分直接说明
- 语气简洁，不写客套话
```

AI 会自己判断每一步该怎么查，你不需要知道它用什么工具。

开头的几个字段：

| 字段                       | 说明                                                       |
| -------------------------- | ---------------------------------------------------------- |
| `name`                     | 显示的名称                                                 |
| `description`              | 这个 Skill 做什么、什么时候用。AI 靠它判断要不要读这份说明 |
| `disable-model-invocation` | 写 `true` 时默认为「仅手动」，AI 不会自己加载              |

描述里一定要写「什么时候用」，比如上面的「用户提到『周报』『本周总结』时使用」。漏了这一句，编辑时 Tau 会提示你补上。

:::detail{title="内容多的 Skill：拆成多个文件，附带脚本"}
可以把细节拆到其他文件里，`SKILL.md` 只放概要和索引，AI 需要时再去读：

```text
reading-card/
├── SKILL.md          必需：说明和索引
├── reference/
│   └── examples.md   参考资料、范例
└── scripts/
    └── extract.py    需要时运行的脚本
```

在 `SKILL.md` 里写明什么情况下运行哪个脚本，AI 会按说明执行。支持 `.py`（Python 3）、`.js` / `.mjs` / `.cjs`（Node）、`.sh`（Bash）和 `.ts`，其他文件需要有可执行权限。脚本在 Skill 文件夹里运行，单次最长 2 分钟。
:::

:::detail{title="编辑 Skill"}
点击一个 Skill 打开详情，再点编辑进入整页编辑器。左侧是文件列表，可以新建文件和文件夹；正文可以在「编辑」和「源码」两种视图间切换。内置和关联目录里的 Skill 是只读的，想修改时点「复制为我的」，在副本上改。
:::

### 自动、仅手动还是停用

每个 Skill 都可以选一种调用方式：

| 方式   | AI 什么时候用                       | 适合                       |
| ------ | ----------------------------------- | -------------------------- |
| 自动   | 根据描述，在需要时自己读取          | 经常用、希望一说就生效的   |
| 仅手动 | 只在你于输入框输入 `$` 选中它时才用 | 偶尔用，或者只想自己点名的 |
| 停用   | 完全看不到                          | 一阵子不用，又不想删掉的   |

周报每周都要写，设成「自动」，说「写本周周报」就会生效。只在季度末用一次的「季度复盘」，设成「仅手动」就够了，用时在输入框输入 `$` 选它。

页面右上角的「常驻上下文」值得留意。设为「自动」的 Skill，名称和描述会跟着每一次对话发给模型，这个数字就是它们加起来的长度。数字越大，每次对话要多发的内容越多，回答会慢一点，按用量计费的模型也会贵一点。描述偏长的 Skill 卡片上会有提示，把细则挪到正文里即可；不常用的设成「仅手动」，就不占这部分长度。

调用方式只保存在本机，不会改动 Skill 文件，内置和关联目录里的 Skill 也能设置。详情的「使用记录」里可以看到它最近被加载了几次，其中几次是 AI 自动加载的。

## 用 MCP 接入外部工具

MCP 是一种通用的接法，很多工具和服务都提供 MCP 服务器。接上之后，AI 就多了这个服务的能力，比如读写你电脑上的某个文件夹、查询 GitHub、操作浏览器。服务的说明文档里一般会给出配置，照着填进 Tau 就行。

### 添加服务器

在侧边栏点击「MCP 服务器」，然后点击「添加服务器」。服务的说明会告诉你它属于哪一种：

- **本地进程**：在你的电脑上运行一个程序。填写说明里给的命令（如 `npx`、`uvx`）和参数，有需要再填环境变量和工作目录。
- **远程 HTTP**：连接一个网址。填写服务给的地址；需要登录的服务，在请求头里加上 `Authorization` 和你的密钥。

更省事的做法是「粘贴 JSON」：

::demo{name="mcp-import" caption="改一改左侧的 JSON，看右侧识别出的服务器；点「导入」后看它们连接"}

Claude Desktop、Cursor 和 VS Code 里的 MCP 配置可以直接复制过来，一次导入多个：

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/Users/you/Documents/notes"]
    },
    "github": {
      "url": "https://api.githubcopilot.com/mcp/",
      "headers": { "Authorization": "Bearer <你的 GitHub Token>" }
    }
  }
}
```

名称里带 KEY、TOKEN、SECRET 等字样的配置项，值会默认遮住。只提供 SSE 地址的服务器接不上，导入时会标出来；这类服务大多同时提供 HTTP 地址，换成那个地址即可。点击页面上方的「导出为 JSON」，可以把你添加的全部服务器复制成同样的格式，用来备份或换到其他工具里用。

:::warning{title="请只添加可信的服务器"}
本地进程类的服务器可以在你的电脑上执行命令、读写你的文件。
:::

### 管理和排查

每个服务器卡片底部显示当前状态：可用的工具数、「连接中…」、「连接失败」或「已停用」。侧边栏「MCP 服务器」旁的数字是连接失败的服务器数。

点击一个服务器打开详情：

- **工具**：列出它提供的全部工具，可以单独关掉不想让 AI 用的；
- **配置**：修改后点「保存并重连」；
- **日志**：查看最近 200 行输出，连接失败时先看这里。

改完配置或服务器卡住时，点击「重新连接」。

「内置」分组里是 Tau 自带的能力，比如搜索你的内容、修改正文、安排待办和日程，部分常开不可关，具体能做什么见 [AI 对话与洞见](/docs/ai/)。

### 在对话中开关

在对话输入框里点击「+」，选择「MCP 服务器」，可以临时开关某个服务器，不用离开对话。这里的开关和 MCP 服务器页面是同一个。

:::tip{title="少开几个，AI 选得更准"}
每个打开的服务器都会把自己的工具清单交给 AI。工具太多时，AI 更容易用错，每次对话也更长、更贵。不常用的服务器先关着，要用时在输入框里打开。
:::

## 在手机上

手机上的 AI 对话同样可以用 Skill 和 MCP，在「我的」页管理。Skill 来自内置、插件和插件中心的 Skill 包，同样可以设为自动或仅手动，对话时点「选择 Skill」点名。MCP 只能添加远程 HTTP 服务器，不能运行本地进程。详见 [手机](/docs/mobile/)。
