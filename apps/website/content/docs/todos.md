待办用来记下要做的事，日程用来在日历上安排时间。两者是同一份数据：有截止时间的待办会显示在日历上，没排时间的待办也可以直接拖进日历。

## 添加待办

在待办页顶部的输入框里用一句话写下要做的事，按回车就添加好了。在待办页按 <kbd>⌘/</kbd>（Windows 上为 <kbd>Ctrl+/</kbd>）可以快速定位到输入框。

::demo{name="todos" caption="输入「明天 17:00 交周报 #工作」后按回车；点击圆圈完成一条待办"}

Tau 会从这句话里识别出日期、时间和项目，在输入框下方显示「识别为…」，回车前你就能确认对不对：

| 输入                     | 识别结果                    |
| ------------------------ | --------------------------- |
| `明天 17:00 交周报`      | 截止任务，明天 17:00 截止   |
| `周五下午3点 评审`       | 截止任务，本周五 15:00 截止 |
| `周六 10点到12点 大扫除` | 安排，周六 10:00–12:00      |
| `每周一、四 周会`        | 周期任务，每周一和周四打卡  |
| `每天 晨读`              | 周期任务，每天打卡          |
| `#工作`                  | 归入「工作」项目            |
| `买牛奶`                 | 普通任务，没有日期          |

日期还可以写「后天」「下周三」「10月30日」「今晚」等；时间可以写「15:00」「3点半」「下午3点」。只写「3点」而不写上午下午时，1 点到 6 点按下午算。写了起止时间的会直接排进日历。

:::info{title="先建一个项目"}
每条待办都属于一个项目。第一次使用时，先点击「新建项目」建一个，比如「工作」「生活」。没写 `#项目` 时，待办会放进当前选中的项目。
:::

## 查看和管理

待办默认按日期分段：已逾期、今天、明天、本周稍后、以后、无日期。点击右上角的「按项目」可以改为按项目分组。

- **完成**：点击待办前的圆圈。完成的待办收进该段末尾的「已完成」。周期任务点圆圈表示「今日打卡」。
- **编辑**：点击一条待办，右侧打开详情。可以改类型（普通、截止、周期）和截止时间，设置重复规则和提醒，写描述，添加子任务，或者关联卡片、文章作为参考资料。
- **改期**：右键点击一条待办，在「改期」里选今天、明天或下周一；在「移动到」里换一个项目。
- **删除**：右键选「删除」。删除不会弹确认框，底部会出现「撤销」，几秒内点击即可恢复。

点击右上角的「今日」，会打开今日概览：今天要打卡的周期任务、本周每天的任务量，以及最近完成的事。

截止任务可以设置提醒，从「准时」到「提前 1 天」都可以选。到了时间，Tau 会弹出通知。

### 周期任务和打卡

「每天晨读」「每周一、四健身」这类习惯，用周期任务来记。在详情里可以看到连续打卡的天数、近 12 周的完成率，以及一张打卡格。点击过去的格子可以补打卡；今天确实做不了，可以选「跳过今天」，不算断签。

设置重复规则时，可以选每天、每周几、每月几号，还可以勾选「排除法定节假日」。

### 项目

侧边栏「待办」下方列出了你的所有项目，后面的数字是未完成的条数。点击一个项目只看它，再点一次回到全部。右键可以编辑、归档或删除项目；归档的项目在「已归档」里，点击即可恢复。

### 文档里的待办

在任意卡片、文章或日记里输入 `[]` 加空格，就能写一个勾选项。这些勾选项会汇总到侧边栏「待办 › 文档中」，按文档分组。在这里勾选，原文中的勾选项也会同步勾上。

## 日程

日程页以日历的形式安排时间，有月、周和议程三种视图。

::demo{name="schedule" caption="把右侧「待安排」中的待办拖到某一天；双击空白日期可新建全天日程"}

- **新建日程**：点击「新建日程」；也可以在月视图双击某一天，或横向拖过几天新建跨天日程；在周视图里拖选一段时间。
- **快速添加**：点击右上角的「今天 · N 项」打开当日时间线，在底部输入「明天 3 点 评审 #工作」按回车。这里的 `#` 指的是日历。
- **安排待办**：点击「待安排」，把还没排时间的待办拖进日历或时间线上的空档。
- **补记**：当日时间线里，过去两段日程之间的空隙可以直接补记刚才做了什么。
- **日历**：日程上方的彩色标签是不同的日历，点击可以显示或隐藏。在「管理日历」里可以分组、新建、归档或合并日历。

有截止时间的待办和完成的番茄专注会自动显示在日历上。这些条目在日历里只能查看，要修改请回到对应的待办或专注记录。

打开一条有具体时间的日程，点击「开始专注」，就能用 [番茄专注](/docs/pomodoro/) 为它计时。

## 一个例子

周一早上，你在待办页依次输入：

1. `周三 17:00 交选题报告 #工作`，这是一条截止任务；
2. `每天 晨读 30 分钟`，每天打卡；
3. `周四 14点到16点 写报告初稿 #工作`，直接在周四下午占好两个小时。

到了周四下午 2 点，在「今日」的日程里点开「写报告初稿」，点「开始专注」。写完后回到日程页，会看到这两个小时里专注的时段已经画在了日历上。
