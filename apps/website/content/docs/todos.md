待办用来记下要做的事，日程用来在日历上安排时间。两者是同一份数据：有截止时间的待办会显示在日历上，没排时间的待办也可以直接拖进日历。到了时间，Tau 会弹出提醒。

## 查找待办和日程

按 <kbd>⌘K</kbd>（Windows 上为 <kbd>Ctrl+K</kbd>）打开搜索，输入标题中的文字，即可查找待办和日程。点击「待办」「日程」可以限定类型，也可以输入「待办: 年度复盘」或「日程: 评审」。选中结果后按回车，会打开对应待办详情或定位到日程日期。「待办」也会查找文档里的勾选项，打开这类结果会直接定位到原文中的该项。

已完成但未归档的待办仍可找到；已归档的待办不在搜索结果中。截止提醒和周期任务的系统日历记录不作为独立日程重复列出，可从「待办」结果打开任务。

待办与日程的固定标签和操作提示支持简体中文、繁体中文和 English。切换语言会保留过滤、正在编辑的标题与正文、日期和提醒；已经保存的日历、待办项目与事件名称按原名显示。

## 添加待办

快速添加输入条和日期、时段、周期预览会跟随界面语言显示。任务标题、`#` 后面的项目或日历名称保持原样；日期写法按下方示例识别，切换语言不会自动翻译输入。

在待办页顶部的输入框里用一句话写下要做的事，按回车就添加好了。在待办页按 <kbd>⌘/</kbd>（Windows 上为 <kbd>Ctrl+/</kbd>）可以快速定位到输入框。

::demo{name="todos" caption="输入「明天 17:00 交周报 #工作」后按回车；点击圆圈完成一条待办"}

Tau 会从这句话里识别出日期、时间、优先级、标签和待办项目，在输入框下方显示「识别为…」，回车前你就能确认对不对：

| 输入                     | 识别结果                                            |
| ------------------------ | --------------------------------------------------- |
| `明天 17:00 交周报`      | 截止任务，明天 17:00 截止                           |
| `周五下午3点 评审`       | 截止任务，本周五 15:00 截止                         |
| `周六 10点到12点 大扫除` | 安排，周六 10:00–12:00                              |
| `每周一、四 周会`        | 周期任务，每周一和周四打卡                          |
| `每天 晨读`              | 周期任务，每天打卡                                  |
| `!高` / `!中` / `!低`    | 设置高 / 中 / 低优先级（也支持 `p1` / `p2` / `p3`） |
| `@评审`                  | 添加「评审」标签，可连续写多个                      |
| `#工作`                  | 归入「工作」这个待办项目                            |
| `买牛奶`                 | 普通任务，没有日期                                  |

获得待办权限的插件也可以读取或更新独立待办的优先级和标签。周期待办的所有实例共用系列上的设置。

不记语法也没关系，点击输入框右侧的优先级和 `#` 按钮同样可以点选后再回车添加。

日期还可以写「后天」「下周三」「10月30日」「今晚」等；时间可以写「15:00」「3点半」「下午3点」。只写「3点」而不写上午下午时，1 点到 6 点按下午算。写了起止时间的会直接排进日历。

:::info{title="先建一个待办项目"}
待办项目是待办的分组，比如「工作」「生活」，和文档树里的 [项目](/docs/projects/) 无关。每条待办都属于一个待办项目，第一次使用时，先在侧边栏「待办」下方点击「新建项目」建一个。没写 `#` 时，待办会放进当前选中的待办项目。
:::

:::tip{title="「#」在不同地方的意思"}

- 在待办页的输入框里，`#工作` 指待办项目「工作」；名字对不上已有的待办项目时，它会原样留在标题里。
- 在日程页的快速添加里，`#工作` 指名为「工作」的日历。
- 在文档的勾选项里，`#工作` 同样指待办项目，见下文「文档里的待办」。
- 在 [日记](/docs/diary/) 里，`#读书` 是标签；在编辑器里，行首输入 `#` 再按空格是标题。

:::

## 查看和管理

待办默认按日期分段：已逾期、今天、明天、本周稍后、以后、无日期。点击右上角的「按项目」或「按优先级」可以切换分组方式；点击「筛选」可以按优先级和标签多选过滤，点击待办行上的 `#标签` 也能直接按该标签筛选。在筛选面板里悬停某个标签，可以通过更多菜单重命名或删除该标签。

- **完成**：点击待办前的圆圈。完成的待办收进该段末尾的「已完成」。周期任务点圆圈表示「今日打卡」。
- **编辑**：点击一条待办，右侧打开详情。可以设置优先级（无、低、中、高）与标签，改类型（普通、截止、周期）和截止时间，设置重复规则和提醒，写描述，添加子任务，或者关联卡片、文章作为参考资料。描述输入区不显示段落左侧的拖拽手柄。
- **右键快捷操作**：右键点击一条待办，可以直接修改「优先级」和勾选「标签」，在「改期」里选今天、明天或下周一，或在「移动到」里换一个待办项目。
- **删除**：右键选「删除」。删除不会弹确认框，底部会出现「撤销」，几秒内点击即可恢复。

点击右上角的「今日」，会打开今日概览：今天要打卡的周期任务、本周每天的任务量，以及最近完成的事。

待办列表、详情和项目管理会跟随界面语言显示，任务标题、描述和自定义项目名保留原文。切换语言会保留草稿、过滤条件和当前任务。日期与提醒选择器也会跟随语言，已经选定的日期、时刻和提醒保持不变；日期网格从周一开始。

### 到点提醒

同一条截止任务或日程可以勾选多个提醒，比如同时选「1 天前」「1 小时前」「5 分钟前」和「准时」。截止任务在详情的「提醒」里选，可选「准时」到「2 天前」；日程在编辑窗口的「提醒」里选，全天日程则按「当天 9:00」「前一天 20:00」这样的时刻提醒。

到了时间，Tau 会弹出通知，在你处理之前一直留着。点通知里的「查看」，Tau 会回到前台并直接打开这条待办或日程。

### 周期任务和打卡

「每天晨读」「每周一、四健身」这类习惯，用周期任务来记。在详情里可以看到连续打卡的天数、近 12 周的完成率，以及一张打卡格。点击过去的格子可以补打卡；今天确实做不了，可以选「跳过今天」，不算断签。

设置重复规则时，可以选每天、每周几、每月几号，还可以勾选「排除法定节假日」。在详情里把类型改为「截止」或「普通」后，再选「周期」，会恢复原来的重复规则和打卡记录。

### 待办项目

侧边栏「待办」下方列出了你的所有待办项目，后面的数字是未完成的条数。点击一个只看它，再点一次回到全部。右键可以编辑、归档或删除；归档的待办项目在「已归档」里，点击即可恢复。

### 文档里的待办

在任意卡片、文章或日记里输入 `[]` 加空格，就能写一个勾选项。这些勾选项会汇总到侧边栏「待办 › 文档中」，按文档分组。在这里勾选，原文中的勾选项也会同步勾上。

勾选项的文字在原文里改：写上 `#工作` 就归入这个待办项目，写上「周五」这样的日期就排进对应的那一天。点开一条，可以「打开原文定位」；需要周期、番茄或日程时，点「转为独立待办」，原文保持不变。某篇文档的勾选项不想出现在待办里，点「本文不收集」。

## 日程

日程页以日历的形式安排时间，有月、周和议程三种视图。

新建定时日程时照常选择时间，Tau 自动记录设备时区。换到另一个时区，重新打开日历或回到前台即可看到当地时间，提醒仍在同一时刻触发。全天日程按日期显示。旧日程保留原有记录。旧版 Tau 也可以打开资料库、查看日程。旧版按保存的日期和时间显示，跨时区或夏令时切换时，显示和提醒可能有偏差。修改这类日程的时间请使用支持时区的版本。

::demo{name="schedule" caption="把右侧「待安排」中的待办拖到某一天；双击空白日期可新建全天日程"}

- **新建日程**：点击「新建日程」；也可以在月视图双击某一天，或横向拖过几天新建跨天日程；在周视图里拖选一段时间。
- **快速添加**：点击右上角的「今天 · N 项」打开当日时间线，在底部输入「明天 3 点 评审 #工作」按回车，`#工作` 会把它放进「工作」日历。
- **安排待办**：点击「待安排」，把还没排时间的待办拖进日历或时间线上的空档。
- **补记**：当日时间线里，过去两段日程之间的空隙可以直接补记刚才做了什么。
- **日历**：日程上方的彩色标签是不同的日历，点击可以显示或隐藏。在「管理日历」里可以分组、新建、归档或合并日历。

有截止时间的待办和完成的番茄专注会自动显示在日历上。这些条目在日历里只能查看，要修改请回到对应的待办或专注记录。

打开一条有具体时间的日程，点击「开始专注」，就能用 [番茄专注](/docs/pomodoro/) 为它计时。

## 一个例子

周一早上，你在待办页依次输入：

1. `周三 17:00 交选题报告 #工作`，这是一条截止任务，打开详情把提醒设成「1 天前」和「1 小时前」；
2. `每天 晨读 30 分钟`，每天打卡；
3. `周四 14点到16点 写报告初稿 #工作`，直接在周四下午占好两个小时。

周二下午 5 点，通知提醒你明天要交选题报告，点「查看」就回到这条待办。到了周四下午 2 点，在「今日」的日程里点开「写报告初稿」，点「开始专注」。写完后回到日程页，会看到这两个小时里专注的时段已经画在了日历上。

想把专注计时用得更顺手，接着读 [番茄专注](/docs/pomodoro/)。

## 通过插件处理待办与日程

你可以把待办或日程的读写权限授予需要使用这些内容的插件。插件能选择或新建待办项目和日历，修改目录名称与颜色，保留普通待办的提醒，以及日程的提醒和备注。改名后，原来的待办和日程仍在对应项目或日历里。只读日历不能修改；是否关联其他服务、处理哪些项目，由所用插件的功能和设置决定。安装和授权见[插件](/docs/plugins/)。

提醒设置、权限说明和应用内提醒操作会跟随界面语言。切换语言会保留设置和已显示的提醒，不会重新请求权限、重排或重复通知；既有提醒标题与正文保持原样。

新排期的系统提醒使用排期时的界面语言，包括操作按钮和稍后提醒说明。既有提醒保留原有语言、标题与正文；切换语言不会重新排期。Android 通知渠道的显示名称与说明在下次排期时更新，已有通知偏好保留。

正文任务的项目选择、日期操作与即时反馈会跟随界面语言。切换语言保留候选、定位和当前任务，不会改变日期或移动任务；项目名称与正文保持原样。
