Notebook 用来围绕一个主题集中学习。你把相关的 PDF、网页、视频和笔记放进同一个 Notebook，边读边向 AI 提问，再让 AI 把读过的内容整理成大纲、重点、思维导图、测验，甚至一期播客。

使用 Notebook 需要先连接 AI 模型，详见 [AI 对话与洞见](/docs/ai/)。

## 一个完整的例子

假设你想在两周内弄明白「怎样才能长时间专注」。手头有一本《心流》的 PDF、一篇讲注意力被打断的网页文章、一段深度工作的讲座视频，还有自己以前写过的几张卡片。

1. **新建 Notebook**：名称写「专注与深度工作」，描述写「搞懂专注为什么难，以及有哪些可练习的方法」。
2. **放进资料**：依次添加 PDF、网页、视频，再从卡片库里选出那几张旧卡片。
3. **边读边问**：打开《心流》第三章，读到不懂的地方就在右侧问 AI，比如「为什么被打断之后很难回到原来的状态？」。AI 会去所有资料里找答案，而不只是当前打开的这一份。
4. **整理产物**：读完一份资料，点底部的「重点提炼」；全部读完后，基于所有资料生成一份「学习大纲」和一套「测验」。
5. **检验自己**：过几天做一遍测验，看看哪些还没记住。

下面按这个顺序介绍每一步。

## 新建 Notebook

在侧边栏「学习」分组中点击「Notebook」，然后点击「新建 Notebook」，填写名称和描述。

描述就是这次的学习目标，值得认真写一两句。AI 回答时会围绕它组织资料，还会指出现有资料没有覆盖到的部分。之后想调整，可以随时编辑。

## 添加资料

打开 Notebook，点击左侧「资料」旁的「+」，选择来源：

| 来源 | 说明                                                           |
| ---- | -------------------------------------------------------------- |
| 文件 | 点击或拖入文件，支持 PDF、Office、Markdown、音视频和图片       |
| 网页 | 粘贴网页地址，Tau 会剪藏正文；标题可以留空，自动从网页提取     |
| 视频 | 粘贴视频链接并选择清晰度，Tau 会在后台下载并转写成文字         |
| 笔记 | 从卡片库、文章、项目文档和日记中挑选已有的内容，可以一次选多篇 |

资料加入后，Tau 会在后台转换成文本并建立索引，完成前目录里会显示处理状态。处理完成后，AI 才能检索这份资料。

:::info{title="添加视频需要先装插件"}
视频来源由插件提供。先在 [插件](/docs/plugins/) 中安装 Bilibili、YouTube 等视频来源插件，「视频」里才能选择来源。
:::

在资料上点击「⋯」，可以重命名、删除，或「用默认程序打开」原件。如果某份资料处理失败，可以选择「重新处理」。

## 阅读与提问

::demo{name="notebook" caption="点击左侧的一份资料将其打开，对话会移到右栏；再点击底部「基于这份资料」中的「测验」"}

Notebook 是一整张纸，分为三栏：

- **左栏**：目录，上方是资料，下方是产物。
- **中栏**：当前打开的资料或产物。
- **右栏**：对话。什么都没打开时，对话显示在中间。

AI 知道这个 Notebook 的学习目标和所有资料，提问时不需要重复交代背景。它会先在资料里搜索、读原文，再回答；如果资料里没有，它会直接告诉你，而不是凭空补全。点击对话上方的「新对话」可以开始一个新话题，之前的对话可以从标题处的下拉列表找回。

:::tip{title="怎么问效果更好"}

- 问具体的问题：「第三章说的挑战与能力匹配，和讲座里的刻意练习是一回事吗？」比「讲讲心流」更容易得到有用的回答。
- 让 AI 对比资料：「这几份资料在专注能不能练习这件事上，观点有什么不同？」
- 让 AI 指出盲区：「关于怎样减少被打断，我的资料还缺什么？」
:::

## 整理产物

产物是 AI 根据资料生成的学习材料，有八种：

| 产物     | 适合用来                     |
| -------- | ---------------------------- |
| 学习大纲 | 梳理成一条由浅入深的学习路径 |
| 重点提炼 | 提取核心知识点，复习时看     |
| 文章     | 写成一篇可以直接阅读的长文   |
| 思维导图 | 把知识结构画成导图           |
| PPT      | 生成一份演示文稿             |
| 报告     | 生成一份分析报告             |
| 测验     | 出一套自测题                 |
| 播客     | 生成一期双人对话播客         |

有两个入口：

- **基于一份资料**：打开资料后，底部有「基于这份资料」一行，可以直接生成学习大纲、重点提炼、思维导图或测验，其他类型在旁边的「⋯」里。
- **基于全部资料**：点击「产物」旁的「+」，选择要生成的类型。

两种方式都会打开一个设置窗口，你可以勾选要用哪些资料，选择文章、PPT、报告的风格，再写下额外要求，比如「重点关注概念和公式，适合考试复习」。点击「开始生成」后，内容在后台生成，你可以离开这个页面去做别的事。生成过程中，目录里的产物会显示「生成中」。

在对话中也可以直接让 AI 生成产物，比如「把刚才讨论的内容整理成一份学习大纲」，或者「把这个回答存成笔记」。

:::info{title="生成播客需要先配置语音"}
播客要为主持人和嘉宾选择音色，需要先在设置中配置 TTS 服务。
:::

### 使用产物

- **测验**：点击测验即可开始作答，交卷后显示正确率和用时。在测验的「⋯」中可以查看「测验记录」或「编辑题目」。
- **PPT 和报告**：在「⋯」中选择「AI 编辑」，写下修改要求，比如「第 3 页加一个流程图」，AI 会按要求改写。
- **加入资料**：在产物的「⋯」中选择「加入资料」，这份产物就成了新的学习资料，之后的提问和生成也会参考它。

点击「产物」旁的「+」，选择「新建笔记」，还可以手写自己的笔记。

:::tip{title="测验之后，把错题做成闪卡"}
测验适合检验刚学完的内容，[闪卡](/docs/flashcards/) 适合长期记住。做测验时发现总是答错的知识点，可以单独做成闪卡，交给复习计划。
:::
