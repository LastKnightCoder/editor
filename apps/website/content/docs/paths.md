## 每条路线的第一周

读完文档，最好马上用起来。下面是每条路线第一周可以试的事，不必一次做完。

**随手记**

- 每天写两三张卡片，随手加一个宽泛的标签；
- 晚上在 [日记](/docs/diary/) 里用一两句话记下今天；
- 一周后打开 [漫步](/docs/walk/)，看看 Tau 帮你翻出哪些旧想法。

**读书学习**

- 把一本正在读的书或一篇 PDF 收进 Tau，边读边划线，见 [收集与阅读](/docs/reading/)；
- 读完一章，把有感触的划线转成 [卡片](/docs/cards/)，再用自己的话补上理解；
- 挑三五个关键概念做成 [闪卡](/docs/flashcards/)，第二天开始复习。

**写作输出**

- 先读 [编辑器基础](/docs/editor/)，熟悉 Markdown 语法和 `/` 插入菜单；
- 选一个主题，把相关的卡片串成一篇 [文章](/docs/articles/)；
- 内容多了，建一个 [项目](/docs/projects/)，按目录整理成一套文档。

**管好每一天**

- 早上在 [待办](/docs/todos/) 用一句话记下今天要做的事，带上时间；
- 用 [番茄专注](/docs/pomodoro/) 为最重要的一件事计时；
- 每天打开 [今日](/docs/today/) 看一眼，养成习惯。

## 不确定选哪个

从「随手记」开始最轻松：每天写几张卡片，过一段时间再回头看。熟悉之后，再按需要试试其他功能。

如果你已经在用别的笔记软件，可以先把旧笔记导入进来，见 [数据与备份](/docs/data/)。
