Tau 的功能不少，刚开始不用全部了解。在下面找一条和你的目的最接近的路线，按顺序读完那几篇，再照着「第一周」试一试。其他功能等用得上时再来查。

## 随手记

适合想到什么就记一笔、以后再慢慢整理的人。

先读：[卡片](/docs/cards/) → [日记](/docs/diary/) → [漫步与知识地图](/docs/walk/)

第一周可以试：

- 每天写两三张卡片，随手加一个宽泛的标签，比如「读书」「工作」；
- 晚上在日记里用一两句话记下今天；
- 一周后打开漫步，看看 Tau 帮你翻出了哪些旧想法。

## 读书学习

适合在读一本书、上一门课，想把读到的东西真正记住的人。

先读：[收集与阅读](/docs/reading/) → [Notebook](/docs/notebook/) → [卡片](/docs/cards/) → [闪卡复习](/docs/flashcards/)

第一周可以试：

- 把正在读的《深度工作》PDF 收进 Tau，边读边划线；
- 把这本书放进一个 Notebook，问 AI 你没读懂的地方；
- 读完一章，把有感触的划线转成卡片，用自己的话补上理解；
- 挑三五个关键概念做成闪卡，第二天开始复习。

看课程视频的话，再读一篇 [视频笔记](/docs/video-notes/)。

## 写作输出

适合要写长文、写读书笔记，或者想把文章发到网上的人。

先读：[编辑器基础](/docs/editor/) → [文章](/docs/articles/) → [发布](/docs/publish/)

第一周可以试：

- 熟悉 Markdown 写法和输入 `/` 弹出的插入菜单；
- 选一个主题，把相关的几张卡片串成一篇文章，写的时候打开创作模式对照资料；
- 挑一篇满意的，发布成自己的网站。

## 做知识库

适合想把一个领域系统地整理成一套文档，比如课程笔记、研究方向、个人手册的人。

先读：[项目](/docs/projects/) → [卡片](/docs/cards/) → [漫步与知识地图](/docs/walk/) → [发布](/docs/publish/)

第一周可以试：

- 建一个「深度工作」项目，按「为什么重要」「怎么练习」「常见阻碍」分出几篇文档；
- 平时零散的想法先记成卡片，写项目文档时用 `@` 引用它们；
- 在知识地图上看看哪些内容还没和别的连起来；
- 整理得差不多了，在发布页勾选这个项目里要公开的文档，发布成一个知识库网站。

## 用 AI 帮忙

适合想让 AI 帮你查自己写过的东西、改写内容、安排待办的人。

先读：[AI 对话与洞见](/docs/ai/) → [Notebook](/docs/notebook/) → [Skill 与 MCP](/docs/skills-mcp/)

第一周可以试：

- 接入一个模型服务商，在「功能分配」里给「对话功能」和「AI 洞见」选上模型；
- 按 <kbd>⌘J</kbd>（Windows 上为 <kbd>Ctrl+J</kbd>）打开对话栏，问一句「我写过哪些关于专注的内容？」；
- 打开一张卡片，点标题下方的「AI 洞见」，看它和哪些旧内容呼应、哪里有矛盾；
- 有一套固定的做事方法，比如每周复盘的格式，把它写成一个 Skill。

## 画图梳理

适合想先把思路摊开、画思维导图或流程图，再动笔的人。

先读：[白板](/docs/whiteboard/) → [卡片](/docs/cards/) → [项目](/docs/projects/)

第一周可以试：

- 新建一块白板，用思维导图拆出《深度工作》的几个主题；
- 把相关的读书卡片拖到导图旁边作参考；
- 画一个画框，排出你每天的深度时段；要讲给别人听时，把画框排成演示序列逐帧放映。

## 管理结构化数据

适合要记书单、观影记录、学习计划这类一条一条、有固定属性的数据的人。

先读：[数据库](/docs/database/) → [编辑器基础](/docs/editor/)

第一周可以试：

- 建一个书单数据库，列出书名、作者、状态和页数，录入几本书；
- 切到看板，按「想读 / 在读 / 读完」拖动；
- 加一列公式算阅读进度，再把这个数据库插到一篇文章里。

## 管好每一天

适合想用一个地方管待办、日程和专注时间的人。

先读：[今日](/docs/today/) → [待办与日程](/docs/todos/) → [番茄专注](/docs/pomodoro/)

第一周可以试：

- 早上在待办页用一句话记下要做的事，比如「周五 17:00 交周报」，日期和时间会自动识别；
- 用番茄专注为最重要的一件事计时；
- 每天先打开今日看一眼，过期的待办处理掉或改个日期。

## 拿不准选哪条

从「随手记」开始最轻松：每天写几张卡片，过一段时间再回头看，熟悉之后再按需要试别的路线。已经在用别的笔记软件，可以先把旧笔记导入进来，见 [数据与同步](/docs/data/)。

选好路线，就从清单里的第一篇读起。
