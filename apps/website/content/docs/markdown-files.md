电脑上已有的 Markdown 文件，比如博客草稿、项目 README、别的软件导出的笔记库，不用导进资料库。用 Tau 打开，就是一个单独的编辑窗口，写完保存回原文件，和资料库互不影响。

快捷键以 macOS 为例，Windows 上把 <kbd>⌘</kbd> 换成 <kbd>Ctrl</kbd>。

## 打开

安装后，`.md` 文件的「打开方式」里会出现 Tau，双击就直接进入编辑窗口，不经过主界面。也可以按 <kbd>⌘K</kbd> 打开命令面板，选「打开 Markdown 文件 / 文件夹」，再按 <kbd>⌘O</kbd> 打开文件、<kbd>⌘⇧O</kbd> 打开文件夹、<kbd>⌘N</kbd> 新建。刚打开时的欢迎页里，列着最近打开过的文件。

## 写

用的就是资料库那套编辑器：Markdown 语法输入即排版，`/` 插入菜单、悬浮工具栏、快捷键都一样，写法见 [编辑器基础](/docs/editor/)。按 <kbd>⌘/</kbd> 或点窗口右下角的代码图标，可以在排版视图和源码之间切换，光标位置不变。

- 粘贴的图片自动存在文件旁边，正文里是相对路径，整个文件夹拷到别处，图片照样显示；
- 正文里指向 `.md` 文件的链接，点击就在当前窗口打开，网页链接交给系统浏览器。

## 打开文件夹

打开一个文件夹，左侧是文件树。右键可以新建文件或文件夹，<kbd>F2</kbd> 重命名，拖动移动；删除走「移到废纸篓」（Windows 上为回收站），删错了还能找回。文件夹在别的软件里有了改动，文件树会自动跟上。

只打开单个文件时没有侧栏，按 <kbd>⌘\</kbd> 可以开关它。

## 长文章

- 标题大纲贴在正文右缘，点击直达那一节；
- 按 <kbd>⌘F</kbd> 全文查找；
- 文章再长也流畅：只渲染正在看的部分，复制和保存拿到的始终是全文。

## 保存与导出

内容自动保存，<kbd>⌘S</kbd> 立即保存，窗口底部显示保存状态。

- 文件在别的软件里被改了：这边没有改动就自动同步，两边都改了才需要你选一版；
- 文件被删除或移走：内容还在窗口里，可以另存为。

「⋯」菜单里可以复制成公众号排版格式，或导出为 Word 文档、图片、EPUB、PDF。

想把整库笔记收进资料库、和卡片文章连起来，见 [数据与同步](/docs/data/)。
