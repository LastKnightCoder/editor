卡片、文章和项目文档都是「输出」——把你的理解用自己的话写下来。它们没有大小之分，只是适合的内容不同。

## 卡片

适合随笔、短思考、读书时的一闪念。写卡片不需要想标题，也不用决定它属于哪里，用标签归类即可。

## 文章

适合需要展开论述的长篇：读书笔记、观点文章、复盘总结。文章有封面、大纲和字数统计，长文也能一眼看清结构。

:::tip{title="创作模式"}
写文章时打开「创作模式」，左边是白板，右边是正文。可以先把相关的卡片和资料摆到白板上，再对照着写，不用从一张白纸开始。
:::

## 项目文档

适合把一个领域系统地整理成目录层级，比如一门课的笔记、一个研究方向、一份个人手册。项目就是一棵文档树，可以随时调整层级和顺序。

## 怎么选

| 想写的内容               | 推荐     |
| ------------------------ | -------- |
| 一个念头、一段摘录的感想 | 卡片     |
| 一个完整的观点或一次复盘 | 文章     |
| 一整个主题的系统整理     | 项目文档 |

三者都会进入同一张知识地图，可以互相引用。先用卡片记下来，日后再把相关的卡片组织成文章或项目文档，是很常见的写法。
