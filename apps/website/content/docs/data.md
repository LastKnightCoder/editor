Tau 是本地优先的：资料库保存在你自己的电脑和手机上，不需要注册账号，离线也能用。只有在你使用同步、协作、发布或 AI 时，相关内容才会离开这台设备：同步发往你自己的另一台设备或你自己的云存储，协作经过 Tau 的协作服务，发布到你选的托管服务，AI 只发给你配置的模型服务商。

## 数据存在哪里

Tau 的数据都放在你个人目录下一个名为 `.editor` 的文件夹里：

| 系统    | 位置                                        |
| ------- | ------------------------------------------- |
| macOS   | `~/.editor`，即 `/Users/你的用户名/.editor` |
| Windows | `C:\Users\你的用户名\.editor`               |

这个文件夹以 `.` 开头，默认是隐藏的。在 macOS 的访达里按 <kbd>⌘⇧.</kbd> 可以显示隐藏文件；在 Windows 的文件资源管理器中，勾选「查看 › 显示 › 隐藏的项目」。

文件夹里最重要的是这几样：

| 文件或文件夹   | 内容                                                                       |
| -------------- | -------------------------------------------------------------------------- |
| `data.db`      | 资料库文件：卡片、文章、项目、日记、待办、白板、闪卡等几乎所有内容都在这里 |
| `resources/`   | 你插入笔记的本地图片、音视频和附件                                         |
| `setting.json` | 设置：外观、同步服务、模型服务商（含 API Key）等                           |
| `plugins/`     | 已安装的插件                                                               |
| `backup/`      | 用别处的版本替换本机资料库之前，自动留下的本地备份                         |

:::info{title="可以有多个资料库"}
在「设置 › 同步 › 本地数据库」中可以新建，比如把工作笔记和个人笔记分开。每个资料库是 `.editor` 里的一个 `.db` 文件，切换后，内容和同步都针对当前这一份。
:::

## 在设备之间同步

「设置 › 同步」里有两种同步方式，手机上在「我的 › 同步」：

|              | 设备同步                                 | 云端存储                                                       |
| ------------ | ---------------------------------------- | -------------------------------------------------------------- |
| 适合         | 电脑和手机常在同一个 Wi‑Fi 下            | 设备不在一处，或者想在云端留一份                               |
| 需要准备     | 一台常开的电脑负责协调                   | 一个同步插件和你自己的云存储（WebDAV、S3、阿里云 OSS、GitHub） |
| 什么时候同步 | 自动：打开 Tau、回到窗口或重新联网时补齐 | 手动：点「同步到云端」或「拉取远程」                           |
| 两边都改了   | 合并两边的修改，正文都保留               | 不合并，后上传的一份覆盖另一份                                 |

还是用一个例子：你在家里的台式机上写《深度工作》的读书笔记，出门带着笔记本电脑和手机。台式机常开，大家都连着家里的 Wi‑Fi，用设备同步最省心；出差时想在酒店接着写，再配一个云端存储。

## 设备同步

设备同步让一份资料库在你的几台设备之间自动保持一致。其中一台电脑负责协调，其他电脑和手机连接它。每台设备都能离线编辑，回到同一个局域网后自动补齐，不需要所有设备同时在线。

同步的内容包括笔记、标签、数据库修改和正文里的图片；AI 对话记录、单独的 PDF 原件、插件和账号设置不在其中，需要在每台设备上分别设置。

### 选一台电脑协调

协调电脑应该是资料最全、平时常开着的那台，比如例子里的台式机。一份资料库只由一台电脑协调，之后不能改由其他设备协调，所以先想好再开启。手机只能连接，不能协调。

1. 在协调电脑上打开「设置 › 同步 › 设备同步」，选「由本机协调」，点「开启并协调」。
2. 点「添加设备」，Tau 会生成一段以 `tau-pair:` 开头的配对信息。每段只给一台设备用，5 分钟内有效，过期了重新生成即可。
3. 点复制，经隔空投送、备忘录或自己的聊天工具发到要连接的设备上。配对信息只发给你自己的设备。

### 连接其他设备

- **另一台电脑**：打开「设置 › 同步 › 设备同步」，在「连接已有协调电脑」里粘贴配对信息，点「配对并建立本机副本」。
- **手机**：打开「我的 › 同步」，在「局域网设备同步」里点「粘贴配对信息」，再点「配对」。第一次会请求「本地网络」权限，选允许。

第一次配对会从协调电脑下载整份资料库，新建一份本机副本，原来的资料库保持原样。资料较多时要等几分钟，手机上请让 Tau 留在前台。配对完成后，协调电脑的设备列表里会出现这台设备。

### 之后怎么用

之后不用再管。连接的设备在打开 Tau、回到窗口、从睡眠中唤醒或重新联网时自动和协调电脑补齐，失败了会自动重试。想马上同步，点「立即补齐」。

在路上用手机改了笔记，或者在没网的地方用笔记本写了一段，修改都先保存在本机，连上协调电脑后再补齐。几台设备改了同一篇正文，修改会合并，正文都会保留。少数没法自动合并的情况，Tau 会留一份冲突副本，日常同步照常继续；在协调电脑的设备同步页里可以查看这些副本，另存或导出。

图片会在正文之后下载，没下完的图片稍后显示，不影响阅读和编辑。

### 连不上时

设备同步页会写明连不上的原因。最常见的几种：

- 两台设备不在同一个局域网；
- 协调电脑上的 Tau 没有开着，或者暂停了局域网连接；
- 防火墙拦住了 Tau（端口 24721）；
- 协调电脑换了网络地址，这时在连接的设备上点「⋯ › 重新粘贴配对信息」，修改都会保留；
- 两台设备的 Tau 版本不一致，都更新到最新版本即可。

协调电脑的「⋯」里可以暂停局域网连接；设备列表里每台设备的「⋯」可以解除配对，解除后那台设备就连不上了，它本机的内容不会被删除。

### 换成协调电脑的版本

某台设备上的资料明显不对时，可以用协调电脑的版本整份替换它：电脑上在设备同步页的「恢复」里点「下载协调电脑版本并覆盖本机」，手机上是「用电脑版本覆盖这台手机」。

这会丢弃这台设备上还没同步到协调电脑的修改、草稿和撤销记录，账号、配对信息和其他资料库不受影响。电脑上原来的资料库会先备份到 `backup` 文件夹。只有连得上协调电脑时才能用。

:::warning{title="设备同步不能和协作共享同时用"}
一份资料库里有正在协作共享的正文时，不能开启设备同步，要先在 [协作](/docs/collaboration/) 里结束共享；已经开启设备同步的资料库，也不能再把正文共享给别人协作。两样都要用，可以把要共享的内容放在另一份资料库里。
:::

## 云端存储

云端存储把整份资料库上传到你自己的云存储，其他设备再从那里下载。它不会合并两边的修改，适合同一时间只在一台设备上写的情况。

### 配置云端存储

云端存储由插件提供。第一次配置时，需要先装一个同步插件：

1. 点击侧边栏底部的「插件」，在「发现」中选择「同步」分类，安装一个同步插件，例如「WebDAV 存储」，装好后它会直接启用。可选的还有「S3 同步存储」「阿里云 OSS 同步存储」「GitHub 同步存储」。
2. 打开「设置 › 同步 › 云端存储」，在「同步服务」中找到刚才的服务，点击「去配置」。
3. 在打开的插件设置页填写账号和存储位置，点击「保存并测试」。看到「连接正常」后，点击「设为同步服务」。
4. 回到「设置 › 同步 › 云端存储」，在「数据库」卡片上点击「同步到云端」。

::demo{name="sync-setup" caption="点击「去配置」填写 WebDAV 账号，依次点「保存并测试」「设为同步服务」，回到同步页后点「同步到云端」"}

### 日常同步

云端存储需要你手动触发：写完点「同步到云端」，换到另一台设备先「拉取远程」。上传和下载时按钮上会显示完成的百分比。「数据库」卡片显示本地版本和远程版本，每上传一次，版本号加一。

- 远程版本比本地新时，说明另一台设备上传过，按钮会变成「拉取远程」。拉取前，本地的资料库会先复制一份到 `backup/` 文件夹。
- 本地版本落后时仍要上传，可以点「强制上传」。这会用本地内容覆盖云端，另一台设备上传的修改会丢失，请确认后再操作。
- 「资源文件」卡片单独显示图片、附件的同步进度。同步失败的文件可以在「资源文件」标签中查看和重试。

:::warning{title="两台设备别同时改"}
云端存储以整份资料库为单位上传下载，不会合并两边的修改。在一台设备上写完后先「同步到云端」，换到另一台设备时先「拉取远程」再动笔，就不会互相覆盖。
:::

### 手机上用云端存储

1. 先在电脑上配好云端存储，并点「同步到云端」上传一次。
2. 在手机上打开「我的 › 同步」。还没有同步服务时，「云端存储同步」下面会列出可选的存储服务；没有你要的服务，点「去插件中心添加同步服务」安装它。
3. 点击服务，填入和电脑上完全相同的账号与存储位置，点右上角「保存」。保存后会自动测试连接，显示「连接正常」和云端已有的版本。
4. 点「设为当前」，回到同步页，点「下载更新」把电脑上的内容下载到手机。

之后在同步页点中间的主按钮即可。按钮会根据两端版本变化：云端有更新时是「下载更新」，手机上的版本更新时是「上传改动」，两端一致时是「立即同步」。资料库同步完成后，图片和附件会在后台接着同步，进度显示在「资源文件」一行。从云端下载前，手机上原来的资料库会先自动备份。

如果某一端的数据出了问题，需要强制以另一端为准，在同步页「更多」里打开「整库覆盖」，选择「以本机为准」或「以云端为准」。被覆盖一侧未同步的修改会丢失，无法撤销，所以要按住按钮确认。

## 备份

同步不等于备份：误删的内容也会同步到其他设备。为了防止误操作或设备损坏，建议再用一种方式留一份：

- **定期导出**：把全部内容导出为 Markdown 压缩包，存到移动硬盘或网盘。
- **系统备份**：用 macOS 的时间机器或 Windows 的文件历史记录备份整台电脑，`.editor` 文件夹会一起备份。
- **云端存储**：上传到云端的那一份也可以当作备份，记得写完点「同步到云端」。

### 导出

打开「设置 › 导入与导出」：

- **导出为 Markdown 压缩包**：点击「选择范围」，选项目、文章、卡片或全部内容，可以只勾选其中几篇。「本地资源」选「打包进 assets/」，图片会一起打包、正文改为相对路径，换到别的软件也能正常显示；打开「同时下载远程图片」，图床上的图片也会下载进压缩包。
- **导出为 PDF / EPUB**：在项目列表里点击项目卡片的「⋯」，选「整体导出」，按文档树排版成一本书。
- **导出单篇**：卡片、文章、项目文档的「⋯」菜单里有「导出」，有本地图片时会导出为带 `assets/` 的压缩包。

Markdown 是通用的纯文本格式，大多数写作工具都能打开，你的数据不会被锁在 Tau 里。

## 导入

从其他笔记软件搬过来时，先在原软件里导出 Markdown，然后在「设置 › 导入与导出」中点击「选择来源」：

1. 选择一个文件夹或 `.zip` 压缩包。Tau 会自动识别来源格式，支持通用 Markdown、Obsidian、Notion 和 Logseq，识别有误时可以手动换一种。
2. 选择导入为项目（保持原来的目录结构）、文章或卡片。
3. 预览确认后开始导入。正文引用的本地图片会一起导入，文档之间的 `.md` 链接会转成 Tau 里的内部链接。

也可以直接把文件夹或压缩包拖到卡片、文章或项目页面上。导入后发现不对，可以在同一页的「导入记录」中点击「撤销」，这次导入建出的内容会全部删除。

## 换电脑

换电脑时，把旧电脑上的数据完整带到新电脑上。有两种做法。

### 方法一：用云端存储迁移（推荐）

适合已经配置了云端存储的情况，图片附件也会一起过去。

1. 在旧电脑上打开「设置 › 同步 › 云端存储」，点击「同步到云端」，等「数据库」和「资源文件」两张卡片都显示同步完成。
2. 在新电脑上 [安装 Tau](/docs/install/)，打开后先到「插件」中安装并启用同一个同步插件。
3. 打开「设置 › 同步 › 云端存储」，点击这个服务的「去配置」，填入和旧电脑完全相同的账号与存储位置，点击「保存并测试」。这时会提示云端已有数据库。
4. 点击「设为同步服务」。因为云端已有数据，Tau 会先弹窗确认，点击「切换」。
5. 回到同步页，点击「拉取远程」，再在「资源文件」卡片上点击「同步」，下载图片和附件。

这样迁移的是资料库和资源文件。外观、模型服务商这类设置不随同步走，需要在新电脑上重新设置一遍，比如到「设置 › AI 服务 › 大语言模型」重新添加服务商。

### 方法二：直接复制数据文件夹

不想用云端存储，或者要连设置一起带走时，可以直接复制整个 `.editor` 文件夹。

1. 在旧电脑上完全退出 Tau：macOS 上按 <kbd>⌘Q</kbd>，Windows 上从系统托盘退出。资料库还在写入时复制，可能得到不完整的文件。
2. 把整个 `.editor` 文件夹复制到移动硬盘或网盘。
3. 在新电脑上安装 Tau，但先不要打开；如果已经打开过，请先退出。
4. 把 `.editor` 文件夹放到新电脑的个人目录下（位置见上文「数据存在哪里」），已有同名文件夹时先改名备份。
5. 打开 Tau，内容、设置和插件都会恢复。

:::warning{title="复制的文件夹里有密钥"}
`setting.json` 里保存着你的同步账号、模型 API Key 等信息。拷贝 `.editor` 文件夹时请妥善保管，用完删掉移动硬盘或网盘上的副本。
:::

迁移完成后，旧电脑上的数据仍然保留。确认新电脑一切正常后，再决定是否删除。

## 卸载前

卸载 Tau 不会自动删除 `.editor` 文件夹。如果打算彻底删除，请先确认重要内容已经同步或导出，再手动删除这个文件夹。

## 分享内容

如果希望别人看到你的内容，可以使用以下两种方式：

- **[发布](/docs/publish/)**：把选中的内容生成为一个网站；
- **[协作](/docs/collaboration/)**：共享一篇文章，与他人实时编辑。
