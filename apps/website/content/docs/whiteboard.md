白板是一张无限画布：可以画思维导图、梳理流程，也可以把卡片、文章和图片摊在一起比较、归类。画好的白板还能直接拿来演示。

在[全局搜索](/docs/shortcuts/#全局)中选择「白板」，可以按标题或描述查找，打开结果即可进入对应白板。

比如你在做《深度工作》的读书计划：用思维导图拆出「为什么重要」「怎么练习」「常见阻碍」，再在旁边画一个画框，用形状和箭头排出每天的深度时段，最后把相关的读书卡片拖进来作参考。

白板列表、创建与编辑信息、标签筛选、删除和选择弹窗会跟随界面语言。切换语言会保留正在写的名称、描述、筛选和勾选；白板内容及已保存的标题、标签保持原文。

## 新建白板

在侧边栏点击「白板」，点击「新建白板」，填写标题；描述和标签都可以不填。加了标签的白板会出现在侧边栏「白板」下方，点击标签即可筛选。

白板列表以缩略图显示所有白板。鼠标在缩略图上左右移动，可以快速翻看每一页，点下去打开的就是看到的那一页。右上角可以搜索标题，或按最近更新、创建时间、名称排序。

未共享的白板长期编辑后，关闭最后一个打开它的视图，会在保存完成后自动整理累积的编辑记录。再次打开即可继续编辑，无需手动整理。共享白板重新连接后的离线内容见[协作](/docs/collaboration/)。

白板页签、重命名、侧栏开关与会话恢复提示也会跟随界面语言。切换语言会保留活动页、历史、正在编辑的页名和已打开的共享确认，不会重新创建画布或重复操作。

白板工具栏、创建提示和几何工具菜单会跟随界面语言。切换语言会保留打开的菜单和当前工具，不会重复创建元素；画布内容、形状默认名称与插件自定义提示保持原样。

白板属性、笔触、颜色与数值调节提示会跟随界面语言。切换语言会保留正在输入的数值、选区和滑杆状态；元素属性值、颜色与画布内容保持原样。

## 用工具栏做事

画布顶部工具栏最左边的按钮显示当前指针模式。点它右侧的小箭头，可以选择「指针」「抓手」或「文本」。使用其他工具时，点主按钮就能回到它显示的模式。

- **指针**是默认模式。点一下选中对象，拖动对象可以移动，拖动空白处可以框选。双击空白处可以直接输入文本，输入时隐藏文本的连接点。
- **抓手**用来移动视野。从文字、图片或空白处按住鼠标左键拖动，都可以平移画布。
- **文本**适合随手记。点一下空白处就会出现可输入的文本框，再点另一处空白就能接着写下一段。点已有文字可以继续编辑；选中一段文字，会出现设置格式的工具条。文字输入区不显示段落左侧的拖拽手柄。只点一下就离开，空文本框会自动收起。

选中文本框后，点浮动属性条里的「适应高度」，可以让文本框完整容纳文字。只有某个方向还有未显示的内容时，对应边缘才会渐隐；文字已全部显示时不会渐隐。

整理《深度工作》读书计划时，还可以搭配这些工具。

| 你想做的                                   | 用哪个工具                                                   |
| ------------------------------------------ | ------------------------------------------------------------ |
| 拆出「为什么重要」「怎么练习」「常见阻碍」 | 「思维导图」，点下中心主题后用键盘加节点，见下文「思维导图」 |
| 排出每天的深度时段                         | 「形状」画出时间块，「箭头」把它们连起来，「文本」写说明     |
| 把读书卡片、读书笔记、PDF 摊开参考         | 「文档」，或在画布上按 `/`，搜到就放下，可以多选             |
| 收进书的封面、讲座视频、作者访谈网页       | 「图片」「视频」「音频」「网页」                             |
| 把资料按「本周」「下周」分区               | 「画框」圈出一块区域；想让元素自动排成几列，用「分栏」       |
| 把整本书拆成几块小白板                     | 「白板」，新建一块白板或引用已有的白板                       |
| 随手圈画重点                               | 「手写」                                                     |

- **形状**：矩形、圆形、三角形、菱形、胶囊、平行四边形、梯形、六边形、圆柱、文档、对话气泡、云朵、箭头、五角星、心形。选好后在画布上拖出大小，双击形状可以在里面写字，文字输入区不显示段落左侧的拖拽手柄。
- **文档**：在画布上按 `/`，在光标处搜索卡片、文章、项目文档或日记，按回车放下；按 ⌘↵ 可以勾选多篇一起放。选中一张文档卡时，搜索框上方先列出和它相关的内容。已经在白板上的那篇不会重复放，会直接带你过去。放到白板上的内容可以双击展开阅读，修改后原文同步更新。
- **从文档卡拉出新的一篇**：从文档卡边上的连接点拖出箭头，松在空白处，就地搜索一篇放下，箭头自动连好。撤销一次会一起收回新卡和连线。
- **长出相关**：选中一张文档卡，按 `R` 或点浮动工具条上的「相关」，旁边浮出几张虚框建议，写着为什么相关。点一张就放到白板上并连好线，可以接着点下一张；点别处或按 Esc 收起。
- **素材架**：点白板标题左边的素材架按钮，画布左侧出现素材列表，可以搜索、按类型筛。把一篇拖到画布上就放下；拖到某张卡上，就放在它旁边并连线。按住 ⌘ 点选多篇，可以一起拖进去。选中一张文档卡时，列表顶部先列出和它相关的内容；已经在白板上的带圆点，点一下镜头带你过去。
- **PDF**：PDF 放到白板上是一整份，卡面显示上次读到的那一页，右下角有页码。选中后按 `[` `]` 或点浮动工具条上的上一页、下一页翻页；在 PDF 阅读页或白板上展开阅读时翻到哪页，卡面也跟着换到哪页，白板上同一份 PDF 的卡片一起换。有笔记的标注会在页边留一个小圆点。双击展开就在白板上读，点右上角可以去 PDF 阅读页。
- **摘录**：在白板上展开一份 PDF，划线后点工具条上的「放到白板」，这段原文就成了一张摘录卡，放在 PDF 旁边并用虚线连回去；点已有的高亮，也能用「放到白板」，或者直接把这个按钮拖到画布上想放的位置。摘录卡底部写着出自哪份 PDF 的第几页，点一下回到原文，原来的高亮会闪两下。只读白板上可以阅读已有摘录。原 PDF 已删除，或当前资料库找不到共享摘录的来源时，卡上仍会保留原文和笔记，来源条显示「原文不可用」。
- **速览**：按住一张文档卡不动，或选中后按住空格，卡片原地放大到能看清，松开就落回去。想接着读就双击展开。
- **展开后的「相连」**：展开一张文档卡，底部列出白板上和它连着线的内容，点一下换过去。正文里引用的其他内容可以直接拖出纸面，放到白板上并连回这一篇。
- **画框与分栏**：在画布上拖拽时可预览容器及其标题，松手后创建。把文字、文档、图片、视频等内容拖进分栏会自动排列，适合做看板或分类整理。拖入时的灰色占位提示放置位置，松手后消失。空列显示「拖入内容」；点击列底部的「添加文字」，可以直接在列内输入。
- **手写**：选中「手写」后，工具栏下方出现笔的设置，可以先调好颜色、粗细、不透明度和笔刷手感再落笔；画笔会保持选中，连续书写都用这套设置。选中已写好的笔迹，也能在浮动工具条上改它的样式。按 <kbd>Delete</kbd> 或 <kbd>Backspace</kbd> 删除选中的整笔，也可以剪切后粘贴到别处；撤销会恢复完整笔迹。

在空白处右键，也可以快速选用箭头、画框、分栏等工具。安装了白板插件（比如「火柴人」）后，插件提供的工具在工具栏最右侧的「扩展工具」里。拖拽创建的插件元素也会在松手前显示预览，取消拖拽不会留下元素。

## 在白板上与助手一起画图

打开白板，点标题栏的「AI 对话」。比如你可以说「画两个步骤，分别写上深度阅读和整理笔记，再用箭头连起来」。需要整理已有内容时，先在画布上选中图形，再说「把我选中的这两个框横向排齐」。助手会在当前页标出处理的位置，改动直接出现在画布上。使用「手动确认」时，先在对话里确认写入。

切到另一页后，重新发消息就会操作新页。共享白板上的改动会同步给其他成员。断网时已经保存到本机的改动会在重连后继续同步。

## 思维导图

::demo{name="whiteboard" caption="点击一个节点将其选中，按 Tab 添加子节点、按 Enter 添加同级节点，双击可修改文字；点击右下角切换画风"}

在工具栏中选择「思维导图」，在画布上点击放置中心主题，比如「深度工作」。输入文字后按 <kbd>Enter</kbd> 结束编辑并选中节点，再按 <kbd>Tab</kbd> 添加子节点「为什么重要」。新节点会直接进入文字编辑，输入完成后按 <kbd>Enter</kbd> 选中它，再按一次 <kbd>Enter</kbd> 添加同级的「怎么练习」「常见阻碍」。

节点会根据文字自动调整大小，较长的文字会换行。节点内的文字输入区不显示段落左侧的拖拽手柄。返回白板列表后再打开，节点会直接按内容显示，无需再次选中或编辑。

| 按键                          | 作用                                                     |
| ----------------------------- | -------------------------------------------------------- |
| <kbd>Tab</kbd>                | 添加子节点                                               |
| <kbd>⇧Tab</kbd>               | 升一级，变成上一级节点的下一个同级                       |
| <kbd>Enter</kbd>              | 在下方添加同级节点                                       |
| <kbd>⇧Enter</kbd>             | 在上方添加同级节点                                       |
| <kbd>⌘D</kbd>                 | 复制整个分支，放在它下方                                 |
| <kbd>空格</kbd>               | 编辑节点文字，按 <kbd>Enter</kbd> 或 <kbd>Esc</kbd> 结束 |
| 方向键                        | 在节点之间移动                                           |
| <kbd>⌘↑</kbd> / <kbd>⌘↓</kbd> | 把节点上移或下移                                         |
| <kbd>⌘←</kbd> / <kbd>⌘→</kbd> | 把一级分支换到左边或右边（仅「思维导图」布局）           |
| <kbd>⌘.</kbd>                 | 收起或展开节点                                           |
| <kbd>⌘⇧.</kbd>                | 展开节点下的全部层级                                     |
| <kbd>⌥1</kbd> … <kbd>⌥5</kbd> | 整张导图展开到第 1 至 5 层，<kbd>⌥0</kbd> 全部展开       |
| <kbd>⌘⇧S</kbd>                | 给选中的相邻同级节点加概要                               |
| <kbd>⌘⇧B</kbd>                | 给选中的相邻同级节点加外框                               |
| <kbd>⌘L</kbd>                 | 从选中节点画一条联系线                                   |
| <kbd>Delete</kbd>             | 删除节点                                                 |

在 Windows 上把 <kbd>⌘</kbd> 换成 <kbd>Ctrl</kbd>，<kbd>⌥</kbd> 换成 <kbd>Alt</kbd>。

每条分支会自动使用不同的颜色。选中中心主题后，浮动属性条里的「导图样式」可以换布局、风格和配色。把鼠标停在一张卡片上，画布会先预览效果，点击才会换上。勾选「设为新导图默认」后，之后新建的导图都用这套样式。

布局有四种：

- **思维导图**：分支在中心主题左右两侧展开，新导图默认用它。
- **逻辑图**：所有分支都向右展开，适合一层层往下推。
- **组织结构图**：一级分支在中心主题下方横排，每条分支再往下列出子项，适合分类和拆解。
- **树状图**：整张导图排成一列缩进清单，适合条目很多的大纲。

方向键会跟着布局走。比如在组织结构图里，<kbd>↓</kbd> 进入子节点，<kbd>←</kbd> <kbd>→</kbd> 在一级分支之间移动。换到其他布局再换回「思维导图」时，分支仍在原来的那一侧。

右键点击节点，可以添加节点、收起分支或「展开全部子级」。右键点击中心主题还有「展开到」，选第几层就把整张导图展开到那一层，内容多的导图可以先收到第 2 层看主干。

### 概要、外框和联系线

按住 <kbd>⇧</kbd> 点选几个相邻的同级节点，比如「专注时段」「关掉通知」「固定仪式」，按 <kbd>⌘⇧S</kbd> 会在它们旁边加一个大括号和一个概要节点，写下「先保护时间」这样的总结。概要节点和普通节点一样能编辑、加子节点。只选一个节点也可以加概要。同一级可以为不同范围分别添加概要，多个概要会向外错开，方便分别编辑。对同一组节点再次添加概要时，会选中已有概要，保留你写下的总结。多人同时给同一组节点添加概要时，多出的总结会保留为普通节点，内容不会被覆盖。

按 <kbd>⌘⇧B</kbd> 会用一个虚线框把这几个节点连同下面的分支圈起来。双击外框边线可以写标题，右键点击框里的节点，选「外框」可以修改标题或删除外框。多人同时添加不同外框，或修改不同外框的标题时，各自的修改都会保留。

删掉框里或括号里的一部分节点时，概要和外框会缩到剩下的节点上，全部删掉或移走时它们也一起消失，连在消失概要上的联系线也会一起删除；撤销时一起恢复。右键菜单里也有「概要」「外框」，选中的节点不相邻时这两项不可用。

想把两个不在同一分支上的想法连起来，选中一个节点按 <kbd>⌘L</kbd>（或右键选「添加联系线」），再点另一个节点，会画出一条带箭头的虚线。按 <kbd>Esc</kbd> 或点空白处可以取消。右键点击联系线可以编辑标签、反转方向或删除。某一端被收起时，联系线会接到可见的上级节点上并变淡；删除节点时，连在它上面的联系线也会一起删除。删除包含导图的画框时，也会清理连接到框内节点的联系线；撤销会一起恢复。 多人同时删除节点和添加联系线时，缺少端点的联系线不会留在画布或导出文件里；撤销删除、恢复两端节点后，联系线会重新出现。

### 关联笔记

右键点击节点，选「关联笔记」，可以新建一篇笔记，或选择已有的卡片、文章。关联后节点右侧会出现一个笔记图标，把鼠标停在图标上能看到笔记标题和开头几行，点击图标打开笔记。

### 和笔记之间复制粘贴

- 选中导图节点后复制，粘到笔记、聊天或其他应用里是一份缩进列表，层级和加粗、斜体、链接都保留。粘回白板时仍是导图节点。
- 选中一个节点后粘贴，剪贴板里的内容会挂到它下面成为子节点：复制的导图分支连同概要、外框和标题一起挂上，一段多级列表按层级拆成节点，`#` 标题也算一层。
- 在画布空白处直接粘贴文字，得到的仍是文本框。想把一段多级列表直接变成导图，右键点击空白处，选「粘贴为思维导图」。列表第一层只有一项时它就是中心主题。
- 一次最多转换 2000 行，超出的部分不会粘进来。导图连同所在画框最多嵌套 64 层；列表超过剩余层级时会提示你减少缩进，原内容保持不变。

## 连线、画框与对齐

用形状和箭头画流程图、用画框把一组元素圈起来，是白板最常用的几个操作：

::demo{name="canvas" caption="拖动形状，连着的箭头会跟着走；把鼠标移到形状上，从边上的圆点拖到另一个形状即可连线；按住 ⌘ 或 Ctrl 点选两个以上的形状，用上方的按钮对齐或均分"}

### 用箭头连接

- 把鼠标移到形状、文本或图片上，边上会出现几个连接点。从连接点按住拖出，松手落在另一个元素上，就画好一条连着两端的箭头。之后移动任一端的元素，箭头会跟着走。
- 也可以用工具栏的「箭头」在任意两点之间画线。
- 选中箭头，点属性条里的「端点」，在「起点」和「终点」各选一种样式。创作模式左侧的白板也可以这样设置。
- 点属性条里的色块可以换颜色。把鼠标移到色块上可以看到颜色名，如「蓝色」或「琥珀色」。属性条里还可以改线型（直线、曲线、正交线）、粗细和虚实，或打开「流动动画」表示数据流向。
- 双击箭头可以在线上写一段说明。把直线拖弯后，右键选「恢复直线」可以拉回去。

### 画框

画框是一个有标题的容器，用来给一组元素分区，比如把每天的深度时段圈成「本周」「下周」，或者圈出演示时的一页。

- 选择「画框」后在画布上拖出范围，范围内的元素会自动收进画框。
- 把元素拖进画框，画框会高亮，松手后元素归入画框；拖出去就离开。拖动画框时，里面的元素和连接它们的箭头一起跟随，松手保存落点；按 <kbd>Esc</kbd> 取消本次拖动。
- 分栏可以作为整体收进画框。新建画框时圈住分栏、把分栏拖入画框，或扩大画框范围都可以；列内内容继续自动排列。
- 在画框内，把内容拖进分栏会归入该列；拖到画框中的空白处就离开分栏、留在画框里。解散框内分栏时，内容也留在原画框中。
- 画框之间、分栏之间不能相互嵌套；箭头不归入画框。
- 双击画框标题可以改名。选中画框后，属性条里可以换颜色和边框样式、把标题放在上方或内嵌，「适应内容」把画框缩到刚好包住里面的元素，「解散画框」则只删画框、保留里面的元素。

### 多选与对齐

- 在空白处拖出一个框，框住的元素都会被选中；按住 <kbd>⌘</kbd>（Windows 上为 <kbd>Ctrl</kbd>）点击可以逐个加选或取消。<kbd>⌘A</kbd>（Windows 上为 <kbd>Ctrl+A</kbd>）全选。
- 选中两个以上元素时，浮动属性条里有左对齐、右对齐、顶部对齐、底部对齐、横向均分、纵向均分。
- 拖动元素时会跟随指针预览位置，松手后保存最终位置。移动时会自动吸附到附近元素的边缘和中线，并显示参考线；按住 <kbd>Alt</kbd> 拖动可以暂时关闭吸附。
- 右键菜单里可以调整层级：上移一层、下移一层、移至顶层、移至底层；也可以把元素「移动到画板页」，移到同一白板的另一页。

## 画布操作

| 操作         | 方法                                                                           |
| ------------ | ------------------------------------------------------------------------------ |
| 平移画布     | 用抓手拖动、按住鼠标右键拖动、滚动滚轮，或在触控板上双指滑动                   |
| 缩放         | 按住 <kbd>⌘</kbd> / <kbd>Ctrl</kbd> 滚动滚轮，或 <kbd>⌘=</kbd> / <kbd>⌘-</kbd> |
| 看全部内容   | 按 <kbd>Z</kbd> 在全览和原视图之间切换；<kbd>⇧1</kbd> 适应全部                 |
| 看选中的元素 | <kbd>⇧2</kbd> 适应选中                                                         |
| 回到 100%    | <kbd>⇧0</kbd>                                                                  |
| 撤销 / 重做  | <kbd>⌘Z</kbd> / <kbd>⌘⇧Z</kbd>                                                 |
| 删除         | <kbd>Delete</kbd> 或 <kbd>Backspace</kbd>                                      |

放大白板后也可以用双指轻滑来微调位置。同样的滑动，在屏幕上平移的距离相同。

右下角的百分比按钮打开视图菜单，可以选择缩放比例，或打开「显示点阵」。开启点阵后，元素会对齐到点阵上。

## 多页

一个白板可以包含多页，比如读书计划按「导图」「日程」「资料」分成三页。点左下角的「新建页」，输入页名称，再点「创建」。新页会加在末尾并自动打开。

点击页签可以切换页面，双击可以改名，拖动可以调整顺序。右键点击页签可以复制这一页，或选择「删除这一页」并确认。如果某页显示「白板格式不受支持」，也可以从页签删除它。删除当前页后会打开相邻页。每块白板至少保留一页。

点击标题栏里的「展开元素树」，可以查找和定位当前页的元素。元素树和素材架共用画布左侧的侧栏，打开时画布和底部页签会向右让位。点另一个按钮即可切换，点当前按钮即可收起。拖动侧栏右边缘可以调整宽度，两个面板会分别记住各自的宽度。

## 手绘风格

点击右下角的画风按钮，在菜单中选择「普通」或「手绘」，并在「默认笔触」中选择工整、自然或潦草。形状还可以使用淡涂、斜线、交叉、涂鸦等填充。单独设置过画风的元素不受整页设置影响。

手绘风格的文字用内置的手写字体：中文「小赖 SC」、英文「Shantell Sans」。喜欢这种字，也可以到「设置 › 外观 › 字体」把它选成整个界面和正文的字体。

## 演示

读书会上要分享《深度工作》，可以直接拿这块白板演示，按你安排的顺序逐帧放映：

1. 点击右下角的「演示」，再点「新建演示序列」。
2. 在画布上选中要展示的元素（比如思维导图，或「本周」画框），点击「添加帧」。需要的话点「调整视口」改变这一帧的范围和「视口留白」，点「预览」看效果。
3. 按顺序添加后续帧，填写演示序列名称后点「保存」。
4. 再次点击「演示」，选择序列开始放映。

放映时用方向键切换上一帧、下一帧，按 <kbd>F</kbd> 全屏，按 <kbd>Esc</kbd> 退出。底部的按钮可以切换为激光笔，指着讲解。一个白板可以保存多个演示序列。

:::tip{title="用画框排版每一页"}
先用画框把每一页的内容圈好，演示时每一帧选一个画框，切换就很整齐。
:::

## 导出和转换

- 在空白处右键选「导出白板为图片」；右键选中的元素选「导出选中元素为图片」，只导出这一部分。
- 「导出可编辑白板」保存为文件，之后可以用「导入可编辑白板」导回来。
- 右键文本，选「创建为」可以把这段文字存成卡片、文章或项目文档。比如思维导图旁边写下的一段感想，可以存成一张读书卡片。

粘贴的内容、复制的页面和导入的可编辑白板都会自动保存，和其它编辑一样，无需另外操作。

从云端拉取并替换资料库后，若嵌入的白板提示「资料库已更新，请重新打开此白板」，旧画布会变为只读。关闭并重新打开后再继续编辑。

白板也可以放进项目，和文档挂在同一棵树上，见 [项目](/docs/projects/)。写文章时把资料摊在白板上对照着写，见 [文章](/docs/articles/) 的「创作模式」。

元素树的类型名称、查找和操作提示会跟随界面语言，自己填写的名称与扩展提供的名称保持原样。切换语言会保留查找内容、展开状态和正在编辑的名称，素材架中的操作也会继续保留。

白板演示的创建、帧操作、放映控制与快捷键提示会跟随界面语言。切换语言会保留未完成的创建内容、帧顺序、当前画面、激光笔模式与视口位置，不会重新进入全屏或重置提示计时。

白板的只读和未知元素提示、媒体链接输入与图片预览会跟随界面语言。切换语言会保留已输入的链接与正在处理的图片，不会重新解码或插入；自定义图片说明保持原样。

箭头、页面、分栏、文本、文档、网页、嵌套白板与手写元素的菜单会跟随界面语言。切换语言不会改变已经选定的操作目标、模式或菜单动作，原有名称与正文保持原样。

脑图与复制、粘贴菜单会跟随界面语言，页面名称和已选操作目标保持原样。切换语言不会改变生成的脑图正文、概要内容或复制的内容。

白板图片、音频、视频和文件拖放操作的提示会跟随界面语言。正在上传或导出时切换语言，不会重新开始任务或重置提示计时。图片预览的默认说明会翻译，自定义说明保持原样。

白板导出弹窗的选项和操作会跟随界面语言。生成图片时切换语言，会保留选择、缩放与背景选项，不会重新截图、再次下载或更改导出文件名。

白板分栏、脑图备注、字段输入和缺少宿主能力时的提示会跟随界面语言。切换语言会保留输入草稿、光标、选区和脑图备注预览，不会重新订阅或提交内容。

白板扩展提供的动态名称会跟随作者的语言配置更新，切换语言会保留工具面板、输入和扩展实例。图片描述的空白提示会翻译，原有描述与图片内容保持原样。

白板中的图片地址、AI 生成、网页地址和本地 HTML 插入界面会跟随界面语言。切换语言保留输入和正在处理的任务，不会重复生成、上传或重新解析网页；图片、网页地址、文件名和 HTML 内容保持原样。

白板影音插入工具的名称和处理提示会跟随界面语言。切换语言保留正在插入的媒体，不会再次选取文件、重复插入或重新显示处理通知。

远程音频和视频地址表单及校验提示会跟随界面语言。切换语言保留地址和光标，不会自动提交；音频仍要求 HTTP 或 HTTPS，视频保留原有的地址支持范围。

语音生成工作台的输入说明、声音选择、试听、添加操作和已知失败提示会跟随界面语言。切换语言会保留文字、已选声音和生成结果，不会重新生成、播放或添加；已保存的配音标题、文本和音频文件保持原样。

白板文档的检索、素材架、相关推荐、放入操作和白板选择界面会跟随界面语言。切换语言保留搜索、已选内容和正在读取的白板，不会再次检索或放入；实际资料标题、引用与摘录内容保持原样。

白板文档的阅读工具、编辑状态、相邻资料、PDF 页码和摘录操作会跟随界面语言。切换语言保留阅读位置与编辑状态，不会提前保存或重新打开资料；原有 PDF 名称、截图摘录和来源信息保持原样。

正文白板的缺失提示、选择界面和全屏说明会跟随界面语言。切换语言保留当前引用和白板状态，不会重新读取或写入；已有白板名称保持原样。

音频没有可用名称时，界面占位会跟随所选语言。切换语言保留播放位置、音量与播放速度，不会改写已有音频名称。
