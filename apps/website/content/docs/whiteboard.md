白板是一张无限画布：可以画思维导图、梳理流程，也可以把卡片、文章和图片摊在一起比较、归类。画好的白板还能直接拿来演示。

比如你在做「深度工作」的读书计划：用思维导图拆出「为什么重要」「怎么练习」「常见阻碍」，再在旁边画一个画框，用形状和箭头排出每天的深度时段，最后把相关的读书卡片拖进来作参考。

## 新建白板

在侧边栏点击「白板」，点击「新建白板」，填写标题；描述和标签都可以不填。加了标签的白板会出现在侧边栏「白板」下方，点击标签即可筛选。

白板列表以缩略图显示所有白板。鼠标在缩略图上左右移动，可以快速翻看每一页，点下去打开的就是看到的那一页。右上角可以搜索标题，或按最近更新、创建时间、名称排序。

## 工具栏

画布顶部是工具栏，从左到右依次是：

| 分组 | 工具                             |
| ---- | -------------------------------- |
| 选择 | 选择                             |
| 绘制 | 形状、箭头、手写、文本、思维导图 |
| 媒体 | 图片、视频、音频、网页           |
| 引用 | 文档、白板                       |
| 容器 | 画框、分栏                       |

- **形状**：矩形、圆形、三角形、菱形、胶囊、平行四边形、梯形、六边形、圆柱、文档、对话气泡、云朵、箭头、五角星、心形。选好后在画布上拖出大小，双击形状可以在里面写字。
- **文档**：放入一张卡片、文章、项目文档或日记，可以多选。放到白板上的内容可以点击展开阅读，修改后原文同步更新。
- **白板**：创建一块新白板，或引用一块已有的白板，适合把大主题拆成几块小白板。
- **分栏**：画出几列，把元素拖进去会自动排列，适合做看板或分类整理。

在空白处右键，也可以快速选用箭头、画框、分栏等工具。

## 思维导图

::demo{name="whiteboard" caption="点击一个节点将其选中，按 Tab 添加子节点、按 Enter 添加同级节点，双击可修改文字；点击右下角切换画风"}

在工具栏中选择「思维导图」，在画布上点击放置中心主题，然后用键盘添加节点：

| 按键                          | 作用                     |
| ----------------------------- | ------------------------ |
| <kbd>Tab</kbd>                | 添加子节点               |
| <kbd>Enter</kbd>              | 在下方添加同级节点       |
| <kbd>⇧Enter</kbd>             | 在上方添加同级节点       |
| <kbd>空格</kbd>               | 编辑节点文字             |
| 方向键                        | 在节点之间移动           |
| <kbd>⌘↑</kbd> / <kbd>⌘↓</kbd> | 把节点上移或下移         |
| <kbd>⌘←</kbd> / <kbd>⌘→</kbd> | 把一级分支换到左边或右边 |
| <kbd>Delete</kbd>             | 删除节点                 |

在 Windows 上把 <kbd>⌘</kbd> 换成 <kbd>Ctrl</kbd>。

每条分支会自动使用不同的颜色。选中导图后，浮动属性条里可以换「导图主题」的风格和配色，也可以「设为新导图默认」。右键点击节点，可以添加节点、重新布局、收起某一侧的分支，或给节点「关联笔记」：新建一篇笔记，或选择已有的卡片、文章，之后从节点上就能打开它。

## 连线、画框与对齐

用形状和箭头画流程图、用画框把一组元素圈起来，是白板最常用的几个操作：

::demo{name="canvas" caption="拖动形状，连着的箭头会跟着走；把鼠标移到形状上，从边上的圆点拖到另一个形状即可连线；按住 ⌘ 或 Ctrl 点选两个以上的形状，用上方的按钮对齐或均分"}

### 用箭头连接

- 把鼠标移到形状、文本或图片上，边上会出现几个连接点。从连接点按住拖出，松手落在另一个元素上，就画好一条连着两端的箭头。之后移动任一端的元素，箭头会跟着走。
- 也可以用工具栏的「箭头」在任意两点之间画线。
- 选中箭头后，属性条里可以改线型（直线、曲线、正交线）、两端的箭头样式、颜色、粗细和虚实，还能打开「流动动画」，让线条显示流动效果，适合表示数据流向。
- 双击箭头可以在线上写一段说明。把直线拖弯后，右键选「恢复直线」可以拉回去。

### 画框

画框是一个有标题的容器，用来给一组元素分区，比如「本周」「下周」，或演示时的一页。

- 选择「画框」后在画布上拖出范围，范围内的元素会自动收进画框。
- 把元素拖进画框，画框会高亮，松手后元素归入画框；拖出去就离开。移动画框时，里面的元素一起移动。
- 双击画框标题可以改名。选中画框后，属性条里可以换颜色和边框样式、把标题放在上方或内嵌，「适应内容」把画框缩到刚好包住里面的元素，「解散画框」则只删画框、保留里面的元素。

### 多选与对齐

- 在空白处拖出一个框，框住的元素都会被选中；按住 <kbd>⌘</kbd>（Windows 上为 <kbd>Ctrl</kbd>）点击可以逐个加选或取消。<kbd>⌘A</kbd>（Windows 上为 <kbd>Ctrl+A</kbd>）全选。
- 选中两个以上元素时，浮动属性条里有左对齐、右对齐、顶部对齐、底部对齐、横向均分、纵向均分。
- 拖动元素时会自动吸附到附近元素的边缘和中线，并显示参考线；按住 <kbd>Alt</kbd> 拖动可以暂时关闭吸附。
- 右键菜单里可以调整层级：上移一层、下移一层、移至顶层、移至底层；也可以把元素「移动到画板页」，移到同一白板的另一页。

## 画布操作

| 操作         | 方法                                                                           |
| ------------ | ------------------------------------------------------------------------------ |
| 平移画布     | 滚动鼠标滚轮或在触控板上双指滑动                                               |
| 缩放         | 按住 <kbd>⌘</kbd> / <kbd>Ctrl</kbd> 滚动滚轮，或 <kbd>⌘=</kbd> / <kbd>⌘-</kbd> |
| 看全部内容   | 按 <kbd>Z</kbd> 在全览和原视图之间切换；<kbd>⇧1</kbd> 适应全部                 |
| 看选中的元素 | <kbd>⇧2</kbd> 适应选中                                                         |
| 回到 100%    | <kbd>⇧0</kbd>                                                                  |
| 撤销 / 重做  | <kbd>⌘Z</kbd> / <kbd>⌘⇧Z</kbd>                                                 |
| 删除         | <kbd>Delete</kbd> 或 <kbd>Backspace</kbd>                                      |

右下角的百分比按钮打开视图菜单，可以选择缩放比例，或打开「显示点阵」。开启点阵后，元素会对齐到点阵上。

## 多页

一个白板可以包含多页，比如按章节或按周分页。左下角的页签用来管理页面：点击切换，双击改名，拖动调整顺序，右键可以重命名、复制或删除，点「新建页」在末尾加一页。

点击标题栏里的元素树按钮，可以在侧边列出当前页的全部元素，方便在大白板里查找和定位。

## 手绘风格

点击右下角的画风按钮，可以把整页切换为「手绘」风格。默认笔触有工整、自然、潦草三种，形状还可以使用淡涂、斜线、交叉、涂鸦等填充。单独设置过画风的元素不受整页设置影响。

## 演示

白板可以按你安排的顺序逐帧放映：

1. 点击右下角的「演示」，再点「新建演示序列」。
2. 在画布上选中要展示的元素（比如一个画框），点击「添加帧」。需要的话点「调整视口」改变这一帧的范围和「视口留白」，点「预览」看效果。
3. 按顺序添加后续帧，填写演示序列名称后点「保存」。
4. 再次点击「演示」，选择序列开始放映。

放映时用方向键切换上一帧、下一帧，按 <kbd>F</kbd> 全屏，按 <kbd>Esc</kbd> 退出。底部的按钮可以切换为激光笔，指着讲解。一个白板可以保存多个演示序列。

:::tip{title="用画框排版每一页"}
先用画框把每一页的内容圈好，演示时每一帧选一个画框，切换就很整齐。
:::

## 导出和转换

- 在空白处右键选「导出白板为图片」；右键选中的元素选「导出选中元素为图片」，只导出这一部分。
- 「导出可编辑白板」保存为文件，之后可以用「导入可编辑白板」导回来。
- 右键文本，选「创建为」可以把这段文字存成卡片、文章或项目文档。
