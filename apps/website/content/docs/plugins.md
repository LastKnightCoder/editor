插件为 Tau 添加新功能。比如你习惯在微信读书里读书，装上「微信读书」插件，书架和划线就会出现在 Tau 里；想把资料库存一份到坚果云，装一个「WebDAV 存储」即可。云端存储、资源上传、博客发布、语音、图片生成等能力都由插件提供，你只装自己用得上的。

## 插件能做什么

插件中心按用途分类：

| 分类     | 插件                                                           | 装好后在哪里用                                           |
| -------- | -------------------------------------------------------------- | -------------------------------------------------------- |
| 同步     | WebDAV 存储、S3 同步存储、阿里云 OSS 同步存储、GitHub 同步存储 | 「设置 › 同步 › 云端存储」，见 [数据与备份](/docs/data/) |
| 资源上传 | WebDAV 存储、GitHub、阿里云 OSS、S3 资源上传                   | 「设置 › 资源存储」，插入的图片和附件存到这里            |
| 编辑器   | TikZ 绘图、Typst 排版、ABC 乐谱、HTML、图册、自定义组件块      | 正文里输入 `/` 插入                                      |
| 白板     | 火柴人                                                         | 白板工具栏的扩展工具                                     |
| 博客发布 | GitHub Pages 发布、S3 静态托管发布                             | [发布](/docs/publish/) 页面                              |
| AI       | OpenAI 嵌入、OpenAI 图片                                       | 「设置 › AI 服务」的「嵌入模型」「图片生成」             |
| 语音     | 豆包语音识别、MiniMax 语音、Qwen 语音                          | 「设置 › AI 服务 › 语音」                                |
| 视频     | Bilibili、YouTube                                              | 添加视频时选择来源，见 [视频笔记](/docs/video-notes/)    |
| 页面     | 微信读书、问题管理、播客、记账本、减重                         | 侧边栏出现新的入口                                       |

博客模板（决定发布出来的网站长什么样）也在插件中心安装，用法见 [发布](/docs/publish/)。

## 安装插件

::demo{name="plugins" caption="点击「微信读书」的「安装」，确认后等待安装完成；装好后插件直接启用，卡片右上角的开关可以停用它"}

1. 点击侧边栏底部的「插件」，打开「发现」页。也可以先在浏览器里逛逛 [插件中心](https://plugins.taunote.app)。
2. 用右上角的分类和排序（最近热门、下载最多、最近更新）筛选，或在搜索框里输入插件名。点开一张卡片可以看介绍、更新日志和其他用户的评论。
3. 点击「安装」，阅读风险提示后确认。按钮会显示「下载校验中」，完成后变成「已安装」。
4. 从插件中心安装的插件会直接启用。不想用时，关掉卡片右上角的开关，或在「已安装」中关掉它的开关即可停用，设置和数据都会保留。

装好后，插件提供的功能会出现在对应位置。比如「微信读书」会在侧边栏多出一个入口，「TikZ 绘图」会出现在正文的 `/` 插入菜单里。

:::info{title="有些插件启用后需要重启"}
普通插件即时生效。为编辑器或白板添加内容类型的插件（如 TikZ 绘图、火柴人），安装、启停或更新后需要重启 Tau。这时页面顶部会提示「涉及内容插件的变更将在重启后生效」，点击「立即重启」即可。
:::

除了插件中心，也可以把插件文件放进插件目录：点击插件页右上角的「⋯」，选择「打开插件目录」，放好后再选「重新扫描」。

## 配置插件

不少插件装好后还要填一些信息才能用，比如同步服务的账号、微信读书的 API Key。这些都在插件详情页的「设置」里完成：在「已安装」中点击插件，切到「设置」标签。

以 WebDAV 为例，设置页分为两组：

| 分组     | 字段                   | 说明                               |
| -------- | ---------------------- | ---------------------------------- |
| 账号     | 服务地址、用户名、密码 | 坚果云等服务的密码要填「应用密码」 |
| 存储位置 | 目录（可选）           | 数据存到 WebDAV 上的哪个文件夹     |

改了任何一项，页面底部会浮出一条保存条，显示有几项修改未保存。点「保存并测试」或按 <kbd>⌘S</kbd>（Windows 上是 <kbd>Ctrl S</kbd>）保存，点「还原」放弃这次修改。连接成功时会显示「连接正常」，以及云端是否已有数据；再点上方的「设为同步服务」，以后就同步到这里。有修改没保存就切换标签、关闭窗口时，Tau 会先问你是保存、继续编辑还是放弃修改，不会悄悄丢掉。

同一个插件可能提供多组设置。WebDAV 既能同步资料库，也能存放图片和附件，所以设置页顶部有两个分组按钮，两种用途的账号分开填写。

语音合成、图片生成这类服务可以添加多个账号，比如工作和个人各一个。账号排在设置页顶部，点一下切换到它的表单，点「添加账号」新建一个。添加和保存账号不会改变正在使用的服务，要在「设置 › AI 服务」里选用哪一个。

:::tip{title="从设置页跳过来的"}
在「设置 › 同步」或「设置 › 资源存储」中点击某个服务的「去配置」，会直接打开这个插件的设置页。页面顶部有一行提示，填完后点「返回同步设置」就能回到原来的位置。
:::

## 插件权限

读写你笔记的插件，会在第一次用到某类数据时弹出「请求访问你的数据」，列出它想做的事，比如「读取卡片」「新建和修改卡片」「读取摘录与标注」。

::demo{name="plugin-permissions" caption="在弹窗中选择「始终允许」或「仅这次」，然后在下方的权限列表里撤销某一项；点击「再次请求」可以重新弹出"}

你有三种选择：

- **始终允许**：以后不再询问。
- **仅这次**：在插件停用或 Tau 重启之前有效，之后再用到时会重新询问。
- **拒绝**：插件这次拿不到数据。连续拒绝三次后，这项权限会被标记为「已阻止」，不再弹窗打扰你。

插件详情页的「权限」标签列出了它申请的每项权限和当前状态（始终允许、本次允许、已阻止、使用时询问）。在这里可以随时「撤销」已给的权限，或「解除阻止」。列表下方还会显示最近读取、修改和删除的次数。

:::tip{title="插件删错了内容"}
插件删除的卡片、文章、待办等内容会保留 7 天。在插件详情页「权限」标签底部的「最近删除」中，可以把它们恢复回来。
:::

调用 AI 的插件同样需要授权，它会沿用你在「设置 › AI 服务 › 大语言模型 › 功能分配」中为对应功能选的模型，用量计入这个插件。可以在插件的「设置」里关闭「允许此插件调用 AI」，或限制每日请求次数和 Token 额度。

:::warning{title="请只安装可信的插件"}
插件和 Tau 运行在同一环境中，可以联网，你允许它读取的内容可能被发送出去。插件中心会审核插件的功能和来源，但不保证没有缺陷。少数插件会在你的电脑上运行自己的程序，能像你本人一样读写电脑上的文件、访问网络，比如调用本机安装的工具。这类插件安装前会额外提示它要用电脑做什么，详情页里也会多出「本机后台」标签，写明这些用途。
:::

## 管理插件

插件页有三个标签：

- **发现**：浏览插件中心的所有插件。
- **已安装**：启用、停用插件，点进详情页调整设置和权限。出问题的插件会单独列在「需要处理」中，不影响其他插件。
- **更新**：列出有新版本的插件，可以逐个更新，也可以点「全部更新」。有可更新的插件时，侧边栏「插件」入口会显示数量。普通插件下载后自动切换到新版本，编辑器和白板内容插件重启后生效，失败会保留旧版本。

想换回旧版本时，在详情页的「版本」标签中选择历史版本。切换版本只替换插件代码，不会回退插件已保存的数据。

卸载插件：在详情页右上角的「⋯」中选择「卸载…」。插件提供的入口会随之消失，已经写进笔记的内容不受影响。确认框里可以勾选「同时删除插件的私有数据」；不勾选的话，以后重新安装还能恢复它的设置和记录。

## 手机上的插件

手机上的插件在「我的 › 插件中心」安装，分为「商店」和「已安装」两个标签。商店只列出能在手机上用的插件：同步存储、资源上传、语音合成、语音识别、图片生成、编辑器类插件，以及微信读书、记账本、减重这类页面插件。嵌入模型、视频来源和博客发布只在电脑上使用。

- **装好后在哪里**：插件提供的页面出现在「我的」顶部的功能宫格里；有的插件还会在「今天」页放一张卡片，比如记账本和减重。
- **生效**：从插件中心安装的插件直接启用，安装和更新下载完成后自动生效，不用重启。停用或启用插件后，插件中心顶部会提示有变更等待生效，点「立即生效」即可。
- **更新**：有可更新的插件时，「插件中心」一行会显示可更新的数量。

## 开发插件

想要的功能插件中心里没有？可以自己做一个，从 [插件开发文档](/developers/) 的「快速开始」读起。软件里也能打开：点击插件页右上角的「⋯」，选择「开发插件文档」。做好后，在 [插件中心](https://plugins.taunote.app) 登录并提交，审核通过后就会上架。

装好插件之后，同步插件的用法见 [数据与备份](/docs/data/)，发布插件的用法见 [发布](/docs/publish/)。
