Tau 是一个本地优先的个人知识工作台，适合想把读到的、想到的东西攒成自己的知识，并且每天用它安排事情的人。你可以在里面读书划线、写卡片和文章、做闪卡复习、管待办和日程，内容之间可以互相引用。不需要注册账号，内容保存在你自己的电脑上，没有网络也能写作和复习，随时可以导出成 Markdown。电脑上有 macOS 和 Windows 版，手机上有 Android 版。

## 一个想法在 Tau 里怎么走

假设你在读《深度工作》，读到「专注是可以练习的」这句话。在 Tau 里，它可以这样一路走下去：

1. **收进来**：在 PDF 或网页上划下这句话，Tau 记下它的出处，见 [收集与阅读](/docs/reading/)。
2. **读懂它**：把这本书放进 [Notebook](/docs/notebook/)，问 AI「作者说的刻意练习具体怎么做」。
3. **写下来**：用自己的话写成一张 [卡片](/docs/cards/)；想得多了，再展开成一篇 [文章](/docs/articles/)。
4. **记住它**：挑几个概念做成 [闪卡](/docs/flashcards/)，Tau 按遗忘规律安排你哪天复习。
5. **重新遇见**：过些天，[漫步](/docs/walk/) 把这张卡片翻出来，知识地图上能看到它和另一篇旧文章连在一起。
6. **分享出去**：整理好的文章可以 [发布](/docs/publish/) 成自己的网站，也可以邀请读书会的朋友 [一起编辑](/docs/collaboration/)。

这几步不用都走。只想随手记、只想管待办，也完全可以。

每天打开 Tau，先看到的是 [今日](/docs/today/)：今天的待办、日程、到期的闪卡和刚写过的内容都在这一页。连接模型后，[AI](/docs/ai/) 能读你写过的内容，帮你查资料、改写、安排待办，还会指出这张卡片和哪篇旧文章相呼应、和哪里矛盾。AI、同步、发布和协作需要联网，其他功能离线也能用。

## 从哪里开始读

1. [下载与安装](/docs/install/)：把 Tau 装到电脑或手机上。
2. [五分钟上手](/docs/quick-start/)：写下第一张卡片，再把第二张连到它上面。
3. [选一条路线](/docs/paths/)：按你想做的事，挑几篇先读，其他的用到时再查。

左侧目录和 Tau 的侧边栏分组一样：「日常」是每天用的今日、待办、日记和番茄专注，「知识」是写作和整理，「学习」是阅读、复习和漫步。你在软件里看到哪个功能，就能在目录里找到同名的一篇。想查快捷键，见 [快捷键](/docs/shortcuts/)；遇到问题，先看 [常见问题](/docs/faq/)。
