Tau 是一个**本地优先**的个人知识工作台。读到的一句话、冒出来的一个念头、写成的一篇长文，都放在同一个地方，彼此连在一起，慢慢长成你自己的体系。

## 一个想法的一生

Tau 围绕一个想法从进来到长成体系的全过程来设计，分成六段：

| 阶段 | 做什么                       | 用到的功能                     |
| ---- | ---------------------------- | ------------------------------ |
| 输入 | 把读到的东西收进来，记得出处 | 浏览器插件、PDF 划线、微信读书 |
| 消化 | 读不懂的就问，问完整理成大纲 | Notebook、问题管理             |
| 输出 | 用自己的话写下来             | 卡片、文章、项目文档、白板     |
| 复习 | 让旧想法不被遗忘             | 闪卡、漫步                     |
| 总览 | 看见内容之间的关联           | 知识地图                       |
| 分享 | 发布出去，或与人一起写       | 博客发布、实时协作             |

不必一次用上所有功能。从写下第一张卡片开始，用到哪儿学到哪儿就好。

## 三个承诺

- **离线可用**：不需要账号，不依赖网络，飞机上、山里一样能写。
- **数据是你的**：所有内容都存在你自己的电脑里，可以随时导出成 Markdown。
- **所见即所得**：熟悉的 Markdown 语法，敲下去就是排好的样子。
