卡片用来记下随笔、短小的想法和读书时的感想。写卡片不需要标题，也不用先想好放进哪个分类，加上标签就行。

Tau 有三种写作形式，适合不同的内容：

| 内容                     | 推荐形式                |
| ------------------------ | ----------------------- |
| 一个想法、一段摘录的感想 | 卡片                    |
| 一个完整的观点、一次复盘 | [文章](/docs/articles/) |
| 对一个主题的系统整理     | [项目](/docs/projects/) |

比如你在读《深度工作》：每读到一处有感触的地方，就写一张卡片，打上「读书/深度工作」的标签；读完后，把这些卡片串起来写成一篇读书笔记文章。三种形式之间可以互相引用，后面会讲到。

## 卡片库

::demo{name="cards" caption="点击左侧的标签筛选卡片，再次点击取消筛选"}

在侧边栏点击「卡片库」，所有卡片按时间排列：置顶的卡片在最前，之后依次是今天、昨天、本周、本月和更早。页面顶部显示当前一共有多少张卡片、累计多少字。

### 新建卡片

有两种方式：

- 在卡片库点击「新建卡片」，在弹窗里写好内容；
- 在任何地方按 <kbd>⌘⇧N</kbd>（Windows 上为 <kbd>Ctrl+Shift+N</kbd>），打开一个置顶的速记窗口。即使 Tau 不在前台也能唤出，写完直接关掉，内容自动保存。什么都没写就关掉，不会留下空卡片。

:::tip{title="灵感来了先记下来"}
速记窗口最适合「一闪念」：读网页、开会、散步时冒出的想法，先用 <kbd>⌘⇧N</kbd> 记下一两句，不用整理。回头在卡片库里补标签、补引用就好。
:::

### 查看和编辑

点击一张卡片，会在弹窗中打开，可以直接修改，内容自动保存。点击右上角的「进入详情」可以全屏编辑，详情页的写法和 [编辑器基础](/docs/editor/) 里介绍的一样。

### 切换视图

标题栏的「卡片库 / 卡片墙」可以切换三种视图：

| 视图   | 适合                                                                                 |
| ------ | ------------------------------------------------------------------------------------ |
| 卡片墙 | 平时浏览，卡片按时间分组平铺                                                         |
| 列表   | 快速扫一遍，每行显示内容开头、标签、连接数、字数和时间，点列头排序                   |
| 表格   | 批量整理：标题、标签、连接、创建和更新时间各占一列，可以筛选、排序，也能新建多个视图 |

### 导入

点击「导入」，可以选择「Markdown 文件…」导入单个文件，或选择「文件夹或压缩包…」批量导入，每个 Markdown 文件会成为一张卡片。也可以直接把文件夹或 .zip 拖到卡片库页面上。

## 使用标签

在卡片末尾的「添加标签」处输入标签名，按回车确认。点击已有的标签可以修改它的名字。

标签支持层级：输入 `读书/深度工作`，侧边栏「卡片库」下方会在「读书」下显示「深度工作」，每个标签旁边显示卡片数。点击「读书」时，带有其子标签的卡片也会一起显示；再点一次回到全部。

:::info{title="标签怎么起"}
标签用来回答「这张卡片和什么有关」。按来源（`读书/深度工作`）或主题（`学习方法`）起名都可以，层级不要太深，两三层足够。
:::

## 引用其他内容

写作时如果想提到另一张卡片或一篇文章，输入 `@`，然后在列表中选择：

::demo{name="mention" caption="在正文末尾输入 @，再输入「间隔」筛选，用 ↑↓ 选择、回车插入；鼠标悬停在插入的链接上可以预览"}

- 输入 `[[`（中文输入法下为 `【【`）也可以打开该列表；
- 鼠标悬停在链接上会显示预览，点击「打开」跳转到对应内容；
- 选中一段文字，在悬浮工具栏里点「关联内容」，可以把这段文字链接到另一条内容。

被引用的内容会记录引用来源。在详情页标题下方点击「N 处关联」，可以看到它引用了谁、被谁引用、还有哪些相关内容，也可以在这里「添加连接」。不想在正文里插链接时，用「添加连接」把两条内容直接连起来即可。

这些连接会显示在 [知识地图](/docs/walk/) 上，漫步时也会沿着这些连接推荐相关内容。

## 更多操作

鼠标悬停在卡片上，点击右上角的「⋯」：

- **窗口打开**：在独立窗口里编辑这张卡片，方便一边看资料一边写；
- **设置置顶**：把常用的卡片固定在卡片库最前面；
- **演示模式**：把卡片内容全屏展示；
- **导出**：导出为 Markdown、图片、EPUB 或 PDF；
- **删除卡片**。

详情页的「⋯」菜单还有更多选项：

| 菜单 | 选项                                        |
| ---- | ------------------------------------------- |
| 场景 | 演示模式、沉浸模式、在新窗口打开            |
| 复制 | 复制 Markdown、复制公众号格式               |
| 导出 | Markdown 文件、图片、EPUB、PDF              |
| 生成 | AI 制卡（闪卡）、手动制卡（闪卡）、生成播客 |

此外还可以「添加连接」和「发起协作」。把卡片做成闪卡的方法见 [闪卡复习](/docs/flashcards/)，协作见 [协作](/docs/collaboration/)。
