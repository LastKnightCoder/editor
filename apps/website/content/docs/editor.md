卡片、文章、项目文档和日记都用同一个编辑器。它是所见即所得的 Markdown：你用 Markdown 语法输入，内容立即显示成排版后的样子，不需要在源码和预览之间切换。

比如你读完《深度工作》，要写一篇读书笔记：用标题分出「核心观点」「四种日程安排」「我的实践」，摘一段原文放进引用块，把「注意力残留」这个概念的出处写成注解，贴上作者博客的网页书签，再插一张表格比较四种安排深度工作的方式。下文的例子都来自这篇笔记。

| 调整段落顺序             | 按住块左侧的手柄上下拖动                         |

## 用 Markdown 语法输入

### 段落开头的语法

在段落开头输入下面的符号再按空格，这一段就会变成对应的格式：

| 输入            | 效果         |
| --------------- | ------------ |
| `#` 到 `######` | 一到六级标题 |
| `-`、`*` 或 `+` | 无序列表     |
| `1.`            | 有序列表     |
| `>`             | 引用块       |

另外几种需要在整段只写符号时按回车：

| 输入                      | 效果                                   |
| ------------------------- | -------------------------------------- |
| ` ``` `，或 ` ```python ` | 代码块，后面写上语言名可以直接选好语言 |
| `---`                     | 分割线                                 |
| `$$`                      | 单独成行的公式                         |

任务列表没有快捷语法，请用斜杠菜单里的「任务列表」插入。

### 行内格式

输入完收尾的符号，格式就会生效。撤销一次可以回到原始符号：

| 输入                     | 效果                           |
| ------------------------ | ------------------------------ |
| `**粗体**` 或 `__粗体__` | **粗体**                       |
| `*斜体*` 或 `_斜体_`     | _斜体_                         |
| `***粗斜体***`           | _**粗斜体**_                   |
| `~~删除线~~`             | ~~删除线~~                     |
| `==高亮==`               | :highlight[高亮]{color=yellow} |
| `` `代码` ``             | `代码`                         |
| `$E = mc^2$`             | $E = mc^2$                     |

在行内代码里输入这些符号不会触发转换。

## 常用快捷键

在 macOS 上用 <kbd>⌘</kbd>，在 Windows 上用 <kbd>Ctrl</kbd>：

| 操作                 | macOS          | Windows                 |
| -------------------- | -------------- | ----------------------- |
| 粗体                 | <kbd>⌘B</kbd>  | <kbd>Ctrl+B</kbd>       |
| 斜体                 | <kbd>⌘I</kbd>  | <kbd>Ctrl+I</kbd>       |
| 下划线               | <kbd>⌘U</kbd>  | <kbd>Ctrl+U</kbd>       |
| 删除线               | <kbd>⌘⇧S</kbd> | <kbd>Ctrl+Shift+S</kbd> |
| 高亮                 | <kbd>⌘M</kbd>  | <kbd>Ctrl+M</kbd>       |
| 行内代码             | <kbd>⌘E</kbd>  | <kbd>Ctrl+E</kbd>       |
| 插入链接             | <kbd>⌘L</kbd>  | <kbd>Ctrl+L</kbd>       |
| 选中文字转为行内公式 | <kbd>⌘⇧E</kbd> | <kbd>Ctrl+Shift+E</kbd> |
| 给选中文字加批注     | <kbd>⌘⇧M</kbd> | <kbd>Ctrl+Shift+M</kbd> |
| 插入代码块           | <kbd>⌘\`</kbd> | <kbd>Ctrl+\`</kbd>      |

编排结构时还有这些按键：

- **标题升降级**：<kbd>Alt+=</kbd> 提高一级，<kbd>Alt+-</kbd> 降低一级。在普通段落上按 <kbd>Alt+=</kbd> 会变成六级标题，六级标题再降就回到段落。
- **列表缩进**：在列表或任务列表里按 <kbd>Tab</kbd> 缩进一级，<kbd>⇧Tab</kbd> 退回一级。
- **移动列表项**：<kbd>⌘↑</kbd> / <kbd>⌘↓</kbd>（Windows 上为 <kbd>Ctrl+↑</kbd> / <kbd>Ctrl+↓</kbd>）把当前列表项上移或下移。
- **退出格式**：光标处带着粗体、高亮等格式时按 <kbd>Esc</kbd>，接下来输入的文字就不再带格式。

## 斜杠菜单：插入各种块

在任意位置输入 `/`，会弹出插入菜单。接着输入关键词可以筛选，比如 `/表格`、`/code`、`/biaoge` 都能找到表格。用 <kbd>↑</kbd> <kbd>↓</kbd> 选择、<kbd>→</kbd> 进入子菜单、<kbd>←</kbd> 返回、回车插入，输入空格关闭菜单。

| 分类     | 菜单项                                                                     |
| -------- | -------------------------------------------------------------------------- |
| 文字结构 | 标题（一到六级）、无序列表、有序列表、任务列表、引用块、分割线             |
| 容器     | Callout（提示、信息、笔记、危险、警告）、高亮块、详情块、标签页            |
| 数据     | 表格、数据库视图、查询数据库                                               |
| 代码与图 | 代码块、数学公式、流程图、PlantUML                                         |
| 媒体     | 图片（本地上传、网络地址、行内图片）、音频、视频、网页、网页书签、文件附件 |
| 其他     | 表情符号、注解、白板、引用白板                                             |

内置插入项、通用块操作和类型转换菜单会跟随界面语言显示简体中文、繁体中文或 English。插入项可以用这三种语言的类型名称查找。切换语言会保留打开的菜单、当前选择和正在输入的内容。插件条目的分组由插件自己的配置决定。

在项目文档里，菜单还多一项「项目列表」，用卡片的形式列出当前文档的子文档。安装了编辑器插件后，插件提供的块也会出现在这个菜单里，比如装上「TikZ 绘图」就能用 `/TikZ` 插入一张 TikZ 图，见 [插件](/docs/plugins/)。

输入 `/` 选择「查询数据库」，可以在正文里用 DSL 或 JavaScript 自动组织已有内容，见 [查询数据库](/docs/query-database/)。

### 网页书签

读书笔记里附上作者博客、相关报道这类网页时，网页书签比一行网址更好认：它把网页的标题、描述和封面做成一张卡片。

- **插入**：在空行粘贴一个网址，会弹出「粘贴为」菜单，选「网页书签」；也可以输入 `/网页书签`，再粘贴或输入网址。
- **外观**：点击书签块左侧的手柄，在「外观」里选横向卡、封面卡或紧凑（只占一行）。
- **修改**：在同一个菜单里选「编辑」，可以改标题、描述和封面；网页内容变了，选「重新读取网页信息」。
- **打开**：点击书签，网页会在窗口右侧打开，正文留在原位。菜单里还有「复制链接」。

### 注解

注解是写给读者看的补充说明，比如一个概念的出处。正文里只显示一个上标序号，读者需要时再看。

- 光标停在要注解的位置，输入 `/注解`。正文里出现一个序号，旁边弹出编辑卡片，写下内容即自动保存，按 <kbd>Esc</kbd> 关闭。
- 序号按注解在文中的先后自动排列，插到前面的注解会让后面的序号顺延。导出 Markdown 时，注解变成同样编号的脚注。
- 鼠标悬停在序号上可以预览内容；点击序号打开编辑卡片，可以修改、复制或删除。
- 插入后什么都没写就关掉，这个注解会自动移除。

注解和悬浮工具栏里的「批注」用处不同：注解是正文的一部分，读者能看到；批注是留给自己或协作者的修改意见，适合审稿时用。

### 几种容器块

- **Callout**：带图标和底色的提示框，适合放注意事项、技巧或补充说明。插入后可以在块菜单的「修改类型」里换样式。
- **高亮块**：用一种底色把一段内容圈起来，比 Callout 更轻，适合标出核心结论。块菜单里可以「修改颜色」。
- **详情块**：默认可以收起，只露出标题，适合放推导过程、长段引用这类不需要每次都看的内容。
- **标签页**：把并列的几段内容叠在一起，点标题切换。双击标题或选中后按回车可以重命名，点「添加标签」新建一页，拖动标题调整顺序。

:::detail{title="详情块长这样"}
收起时只显示这一行标题，点击才展开正文。
:::

### 表格

插入的表格默认 3 行 3 列。比较四种日程安排时，可以第一列写安排方式，后面几列写「适合谁」「每天能深度工作多久」。表格里的常用操作：

- <kbd>Tab</kbd> / <kbd>⇧Tab</kbd> 移到右边或左边的格子，在最后一格按 <kbd>Tab</kbd> 会新增一行；
- 回车跳到下一行的同一列，<kbd>⇧Enter</kbd> 在格子里换行；
- 鼠标悬停在格子上，列的顶边和行的左边会出现手柄。点击手柄选中整行或整列并打开菜单，可以在上下左右插入行列、设置对齐、清空内容或删除；按住手柄拖动可以调整行列顺序；
- 表格右侧和底部的「+」用来追加一列或一行；
- 跨着格子拖选，选区右下角会浮出「合并 3 格」这样的按钮，点一下把选中的格子并成一个，内容按阅读顺序并进左上格。合并后按钮变成「拆分单元格」，行、列手柄的菜单里也有「拆分合并单元格」；
- 合并过的格子不会被移动行列拆开——拖动时放下位置变红，就先拆分再移动。导出成 Markdown 时不保留合并（Markdown 表格没有这种写法），复制到别处或导出网页会保留。

从网页或电子表格复制一张表格粘贴进来，会直接生成表格；在格子里粘贴多行多列的数据，会从当前格开始依次填满。

### 代码、公式和图

代码块支持语法高亮，在代码块顶部可以切换语言、复制代码：

```ts
const idea = "让想法，长成体系";
```

编辑源码时，按 <kbd>Tab</kbd> 缩进，按 <kbd>⇧Tab</kbd> 减少缩进，按回车保留当前行的缩进。撤销、重做使用同样的 <kbd>⌘Z</kbd> / <kbd>⌘⇧Z</kbd>；Windows 使用 <kbd>Ctrl+Z</kbd> / <kbd>Ctrl+Y</kbd>。

公式用 LaTeX 语法，可以写在行内，例如 $\sqrt{a^2 + b^2}$，也可以单独成行：

$$
\int_0^1 x^2 \, dx = \frac{1}{3}
$$

「流程图」用 Mermaid 语法画流程图、时序图、甘特图等，「PlantUML」用 PlantUML 语法画 UML 图。插入后写入源码，下方实时显示渲染结果；之后鼠标悬停在图上，工具栏里可以编辑、复制源码或删除。

## 选中文字后的悬浮工具栏

选中一段文字，上方会出现悬浮工具栏，常用的行内格式都在这里：

- **加粗、斜体、删除线、代码**：和快捷键效果相同；
- **下划线**：可以选颜色和线型（实线、波浪线等）；
- **快捷键**：把文字显示成按键样式，比如 <kbd>Enter</kbd>；
- **颜色**：设置文字颜色、高亮底色，或使用渐变字；
- **链接**：给文字加网址链接，已有链接时可以编辑。网页在窗口右侧打开。拖动右栏左边缘可以调整宽度，鼠标移到网页上也可以松手。点右上角的放大按钮可以占满正文区。按 <kbd>Esc</kbd> 收回后，网页仍停在刚才的位置。切换资料库会关闭这个网页。想直接用系统浏览器打开，可以按住 <kbd>Ctrl</kbd> 点击链接或书签；
- **关联内容**：把文字链接到一张卡片、一篇文章或项目文档；
- **行内公式**：把选中的文字转成公式；
- **批注**：在文字旁留一条批注，鼠标悬停可以查看。

文字样式工具栏、颜色与下划线面板、批注和行内公式会跟随界面语言显示简体中文、繁体中文或 English。切换语言会保留打开的面板、正在写的批注和公式。链接编辑弹层也会保留正在输入的文字和网址，点「完成」才会写入正文。

代码、图片、音视频、网页和书签的操作提示，以及图片灯箱、裁剪和播放器控件也会跟随界面语言。切换语言会保留文件名或网址草稿、源码光标和播放位置；代码、公式、媒体标题和字幕保留原文。

给选中的文字加链接、关联内容、下划线、按键样式或批注时，原有的加粗、斜体和颜色会保留。例如，从按键样式的中间选到后面的正文再加链接，只有选中的字可以点击，按键样式仍保留在原来的位置。

窗口较窄时，部分按钮会收进「文本样式」和「更多」里。

高亮默认是一块平涂的底色。想让它更像纸上的马克笔，到「设置 › 外观」的「高亮」里换成平头荧光笔、下半划线或干笔颗粒。笔触对所有文档生效，发布成博客时也会保留。

字体也有得挑：「设置 › 外观 › 字体」里除了系统字体，还有内置的「小赖 SC」和「Shantell Sans」，选中后界面和正文统一换字。想让同一行显示更多文字，或想要更聚焦的阅读留白，可以在「设置 › 外观 › 正文页边距」里切换「窄留白」「适中」或「宽留白」，对文章、卡片、项目文档和独立窗口统一生效。

## 打字时的 AI 续写

在「设置 › AI 服务 › 大语言模型 › 功能分配」里给「行内建议」选一个模型后，写正文或代码块时稍微停一下，光标后面会出现一段灰色的候选文字：觉得合适按 <kbd>Tab</kbd> 采纳（它算独立的一步，可以单独撤销），不想用就继续打字或按 <kbd>Esc</kbd>，它自己会消失。候选每次只有一小句，不会替你写下去。这项功能只在电脑上可用。

共享给别人的正文默认不发内容给模型，要在「功能分配」里另行打开「协作正文的行内建议」才会启用。

## 拖拽和块菜单

把鼠标移到任意一块（段落、标题、列表项、图片、表格……）上，它的左侧会出现一个拖拽手柄：

- **调整顺序**：按住手柄上下拖动，指示线会标出放下的位置。列表项和任务项可以单独拖动；
- **打开块菜单**：点击手柄。菜单里可以「转换成」其他块类型（比如把段落转成标题、Callout 或引用块），也可以上移、下移、剪切、复制或删除这一块。部分块还有自己的选项，比如 Callout 的「修改类型」、高亮块的「修改颜色」。

调整标题层级时，点击标题左侧的拖拽手柄，在「标题级别」中选择一到六级标题，当前级别会置灰。标题文字与格式保持不变。

标题旁还会出现一个折叠箭头，点击可以收起这个标题下面的内容，写长文时方便只看结构。

## 粘贴

粘贴时，编辑器会尽量保留原来的样子：

| 粘贴的内容                | 结果                                                         |
| ------------------------- | ------------------------------------------------------------ |
| 一段 Markdown 文本        | 自动转成对应的标题、列表、表格、代码块等                     |
| 在空行粘贴一个网址        | 先变成链接，同时弹出「粘贴为」菜单，可以改成网页书签或纯文本 |
| 在句子中间粘贴网址        | 直接变成链接；先选中文字再粘贴网址，这段文字就成了链接       |
| 图片文件或截图            | 插入为图片                                                   |
| 网页或电子表格里的表格    | 生成一张表格                                                 |
| 从 Tau 其他地方复制的内容 | 原样保留所有块和格式                                         |

:::tip{title="把旧笔记搬进来"}
从其他 Markdown 编辑器复制整篇笔记，直接粘贴就能得到排好版的内容。要一次导入很多文件，用卡片库、文章或项目页的「导入」更方便。
:::

## 编辑历史

写错了、删多了，都能回头找。文章、卡片和项目文档都自动记录编辑历史：点工具栏的时钟图标，或「⋯」菜单里的「编辑历史」，正文旁边会展开一栏时间轴，按天分组，共享的正文还能按作者筛选。

连续写的一段会记成一条。停笔超过 5 分钟、连续写满半小时、换了人或交给 AI 修改、关掉正文再打开，或者共享连接断开后重连，后续修改会另起一条。撤销和恢复总是单独一条。

- **看一次改动**：点一条记录，正文里用颜色标出它动了哪里——新增、修改、移动各有颜色，虚线连到对应的块。展开记录能看改动前后的文字，点「该版本全文」读当时整篇的样子。查看过的版本会固定下来，之后继续输入不会改变这条记录。
- **撤销与恢复**：「撤销这次编辑」撤掉这一次改动，「恢复到此版本」把正文变回当时的样子。两者都会先让你确认，并且作为一次新的修改记进历史，不会把历史抹掉。
- **共享的正文**：大家的改动记在同一条时间轴里，各有署名，谁能撤销谁的改动见 [协作](/docs/collaboration/)。

手机上也能翻历史：卡片详情顶栏的时钟图标、共享正文的「⋯」菜单，见 [手机](/docs/mobile/)。

## 引用其他内容

内容选择器和引用预览会跟随界面语言显示类型、日期与操作提示，切换语言会保留搜索条件和已选内容。

输入 `@` 或 `[[`（中文输入法下输入 `【【` 也可以），在弹出的列表中选择一张卡片、一篇文章或项目文档，即可在正文中插入指向它的链接。读书笔记里提到之前写的读书卡片，就用这个方法。详见 [卡片](/docs/cards/) 中的「引用其他内容」。

AI 的回答也能收进正文。把鼠标移到对话里的一条回答上，点「引用到正文」：选「插入到正文」，在最近写的正文里留下一条行内引用；选「作为摘录块插入」，把这段回答原样收成一块摘录——先选中几句就只摘那几句；也可以「复制引用链接」，粘到正文里同样变成引用。正文里它显示对话的标题，悬停可以预览那一轮问答，点击在右侧对话栏打开并定位到那条消息；对话删掉后，摘录的文字仍然保留。

电脑上不打算放进资料库的 Markdown 文件（比如 README、博客草稿）也能直接用 Tau 编辑，见 [Markdown 文件](/docs/markdown-files/)。

编辑器用熟之后，可以去 [卡片](/docs/cards/) 记下第一批想法，或在 [文章](/docs/articles/) 里把它们写成长文。全部快捷键见 [快捷键](/docs/shortcuts/)。
