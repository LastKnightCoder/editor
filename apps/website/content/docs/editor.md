Tau 的编辑器是所见即所得的 Markdown：用熟悉的语法输入，内容立刻排成最终的样子，不用在源码和预览之间来回切换。

## 用 Markdown 语法输入

在行首输入下面的符号再按空格，就会变成对应的块：

| 输入             | 效果         |
| ---------------- | ------------ |
| `#`、`##`、`###` | 一到三级标题 |
| `-` 或 `*`       | 无序列表     |
| `1.`             | 有序列表     |
| `[]`             | 待办         |
| `>`              | 引用         |
| ` ``` `          | 代码块       |
| `---`            | 分割线       |

行内也一样：`**粗体**`、`*斜体*`、`` `代码` ``、`$公式$` 输入完就会生效。

## 常用快捷键

| 操作     | macOS                       | Windows                        |
| -------- | --------------------------- | ------------------------------ |
| 粗体     | <kbd>⌘</kbd> + <kbd>B</kbd> | <kbd>Ctrl</kbd> + <kbd>B</kbd> |
| 斜体     | <kbd>⌘</kbd> + <kbd>I</kbd> | <kbd>Ctrl</kbd> + <kbd>I</kbd> |
| 下划线   | <kbd>⌘</kbd> + <kbd>U</kbd> | <kbd>Ctrl</kbd> + <kbd>U</kbd> |
| 高亮     | <kbd>⌘</kbd> + <kbd>M</kbd> | <kbd>Ctrl</kbd> + <kbd>M</kbd> |
| 行内代码 | <kbd>⌘</kbd> + <kbd>E</kbd> | <kbd>Ctrl</kbd> + <kbd>E</kbd> |
| 插入链接 | <kbd>⌘</kbd> + <kbd>L</kbd> | <kbd>Ctrl</kbd> + <kbd>L</kbd> |

## 插入更多块

在空行输入 `/` 会打开块菜单，可以插入图片、表格、提示块、折叠块、公式、代码块等。

### 提示块

:::warning{title="提示块"}
适合放注意事项、技巧或补充说明，有注意、技巧、信息、警告、危险五种样式。
:::

### 折叠块

:::detail{title="点开看看"}
折叠块默认收起，适合放不必每次都看的细节，比如推导过程或长段引用。
:::

### 代码与公式

```ts
// 代码块支持语法高亮
const idea = "让想法，长成体系";
```

公式用 LaTeX 书写，比如质能方程 $E = mc^2$，或者单独成行：

$$
\int_0^1 x^2 \, dx = \frac{1}{3}
$$
