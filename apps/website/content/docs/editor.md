卡片、文章、项目文档和日记都用同一个编辑器。它是所见即所得的 Markdown：你用 Markdown 语法输入，内容立即显示成排版后的样子，不需要在源码和预览之间切换。

## 用 Markdown 语法输入

### 段落开头的语法

在段落开头输入下面的符号再按空格，这一段就会变成对应的格式：

| 输入            | 效果         |
| --------------- | ------------ |
| `#` 到 `######` | 一到六级标题 |
| `-`、`*` 或 `+` | 无序列表     |
| `1.`            | 有序列表     |
| `>`             | 引用块       |

另外几种需要在整段只写符号时按回车：

| 输入                      | 效果                                   |
| ------------------------- | -------------------------------------- |
| ` ``` `，或 ` ```python ` | 代码块，后面写上语言名可以直接选好语言 |
| `---`                     | 分割线                                 |
| `$$`                      | 单独成行的公式                         |

任务列表没有快捷语法，请用斜杠菜单里的「任务列表」插入。

### 行内格式

输入完收尾的符号，格式就会生效。撤销一次可以回到原始符号：

| 输入                     | 效果                           |
| ------------------------ | ------------------------------ |
| `**粗体**` 或 `__粗体__` | **粗体**                       |
| `*斜体*` 或 `_斜体_`     | _斜体_                         |
| `***粗斜体***`           | _**粗斜体**_                   |
| `~~删除线~~`             | ~~删除线~~                     |
| `==高亮==`               | :highlight[高亮]{color=yellow} |
| `` `代码` ``             | `代码`                         |
| `$E = mc^2$`             | $E = mc^2$                     |

在行内代码里输入这些符号不会触发转换。

## 常用快捷键

在 macOS 上用 <kbd>⌘</kbd>，在 Windows 上用 <kbd>Ctrl</kbd>：

| 操作                 | macOS          | Windows                 |
| -------------------- | -------------- | ----------------------- |
| 粗体                 | <kbd>⌘B</kbd>  | <kbd>Ctrl+B</kbd>       |
| 斜体                 | <kbd>⌘I</kbd>  | <kbd>Ctrl+I</kbd>       |
| 下划线               | <kbd>⌘U</kbd>  | <kbd>Ctrl+U</kbd>       |
| 删除线               | <kbd>⌘⇧S</kbd> | <kbd>Ctrl+Shift+S</kbd> |
| 高亮                 | <kbd>⌘M</kbd>  | <kbd>Ctrl+M</kbd>       |
| 行内代码             | <kbd>⌘E</kbd>  | <kbd>Ctrl+E</kbd>       |
| 插入链接             | <kbd>⌘L</kbd>  | <kbd>Ctrl+L</kbd>       |
| 选中文字转为行内公式 | <kbd>⌘⇧E</kbd> | <kbd>Ctrl+Shift+E</kbd> |
| 给选中文字加批注     | <kbd>⌘⇧M</kbd> | <kbd>Ctrl+Shift+M</kbd> |
| 插入代码块           | <kbd>⌘\`</kbd> | <kbd>Ctrl+\`</kbd>      |

编排结构时还有这些按键：

- **标题升降级**：<kbd>Alt+=</kbd> 提高一级，<kbd>Alt+-</kbd> 降低一级。在普通段落上按 <kbd>Alt+=</kbd> 会变成六级标题，六级标题再降就回到段落。
- **列表缩进**：在列表或任务列表里按 <kbd>Tab</kbd> 缩进一级，<kbd>⇧Tab</kbd> 退回一级。
- **移动列表项**：<kbd>⌘↑</kbd> / <kbd>⌘↓</kbd>（Windows 上为 <kbd>Ctrl+↑</kbd> / <kbd>Ctrl+↓</kbd>）把当前列表项上移或下移。
- **退出格式**：光标处带着粗体、高亮等格式时按 <kbd>Esc</kbd>，接下来输入的文字就不再带格式。

## 斜杠菜单：插入各种块

在任意位置输入 `/`，会弹出插入菜单。接着输入关键词可以筛选，比如 `/表格`、`/code`、`/biaoge` 都能找到表格。用 <kbd>↑</kbd> <kbd>↓</kbd> 选择、<kbd>→</kbd> 进入子菜单、<kbd>←</kbd> 返回、回车插入，输入空格关闭菜单。

| 分类     | 菜单项                                                           |
| -------- | ---------------------------------------------------------------- |
| 文字结构 | 标题（一到六级）、无序列表、有序列表、任务列表、引用块、分割线   |
| 容器     | Callout（提示、信息、笔记、危险、警告）、高亮块、详情块、标签页  |
| 数据     | 表格、数据库视图                                                 |
| 代码与图 | 代码块、数学公式、流程图、PlantUML                               |
| 媒体     | 图片（本地上传、网络地址、行内图片）、音频、视频、网页、文件附件 |
| 其他     | 表情符号、注解、白板、引用白板                                   |

在项目文档里，菜单还多一项「项目列表」，用卡片的形式列出当前文档的子文档。

### 几种容器块

- **Callout**：带图标和底色的提示框，适合放注意事项、技巧或补充说明。插入后可以在块菜单的「修改类型」里换样式。
- **高亮块**：用一种底色把一段内容圈起来，比 Callout 更轻，适合标出核心结论。块菜单里可以「修改颜色」。
- **详情块**：默认可以收起，只露出标题，适合放推导过程、长段引用这类不需要每次都看的内容。
- **标签页**：把并列的几段内容叠在一起，点标题切换。双击标题或选中后按回车可以重命名，点「添加标签」新建一页，拖动标题调整顺序。

:::detail{title="详情块长这样"}
收起时只显示这一行标题，点击才展开正文。
:::

### 表格

插入的表格默认 3 行 3 列。表格里的常用操作：

- <kbd>Tab</kbd> / <kbd>⇧Tab</kbd> 移到右边或左边的格子，在最后一格按 <kbd>Tab</kbd> 会新增一行；
- 回车跳到下一行的同一列，<kbd>⇧Enter</kbd> 在格子里换行；
- 鼠标悬停在格子上，列的顶边和行的左边会出现手柄。点击手柄选中整行或整列并打开菜单，可以在上下左右插入行列、设置对齐、清空内容或删除；按住手柄拖动可以调整行列顺序；
- 表格右侧和底部的「+」用来追加一列或一行。

从网页或电子表格复制一张表格粘贴进来，会直接生成表格；在格子里粘贴多行多列的数据，会从当前格开始依次填满。

### 代码、公式和图

代码块支持语法高亮，在代码块顶部可以切换语言、复制代码：

```ts
const idea = "让想法，长成体系";
```

公式用 LaTeX 语法，可以写在行内，例如 $\sqrt{a^2 + b^2}$，也可以单独成行：

$$
\int_0^1 x^2 \, dx = \frac{1}{3}
$$

「流程图」用 Mermaid 语法画流程图、时序图、甘特图等，「PlantUML」用 PlantUML 语法画 UML 图。插入后写入源码，下方实时显示渲染结果；之后鼠标悬停在图上，工具栏里可以编辑、复制源码或删除。

## 选中文字后的悬浮工具栏

选中一段文字，上方会出现悬浮工具栏，常用的行内格式都在这里：

- **加粗、斜体、删除线、代码**：和快捷键效果相同；
- **下划线**：可以选颜色和线型（实线、波浪线等）；
- **快捷键**：把文字显示成按键样式，比如 <kbd>Enter</kbd>；
- **颜色**：设置文字颜色、高亮底色，或使用渐变字；
- **链接**：给文字加网址链接，已有链接时可以编辑；
- **关联内容**：把文字链接到一张卡片、一篇文章或项目文档；
- **行内公式**：把选中的文字转成公式；
- **批注**：在文字旁留一条批注，鼠标悬停可以查看。

窗口较窄时，部分按钮会收进「文本样式」和「更多」里。

## 拖拽和块菜单

把鼠标移到任意一块（段落、标题、列表项、图片、表格……）上，它的左侧会出现一个拖拽手柄：

- **调整顺序**：按住手柄上下拖动，指示线会标出放下的位置。列表项和任务项可以单独拖动；
- **打开块菜单**：点击手柄。菜单里可以「转换成」其他块类型（比如把段落转成标题、Callout 或引用块），也可以上移、下移、剪切、复制或删除这一块。部分块还有自己的选项，比如 Callout 的「修改类型」、高亮块的「修改颜色」。

标题旁还会出现一个折叠箭头，点击可以收起这个标题下面的内容，写长文时方便只看结构。

## 粘贴

粘贴时，编辑器会尽量保留原来的样子：

| 粘贴的内容                | 结果                                               |
| ------------------------- | -------------------------------------------------- |
| 一段 Markdown 文本        | 自动转成对应的标题、列表、表格、代码块等           |
| 单独一个网址              | 变成链接；先选中文字再粘贴网址，这段文字就成了链接 |
| 图片文件或截图            | 插入为图片                                         |
| 网页或电子表格里的表格    | 生成一张表格                                       |
| 从 Tau 其他地方复制的内容 | 原样保留所有块和格式                               |

:::tip{title="把旧笔记搬进来"}
从其他 Markdown 编辑器复制整篇笔记，直接粘贴就能得到排好版的内容。要一次导入很多文件，用卡片库、文章或项目页的「导入」更方便。
:::

## 引用其他内容

输入 `@` 或 `[[`（中文输入法下输入 `【【` 也可以），在弹出的列表中选择一张卡片、一篇文章或项目文档，即可在正文中插入指向它的链接。详见 [卡片](/docs/cards/) 中的「引用其他内容」。
