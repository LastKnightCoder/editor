番茄专注是一个专注计时器：选一个预设，开始计时，一次只做一件事。每次专注都会记进时间账本，你可以回头看看时间都花在了哪里。

比如你今天要写读书笔记的第三章，打算用「写作 25 分钟」连做几轮。下文都用这个例子。

## 开始一次专注

::demo{name="pomodoro" caption="鼠标悬停在一个预设上，点击 ▶ 开始。示意中每分钟只需一秒"}

页面左侧是你的预设。第一次使用时这里是空的，点击「新建预设」，建一个「写作」，选倒计时 25 分钟。

开始前，在「专注于…」里选今天的待办「写第三章」，这次专注就会关联到它，之后在这条待办的详情里能看到它累计专注了几个番茄。然后把鼠标悬停在「写作」上，点击行尾的 ▶。手不想离开键盘时，按预设前面的数字键 <kbd>1</kbd>–<kbd>9</kbd> 也能直接开始，右键菜单里也有「开始专注」。

如果你已经在待办页或日程页看着「写第三章」，就不用回番茄页了：在待办详情里点「专注」，或在有具体时间的日程详情里点「开始专注」，选一个预设就开始，并自动关联到这一条。已经有一次专注在计时，这里的按钮会变成「专注于此」，点一下就把正在进行的这次改关联到这一条，按钮随即显示为「专注中」。

## 专注的时候

开始后，左侧变成一个播放器，显示剩余时间和预计结束的时刻。

| 想做的                 | 怎么做                                                                     |
| ---------------------- | -------------------------------------------------------------------------- |
| 被打断了，先停一下     | 点击圆形按钮，或按 <kbd>空格</kbd>，再点一次继续                           |
| 屏幕上只留时间         | 按 <kbd>I</kbd> 进入沉浸模式，全屏只显示一个大时钟，按 <kbd>Esc</kbd> 退出 |
| 切到别的软件时也看得到 | 点「小窗」，打开一个置顶的计时小窗                                         |
| 需要一点白噪音         | 点「背景音」，选小溪、小鸟、潮汐、篝火、大雨等环境音并调节音量             |
| 提前写完了             | 点「结束」                                                                 |

计时在后台进行，离开番茄专注页面不会中断。专注期间，侧边栏「番茄专注」旁会显示剩余时间。

25 分钟走完会自动结束，并弹出「番茄完成」的通知。这时不妨起身走走，休息几分钟再开始下一轮。

:::info{title="不足 5 分钟不会记录"}
专注不到 5 分钟就结束，Tau 会先确认一次；确认后这次不会记入账本。误点开始的不会留下记录。
:::

## 管理预设

点击右上角的「新建预设」，填写名称，选择计时方式和时长：

- **倒计时**：设定时长，例如 25 分钟，到点自动结束。适合番茄工作法。
- **正计时**：从零开始计，手动结束。适合不确定要多久的事，比如读一章书。

右键点击预设可以编辑或归档，拖动可以调整顺序。点击预设本身会打开详情，查看近 90 天的专注次数、累计时长和每一次的记录。归档的预设可以在右上角的「已归档的预设」里恢复，历史记录都会保留。

## 回头看时间花在哪

页面右侧的时间账本每天一行，横轴是早上 6 点到午夜，色块就是你专注的时段，颜色对应预设。写了一周第三章，看看「写作」的色块都落在一天里的什么时候：

- 点击标题旁的时间范围，可以切换近 7 天、近 30 天、本月、今年等，也可以选「全部」查看全年热力格；
- 点击某一天，查看当天的详细记录；
- 点击色块，查看这一次专注的时间、时长和关联的待办或日程；
- 点击图例里的「写作」，只高亮这个预设的记录。

账本下方的「时段分布」会标出你一天中最常专注的时段。

记错了也能改：在当天的详情里，点击某条记录的时长可以修改，右键可以删除。删除后底部会出现「撤销」。

完成的专注还会自动出现在 [日程](/docs/todos/) 的日历上，和当天的其他安排排在一起。专注时长也会汇总到 [今日](/docs/today/) 顶部的「已专注」和「回顾」里。
