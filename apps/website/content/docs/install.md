Tau 支持 macOS、Windows 和 Android，可以免费下载，不需要注册账号。打开 [官网下载区](/#download)，选择你的系统即可。

## macOS

macOS 版分为 Apple 芯片和 Intel 芯片两个安装包，先确认你的电脑属于哪一种：

1. 点击屏幕左上角的苹果菜单，选择「关于本机」。
2. 看「芯片」一栏：写着 Apple M 系列就下载 Apple 芯片版，写着 Intel 就下载 Intel 版。

下载完成后：

1. 双击打开下载的 `.dmg` 文件。
2. 在弹出的窗口里，把 Tau 图标拖进「应用程序」文件夹。
3. 打开「启动台」或「应用程序」文件夹，点击 Tau 启动。

第一次打开时，系统会提示「Tau 是从互联网下载的 App，确定要打开吗？」，点击「打开」即可。之后就不会再问了。

:::info{title="不确定选哪个？"}
在 Mac 上打开官网时，下载按钮会自动推荐适合当前电脑的版本。识别不出芯片时，按钮下方会提示你怎么查看。
:::

## Windows

1. 下载 Windows 安装程序（`.exe` 文件），双击运行。
2. 按提示选择安装位置，点击「安装」。安装时需要管理员权限，系统会弹窗确认。
3. 安装完成后，可以从桌面快捷方式或开始菜单打开 Tau。

安装后，`.md` 和 `.markdown` 文件的「打开方式」里会出现 Tau，可以直接用它打开本地 Markdown 文件。

## Android

用手机浏览器打开官网，下载 Android 安装包，然后点击下载好的文件进行安装。

1. 首次安装时，系统可能提示「禁止安装未知应用」。点击「设置」，允许当前浏览器安装应用，然后返回继续。
2. 按提示点击「安装」，完成后从桌面打开 Tau。

安装包适用于 Android 7.0 及以上、64 位 ARM 架构的手机，近几年上市的 Android 手机基本都属于这一类。手机端能做什么，见 [手机端](/docs/mobile/)。

## 更新

### 电脑

Tau 启动后会在后台检查新版本，发现后自动下载。下载完成时，右上角会弹出「新版本已就绪」的通知：

- 点击「立即更新」，Tau 会重启并完成安装；
- 暂时不想更新也没关系，下次退出 Tau 时会自动装好；
- 点击「查看更新内容」，可以先看看这个版本改了什么。

你也可以打开「设置 › 关于与更新」，手动点击「检查更新」。不想自动检查的话，在同一页关闭「自动检查更新」。

### 手机

进入「我的」页面时，Tau 会检查一次更新。有新版本时，「关于与更新」一栏会显示提示。点击进入后选择「下载并安装」，下载完成后会打开系统安装界面。

第一次更新时，系统会要求你允许 Tau 安装应用。允许后返回 Tau，点击「安装」即可。

更新不会影响你的内容和设置。

## 常见安装问题

:::detail{title="Mac 上打开时提示「无法打开」或「无法验证开发者」"}
官网提供的 macOS 安装包都经过 Apple 签名和公证，正常情况下不会出现这个提示。如果遇到了，请检查：

- 安装包是否从 [官网](/#download) 下载。从其他渠道转发的文件可能已损坏或被改动，请重新下载。
- 下载是否完整。下载中断的文件无法打开，重新下载一次即可。
:::

:::detail{title="Mac 上双击后没有反应，或提示无法在这台 Mac 上运行"}
多半是下错了芯片版本：Apple 芯片版不能在 Intel 的 Mac 上运行。按上文的方法查看芯片类型，下载对应的版本，再拖进「应用程序」覆盖原来的即可。
:::

:::detail{title="Windows 提示「Windows 已保护你的电脑」"}
第一次运行新下载的程序时，Windows 可能弹出这个提醒。确认安装程序是从官网下载的，点击「更多信息」，再点击「仍要运行」即可继续安装。
:::

:::detail{title="Android 提示「安装包无效」或「与手机不兼容」"}
请确认手机系统是 Android 7.0 及以上，且安装包已完整下载。少数较老的 32 位手机无法安装。
:::

:::detail{title="重装或换电脑后，原来的内容还在吗？"}
内容保存在电脑本地，覆盖安装新版本不会丢失。如果要卸载 Tau 或换电脑，请先按 [数据与备份](/docs/data/) 导出或同步内容。
:::

装好之后，跟着 [五分钟上手](/docs/quick-start/) 写下第一张卡片。
