Tau 支持 macOS、Windows 与 Android，免费下载，不用注册。

## macOS

macOS 版分为 **Apple 芯片** 和 **Intel 芯片** 两个安装包，请选择与电脑对应的版本：

1. 点屏幕左上角的苹果菜单，选择「关于本机」。
2. 看「芯片」一栏：写着 Apple M 系列就下载 Apple 芯片版，写着 Intel 就下载 Intel 版。
3. 打开下载好的安装包，把 Tau 拖进「应用程序」文件夹。

:::info{title="不确定选哪个？"}
在 Mac 上打开官网时，下载按钮会自动推荐适合你电脑的版本。
:::

## Windows

下载 Windows 安装程序，双击运行，按提示完成安装即可。安装完成后可以从开始菜单打开 Tau。

## Android

用手机浏览器打开官网，下载 Android 安装包，再点开下载好的文件安装。

1. 第一次安装时，系统会提示「禁止安装未知应用」，点「设置」，允许当前浏览器安装应用，再返回继续。
2. 按提示点「安装」，完成后从桌面打开 Tau。

安装包适用于 64 位 ARM 手机，近几年上市的 Android 手机基本都属于这一类。

## 更新

桌面版会在后台检查新版本，有更新时提醒你。

进入「我的」时 Android 版会自动检查更新，有新版本时「关于与更新」一栏会出现提示。点进去后点「下载并安装」，下载完成会打开系统安装界面。第一次需要允许 Tau 安装应用，之后点「安装」即可，笔记和设置都会保留。

你也可以随时回到 [官网下载页](/#download) 获取最新版本。
