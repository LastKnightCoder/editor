Tau 提供 Android 版，适合在路上随手记卡片、写日记，或者用排队、通勤这样的碎片时间复习闪卡。手机和电脑通过你自己的云存储同步，回到电脑前就能接着整理。安装方法见 [下载与安装](/docs/install/)。

## 认识手机端

底部有四个标签页：

| 标签 | 内容                                                                 |
| ---- | -------------------------------------------------------------------- |
| 今天 | 今天的日程、待复习闪卡、任务和日记，以及最近写的卡片、文章与项目文档 |
| 卡片 | 卡片库，浏览和搜索所有卡片                                           |
| 日记 | 按日期浏览日记，随手写下一段                                         |
| 我的 | 更多功能、同步、插件和设置                                           |

中间的 + 按钮可以快速新建卡片、文章、日程或日记。在今天、卡片、日记、我的之间左右滑动也能切换标签。

「我的」页顶部是功能宫格：任务、文章、项目、闪卡和番茄专注都从这里进入。下方依次是插件功能、同步、图片与附件、实时协作、语音合成、外观（主题、图片渲染、正文字体）、编辑器、反馈与关于。右上角的放大镜可以搜索所有内容。

:::info{title="哪些功能只在电脑上"}
AI 对话、白板、PDF 阅读、数据库、Notebook 和知识地图目前只在电脑版中提供。手机上记下的内容同步到电脑后，都可以在这些功能里使用。
:::

## 典型用法

- **随手记**：路上冒出一个想法，点 + 选「新卡片」，写两句就关掉。回到电脑后在卡片库里补全、加标签、引用到文章里。
- **碎片复习**：在「今天」的闪卡一行点「开始」，或进入「我的 › 闪卡」，用几分钟复习今天到期的卡片。复习进度同步回电脑后，电脑上不会重复出现。
- **睡前日记**：切到「日记」标签，或在「今天」的日记一行点「写」，记下今天的事。
- **专注计时**：「我的 › 番茄」里选一个预设开始计时，记录和电脑的时间账本合在一起。
- **导入外部 Markdown**：在微信、文件管理器等应用中打开一个 `.md` 文件，选择用 Tau 打开，预览后可以「存为卡片」「存为文章」或「加入项目」。

## 与电脑同步

手机和电脑通过同一个云存储同步，支持 WebDAV、S3、阿里云 OSS 和 GitHub。同步服务由插件提供，两端都要安装同一个同步插件并填写相同的账号。

::demo{name="mobile" caption="点击「下载更新」，等同步完成后变成「已是最新」；点击底部中间的 + 查看可以新建的内容"}

第一次配置时：

1. 先在电脑上配好同步，并点击「同步到云端」上传一次，步骤见 [数据与备份](/docs/data/) 的「配置同步」。
2. 在手机上打开「我的 › 同步」。还没有同步服务时，页面会列出可选的存储服务；没有你要的服务，点击「去插件中心添加同步服务」安装它。
3. 点击服务，填入和电脑上完全相同的账号与存储位置，点击「保存」。保存后会自动测试连接，显示「连接正常 · 云端已有数据库」。
4. 点击「设为当前」，回到同步页，点击「下载更新」把电脑上的内容下载到手机。

之后的日常同步只需打开「我的 › 同步」，点击页面中间的主按钮。按钮会根据两端版本自动变化：

| 状态         | 按钮     | 含义                               |
| ------------ | -------- | ---------------------------------- |
| 云端有更新   | 下载更新 | 电脑上传了新版本，下载后即可看到   |
| 本机版本更新 | 上传改动 | 手机上有新内容，上传后电脑才能拉取 |
| 已是最新     | 立即同步 | 两端一致                           |

数据库同步完成后，图片和附件会在后台接着同步，进度显示在「资源文件」一行。从云端下载数据库前，手机上原来的数据库会先自动备份。

:::warning{title="一端写完先同步"}
同步以整个数据库为单位，不会合并两边的修改。在手机上记完先上传，回到电脑上先「拉取远程」再动笔；反过来也一样。
:::

如果某一端的数据出了问题，需要强制以另一端为准，可以在同步页「更多」中打开「整库覆盖」，选择「以本机为准」或「以云端为准」。被覆盖一侧未同步的修改会丢失，无法撤销，所以需要按住按钮确认。

## 插件

手机端也可以安装插件，入口在「我的 › 插件中心」，分为「商店」和「已安装」两个标签。商店只显示适用于手机的插件，从这里安装的插件校验通过后会自动启用。安装或启停后，在插件中心顶部点击「立即生效」即可。插件提供的页面会出现在「我的」页的「插件功能」中。更多说明见 [插件](/docs/plugins/)。

## 协作

在「我的 › 实时协作」中可以修改昵称、查看连接状态。别人分享给你协作码后，进入「我的协作」输入协作码，对方同意后即可加入，和电脑上的协作者实时编辑同一份内容。详见 [协作](/docs/collaboration/)。

## 更新

进入「我的」页时，Tau 会检查新版本，有新版本时「关于与更新」一行会显示提示。点进去选择「下载并安装」，下载完成后会打开系统安装界面，更新后笔记和设置都会保留。
