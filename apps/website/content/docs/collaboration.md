协作可以让别人和你实时编辑同一份内容。文章、卡片、项目文档、日记和白板都能共享。双方都不用注册账号，各自用一个昵称参与；改动会通过 Tau 的协作服务实时同步，每个人的光标颜色不同，一眼就能看出谁在改哪里。

比如你和读书会的朋友一起整理《Deep Work》的讨论记录：你把这篇文章共享出去，把协作码发到群里，大家申请加入、你同意后，就能同时往里写。

## 发起协作

::demo{name="collab" caption="点左侧的复制按钮，协作码会填到右侧；点「申请加入」，再在左侧点 ✓ 同意"}

1. 打开要共享的文章、卡片或项目文档，在「⋯」菜单中选择「发起协作」，然后点「发起共享」；白板在右下角点「共享」。也可以在侧边栏点「协作」，点「共享本地内容」，搜索并选择一份内容，日记从这里共享。
2. Tau 会生成一个 12 位协作码，7 天内有效。把它发给对方。
3. 对方申请后，你会收到通知，侧边栏「协作」旁也会出现数字。在「成员与邀请」里点 ✓ 同意，或点 × 拒绝。

共享后，内容仍在原来的位置，你照常在那里编辑，改动会同步给成员。已共享的内容顶部会常驻成员头像，点开就是「成员与邀请」。

:::info{title="哪些东西不会共享"}

- 正文里的白板、数据库这类本地块不会共享，成员看到的是一段占位说明；
- 本机视频不会上传。含有本机视频的白板暂时不能共享；
- 白板里引用的文章和卡片只带卡面标题，原文不会随之共享。

图片和其他附件会在发起共享时上传，成员可以正常查看。
:::

## 加入协作

在侧边栏点「协作」，点「输入协作码」，粘贴收到的协作码（会自动分成三段），然后点「申请加入」。申请 7 天内有效，对方同意后，这份内容会出现在侧边栏「协作」下的「我加入的」中，点开即可编辑。

在协作页右上角可以修改你的昵称，其他成员看到的就是这个名字。手机上也可以输入协作码加入，详见 [手机端](/docs/mobile/)。

## 一起编辑

打开协作中的内容，顶部会显示成员头像和在线情况，例如「2 人正在编辑」。头像右下角的小圆点表示状态：绿色是正在编辑，蓝色是正在查看，灰色是在后台，头像变淡则表示离线。

### 发起人和成员能做什么

所有成员都可以编辑内容。管理协作的操作只有发起人能做：

| 操作               | 发起人 | 成员 |
| ------------------ | ------ | ---- |
| 编辑内容           | ✓      | ✓    |
| 复制、轮换协作码   | ✓      |      |
| 同意或拒绝加入申请 | ✓      |      |
| 移除成员           | ✓      |      |
| 结束共享           | ✓      |      |
| 退出协作           |        | ✓    |

协作码可以随时在「⋯」菜单里点「轮换协作码」更换，旧码立即失效，已加入的成员不受影响。协作码发错了人，轮换一下即可。移除某个成员后，他的设备会立即断开、不能再访问，但他本机已经保存的内容不会被删除。

### 断网时

断网不影响编辑。离线时顶部会出现提示，你写的内容先保存在本机，网络恢复后自动和其他人的改动合并。

::demo{name="collab-offline" caption="打开林夏那边的「断网」，两边各点几句；再把网连上，看两边的改动合到一起"}

几个人同时改同一段时，各自的改动都会保留并自动合并，不需要你手动处理冲突。改完之后读一遍，把重复或前后不通的句子理顺就好。

## 结束协作

发起人在「⋯」菜单里点「结束共享」。所有成员会停止协作，协作服务上保存的正文和附件会被清理，原内容完整保留在你本机。

成员点「退出协作」，这份内容会从「我加入的」里移除。

:::warning{title="还有没同步完的改动"}
发起人有改动还没同步时，要等同步完成才能结束共享。成员退出时如果还有未同步的改动，可以等同步完成再退出，或者选「丢弃改动并退出」。
:::

协作服务连不上时，按钮会变为「清理本地记录」：缓存的内容会先保留到本地，再删除本机的共享记录，原内容不会删除。共享被发起人结束后，成员这边会显示「清理协作缓存」。

## 常见问题

:::detail{title="对方说协作码不能用"}
检查三点：协作码是否超过 7 天，是否已经被轮换，是否少复制了几位。在「成员与邀请」里可以看到当前协作码和剩余天数，必要时轮换一个新的再发。
:::

:::detail{title="能加多少人、共享多少份内容"}
一份内容最多 10 名成员。每台设备同时共享的内容有数量上限，达到时会提示「已达到共享内容数量上限」，结束一份不再需要的共享即可。
:::

:::detail{title="协作需要联网吗"}
发起共享、加入协作和同步改动都需要联网。协作中途断网时仍可继续编辑，联网后自动同步。
:::

:::detail{title="成员能看到我的其他笔记吗"}
不能。成员只能看到你共享的这一份内容，你的其他笔记不会随之共享。
:::
