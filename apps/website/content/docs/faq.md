## Tau 收费吗？

Tau 免费下载、免费使用，不需要注册账号。

## 没有网络能用吗？

可以。写作、整理、复习等核心功能都在本地完成，完全离线可用。只有 AI、发布、协作和插件安装这类需要连接外部服务的功能才需要网络。

## 我的数据安全吗？

内容只存在你自己的电脑上。使用 AI 时，相关内容会发送给你自己配置的模型服务。

## 可以从其他笔记软件迁移过来吗？

可以把 Markdown 内容粘贴或导入到 Tau 中，标题、列表、表格、代码块等格式会自动识别。

## Tau 开源吗？

开源，源码在 [GitHub](https://github.com/LastKnightCoder/editor)。欢迎提交问题和建议。

## 遇到问题怎么办？

:::detail{title="反馈渠道"}
可以在 GitHub 仓库提交 Issue，描述你遇到的问题和使用的系统版本，最好附上截图。
:::
