写下的东西越多，越容易被遗忘在角落。漫步和知识地图帮你把旧内容重新翻出来：漫步每次给你一条，顺着它走到相关的内容；知识地图把所有内容摊在一张图上，让你看清它们怎样连在一起。

## 漫步

在侧边栏「学习」分组中点击「漫步」。Tau 会从你写过的内容里抽出一条，并告诉你为什么是它，比如「317 天没见过它了」「那年今日 · 2 年前的今天」，或者「从「Deep Work 读书笔记」经双链走来」。

::demo{name="walk" caption="点击右侧的一条相关内容走过去，顶部足迹会多一步；按空格随机换一条"}

### 顺着岔路走

右侧的「从这里走向」列出了和当前内容相关的几条，并注明关系：

- **双链**：两条内容之间有引用，比如你在一张卡片里用 `@` 提到过另一篇文章。
- **标签**：它们有相同的标签。
- **语义相近**：内容说的是相近的事，即使你从没把它们连起来过。

点击一条就走过去。走过的每一步都记在顶部的「足迹」里，按 <kbd>←</kbd> <kbd>→</kbd> 可以在足迹中前后切换，点击足迹里的标题也能直接跳回去。想换个方向时，按 <kbd>空格</kbd>，或点击「换个方向，随机跳一下」。

比如某天晚上你打开漫步，抽到一年前写的卡片「专注是可以练习的能力」。右边提示它经双链连到「Deep Work 读书笔记」，你点过去，又顺着语义相近走到一篇日记，发现自己那天写的散步心得，正好是这个观点的一个例子。这样的偶遇，正是漫步想帮你制造的。

### 遇到值得处理的内容

每条内容下方有三个操作：

- **打开原文**：跳到这条内容本身，可以接着修改或补充。
- **做成闪卡**：用 AI 把这条内容做成 [闪卡](/docs/flashcards/)，交给复习计划。PDF 批注没有这个入口。
- **别再抽到这条**：点击右侧的眼睛图标，这条内容以后不会再被抽中。

### 设置抽取范围

点击右上角的选择器，可以设置两件事：

- **从哪些内容里抽**：卡片、文章、日记、项目文档、PDF 批注，可以多选。
- **抽取偏好**：

| 偏好     | 效果                                     |
| -------- | ---------------------------------------- |
| 纯随机   | 每条内容被抽到的机会均等                 |
| 久未见   | 越久没见的内容，越容易被抽到（默认）     |
| 那年今日 | 优先抽往年今天写下的内容，没有时按久未见 |

:::info{title="为什么有些内容从没出现过？"}
少于 30 字的内容不会被抽到，太短的片段很难重读出新意。如果漫步页提示没有内容，先写几条 30 字以上的卡片、文章或日记，或者检查抽取范围是不是选得太窄。
:::

:::tip{title="把漫步变成一个习惯"}
每天花五分钟走几步，效果比偶尔走一大圈好。遇到想补充的，打开原文多写一句；遇到想记住的，做成闪卡；遇到已经过时的，点「别再抽到这条」。旧内容就这样一点点被你整理起来。
:::

## 知识地图

点击标题栏右侧的地图图标，打开知识地图。在某篇内容的详情页中打开时，地图会以这篇内容为中心。

::demo{name="map" caption="鼠标悬停在一个节点上，只显示与它相连的内容；切换上方的类型筛选"}

地图上的每个点是一篇卡片、文章或项目文档。内容相近的会自动聚成一组，并标上主题名。点和点之间的连线，来自你写的引用和手动添加的连接，添加方法见 [卡片](/docs/cards/) 中的「引用其他内容」。

### 在地图上找东西

- **看关联**：鼠标悬停在一个点上，与它相连的内容会保留，其余内容变淡。稍等片刻，会显示这篇内容的预览。
- **查看内容**：点击一个点，在右侧查看全文，点击「打开」进入原文。
- **筛选**：按卡片、文章、项目文档筛选，或在「全部项目」中只看某个项目的内容。没被选中的点会变淡，但不会消失，你仍能看清它在整张图里的位置。
- **回放生长过程**：左下角的说明行显示一共有多少条笔记、从哪个月开始。点击它，可以看到这张地图从第一条笔记开始一点点长出来的过程；播放中按 <kbd>Esc</kbd> 跳到结尾。

### 让 AI 帮你找联系

点击右上角的「AI 洞见」，AI 会通读一遍你的知识版图，在地图上标出那些值得建立关联、但你还没连起来的内容，详见 [AI 对话与洞见](/docs/ai/)。

:::tip{title="孤零零的点值得看一眼"}
地图边缘那些没有连线的点，往往是写完就再没碰过的内容。点开看看，也许能用 `@` 把它和某篇相关的文章连起来，下次漫步时就能顺着它走到更多地方。
:::
