文章适合需要展开论述的长篇内容，例如读书笔记、观点文章和复盘总结。和卡片相比，文章有标题、封面和目录，方便你写长、也方便日后回头读。

一种常见的用法：读《深度工作》时先随手写了十几张卡片，读完后新建一篇「《深度工作》读书笔记」，在创作模式里把这些卡片摆在左边，一边看一边写成完整的文章。

## 文章列表

::demo{name="articles" caption="在右上角的搜索框中输入「读书」试试"}

在侧边栏点击「文章」。文章按月份分段显示，置顶的文章排在最前；每个月的分段标题旁会显示这个月写了几篇、多少字。

- **新建**：点击「新建」，选择「空白文章」，或「在创作模式中新建」直接带着资料白板开始写。
- **导入**：点击「导入」，选择「Markdown 文件…」或「文件夹或压缩包…」，每个 Markdown 文件会成为一篇文章。也可以把文件夹或 .zip 直接拖到页面上。
- **搜索**：在右上角的搜索框中输入标题里的词，列表实时过滤。
- **切换视图**：搜索框旁边的按钮可以在「网格」和「列表」之间切换。列表视图可以按标题、字数、更新或创建时间排序。

鼠标悬停在一篇文章上，点星标可以置顶，点「⋯」可以进入演示模式、导出 Markdown、换封面、窗口打开或删除文章。

## 写文章

打开一篇文章后：

1. 点击顶部的「添加封面」，选一张图片作为封面。没有封面时，列表里会用一块彩色底和正文开头的文字代替。
2. 在封面下方填写标题，按回车确认。
3. 写正文。写法见 [编辑器基础](/docs/editor/)：用 `##` 分出章节，用 `@` 引用你的卡片。
4. 在文章末尾的「添加标签」处输入标签，按回车确认。

标题下方的一行显示最后编辑时间、字数和创建时间。正文里有标题时，右侧会出现大纲，点击可以跳到对应章节，滚动时当前章节会高亮。

侧边栏「文章」下方列出了所有标签，点击标签只显示相关文章，再点一次回到全部。

:::tip{title="在文章之间快速切换"}
点击标题栏里「文章 /」后面的文章名，会弹出一个速切列表：可以搜索标题，直接跳到另一篇文章，不用回到列表页。
:::

## 创作模式

写长文时，你可以先把要用的资料摆出来再动笔。创作模式把窗口分成两部分：左侧是白板，用来放资料、打草稿；右侧是正文。

::demo{name="compose" caption="鼠标悬停在左侧的资料上，点击右上角的「引用」；再次悬停在「已引用」上可以取消"}

1. 在文章标题下方点击「创作模式」。
2. 首次进入时，Tau 会询问「这篇想写什么？」。用一句话说说主题、想表达的观点或想回答的问题，再选择要从卡片、文章、项目文档还是日记里找资料，然后点击「开始找资料」。不需要的话点「跳过，空白白板」。
3. 这篇文章已经关联的内容（「添加连接」连上的和正文里引用的）会先作为「已关联」一组放到白板上，AI 再从你的笔记中找出相关资料，分好组摆在白板上。不需要的资料直接从白板上删掉；想要更多，点击白板右上角的「再找一些」。
4. 动笔写作。写到某一段时，和这段相关的资料会亮起来，点击「连到此段」就能在这段末尾插入指向它的链接；也可以悬停在任意一张资料上点「引用」，在光标处插入链接。已经引用的资料会标上「已引用」，悬停点击可以取消引用。

两栏中间的分隔线可以拖动，调整正文栏的宽度。点击「退出创作模式」回到普通编辑，白板会保留，下次进来资料还在。

:::info{title="没有连接 AI 模型时"}
创作模式照样可以用，只是不会自动找资料。你可以用白板工具栏的「文档」放入卡片、文章、项目文档或日记。写作意图随时可以在白板右上角查看和修改。为「AI 洞见」分配模型后即可自动找资料，设置方法见 [AI 对话与洞见](/docs/ai/)。
:::

## 更多操作

文章标题下方一行的「⋯」菜单：

| 菜单 | 选项                                        |
| ---- | ------------------------------------------- |
| 场景 | 演示模式、沉浸模式、在新窗口打开            |
| 复制 | 复制 Markdown、复制公众号格式               |
| 导出 | Markdown 文件、图片、EPUB、PDF              |
| 生成 | AI 制卡（闪卡）、手动制卡（闪卡）、生成播客 |

菜单里还有「发起协作」和「删除文章」。写完的文章可以发布成网页分享出去，见 [发布](/docs/publish/)。

- **沉浸模式**：隐藏界面其他部分，只留正文，适合专心写作；
- **复制公众号格式**：复制带排版的内容，直接粘贴到微信公众号编辑器里；
- **生成播客**：把文章转成一段可以收听的音频，需要先配置语音服务。
