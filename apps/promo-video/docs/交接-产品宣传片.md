## 1. 用户已拍板的决策（不要推翻）

### 叙事 v2（以此为准）

- **叙事参考官网 `apps/website/index.html`**。官网的区块顺序就是能力清单：首屏 → 写作 → 白板 → 数据库 → 知识闭环 → AI → All in one → 插件 → 下载。每个区块一句标题加一个示意，正好对应视频的「宣言 + 演示」。**文案优先取官网原句。** 用户原话：官网「比较全面展示我们的能力，比较符合产品介绍」。
- **转场骨架：一张无限画布**（用户选定）。所有窗口摆在同一个 `World` 上，章节之间不黑场、不切白，镜头飞越过去。手法有四个：
  1. **线索物件**：同一元素在相邻镜头里都出现，充当过渡的桥。
  2. **用软件自己的动作转场**：侧栏换页、创作模式展开、白板 fit、推进卡片、知识地图拉远。
  3. **宣言从画面里长出来**：见下面「宣言样式」。
  4. **卡拍**：段落切换卡小节线，元素落位卡拍。
- **转场必须丝滑**。样片 8 用交叉淡化交接，用户评价「非常的不丝滑」。现在的标准做法是：镜头一路推进，前一个画面里的内容直接长成下一个画面（详见 §6「白板 → 数据库」）。**任何交接都不要用硬切或交叉淡化**。
- **故事线：Deep Work / 专注（官网同款）**（用户选定）。演示数据与官网一致，都在 `mock/deepwork.ts`：
  - 文章「Deep Work：在喧嚣里保持专注」
  - 卡片「先改环境，再谈专注」「注意力残留」
  - 网页「注意力为什么越来越稀缺」（少数派）
  - 书单数据库
  - 「专注力手册」项目与待办

  旧的「延展心智」数据（`mock/day.ts`、`mock/product.ts`、`mock/compose.ts` 的 `COMPOSE_*`）只留给功能片和场景片用。

- **宣言样式定为 a + c**（用户选定）：
  - **a：叠在画面上的宣言**（`kit/Manifesto` 的 `ManifestoOverlay`）。背后的画面按 `manifestoVeil` 虚化 `VEIL_BLUR = 9px`（用户在 14/9/5 三档里认可了 9），再加一层淡白雾。**背后必须是前后两段演示用的同一个窗口**：字退场时窗口变清晰，接着演示。用户一开始不理解「为什么背后放个窗口」，解释成「不离开软件、只是暂停点题」之后才接受。
  - **c：整屏宣言**（`Manifesto`）。只用在需要整屏停住的重拍上：第 56 小节的空拍、片尾。
  - **b（官网式左文右窗）已否决**：两个焦点抢视线，字被挤小，窗口小到读不了，看起来像网页截图。
- **Slogan 改用官网首屏的「让想法，长成体系。」**，用户说「slogan 可以后面放」，倾向和片尾字标一起出。片尾用官网下载区的「从下一个想法开始。」「免费下载，不用注册」。片尾网址 **taunote.app**。

### 各段的口径

- **写作**：只讲所见即所得和丰富的块。**不强调「断网也照写」**（用户要求）。宣言「所见，即所得。」。
  - 所见即所得像 Notion 那样**就地成型、不分屏**：打 `## `、`> `、`**` 当场成型。
  - 块要「快速闪过、越多越好」，不逐个讲解。
- **输入时正在写的那一行必须始终在画面正中**（用户：「输入的时候内容应该始终在中间看的才舒服」）。
- **白板不能只演示思维导图**（用户：「白板的演示是不是太少了」）。形状、箭头、画框、导图、配色、手绘、嵌入文章卡、演示都要有。时间从数据库里挤（用户选定）。
- **本地数据**：口径是「数据全在本地」，不是「不联网」。限制见 §4。
- **双链 / 关联**：在卡片里单独演示 `[[` 被批评「意义不明」，因为看不出在哪个模块。要放进**知识地图章节**：在卡片里加链接，镜头沿这条新连线顺滑转场到知识地图。
- **每个演示都要能看出在哪个模块、为什么重要**。现在用底部的 `kit/ModuleTag` 标「01 输入 · 浏览器插件划线，记得出处」这样的标签。
- **知识地图段**（2026-10-18 用户三选都选推荐项）：
  - `[[` 在**卡片**里演示（不在创作模式文章里），和 AI 的「连到此段」区分开，看得出是手动的双链。
  - 第 56 小节整屏宣言用「**想法之间，自有引力。**」，「引力」染强调色（最早分镜草案的句子；先用过官网文档原句「先写，再连，最后才需要结构。」，用户嫌太怪），副标题取官网总览标签「知识地图 · 双向关联 · 相关推荐」。做法是点说明行开始回放、地图清空，镜头推进满屏白画布，字压在白上——不是 `Manifesto` 的舞台底，是画布本身。
  - 高潮后半段做**地图上的 AI 洞见**（呼应弧线跨簇画出、选一处连接）。
- **All in one 段**（2026-10-18 用户选定）：**四个窗口汇进今日**——番茄、待办、日程、日记各一个窗口摆成 2×2，镜头逐个飞过去各演一个动作，最后拉远，四个窗口一起缩小飞进中间今日窗口里各自的区块。宣言用官网原句「写作之外的日子，也在这里。」。
- **插件 + 本地段**（2026-10-19 用户选定）：
  - **如实演重启**：从插件中心装的插件要重启才生效（真实代码如此；官网文档写「不需要重启」是错的，视频按代码）。
  - **本地部分只演导出 Markdown**，不演数据库路径。口径「笔记存在你自己的电脑里，随时导出 Markdown」。
  - 宣言「装一个插件，多一种能力。」，副标题取官网插件区的能力标签「页面 · 编辑器块 · 白板元素 · 同步存储」（不用官网副标题「装完自动启用」，与重启矛盾）。

### 不变的旧决策

- 这是**产品介绍**，**不要出现时间点或「一天」的概念**。
- **开场**（8 秒，用户认可）：光点汇聚成渐变字标 Tau → 实体字 +「你的个人知识工作台」→ Deep Work 文章窗口在 3D 里立起 → 镜头俯冲进窗口，写作段在同一机位接住。
  - 不要「四根支柱目录」，不要开场快闪局部窗口，不要深蓝底叠图标（用户说「蛮丑」）。
- **视觉**：
  - 舞台不用软件的暖色 token，用 **「冷白」**（`brand/stage.ts` 的 `STAGES.studio`）。
  - 窗口里用软件真实主题 **「海盐」（ocean）**，经 `AppThemeProvider` 注入。
  - 品牌色取自图标的藏青 → 金。
  - 字体：思源宋体（宣言）、思源黑体（字幕）、JetBrains Mono（标签）、白板手绘字体（小赖 SC + Shantell Sans），都是 OFL。**不要用本机方正字体。**
  - **界面必须是完整窗口**，只有特写可以推近。
- **配乐**：Motivational Technology，作者 Rockot（Pixabay Content License，可商用，无需署名）。
  - 文件：`public/music/motivational-technology.mp3`，原件在 `apps/promo-video/assets/`（用户让从 `apps/assets` 移进来的）。
  - 117.45 BPM，一小节约 2 秒。产品片从曲内**第 11 小节（23.057 秒）**截入（`MUSIC_OFFSET`），全片最长 2:46。

## 2. 配乐结构 → 章节排布

`films/product/timeline.ts`：

- `bar(n)`：曲内第 n 小节在影片里的秒数。
- `beat(n)`：曲内第 n 拍（小节 n 的第 k 拍 = `n * 4 + k`）在影片里的秒数，**n 可以带小数**（半拍 `+0.5`）。
- `f(秒)`：秒 → 帧（60fps）。
- 各章的时刻全部写成曲内拍序号，放在 `P.write / P.board / P.life / P.ai`。

### 工作流程（每一段都这样做，用户认可）

1. **调研真实界面**：用 Explore 子代理并行读 `apps/desktop/src/features/...`、`packages/...` 的源码，摘出 JSX、完整 className、文案原文、尺寸常量。同时读官网对应区块（`apps/website/index.html` 和 `src/styles/*.css`），列出官网示意和真实界面的差异。**以真实界面为准，只借官网的文案和数据。**

6. **同步本文档**：章节状态、做法、新坑。

## 4. 软件真实情况（写文案和画面时要守住，不要编造功能）

### 数据与本地

- 数据存在 `~/.editor/`：数据库是 `data.db`（SQLite + sqlite-vec），附件在 `resources/`。界面上叫「数据库」，可以有多个库并切换，入口在：设置 › 数据 › 同步 › 「本地数据库」。
- **没有账号体系，不需要注册。**
- 同步是手动的：WebDAV、阿里云 OSS、GitHub、插件（S3 等）。
- 导出：设置 › 导入与导出 › 导出为 Markdown 压缩包。弹窗选项有：
  - 范围：项目 / 文章 / 卡片 / 全部
  - assets 打包
  - 链接格式：相对 .md 或 `[[文件名]]`
  - frontmatter
- ⚠️ **图片默认传 GitHub 图床**，不在本地。所以只能说「笔记 / 数据存在你自己的电脑里」，**不能说「全部在本机」**。官网写了「所有内容都存在你自己的电脑里」，视频不照搬。
- ⚠️ 默认会上报**匿名使用统计**，所以**不能说「不发送任何数据」**。
- 联网的功能：AI 对话（用户自填 Key）、协作（collab.taunote.app）、发布、同步、图床。

### 写作 / 文章

- 文章页：标题 27px semibold。元信息行依次是：「刚刚编辑 · N 字」、`N 处关联`（ContextBadge，**没有关联时不渲染**）、`AI 洞见`、`创作模式`（PanelsLeftRight 图标）。正文版心 720px。
- **文章页没有「离线 · 已保存到本机」状态**，那是官网示意加的。
- 内链样式：`text-accent-text`，下面是 1.5px 点线下划线（38% 的 accent），`underline-offset 3px`。

### 白板（packages/whiteboard）

- **已移除 roughjs**。手绘是自研算法加 perfect-freehand，分三档：工整 / 自然 / 潦草，三档只差抖动幅度。填充有淡涂 / 斜线 / 交叉 / 涂鸦。切换画风是一帧内整体替换，**没有过渡动画**。
- 画风开关在状态栏最左：「普通 / 手绘 · 自然」。
- 顶部工具栏顺序：选择 | 形状 箭头 手写 文本 导图 | 图片 视频 音频 网页 | 文档 白板 | 画框 分栏。组间是 8px 空白，不画竖线。当前工具有一个会滑动的 accent-soft 底块。
- 状态栏（右下）：画风 | − 100% + 全览（只有图标）| 演示。页签条在左下：「＋ 新建页」。
- 导图布局：
  - 水平间距 36，同级竖向间距按层级 24 / 16 / 8。
  - 节点高 = 字号 × 1.57 + 32，节点内边距 16。
  - 连线是 S 形三次贝塞尔，线宽按层级 3 / 2 / 1.5。
  - 8 套配色 × 3 种风格（实心 / 浅底 / 线框），颜色由 `MindThemeUtil.getNodeVisual` 推导。
- 画框：底 `rgba(59,130,246,.1)`，边框 `#3b82f6` 2px，圆角 8。名签在框外上方 50px，高 40，蓝底白字。
- **演示**：对白板容器全屏。切帧时视口用 500ms cubic ease-out 适配到这一帧的元素，四周留 50px。底部导航是「‹ 1 / 2 › · 激光笔 · 退出」，进入时顶部出提示「使用方向键或滚轮导航，按 ESC 退出演示模式」。**演示序列每帧是一组元素 id，不是「一个画框一帧」**（官网的说法和代码不一致，视频按代码）。
- 文档卡尺寸：card 260×240（按 460 版宽缩放），article 280×360（按 620 版宽缩放），圆角 16，`shadow-paper`，底部 h-14 渐隐。缩放低于 0.3 时只画骨架。

## 5. 踩过的坑

1. **渲染器**：Remotion 自带的 chrome-headless-shell 在 macOS 26 上起不来，`remotion.config.ts` 已改用本机 Google Chrome。**Agent 的命令沙箱会挡住 Chrome，所有 `remotion still/render` 都要关掉沙箱**（`dangerouslyDisableSandbox: true`）。
2. **中文字体掉字**：Fontsource 按 unicode-range 懒加载。`brand/fonts.ts` 在首帧前预载，**新文案的字必须进 `PRODUCT_GLYPHS`**（`films/product/copy.ts`）。白板手绘模式下出现的字要进 `mock/board.ts` 的 `BOARD_TEXT`（`preloadFonts` 的第二个参数）。
3. **`interpolate` / `progress` 不接受 Infinity 和 NaN**：会直接崩，而且 `remotion still --log=error` 只显示「fail」不报原因。**看到 fail 就去掉 `--log=error` 重跑一帧看堆栈。** 「不存在的时刻」用 `1e9`。曾经因为 `beat(小数)` 返回 NaN 整段崩掉，已修成支持小数拍。
4. **macOS 文件名不区分大小写**：`liveDoc.ts` 和 `LiveDoc.tsx` 会冲突。
5. **`Sequence` 会重置帧号**：场景都读绝对时间轴，用 `kit/During` 控制挂载。功能片例外，故意用负偏移 `Sequence` 做对齐。
6. **异步取样**：`useTextPoints` 要用 state + effect 配合 `delayRender`。
7. **渐变字**：`background-clip: text` 要包 `inline-block`。
8. **3D 透视**：`perspective` 容器用 flex 居中，不要用 `translate(-50%)` 配 `rotateX`。
9. **宣言居中**：文字层要 `absolute inset-0 flex`。
10. **在 `AppWindow` 外面画软件界面，必须自己带 `data-theme={useAppTheme()} data-mode="light"`**，否则 `--tau-*` 全空，背景透明、填充变黑。演示全屏层、块陈列纸 `BlockPaper`、浏览器窗口都是这样。
11. **镜头交接的速度**：`ease.in` 末端速度趋于无穷，下一段从静止起步会急刹。要么沿原速度继续推进再减速，要么像 `PUSH_IN` / `PUSH_OUT` 那样按「斜率 × 对数缩放跨度 / 时长」配平两段的速度。
12. **画面里的位置不要估算，要实测**：用已知机位渲染全分辨率静帧，PIL 量出屏幕坐标，再按 `世界 = 镜头 + (屏幕 − 960 或 540) / zoom` 换算。写作段的 `LINE_Y` 就是这样量的。估算块高度曾经偏了 120px。
13. **zsh 的通配**：`rm -f dir/*.png` 在没有匹配时报 `no matches found`，命令照样继续。`--include=*.ts` 这类参数也会被 zsh 展开报错，要加引号。
14. **配乐**：Pixabay 有人机验证，Agent 下载不了。依赖安装（`pnpm add`）会触发根 postinstall，约 40 秒。macOS 没有 `timeout`，长渲染用 `run_in_background`。librosa 在临时 venv `/tmp/beatenv`，重启后要重建。
15. **Shiki 是异步的**：`kit/Shiki.tsx` 用 `delayRender` 等结果。
16. **`DocCard` 的 `why` 为空时不显示理由条**：白板里嵌的文章卡就是这样用的。
17. **地图的 lens**：拉远进地图时窗口还没出现，镜头推近要表现成「软件自己把地图放大」——位置随镜头放大，字号 / 半径 / 线宽不变大。`MapView` 的 `lens` 就是这个倍数（= 镜头缩放 / 地图窗口看全的缩放）。窗口浮现以后 lens 固定为 1，再推近就是把窗口本身推近（字跟着变大，和其他章节一致）。两者在 `pull.fit` 那一帧正好相等，无跳变。
18. **本工程是宽行风格（printWidth 200）**：第五个会话加了 `apps/promo-video/.prettierrc.json`（根配置照抄、只改 200 列）和 `.eslintrc.cjs`（prettier 规则改读本目录配置，根配置写死了 100 列），提交钩子的 `eslint --fix` + `prettier --write` 会按 200 列格式化，不再把文件折碎。全工程已按它格式化过一次。
19. **Gallery 把窗口放大 1.25 倍居中**（1440×900 → 1800×1125，左上角在 (60, −22.5)），用 Gallery 静帧量窗口内坐标时要换算回去。
20. **`Cursor` 的路径点必须严格递增**：相邻两次点按间隔小于提前量（0.9 拍）时会报 `inputRange must be strictly monotonically increasing`，给那一次传更小的 lead。
21. **从网格拼图上读坐标要先换算拼图的显示缩放**：Read 显示的图会被缩小（提示里有 Multiply coordinates by …），先乘回原图，再除以渲染 scale，再按坑 19 换算成窗口坐标。曾因漏乘一次把按钮位置读错 30%。
22. **点按坐标用 `Measure-*` 量，不要从静帧估算**：`films/gallery/Measure.tsx` 把某一时刻的窗口 1:1 画在左上角，按文字或 `data-hit` 找到元素，把中心坐标（窗口坐标）**写在画面右侧**（Remotion 不转发组件里的 `console.log`），渲染后 crop 右侧读数。图标按钮没有文字的，在 app-kit 组件上加 `data-hit`（已加：标题栏 `map` / `assist`、停靠栏 `send`、洞见 `link-mark`、AI 段内链 `inline-link`、待办 `todo-check:标题`、日记 `diary-input` / `diary-send`）。
23. **`Cursor` 的 `visibleTo` 缺省是 1e9**（原来是 Infinity，会让 progress 崩，坑 3）。

### 写作 `WriteChapter`（样片 7）
