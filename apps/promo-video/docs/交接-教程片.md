# Tau 使用教程片 · 交接文档

第一支教程片：所见即所得的快捷语法 + 斜杠菜单 + 各种块。和产品宣传片同一个工程（`apps/promo-video`），复用 `app-kit` 的重建界面；宣传片的做法与坑见 [`交接-产品宣传片.md`](交接-产品宣传片.md)。

## 1. 已拍板的决策

- **只用字幕，没有旁白。**
- **声音：音效在前，配乐铺满全片但退后。** 打字声和成型提示音（§5）讲「敲下触发键 → 成型」；配乐从片头铺到片尾（用户看完无配乐样片：「还是得配点音乐，否则太干了」），打字演示时退后（音量 0.5），章节卡 / 片头片尾回来（0.85）。
- **先出画面，再配声音。** 章节长度由内容决定，音效从打字排期导出；声音不驱动时间轴。
- **配乐用现成曲目：Mixkit「Chillax」（Francisco Alvear，New Age）**（§4）。程序作曲试过三版都被否（「还是那么的吵」），脚本已删：
  - chill pop（八分镲 + 十六分沙锤 + 锯齿垫音 + 侧链）：「太吵，背景一直在吵」；
  - 钢琴 + 弦乐分解和弦（起音密度约 2.2 次 / 秒）：先嫌尖，换柔的钢琴采样后仍嫌吵；
  - **选曲口径：起音密度低（约 1 次 / 秒）、几乎没有打击乐、2–6 kHz 少、后段不变满。不要持续的镲片 / 沙锤 / 噪声铺底，转场不用 riser / impact。**
- **斜杠菜单和块都要介绍**（用户要求），不只讲 Markdown 记号。
- **只演真实存在的语法**：以 `packages/editor/src/extensions` 的代码为准（§2），没有快捷方式的块只从斜杠菜单插入。
- 和宣传片的区别：教程以看懂为主，**固定机位，不飞无限画布**；章节之间用文档自己滚动加章节卡过渡。

## 2. 真实支持的快捷语法（核对自源码）

| 触发                 | 语法                                                                                                        | 源码                                                                                  |
| -------------------- | ----------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 行首输入后按**空格** | `#`～`######` 标题、`>` 引用、`-` `*` `+` 无序列表、`1.` 有序列表                                           | `header/src/behaviors.ts`、`blockquote/src/behaviors.ts`、`list/src/normalization.ts` |
| 整行输入后按**回车** | `---` 分割线、` ```语言 ` 代码块、`$$` 公式块                                                               | `divide-line/src/index.tsx`、`code-block/.../behaviors.ts`、`math/src/index.tsx`      |
| 敲下**收尾定界符**   | `***粗斜***` `**粗**` `__粗__` `*斜*` `_斜_` `~~删除~~` `==高亮==` `` `代码` `` `$公式$` `$$公式$$`（行内） | `text-formatting/src/inputRules.ts`、`math/src/inputRules.ts`                         |

行为细节（`core/api/inputRules.ts`）：

- 转换单独成一个撤销步，**撤销回到原始符号**。
- **行内代码里不再识别其他定界符**（`excludeMarks: ["code"]`）。
- `_` / `__` 要求定界符外侧不紧邻字母数字，**`snake_case` 不会变斜体**。
- **粘贴不触发**，只在键入（含输入法上屏）时触发。

**没有输入快捷方式**（只在 Markdown 导入导出时识别，视频里不演记号）：待办 `- [ ]`、链接 `[]()`、提示块、表格。

## 3. 分镜（草案）

1. 记号用淡墨打出来，画面下方出键帽（如 `#` `#` `␣`）。
2. 触发键落下的那一帧当场成型。
3. 底部速查条多一行小标签（「`## ␣` → 二级标题」）。速查条逐条累积，片尾正好汇成速查表。

### 第 7 章 · 斜杠菜单（交互核对自 `core/plugins/withSlashCommands.ts`、`core/stores/useBlockPanelStore.ts`、`core/hotkeys/slashCommand.ts`）

按实做（与草案的出入：子菜单用「标题 › 标题2」，筛选演引用块，表格和 Callout 留到第 8 章，免得重复）：

1. 空行敲 `/`，菜单在光标右下弹出（光标 x + 10、行底）。字幕「在任意位置敲 /，弹出插入菜单」。
2. `→` 打开「标题」子菜单，`↓` 到「标题2」，回车插入；接着打标题文字。
3. 筛选：`/引用` → 退格两次 → `quote` → 退格五次 → `yinyong`，三种写法都命中「引用块」（搜索时只列叶子；退格删到只剩 `/` 时菜单仍开着，再退格才关）。回车插入，`/yinyong` 自动删掉。
4. 敲 `/` 再按 Esc：菜单关掉，`/` 留在正文里，再退格删掉。
5. 收束字幕「记得记号就直接打，记不住就敲 /」。

不演：拼音首字母（不支持）；无匹配时菜单直接消失、没有提示文字。

## 4. 配乐

- 曲目：**Chillax**，Francisco Alvear，New Age，2:24。文件 `public/music/mixkit-chillax.mp3`（原件 `https://assets.mixkit.co/music/655/655.mp3`），登记在 `brand/music.ts` 的 `TRACKS.chillax`。
- 授权：[Mixkit Stock Music Free License](https://mixkit.co/license/)：可商用（含 YouTube 等平台），**无需署名**；不得原样转售。Mixkit 另有仅限非商用的 Restricted License，选别的曲目时看列表页 JSON-LD 的 `copyrightNotice`。条款没提 Content ID，B 站版权识别的情况未核实。
- 用法：从曲内第 14 秒截入（前 10 秒近乎无声），`kit/Soundtrack` 的 `gain` 按帧退后：打字演示 0.5、章节卡 / 片头片尾 0.85，首尾淡入 1.5 秒 / 淡出 3 秒。
- 实测（样片 3）：打字时配乐 -25～-27 LUFS、音效 -19 LUFS；成片声音整体 -20 LUFS，发布前可整体提到 -16。
- **接第二遍**：全片约 182 秒，曲子从第 14 秒截入只够约 130 秒。`TutorialFilm.tsx` 的 `Music` 在曲尾淡出前 12 秒接第二遍、交叉淡化 4 秒，第二遍的截入点倒推到曲尾正好对齐片尾。改了时长不用改它。
- 选曲过程：Pixabay 有人机验证、Agent 下载不了；Mixkit 可直接下载。从 piano / ambient / calm / relaxing 标签下载 24 首，用 librosa 测打击乐占比（HPSS）、2–6 kHz 占比、起音密度、每 10 秒响度曲线，挑出 4 首给用户试听（Smooth Meditation、Chillax、Forest Walk、Classical vibes 3），用户选了 Chillax。候选原件在 `~/.cache/tau-promo/mixkit/`（不入库）。

## 5. 音效（正片）

脚本 `scripts/sfx/sfx.py`，全部合成、不用采样，依赖由 uv 按脚本头自动装。

```bash
uv run scripts/sfx/sfx.py scripts/sfx/sfx-sample.json out/music/sfx-sample.wav --mp3
```

- 事件表 `[{ t: 秒, kind }]`，`kind` 取 `key`（普通字符）/ `space` / `enter`（触发键，更低更厚）/ `form`（成型提示音）。成片时由按键重放的时间轴（`films/tutorial/run.ts`）导出，画面与声音读同一份时刻，天然同步。
- **音色用户已认可**（`out/music/sfx-sample.mp3`），正片沿用。
- 打字声：低频木质「哒」+ 少量带通噪声，低通到 3 kHz，每次音高 / 音量略有随机；成型提示：F4 → C5 上行五度的木槌音，间隔 60 ms。
- `sfx-sample.json` 是演示用的事件表（标题、引用、粗体、分割线），2–6 kHz 能量占比 0.10%。

## 7. 实现（全片 10 章已做，最新样片 `out/教程片-样片4-全片.mp4`）

Composition `Tutorial-Syntax`，代码在 `src/films/tutorial/`：

- `model.ts`：迷你编辑器。块快捷、回车快捷、行内输入规则（逐行对照 `core/kit/inputRules.ts` 的 `matchInputRule`）、撤销回到原始符号；斜杠菜单（打开 / 筛选 / 子菜单 / 插入）；任务列表、表格、标签页、提示 / 详情 / 高亮块、流程图、嵌入块；点按（`click`）。文档是 `{ blocks, focus, panel }`。纯 TS。
- `run.ts`：把一章的步骤（字幕 / 打字 / 特殊键 / 点按 / 嵌入块 / 速查条）逐键重放成时间轴：文档快照、键帽、点按、字幕、速查条、音效事件。触发键前自动停顿，成型后留时间看清。纯 TS。
- `script.ts`：各章脚本与文案，`TUTORIAL_GLYPHS` 进 `Root.tsx` 的字体预载。
- `timeline.ts`：片头 → 章节卡 + 按键重放首尾相接 → 速查表（停 560 帧）→ 片尾，**时长全由内容决定**；章节卡虚化最浓时换成下一章的空文章。
- `TutorialDoc.tsx`：快照渲染，样式复用 `app-kit/doc/LiveDoc.tsx` 导出的 `HEADING_SIZE / BULLET_ITEM / QuoteFrame / CodeBlock / MathBlock / formStyle`；没成型的记号淡墨显示。
- `TutorialFilm.tsx`：窗口放大 1.45 倍、正文版心中心停在画面 x=830；**每帧测量**光标行（`data-caret`）、各行（`data-anchor` / `data-block-end`）、可点元素（`data-hit`）与斜杠菜单（`data-slash-panel`），正文像打字机模式那样滚动，让光标行停在 y=470，换行时 16 帧缓动；斜杠菜单打开时光标行再上移 150，键帽挪到菜单右侧；点按时从右下方移来一个 macOS 光标。片尾字标、配乐接第二遍也在这里。
- `Overlays.tsx`：键帽（触发键染 accent，一组最多显示最近 5 个）、底部字幕条、右侧速查条、第 9 章速查表。

音效：`pnpm tutorial:sfx` 从同一份时间轴导出事件表，合成 `public/sfx/tutorial-syntax.mp3`。**改了章节脚本要重跑**，否则声音和画面对不上。配乐的退后曲线（`timeline.ts` 的 `typingWeight`）每帧从时间轴算，不用重跑。
只改了声音时不必重渲画面：`npx remotion render src/index.ts Tutorial-Syntax out/music/tutorial-mix.m4a --codec=aac`（约 2 分钟），再用 `ffmpeg -i 旧片.mp4 -i tutorial-mix.m4a -map 0:v -map 1:a -c copy 新片.mp4` 换音轨。

```bash
npx remotion still src/index.ts Tutorial-Syntax out/frames/tut/f1500.png --frame=1500 --scale=0.5 --log=error
npx remotion render src/index.ts Tutorial-Syntax "out/教程片-样片N.mp4" --codec=h264 --scale=0.5 --crf=28 --concurrency=4 --log=error   # 全片 182 秒约 17 分钟（放后台）
uv run --quiet --with numpy python scripts/scan-glitches.py "out/教程片-样片N.mp4"
```

坑：

- **测量一律用 `offsetTop` / `offsetLeft`（`offsetIn`），不用 `getBoundingClientRect`**：后者带 transform 与亚像素，缩放 + 小数滚动下「测量 → 滚动 → 再测量」会无限循环（React 错误 #185）；加容差能止住循环，但整片并行渲染时 4 个标签页各自留着差零点几像素的旧值，成型回弹、详情块收起这类动画之后，键帽与正文以 4 帧为周期上下抖（用户在 15 秒、2:21 发现）。offset 是排版整数、不受 transform 和滚动影响，各标签页量到的一样。
- `kit/Shiki.tsx` 原来只在挂载时 `delayRender` 一次，逐字敲代码时会截到上一帧的高亮；已改为每份代码各等一次，结果按代码记。
- **点完会消失的按钮**（流程图「完成」）：点按的 `data-hit` 放在一个常驻的透明标记上，按钮消失后光标仍量得到位置，涟漪不跳。
- `pnpm frames` 曾因格式化给 `music.ts` 的 beats 表加了尾逗号而 `JSON.parse` 失败，`scripts/beat-frames.mjs` 已去掉尾逗号再解析。

终版：`out/教程片-终版.mp4`（1080p60，3:01，声音 -16 LUFS / 峰值 -1.5 dBFS）。出法：

1. `npx remotion render src/index.ts Tutorial-Syntax out/教程片-终版-raw.mp4 --codec=h264 --crf=17 --concurrency=4`（约 50 分钟）。
2. `scan-glitches.py` 扫丢帧。这次有 2 帧（1667、9805）被 Chrome 渲成 3×3 平铺的碎画面；不整片重渲，单独 `remotion still` 这两帧，再用 ffmpeg `overlay=enable='eq(n\,帧号)'` 换进去。
3. 同一次编码里做两遍 `loudnorm`（先测再按测得值 `linear=true` 拉到 -16 LUFS），`-crf 16 -preset slow`。zsh 里变量后面紧跟 `:` 会被当成修饰符（`$OFF:l`），滤镜串里的变量要写成 `${OFF}`。
