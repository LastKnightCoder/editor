# Tau 产品介绍片 · 分镜草案 v0

骨架：**宣言 + 能力蒙太奇**。全片约 3 分钟，没有时间线概念。

每一段的写法：

1. 先在纯色底上用超大衬线字打出一句宣言，1.5–2 秒。
2. 宣言卡在强拍上，接一段快节奏的能力蒙太奇。
3. 重点能力再给一个 6–10 秒的"哇"镜头，然后进入下一句宣言。

画面不再一直是"窗口居中"，会穿插这几种手法：

- 界面零件拆开悬浮
- 窗口 3D 倾斜
- 局部特写放大
- 纯色底大字

## 0. 冷开场（0:00–0:14）

- 0–8s：卡点快切 8 个最强镜头，每个约 1 秒。依次是：打字即成型、斜杠插入块、公式渲染、白板召集资料、星图生长、内容落进本地文件夹、闪卡翻面、插件安装。
- 8–14s：画面全部收进黑场，出现 Tau 图标。宣言：**「为思考而生的知识工作台。」**

## 1. 编辑器（0:14–0:50，重点）

**宣言 1：「所见，即所得。」**

- 和 Notion 一样的就地成型，不分屏：在文档里直接打 Markdown 记号，敲完记号当场变成对应排版（`## ` → 标题，`> ` → 引用，`**…**` → 加粗，`` `…` `` → 行内代码，`- ` → 列表，`$$` → 公式，` ``` ` → 代码块高亮）。
- 镜头贴着光标特写，每次成型时记号淡出、排版弹出，卡在节拍上。

**宣言 2：「一个块，就是一种表达。」**（快速带过，约 5 秒）

- 输入 `/` 弹出斜杠菜单，紧接着 8 个代表性块按节拍快切，每个 0.5 秒左右：表格、代码块、公式、Callout、Mermaid 图表、图集、Tabs、数据库视图。
- 最后一拍收回到文档里，输入 `[[` 链接到另一篇笔记。

## 2. 创作模式 + AI（1:05–1:50，重点）

**宣言 3：「不必从一张白纸开始。」**

- 创作模式：左边白板、右边正文。AI 把相关的卡片、划线、文章"召集"到白板上，卡片逐张飞入落位。
- 写作时，和当前段落相关的那张卡片亮起；点击「标出可引用处」后，编号逐个点亮。

**宣言 4：「一个读过你全部笔记的 AI。」**

蒙太奇三连：

- 小管家：搜索知识库、改写正文、新建待办，工具调用卡片逐个完成。
- 洞见：AI 指出"这两篇说的是同一件事""这里还缺一环"。
- 创作：召集资料，和第 2 段开头呼应。

## 3. 知识地图（1:50–2:20，重点）

**宣言 5：「想法之间，自有引力。」**

- 一条双链 → 两个节点相连 → 整片星图生长 → 自动聚类，主题名浮现 → 洞见弧线接上两年前的一张卡。
- 星图沿用并加强场景片里的那一段。

## 4. 本地数据（2:20–2:40，重点）

**宣言 6：「你的数据，只在你手里。」**

- 口径：数据全在本地，不是不联网。
- 卡片、文章、白板等内容化作光点，落进本机的一个文件夹（库），没有云端中转。
- 一键导出 Markdown，随时带走。
- 收一句：**「无需注册，本地优先。」**

## 5. All in one 蒙太奇（2:40–2:52）

**宣言 7：「一个工作台，装下整个知识生活。」**

卡点快切，每个镜头 0.6 秒：PDF 划线、浏览器剪藏、Notebook、闪卡、漫步、番茄、日程、待办、日记、发布博客、实时协作、插件中心、MCP。

## 6. 收尾（2:52–3:05）

- 所有画面收拢成一点，绽开为 Tau 图标。
- 依次出现：**「你的知识，在这里长成体系。」**、taunote.app。

## 配乐

3 分钟的宣言蒙太奇需要明确的节拍和至少两次推进。暂定的 Inspiring Piano & Strings 长 2:34、偏抒情，不太够。见对话中的选项。
