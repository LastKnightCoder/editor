# Tau 功能片系列 · 交接文档

一支功能片：`Feature-VideoNotes`（视频笔记，Bilibili / YouTube 插件作为入口一章带过）。和产品片、教程片同一个工程（`apps/promo-video`），复用 `app-kit` 的重建界面；那两支片的做法与坑见 [`交接-产品宣传片.md`](交接-产品宣传片.md)、[`交接-教程片.md`](交接-教程片.md)。之后别的功能按同一套骨架（`films/feature-films/shared/`）继续出片。

## 1. 已拍板的决策

- **拆法**：只有一支主片，把插件当入口一章演全。两支插件短片原计划各 20 秒、可单独投稿，看过第一版样片后用户决定不做了。
- **配乐（用户选定）**：找一首新曲，作为功能片系列的固定配乐，见 §4。
- **节奏跟内容走**（同教程片）：时长由脚本回放决定，配乐当背景。换曲不改时间轴。
- **镜头语言取产品片**：宣言叠在虚化的窗口上（样式 a），不硬切、不交叉淡化；有点按就上光标；一个操作序列一个固定机位，运镜至少 1 秒、停住至少半秒；入口路径演全，弹窗至少停 1 秒。
- **点按要快，界面跟着光标走**（用户看过第 2 版样片后的反馈：「点击节奏太慢，没必要点击停半天」「菜单鼠标还没放上去就高亮了，二级菜单提前出来了」）：
  - 一次点按约半秒：光标移过去 20 帧、到了就按，按完停 12 帧。要让人看清的东西（确认框、解析结果）单独用 `wait` 留时间，不在每次点按后面都拖一拍。第 2 版是 0.93 秒一次，全片 131 秒；改后 98 秒。
  - 菜单项的高亮、二级菜单的展开、下拉选项的高亮都按「光标此刻在哪」算（`tools.under()`），不写死时刻。鼠标停上去要有 `hover` 这一步，光标才真的会移过去；二级菜单在停上去约 0.25 秒后展开，展开后父项保持高亮。
  - 按钮还在动的时候（对话栏滑出、文档树展开）先 `wait`，等它停稳再让光标移过去。
- **第 4 版重排叙事（用户看过第 3 版后要求「做得和产品片一样有质感」，允许重写）**：
  - 先给成品：片头直接是记好的视频笔记在播，宣言叠在上面（样式 a），不再整屏标题。
  - 「视频从哪来」压成一遍：只装 Bilibili、只加一个视频，YouTube 只在字幕里带过。不再演两遍同样的流程。
  - 摘录、时间戳、截帧是一个连续的动作序列，放一章里；镜头推到 1.4 倍，跟着动作在字幕、笔记、播放器之间平移。
  - 章节卡只留两张：「每一行笔记，都记得出处。」（点回那一刻）和「不是总结，是一本书。」（电子书）。字幕写效果，不写操作说明。
  - 挂载字幕砍掉（看不出价值、和主线无关）。本地视频转录也砍过，第 6 版改成单独一章（见下）。
- **画面配色跟软件的海盐蓝走（用户指出暖色不搭）**：播放器里的课件、电子书封面用深海蓝底 + 盐白字 + 浅海盐蓝强调（`LectureSlide.tsx` 的 `SLIDE_COLORS`），不再用米黄纸底 + 赭石色。舞台冷白、窗口海盐不变。
- **第 5 版：放慢、让人看清在操作什么（用户看第 4 版：「节奏好快」「用户没感知到重点」「看不到你在操作什么」「添加视频那步没有点击的感觉，二级菜单离得那么远」）**：
  - 点按约 0.8 秒：光标移过去 28 帧、在目标上停 8 帧再按（`PACE.settle`），按下时目标处荡开一圈强调色涟漪（`FeatureFrame` 的 `ClickRings`）。光标曾放大到 1.5 倍，第 6 版用户要求恢复原大小。
  - 每一步做完用 `{ spot: <data-hit>, hold }` 圈出结果：强调色描边 + 四周压淡，停 1–2 秒（`Spotlight`）。
  - 五章各有章节卡点题；字幕先说「做什么」，再说「得到什么」。
  - 「+」菜单的二级菜单贴着「添加视频」那一行右边 4px 展开（真实 `Menu` 的 `right-start`），不再挂在文档栏的右边缘。
  - 粘贴的链接用地址栏里的 BV 号链接 `https://www.bilibili.com/video/BV…`（BV 号是示意），不用 b23.tv 短链。
  - 全片约 110 秒。
- **第 6 版：转录单独成章、截帧看得见、AI 多演几种问法（用户看第 5 版：「截图那块视口不在截的图上」「划字幕时鼠标没和字幕对齐，鼠标不用那么大」「转录是好功能，太简单、太突兀，得在前面介绍」「AI 多点场景：总结、提问、搜索、字幕直接问」）**：
  - 光标恢复原大小；划选的起止锚点落在字上。错位的原因是测量只减了 `offsetParent` 链上的滚动，字幕的滚动容器不在链上，现在沿 `parentElement` 链把所有祖先的滚动都减掉；字幕跟随滚动改按「这句在内容里的位置」算（`transcript-content`），不再依赖当前滚动。
  - 转录放在「视频从哪来」之后、记笔记之前单独一章：添加的视频不带字幕 → 点「开始转录」→「正在准备视频… / 正在提取音频… / 正在转录 … N%」→ toast「转录完成」，字幕逐句出现 → 标题行下「正在分章节…」→ 章节段头与进度条分段出现。字幕讲清楚两点：在本机完成、视频不上传；有了字幕才能划句摘录、让 AI 读懂这节课。章节卡「讲的每一句，都变成字幕。」副标题「有字幕直接用 · 没有就在本机转录」（平台自带字幕会自动读取，这里只在副标题带过）。
  - 截帧：按 ⌘⇧S 时镜头拉开到播放器和整栏笔记同框（`SHOT`），这一帧从播放器沿弧线飞进笔记里截图的位置（`ShotFlight`），落地后推近这张图（`SHOT_NOTE`），再拉开看进度条上新弹出的方块。
  - 问 AI 一章演三问，在同一个对话里：点建议提问「总结这个视频的核心观点」（直接发送，工具行 `get_video_note_transcript_range`）→ 自己打一问「学新东西时，该先用哪种模式？」（工具行先 `search_video_note_knowledge` 再 `get_video_note_transcript_range`，圈出工具行讲「先在字幕里找到出处」）→ 划一句「问 AI」→ 原句带进输入框上方 →「举个例子」→ 发送。工具名与「先搜再读一段」的顺序取自 `tools/videoNoteSearchTool.ts` 的系统提示词。章节卡改为「关于这节课，尽管问。」副标题「总结 · 提问 · 划一句问」。
  - 全片约 139 秒。
- **AI 导出电子书是收尾（用户定）**：演弹窗内部的两步（选风格 → 草稿流出 → 下一步 → 改书名 → 导出 EPUB → 访达里选中）。用户的初衷：大家常用 AI 总结，但总结会丢掉精华；这里刻意把内容写长，给没耐心看视频、但有时间看书的人。片里用章节卡「不是总结，是一本书。」和最后一句字幕「没耐心看完的课，留着慢慢读」讲这个意思。
- **讲解用字幕 + 键帽，没有旁白**（沿用教程片的决定）。
- **演示内容取官网文档的例子**（`apps/website/content/docs/video-notes.md`）：「学会学习」项目、《Learning How to Learn》、「专注模式与发散模式」这一节、摘录「卡住的时候先离开一会儿」。播放器里是代码画的讲解幻灯片（`app-kit/parts/LectureSlide.tsx`），**不用任何真实视频画面**。
- **全片一个宽窗口 1760×990**：视频笔记里对话要停靠成第三栏需要条目区 ≥ 1280 宽，1440 的窗口放不下（会盖在笔记上）。
- **只演真实存在的**：以 `apps/desktop`、`plugins/tau-plugin-*` 的源码为准（§3）。

## 3. 软件真实情况（写文案和画面时要守住）

### 插件中心（`features/plugins`）

- 入口：侧栏底部「插件」。发现页：标题「插件」+「扩展页面、侧边栏、命令与摘录来源」+「全部分类」+ 排序下拉（最近热门 / 下载最多 / 最近更新）+ 搜索「搜索插件」+ ⋯；页签「发现 / 已安装 N / 更新」。
- **搜索匹配** id、名称、简介、关键词，不匹配作者。搜「Bilibili」「YouTube」各出一张卡。
- 卡片：首字图标、名称、`@作者`、两行简介、分类标签（视频）、版本 + 下载图标 + 次数 + 「安装」。点卡片 anywhere 进详情页。
- **普通插件装好即用，不重启**（`PluginParts.tsx` 的 `INSTALL_NOTICE`：「…安装后即启用，可随时在「已安装」中停用。普通插件立即生效，编辑器和白板内容插件需重启应用后生效。」）。视频插件是普通插件。
- 安装：点「安装」→ 确认框「安装「Bilibili」0.2.7？」，正文是上面那段提示 + 复选框「以后安装不再提示（含后台的插件仍会提示，可在插件页「⋯」中恢复）」（默认不勾）→「安装」→ 按钮「下载校验中」→ 胶囊「已安装」，卡片右上多出启用开关。「已安装 N」加一。
- 详情页（点卡片或「已安装」里的行进入，**默认停在「介绍」**）：大图标 + 名称 + `@作者` · 版本 · 「插件中心」·「已启用」+ 右侧启用开关和 ⋯；页签「介绍 / 设置 / 权限 / 更新日志 / 版本 / 评论与喜欢」。**没有比这更短的路径到设置。**
- 设置页签（视频插件）：卡片头「视频网站」+「使用中」+「添加该网站的视频时使用这份配置」。
  - Bilibili 是自定义组件：未登录「未登录也可以添加视频，默认最高 720P；登录后可选择更高清晰度。」+「扫码登录 / 手动填写」→ 二维码（180px）+ 状态「正在获取二维码…」「使用 Bilibili 手机客户端扫码登录」「已扫码，请在手机上确认登录」「二维码已过期，请刷新」+「获取二维码 / 刷新二维码」；登录后头像 + 名称 +「大会员 / 普通用户」+「登录后可选择更高清晰度；大会员可使用 1080P+ 与 4K。」+「退出登录」。手动填写是 SESSDATA 和 bfe_id。
  - YouTube 是声明式表单：分组「网络连接」，一行「代理地址」（等宽输入框，占位 `http://127.0.0.1:7890`，说明「留空直连；支持 HTTP、HTTPS、SOCKS5 代理，可选」）；改动后底部浮出「保存 ⌘S / 还原」。
- 插件卡片数据：名称、简介、版本取自 `plugins/tau-plugin-*/manifest.json`（Bilibili 0.2.7，YouTube 0.2.8）；作者和下载次数只在插件中心服务端，视频里用演示数字。
- 视频片里二维码画成不可扫的装饰图案，不放真实登录链接。

### 项目 › 添加视频（`features/projects`）

- 项目页：左侧项目栏 300px，栏头 60px：「返回项目列表」小房子 + 项目名下拉 + 视图切换 +「+」；下面是文档树。
- 「+」菜单依次：添加文档、添加白板、**添加视频 ›**（本地视频 / 远程视频 / 已启用的视频插件名）、添加网页、添加表格、添加 PDF ›、关联卡片、关联白板、导入Markdown。
- 选插件名 → 弹窗「添加 Bilibili 视频」，副题「粘贴视频链接，解析后选择清晰度」，440 宽：字段「视频链接」（占位 `https://`）→「取消 / 解析视频」（链接为空时禁用）→ 解析中按钮变「正在解析…」→ 解析后：封面 + 标题 + 来源名、「清晰度」下拉、底栏「返回 / 确认添加」。
- 清晰度选项（Bilibili，`provider.ts`）：「360P 流畅」「480P 清晰」「720P 高清」「720P60 高帧率 · 需登录」「1080P 高清 · 需登录」「1080P+ 高码率 · 大会员」「1080P60 高帧率 · 大会员」「4K 超清 · 大会员」。YouTube：「720p」「1080p60」等，后缀是格式（MP4 / WEBM）。
- 确认后：弹窗关、toast「视频笔记添加成功」、文档树多出一行（视频图标）并**自动打开**成视频笔记。
- 视频笔记里文档树放不下两栏时自动收起，标题栏面包屑左侧的按钮可以重新展开。
- 不演：系统文件选择框（本地视频）。

### 视频笔记（`features/projects/.../VideoNoteView`、`components/VideoNotePanel`）

- 标题行 52px：视频图标 + 标题 +「Bilibili · 已转录」（来源 · 转录状态：转录中… / 已转录 / 未转录）+ 右侧对话按钮、⋯。
- 左栏约 56% 宽：播放器卡片，下面一行「转录 · N 段 · N 章」，再下面是字幕。
- 缓存中：16:9 的凹底框里「正在缓存 Bilibili 视频」+「正在获取视频信息…」+「视频 / 音频」两条进度（`12.3 MB / 45.6 MB`），完成后「视频已就绪」。
- 播放器：黑色画面区；控制条依次是播放圆钮、时间 `12:48 / 1:26:35`、当前章节名、音量、`1×`、画中画、全屏；进度条按章节分段，有刻度时控制条变高。
- 字幕：章节名吸顶作段头（时间 + 标题）；每句左时间右文字，当前句整行选中底、时间染强调色；**已摘录的句子留浅色强调底 + 后面一支小笔**；随播放滚动到当前句居中。点一句从这里播放。
- 划选一句或几句 → 工具条出现在选区上方 44px：「摘到笔记」（强调色）/「问 AI」/ 分隔线 / ▶ / 复制。
- 右栏：标签页「笔记 1」+「+」，右侧「插入时间戳」「截取当前帧」「⋯」。**没有笔记时是空态**「还没有笔记 / 边看边记，时间戳和截帧都能一键插入 / 新建笔记」；第一次摘录会自动建一篇，叫「笔记 1」。
- 摘录插进笔记是引用块，开头带时间戳芯片。时间戳芯片 `MM:SS`（分补零），点击跳播，悬停浮出当时画面。截帧是图片块，说明「视频截图 - MM:SS」。
- 进度条下方的刻度：时间戳是空心圆点，摘录是实心圆点，截帧是方块；悬停显示笔记内容「… / 摘录 · 笔记 1」。
- 没有字幕：空态「还没有转录。转录后能跟着字幕读、划句子摘到笔记，也能让 AI 基于视频内容回答」+「开始转录」+「自动识别语言，需要指定语言可在右上角 ⋯ 中选择」。转录中：「转录完成后，字幕会出现在这里 / 可以先开始记笔记，时间戳和截帧不依赖转录」，标题行状态变「转录中…」。
- ⋯ 菜单：本次转录设置…、重新转录（或指定语言转录）、AI 优化断句、重新生成章节、挂载字幕（或取消挂载字幕）、分隔线、AI 导出电子书。

## 7. 实现与踩坑

### 共用骨架（`src/films/feature-films/shared/`）

- `run.ts`：回放引擎（仿教程片）。步骤脚本 → 事件时间轴：字幕、点按、悬停、划选、键帽、打字进度、状态时刻、音效。步骤有 `cue / wait / click / hover / keys / drag / type / mark / sfx`；`click`、`hover`、`keys` 可以用 `as` 把帧号记成状态时刻，场景用 `mark(名字)` 取；`tools.under()` 告诉场景光标此刻停在哪。
- `timeline.ts`：片头 → 各章（章节卡 + 回放）→ 片尾，时长由内容决定。每章可以给 `view`（章节卡退场时镜头落到这里）或 `shots`（章内换机位的一串关键帧，`script.ts` 里的 `cameraPath`）。
- `FeatureFrame.tsx`：外壳。舞台 + 宽窗口 + 镜头 + 光标 + 章节卡 + 字幕 + 键帽 + 片头片尾 + 声音。光标的路径就是回放里的每一站（点按、悬停、划选的起终点）。每一章的画面是影片给的一个场景函数（读回放时间轴决定此刻界面的状态），场景只管窗口里的内容。
- **每章的状态只从本章的回放里取**：上一章结束时的东西（笔记里已有的内容、文档树里已有的视频）要么写进演示数据，要么用同一套算式从那一章的回放里重算（`VideoNotesFilm.tsx` 里的 `STAMP_TIME` / `SHOT_TIME`）。两段连续的动作放在同一章里（摘录、时间戳、截帧就是），不要拆开。
- 章节自带 `shots` 时，第一帧是接手机位：有章节卡就在卡片虚化里走过去，没有章节卡就必须和上一章收尾的机位相同（否则会硬切）。
- 空字幕 `{ cue: "" }` 收起字幕条：画面底部有要点的东西（对话的快捷提问、发送键）时用。键帽固定在画面右下角，不跟窗口走（特写里窗口右下角常在画外）。
- 量点按位置：每帧按真实排版量各 `data-hit` 元素的中心（`offsetTop` / `offsetLeft`，再沿 `parentElement` 链减去所有祖先滚过的像素：滚动容器常常不在 `offsetParent` 链上，只减链上的会让光标对不上滚动过的内容）。**量到不一样才 setState**，每帧都设会无限重渲。
- 字幕跟随滚动：当前句挪到视口正中 = 这一句在内容里的中心（`segment:N` 减 `transcript-content` 顶边）减半个视口高，用 `data-hit` 的实测位置算，不估行高。

### 踩坑

- **Remotion 自带命令每跑一次就重新打包一次**（约 20 秒）：抽多帧用 `pnpm stills <CompositionId> <目录> <帧号,帧号…>`，一次打包连出；网格图用 `pnpm grid <CompositionId> <目录> <帧号…>`（原来的 `pnpm grid` 第一个参数是目录，现在第一个是 Composition）。
- **`aspect-video` 的容器里 `h-full` 撑不出高度**，里面的 `cqw` 字号和分栏都会乱：幻灯片根节点用 `absolute inset-0`，外面套定位过的容器。
- 网格里放分隔线：分隔线也是网格项，三样东西要写 `grid-cols-[1fr_auto_1fr]`，不然第三样掉到第二行。
- **`span` 上的宽高不生效**：不在伸缩容器里的开关、胶囊要 `inline-block`。
- zsh 会把 `$id[` 当成数组下标、把 `--include=*.ts` 展开报错：写脚本时变量用 `${id}`，通配加引号。
- 用 Python 往 `.ts` 里写模板字符串时，反引号前的反斜杠会留在文件里（把模板字符串转义掉）：这类文件用编辑器直接写。
- 演示视频别用一两个小时的课：进度条上几秒钟的刻度会叠在一起，看不到「空心圆点弹出来」。
- **界面的变化不能按写死的时刻触发**（高亮、二级菜单、下拉选项）：要让光标先移过去。只抽单帧自检时，已经消失的元素量不到位置，光标会退回更早的一站——这是单帧渲染没有历史，成片里不会出现。
